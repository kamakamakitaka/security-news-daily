# パスワード管理アプリ「Dashlane」で暗号化された金庫データが流出――20人未満のユーザーが被害

**元記事**: [Dashlane Discloses Brute-Force Attack, Encrypted Vaults of Fewer Than 20 Users Downloaded](https://inl03.netline.com/ltr6/?_m=3n.009a.3993.sp0ao46r89.31no)
**解説日**: 2025年6月

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な仕組みを押さえておきましょう。

### 🔐 パスワードマネージャーとは？

みなさんは、SNS・学校のポータルサイト・ゲームアカウントなど、たくさんのサービスにログインしていると思います。それぞれのパスワードを全部覚えるのは大変ですよね。

**パスワードマネージャー**とは、いわば「デジタルの鍵束」です。様々なサービスのID・パスワードを一か所にまとめて管理してくれるアプリです。**Dashlane（ダッシュレーン）**はその代表的なサービスの一つで、世界中で多くのユーザーに使われています。

### 🗄️ 暗号化された「ボルト（Vault）」とは？

パスワードマネージャーの中身は、**「ボルト（Vault）」** と呼ばれます。日本語にすると「金庫」です。

- あなたのID・パスワードの一覧が、金庫の中にしまわれているイメージです
- この金庫は**暗号化**されています。つまり、データ自体は暗号（パズルのような変換）がかかっており、正しい「鍵」がないと中身を読めません
- その「鍵」にあたるのが、**マスターパスワード**（後述）です

### 🔑 マスターパスワードとは？

パスワードマネージャーを開くための、**たった一つの大切なパスワード**です。「金庫の鍵」のようなもので、これさえ知らなければ、暗号化された金庫を手に入れても中身を読むことはできません。

### 📱 二段階認証（2FA）とは？

**2FA（Two-Factor Authentication）**とは、ログイン時に「パスワード」だけでなく、**もう一つの確認手段**を組み合わせるセキュリティの仕組みです。

> **例え話**：銀行の ATM に「キャッシュカード（持ち物）＋暗証番号（知識）」の両方が必要なのと同じ考え方です。スマホのSMSに届く確認コードや、認証アプリのワンタイムパスワードがその代表例です。

### 💪 ブルートフォース攻撃（総当たり攻撃）とは？

**ブルートフォース（Brute-Force）攻撃**とは、「力任せ」という意味の英語のとおり、パスワードや認証コードを**片っ端から全部試す**攻撃手法です。

> **例え話**：ダイヤル式の鍵（0〜9の4桁）を「0000、0001、0002…9999」と順番に全部試して解錠しようとするイメージです。コンピューターを使えば、膨大な組み合わせを高速で試せてしまいます。

## 何が起きたのか

2026年5月31日、**身元不明の攻撃者**が、Dashlaneの一部ユーザーアカウントに対してブルートフォース攻撃を仕掛けました。

出来事の流れをまとめると以下のとおりです：

```
① 攻撃者が特定のDashlaneユーザーアカウントに
　 ブルートフォース攻撃を開始
        ↓
② 2FA（二段階認証）を突破し、
　 新しいデバイスを登録しようとした
        ↓
③ 大量の不正アクセス試行をDashlaneが検知し、
　 一時的にアカウントを凍結・認証に問題が発生
        ↓
④ 一部（20人未満）のアカウントで攻撃が成功し、
　 暗号化されたボルト（金庫データ）がダウンロードされた
        ↓
⑤ Dashlaneが被害ユーザーに直接通知
```

Dashlaneは被害を受けた**20人未満のユーザー全員に直接連絡済み**であり、「Dashlaneから特定の通知を受け取っていなければ、あなたのアカウントへの影響はありません」と述べています。

## 技術的な詳細

### どうやって2FAを突破したのか？

今回の攻撃のポイントは、**2FAを突破しようとした**ことです。

通常、ブルートフォース攻撃でパスワードを破っても、2FAが有効であれば「SMSの確認コードは？」という壁がさらに立ちはだかります。

攻撃者はこの**2FAのコードも含めて総当たりで試した**と見られています。2FAのワンタイムコードは一般的に6桁の数字（000000〜999999）なので、**有効時間内（通常30秒）**に素早く試し続けることで、突破できるケースがあります。

```
通常のログインの流れ:
  パスワード入力 → 2FAコード入力 → ログイン成功

攻撃者がやったこと:
  パスワードを総当たりで入力 → 2FAコードも総当たりで入力
  → 一部で成功 → 新しいデバイスを登録 → ボルトをダウンロード
```

### 流出したデータは危険なの？

ここが重要なポイントです。

流出したのは**「暗号化された」ボルト**です。暗号化されているということは、**マスターパスワードがわからない限り、中身は読めません**。

> **例え話**：金庫ごと盗まれたけど、金庫は頑丈な特殊合金製。鍵がなければ開けられない、という状況です。

ただし、マスターパスワードが「123456」や「password」のような**簡単なもの**だった場合、攻撃者は金庫を解読できてしまう可能性があります。

## なぜ重要なのか

### 🎯 パスワードマネージャーは「すべての鍵を持つ鍵束」

パスワードマネージャーの金庫の中には、あなたが使っている**すべてのサービスのID・パスワード**が入っています。

もしこの金庫を解読されると…

| サービス | 影響 |
|---|---|
| SNS（Instagram、Xなど） | アカウントを乗っ取られる |
| ネットバンキング | お金を不正に引き出される |
| ショッピングサイト | 不正購入される |
| メールアカウント | 個人情報・秘密の連絡が漏れる |

つまり、**一か所やられるだけで全部やられる**というリスクがあります。だからこそ、パスワードマネージャーのセキュリティは非常に重要です。

### 📌 今回の被害は限定的だったが、教訓は大きい

- 被害は20人未満と少人数でしたが、**パスワードマネージャー自体も攻撃対象になり得る**ということが改めて示されました
- Dashlane自体のサーバーや内部システムには侵入されていないため、**会社側の大規模情報漏洩ではない**のが不幸中の幸いです

## 対策・今後の展望

Dashlaneは今回の件を受けて、全ユーザーに以下の対策を推奨しています。

### ✅ あなたが今すぐできること

#### 1. 登録デバイスを確認する
アカウントに登録されているデバイス一覧を見て、**身に覚えのないデバイスがあれば削除**しましょう。攻撃者が不正に登録したデバイスが残っている可能性があります。

#### 2. 2FA（二段階認証）を有効にする
まだ設定していない人は、**今すぐ有効にしてください**。突破されにくい認証アプリ（Google AuthenticatorやAuthyなど）の使用がより安全です。

#### 3. 強いマスターパスワードを設定する
マスターパスワードは以下の条件を満たすものにしましょう：

| 条件 | 悪い例 | 良い例 |
|---|---|---|
| 長い（12文字以上） | `pass` | `MyD0g-Loves-Ramen!2024` |
| 推測されにくい | `123456` | ランダムな文字列 |
| 他で使い回していない | 他のサービスと同じ | このサービス専用 |

> **覚え方のコツ**：好きなフレーズや文章の頭文字を組み合わせる方法が便利です。例：「私の猫は毎朝6時に起きる」→ `WnNhM6jO!` など

#### 4. パスワードマネージャー自体の使い方を見直す
- 定期的に登録デバイスや連携アプリを確認する習慣をつけましょう
- 不審なログイン通知が届いたら、すぐに対応を

## 過去記事との関連

今回の記事は単独での紹介ですが、**パスワードマネージャーへの攻撃**という文脈では、2022年に起きた**LastPass（ラストパス）の大規模情報漏洩事件**が有名な先行事例として挙げられます。

LastPassでは攻撃者が内部システムへの侵入に成功し、多数のユーザーの暗号化されたボルトが盗まれました。あの事件との違いは以下のとおりです：

| 比較 | LastPass（2022年） | Dashlane（今回） |
|---|---|---|
| 侵入経路 | 会社内部システムへの侵入 | 個別ユーザーへのブルートフォース |
| 被害規模 | 大規模（多数ユーザー） | 限定的（20人未満） |
| 会社システムへの侵入 | あり | なし |

パスワードマネージャーは便利ですが、**「絶対に安全な場所はない」**という意識を持って使うことが大切です。

## 用語解説

| 用語 | 解説 |
|---|---|
| **パスワードマネージャー** | 様々なサービスのIDとパスワードをまとめて管理するアプリ・サービス |
| **Dashlane（ダッシュレーン）** | フランス発祥のパスワードマネージャーサービス |
| **ボルト（Vault）** | パスワードマネージャー内の「金庫」。ID・パスワード一覧が保存されている |
| **暗号化** | データを特定の規則で変換し、鍵がなければ読めなくする技術 |
| **マスターパスワード** | パスワードマネージャーを開くための唯一のパスワード。金庫の鍵に相当 |
| **2FA / 二段階認証** | パスワードに加えて、もう一つの確認（SMSコードなど）でログインする仕組み |
| **ブルートフォース攻撃（総当たり攻撃）** | パスワードや認証コードをすべての組み合わせで試す攻撃手法 |
| **脅威アクター（Threat Actor）** | サイバー攻撃を行う悪意ある個人またはグループの総称 |
| **デバイス登録** | 特定のアカウントに「このスマホ・PCからアクセスを許可する」と登録すること |

---

> 💡 **まとめ**：今回の事件は、便利なパスワードマネージャーも攻撃対象になり得ることを示しています。被害は20人未満と限定的でしたが、「マスターパスワードをしっかり設定すること」「2FAを有効にすること」の重要性を改めて教えてくれる出来事でした。自分のアカウントを守るのは、最終的には自分自身です！
