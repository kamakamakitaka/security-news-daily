# エンドポイント検知・対応（EDR）はもはや「当たり前」——次の時代のセキュリティとは？

**元記事**: [Endpoint Detection & Response Is Now Table Stakes — Here's What Comes Next](https://inl03.netline.com/ltr6/?_m=3n.009a.3994.sp0ao46r89.31p8)
**解説日**: 2025年7月11日

---

## 背景知識

まずこの記事を読む前に、いくつかの基本的な考え方を押さえておきましょう。

### 🖥️ 「エンドポイント」って何？

「エンドポイント（Endpoint）」とは、ネットワークに接続されている**パソコン、スマホ、タブレット、サーバーなどの端末**のことです。会社のネットワークで考えると、社員が使うすべてのパソコンがエンドポイントにあたります。

> **例え話**: 会社を「お城」に例えると、エンドポイントは「城の入口や窓」のようなもの。ここを守ることが、外敵（攻撃者）から城を守る第一歩です。

---

### 🛡️ セキュリティの進化の流れ

セキュリティ対策はざっくりこんな順番で進化してきました：

| 世代 | 名前 | できること | 例え |
|------|------|-----------|------|
| 第1世代 | **アンチウイルス（AV）** | 既知のウイルスをブロックする | 「手配書」を持った門番 |
| 第2世代 | **EPP（エンドポイント保護プラットフォーム）** | より高度な脅威をブロック | 顔認識カメラ付きの門番 |
| 第3世代 | **EDR（エンドポイント検知・対応）** | 侵入を検知し、調査・対応する | 侵入後も追跡する探偵チーム |

今回の記事は、「EDRがもはや『持っていて当然のもの』になった」という話です。

---

## 何が起きたのか

セキュリティ企業「**Bitdefender（ビットディフェンダー）**」が行った調査によると、なんと**回答者の97.7%がすでにEDRを導入済み**であることがわかりました。

これはどういうことかというと——

> 「エンドポイントを守るだけ」の時代は終わった。
> 今や「攻撃を素早く見つけて、対応できること」が企業の**最低限の条件**になっている。

という大きなセキュリティの考え方の転換を示しています。

かつては「ウイルスをブロックできればOK」でしたが、現代の攻撃者はそれをかいくぐる方法を次々と開発しています。そのため、**「入ってこさせない」だけでなく「入ってきても素早く気づいて対応する」**能力が求められるようになったのです。

---

## 技術的な詳細

### 🔍 なぜ「ブロックするだけ」では足りないのか？

現代の攻撃者が使う2つの狡猾な手口を紹介します。

#### 1. 資格情報の悪用（Credential Abuse）
「資格情報」とはIDとパスワードのこと。攻撃者は正規のユーザー名・パスワードを盗んで、**正規のユーザーのふりをしてシステムに入り込みます**。

> **例え話**: 泥棒が合鍵を使って家に入ってくる感じ。玄関のカギ（ウイルス対策）は壊されていないので、警報が鳴らない。

#### 2. LOTL（Living-off-the-Land）攻撃
「土地のものだけで生き延びる」という意味で、**Windowsなどに最初から入っている正規のツール（管理ツールなど）を悪用**して攻撃します。

> **例え話**: 料理包丁（正規ツール）は凶器ではありませんが、使い方次第で危険になる。セキュリティソフトは「怪しいものを持っていないか」しかチェックしないので、正規ツールの悪用を見抜けないことがある。

---

### 🏗️ EDRって具体的に何をするの？

EDRは大きく3つの役割を担います：

```
【EDRの3つの役割】

1. 検知（Detect）
   └─ 端末上で起きているすべての動作を記録・監視
      「なんか変な動きがある！」を見つける

2. 調査（Investigate）
   └─ 「何が起きたのか」「どこまで広がったか」を分析する

3. 対応（Respond）
   └─ 感染した端末を隔離したり、攻撃を止めたりする
```

---

### ⚠️ 中規模企業が直面している課題

調査では**45%のITやセキュリティ担当者が「アラート（警告）の調査に手が回らない」**と感じていることもわかりました。

これはなぜかというと、EDRは優れたツールですが、**使いこなすのが難しい**からです。

中規模企業の多くには以下のものが不足しています：

- 📍 **SOC（セキュリティ・オペレーション・センター）** → 24時間365日セキュリティを監視する専門チームのこと
- 📍 **経験豊富な脅威アナリスト** → 「これは本物の攻撃か？」を判断できる専門家
- 📍 **24時間体制の予算と人員**

## なぜ重要なのか

### 📊 「ブロックだけ」では何が起きるか？

防御するだけで検知・対応ができない場合、こんなリスクがあります：

| リスク | 説明 |
|--------|------|
| **ランサムウェアの長期潜伏** | 気づかないうちにデータが暗号化され、身代金を要求される |
| **復旧に時間がかかる** | 侵入経路がわからず、復旧に何週間もかかることがある |
| **経済的損失** | 業務停止、データ流出、賠償問題 |
| **信頼の失墜** | 顧客・取引先・保険会社・規制当局から「ちゃんと守れていたの？」と問われる |

### 🤖 AI時代の攻撃者はさらに手強い

記事には「**攻撃者もAIを活用している**」という重要な指摘があります。AI技術のおかげで：

- より巧妙なフィッシングメールを大量に作成できる
- 防御をかいくぐる新しい攻撃パターンを素早く開発できる
- 検知を避けながら静かにシステムに潜伏できる

攻撃側がAIで武装している以上、守る側もより高度な対応が必要になっています。

## 対策・今後の展望

### ✅ セキュリティ担当者・企業が取るべき考え方

記事が強調しているのは、**「侵入されないこと」ではなく「侵入されたことを前提に考える」**というマインドセットの転換です。

これを「**Assume Breach（侵入前提）**」という考え方と言います。

```
【旧来の考え方】
「壁を高くすれば入ってこられない」→ 防御一辺倒

【現代の考え方】
「いつか必ず入られる。入られたとき素早く気づいて対処できるか？」
→ 検知・対応能力が不可欠
```

### 🔧 具体的な対策の方向性

| 対策 | 説明 |
|------|------|
| **EDR導入** | まずは検知・対応ツールを導入する |
| **MDR（マネージドDR）の活用** | 自社にSOCがない場合、外部の専門会社に24時間監視を委託する |
| **アラートの優先順位付け** | すべてのアラートに対応するのではなく、重要なものから対応する仕組みを作る |
| **インシデント対応計画** | 「もし侵入されたら何をするか」を事前に決めておく |

> **MDR（Managed Detection and Response）**: 検知・対応をまるごと専門会社にアウトソース（外注）するサービス。SOCを自前で持てない中規模企業にとって有力な選択肢。

## 過去記事との関連

今回は関連する過去記事はありませんが、セキュリティ業界全体の流れとして押さえておくべきポイントがあります。

- 以前から「**ゼロトラスト（Zero Trust）**」という「誰も信用しない・常に確認する」セキュリティの考え方が広まってきていましたが、今回の「Assume Breach（侵入前提）」はその考え方と深くつながっています。
- ランサムウェア被害が世界中で急増している流れの中で、「ブロックするだけ」の対策の限界が改めて浮き彫りになっています。

## 用語解説

| 用語 | 意味 |
|------|------|
| **エンドポイント** | パソコンやスマホなど、ネットワークに接続された端末 |
| **EPP（Endpoint Protection Platform）** | ウイルスや脅威をブロックするためのエンドポイント保護ツール |
| **EDR（Endpoint Detection & Response）** | エンドポイントで起きている脅威を検知し、調査・対応するツール |
| **SOC（Security Operations Center）** | セキュリティ監視・対応を行う専門チーム・施設 |
| **MDR（Managed Detection & Response）** | 検知・対応を外部の専門会社に委託するサービス |
| **LOTL（Living-off-the-Land）** | OSや正規ツールを悪用する攻撃手法 |
| **資格情報（Credential）** | ユーザーIDとパスワードのこと |
| **ランサムウェア** | データを暗号化して身代金を要求するマルウェア（悪意あるソフト） |
| **Assume Breach** | 「いつか必ず侵入される」という前提でセキュリティを考える思想 |
| **アラート** | セキュリティツールが出す「怪しい動きがあります！」という警告 |
| **脅威アナリスト** | セキュリティの脅威を分析・調査する専門家 |
| **ゼロトラスト** | 「社内でも社外でも誰も信用しない」という現代的なセキュリティの考え方 |

---

> 💡 **まとめると…**
> セキュリティの世界は「泥棒を入れないこと」から「入られても素早く気づいて対応すること」へとシフトしています。EDRはその中心的なツールですが、使いこなすには専門知識と体制が必要。人手が足りない企業は、外部の専門家（MDR）に頼るという選択肢も重要になっています。
