# エンドポイント検知・対応（EDR）は今や「最低限」—その先に何が来るのか？

**元記事**: [Endpoint Detection & Response Is Now Table Stakes — Here's What Comes Next](https://inl03.netline.com/ltr6/?_m=3n.009a.3994.sp0ao46r89.31p8)
**解説日**: 2025年7月10日

---

## 背景知識

まず、この記事を理解するために必要な基本的な考え方を整理しましょう。

### 💻 「エンドポイント」って何？
「エンドポイント」とは、ネットワークに接続されているパソコン、スマートフォン、サーバーなど、**末端にある機器**のことです。会社で社員が使っているパソコン1台1台が「エンドポイント」にあたります。

### 🛡️ セキュリティ対策の「進化の段階」
セキュリティ対策には、大きく分けて以下の3段階があります。

| 段階 | 名前 | たとえるなら… |
|------|------|--------------|
| 第1段階 | **EPP**（エンドポイント保護）| 玄関に鍵をかけて泥棒を入れない |
| 第2段階 | **EDR**（エンドポイント検知・対応）| 家の中にカメラを設置し、侵入者を検知して追い出す |
| 第3段階 | **MDR/XDR**（管理型検知・対応）| 警備会社に24時間監視を依頼する |

### 🔍 今回の記事のポイント
セキュリティ会社の**Bitdefender（ビットディフェンダー）**が調査した結果をもとに、「EDRは今や最低限のセキュリティ対策になった。次のステップは何か？」を解説した内容です。

---

## 何が起きたのか

Bitdefenderが行った調査で、驚くべき結果が出ました。

> **調査対象の97.7%の企業が、すでにEDRを導入している**

これは何を意味するのでしょうか？

少し前まで、「EDRを導入する企業は少数派・先進的な企業だけ」と思われていました。しかし今では、**EDRを持っていることは「当たり前」になった**ということです。

🏫 **身近な例で考えると…**
昔は「スマホを持っている人はすごい」と思われていたのに、今は「スマホを持っていないと不便」になったのと同じです。EDRもそのくらい「普通のもの」になってきました。

同じ調査では、**45%のITやセキュリティの専門家が「セキュリティツールからのアラート（警告）を調査しきれていない」と回答**しています。つまり、ツールは増えているのに、それを管理する人手が足りていないという問題が浮き彫りになっています。

---

## 技術的な詳細

### 🔐 EPP（エンドポイント保護）だけでは不十分な理由

EPPは「**既知の（知られている）ウイルスや攻撃をブロック**」するツールです。ウイルス対策ソフトをイメージするとわかりやすいです。

しかし、現代の攻撃者はこれを簡単に回避します。

#### 代表的な回避手法 ①：クレデンシャル悪用（Credential Abuse）
「クレデンシャル」とは**ユーザーIDとパスワードのセット**のことです。攻撃者は正規のIDとパスワードを盗んでログインするので、セキュリティソフトから見ると「正規のユーザーが操作している」ように見えてしまいます。

🏫 **たとえるなら…**
泥棒が合鍵を作って家に入ってきた場合、ドアの鍵（EPP）は役に立ちません。「正しい鍵で開けた人」だと思ってしまうからです。

#### 代表的な回避手法 ②：LotL（Living-off-the-Land：環境寄生型攻撃）
これは「**Windowsにもともと入っている正規のツールを悪用して攻撃する**」手法です。

🏫 **たとえるなら…**
「不審者が自分で凶器を持ち込むのではなく、家の中にある包丁を使う」ようなイメージです。もともとある道具なので、セキュリティソフトが「怪しい！」と判断しにくいのです。

### 🤖 AIを使った攻撃者との戦い
記事では「脅威アクター（攻撃者）はAIを活用しており、より狡猾になっている」と書かれています。攻撃者がAIを使うことで、

- より巧妙にセキュリティをすり抜ける
- 大量の攻撃を自動化できる
- 防御側の隙をすばやく見つけられる

…という状況になっています。

### 🚨 EDRが求める「新しい考え方」
EDRが前提とする考え方は、以下のように変わっています。

```
【古い考え方】
「攻撃を完全にブロックすれば安全！」
↓
【新しい考え方】
「侵入されることを前提に、素早く検知して被害を最小限に抑える」
（= "Assume Breach"：侵入されたと仮定せよ）
```

---

## なぜ重要なのか

### 📊 「中堅企業」が特に危ない
大企業は専門のセキュリティチームを持っていることが多いですが、**中堅・中小企業（Mid-market）**は以下のような問題を抱えています。

- ❌ セキュリティ専門家がいない
- ❌ 24時間監視するチームがない
- ❌ 予算が限られている
- ❌ アラートが多すぎて対応しきれない

これらの企業では、「**EDRは導入したけれど、うまく使えていない**」という状況が起きやすいです。

### 💸 対応が遅れると何が起きる？
記事では、EPPだけに頼り続けることの「リスク」が以下のように説明されています。

1. **ランサムウェア**（身代金要求型ウイルス）に気づかず感染が広がる
2. 被害が発覚したときには手遅れで、**復旧に時間とお金がかかる**
3. 取引先や保険会社、規制当局から「なぜ防げなかったのか」と責任を問われる
4. 最悪の場合、**法的手続き（裁判）**で「適切な対策をしていたか」を証明しなければならない

🏫 **身近な例で考えると…**
家に泥棒が入ったとき、「鍵はかけていました（EPP）」では不十分で、「カメラで監視していて、侵入に気づいたらすぐに警察に連絡する仕組みがありました（EDR）」を証明しないといけない時代になったということです。

---

## 対策・今後の展望

### ✅ 企業がすべき「次のステップ」
記事の内容を整理すると、企業が取るべき対策は以下のとおりです。

#### STEP 1：「侵入されること前提」のマインドセットに切り替える
「完璧な防御はない」と認識し、**検知・対応の仕組みを整える**ことが最優先です。

#### STEP 2：EDRを「入れるだけ」で終わらせない
EDRは導入するだけでは意味がありません。**アラートを実際に確認・対応できる体制**が必要です。

#### STEP 3：人手が足りない場合は「外部委託（MDR）」を検討する
**MDR（Managed Detection and Response：管理型検知・対応）**とは、セキュリティ会社に監視・対応を丸ごと任せるサービスです。

```
自社でやる場合  → EDR（ツール）を使いこなせる人材が必要
外部に任せる場合 → MDR（サービス）で24時間プロが監視してくれる
```

### 🔮 今後の動向
- AIを使った攻撃はさらに増加する見込み
- 「セキュリティ対策をしていたことを証明できるか」が、企業の信頼性に直結する時代に
- 中堅・中小企業向けの手頃なMDRサービスの需要が急増している

## 用語解説

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **EPP** | イーピーピー | Endpoint Protection Platform。エンドポイント保護プラットフォーム。ウイルスなど既知の脅威をブロックするソフト |
| **EDR** | イーディーアール | Endpoint Detection and Response。エンドポイント検知・対応。侵入を検知して調査・対応する仕組み |
| **MDR** | エムディーアール | Managed Detection and Response。EDRの運用を外部のセキュリティ会社に委託するサービス |
| **XDR** | エックスディーアール | Extended Detection and Response。EDRをネットワークやクラウドなど広い範囲に拡張したもの |
| **SOC** | ソック | Security Operations Center。セキュリティを24時間365日監視する専門チーム・組織 |
| **LotL攻撃** | ロットルこうげき | Living-off-the-Land。OSにもともと入っている正規ツールを悪用して攻撃する手法 |
| **クレデンシャル** | ー | IDとパスワードのセット。これを盗まれると正規ユーザーになりすまされる |
| **ランサムウェア** | ー | データを暗号化して使えなくし、復元と引き換えに身代金を要求するウイルス |
| **Assume Breach** | アシューム・ブリーチ | 「侵入されることを前提に考える」というセキュリティの考え方 |
| **Bitdefender** | ビットディフェンダー | ルーマニア発のセキュリティソフト会社。世界的に有名 |

---

> 💡 **まとめると…**
> 「玄関の鍵（EPP）だけでは不十分な時代。家の中にカメラ（EDR）を設置し、さらに警備会社（MDR）に頼む時代になった」というのが今回のニュースの本質です。セキュリティは「防ぐ」から「検知して素早く対応する」へと変化しています。
