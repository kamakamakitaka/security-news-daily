# Google、2026年6月のAndroidアップデートで124件の脆弱性を修正！うち1件はすでに攻撃に悪用されていた

**元記事**: [Google June 2026 Android Update Patches 124 Flaws, One Actively Exploited](https://inl03.netline.com/ltr6/?_m=3n.009a.3994.sp0ao46r89.31pk)
**解説日**: 2026年6月4日

---

## 背景知識

まず、このニュースを理解するためのキーワードをいくつか押さえておきましょう。

### Androidって何？
みなさんのスマートフォンの多くに入っている「OS（基本ソフト）」です。Windowsがパソコンを動かすのと同じように、AndroidはスマホやタブレットをGoogleが作った仕組みで動かしています。世界中で数十億台のデバイスで使われています。

### 「脆弱性（ぜいじゃくせい）」って何？
ソフトウェアの「バグ（欠陥）」の中でも、**悪用されるとセキュリティ上の被害につながるもの**を指します。家の鍵に例えると、「鍵をかけているのに、特定の方法でドアを開けられてしまう欠陥」のようなものです。

### 「セキュリティパッチ」って何？
その脆弱性を修正するための「修理プログラム」です。アプリのアップデートをするのと同じ感覚で、スマホに届きます。

---

## 何が起きたのか

Googleは2026年6月、Androidスマートフォン向けに**合計124件のセキュリティ上の欠陥（脆弱性）を修正するアップデート**を公開しました。

その中でも特に注目されているのが、**「CVE-2025-48595」という脆弱性**です。

> 🚨 **この脆弱性はすでに実際の攻撃に使われていることが確認されています！**

- **対象OS**: Android 14、15、16（最近のほぼすべてのAndroid端末）
- **深刻度スコア**: 8.4 / 10（かなり高め！）
- **特徴**: 操作している人が何もしなくても攻撃が成立する

さらに、アメリカのサイバーセキュリティ機関（CISA）もこの脆弱性を「既知の悪用脆弱性リスト」に登録し、**政府機関に対して2026年6月5日までの対応を義務付けました**。

---

## 技術的な詳細

### どんな仕組みの攻撃なの？

今回の脆弱性には、2つの重要な技術的要素があります。

---

#### ① 「整数オーバーフロー」（Integer Overflow）
少し難しいですが、こんなイメージです👇

> 🎒 ランドセルに「最大10冊まで」しか入らないとします。でも、システムが「11冊入った」と間違って計算してしまったら、どうなるでしょう？ランドセルが壊れたり、飛び出した1冊が別の場所に行ってしまいますよね。

コンピュータも同じで、**数値の計算が想定外の範囲を超えてしまうと、プログラムが予期しない動作をします**。攻撃者はこの「計算ミス」を意図的に引き起こして、悪意のある命令を実行させることができます。

---

#### ② 「権限昇格」（Privilege Escalation）
これも大事な概念です。

> 🏫 学校で例えると、「生徒」がいつの間にか「先生と同じ権限」を手に入れてしまう、という感じです。

スマートフォンの中では、アプリごとに「できること・できないこと」が決められています。しかし、この脆弱性を使うと、**本来は許されていない操作（個人データの閲覧、設定の変更など）を勝手にできるようになってしまいます**。

しかも今回の脆弱性は：
- ✅ 追加の権限が不要
- ✅ ユーザーが何かをタップしたりする必要もない（=気づかないうちに攻撃される）

という、非常に危険な条件が揃っています。

---

#### ③ 「Frameworkコンポーネント」とは？
Androidの「Framework」は、アプリとスマホのハードウェアをつなぐ**土台となる重要な部分**です。ここに脆弱性があると、影響が非常に広範囲に及びます。

---

## なぜ重要なのか

### 🌍 影響が非常に広い
Android 14・15・16は現在最も普及しているバージョンです。つまり、**世界中の数十億台のスマートフォンが対象**になる可能性があります。

### 🎯 スパイウェアに悪用される危険性
記事では「**商業スパイウェア業者が類似の脆弱性を悪用し、特定の著名人を狙った攻撃を行った前例がある**」と指摘されています。

スパイウェアとは、スマホの中をこっそり監視するソフトウェアです。メッセージの盗み見、カメラやマイクの不正利用などに使われます。

### 🏛️ 政府機関も対応を急いでいる
アメリカのCISA（サイバーセキュリティ・インフラセキュリティ庁）が「すでに悪用されている脆弱性リスト（KEV）」に登録し、政府機関への緊急対応を求めていることからも、**この脆弱性の深刻さが伝わります**。

## 対策・今後の展望

### ✅ 今すぐできる対策

| 対策 | 方法 |
|------|------|
| **Androidをアップデートする** | 設定 → システム → ソフトウェアアップデート |
| **セキュリティパッチレベルを確認** | 設定 → デバイス情報 → Androidバージョン |
| **不審なアプリをインストールしない** | 公式のGoogle Playストア以外は使わない |
| **アプリの権限を見直す** | 必要のないアプリに過剰な権限を与えない |

### 🔍 確認すべきパッチレベル
- `2026-06-01` または `2026-06-05` 以降であれば対応済みです
- `2026-06-05` のほうがより多くの修正が含まれています

### 📅 今後の展望
Googleは毎月このようなセキュリティアップデートを公開しています。スマホのOSを**常に最新の状態に保つこと**が、最も基本的かつ効果的な対策です。端末メーカーによってアップデートの配信時期が異なる場合があるため、こまめに確認しましょう。

## 用語解説

| 用語 | 意味 |
|------|------|
| **脆弱性（ぜいじゃくせい）** | ソフトウェアのセキュリティ上の欠陥・穴 |
| **CVE** | 脆弱性に付けられる世界共通の識別番号（例：CVE-2025-48595） |
| **CVSSスコア** | 脆弱性の深刻さを0〜10点で表したスコア。8.4は「高」に分類 |
| **整数オーバーフロー** | 数値の計算が範囲を超えてしまうプログラムのバグ |
| **権限昇格** | 本来持っていないはずの高い権限を不正に取得すること |
| **Frameworkコンポーネント** | Androidのアプリと端末ハードをつなぐ重要な土台部分 |
| **スパイウェア** | ユーザーの知らないうちに端末を監視する悪意のあるソフト |
| **CISA** | アメリカのサイバーセキュリティ機関（日本のIPAに相当） |
| **KEV（Known Exploited Vulnerabilities）** | CISAが管理する「実際に悪用が確認された脆弱性リスト」 |
| **セキュリティパッチレベル** | スマホがどの時点までの修正を適用済みかを示す日付 |
| **QPR（Quarterly Platform Release）** | Androidの四半期ごとの機能・修正アップデート |
