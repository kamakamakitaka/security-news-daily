# Googleが2026年6月のAndroidアップデートを公開：124件の脆弱性を修正、うち1件はすでに攻撃に悪用済み

**元記事**: [Google June 2026 Android Update Patches 124 Flaws, One Actively Exploited](https://inl03.netline.com/ltr6/?_m=3n.009a.3994.sp0ao46r89.31pk)
**解説日**: 2026年6月5日

---

## 背景知識

まず、このニュースを理解するために必要な基礎知識を整理しておきましょう。

### Androidって何？
Androidは、Googleが開発したスマートフォン向けの**OS（オペレーティングシステム）**です。iPhoneのiOSと並んで、世界中で最も使われているスマホ用OSで、日本でも多くの人が使っています。

### セキュリティアップデートって何？
ソフトウェアには、発見された「穴（脆弱性）」を埋めるための修正プログラムが定期的に配布されます。これを**セキュリティパッチ（アップデート）**と言います。Googleは毎月Androidのセキュリティパッチを公開しています。

### 「脆弱性」って何？
スマホやパソコンのソフトウェアには、プログラムのミスや設計上の問題から生まれた「弱点」が存在することがあります。これを**脆弱性（ぜいじゃくせい）**と言います。悪意ある人がこの弱点を突いて攻撃することを「悪用（エクスプロイト）」と言います。

---

## 何が起きたのか

Googleは2026年6月、Androidスマートフォンに存在していた**124件**のセキュリティ上の脆弱性を修正するアップデートを公開しました。

この中で特に注目されているのが、**CVE-2025-48595**という番号で管理されている脆弱性です。この脆弱性は「危険度：高（CVSSスコア：8.4/10点）」と評価されており、さらに深刻なことに、**すでに実際の攻撃に使われている**ことが確認されています。

対象となるAndroidのバージョンは以下の通りです：
- Android 14
- Android 15
- Android 16
- Android 16 QPR2

つまり、現在使われている多くのAndroid端末が影響を受けます。

## 技術的な詳細

### この脆弱性の「仕組み」をわかりやすく説明します

#### 権限昇格（Privilege Escalation）とは？
スマホの中では、アプリや機能ごとに「できること・できないこと」が決まっています。たとえば、普通のゲームアプリは「カメラに勝手にアクセスできない」ようになっています。これを**権限（けんげん）の仕組み**と言います。

**権限昇格**とは、本来持っていない「上位の権限（管理者レベルの権限）」を不正に手に入れることです。例えるなら、「一般の来場者なのに、バックステージに勝手に入り込む」ようなイメージです。

#### 整数オーバーフロー（Integer Overflow）とは？
コンピューターの数値計算には「扱える最大の数」があります。この最大値を超えてしまうと、数値が「あふれて」おかしな値になってしまいます。これを**整数オーバーフロー**と言います。

🍜 **例え話**：10桁のそろばんで、9999999999（最大値）に1を足そうとすると、桁があふれて「0000000000」になってしまう、というイメージです。

このバグを悪用することで、攻撃者はAndroidスマホ内で**本来許可されていないコード（プログラム）を実行**できてしまいます。

#### さらに怖いポイント：ユーザー操作が不要！
通常、攻撃には「怪しいリンクをクリックさせる」など、ユーザーに何かをさせる必要があります。しかし、この脆弱性は**ユーザーが何もしなくても**攻撃が成立してしまいます。これは非常に危険な特徴です。

## なぜ重要なのか

### 1. 「すでに使われている」攻撃
Googleは「限定的・標的型の攻撃に使われている可能性がある」と認めています。つまり、**理論上の危険ではなく、現実の攻撃がすでに起きている**ということです。

### 2. スパイウェアとの関連が疑われる
記事では「同様の脆弱性は、商業スパイウェア業者が特定の著名人を標的にするために悪用してきた」と指摘しています。**商業スパイウェア**とは、政府機関や諜報機関などが購入して使う「合法的だが問題視されている監視ソフト」のことです（PegasusやFinFisherなどが有名です）。

### 3. 米国政府も動いた
アメリカのサイバーセキュリティ機関（CISA）は、この脆弱性を「既知の悪用脆弱性カタログ（KEV）」に登録し、**連邦政府機関に対して2026年6月5日までに修正するよう義務付け**ました。政府が緊急対応を求めるほど深刻な問題と判断されています。

### 4. 影響を受ける端末が多い
Android 14〜16は現在広く使われているバージョンであり、**世界中の非常に多くのスマートフォンが対象**となります。

---

## 対策・今後の展望

### ✅ 今すぐできる対策

#### 1. Androidをアップデートする
最も重要な対策は、**スマートフォンのソフトウェアを最新版に更新すること**です。

手順（Androidスマホの場合）：
```
設定 → システム → ソフトウェアアップデート → 更新の確認
```
※機種によってメニューの場所が異なることがあります。

#### 2. セキュリティパッチレベルを確認する
設定から「セキュリティパッチレベル」が確認できます。
- **2026-06-05**以降の日付になっていれば、今回の修正がすべて適用されています ✅
- それより古い日付の場合は、アップデートが必要です ⚠️

#### 3. 不審なアプリをインストールしない
今回の脆弱性はユーザー操作なしでも攻撃できますが、悪意あるアプリと組み合わせた攻撃も考えられます。**公式のGoogle Playストア以外からアプリをインストールしない**ようにしましょう。

### 今後の展望
Googleは今後も毎月セキュリティパッチを公開し続けます。スマートフォンを安全に使うためには、**定期的なアップデートを習慣にすること**が最も重要です。

## 過去記事との関連

以前の週刊まとめ記事（2026年6月3日）では、Linux・PAN-OS・AI攻撃・OAuthフィッシングなど**複数のプラットフォームでの脆弱性や攻撃手法**についてお伝えしました。また、WindowsのNTLMv2ハッシュ盗難の問題も報告されました。

今回のAndroidの脆弱性は、これらと合わせて見ると「**Windows・Linux・Androidと、あらゆる主要OSで同時期に深刻な脆弱性が発覚・悪用されている**」という大きな流れの一部です。特定のOSだけを狙うのではなく、攻撃者はあらゆるプラットフォームを常に狙っていることがよくわかります。

また、AIを使った攻撃の加速（2026年6月3日の記事）という背景もあり、**脆弱性が発見されてから悪用されるまでの時間がどんどん短くなっている**傾向があります。だからこそ、パッチが出たらすぐに適用することが以前にも増して重要になっています。

## 用語解説

| 用語 | 解説 |
|------|------|
| **脆弱性（ぜいじゃくせい）** | ソフトウェアやシステムにある「弱点・穴」のこと |
| **CVE（Common Vulnerabilities and Exposures）** | 世界共通で脆弱性を管理するための番号システム。「CVE-2025-48595」のように表記される |
| **CVSSスコア** | 脆弱性の危険度を0〜10点で表したスコア。10に近いほど危険 |
| **権限昇格（Privilege Escalation）** | 本来持っていない高い権限を不正に取得する攻撃手法 |
| **整数オーバーフロー（Integer Overflow）** | 数値の計算で扱える最大値を超えてしまうプログラムのバグ |
| **Framework（フレームワーク）** | Androidアプリが動くための土台となるシステム部分 |
| **セキュリティパッチ** | 脆弱性を修正するための更新プログラム |
| **スパイウェア** | ユーザーの情報を密かに収集・送信する悪意あるソフトウェア |
| **CISA** | アメリカのサイバーセキュリティ・インフラセキュリティ庁。日本の総務省・警察庁に近い機関 |
| **KEV（Known Exploited Vulnerabilities）** | CISAが管理する「実際に悪用が確認された脆弱性のリスト」 |
| **アクティブエクスプロイト** | 脆弱性がすでに現実の攻撃に使われている状態のこと |
