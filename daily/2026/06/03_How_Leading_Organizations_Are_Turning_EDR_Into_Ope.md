## 背景知識

まず、このニュースを理解するためのキーワードを整理しましょう。

### 🖥️ エンドポイントって何？
「エンドポイント」とは、パソコン・スマートフォン・サーバーなど、ネットワークに接続されている「端末」のことです。会社の中にあるパソコン一台一台が、すべてエンドポイントです。

### 🛡️ EDR（エンドポイント検知・対応）って何？
**EDR（Endpoint Detection and Response）** とは、端末の上で起きている「あやしい動き」をリアルタイムで監視・記録し、攻撃を検知したらすぐに対応するセキュリティシステムのことです。

> 🏠 **例え話**: 家のセキュリティで考えると、昔の「鍵をかけるだけ」から、「家の中に監視カメラを設置して、不審な動きがあればすぐアラートが鳴り、自動でドアをロックする」レベルに進化したものがEDRです。

### 🤖 AIを使ったサイバー攻撃とは？
攻撃者がAIを使って、より速く・より賢く・より見つかりにくい攻撃をしかけてくること。パスワードの解析や、怪しまれないような攻撃パターンの生成なども自動化されています。

## 技術的な詳細

### 🔍 なぜ「EDRを入れるだけ」ではダメなのか？

EDRを導入すると、大量の「アラート（警告）」が発生します。

> 🚨 **例え話**: 学校に監視カメラを設置したとします。廊下を誰かが走るたびに「警告！」と通知が来たら、先生は一日中通知対応で終わってしまいます。本当に危険な場面を見逃してしまうかもしれません。

これと同じことがセキュリティ現場で起きています。

| 問題 | 内容 |
|------|------|
| アラートが多すぎる | 本当に危険なものを見つけにくい |
| 調査に時間がかかる | 攻撃者の動きに追いつけない |
| 専門スキルが不足 | 高度な分析ができる人材が少ない |
| 疲弊 | 常に後手後手（reactive）な対応で担当者が燃え尽きる |

### 🥷 "ローカルの道具を悪用する"攻撃手法「LOTL」とは？

記事の中で「**LOTL（Living off the Land）**」という言葉が出てきます。

> 🌲 **例え話**: 泥棒が「自分の道具を持ち込まず、家の中にある包丁やロープを使って犯行に及ぶ」イメージです。

サイバー攻撃でも同様に、攻撃者がウイルスなどの「怪しいソフト」を使わず、**Windowsに最初から入っている正規の管理ツール**を悪用して攻撃します。これだと「普通の操作」と見分けがつきにくく、セキュリティソフトが検知しにくいのです。

Bitdefender社の調査では、**主要な攻撃の84%がこのLOTL手法を使っている**ことが明らかになりました。

### 💡 解決策として紹介されている2つの機能

記事ではBitdefender社の2つの技術が紹介されています。

#### ① GravityZone PHASR（ファサー）
- AIがユーザーの「普段の行動」を学習する
- 不審な操作・不要な権限・LOTLに使われやすいツールの悪用を**事前に制限**する
- 普段の仕事の邪魔はしない

> 🔑 **例え話**: 「この人は経理担当だからサーバーの設定を変える必要はないはず」とAIが判断し、そういう操作を自動でブロックするイメージです。

#### ② MDR（マネージドな検知と対応）
- 社内のセキュリティチームだけでは手が足りない部分を、**外部の専門家チームが24時間監視・対応**してくれるサービス
- 小さなセキュリティチームでも、大企業並みの対応力を持てるようになる

## なぜ重要なのか

### 👤 私たちの身近にも関わる話

「会社のセキュリティの話でしょ？自分には関係ない」と思うかもしれませんが、実はそうではありません。

- 皆さんが使っているサービス（ショッピング、SNS、ゲームなど）は、どこかの企業のサーバーで動いています
- その企業がサイバー攻撃に遭うと、**個人情報が流出したり、サービスが止まったりする**ことがあります
- セキュリティの強い組織が増えれば、私たちのデータも守られやすくなります

### 📊 数字で見る深刻さ

- **67%** の組織がAI攻撃の増加を報告（2025年調査）
- **84%** の主要攻撃がLOTL手法を使用（70万件以上の事例分析）

これだけ多くの組織が苦しんでいる状況です。

## 対策・今後の展望

### ✅ 企業・組織ができること

| 対策 | 説明 |
|------|------|
| **EDRの"使いこなし"を強化** | 導入するだけでなく、運用体制を整える |
| **動的なハードニング** | 攻撃される前に「狙われやすい隙」をAIで自動的に塞ぐ |
| **MDRの活用** | 外部の専門家チームと連携して24時間対応力を確保 |
| **LOTL対策の強化** | 正規ツールの不審な使用を監視・制限する |
| **アラートの優先順位付け** | 重要なものに集中できる仕組みを作る |

### 🔮 今後の展望

- AIを使った攻撃はさらに増加・高度化する見込み
- セキュリティ担当者の不足は世界的な問題で、「自動化」と「外部委託」の活用がカギになる
- 「検知してから対応する」後手の対応から、「攻撃される前に隙を減らす」先手の対応へのシフトが重要

## 用語解説

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **EDR** | イーディーアール | Endpoint Detection and Response。端末の不審な動きをリアルタイムで検知・対応するセキュリティシステム |
| **エンドポイント** | - | パソコン・スマホ・サーバーなど、ネットワークに接続された端末のこと |
| **アラート** | - | セキュリティシステムが「あやしい動き」を検知した際に発する警告 |
| **LOTL** | ロトル | Living off the Land。正規のOS機能や管理ツールを悪用する攻撃手法 |
| **MDR** | エムディーアール | Managed Detection and Response。外部の専門家チームが検知・対応を代行するサービス |
| **脆弱性** | ぜいじゃくせい | ソフトウェアのセキュリティ上の欠陥・穴 |
| **ハードニング** | - | 攻撃に狙われにくいよう、システムの設定を強化すること（「硬化」「堅牢化」とも） |
| **権限昇格** | けんげんしょうかく | 攻撃者が一般ユーザーの権限から管理者権限を奪い取ること |
| **ラテラルムーブメント** | - | 侵入後、攻撃者がネットワーク内を横断して被害を広げること（「横展開」とも） |
| **スレットハンティング** | - | 脅威を能動的に探し出す調査活動 |

---

> 💬 **まとめると…**
>
> セキュリティツールを「買って終わり」にしてしまっている組織が多い中、AI攻撃の増加によってその問題がより深刻になっています。これからのセキュリティは「攻撃を受けてから対応する」だけでなく、「そもそも攻撃されにくい状態を作り続ける」という考え方が重要になっています。
