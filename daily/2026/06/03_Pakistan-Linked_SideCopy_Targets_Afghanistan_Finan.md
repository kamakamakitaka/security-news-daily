# パキスタン系ハッカー集団「SideCopy」がアフガニスタン財務省を標的に「Xeno RAT」で攻撃

**元記事**: [Pakistan-Linked SideCopy Targets Afghanistan Finance Ministry with Xeno RAT](https://inl03.netline.com/ltr6/?_m=3n.009a.3993.sp0ao46r89.31ni)
**解説日**: 2025年6月3日

---

## 背景知識

このニュースを理解するために、いくつかのキーワードを先に整理しておきましょう。

### 🌏 地政学的な背景
パキスタンとアフガニスタンは隣国で、歴史的に複雑な関係にあります。今回の攻撃は「国家に関係するハッカー集団が、隣国の政府機関をスパイするために行った」と考えられています。まるで「隣の国の財布の中を覗こうとした」ようなイメージです。

### 💻 「国家支援型ハッカー集団」とは？
普通のハッカーと違い、特定の国の政府や情報機関と関係を持ちながら活動するハッカーグループです。金銭目的ではなく、**情報収集・スパイ活動・妨害工作**を目的とすることが多いです。

### 📧 「スピアフィッシング」とは？
通常の詐欺メール（フィッシング）が「不特定多数」に送られるのに対し、スピアフィッシングは**特定の人物や組織だけを狙い撃ち**にした、非常に巧妙な偽メール・偽ファイルを使う攻撃です。槍（スピア）で狙いを定めて突くイメージです。

---

## 何が起きたのか

セキュリティ企業「Seqrite Labs」の研究者が、**「Operation XENOFISCAL（ゼノフィスカル作戦）」**と名付けられた攻撃キャンペーンの詳細を公表しました。

### 🎯 攻撃の標的
- アフガニスタン財務省
- 各州の歳入局・財務局
- パシュトゥー語を話す政府職員
- 州レベルの政府職員

### 🕵️ 誰がやったのか
**「SideCopy（サイドコピー）」** というパキスタンと関係があるハッカー集団です。さらに上位の「Transparent Tribe（別名APT36）」という大きなグループの一部として活動しています。

### 📁 どうやって攻撃したか（入口）
攻撃の入り口は、**ZIPファイル（圧縮ファイル）の添付**です。その中に**パシュトゥー語のファイル名が付いた悪意のあるショートカットファイル（LNKファイル）**が入っていました。

> 💡 **ポイント**: パシュトゥー語はアフガニスタン政府内で広く使われる言語です。攻撃者があえてこの言語を使ったのは、「怪しいと思わせないため」のカモフラージュです。まるで「アフガン政府職員向けの公式文書に見せかけた罠」です。

## 技術的な詳細

攻撃がどのような手順で進むか、ステップごとに解説します。

```
【攻撃の流れ】

① 被害者がZIPファイルを受け取り、中のLNKファイルをダブルクリック
        ↓
② 「mshta.exe」という正規のWindowsツールが悪用される
        ↓
③ アフガニスタンの教育機関の乗っ取られたWebサイトから
   「HTA（HTMLアプリケーション）」という悪性ファイルをダウンロード
        ↓
④ 難読化されたJavaScriptがメモリ上で実行される
        ↓
⑤ 「Xeno RAT 1.8.7」がインストールされる
        ↓
⑥ 偽の「おとり文書」が表示され、被害者は何も気づかない
        ↓
⑦ 攻撃者がパソコンを遠隔操作できる状態に！
```

### 🧬 「Xeno RAT」でできること

Xeno RATはいわば「パソコンへの不正な遠隔操作ツール」です。インストールされると攻撃者は以下のことができるようになります：

| 機能 | 内容 |
|------|------|
| 🖥️ 遠隔操作 | インターネット経由でパソコンを操る |
| ⌨️ キーロギング | キーボードの入力をすべて記録（パスワードも盗める！） |
| 📸 スクリーンショット | 画面を好きなタイミングで撮影 |
| 📋 クリップボード監視 | コピー&ペーストした内容を盗む |
| 📷 カメラ・マイク | ウェブカメラや音声をこっそり使う |
| 📁 ファイル操作 | ファイルの閲覧・コピー・削除 |
| 🔒 永続化 | パソコンを再起動しても自動的に起動し続ける |

### 🎭 「Microsoftのふりをする」巧妙な手口

このマルウェアは**Microsoft Edge（マイクロソフトの正規ブラウザ）に偽装**してWindowsの設定（レジストリ）に登録されます。これにより、セキュリティソフトや管理者に「正規のプログラムだ」と思わせて検出を逃れようとします。

## なぜ重要なのか

### 💰 財務省が狙われた意味
財務省は国のお金の流れを管理する場所です。そこへの不正アクセスは…
- 国家予算・税収などの機密情報が漏洩するリスク
- 資金の流れを把握されることで、外交・軍事上の弱点を突かれる可能性
- 政府システムへのさらなる侵入の足がかりになる危険性

### 🌏 南アジア全体の問題
今回の攻撃はアフガニスタンだけでなく、**インドの軍事・防衛インフラ**も同じグループ（Transparent Tribe）によって標的にされていることが同時に報告されています。

インドへの攻撃では：
- **WhatsAppを使ったソーシャルエンジニアリング**（人の心を操る詐欺的手法）
- **Linux向けの悪性ファイル（.desktopファイル）** が使われた
- 「DeskRAT（デスクRAT）」というGoプログラム言語で作られた遠隔操作ツールが展開された

つまり、**同一グループが異なる国・異なる手法で、同時並行的に攻撃を行っている**ことになります。

## 対策・今後の展望

### 🛡️ 組織・政府機関向けの対策

1. **不審なZIPファイルは絶対に開かない**
   - 送り主が知り合いでも、突然送られてきたファイルには注意
   - 「パシュトゥー語のファイル名」のように、「なぜこの言語？」と感じたら要注意

2. **LNKファイル（ショートカット）の実行を制限する**
   - 組織のポリシーで、メールの添付ファイルのショートカット実行を禁止する

3. **mshta.exeの実行を監視・制限する**
   - 本来Windowsの管理目的で使うツールが、攻撃に悪用されている

4. **多層防御（EDRなど）の導入**
   - 1つのセキュリティソフトに頼らず、複数の防御層を設ける

5. **セキュリティ教育の徹底**
   - 職員がスピアフィッシングを見抜けるようにトレーニングする

### 🔮 今後の動向
SideCopyは2025年4月にもインドへの攻撃が確認されており、活動が活発化しています。南アジア地域の政府・軍事・インフラ機関は引き続き高い警戒が必要です。

## 過去記事との関連

過去に「**EDR（Endpoint Detection and Response）を組織の強靭さに変える方法**」という記事を紹介しました。

今回の攻撃はまさにEDRが重要である理由を示す好例です。Xeno RATは「Microsoft Edgeに偽装する」「メモリ上で実行する」など**検出を回避するための工夫**を多数備えています。従来のウイルス対策ソフトだけでは検出が難しく、**挙動を監視するEDRのような高度なツール**が必要になります。「なぜEDRが必要か？」という問いへの、リアルな答えが今回の事例といえるでしょう。

## 用語解説

| 用語 | 解説 |
|------|------|
| **RAT（リモートアクセストロイ）** | 感染したパソコンを遠隔操作するための悪性ソフト。「Remote Access Trojan」の略 |
| **スピアフィッシング** | 特定の人物・組織を狙い撃ちにした精巧な偽メール・偽ファイルによる攻撃 |
| **LNKファイル** | Windowsのショートカットファイル。一見無害に見えるが、悪性プログラムを呼び出すために悪用されることがある |
| **mshta.exe** | Windowsに標準で入っているHTMLアプリケーション実行ツール。攻撃者に悪用されやすい |
| **難読化（obfuscation）** | コードを読みにくくして、セキュリティソフトや人間による解析を困難にする技術 |
| **永続化（persistence）** | マルウェアがパソコンの再起動後も自動的に動き続けるように設定すること |
| **レジストリ** | Windowsの設定情報を管理するデータベース。マルウェアはここに自身を登録して生き残る |
| **APT（高度持続的脅威）** | 国家支援型の高度なハッカー集団による、長期にわたる計画的な攻撃 |
| **SOCKS5プロキシ** | 通信を中継して発信元を隠す仕組み。マルウェアが通信を隠蔽するために使う |
| **EDR** | パソコン・サーバーの「ふるまい」を監視し、不審な動きを検出・対応するセキュリティツール |
| **ソーシャルエンジニアリング** | 技術ではなく「人の心理の隙」を突いて情報を盗んだり、悪性ファイルを実行させたりする手法 |
| **Transparent Tribe（APT36）** | パキスタンと関係があるとされる国家支援型ハッカー集団の総称 |
