# IAM攻撃対象領域の縮小：「見えないIDリスク」を可視化する新技術「IVIP」とは

**元記事**: [Shrinking the IAM Attack Surface through Identity Visibility and Intelligence Platforms (IVIP)](https://inl03.netline.com/ltr6/?_m=3n.009a.3994.sp0ao46r89.31oe)
**解説日**: 2025年6月3日

---

## 背景知識

この記事を理解するために、まず「**企業のデジタルIDとは何か**」を押さえておきましょう。

### 🏫 学校で例えると…

学校では、生徒や先生それぞれに「生徒証・職員証」が配られ、「どの教室に入れるか」「どの機材を使えるか」が決まっていますよね。これと同じように、企業でも**すべての人・システム・機械が「デジタルID（身分証）」を持って**おり、「どのデータにアクセスできるか」が管理されています。

### 主要な概念

| 用語 | わかりやすい説明 |
|------|----------------|
| **IAM (Identity and Access Management)** | 「誰が・何に・どこまでアクセスできるか」を管理するシステム。学校の「入退室管理システム」のようなもの |
| **ID（アイデンティティ）** | デジタル世界における「身分証」。人間だけでなく、ロボットやプログラムも持つ |
| **非人間ID (Non-Human Identity)** | AIやプログラムなど、機械が持つデジタル身分証 |
| **権限（パーミッション）** | 「どのファイルを開けるか」「どのシステムを操作できるか」などのアクセス許可 |

## 何が起きたのか

### 😱 企業の「見えないID」問題が深刻化している

セキュリティ調査会社のOrchid Securityの分析によると、企業で行われているID関連の活動のうち、**約46%（ほぼ半分！）が中央管理システムの「見えないところ」で起きている**ことがわかりました。

これを記事では「**Identity Dark Matter（アイデンティティ・ダークマター）**」と呼んでいます。宇宙の「暗黒物質（目に見えないのに存在する物質）」になぞらえた表現です。

```
企業のIDアクセス活動

┌─────────────────────────────────┐
│  管理・監視できている部分  54%  │  ← セキュリティチームが把握
├─────────────────────────────────┤
│  見えていない「ダークマター」46% │  ← ⚠️ ここが危険地帯！
└─────────────────────────────────┘
```

### 📦 「見えないID」の正体は何か？

1. **野良アプリケーション** → 会社が正式に管理していないソフトやサービス
2. **ローカルアカウント** → 個人PCだけに存在する、会社の管理外のアカウント
3. **AIエージェント** → 自動的に動くAIが持っているID（最近急増中）
4. **過剰な権限を持つ機械ID** → 必要以上に多くの操作ができるプログラムのID

## 技術的な詳細

### 🔍 Gartnerが提唱する新しい仕組み「IVIP」

この問題を解決するため、世界的なIT調査会社「**Gartner（ガートナー）**」が「**IVIP（Identity Visibility and Intelligence Platform）**」という新しいカテゴリーのセキュリティツールを定義しました。

**IVIP = "IDを360度見える化＆インテリジェントに分析するプラットフォーム"**

### IVIPが持つべき3つの機能

```
【IVIP の3大機能】

① 継続的なID発見（Discovery）
   すべての人間・機械のIDを、管理対象外も含めて自動検出

② IDデータ統合（Unification）
   バラバラに散らばった情報を一箇所に集めて整理

③ インテリジェント分析（Intelligence）
   AIを使って「怪しい動き」と「普通の動き」を区別
```

### 🤖 Orchid Securityの革新的なアプローチ

記事で紹介されているOrchid SecurityというIT会社は、IVIPを実際に製品化した企業です。

その特徴は**「バイナリ解析（Binary Analysis）」**と**「動的インスツルメンテーション（Dynamic Instrumentation）」**という技術を使っている点です。

> 📖 **バイナリ解析とは？**
> アプリの設計図（ソースコード）を見なくても、完成品のプログラムを直接調べてセキュリティの問題を見つける技術。建物の設計図がなくても、建物の構造をスキャンして欠陥を見つけるようなイメージ。

これにより「APIの設定もいらず、ソースコードの変更もなく」企業内の全アプリを調査できます。

## なぜ重要なのか

### 🎯 攻撃者が狙うのは「見えないすき間」

サイバー攻撃者は、セキュリティチームが**監視できていない場所**を狙います。

```
攻撃者の思考

「この会社のメインIDシステムは厳重に守られている」
           ↓
「でも、管理されていないサブシステムに
　野良アカウントや過剰権限のAIがいるんじゃないか？」
           ↓
「そこから侵入すれば気づかれにくい！」
```

### 📊 現代企業が抱える3つのリスク

| リスク | 内容 | 具体例 |
|--------|------|--------|
| **AIエージェントの急増** | 自律的に動くAIが持つIDが増加・管理困難に | 「社内業務自動化AI」が必要以上の権限を持ってしまう |
| **ツールの乱立** | 各部署が独自ツールを使い、IDが分散 | 部署ごとに別々のクラウドサービスを利用 |
| **見えない認証フロー** | どこでどう認証されているか全体像が不明 | 古いシステムが独自の認証で動いている |

## 対策・今後の展望

### ✅ 企業が今すぐ取り組めること

1. **「見えていないID」の棚卸し**
   → 自社で使っているアプリ・サービスをすべてリストアップし、管理されているIDを確認する

2. **最小権限の原則を徹底する**
   → 「必要最低限のアクセス権限だけを与える」ルールを全IDに適用する
   → 例：コピー機の管理プログラムに「全社データベースへのアクセス権」は不要！

3. **AIエージェントのID管理を強化**
   → AIが使うIDも、人間のIDと同じように厳格に管理・監視する

4. **IVIPのような統合可視化ツールの導入**
   → バラバラなIDシステムを一元的に見渡せるプラットフォームを検討する

### 🔮 今後の展望

- **AIエージェントの普及**に伴い、「機械ID」の管理がより一層重要になる
- **CAEP（Continuous Access Evaluation Protocol）** というリアルタイムでセキュリティ情報を共有する標準規格の活用が広がる見込み
- GartnerがIVIPというカテゴリーを定義したことで、**業界全体でIDの可視化への投資が加速**すると予想される

## 過去記事との関連

以前の週刊まとめ記事（2025年6月3日）で「**OAuthフィッシング攻撃**」について触れましたが、これは今回の記事と深くつながっています。

> **OAuthフィッシングとは？**
> OAuthという「ログイン情報を安全に共有する仕組み」を悪用して、ユーザーをだましてIDへのアクセス権を奪う攻撃。

OAuthフィッシングが成功しやすい背景の一つが、まさに今回記事が指摘する「**IDの可視化不足**」です。管理されていないID・過剰な権限を持つIDが存在するほど、攻撃者に悪用される入り口が増えます。

また「Miasmaサプライチェーン攻撃」で悪意あるコードが企業に侵入できた背景にも、「どのコード・どのIDが動いているか把握しきれていない」という問題が関係しています。

## 用語解説

| 用語 | 解説 |
|------|------|
| **IAM（Identity and Access Management）** | IDとアクセス権を統合管理するシステム |
| **IVIP** | IDを可視化・分析する新世代のセキュリティプラットフォーム（Gartner提唱） |
| **Identity Dark Matter** | セキュリティチームの監視が届かない「見えないID活動」 |
| **非人間ID (Non-Human Identity)** | AIやプログラムなど機械が持つデジタル身分証 |
| **Gartner** | 世界的に影響力のあるIT調査・コンサルティング会社 |
| **バイナリ解析** | プログラムの「完成品」を直接調べてセキュリティ問題を発見する技術 |
| **CAEP** | リアルタイムでセキュリティ状態を共有するための業界標準規格 |
| **LLM（大規模言語モデル）** | ChatGPTのような高度なAI言語システム |
| **アジェンティックAI** | 自律的に判断・行動するAIシステム（最近急増） |
| **最小権限の原則** | 必要最低限のアクセス権だけを与えるセキュリティの基本原則 |

---

> 💡 **まとめると...**
> 企業のIDシステムの「ほぼ半分」が管理の目が届いていないことが判明。攻撃者はそのすき間を狙います。これを解決する新しい技術「IVIP」が注目されており、特にAIエージェントの急増を受けてID管理の重要性はますます高まっています。
