# マインクラフトプレイヤーを狙った新マルウェア「Weedhack」が猛威！86,000人超の被害も

**元記事**: [Weedhack Attacks Minecraft Users, CountLoader Hits 86K, Miners Spread via Pirated Content](https://inl03.netline.com/ltr6/?_m=3n.009a.3994.sp0ao46r89.31pe)
**解説日**: 2026年6月4日

---

## 背景知識

このニュースを理解するために、いくつかの基本的な概念を押さえておきましょう。

### 🎮 マインクラフト（Minecraft）とは？
世界で最も売れたゲームの一つです。「Mod（モッド）」と呼ばれる、ゲームに新しい機能を追加する改造データを、プレイヤーが自分でダウンロードして使う文化があります。この「Modをダウンロードする習慣」が今回の攻撃に悪用されました。

### 🦠 マルウェアとは？
「Malware（マルウェア）」は「悪意のあるソフトウェア」の略です。インストールしてしまうと、あなたのパソコンを勝手に操作されたり、パスワードを盗まれたりします。

### 🛒 MaaS（マルウェア・アズ・ア・サービス）とは？
まるでNetflixの月額サービスのように、「攻撃ツールをサブスク契約して使う」という仕組みです。プログラムの知識がない人でも、お金さえ払えば高度な攻撃ができてしまいます。

### 🔍 SEOポイズニングとは？
「SEO」はGoogleなどの検索結果で上位に表示させる技術です。「ポイズニング（毒を盛る）」とは、その仕組みを悪用して、**危険なサイトを検索結果の上位に意図的に表示させる**攻撃手法です。

## 何が起きたのか

セキュリティ企業「McAfee Labs」が、**マインクラフトプレイヤーを狙った大規模なマルウェアキャンペーン**を発見しました。その名も **「Weedhack（ウィードハック）」** です。

### 📊 被害の規模

| 項目 | 数値 |
|------|------|
| 確認された悪意のあるファイル数 | **3,820個** |
| 悪意のあるURL数 | **240以上** |
| Telegramの購読者数（攻撃者のチャンネル） | **850人以上** |
| 主な被害国 | アメリカ、ドイツ、インド、イギリス、イタリアなど |

活動は**2026年1月から始まっており**、主にYouTubeを入口として被害が広がっています。

### 😱 何が盗まれるのか？

無料版だけでも、これだけのことができてしまいます：

- ✅ マインクラフトのアカウント情報（セッションID）
- ✅ **36種類のウェブブラウザ**からパスワード・Cookie（クッキー）
- ✅ **56種類のブラウザ拡張の仮想通貨ウォレット**の情報
- ✅ Discord・Steam・Telegramのログイン情報
- ✅ スクリーンショット（画面の写真）
- ✅ パソコン内のファイル

## 技術的な詳細

### 🕵️ 攻撃の流れ（ステップbyステップ）

攻撃は以下のように段階的に進みます。まるで「罠の入れ子」のような構造です。

```
【ステップ1】罠への誘導
YouTubeの偽Mod紹介動画を見る
  ↓
説明欄のリンクをクリック
  ↓
悪意のあるサイトへ移動
```

```
【ステップ2】最初のファイルをダウンロード
「DonutDupe.jar」という罠ファイルをダウンロード
（.jarはJavaのプログラムファイル形式）
  ↓
「EtherHiding（イーサーハイディング）」という技術で
攻撃者のサーバーのアドレスを取得
```

> 💡 **EtherHidingとは？**
> イーサリアム（仮想通貨）のブロックチェーンを「隠し場所」として使う技術です。ブロックチェーンは削除・改ざんができないため、攻撃者サーバーの居場所を警察や研究者に消されないように隠せます。郵便ポストに暗号メモを入れておくイメージです。

```
【ステップ3】本体をダウンロード
攻撃者のサーバーから「Elevator.jar」を受け取る
  ↓
Windowsのウイルス対策ソフト（Microsoft Defender）を
無効化・回避する設定をする
  ↓
さらに2つのファイルを追加ダウンロード
```

```
【ステップ4】完全に乗っ取られる
「SecurityManager.jar」→ パソコン起動のたびに自動実行される仕掛け
  ↓
「Component.jar」→ 遠隔操作の完成
```

### 💰 有料プランの恐ろしい機能

月額わずか**約700円（$4.99）**で以下が使えてしまいます：

| 機能 | 内容 |
|------|------|
| ウェブカメラアクセス | 被害者の顔を無断撮影 |
| キーロギング | キーボードの入力を全て記録（パスワードも！） |
| 画面共有 | 被害者の画面をリアルタイムで見る |
| マウス・キーボード操作 | 被害者のパソコンを遠隔操作 |
| ファイルの送受信 | ファイルを盗んだり送り込んだりする |

## なぜ重要なのか

### 🔴 ポイント1：入門のハードルが限りなく低い

これまでのサイバー犯罪は、ある程度のプログラミング知識が必要でした。しかし今回のWeedhackは：

- **無料で使える**
- **使い方のチュートリアル（解説動画）付き**
- **Telegramでサポートも受けられる**

つまり、**中学生や高校生でも使えてしまう**危険なツールになっています。

### 🔴 ポイント2：ターゲットが若者・子供

> McAfee Labsは「攻撃者の顧客と思われるのは10代・20代前半が多く、遠隔操作機能を使って被害者を脅したり、嫌がらせをしたりしている」と報告しています。

さらに衝撃的なのは、**ウェブカメラで被害者を録画し、その動画をTelegramで「戦利品」として共有している**という事実です。これはもはやサイバー犯罪であるだけでなく、**深刻ないじめ・ハラスメント**でもあります。

### 🔴 ポイント3：マインクラフトという「信頼されるコミュニティ」が悪用されている

多くのプレイヤーが「Modは当たり前にダウンロードするもの」という感覚を持っています。その「普通の行動」が罠になっています。

## 対策・今後の展望

### ✅ あなたができる対策

#### 【最重要】ファイルのダウンロード元を必ず確認する
```
❌ NG：YouTubeの動画の説明欄のリンクから直接ダウンロード
✅ OK：CurseForge・Modrinthなど公式のMod配布サイトのみ使う
```

#### 【重要】ウイルス対策ソフトを常に最新の状態に
Weedhackは「Microsoft Defenderの除外設定」を勝手に変更しようとします。定期的にウイルス対策ソフトの設定を確認しましょう。

#### 【必須】パスワードを使い回さない
万が一パスワードを盗まれた場合でも、**ゲーム用・学校用・SNS用などでパスワードを別にしておく**と被害を最小限にできます。

#### 【推奨】2段階認証（2FA）を設定する
Discord・Steam・Microsoftアカウントなど、すべてに2段階認証を設定しましょう。パスワードが盗まれても、ログインを防げます。

#### 【注意】「無料の高機能Mod・チート」は疑ってかかる
「無料で使えるチート」「本来有料のModが無料」などは、マルウェアの定番の罠です。

### 🔮 今後の展望

- McAfee Labsは既にこの情報を公開しており、セキュリティソフトのアップデートで対応が進む見込みです
- ただし、攻撃者は常に新しい手口を開発するため、**自分自身の「習慣」を見直すことが最大の防御**になります

## 過去記事との関連

以前、「**パッチ未適用のWindows検索機能の脆弱性で、パスワードの"カギ"が盗まれる危険性**」について解説しました。

今回のWeedhackとの共通点は**「一般ユーザーの日常的な行動を入口にする」**という点です。

- 前回：Windowsの「検索」という普通の機能を使うだけで攻撃される
- 今回：Minecraftの「Modダウンロード」という普通の行動が罠になる

どちらも共通しているのは、「特別な行動をしなくても被害に遭う」という怖さです。**OSやソフトのアップデートを怠らないこと**と**ダウンロード元をしっかり確認すること**が、どちらの攻撃に対しても有効な基本的な対策となります。

## 用語解説

| 用語 | 意味 |
|------|------|
| **マルウェア（Malware）** | 悪意を持って作られたソフトウェアの総称 |
| **MaaS（Malware as a Service）** | 月額課金などでマルウェアを提供するサービス形態 |
| **SEOポイズニング** | 検索エンジンの仕組みを悪用して危険サイトを上位表示させる手法 |
| **JAR（ジャー）ファイル** | Javaというプログラム言語で作られた実行ファイル。マインクラフトはJavaで動くため狙われやすい |
| **C2サーバー（Command and Control）** | 攻撃者がマルウェアに命令を送るための「司令塔」サーバー |
| **EtherHiding** | ブロックチェーンを隠し場所として使い、C2サーバーの情報を隠す技術 |
| **キーロギング** | キーボードの入力を記録する機能。パスワードが丸見えになる |
| **リバースシェル** | 被害者のパソコンから攻撃者のサーバーに接続させ、遠隔操作を可能にする技術 |
| **Cookie（クッキー）** | ウェブサービスへのログイン状態などを記録した小さなデータ。盗まれると「なりすましログイン」される |
| **ブロックチェーン** | データを改ざん・削除できない形で記録する技術。仮想通貨で使われる |
| **インフォスティーラー** | 「情報を盗む」マルウェアの種類。パスワードやファイルなどを収集して攻撃者に送る |
| **パーシステンス（Persistence）** | パソコンを再起動してもマルウェアが消えないように仕掛けること |
