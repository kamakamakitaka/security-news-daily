# Weedhack：Minecraftユーザーを狙うマルウェア攻撃・CountLoaderが86,000件に・海賊版コンテンツを通じたマイナー拡散

**元記事**: [Weedhack Attacks Minecraft Users, CountLoader Hits 86K, Miners Spread via Pirated Content](https://inl03.netline.com/ltr6/?_m=3n.009a.3994.sp0ao46r89.31pe)
**解説日**: 2026年6月4日

---

## 背景知識

まず、この記事を理解するために知っておきたいポイントをいくつか説明します。

**Minecraft（マインクラフト）とは？**
世界で最も人気のあるゲームのひとつで、ブロックを使って建物や世界を作るゲームです。「Mod（モッド）」と呼ばれる拡張機能を追加することで、ゲームに新しい要素を加えることができます。公式ではないModも多く出回っており、これが今回の攻撃に悪用されました。

**マルウェア（Malware）とは？**
「悪意のあるソフトウェア」の総称です。ウイルスやスパイウェアなど、コンピュータに害を与えるプログラム全般を指します。

**MaaS（Malware-as-a-Service）とは？**
「サービスとしてのマルウェア」という意味で、まるでNetflixのように「月額料金を払えばマルウェアを使わせてあげます」というビジネスモデルのことです。技術的な知識がなくても、お金を払えば攻撃できてしまうという怖い仕組みです。

**JAR ファイルとは？**
Java（ジャバ）というプログラミング言語で作られたプログラムをまとめたファイルです。Minecraftはまさにこのファイル形式を使って動いています。

## 何が起きたのか

セキュリティ企業「McAfee Labs（マカフィーラボ）」が、**Minecraftプレイヤーを狙った大規模なマルウェア攻撃キャンペーン**を発見しました。この攻撃は **「Weedhack（ウィードハック）」** と名付けられており、2026年1月から活動が確認されています。

### 被害の規模

- 🗂️ **3,820個**の悪意あるJARファイルを確認
- 🔗 **240以上**の悪意あるURLが拡散に使われている
- 👥 Telegramチャンネルの登録者は**850人以上**
- 🌍 被害者は**アメリカ・ドイツ・インド・イギリス・イタリア・ベトナム・カナダ・ノルウェー・スウェーデン・フィンランド・スペイン**など多数の国に広がっている

### 攻撃の入口はYouTube

攻撃者は、**YouTubeに「MinecraftのModの使い方・紹介動画」を投稿**し、その動画の説明欄に悪意あるリンクを貼り付けていました。「このModを使うとゲームが面白くなるよ！」と見せかけて、実は危険なファイルをダウンロードさせていたのです。

## 技術的な詳細

攻撃の流れをステップごとに解説します。まるで悪意ある「罠のルート」のようなものです。

### STEP 1：罠のダウンロード
ユーザーが偽のMinecraft ModサイトやYouTubeリンクから **「DonutDupe.jar」** というファイルをダウンロードします。見た目は普通のModファイルです。

### STEP 2：C2サーバーへの接続
ダウンロードされたファイルは **「EtherHiding（イーサーハイディング）」** という技術を使って、攻撃者の指令サーバー（C2サーバー）のアドレスを探します。

> 💡 **EtherHidingとは？**
> イーサリアム（仮想通貨）のブロックチェーンを「隠し場所（dead drop）」として使う技術です。ブロックチェーンは書き換えが難しく、セキュリティソフトが怪しいサーバーアドレスをブロックしにくいため、悪用されています。まるで「犯罪指令が書かれた手紙を、誰も消せない掲示板に貼っておく」ようなイメージです。

### STEP 3：追加マルウェアの投下
C2サーバーから **「Elevator.jar」** というファイルが送られてきます。このファイルは：
- コンピュータの情報を収集する
- Windowsのセキュリティ機能（Defender）を無効化する
- さらに別のマルウェアを呼び込む通路になる

### STEP 4：持続化と完全乗っ取り
**「SecurityManager.jar」** がパソコンに居座り続ける仕組みを作り、最終的に **「Component.jar」** が遠隔操作（リモートアクセス）機能を起動します。

### 🎁 無料・有料プランまで用意されている！

なんと、このマルウェアは**「無料プラン」と「有料プラン」**に分かれています。まるでアプリの課金システムのようですが、これは犯罪ツールです。

#### 無料プラン（タダで使える機能）
- Minecraftのアカウント情報（セッションID）を盗む
- スクリーンショットを取る
- **36種類のブラウザ**からパスワード・クッキー・履歴を盗む
- **56種類のブラウザ内仮想通貨ウォレット**と**12種類のデスクトップウォレット**からデータを盗む
- Discord・Steam・Telegramのアカウントを盗む

#### 有料プラン（月額約730円〜）
- **Webカメラへのアクセス**（ユーザーを盗撮できる）
- **キーロギング**（キーボードで入力した文字をすべて記録）
- **リバースシェル**（コンピュータを完全に乗っ取る）
- 画面共有・ファイルの送受信

> 💡 **キーロギングとは？**
> キーボードで打ったすべての文字（パスワードや個人情報も含む）を記録する機能です。

## なぜ重要なのか

### 🚨 特に危険な3つの理由

**① 「無料」なので参入障壁が低い**
通常、サイバー攻撃には高度な技術が必要です。しかしWeedhackは無料で使えるため、**技術的な知識がない10代の若者でも犯罪者になれてしまいます**。McAfee Labsの研究者も「コストと利用のしやすさが参入障壁を大幅に下げている」と指摘しています。

**② ターゲットが若い世代**
MinecraftはZ世代・α世代に絶大な人気があります。若いユーザーはセキュリティ意識が低い傾向があり、騙されやすいというリスクがあります。また、**被害者も加害者も10代・20代が多い**という深刻な状況が確認されています。

**③ サイバーいじめへの悪用**
McAfee Labsは、このツールが**「サイバーいじめ（cyberbullying）」の道具**として使われている証拠も発見しました。10代の犯罪者たちが、被害者のWebカメラで動画を撮影し、それをTelegramで「トロフィー」として共有しているというゾッとする実態が明らかになっています。これは単なる情報漏洩ではなく、**プライバシーの侵害・ハラスメント行為**でもあります。

## 対策・今後の展望

### ✅ 今すぐできる対策

1. **Modは公式・信頼できるサイトからのみダウンロード**
   - CurseForge（カースフォージ）やModrinth（モドリンス）など、実績のある公式プラットフォームを使いましょう
   - YouTubeの説明欄のリンクは安易にクリックしない！

2. **知らないJARファイルは絶対に実行しない**
   - 「無料でゲームを強化できる」という甘い言葉には要注意です

3. **セキュリティソフトを常に最新の状態に保つ**
   - Weedhackはセキュリティソフト（Defender）を無効化しようとするので、常に有効にしておくことが重要です

4. **公式ランチャー（起動ツール）を使う**
   - Minecraft公式サイトのランチャーを使い、非公式の「クライアント」は避けましょう

5. **パスワードの定期的な変更と2段階認証**
   - Minecraftアカウントだけでなく、Discord・Steam・Googleなどのサービスにも2段階認証（2FA）を設定しましょう

6. **Webカメラには物理カバーを**
   - 使わないときはカメラを隠すシールやカバーを付けるだけで、最悪の事態を防げます

### 📌 今後の動向
攻撃者はTelegramチャンネルで積極的にアップデートを告知しており、ツールは今後も進化していく可能性があります。Minecraft以外のゲームや若者向けプラットフォームへの拡大も懸念されます。

## 過去記事との関連

以前「**Miasma（ミアズマ）サプライチェーン攻撃**」として、正規のソフトウェアパッケージに悪意あるコードを混入させる手法について解説しました。今回のWeedhackも同様に、**「正規のMinecraft Mod」を装って悪意あるコードを混入させる**という手法を取っています。

攻撃者は「正規のものに見せかける」という戦略を変えていません。これはサプライチェーン攻撃の考え方と共通しており、**「信頼されているコンテンツを踏み台にする」**という攻撃トレンドが続いていることを示しています。

また「**AIを使った攻撃**」のまとめ記事でも触れたように、攻撃ツールが「サービス化・商品化」されることで、一般人が手軽に攻撃者になれてしまう時代になっています。Weedhackはまさにその典型例です。

## 用語解説

| 用語 | 意味 |
|------|------|
| **マルウェア（Malware）** | 悪意のあるソフトウェアの総称。ウイルス・スパイウェアなどを含む |
| **MaaS（Malware-as-a-Service）** | 月額制などでマルウェアを提供するビジネスモデル。犯罪の「サブスク」 |
| **JAR ファイル** | Javaプログラムをまとめたファイル。Minecraftが使う形式 |
| **C2サーバー（Command & Control）** | 攻撃者がマルウェアに指示を出すための「指令センター」 |
| **EtherHiding** | 仮想通貨イーサリアムのブロックチェーンをC2サーバーアドレスの隠し場所として使う技術 |
| **SEOポイズニング** | 検索結果の上位に悪意あるサイトが表示されるよう操作する手法。「検索結果の汚染」 |
| **キーロギング（Keylogging）** | キーボード入力をすべて記録する機能。パスワードも盗まれる |
| **リバースシェル（Reverse Shell）** | 被害者のPCを完全遠隔操作できる状態にする高度な攻撃手法 |
| **インフォスティーラー（Infostealer）** | パスワードや個人情報を盗むことに特化したマルウェア |
| **ブロックチェーン** | 改ざんが非常に難しいデータの記録技術。仮想通貨で有名 |
| **2段階認証（2FA）** | パスワードに加え、スマホへのコード送信などで本人確認をする仕組み |
| **Minecraft Mod** | Minecraftに新機能を追加する非公式の拡張プログラム |
