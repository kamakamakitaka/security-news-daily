# Weedhack：Minecraftユーザーを狙う新マルウェア・86,000台感染のCountLoader・海賊版ソフトを経由するマイナー拡散

**元記事**: [Weedhack Attacks Minecraft Users, CountLoader Hits 86K, Miners Spread via Pirated Content](https://inl03.netline.com/ltr6/?_m=3n.009a.3994.sp0ao46r89.31pe)
**解説日**: 2026年6月3日

---

## 背景知識

まず、この記事を理解するために必要な基本知識を押さえておきましょう。

### Minecraftとは？
世界で最も人気のあるゲームのひとつです。「Mod（モッド）」と呼ばれる有志が作った拡張プログラムを追加することで、ゲームに新機能を追加できます。Modは公式のものではなく、**誰でも作って配布できる**ため、悪意あるファイルを紛れ込ませやすいという特徴があります。

### MaaS（Malware-as-a-Service）とは？
「マルウェア・アズ・ア・サービス」の略。マルウェア（悪意あるソフトウェア）を**まるでサブスクサービスのように販売・提供するビジネスモデル**です。専門知識がなくても、お金を払えば強力な攻撃ツールが使えてしまいます。

### JAR ファイルとは？
Javaというプログラミング言語で作られたプログラムをまとめたファイル形式（`.jar`）です。MinecraftはJavaで動いているため、プレイヤーはJARファイルをよく扱います。**それを悪用されているのが今回の手口です。**

### SEOポイズニングとは？
SEO（検索エンジン最適化）を悪用して、**悪意あるサイトをGoogle等の検索結果の上位に表示させる**手法です。普通に検索しただけで危険なサイトにたどり着かされてしまいます。

---

## 何が起きたのか

セキュリティ企業「McAfee Labs」が、**Minecraftプレイヤーを標的にした大規模なマルウェア配布キャンペーン「Weedhack（ウィードハック）」**を発見しました。

### 主な事実まとめ

| 項目 | 内容 |
|------|------|
| 発覚時期 | 2026年1月から活動中 |
| 悪意あるファイル数 | 3,820個以上のJARファイル |
| 配布URL数 | 240以上 |
| Telegramチャンネル登録者 | 850人以上 |
| 主な被害国 | アメリカ、ドイツ、インド、イギリス、イタリア、ベトナム、カナダ、ノルウェー、スウェーデン、フィンランド、スペイン |

攻撃者たちは**YouTubeでMinecraftのMod紹介動画を投稿し**、動画の説明欄に悪意あるサイトへのリンクを貼ることでプレイヤーをだましています。「このModを入れるともっとゲームが楽しくなるよ！」という動画を見た人が、知らずにマルウェアをダウンロードしてしまうわけです。

## 技術的な詳細

### 攻撃の流れ（ステップごとに解説）

```
①YouTubeの動画やSEO検索で悪意あるサイトへ誘導
        ↓
②「DonutDupe.jar」という悪意あるJARファイルをダウンロード
        ↓
③EtherHiding（イーサリアムブロックチェーンを使って攻撃サーバーを隠す）
        ↓
④攻撃サーバーから「Elevator.jar」を受信
   ・システム情報の収集
   ・Windowsウイルス対策（Defender）の無効化
        ↓
⑤「SecurityManager.jar」→「Component.jar」を順次実行
   ・パソコンへの常駐（再起動しても消えない）
   ・遠隔操作機能の有効化
```

### 特に注目すべき技術：EtherHiding（イーサーハイディング）

> 「EtherHiding」とは、**イーサリアムというブロックチェーン（仮想通貨の技術）を"伝言板"として使い**、攻撃サーバーのアドレスを隠す技術です。

通常、攻撃に使われるサーバーは当局に発見されると閉鎖されます。しかしブロックチェーンは**世界中に分散していて誰も削除できない**ため、攻撃サーバーの情報を隠しておく場所として悪用されています。

### 盗まれる情報の一覧（無料版でもこれだけ！）

- 🎮 Minecraftのアカウント情報（4種類のランチャーに対応）
- 🌐 36種類のブラウザのパスワード・Cookie
- 💰 56種類のブラウザ拡張の仮想通貨ウォレット
- 💻 12種類のデスクトップ仮想通貨ウォレット
- 💬 Discord・Steam・Telegramのアカウント
- 📸 スクリーンショット

### 有料版（月499円〜）ではさらに…

- 📷 **Webカメラの映像を盗み見**
- ⌨️ **キーロギング**（キーボードの入力をすべて記録）
- 🖥️ 画面のリアルタイム共有・マウス・キーボード操作
- ファイルのアップロード・ダウンロード

## なぜ重要なのか

### ① 無料で使えてしまう恐ろしさ

通常、強力なハッキングツールは高価で、使いこなすにも専門知識が必要でした。しかし **Weedhackは無料プランが存在し、使い方のチュートリアルも用意されている**ため、知識がほとんどない人でも攻撃者になれてしまいます。

> 🔑 **ポイント**: 犯罪の「入門ハードル」が極限まで下がっています。

### ② ターゲットが若者・子ども

Minecraftは特に**10代〜20代前半のユーザーが多い**ゲームです。セキュリティ意識がまだ低い層が狙われています。

### ③ サイバーいじめへの悪用

McAfee Labsの調査によると、Weedhackの利用者には**10代・20代前半の若者が多く含まれており**、遠隔操作機能を使って以下のような**サイバーいじめ**に活用しているケースが確認されています：

- 被害者のWebカメラで動画を無断撮影
- その動画をTelegramで「戦利品」として共有
- 被害者を脅迫・嫌がらせ・監視

これは単なるハッキングを超えた**プライバシー侵害・犯罪行為**です。

### ④ ダッシュボードで管理される「被害者リスト」

`weedhack[.]to` というサイトには企業レベルの管理画面があり、攻撃者は感染したパソコンの状況を一覧で確認・遠隔操作できます。まるでビジネスツールのような洗練された作りです。

## 対策・今後の展望

### ✅ 今すぐできる対策

#### Minecraftプレイヤー向け
1. **Modは公式・信頼できるサイト（CurseForge等）からのみダウンロードする**
2. YouTubeの動画説明欄のリンクは**絶対にそのままクリックしない**（公式サイトで検索し直す）
3. 見知らぬ`.jar`ファイルは絶対に実行しない

#### 一般的な対策
4. **ウイルス対策ソフトを最新の状態に保つ**（McAfeeはWeedhackに対応済み）
5. 各サービスで**異なるパスワードを使う**（パスワードマネージャーの活用）
6. **2段階認証（2FA）を設定する**（パスワードが盗まれても不正ログインされにくくなる）
7. 怪しいと思ったら**信頼できる大人やセキュリティ専門家に相談する**

#### 親御さん・先生向け
- 子どもがどんなModをどこからダウンロードしているか確認する
- 「無料でツールが手に入るから使ってみよう」という誘惑に乗らないよう教育する
- Webカメラに**物理的なカバー**をつける

### 今後の展望
- 捜査当局によるTelegramチャンネルやドメインの閉鎖が期待されますが、MaaSビジネスモデルは**「閉鎖されても別の名前で復活」するケースが多い**です
- ブロックチェーンを使ったEtherHidingのような技術は追跡が困難で、**今後も同様の手口が増える**と予想されます

今回のWeedhackとの共通点があります。どちらも**「一般ユーザーが普段使うもの（Windows検索・Minecraftのmod）を入口にして攻撃する」**点です。特別なことをしていないのに被害に遭うケースが増えており、「自分は大丈夫」という油断が最大のリスクになっています。

また、攻撃の対象が専門家ではなく**若者・初心者・ゲーマー**にシフトしていることも、最近のセキュリティ脅威の大きなトレンドとなっています。

## 用語解説

| 用語 | 説明 |
|------|------|
| **マルウェア** | 悪意あるソフトウェアの総称。ウイルス・スパイウェアなどを含む |
| **MaaS（Malware-as-a-Service）** | マルウェアをサブスクのように販売するサービス形態 |
| **JAR ファイル** | Javaで動くプログラムのファイル形式（`.jar`）|
| **SEOポイズニング** | 検索結果を操作して悪意あるサイトを上位表示させる手法 |
| **C2サーバー（Command & Control）** | 攻撃者がマルウェアに命令を送るための指令サーバー |
| **EtherHiding** | ブロックチェーンを使って攻撃サーバーの情報を隠す技術 |
| **インフォスティーラー** | 情報を盗み取ることに特化したマルウェア |
| **キーロギング** | キーボードの入力内容をすべて記録する機能 |
| **リバースシェル** | 攻撃者が遠隔からターゲットのパソコンを操作できるようにする技術 |
| **ペイロード** | マルウェアが実際に悪さをする本体部分のプログラム |
| **パーシステンス（永続化）** | パソコンを再起動しても消えないようにマルウェアが自分を維持する仕組み |
| **2段階認証（2FA）** | パスワードに加えて、スマホ等への確認コードも必要にするセキュリティ機能 |
