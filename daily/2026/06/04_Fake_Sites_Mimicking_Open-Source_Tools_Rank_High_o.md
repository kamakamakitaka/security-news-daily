# 偽サイトがGoogleで上位表示！無料ツールに偽装してマルウェアを配布する大規模詐欺が発覚

**元記事**: [Fake Sites Mimicking Open-Source Tools Rank High on Google to Deliver Malware via TDS](https://inl03.netline.com/ltr6/?_m=3n.009a.3995.sp0ao46r89.31py)
**解説日**: 2026年6月10日

---

## 背景知識

このニュースを理解するために、まずいくつかのキーワードを押さえておきましょう。

### 🔧 オープンソースツールって何？
「オープンソース」とは、プログラムのソースコード（設計図）が無料で公開されているソフトウェアのことです。誰でも無料でダウンロードして使えるため、エンジニアやセキュリティ研究者に広く愛用されています。

### 🔍 SEO（検索エンジン最適化）って何？
GoogleなどのSearch Engineで「上位に表示されやすくする」ための技術のことです。正規のSEOはビジネス目的で使われますが、悪用されると**偽サイトが本物より上に表示される**という危険な状況を生み出します。

### 🚦 TDS（トラフィック・ディストリビューション・システム）って何？
「交通整理システム」のようなものです。ウェブサイトを訪問したユーザーを、条件に応じて**異なるページへ振り分ける仕組み**です。正規のマーケティングでも使われますが、今回は悪意ある目的に使われました。

---

## 何が起きたのか

セキュリティ企業「Check Point」の研究者が、**大規模な偽サイト詐欺キャンペーン**を発見しました。

### 事件の概要

```
① 詐欺師が有名な無料ツールに偽装したサイトを大量に作成
         ↓
② GoogleのSEO対策でそのサイトを検索上位に表示させる
         ↓
③ 本物のツールを探しているユーザーが偽サイトを開いてしまう
         ↓
④ 「ダウンロード」ボタンを押すとマルウェアが仕込まれる
```

### 偽装されたツールの例
- **Ghidra（ギドラ）**: アメリカ国家安全保障局（NSA）が公開した、プログラム解析ツール
- **dnSpy**: .NETアプリを解析するデバッグツール
- **SpiderFoot**: ネットワーク情報収集ツール

これらはすべて、**セキュリティ研究者やエンジニアがよく使う本物の有名ツール**です。

### タイムライン
| 時期 | 出来事 |
|------|--------|
| 2025年9月 | 偽サイト群の運営開始 |
| 2025年11月 | セキュリティ企業Fullstoryが初期段階を報告 |
| 2026年1月 | TDS経由でマルウェア配布開始 |
| 2026年現在 | 約2,000〜3,500件の感染サンプルを確認 |

## 技術的な詳細

### 🎭 偽サイトの巧妙な仕掛け

偽サイトは、**一見しただけでは本物と見分けがつかない**ほど精巧に作られています。さらに、以下のような巧みなトリックが仕込まれていました。

#### トリック① ホバーすると本物のURLが表示される
> ダウンロードボタンにマウスを乗せると、**本物のツールの正規URLが表示される**

「ちゃんと本物に飛ぶんだな」と安心させておいて、クリックした瞬間に悪意あるサイトに誘導されます。

#### トリック② 同じIPからアクセスすると無害なものをダウンロードさせる
> 同じIPアドレスからの繰り返しアクセスには、**Operaブラウザなど無害なソフトをダウンロードさせる**

セキュリティ研究者が調査しようとしても「普通のソフトしかダウンロードされない」と見せかけることで、**分析を妨害**します。

#### トリック③ CloudFront経由のJavaScriptで巧妙に振り分け
> クリック時に「CloudFront（Amazonのクラウドサービス）」を経由してJavaScriptが動き出し、TDSに接続

一般的に信頼されているAmazonのサービスを経由することで、**怪しさを隠します**。

### ⚙️ TDSの「フィルタリング」の仕組み

TDSは以下の条件でユーザーをふるいにかけます：

| チェック項目 | 目的 |
|---|---|
| 初回訪問かどうか | 研究者の繰り返しアクセスを除外 |
| クリック確認 | 自動巡回ボット（ロボット）を除外 |
| VPN・データセンター利用者の除外 | セキュリティ研究者を除外 |
| アクセス頻度の制限 | 調査されにくくする |

つまり「**本当に騙せそうな一般ユーザーだけ**」にマルウェアを届ける仕組みです。

### 💣 配布されるマルウェアの種類

#### 1. Remus Stealer（リームス・スティーラー）
**情報を盗み出すマルウェア（スティーラー）** の一種。

- 20以上のブラウザからパスワード・Cookie・履歴などを窃取
- 暗号資産ウォレット、二段階認証アプリ、パスワードマネージャーも標的
- **MaaS（マルウェア・アズ・ア・サービス）** として販売されている
  - ※MaaS：マルウェアをサービスとしてレンタルするビジネスモデル。犯罪者が"利用料"を払って使う

#### 2. AnimateClipper（アニメートクリッパー）
**暗号資産を横取りするマルウェア**。

- クリップボード（コピー＆ペーストのデータ置き場）を監視
- 暗号資産の送金先アドレスをコピーすると、**こっそり攻撃者のアドレスに書き換える**
- 20以上のブロックチェーン（仮想通貨の取引記録台帳）に対応

> 🌰 **わかりやすい例え話**: 手紙を封筒に入れて郵便ポストに投函しようとしたら、知らない間に宛先が書き換えられていた、というイメージです。

#### 3. SessionGate（セッションゲート）
**多段階の難読化ローダー（読み込みプログラム）**。

- 複雑な仕掛けでセキュリティソフトの分析を回避
- 最終的に別のマルウェアを呼び込む「玄関口」となる
- 無害なインストール画面を見せながら裏で悪意ある動作をする

## なぜ重要なのか

### 📊 被害の規模

- **感染サンプルが約2,000〜3,500件**確認済み
- 被害が確認されている国：トルコ・ポーランド・ブラジル・ドイツ・フランス・ロシア・イギリス
- **日本も無関係ではない**（日本語で検索する場合は比較的リスクが低いが、英語でツールを検索するエンジニアは要注意）

### 😰 特に恐ろしいポイント

1. **Googleの検索結果を信頼している人**が騙されやすい
   → 「Googleで上位に出てるから本物だろう」という先入観を突いてくる

2. **セキュリティ専門家を狙っている**
   → セキュリティエンジニアが使うツールを偽装しているため、守る側の人間も被害を受ける可能性がある

3. **見た目だけでは判断できない**
   → プロでも一目では偽物と見抜けないほど精巧

## 対策・今後の展望

### ✅ 今すぐできる対策

#### 1. ダウンロードは公式サイトから直接アクセスする
```
❌ 悪い例: Googleで「Ghidra ダウンロード」と検索してヒットしたサイトからDL
✅ 良い例: 知っている公式URL（例: ghidra-sre.org）を直接アドレスバーに入力
```

#### 2. URLをよく確認する
- 本物: `ghidra-sre.org`
- 偽物: `ghidra-download.com` / `ghidra-free.net` など

#### 3. クリップボードの内容は必ず目視確認する
- 暗号資産を送金するときは、**ペーストした後に送金先アドレスを必ず目で確認**

#### 4. セキュリティソフトを最新の状態に保つ
- Remus StealerやAnimateClipperの多くは、最新のセキュリティソフトで検出可能

#### 5. VPNを使う（皮肉にも有効）
- TDSはVPN利用者を「研究者かも」と判断してマルウェアを送らない場合があります

### 🔭 今後の動向
- この種の攻撃は**SEOを悪用した「SEOポイズニング（汚染）」** として今後も増加が予想されます
- GoogleやMicrosoftなどの検索エンジン側も対策を進めていますが、いたちごっこが続いています

## 過去記事との関連

以前、**「FlutterShell バックドア：悪意のあるGoogle・YouTube広告でMacに感染拡大」** という事件を解説しました。

あの事件では「**広告**」を悪用して偽サイトに誘導していましたが、今回は「**Google検索の自然検索結果（広告ではない部分）**」を悪用している点が異なります。

```
前回: 広告枠を買って偽サイトに誘導（お金で上位表示）
今回: SEO対策で検索結果を操作して偽サイトに誘導（技術で上位表示）
```

どちらも「**Googleという信頼できる存在を踏み台にする**」という共通点があります。つまり攻撃者は、私たちが「Googleを信頼している」という心理を狙い撃ちにしているのです。

## 用語解説

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **オープンソース** | - | ソースコードが公開・無償で使えるソフトウェア |
| **TDS** | ティーディーエス | Traffic Distribution System。ユーザーを条件に応じて異なるサイトに振り分けるシステム |
| **SEOポイズニング** | エスイーオー ポイズニング | 悪意ある偽サイトを検索上位に表示させる攻撃手法 |
| **スティーラー** | - | パスワードや個人情報を盗むマルウェアの種類 |
| **クリッパー** | - | クリップボードの内容（コピーしたデータ）を書き換えるマルウェア |
| **MaaS** | マース | Malware as a Service。マルウェアをサービスとして提供・販売するビジネスモデル |
| **難読化** | なんどくか | プログラムコードを読みにくく書き換え、解析されにくくする技術 |
| **CloudFront** | クラウドフロント | Amazonが提供するコンテンツ配信サービス。信頼性が高いため悪用される |
| **ブロックチェーン** | - | 暗号資産（仮想通貨）の取引を記録する分散型台帳技術 |
| **バックドア** | - | 攻撃者が後から侵入するために仕込む「裏口」プログラム |
| **サンドボックス** | - | マルウェアを安全な隔離環境で動かして分析する仕組み |

---

> 💡 **まとめ**: 「Googleで上位に出ているから安全」は**もはや通用しません**。特に無料ツールをダウンロードする際は、**必ず公式サイトのURLを直接入力する**習慣をつけましょう！
