# 大手証券取引所の幹部のメールを5ヶ月間こっそり盗み見ていたハッカーたち

**元記事**: [Hackers Spied on a Stock Exchange Executive's Outlook Mailbox for Five Months](https://inl03.netline.com/ltr6/?_m=3n.009a.3995.sp0ao46r89.31qa)
**解説日**: 2025年7月14日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的なことを押さえておきましょう。

### 証券取引所って何？
証券取引所（Stock Exchange）とは、株式（会社の権利書）や債券などを売買する「市場」のことです。東京証券取引所（東証）やニューヨーク証券取引所（NYSE）が有名です。ここで取引される情報は、**世界中のお金の動きに直結する非常に機密性の高いもの**です。

### Outlookって何？
Microsoft Outlookは、会社でよく使われるメールソフトです。メールの送受信だけでなく、カレンダー（スケジュール管理）や連絡先も管理できます。企業の幹部が日々使う「デジタルな手帳兼郵便受け」のようなものです。

### OST/PSTファイルって何？
Outlookのメールデータは、パソコンの中に「OST」や「PST」という特殊なファイル形式で保存されています。このファイルをコピーすれば、**メールボックスごとそっくり持ち出せる**という怖い特性があります。

### DropboxやOneDriveって？
どちらもインターネット上にファイルを保存できる「クラウドストレージ」サービスです。普段から多くの人が業務で使うため、これらへの通信は「普通のこと」として見過ごされやすいという特性があります。

## 何が起きたのか

🔍 **一言で言うと**：「世界的な大手証券取引所の幹部のメールを、ハッカーが5ヶ月以上にわたってこっそり盗み見し続けていた」という事件です。

セキュリティ企業の**Symantec（シマンテック）とCarbon Black**が今週、この攻撃キャンペーンを報告しました。

### 時系列で整理すると：

| 日時 | 出来事 |
|------|--------|
| 2025年10月10日 | 最初の不正活動が確認される |
| 2025年11月12日 | 本格的な攻撃が始まる（メール窃取開始） |
| 2025年8月〜2026年2月 | 2〜4週間おきにメールデータを盗み出し続ける |
| 2026年3月19日 | 最後に確認された活動 |

攻撃者は**誰なのかまだ特定されていません**。また、最初にどうやってパソコンに侵入したかも不明です。

---

## 技術的な詳細

ここが今回の攻撃で一番「巧妙」な部分です。まるで「泥棒がコンビニの制服を着て堂々と侵入する」ような手口でした。

### ① 最高権限での侵入

攻撃者は「SYSTEM」と呼ばれる**Windowsの最も強い管理者権限**でプログラムを動かしていました。これは、パソコンの鍵を全部持っている状態です。

さらに悪賢いことに、動かしていたプログラムを：
- 🎭 **Adobeのアップデーター（のふり）**
- 🎭 **OneDriveのサービス（のふり）**

に偽装していました。普通のプログラムに見せかけることで、セキュリティソフトに怪しまれないようにしていたのです。

### ② メールの「こっそり少しずつ」盗み出し

攻撃者は**Aspose（アスポーズ）**という正規の開発ツールを悪用しました。これはOutlookのメールデータファイルを読み書きできるツールです。

```
やったこと：
1. まず2025年8月以降のメールをまとめてPSTファイルに変換
2. 以降は2〜4週間ごとに「前回の続き」だけを取り出す
3. 合計9回にわたって少しずつ盗み出す
```

**例え話で言うと**：図書館の本を一冊丸ごと持ち出すのではなく、毎週少しずつページをコピーして持ち帰るようなイメージです。量が少ないとセキュリティ検知システムに引っかかりにくいのです。

### ③ 「普通の通信」に紛れ込む

盗んだデータを外に送り出す（**データ持ち出し**）際の手口も巧妙でした：

- **DropboxとOneDriveを使う**：これらは普通の業務でも使う有名サービスなので、通信が怪しく見えない
- **DNSを使わない**：本来「onedrive.live.com」というアドレスに接続するところを、**MicrosoftのIPアドレスを直接指定**することで、会社のセキュリティ機器がドメイン名を監視しても検知されにくくした

> 💡 **DNS（ドメインネームシステム）とは**：「onedrive.live.com」のような人間が読めるアドレスを、コンピュータが理解できる数字のIPアドレスに変換する仕組みです。セキュリティ機器はこの変換の記録を監視して怪しい通信を見つけることがありますが、今回はその監視を巧みに回避しました。

### ④ 他にも使われたツール

セキュリティ企業が確認した不正ツールは他にもありました：

- **FRPC**：トンネルを掘って通信を隠すツール
- **Secretsdump**：Windowsのパスワードを抜き出すツール
- **SharpDecryptPwd**：アプリに保存されたパスワードを復元するツール
- **UACバイパスツール**：Windowsのセキュリティ確認を無効化するツール

## なぜ重要なのか

### 💰 狙われた情報の価値が極めて高い

証券取引所の幹部のメールには、こんな情報が含まれている可能性があります：

- **非公開の上場情報**（どの会社が上場するか、まだ誰も知らない情報）
- **市場を動かすような計画**（大きな取引や規制変更など）
- **取引条件や法的な問題**
- **幹部のスケジュールや人脈**

これらは株式市場で**インサイダー取引（内部情報を使った不正取引）**に悪用できる超機密情報です。

### 🕵️ これはスパイ活動（諜報活動）

Symantecは「これはお金目的の犯罪ではなく、**情報収集目的のスパイ活動**」と断言しています。特定の国家や組織が、競争上・外交上の優位を得るために行った可能性が高いです。

### 🔓 「パッチ（修正プログラム）」で直せない

一般的なサイバー攻撃の多くは、ソフトウェアの「穴（脆弱性）」を利用するため、パッチを当てることで防げます。しかし今回は：

> **「CVE（既知の脆弱性番号）はありません」**

つまり、Windowsのバグを突いたのではなく、**正規のツールと権限を悪用**したため、ソフトウェアを更新するだけでは防げないのです。これが「特に怖い」理由の一つです。

## 対策・今後の展望

### 🛡️ こういう組織は今すぐやるべきこと

記事では以下のような監視・対策が推奨されています：

#### 1. 異常なメール操作を監視する
- Outlookのメールデータが大量にエクスポート（書き出し）されていないか確認
- 通常とは異なるOutlookへのアクセスがないか監視

#### 2. クラウドストレージへの不審なアップロードを監視
- **個人用**のDropboxやOneDriveへの業務PCからのアップロードを警戒
- 大量のデータ送信がないか確認

#### 3. スケジュールタスクを定期確認
- AdobeやLenovo、OneDriveを「名乗っている」怪しいタスクがないか確認

#### 4. 権限管理の徹底
- 管理者権限（SYSTEM権限）で動いている不審なプロセスがないか監視
- 「最小権限の原則」を徹底する（必要な権限だけを与える）

#### 5. Symantecが公開した「侵害の痕跡（IOC）」をチェック
- 今回の攻撃で使われたファイルのハッシュ値（指紋）が公開されているので、社内のシステムに同じものがないか照合する

### 📌 一般的な教訓

このような高度な攻撃に対しては：

- **「入られなければいい」だけでなく「入られた後の検知」も重要**
- 普通のクラウドサービスの通信にも目を光らせる
- 定期的なセキュリティ監査（チェック）が必要

## 過去記事との関連

今回は特定の過去記事との対応はありませんが、この事件は「**Living off the Land（環境寄生型攻撃）**」と呼ばれる手法の典型例です。これは「ターゲットのシステムにもともとあるツールや正規サービスを悪用する」攻撃で、近年のサイバースパイ活動でよく見られるトレンドです。国家レベルの攻撃者が使うことが多く、過去にも中国系・ロシア系・北朝鮮系などの国家支援グループが似た手口を使ったとされています。

## 用語解説

| 用語 | 意味 |
|------|------|
| **証券取引所（Stock Exchange）** | 株式などを売買する市場。東証やNYSEが有名 |
| **Outlook** | Microsoftのメール・スケジュール管理ソフト |
| **OST/PSTファイル** | Outlookのメールデータが保存されるファイル形式 |
| **SYSTEM権限** | Windowsで最も強い管理者権限。何でもできる |
| **クラウドストレージ** | インターネット上のファイル保存サービス（Dropbox、OneDriveなど） |
| **データ持ち出し（Exfiltration）** | 盗んだデータを外部に送り出すこと |
| **DNS（ドメインネームシステム）** | アドレス名をIPアドレスに変換する仕組み |
| **Aspose** | Officeファイルを操作できる正規の開発ツール |
| **CVE** | 公開されているソフトウェアの脆弱性（バグ）に付けられる番号 |
| **IOC（侵害の痕跡）** | 攻撃が行われた証拠となるファイルのハッシュ値やIPアドレスなど |
| **スケジュールタスク** | Windowsで決まった時間に自動実行されるプログラムの設定 |
| **UACバイパス** | Windowsの「本当に実行しますか？」という確認を無効化する手法 |
| **インサイダー取引** | 非公開の内部情報を使って株を売買する不正行為 |
| **Living off the Land** | 正規ツールや正規サービスを悪用する攻撃手法 |
| **ラテラルムーブメント（横展開）** | 侵入した後、社内の別の端末や権限に移動していくこと |

---

> 🔑 **今回の最大の教訓**：「有名なクラウドサービスを使っているから安全」「既知の脆弱性がないから大丈夫」という思い込みは危険です。攻撃者は私たちが「普通だ」と思っている行動の中に隠れています。日々の「異常な普通」に気づく監視体制こそが最大の防衛線です。
