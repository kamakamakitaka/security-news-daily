# SOCの10%しかAIに満足していない？　次世代AIセキュリティに求められるもの

**元記事**: [Only 10% of SOCs Say They're Getting Excellent Value From AI. Here's What the Second Wave Has to Deliver](https://inl03.netline.com/ltr6/?_m=3n.009a.3996.sp0ao46r89.31r6)
**解説日**: 2025年7月13日

---

## 背景知識

このニュースを理解するために、まずいくつかのキーワードを押さえておきましょう。

### 🏢 SOC（ソック）とは？
**SOC（Security Operations Center）** とは、企業や組織のサイバーセキュリティを24時間365日監視・対応する「セキュリティの司令塔」のことです。学校で例えるなら、「生徒指導室」のようなもの。不審な動きがないか常に目を光らせて、問題が起きたらすぐ対応します。

### 🤖 AIをセキュリティに使うとは？
最近は、AIが「不審な通信を自動で検知する」「アラート（警告）を自動で分類する」「レポートを自動で書く」など、これまでセキュリティ担当者が手作業でやっていた仕事を手伝うようになっています。

### 🧩 関係するツールたち
| ツール名 | 役割 | 身近な例え |
|---------|------|-----------|
| **SIEM**（シーム） | ログをまとめて異常を検知 | 学校の監視カメラシステム |
| **EDR**（イーディーアール） | パソコンの端末を個別に監視・保護 | 各教室の防犯センサー |
| **SOAR**（ソアー） | インシデント対応を自動化 | 問題発生時の自動連絡フロー |
| **LLM** | ChatGPTのような大規模言語AI | AIアシスタント |
| **AIエージェント** | 自律的にタスクをこなすAI | 自動で動く使い走りロボット |

## 何が起きたのか

### AIブームなのに、成果が出ていない！

セキュリティの世界では今、**AIの導入が爆発的に進んでいます**。

- 📈 AIコパイロット（副操縦士的なAI補助ツール）の導入：**145%増**
- 📈 AIエージェント（自律型AI）の導入：**118%増**
- 📈 機械学習ツールの導入：**96%増**

…とまあ、どの指標を見ても「導入はすごく進んでいる」ことがわかります。

ところが、2026年版の**SOC成熟度レポート**（約200のSOCを調査）では、衝撃的なデータが出ました👇

```
「AIから優れた価値を得ている」と答えたSOC：約10%
「良い価値を得ている」と答えたSOC：約19%
「ある程度、またはほとんど価値なし」と答えたSOC：約71%
```

> 💬 つまり、**約7割のSOCは「AIを入れたけど、大して役に立っていない」**と感じているのです。

## 技術的な詳細

### なぜAIはうまく機能しないのか？

#### 問題①：「ただ買っただけ」のSOCが多すぎる

調査によると、SOCのAI活用スタイルは3種類に分かれます：

| タイプ | 説明 | 割合 | 価値を感じているか？ |
|--------|------|------|-------------------:|
| 🛒 **テイカー（Taker）** | 既製品のAIをそのまま使う | 65% | ❌ 最も低い |
| 🔧 **シェイパー（Shaper）** | 買ったAIをカスタマイズして使う | 20% | △ 中程度 |
| 🏗️ **ビルダー（Builder）** | 自前のデータでAIを育てる | 15% | ✅ 高い |

全体の**65%が「とりあえず既製品を入れた」タイカーモデル**で、これが最もAIの恩恵を受けられていないグループです。

> 例えるなら、「料理が上手くなりたい」のに、**レシピ本を買っただけで料理の練習はしていない**状態です。

#### 問題②：AIがバラバラに動いていて、連携できていない

現在のAIツールは、それぞれの製品に「おまけ機能」として追加された形になっています：

```
SIEM　　 → AIトリアージ機能が追加された
EDR　　  → AI調査機能が追加された
SOAR　　 → AI自動対応機能が追加された
チケット管理 → AI要約機能が追加された
```

これらは**それぞれ単体では動く**のですが、**お互いに情報を共有できていません**。

> 🎯 わかりやすい例えで言うと…
> 
> 学校のセキュリティ対策で：
> - 正門の警備員はAIカメラで不審者を検知している
> - 各教室の先生はAIシステムで出席管理している
> - 保健室はAIで体調不良者を管理している
> 
> でも、**3つのシステムはお互いに全く情報共有していない**ので、「不審者が正門を通り抜けてどの教室に向かったか」がわからない、という状態です。

#### 問題③：「何をすべきかわからない」という現場の混乱

SOCの課題として今年**増加した**のは：
- ✅ ベストプラクティス（正しいやり方）がわからない：**+17%増**
- ✅ 成熟度を上げる方法が複雑でわからない：**+11%増**

逆に、**予算不足・経営陣の理解不足は減少**しています。

つまり「お金も許可もある、でも**何をどうすればいいかわからない**」という状態に多くのSOCが陥っているのです。

## なぜ重要なのか

### セキュリティの最前線が機能不全になるリスク

SOCはサイバー攻撃から組織を守る最後の砦です。もしSOCのAI導入が失敗続きになると：

1. **🔴 セキュリティの穴が広がる**
   AIがちゃんと機能しないせいで、人間の担当者が見落としていた攻撃が見逃される可能性が上がります

2. **🔴 莫大な投資が無駄になる**
   企業は数億〜数十億円規模のお金をAIセキュリティに注ぎ込んでいますが、7割が「価値を感じない」なら投資対効果が見合いません

3. **🔴 現場担当者の疲弊**
   5つの別々のAIツールを操作しながら、それでも手作業の作業量は減らない…という状況は、セキュリティ担当者のバーンアウト（燃え尽き症候群）を招きます

4. **🔴 業界全体の信頼低下**
   「AIでセキュリティが強くなる」という期待が裏切られ続けると、本当に必要な技術投資まで止まってしまうリスクがあります

## 対策・今後の展望

### 次の波（第2世代AI）に求められること

記事は「第1世代のAIは失敗した、次の世代が解決すべき課題」を示唆しています。具体的には：

#### ✅ 必要なこと①：AIツール同士の「連携」
バラバラに動く5つのAIではなく、**全体を俯瞰して情報を共有する統合型AI**が必要です。

> 例：SIEMが「この通信が怪しい」と検知したら、EDRが「あのパソコンで先週も似た動きがあった」という情報を自動で連携してくれる仕組み

#### ✅ 必要なこと②：カスタマイズの民主化
今は「自分たちのデータでAIを育てられる（ビルダー）」のは全体の15%だけ。もっと多くのSOCが自分たちの環境に合わせてAIを調整できる環境が必要です。

#### ✅ 必要なこと③：「何をすべきか」のガイドライン整備
技術だけあっても使いこなし方がわからなければ意味がありません。業界全体で「AIをSOCでこう使うべき」というベストプラクティス（正しいやり方の指針）を整備することが急務です。

#### ✅ SOCが今すぐできること
| アクション | 内容 |
|-----------|------|
| **現状評価から始める** | 「とりあえず導入」でなく、何を解決したいか明確にする |
| **小さく始めて成功体験を積む** | 一つのユースケースでしっかり価値を出してから広げる |
| **ツール間連携を優先する** | 新しいAIを買う前に、既存ツールの連携を改善する |
| **成熟度を測る指標を作る** | SOC-CMMのような成熟度モデルを活用して自己評価する |

## 用語解説

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **SOC** | ソック | Security Operations Center。企業のセキュリティ監視・対応の司令塔 |
| **SIEM** | シーム | Security Information and Event Management。ログを一元管理して異常を検知するシステム |
| **EDR** | イーディーアール | Endpoint Detection and Response。PC等の端末を監視・保護するツール |
| **SOAR** | ソアー | Security Orchestration, Automation and Response。セキュリティ対応を自動化する仕組み |
| **LLM** | エルエルエム | Large Language Model（大規模言語モデル）。ChatGPTのような文章を扱うAI |
| **AIエージェント** | — | 人間が指示しなくても自律的にタスクをこなすAI |
| **AIコパイロット** | — | 人間の作業を横で補助するAIアシスタント |
| **トリアージ** | — | 緊急度・優先度を判断して振り分ける作業（医療用語から来ている） |
| **SOC-CMM** | — | SOCの成熟度を測るフレームワーク（Capability Maturity Model） |
| **MSSP** | エムエスエスピー | Managed Security Service Provider。セキュリティ業務を代行する外部企業 |
| **テイカー/シェイパー/ビルダー** | — | AIの活用姿勢の3分類。受け身順に：そのまま使う／改造する／自作する |
| **ベストプラクティス** | — | 最も効果的とされる手法・やり方のこと |
| **バーンアウト** | — | 過労や精神的疲弊による「燃え尽き症候群」 |
