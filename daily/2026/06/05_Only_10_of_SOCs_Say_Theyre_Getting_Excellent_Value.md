## 背景知識

まず、この記事を読むために必要な言葉を整理しましょう。

### 🏢 SOC（ソック）って何？
**SOC = Security Operations Center（セキュリティ運用センター）**

会社や組織のネットワークやシステムを**24時間365日監視する専門チーム・部門**のことです。

学校に例えると、**「生徒指導室と保健室と警備室を合わせたような部署」**です。不審者（サイバー攻撃）が来ていないか常に見張り、何か問題が起きたらすぐ対応します。

### 🤖 AIがSOCで使われるとどういうこと？
大量のセキュリティログ（システムの記録）を人間が全部チェックするのは大変なので、AIに「怪しいものを見つける」「調査を手伝う」などの作業を任せるようになっています。

### 📋 主な登場ツール（後で用語解説でも詳しく説明します）
| ツール名 | 役割 |
|---------|------|
| SIEM（シーム） | ログを集めて分析するシステム |
| EDR（イーディーアール） | パソコンやサーバーへの攻撃を検知するツール |
| SOAR（ソアー） | セキュリティ対応を自動化するプラットフォーム |
| AIエージェント | 自律的に動くAIの仕組み |
| LLM | ChatGPTのような大規模言語モデル |

## 何が起きたのか

### 📊 調査結果のショッキングな数字

2026年のSOC成熟度レポート（**SOC-CMM 2026 Maturity Report**）が、世界約200のSOCを対象にした調査結果を発表しました。

その結果がこちらです：

```
AIが「優秀な成果を出している」と答えたSOC ......約10%
AIが「良い成果を出している」と答えたSOC .........約19%
AIが「ある程度・まったく成果なし」と答えたSOC ...約71%
```

> 💡 つまり、**10人中7人以上が「AIを入れたけど、あまり意味がなかった」と感じている**ということです。

### 🤔 でも、AIの導入自体はすごく増えているんです

皮肉なことに、AIツールの**導入数は爆発的に増えています**：

- AIコパイロット（AI補助ツール）：**+145%**増加
- AIエージェント：**+118%**増加
- 機械学習ツール：**+96%**増加

お金もどんどん使われています。なのに、**「実際に役立っている」と感じる人は少ない**——これが今回の記事の核心です。

## 技術的な詳細

### 🧩 なぜAIがうまく機能していないのか？

#### 問題①：「買ってきてそのまま使う」パターンが多すぎる

調査によると、SOCのAI活用スタイルは3つに分類できます：

| タイプ | 説明 | 割合 |
|--------|------|------|
| 🛒 **テイカー（taker）** | 既製品のAIをそのまま使う | **65%** |
| 🔧 **シェイパー（shaper）** | 購入したAIをカスタマイズして使う | 20% |
| 🏗️ **ビルダー（builder）** | 自社データでAIをゼロから育てる | 15% |

問題は、**最多のテイカー層が最も「価値を感じていない」グループ**でもあること。

> 🎮 ゲームに例えると：ゲームを買ってきて、攻略法も読まずにそのまま遊んでいる状態。ゲーム自体は良くても、使いこなせていないから楽しめない——そんな状況です。

#### 問題②：AIツールが「バラバラ」に動いている

現在のSOCには、**複数のAIツールが独立して動いている**という問題があります。

```
[SIEMのAI]  →  アラートのふるい分けをする
      ↓ ← ここで情報が止まる！
[EDRのAI]   →  パソコンへの攻撃を調べる
      ↓ ← ここでも情報が止まる！
[SOARのAI]  →  対応手順を自動生成する
      ↓ ← ここでも止まる！
[チケットのAI] → 報告書をまとめる
```

それぞれのAIは**自分の担当範囲しか知らない**のです。

> 🏥 病院に例えると：受付、診察、検査、薬局がそれぞれ別の「AIアシスタント」を使っているけど、**それぞれが患者の情報を共有していない**状態。受付のAIは診察の内容を知らないし、薬局のAIは検査結果を知らない。これでは医療ミスが起きてしまいます。

セキュリティ担当者が直面している現実はこうです：

> 「タスク1つ1つは速くなった。でも全体のワークフロー（流れ）はバラバラなまま。おまけに5つのAIツールの使い方を覚えなきゃいけなくなった」

#### 問題③：「何をすべきかわからない」問題

今回の調査で、**増加した課題TOP2**は：

1. 📚 **ベストプラクティス（最善の方法）の欠如** → +17%増加
2. 🌀 **成熟度を上げることの複雑さ** → +11%増加

逆に「予算が足りない」「上司の理解がない」という問題は**減っています**。

これが意味することは：
> **「お金も許可もある。でも何をどうすればいいのかわからない」** という状態のSOCが急増しているということ。

## なぜ重要なのか

### 💸 莫大な投資が無駄になりかねない

AIセキュリティ市場には**数十億ドル（数千億円）規模の投資**が流れ込んでいます。しかし10社中7社以上が「大した効果がない」と感じているなら、これは**業界全体の大きな問題**です。

### 🔓 セキュリティの穴が埋まっていない

SOCの仕事は「サイバー攻撃を見つけて止める」ことです。AIがうまく機能していないということは、**本来防げるはずの攻撃が見逃されている可能性**があります。

### 👩‍💼 現場の人間への負担

AIを入れたのに楽にならず、むしろ「新しいツールの使い方を覚える」という仕事が増えてしまっています。これは**セキュリティ担当者の燃え尽き症候群（バーンアウト）**を悪化させる可能性があります。

## 対策・今後の展望

### 🌊 「AI第2波」に求められること

記事では、次世代のAI（第2波）が解決すべき課題として以下が示唆されています：

#### ✅ 1. AIツール同士が「つながる」設計に
バラバラに動くAIではなく、**SOC全体で情報を共有するAI**が必要。

> 🧠 「5人の専門家がバラバラに働く」のではなく、「1人の優秀なオールラウンダーが全体を見渡す」イメージ

#### ✅ 2. 「買って終わり」ではなく「育てる」文化
テイカー（そのまま使う）からシェイパー・ビルダー（カスタマイズ・自社開発）へ移行することで、**自分たちの環境に合ったAI**になっていく。

#### ✅ 3. 「何をすべきか」のガイドラインの整備
AIの導入方法だけでなく、**「どう使いこなすか」のベストプラクティス**を業界全体で共有していくことが急務。

#### ✅ 4. ワークフロー全体の設計から見直す
個別機能にAIを追加するのではなく、**最初から「AIありき」のSOC運用フロー**を設計し直す必要がある。

## 用語解説

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **SOC** | ソック | Security Operations Center。会社のセキュリティを監視・対応する専門チーム |
| **SIEM** | シーム | Security Information and Event Management。ログを一元管理・分析するシステム |
| **EDR** | イーディーアール | Endpoint Detection and Response。PCやサーバーへの攻撃を検知・対応するツール |
| **SOAR** | ソアー | Security Orchestration, Automation and Response。セキュリティ対応を自動化するプラットフォーム |
| **LLM** | エルエルエム | Large Language Model（大規模言語モデル）。ChatGPTのような文章を理解・生成するAI |
| **AIエージェント** | — | 人間の指示なしに自律的に作業をこなすAIの仕組み |
| **AIコパイロット** | — | 人間の作業を横から補助するAIツール（コパイロット＝副操縦士） |
| **ベストプラクティス** | — | 最も効果的とされる手法・やり方 |
| **テイカー/シェイパー/ビルダー** | — | AIの活用スタイルの分類。それぞれ「そのまま使う人」「カスタマイズする人」「自分で作る人」 |
| **SOC-CMM** | ソック・シーエムエム | SOC成熟度モデル。SOCの能力レベルを測るための評価フレームワーク |
| **MSSP** | エムエスエスピー | Managed Security Service Provider。セキュリティ運用を外部に委託する専門業者 |
| **ワークフロー** | — | 業務の流れ・手順のこと |
