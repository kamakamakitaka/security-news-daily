# PCPJackが230台のクラウドサーバーを乗っ取り、秘密のメール中継ネットワークを構築

**元記事**: [PCPJack Hijacks 230 AWS, Google Cloud, and Azure Servers for Covert SMTP Relay Network](https://inl03.netline.com/ltr6/?_m=3n.009a.3996.sp0ao46r89.31ru)
**解説日**: 2026年6月6日

---

## 背景知識

まず、今回の記事を理解するために必要なキーワードをざっくり説明します。

### ☁️ クラウドサーバーって何？
AWS（Amazon）、Google Cloud、Microsoft Azureは、インターネット上に「仮想的なコンピューター」を貸し出すサービスです。世界中の企業がこれを使って自社のWebサービスやシステムを動かしています。いわば「インターネット上に置いたレンタルパソコン」です。

### 📧 SMTPとは？
**SMTP（Simple Mail Transfer Protocol）**は、メールを送るための「ルール・仕組み」です。あなたがメールを送るとき、裏側ではSMTPという仕組みが動いています。

### 📬 SMTPリレーって何？
メールを送るとき、必ずしも直接相手に届くわけではなく、**中継サーバー（リレー）** を経由することがあります。これを「SMTPリレー」と言います。信頼できる企業のサーバーからメールが来ると、スパムフィルターに引っかかりにくくなるという特性があります。

### 🎭 C2サーバーとは？
**C2（Command and Control）サーバー**は、攻撃者が乗っ取ったコンピューターを「遠隔操作する司令塔」のことです。ゲームで例えると、攻撃者が「本部」からゾンビ化した端末に命令を送るイメージです。

## 何が起きたのか

**「PCPJack」という攻撃グループ**が、世界中の企業が使っているクラウドサーバー（AWSやGoogle Cloud、Azure）を**こっそり乗っ取り**、それらを**スパムメールや詐欺メールを大量に送るための中継基地**に変えていたことがわかりました。

- 🌍 被害を受けたサーバーは**アメリカ・ヨーロッパ・アジア**の企業のもの
- 📦 乗っ取られたサーバーの数は**230台**以上
- 🔎 発見したのはセキュリティ会社「Hunt.io」

しかも驚くことに、攻撃者が使っていたC2サーバー上のフォルダが**パスワードなしで公開状態**になっていたため、Hunt.ioがその中身（ソースコード・ツール・設定ファイルなど）をそのまま確認できてしまいました。攻撃者の「うっかりミス」が発覚のきっかけになったわけです。

## 技術的な詳細

少し難しいですが、できるだけわかりやすく説明します！

### ① どうやってサーバーを乗っ取ったのか

PCPJackは、クラウドサービスの**ログイン情報（パスワードなど）を盗む専用ツール**を使って企業のサーバーに侵入しました（2026年4月にSentinelOneというセキュリティ会社が最初に発見）。

### ② 乗っ取ったサーバーに何を仕込んだのか

侵入後、サーバーに**「ビーコン」という小さなプログラム**を仕込みます。

> 💡 **ビーコンとは？** 「定期的に攻撃者の本部（C2サーバー）に連絡を取るスパイプログラム」です。まるで「生存確認のメッセージを10分おきに送り続けるアプリ」のようなもの。

ビーコンは以下の特徴があります：
- 隠しファイルとしてサーバーに置かれる（ファイル名の先頭にドットをつけて見えにくくする）
- 定期的に攻撃者の本部に「自分は生きてますよ」と報告
- メールを外部に送れるか（smtp.gmail.com経由）を自動テスト

### ③ メールが送れるか自動でチェック！

攻撃者は「メールを外に送れないサーバーは使えない」と判断し、自動的に**メールリレーができるかどうかをチェック**します。送れないサーバーは自動でリストから除外されます。

まるで工場の「品質検査ライン」のようです。使えるものだけを選んで中継基地として活用するわけです。

### ④ 5分ごとに情報を同期

使えると判定されたサーバーのリストは、**5分おきに別のサーバーに自動送信**されます。そのサーバーを誰かが「消費している」（＝悪用している）ことがわかっていますが、最終的な目的は現時点では不明です。

## なぜ重要なのか

### 🚨 企業サーバーが「知らない間に」犯罪に使われている

被害を受けた企業は、自社のサーバーが勝手にスパムや詐欺メールの「踏み台」にされていることに気づいていません。これは非常に深刻です。

### 📩 スパムフィルターをすり抜けやすい

通常、怪しいメールアドレスやサーバーからのメールはスパムとして弾かれます。しかし、**信頼性の高い企業のクラウドサーバーを経由したメール**は、スパムフィルターをすり抜けやすいのです。つまり、フィッシング詐欺メールなどが受信トレイに届きやすくなってしまいます。

### 🌐 規模が大きく、今も稼働中（発見時点）

発見されたときも、このシステムはまだ動いていました。230台という規模は、単なる個人の悪戯では考えられない、**組織的なサイバー攻撃**です。

## 対策・今後の展望

### 企業・エンジニア向けの対策

| 対策 | 内容 |
|------|------|
| 🔑 クラウドの認証情報を強化 | 多要素認証（MFA）を必ず設定する |
| 🔍 サーバーの通信を監視 | 不審な外部通信がないかログを確認する |
| 🚫 不要なSMTPポートを閉じる | 必要のないメール送信ポートは開けない |
| 📂 ファイルの配置を確認 | `/var/tmp/` などに見知らぬファイルがないか確認 |
| 🔄 認証情報を定期的に変更 | パスワードや APIキーを定期的にローテーションする |

### 一般ユーザー向けの対策

- 🧐 受信したメールの「差出人」が本物かよく確認する
- 🔗 メール内のリンクを安易にクリックしない
- 📢 不審なメールが来たら、企業の公式サイトから直接問い合わせる

### 今後の動向

攻撃グループPCPJackは、別のグループ「TeamPCP」のツールを意図的に消す行動もとっており、**ハッカーグループ同士の縄張り争い**のような動きも見られます。今後もクラウドサービスを狙った攻撃は増加すると考えられます。

## 過去記事との関連

以前「**FIFAワールドカップ2026の詐欺サイトや銀行マルウェア**」について解説しましたが、今回のニュースはその「配送インフラ」に関わっている可能性があります。

詐欺メールを大量に送るためには、**スパムフィルターをすり抜けられる信頼性の高い送信サーバー**が必要です。PCPJackが構築したこの「秘密のメール中継ネットワーク」は、まさにそのような大規模詐欺メールキャンペーンを支える「裏インフラ」として使われている可能性が高いです。

ワールドカップ詐欺やWordPressサイト乗っ取りなど、個々の攻撃の「裏側」では、このような見えにくいインフラが支えているということを意識しておくと、セキュリティの全体像が見えてきます。

## 用語解説

| 用語 | 解説 |
|------|------|
| **SMTP** | メールを送るための通信規則 |
| **SMTPリレー** | メールを中継（経由）して送る仕組み |
| **C2サーバー** | 攻撃者が乗っ取ったPCを遠隔操作する「司令塔」サーバー |
| **ビーコン** | 感染したPCがC2サーバーに定期的に「報告」するスパイプログラム |
| **Sliver** | オープンソースのC2フレームワーク（本来はセキュリティ研究用）|
| **Chisel** | ネットワークのトンネルを作るツール（通信を隠すのに悪用される）|
| **SOCKS5プロキシ** | 通信を別のサーバー経由に見せかける「迂回路」 |
| **SCP** | ファイルを安全に転送するプロトコル |
| **MD5ハッシュ** | データを一定の長さの文字列に変換する計算方法 |
| **AWS/Google Cloud/Azure** | 世界3大クラウドサービス（Amazon・Google・Microsoft） |
| **フィッシング詐欺** | 偽メールや偽サイトで個人情報を騙し取る攻撃 |
| **多要素認証（MFA）** | パスワード以外にもSMSや認証アプリなど複数で本人確認する仕組み |

> 💬 **まとめると…**
> 悪意のある攻撃グループが、世界中の企業の「レンタルクラウドPC」を勝手に乗っ取り、スパムや詐欺メールを送るための「隠れた郵便局ネットワーク」を作っていた、という事件です。被害企業は気づかないうちに犯罪の片棒を担がされており、私たちの受信トレイに届く詐欺メールの「裏インフラ」になっている可能性があります。クラウドを使う企業はセキュリティ設定の見直しを、一般ユーザーは怪しいメールへの警戒を続けることが大切です。
