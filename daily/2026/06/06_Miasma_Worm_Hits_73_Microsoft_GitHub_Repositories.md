# マイクロソフトのGitHubリポジトリ73件が「Miasmaワーム」に感染！巨大なソフトウェア供給網攻撃

**元記事**: [Miasma Worm Hits 73 Microsoft GitHub Repositories in Major Supply Chain Attack](https://inl03.netline.com/ltr6/?_m=3n.009a.3997.sp0ao46r89.31t8)
**解説日**: 2025年6月

---

## 背景知識

まず、このニュースを理解するために必要な言葉と仕組みを説明します。

### 🔧 GitHubとは？
GitHubは、プログラマーが作ったソフトウェアのコード（設計図）を保存・共有する場所です。世界中の開発者が利用しており、マイクロソフトやGoogle、Appleといった大企業も自社のソフトウェアのコードをここで公開しています。
**「コードの図書館」** のようなイメージです。

### 🔧 リポジトリとは？
GitHubの中にある「プロジェクトごとの本棚」のことです。1つのソフトウェアが1つのリポジトリに保存されています。

### 🔧 ソフトウェアサプライチェーン攻撃とは？
普通の攻撃はソフトウェアを使う人を直接狙いますが、サプライチェーン攻撃は **「ソフトウェアが作られる過程」** を狙います。

🏭 工場のたとえで考えると…
> 食品工場の材料（小麦粉など）に毒を混ぜると、その材料を使った全ての食品が汚染される。

サプライチェーン攻撃も同じで、**開発者が使う部品（ライブラリ）に悪意あるコードを混ぜる**ことで、そのライブラリを使って作られたソフトを使う人全員に被害が広がります。

### 🔧 ワーム（Worm）とは？
コンピュータウイルスの一種で、特に**自分でコピーして次々と他の場所に感染・拡散する**性質を持ちます。生物の虫が這い回って広がるイメージです。

### 🔧 npmとPyPIとは？
- **npm**：JavaScriptというプログラミング言語の「部品ショップ」。開発者が便利な部品をダウンロードして使います。
- **PyPI**：Pythonというプログラミング言語の「部品ショップ」。
  
これらは、料理でいえば **「スーパーマーケット」** のようなもの。毒入り食材がここに並んでしまうと、多くの料理（ソフトウェア）に影響が出ます。

## 何が起きたのか

### 📢 事件の概要

**「Miasma（ミアズマ）」** という名前の自己増殖型ワームが、マイクロソフトのGitHub上のリポジトリ **73件** に感染しました。

感染したリポジトリが含まれる組織は以下の4つです：
- **Azure**（クラウドサービス）
- **Azure-Samples**（サンプルコード集）
- **Microsoft**（マイクロソフト本体）
- **MicrosoftDocs**（公式ドキュメント）

感染が確認されたリポジトリの例：
- `azure-search-openai-demo`
- `durabletask`（耐久タスク管理ツール）
- `llm-fine-tuning`（AIモデルの調整ツール）
- `windows-driver-docs`（Windows ドライバー文書）

GitHubはこれらのリポジトリへのアクセスを **即座に無効化** しました。アクセスしようとすると「GitHubの利用規約違反によりアクセスが無効化されました」というメッセージが表示されます。

### 📅 事件の流れ

```
1ヶ月前（2026年5月）
  ↓
TeamPCPというグループが「Mini Shai-Hulud（シャイフルード）」ワームを公開
  ↓
Miasmaはその進化版として登場
  ↓
Miasmaが突然変異・進化しながら感染を拡大
  ↓
今回、Microsoftの73リポジトリに感染
```

特に注目すべきは「durabletask」というリポジトリで、**先月もすでに感染被害を受けていた場所**です。同じ場所がまた狙われたことは偶然ではなく、攻撃者が**認証情報（パスワードや鍵）を握り続けていた**可能性が高いと専門家は指摘しています。

## 技術的な詳細

### 🦠 Miasmaの感染のしくみ

このワームは非常に巧妙な方法で拡散します。

#### ① 開発者のアカウントや「鍵」を盗む
攻撃者はまず、正規の開発者のログイン情報（認証キー）を盗みます。これにより、**本物の開発者のふりをしてコードを公開できる**ようになります。

#### ② 悪意あるコードを「正規のもの」として公開
盗んだ鍵を使って、ウイルス入りのコードを正規パッケージとして公開します。

> 🔑 たとえるなら、誰かの家の鍵をコピーして、その家の住所から荷物（毒入り）を送りつけるイメージです。

#### ③ AI開発ツールを悪用して自動実行
非常に悪質な点として、今回は**AIコーディングアシスタント**を狙っています。

感染したリポジトリをパソコンにコピー（クローン）して、以下のツールで開くと**自動的に悪意あるプログラムが起動**します：

| ツール名 | 説明 |
|---------|------|
| **Claude Code** | AnthropicのAIコーディング支援ツール |
| **Gemini CLI** | GoogleのAIコーディング支援ツール |
| **Cursor** | AI機能付きのコードエディタ |
| **VS Code** | マイクロソフトの人気コードエディタ |
| **npm test** | プログラムのテスト実行コマンド |

悪意あるファイルのサイズは **4.3MB** で、上記のツールで開いた瞬間に自動起動するよう仕掛けられていました。

#### ④ 自己増殖
感染した開発者の環境から、さらに別のリポジトリやパッケージに広がっていきます。まるで虫が這い回るように。

### 🎭 このワームの「天才的に狡猾な点」

セキュリティ企業FalconFeeds.ioは次のように述べています：

> 「このワームの巧妙さと、従来のセキュリティ対策がほぼ失敗した理由は、**完全に合法的なチャンネルの中だけで動く**からだ。GitHubやnpmの脆弱性を悪用しているわけではない。**正規のパッケージが正規の鍵で署名され、認証済みの管理者によって公開されれば安全だという"信頼モデル"**を悪用している」

つまり、セキュリティシステムが「この人は信頼できる人だ」と認識してしまうため、**警告が鳴らない**のです。

## なぜ重要なのか

### 💥 影響の大きさ

| 項目 | 内容 |
|------|------|
| 感染リポジトリ数 | **73件（マイクロソフトのみ）** |
| 「Hades」ブランドのリポジトリ | **13件** |
| 「Miasma」ブランドのリポジトリ | **82件** |
| 対象ユーザー | 世界中の開発者 |

### 🌊 被害が広がる仕組み（ドミノ倒し効果）

```
[攻撃者]
    ↓ 鍵を盗む
[正規の開発者のアカウント]
    ↓ 悪意あるコードを公開
[部品ショップ（npm/PyPI/GitHub）]
    ↓ 普通に部品をダウンロード
[世界中の開発者]
    ↓ 感染した開発者がさらに拡散
[さらに多くの人]
```

この**指数関数的な広がり方**（1→2→4→8→16…のように倍々に増える）が、このワームの最も危険な特性です。

### 😰 特に心配なこと
- Microsoftのような**超大手企業のコードも安全ではない**ことが証明された
- AIコーディングツールという**最新の開発環境が武器として使われた**
- 「信頼できる公式アカウント」を騙るため**気づきにくい**
- 一度手に入れた認証情報が**長期間使われ続ける**可能性がある

## 対策・今後の展望

### 🛡️ 開発者ができる対策

#### 1. 使うパッケージを慎重に確認する
- パッケージの更新履歴が不自然ではないか確認する
- 急に変な説明文（"Miasma: The Spreading Blight" など）が追加されていないか見る
- セキュリティツール（SafeDep、OpenSourceMalwareなど）を活用する

#### 2. AI開発ツールを使うときは特に注意する
- 知らないリポジトリを**AIツールで開かない**
- 見知らぬコードベースを開く前に**ウイルススキャン**をする

#### 3. 認証情報の管理を徹底する
- 使用する鍵（APIキー・トークン）を定期的に更新する
- 不審なログインがないか定期確認する
- **多要素認証（MFA）**を必ず有効にする

### 🔮 今後の展望

- GitHubやnpm側での**自動検知システムの強化**が期待される
- AI開発ツールを提供する企業（Anthropic、Googleなど）が**セキュリティ対策を追加**する可能性がある
- Miasmaはまだ進化を続けており、**さらなる変種の出現**に警戒が必要
- 「信頼モデル」そのものを見直す**業界全体での議論**が始まる可能性が高い

## 過去記事との関連

今回の攻撃は、**1ヶ月前（2025年5月）に発生した「TeamPCP」によるdurabletaskパッケージへの感染事件**と深く関連しています。

- 前回：TeamPCPが`durabletask`のPyPIパッケージを感染させ、Linuxシステムで情報を盗むマルウェアを配布
- 今回：同じdurabletaskのリポジトリが再び攻撃の中心となり、関連する全リポジトリが巻き込まれた

セキュリティ研究者のポール・マッカーティ氏は「先月の侵害の根っこにあったリポジトリが、今月の大規模削除の中心にある。これは同じ傷が再び開いたものだ」と述べており、**5月に盗まれた認証情報が完全には無効化されていなかった**可能性を指摘しています。

> ⚠️ これは非常に重要な教訓です。**一度セキュリティ侵害が起きたら、関連する全ての認証情報を完全に無効化・更新**しないと、同じ場所から何度も攻撃を受けるリスクがあります。

## 用語解説

| 用語 | 意味 |
|------|------|
| **GitHub** | コードを保存・共有するプラットフォーム。コードの図書館 |
| **リポジトリ** | GitHubにある1プロジェクト分のコード保管場所。本棚の1冊 |
| **ワーム** | 自己増殖して広がるコンピュータウイルスの一種 |
| **サプライチェーン攻撃** | ソフトウェアの「材料（部品）」に毒を混ぜる攻撃 |
| **npm** | JavaScript用の部品ショップ（パッケージレジストリ） |
| **PyPI** | Python用の部品ショップ（パッケージレジストリ） |
| **認証情報（クレデンシャル）** | ログインに使うパスワードや鍵のこと |
| **多要素認証（MFA）** | パスワード以外にもう1つの確認（スマホへの通知など）を使うセキュリティ手法 |
| **Miasma** | 今回の攻撃に使われた自己増殖ワームの名前。「瘴気（しょうき）」という意味 |
| **Shai-Hulud（シャイフルード）** | Miasmaの元となったワームの名前。SF小説「デューン」の巨大砂虫から命名 |
| **クローン** | GitHubのリポジトリを自分のパソコンにコピーすること |
| **ドロッパー** | 悪意あるソフトを「落とし込む（インストールする）」役割を持つプログラム |
| **信頼モデル** | 「正規の鍵で署名されたものは安全」という前提のこと |
| **TeamPCP** | Miasmaの元となったワームを作ったとされるハッカーグループ |

> 💡 **まとめ**：今回の事件は、私たちが「安全だと信じている仕組みそのもの」が攻撃対象になった、非常に深刻なケースです。マイクロソフトほどの大企業でも完全には防ぎきれなかったこの攻撃は、ソフトウェア業界全体が「信頼のあり方」を見直すきっかけになるかもしれません。
