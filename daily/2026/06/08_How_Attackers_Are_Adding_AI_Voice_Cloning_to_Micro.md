# AIによる声のなりすましをMicrosoft Teams攻撃に使う新手口

**元記事**: [How Attackers Are Adding AI Voice Cloning to Microsoft Teams Attacks](https://inl03.netline.com/ltr6/?_m=3n.009a.3998.sp0ao46r89.31us)
**解説日**: 2026年6月8日

---

## 背景知識

まず、このニュースを理解するためのキーワードをいくつか説明します。

**Microsoft Teams（マイクロソフト チームズ）** とは、会社でよく使われるチャット・ビデオ会議ツールです。LINEやDiscordの「会社版」をイメージするとわかりやすいです。

**「外部テナント連携」機能** とは、違う会社のTeamsアカウントからでも、社内の社員にメッセージを送れる機能です。「別の学校の生徒から、自分の学校のチャットに直接メッセージが届く」ようなイメージです。この機能は**最初からONになっています**。

**クイックアシスト（Quick Assist）** とは、Windowsに最初から入っている「遠隔操作」ツールです。「画面共有しながら、相手のパソコンを操作できる」機能で、IT部門が社員のPCトラブルを遠隔で直すときによく使われます。

**AIボイスクローニング（AI音声複製）** とは、誰かの声のサンプル音声をAIに学習させることで、その人の声そっくりの音声を作り出す技術です。30秒〜数分の音声があれば、リアルな偽物の声が作れてしまいます。

---

## 何が起きたのか

攻撃者たちが、**Microsoft Teamsとリアルな「AIによる偽声」を組み合わせた新しい詐欺攻撃手口**を使っています。

流れをざっくり言うと：

1. 攻撃者が**外部Teamsアカウントを作成**し、社員にメッセージを送る
2. 「IT部門の担当者です。緊急のセキュリティ問題が発生しました！」と偽る
3. 社員に「クイックアシスト」を起動させ、**PCの遠隔操作を許可させる**
4. さらに、**AIで作った上司や同僚の声で電話をかけてきて**、要求の正当性を信じ込ませる
5. PC内に侵入し、データを盗んだりマルウェアを仕込んだりする

実際の被害例として、2024年にエンジニアリング企業「Arup（アラップ）」で、社員がAIで作られたビデオ・音声の偽の同僚たちとのビデオ会議後に、**2500万ドル（約38億円）の送金**を承認してしまった事件が紹介されています。

## 技術的な詳細

### 🔴 ステップ1：最初の接触（Teamsメッセージ）

```
攻撃者 → LinkedInや会社サイトで社員の名前・役職を調査
       → 外部Teamsアカウントから「IT担当者」を装ってメッセージ
       → 「MFAの問題が発生！すぐにクイックアシストを開いてください」
```

> **MFA（多要素認証）** とは、パスワードに加えてスマホ認証なども必要にするセキュリティ機能です。「問題が起きた」と言われると焦りやすいポイントです。

### 🔴 ステップ2：AIの声で追い打ち（電話）

クイックアシストを起動させる「一押し」として、今度は**AIで複製した上司や社内IT部長の声で電話がかかってきます**。

声のサンプルは：
- 社員がYouTubeに上げたウェビナー動画
- LinkedInの動画投稿
- 会社の決算説明会の録音
- ポッドキャストへの出演音声

など、**ネット上に公開されている音声から簡単に入手できます**。聞き慣れた上司の声で「早くやって！」と言われると、冷静な判断が難しくなります。

### 🔴 ステップ3：侵入後の動き（クイックアシスト許可後）

| 段階 | 何をするか | 例え |
|------|-----------|------|
| 偵察 | PowerShellでPC環境を調査 | 泥棒が間取りを確認する |
| マルウェア設置 | 信頼済みアプリに悪意あるコードを潜ませる | 正規の宅配便の箱の中に爆弾を隠す |
| 持続化 | 再起動しても残るよう設定を改ざん | 鍵を合鍵に交換する |
| 通信 | 普通のHTTPS通信に偽装してデータ送信 | 普通のメールに見せかけた密書 |
| 横展開 | 社内の他サーバーへ侵入 | 一部屋から全フロアに広がる |
| データ盗難 | 重要ファイルを自動で選別・送信 | 金庫の中だけ狙って盗む |

怖いのは、**すべてWindowsに最初から入っているツールだけを使う**点です。特別なウイルスを使わないので、セキュリティソフトに検知されにくいのです。

## なぜ重要なのか

### 📌 「声」は人間が最も信頼するものの一つ

メールやメッセージへの警戒心は社会的に高まってきましたが、**聞き慣れた声には別の心理的な信頼感があります**。特に「緊急事態」と組み合わせると、考える時間を奪われます。

### 📌 防御が難しい理由

- **技術的には何も「異常」に見えない**：クイックアシストの使用も、Windowsのコマンド実行も、普通のIT作業と区別できない
- **最初の10〜15分が最も危険**：この時間帯はすべてが「合法的なIT作業」に見える
- **デフォルト設定が罠**：外部Teamsメッセージを受け取れる設定がほとんどの企業でONのまま

### 📌 攻撃の「コスパ」が高い

攻撃者にとって、音声のみの偽声通話はビデオ偽造より**はるかに簡単・安く**実行できます。個人を狙った標的型攻撃として使いやすいのです。

## 対策・今後の展望

### ✅ 企業・組織でできること

| 対策 | 内容 |
|------|------|
| **外部Teamsメッセージを制限する** | 知らない外部アカウントからのメッセージをブロックまたは警告表示にする |
| **クイックアシストの使用ポリシーを設ける** | 「IT部門は必ず社内アカウントから連絡する」などルールを明確にする |
| **定期的な訓練** | こういうフィッシング攻撃を疑似体験させる訓練を行う |
| **WinRMの監視強化** | 不審なリモート管理通信にアラートを設定する |

### ✅ 個人でできること

- **「緊急です！今すぐ！」と言われたら一度立ち止まる** → 焦らせるのは詐欺の常套手段
- **別の方法で本人確認する** → 「その電話を一度切って、自分で会社の代表番号に電話し直す」
- **声だけで100%信用しない** → AIで声は簡単に偽造できる時代だと認識する
- **クイックアシストやリモート操作ツールを急に求められたら疑う** → 本物のIT部門なら事前連絡があるはず

### 🔮 今後の展望

AIによる音声・動画の偽造技術は今後さらに精度が上がっていきます。「声で本人確認する」という従来の常識が通用しない時代が来ており、企業のセキュリティ教育のあり方が根本から変わっていく可能性があります。

## 過去記事との関連

以前、**「UNC3753による電話詐欺（ビッシング）と物理侵入を組み合わせた攻撃」**について解説しましたが、今回の記事はその進化版とも言えます。電話を使って人を騙す「ビッシング」の手口に、**AIによる声の偽造技術が加わった**ことで、攻撃の信ぴょう性が格段に上がっています。

どちらの攻撃も共通しているのは、**「人間の心理・信頼感を突く」** という点です。どれだけシステムが強固でも、人間が騙されれば意味がありません。この「人的要素」を突く攻撃が、今のサイバーセキュリティにおける最大の課題となっています。

## 用語解説

| 用語 | 説明 |
|------|------|
| **Microsoft Teams** | 会社向けのチャット・ビデオ会議ツール（LINEの企業版のようなもの） |
| **外部テナント連携** | 別の会社のTeamsアカウントからでも社内にメッセージを送れる機能 |
| **Quick Assist（クイックアシスト）** | Windowsに標準搭載の遠隔操作ツール |
| **MFA（多要素認証）** | パスワード以外にも認証を求めるセキュリティ機能 |
| **AIボイスクローニング** | 人の声をAIで学習・複製する技術 |
| **ディープフェイク** | AIによる偽の動画・音声・画像の総称 |
| **ソーシャルエンジニアリング** | 技術的な攻撃ではなく、人を心理的に操って情報を盗む手法 |
| **DLLサイドローディング** | 正規アプリの処理に悪意あるコードを紛れ込ませる手口 |
| **UEBA** | ユーザーの行動を分析して異常を検知するセキュリティツール |
| **WinRM** | Windowsのリモート管理機能（遠隔からPCを操作できる） |
| **Rclone** | ファイルをクラウドに同期するツール（悪用されるとデータ盗難に使われる） |
| **C2（コマンド＆コントロール）** | 攻撃者がマルウェアに命令を送るための通信チャンネル |
| **横展開（ラテラルムーブメント）** | 一つのPCに侵入後、社内ネットワークの他のPCにも広がっていくこと |
