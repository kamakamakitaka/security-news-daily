# 中国系ハッカー集団「VerdantBamboo」がLinuxアプライアンスに新型バックドアを展開

**元記事**: [VerdantBamboo Deploys BSD Variant of BRICKSTORM on Linux Appliances](https://inl03.netline.com/ltr6/?_m=3n.009a.3998.sp0ao46r89.31u4)
**解説日**: 2026年6月9日

---

## 背景知識

このニュースを理解するために、まず基本的な言葉を整理しましょう。

### 🏢 アプライアンスってなに？
「アプライアンス」とは、特定の目的のために作られた専用のコンピュータ機器のことです。たとえば「NAS（ネットワーク接続ストレージ）」は、会社の中でみんながファイルを共有するためのストレージ専用の機械です。普通のパソコンとは違い、**セキュリティソフト（EDR）が入れられないことが多い**というのが重要なポイントです。

### 🔓 バックドアってなに？
本来の入口（玄関）を使わずに、こっそり建物に入るための「裏口」のことです。ハッカーがシステムに仕込む「隠れた侵入口」で、いつでもこっそり入り込めるようにするためのプログラムです。

### 🕵️ サイバースパイ（サイバー諜報）ってなに？
国家や大きな組織が、他の国や会社の秘密情報を盗むためにネットを通じてこっそり活動することです。今回は**中国政府とつながりがあると疑われる**グループの話です。

### 🌐 VPNってなに？
「Virtual Private Network（仮想プライベートネットワーク）」の略で、インターネット上に「秘密のトンネル」を作って安全に通信する仕組みです。会社のシステムに社外からアクセスするためによく使われます。

### 🔧 MSP（マネージドサービスプロバイダー）ってなに？
会社のIT管理を代行してくれる業者のことです。「うちの会社にはIT専門家がいないから、外部の会社に頼もう」という場合に使います。今回、このMSPが攻撃の「踏み台」にされました。

---

## 何が起きたのか

セキュリティ企業の**Volexity（ボレクシティ）**が2025年9月のインシデント対応中に、中国系ハッカー集団「**VerdantBamboo（ヴァーダントバンブー）**」による大規模な侵入を発見しました。

### 事件の流れを時系列で見てみましょう

```
【約2024年春ごろ】
     ↓
MSP（IT管理業者）のファイアウォールに侵入
     ↓
そこを踏み台にして被害企業にも侵入
     ↓
【2025年9月】
Volexityが調査を開始・発見
     ↓
初期対応（修正）
     ↓
ハッカーが「再侵入」← 懲りてない！
     ↓
今度はNASにも新しいマルウェアを仕込む
```

簡単に言うと…

> 🏠 **「家のカギを管理している管理会社（MSP）がハッキングされ、そのカギを使って本物の家（被害企業）にも侵入された」** というイメージです。

被害者が気づいて鍵を交換しても、ハッカーはまた別の方法で入り込んできました。少なくとも**最初の侵入から18ヶ月以上**にわたって潜み続けていたとみられています。

## 技術的な詳細

### 🦠 使われたマルウェア（悪意のあるプログラム）3種類

#### 1. BRICKSTORM（BSDバリアント）
もともと存在が知られていたバックドアの**新しい亜種**です。今回はBSD（LinuxやWindowsとは別のOS）向けに作られたバージョンが発見されました。

- 権限昇格の脆弱性（弱点）を使ってシステムに侵入
- 「Egnyte Storage Sync」というファイル共有システムの脆弱性を悪用
- **→ 2026年3月リリースのバージョン13.13で修正済み**

#### 2. PLENET（別名：GRIMBOLT）
.NET Coreという技術で作られた**クロスプラットフォーム型バックドア**（WindowsでもLinuxでも動く）。

できること：
- 🖥️ 遠隔からシェル（コマンド操作）を実行
- 📁 ファイルを操作・盗む
- 🌐 指令サーバー（C2）を切り替えて追跡をかわす

#### 3. AGENTPSD
Pythonで作られた**リバースシェル**（被害端末からハッカー側に接続する仕組み）。

> 💡 普通は「サーバー→クライアント」の方向に接続しますが、リバースシェルは逆に「被害端末→攻撃者」の向きで接続します。これにより、ファイアウォールの検知をかわしやすくなります。

PLENETが動かなくなった時の**「保険」として使われる**バックアップ的な存在です。

### 🎭 どうやって発見を免れていたか？

| テクニック | 説明 |
|---|---|
| **正規トラフィックに紛れる** | VPN経由でアクセスし、普通の社員に見せかける |
| **EDRが入れられない機器を狙う** | NASやファイアウォールなど、セキュリティソフトが動かない機器をターゲット |
| **1被害者に少数のIPアドレスのみ使用** | 大量のIPを使うと怪しまれるため、意図的に絞る |
| **機器ごとにカスタマイズ** | マルウェアの名前や設定を端末ごとに変えて、パターン検知を避ける |

## なぜ重要なのか

### 🌍 影響の広さ

このグループは、複数のセキュリティ企業から**別々の名前で追跡されている**ほど有名な脅威です。

| 企業 | グループ名 |
|---|---|
| Volexity | VerdantBamboo |
| Microsoft | Clay Typhoon |
| Google | UNC5221 |
| CrowdStrike | Warp Panda |

つまり、**世界トップクラスのセキュリティ企業が全員注目している**レベルの脅威ということです。

### 😱 特に怖いポイント３つ

1. **MSP（IT管理会社）への侵入** → 1つのMSPが攻撃されると、そのMSPが管理する**何十〜何百もの企業**が道連れになる可能性があります

2. **EDRが入らない機器を狙う** → NASやファイアウォールは、ウイルス対策ソフトが動かないことが多く、感染しても気づきにくい

3. **18ヶ月以上潜伏** → 発見されるまで1年半以上、静かに情報を盗み続けていた可能性があります

> 📌 **CVSSスコア10.0の脆弱性も悪用**
> 記事中に登場する「CVE-2026-22769」はCVSS（脆弱性の深刻度スコア）が**満点の10.0**。これは「最も危険な脆弱性」を意味します。

## 対策・今後の展望

### 🛡️ 企業・組織が今すぐできる対策

#### ソフトウェアのアップデート
- **Egnyte Storage Sync** → バージョン13.13以上に更新（脆弱性修正済み）
- NASやファイアウォールなどのファームウェアを常に最新に保つ

#### アクセス管理の強化
- 管理者アカウントの**多要素認証（MFA）** を必ず有効にする
  - （例：パスワード＋スマホの認証アプリの組み合わせ）
- 不要なVPNアクセスを制限する

#### MSP（委託業者）の管理
- 自社のIT管理を外部に委託している場合、その業者のセキュリティ状況も確認する
- 「信頼できる業者だから大丈夫」ではなく、**ゼロトラスト（誰も最初から信頼しない）** の考え方が重要

#### 監視の強化
- EDRが入れられないNASやファイアウォールの**ログを定期的に確認する**
- 異常なSSH接続（特に深夜や業務時間外）を検知する仕組みを整える

### 🔮 今後の展望

- BRICKSTORMはすでにLinux・BSD・Windowsと複数のOSに対応した亜種が確認されており、**さらなる亜種の登場**が予想されます
- PLENETはGoogleも別グループ（UNC6201）の攻撃で確認しており、**複数のグループ間で共有・流通している**可能性があります
- 国家関与が疑われるサイバー諜報活動は今後も続くとみられ、特にITインフラ管理業者（MSP）が標的になるリスクは高まっています

## 用語解説

| 用語 | 意味 |
|---|---|
| **バックドア** | ハッカーがこっそり侵入するために仕込む「裏口プログラム」 |
| **マルウェア** | 悪意を持って作られたプログラムの総称（ウイルス・スパイウェアなど） |
| **BSD** | UnixというOSから派生したOS。ファイアウォールなどに使われることが多い |
| **NAS** | ネットワーク接続型ストレージ。会社でファイル共有に使う専用機器 |
| **EDR** | Endpoint Detection and Response。パソコンへの攻撃を検知・対応するセキュリティソフト |
| **C2サーバー** | Command & Control（指令・制御）サーバー。ハッカーがマルウェアに命令を送る拠点 |
| **権限昇格** | 一般ユーザーが管理者権限を不正に取得すること |
| **ゼロデイ脆弱性** | 修正パッチが出る前に攻撃に使われる未知の弱点 |
| **リバースシェル** | 被害端末側からハッカー側に接続する手法。ファイアウォールをかいくぐりやすい |
| **MSP** | 企業のIT管理を代行する業者（マネージドサービスプロバイダー） |
| **CVSS** | 脆弱性の深刻度を0〜10で表すスコア。10が最も危険 |
| **ゼロトラスト** | 社内・社外問わず「誰も最初から信頼しない」というセキュリティの考え方 |
| **多要素認証（MFA）** | パスワード以外にも認証を追加する仕組み（例：スマホのワンタイムパスワード） |
| **Living-off-the-land** | OSに最初から入っているツールを悪用する攻撃手法。専用ツールを使わないため発見されにくい |
| **AOTコンパイル** | プログラムを事前に機械語に変換する技術。実行速度が上がり、解析もされにくくなる |

> 💬 **まとめると…**
> 中国系ハッカー集団が、セキュリティソフトを入れられない専用機器（NASやファイアウォール）を巧みに狙い、IT管理業者を踏み台にして多くの企業に侵入する高度なスパイ活動を行っていました。18ヶ月以上気づかれずに潜伏していたという点が特に恐ろしく、「普段使わない機器だから安全」という思い込みが命取りになることを教えてくれる事件です。
