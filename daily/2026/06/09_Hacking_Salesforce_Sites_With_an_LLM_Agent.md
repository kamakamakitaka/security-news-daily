# LLMエージェントでSalesforceサイトをハッキングする

## 背景知識

このニュースを理解するために、まずいくつかの言葉を説明します。

### Salesforceって何？
**Salesforce（セールスフォース）**は、企業が顧客情報や営業データを管理するためのクラウドサービスです。世界中の大企業が使っており、顧客の名前・連絡先・購買履歴・クレジットカード情報なども管理されています。「Salesforce Experience Cloud」はその中でも、外部の人（お客さんや一般ユーザー）向けにウェブサイトを公開する機能です。

> 📦 **イメージ**: 大企業の「顧客データの倉庫」がクラウド上にあって、一部が外部から見えるショーウィンドウになっているイメージです。

### LLM（大規模言語モデル）って何？
**LLM（Large Language Model）**とは、ChatGPTやClaudeのような「高性能なAI」のことです。文章を読んで理解し、コードを書いたり、問題を解いたりできます。

### ペネトレーションテスト（ペンテスト）って何？
**ペネトレーションテスト**とは、「許可を得た上で、わざとシステムに攻撃を仕掛けて弱点を見つける作業」です。セキュリティの専門家が行う「模擬攻撃」です。

### 「エージェント」って何？
AIの文脈では、**エージェント**とは「自分で考えて、次の行動を決めて、自律的にタスクをこなすAIシステム」のことです。

## 何が起きたのか

セキュリティ企業「**Reco（レコ）**」の研究チームが、**AIエージェントを使ってSalesforceのサイトを自動的にハッキングするシステム**を作り上げました。

このシステムは、

1. **URLを1つ渡すだけ**で
2. **人間が何も操作しなくても**
3. 自動でサイトの弱点を探し
4. 攻撃コードを自分で書いて
5. 実際に攻撃を実行し
6. データを抜き取る

ということを**全部自動で**やってしまいます。

Recoのチームはこのシステムを実際の大手テクノロジー企業のSalesforceサイトに向けて試したところ、**セキュリティに多額の投資をしている企業のサイトでさえ、深刻な脆弱性（弱点）が見つかった**というショッキングな結果が出ました。

## 技術的な詳細

このAIエージェントがどうやって動いているのかを、段階を追って解説します。

### 🔍 フェーズ1：偵察（サイトの地図を作る）

> **偵察**とは、攻撃前に「何が狙えるか」を調べる作業です。

エージェントはまず、URLだけを手がかりに、そのSalesforceサイトが外部に公開している情報を全部洗い出します。

- どんなデータベースのテーブル（表）があるか
- どんな機能（メソッド）が外部から呼べるか
- どんなページやファイルが見えるか

これは、泥棒が建物に入る前に「どこにドアがあるか」「どの窓が鍵をかけ忘れているか」を外から調べるようなものです。

### 📊 フェーズ2：データ分析（重要なものを絞り込む）

次に、見つかったテーブルの中から**特に危険なもの**を優先して調べます。

- `Contact`（顧客の連絡先）
- `Lead`（見込み客の情報）
- `CreditCardTransaction__c`（クレジットカードの取引記録）

などは危険度が高いとAIが判断し、優先的に調査します。

> 🔑 **ポイント**: このランク付けを**AIが自動で判断**するのが革新的なところです。人間が一つ一つ確認する必要がありません。

### 💥 フェーズ3以降：攻撃コードの生成・実行

弱点が見つかったら、AIは**攻撃するためのプログラムを自分でゼロから書き**、それを実行してデータを取得します。さらに必要なら、インターネット上の公開情報も自動で集めて攻撃に活用します。

```
[URL入力] 
  ↓ 自動
[偵察・地図作成]
  ↓ 自動
[重要データの特定]
  ↓ 自動
[攻撃コードの自動生成]
  ↓ 自動
[攻撃実行・データ取得]
```

この一連の流れが**全て自動**で行われます。

## なぜ重要なのか

### ⚠️ 「高度な攻撃」のハードルが限りなく低くなった

これまでSalesforceの複雑な脆弱性を狙うには、専門的な知識を持つ熟練ハッカーが何時間も手作業で調査する必要がありました。しかし今では、**AIにURLを渡すだけで誰でも同等の攻撃ができる**可能性があります。

> 🏠 **たとえ話**: 昔は金庫を破るには熟練の専門家が必要でしたが、今や「この金庫を開けて」と言うだけで自動で開けてくれるロボットが登場した、というイメージです。

### 📈 実際の犯罪グループもすでに動いている

記事には「**ShinyHunters（シャイニーハンターズ）**」という実際のハッカー集団が、すでに何千ものSalesforceサイトをスキャンしたことが言及されています。このグループは過去にも大量のデータ流出事件を起こしており、すでに同様のAI活用が始まっていると考えられます。

### 🏢 影響を受けるのは私たちの個人情報

Salesforceを使っている大企業には、私たちが登録した個人情報（氏名・メールアドレス・電話番号・購買履歴など）が保存されています。これらが漏洩するリスクが高まっています。

## 対策・今後の展望

### 企業側が取るべき対策

| 対策 | 内容 |
|------|------|
| 🔒 ゲストユーザーの権限制限 | 未ログインのユーザーが見られるデータを最小限にする |
| 🔍 定期的な設定監査 | Salesforceの公開設定が意図通りになっているか確認する |
| 🚨 異常アクセスの検知 | 大量のデータクエリが来たらアラートを出す仕組みを作る |
| 📋 Aura APIの適切な設定 | 不要なエンドポイント（入口）を閉じる |

### 私たちユーザーができること

- 企業からの「情報漏洩のお知らせ」メールには注意を払う
- 同じパスワードの使い回しをやめる
- 不審なメール・SMSに注意する（漏洩した情報を使ったフィッシング詐欺が増える可能性がある）

### 今後の展望

このような「AIを使った自動攻撃」は今後ますます増えると予想されます。防御側も**AIを使った自動防御**（異常なアクセスをAIが検知して自動ブロックするなど）を導入することが急務となっています。まさに「AIvs.AI」の時代が始まっています。
