# Hades PyPI攻撃：19個のパッケージに毒が仕込まれ、Bunを使った認証情報窃取ツールが自動実行される

**元記事**: [Hades PyPI Attack: 19 Packages Poisoned to Auto-Run Bun Credential Stealer](https://inl03.netline.com/ltr6/?_m=3n.009a.3999.sp0ao46r89.31wc)
**解説日**: 2025年6月10日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な仕組みを押さえましょう。

### 🐍 PyPIとは？
**PyPI（Python Package Index）** は、Pythonというプログラミング言語用の「アプリストア」のようなものです。世界中の開発者が作ったプログラム部品（パッケージ）が50万件以上登録されており、`pip install パッケージ名` という一行のコマンドで誰でも無料でダウンロードして使えます。

> 🏪 **例え話**: スマホのApp Storeに誰でもアプリを公開できるように、PyPIにも誰でもパッケージを公開できます。もしそこに「見た目は普通のアプリ」だけど「裏で個人情報を盗むアプリ」が紛れ込んだら…というのが今回の問題です。

### 🔗 サプライチェーン攻撃とは？
**サプライチェーン攻撃**とは、「ソフトウェアの部品・材料の流通経路に毒を混ぜる」攻撃です。製品本体を直接攻撃するのではなく、その材料（ライブラリやパッケージ）に悪意あるコードを仕込み、それを使った多数のシステムを一度に感染させます。

### 🧰 開発者の認証情報（クレデンシャル）とは？
GitHubやAWSなどのサービスにアクセスするための「鍵」にあたる情報です。パスワード、APIキー、SSHキーなどが含まれ、これが盗まれると攻撃者がサービスに不正ログインできてしまいます。

---

## 何が起きたのか

セキュリティ企業のSocketが、**「Hades（ハデス）」** と名付けられた新たなサイバー攻撃キャンペーンを発見しました。

### 事件の概要

- **PyPIに19個の悪意あるパッケージ**（合計37バージョン）が公開されていた
- これらのパッケージをインストールした開発者のPCから、**大量の認証情報（パスワードや秘密の鍵）が自動的に盗まれる**仕掛けになっていた
- 被害を受けたパッケージ一覧（一部）：

| パッケージ名 | 悪意あるバージョン |
|---|---|
| bramin | 0.0.2, 0.0.3, 0.0.4 |
| coolbox | 0.4.1, 0.4.2 |
| magique | 0.6.8, 0.6.9 |
| executor-engine | 0.3.4, 0.3.5 |
| uprobe | 0.1.3, 0.1.4 |
| （他14パッケージ） | … |

- さらに、バイオインフォマティクス（生物情報科学）関連パッケージにも被害が及んでいた
- この攻撃は以前の **「Miasma」「Shai-Hulud」** というキャンペーンの継続・進化版

## 技術的な詳細

### 🎯 攻撃の手順（ステップごとに解説）

```
① 攻撃者が正規パッケージに似せた悪意あるパッケージをPyPIに公開

② 開発者が気づかず pip install でインストール

③ インストールと同時に「*-setup.pth」ファイルが配置される
   ↓
   Pythonが起動するたびに自動的に悪意あるコードが実行される！
   （開発者が意識して使わなくても動く）

④ バックグラウンドで「Bun（バン）」というJavaScriptの実行環境を
   GitHubからこっそりダウンロード

⑤ 難読化（読み解けないよう暗号化）されたJavaScriptプログラム
   「_index.js」を実行

⑥ PCに保存されているあらゆる認証情報を収集・送信
```

### 🗝️ 盗まれる情報の種類

攻撃者が狙う情報は非常に広範囲です：

- **クラウドサービスの鍵**: AWS、Google Cloud、Azure、Kubernetes
- **開発ツールの認証情報**: GitHub、npm、PyPI、JFrog、CircleCI
- **AIサービスの鍵**: Anthropic（Claude）、MCP設定
- **システム情報**: SSHキー、シェル履歴、.envファイル
- **コンテナ設定**: Docker設定、Vaultトークン

### 🧠 巧妙な仕掛け①：自動実行の仕組み

通常、パッケージの悪意あるコードは「プログラムの中でそのパッケージを呼び出したとき」に実行されます。しかし今回は **`*-setup.pth`（サイトパスファイル）** という特殊なファイルを使っています。

> 📬 **例え話**: 普通の罠は「その部屋に入ったら爆発する」ものですが、今回の罠は「家に荷物が届いた瞬間に、玄関で爆発する」ようなものです。使う前から動いてしまうのです。

### 🧠 巧妙な仕掛け②：Bunを使う理由

悪意あるコードは **JavaScript** で書かれていますが、普通はJavaScriptを実行するにはブラウザかNode.jsが必要です。今回はそれを回避するために **Bun**（軽量なJavaScript実行環境）をGitHubからこっそりダウンロードして使います。これにより：

- Node.jsがインストールされていない環境でも動く
- セキュリティツールによる検出を回避しやすい

### 🧠 巧妙な仕掛け③：ロシア語ロケールのチェック

コードは実行前に**システムの言語設定がロシア語かどうか**を確認します。ロシア語環境では動作しません。これは**ロシア国内のユーザーを意図的に除外している**（＝攻撃者がロシア語圏にいる可能性を示唆）とも解釈できます。

### 🧠 巧妙な仕掛け④：AIセキュリティスキャナーを欺く試み

「Hadesクラスター」と呼ばれる別グループのパッケージ群では、悪意あるコードを `__init__.py` ファイルの中に**1行の難読化されたコード**として埋め込みました。これはAIによるセキュリティスキャンを混乱させることを狙ったものと見られています。

## なぜ重要なのか

### 👨‍💻 特に開発者にとって深刻な理由

一般ユーザーよりも開発者が特に危険な理由があります：

1. **開発者のPCには「マスターキー」が集中している**: クラウドの管理権限、コード管理システムへのアクセス権など、1人の開発者の認証情報が盗まれると、そのプロジェクト全体・会社のインフラ全体が危険にさらされます

2. **CI/CD環境への影響**: 自動テスト・デプロイを行うサーバー（CI/CDサーバー）でもPythonパッケージが使われるため、サーバー上の認証情報が根こそぎ盗まれる可能性があります

3. **気づきにくい**: インストールした時点で実行されるため、「使っていないから大丈夫」が通用しない

### 📊 攻撃の規模感

- 今回だけで **37の悪意あるファイル × 19パッケージ**
- 「Miasma」「Shai-Hulud」から継続する**組織的・継続的な攻撃キャンペーン**
- バイオインフォマティクスなど**特定の専門分野を狙い撃ち**にしている点も注目

## 対策・今後の展望

### ✅ すぐできる対策

#### 開発者向け
1. **パッケージのバージョンを確認する**
   - 上記の被害リストに自分が使っているパッケージ・バージョンが含まれていないか確認
   - 含まれていた場合はすぐにアンインストールし、認証情報を全て変更する

2. **インストール前にパッケージを検証する**
   - 公開日が最近のマイナーアップデートには注意
   - ダウンロード数が急に変わっているものは疑う
   - Socketなどのセキュリティツールを使ってスキャンする

3. **仮想環境を使う**
   - `venv` や `conda` などの仮想環境内でのみパッケージを使い、影響範囲を限定する

4. **認証情報を定期的にローテーション（更新）する**
   - APIキーやSSHキーを定期的に作り直す習慣をつける

#### 組織・チーム向け
5. **プライベートパッケージリポジトリを使う**
   - PyPIから直接取得するのではなく、承認済みパッケージのみを配布する内部リポジトリを使う

6. **CI/CD環境の権限を最小化する**
   - サーバーに必要最低限の権限しか持たせない

### 🔮 今後の展望

セキュリティ企業のSocketとStepSecurityは、この種の攻撃が**今後も進化し続ける**と警告しています。特に：

- AIセキュリティスキャナーを欺く技術の高度化
- 特定の専門分野（バイオ、AI、金融）を狙い撃ちにする傾向
- 「正規パッケージのアップデートに見せかける」手法の継続

## 用語解説

| 用語 | 意味 |
|---|---|
| **PyPI** | Pythonのプログラム部品を配布する公式サービス（アプリストアのようなもの） |
| **パッケージ** | プログラムの「部品」。他のプログラムから呼び出して使う |
| **サプライチェーン攻撃** | ソフトウェアの「部品・材料」に悪意あるコードを仕込む攻撃 |
| **認証情報（クレデンシャル）** | サービスにアクセスするためのパスワードやAPIキーなどの「鍵」 |
| **Bun** | JavaScriptを実行するための軽量なプログラム |
| **難読化（obfuscation）** | コードを読み解けないよう変換して、解析を困難にする技術 |
| **CI/CD** | コードの自動テスト・自動デプロイを行う仕組み（開発の効率化に使われる） |
| **setup.pthファイル** | Pythonの起動時に自動的に読み込まれる特殊な設定ファイル |
| **SSHキー** | サーバーに安全に接続するための電子的な「鍵と錠前」のペア |
| **APIキー** | WebサービスのAPIを使うための「会員証」のようなもの |
| **ロケール** | コンピューターが使う言語・地域の設定 |
| **Miasma / Shai-Hulud** | 今回の「Hades」攻撃の前身となった、同じ攻撃者グループによる過去のキャンペーン名 |

---

> 💡 **まとめ**: 「有名サービスのパッケージだから安全」「自分はターゲットじゃない」という思い込みが最も危険です。開発者の方は特に、インストールするパッケージのバージョンと出所を意識する習慣をつけましょう。
