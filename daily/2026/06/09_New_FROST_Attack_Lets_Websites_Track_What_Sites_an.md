# FROST攻撃：SSDの「読み込み速度」だけで、あなたが見ているサイトやアプリがバレる？

**元記事**: [New FROST Attack Lets Websites Track What Sites and Apps You Open via SSD Timing](https://inl03.netline.com/ltr6/?_m=3n.009a.3999.sp0ao46r89.31w0)
**解説日**: 2025年7月14日

---

## 背景知識

まず、この記事を理解するために必要な「前提知識」を整理しましょう。

### 💾 SSD（ソリッドステートドライブ）とは？
パソコンのデータを保存する部品です。昔のHDD（ハードディスク）より高速で、最近のパソコンにはほぼ標準で搭載されています。ファイルを読み書きするたびに、このSSDが動きます。

### ⏱️ 「タイミング攻撃」とは？
処理にかかる**時間の差**を測ることで、「何が起きているか」を推測する攻撃手法です。例えば、図書館で「本を取ってくる時間が長い＝遠い棚にある」と推測するようなイメージです。直接中身を見なくても、「時間」という情報から間接的に情報を盗み出します。

### 🌐 ブラウザのサンドボックスとは？
Webサイトのプログラム（JavaScript）が、あなたのパソコンに直接悪さをしないよう「隔離された箱」の中で動く仕組みです。「危険なコードもこの箱の中なら安全」という考え方でしたが、今回はこの箱の中からでも攻撃できることがわかりました。

### 📁 OPFS（オリジン・プライベート・ファイルシステム）とは？
2023年から主要なブラウザに追加された機能で、WebサイトやWebアプリがユーザーのパソコンのディスク上に**ファイルを保存・読み込みできる領域**です。Google ドキュメントのようなブラウザ上のアプリが、ファイルをサクサク扱うために作られました。

---

## 何が起きたのか

オーストリアのグラーツ工科大学の研究チームが、**「FROST（フロスト）」** と名付けられた新しい攻撃手法を発見・発表しました（2026年のセキュリティ学会「DIMVA 2026」に論文が掲載予定）。

### 😨 どんな攻撃なの？
あなたが**悪意あるWebサイトを開いているだけで**、そのページがバックグラウンドで動き続け、「あなたが今どのサイトを見ているか」「どのアプリを起動したか」を高い精度で特定できてしまう、というものです。

しかも怖いのは：
- ✅ 特別なソフトのインストール不要
- ✅ 拡張機能も不要
- ✅ あなたに何かの許可を求めることもない
- ✅ 普通のJavaScript（Webページで使われる標準のプログラム）だけで動く

---

## 技術的な詳細

仕組みを順を追って説明します。

### ステップ①：SSDに「大きなファイル」を書き込む
攻撃サイトは、OPFSという機能を使って、あなたのパソコンの**RAM（メモリ）より大きなファイル**をSSDに書き込みます。

> 💡 **たとえで説明すると**：図書館（SSD）に膨大な量の本を置いておくイメージです。本棚（メモリ）に収まりきらないほど大量の本を置くことで、毎回図書館まで取りに行く状態を作り出します。

### ステップ②：SSDの読み込み速度をずっと計測する
攻撃コードは、そのファイルの一部を繰り返し読み込みながら、**1回ごとにかかる時間を`performance.now()`という命令で計測**し続けます。

### ステップ③：「時間のブレ」を観察する
あなたが別のサイトを開いたり、アプリを起動したりすると、そちらもSSDを使い始めます。すると、攻撃サイトのSSD読み込みが**少し遅くなる（競合する）** のです。

> 💡 **たとえで説明すると**：図書館に司書が1人しかいないとします。あなた（攻撃コード）がひたすら本を取り出してもらっている最中に、別の利用者（あなたのアプリ）が来て依頼すると、司書の処理が少し遅くなりますよね？その「遅れ方のパターン」を観察するわけです。

### ステップ④：AIで「何を開いたか」を判定する
計測したタイミングのパターンを、あらかじめ学習させた**ニューラルネットワーク（AI）**に分析させて、「これはTwitterを開いたパターンだ」「これはYouTubeだ」と識別します。

### 📊 驚きの精度
| 対象 | 精度 |
|------|------|
| 上位50サイト（クローズドワールドテスト） | **88.95%** |
| 上位50サイト＋未知の300サイト混在 | **86.95%** |
| macOSの標準アプリ10種 | **95.83%** |

約9割近い精度で「何を見ているか」を特定できるのは、かなり高精度です。

### ⏰ タイマーを「鋭くする」工夫
ブラウザは通常、このような計測を難しくするために時間の計測精度をわざと低くしています。しかし攻撃者は「クロスオリジン分離」という設定を自分のページに対して有効にすることで、計測精度を元に戻してしまいます。

## なぜ重要なのか

### 🚨 「ブラウザの隔離」という前提が崩れた
これまで「ブラウザのサンドボックスに閉じ込めておけば安全」という考え方がありました。しかし今回の攻撃は、**サンドボックスの中にいながら、外の世界（あなたのSSD全体の状況）を観察できる**ことを示してしまいました。

### 🕵️ プライバシーへの深刻な影響
例えば：
- あなたがアダルトサイト、医療情報サイト、政治的なサイトを見ていることがバレる
- どのアプリを使っているかから、職業や趣味が推測される
- ターゲット広告や、さらに悪い場合はスパイ活動・フィッシング詐欺に悪用される

### 📡 さらに怖い「秘密の通信チャネル」
研究チームは同じ仕組みを使って、**パソコン内のアプリからブラウザページへ、こっそりデータを送信する**仕組みも作れることを示しました（Linux: 約662 bit/秒、macOS: 約719 bit/秒）。マルウェア（悪意あるソフト）がこれを使えば、セキュリティソフトに検知されにくい隠れた通信路になる可能性があります。

## 対策・今後の展望

### 😞 正直、今すぐできることは少ない
研究チームはGoogle・Mozilla・Appleに事前に報告しましたが、各社の対応は以下の通りです：

| 企業 | 対応状況 |
|------|----------|
| **Google（Chrome）** | 「フィンガープリントはセキュリティ脆弱性として扱わない」とのスタンス |
| **Apple（Safari）** | 「対象外」としながらも、将来的な対策の可能性は残している |
| **Mozilla（Firefox）** | 問題は認識しているが、まだ対策はリリースしていない |

CVE（セキュリティ脆弱性の公式番号）も割り当てられておらず、実際に悪用された証拠も今のところありません。

### 🛡️ 自分でできる（限定的な）対策
- 🔒 **信頼できないサイトを開きっぱなしにしない**：攻撃には時間が必要です。怪しいサイトをずっと開いたままにしないようにしましょう
- 🧩 **不要なタブはすぐ閉じる**：タブを開きっぱなしにするほど、観察時間が増えます
- 📺 **ブラウザを最新版に保つ**：今後、各社が対策をリリースした際に素早く適用できるようにしましょう
- 🖥️ **複数のストレージ（SSD）を持つ場合**：OSと別ドライブでアプリを動かすと漏えいしにくくなります（一般ユーザーには難しいですが）

## 過去記事との関連

今回の研究チーム（グラーツ工科大学）は、過去にも類似した攻撃を発表しています。

- **「Secret Spilling Drive」（昨年）**：SSDのタイミングを使った攻撃という点では同じですが、こちらはLinuxの`io_uring`という低レベルの機能を使う必要があり、「パソコンに直接アクセスできる人しかできない攻撃」でした。

- **「SnailLoad」攻撃**：ネットワークの遅延だけから、相手がどのサイトや動画を見ているかを推測する攻撃。JavaScriptすら不要でした。

**FROST**の最大の「進化」は、**「パソコンに直接触れなくても、Webサイトを開かせるだけでリモートから実行できる」**点です。攻撃のハードルが大きく下がったと言えます。

## 用語解説

| 用語 | 意味 |
|------|------|
| **SSD** | パソコンのデータを保存する高速な記憶装置 |
| **タイミング攻撃** | 処理時間の差から情報を盗み出す攻撃手法 |
| **JavaScript** | Webページを動かすためのプログラミング言語。ブラウザが標準で実行できる |
| **サンドボックス** | 危険なプログラムが外部に影響を及ぼさないよう隔離する仕組み |
| **OPFS** | ブラウザがディスク上にファイルを保存できる機能（2023年導入） |
| **ニューラルネットワーク（AI）** | 人間の脳を模したAI。パターン認識が得意 |
| **フィンガープリント** | ユーザーを特定・追跡するための情報収集手法 |
| **クロスオリジン分離** | セキュリティ設定の一種。本来は安全のためのものだが、今回は計測精度向上に悪用された |
| **F1スコア** | 精度と網羅率を合わせた評価指標。1.0（100%）が最高 |
| **CVE** | セキュリティ脆弱性に付与される国際的な識別番号 |
| **RAM（メモリ）** | パソコンが処理中のデータを一時的に保存する高速な記憶装置。SSDよりはるかに速いが容量が少ない |
| **covert channel（秘密チャネル）** | 通常の通信経路ではない隠れた経路でデータを送受信する仕組み |

---

> ⚠️ **まとめると**：「悪意あるWebサイトを開いているだけで、SSDの読み込み速度の微妙な変化を観察され、あなたが見ているサイトや使っているアプリを約9割の精度で特定される」という、新しいタイプのプライバシー侵害攻撃が発表されました。今すぐ使えるパッチはなく、各ブラウザメーカーの対応を待つ状況です。信頼できないサイトを長時間開きっぱなしにしないことが、現状できる最善策です。
