# FROST攻撃：SSDの読み書きタイミングで閲覧サイトやアプリを特定できる新手法

**元記事**: [New FROST Attack Lets Websites Track What Sites and Apps You Open via SSD Timing](https://inl03.netline.com/ltr6/?_m=3n.009a.3999.sp0ao46r89.31w0)
**解説日**: 2025年7月11日

---

## 背景知識

この記事を理解するために、まずいくつかの基本的な仕組みを知っておきましょう。

### 💾 SSD（ソリッドステートドライブ）とは？
パソコンのデータを保存する記憶装置です。昔ながらのHDD（ハードディスク）より高速で、最近のパソコンのほとんどに搭載されています。ファイルを読み書きするときに「時間（タイミング）」がかかりますが、複数の処理が同時に行われると、その時間が少し長くなります。

### 🧠 ページキャッシュとは？
パソコンは「よく使うデータ」をRAM（メモリ）に一時的に保存しておきます。これを「キャッシュ」と呼びます。キャッシュにデータがあればSSDにアクセスせず、瞬時に取り出せます。図書館で例えると、**よく借りる本を机の上に出しておく**ような感じです。

### 🌐 ブラウザのサンドボックスとは？
セキュリティのしくみで、ウェブページが動かせる範囲を「箱の中」に制限する仕組みです。悪意のあるサイトがパソコン全体を操作できないよう、**遊び場（sandbox）を囲んで外に出られないようにする**イメージです。

### 📁 OPFS（Origin Private File System）とは？
2023年頃にブラウザに追加された機能で、ウェブアプリ（ブラウザ上で動くアプリ）が自分専用のファイルをパソコンのディスクに保存できる仕組みです。オンラインのメモ帳やコードエディタなどで使われています。ユーザーへの許可確認なしに使えるのが特徴です。

---

## 何が起きたのか

オーストリアの**グラーツ工科大学**の研究チームが、**FROST（フロスト）**と名付けた新しいサイバー攻撃手法を発表しました。

**ポイントをひと言で言うと：**
> 悪意のあるウェブサイトを開いただけで、あなたが他にどんなサイトを見ているか、どんなアプリを使っているかが、ほぼ特定されてしまう可能性があります。

しかも怖いのは、

- ✅ 特別なソフトをインストールしなくていい
- ✅ 怪しいファイルをダウンロードしなくていい
- ✅ 何かを許可するボタンを押さなくていい
- ✅ ただタブを開いておくだけで成立する

という点です。

この研究は2026年のセキュリティ学術会議「DIMVA 2026」に向けて論文として発表予定です。

---

## 技術的な詳細

### 🔍 攻撃の仕組みをわかりやすく解説

#### ステップ1：巨大なファイルをこっそり作る

悪意のあるサイトは、**OPFS機能を使って、あなたのSSDに巨大なファイルを作成**します。このファイルをRAM（メモリ）に収まらないほど大きくします（パソコンのRAMより大きいサイズ）。

> 🏠 例え話：図書館（RAM）に入りきらないほど大量の本を持ち込むイメージです。入りきらないので、倉庫（SSD）を何度も往復しないといけなくなります。

#### ステップ2：タイミングをずっと計測し続ける

そのファイルを**ひたすら読み続け**、毎回の読み取りにかかる時間を`performance.now()`という機能で細かく計測します。

本来、ブラウザはこの計測の精度を意図的に下げて攻撃を難しくしていますが、FROSTは**「クロスオリジン分離モード」**という設定を使って精度を元に戻します（これは自分のサイトでは自由に設定できます）。

#### ステップ3：「競合」を検出する

あなたが別のサイトを開いたり、アプリを起動したりすると、そのサイトやアプリも同じSSDを使います。すると、攻撃者のファイル読み取りが**わずかに遅くなります**。

> 🛣️ 例え話：一本道の道路（SSD）を独占して走っていたところに、別の車（他のサイト・アプリ）が入ってきて、速度が落ちるようなイメージです。

#### ステップ4：AIで何を開いているか判別する

この「遅くなるパターン」は、サイトやアプリによって微妙に異なります。研究チームは**ニューラルネットワーク（AI）**にこのパターンを学習させ、何を開いているかを推測させました。

---

### 📊 どれくらい正確に特定できるの？

| 対象 | 精度（F1スコア） |
|------|-----------------|
| 上位50ウェブサイト（既知のみ） | **88.95%** |
| 上位50ウェブサイト（未知サイト300件混在） | **86.95%** |
| macOSのネイティブアプリ10種 | **95.83%** |

> ⚠️ F1スコアとは：「正確に当たった割合」を示す指標で、100%が完璧です。88%以上というのは非常に高い精度です。

ほぼ9割近い確率で「どのサイトを見ているか」がバレる、ということです。

---

### 🔒 ブラウザのサンドボックスを「超えている」のが問題

従来のSSDタイミング攻撃（昨年同グループが発表した「Secret Spilling Drive」）は、パソコン上に特別なプログラムをインストールする必要がありました。

**FROSTはブラウザだけで完結します。** これにより、「パソコンに直接アクセスできる人」だけでなく、**遠く離れた場所にいる攻撃者が、ウェブサイトを通じて**実行できるようになりました。これが最大の問題点です。

---

## なぜ重要なのか

### 🕵️ プライバシーの侵害
あなたが見ているウェブサイトや使っているアプリは、本来は誰にも知られたくない情報です。これが悪意のあるサイトに筒抜けになる可能性があります。

### 💰 実害につながるリスク
- ショッピングサイトを見ているとわかれば→ターゲット型の詐欺広告
- 銀行サイトを見ているとわかれば→フィッシング攻撃（偽サイトへの誘導）
- 特定のアプリを使っているとわかれば→その脆弱性を狙った攻撃

### 🌍 影響を受けるOS・ブラウザ
- **Chrome・Safari・Firefox**いずれも影響を受ける（程度の差はあり）
- **macOSとLinux**で動作確認済み（Windowsは今回の研究では未検証）
- 単一SSDのノートパソコンが最も影響を受けやすい

## 対策・今後の展望

### 😟 残念ながら今すぐできる対策は限られています

研究チームはGoogle・Mozilla（Firefox）・Apple（Safari）の3社に事前に通知しましたが、各社の反応は以下の通りです：

| 企業 | 反応 |
|------|------|
| **Google（Chrome）** | 「フィンガープリントはセキュリティ脆弱性として扱わない」として対応なし |
| **Apple（Safari）** | 「対象外」としつつも、将来的な対策の余地あり |
| **Mozilla（Firefox）** | 問題を認識したが、現時点で修正なし |

CVE番号（脆弱性の正式な識別番号）も発行されていません。

### 🛡️ 今できる自衛策

完全な防御策はありませんが、リスクを下げる方法として：

1. **怪しいサイトを開かない**（基本中の基本）
2. **使っていないタブはこまめに閉じる**（タブを開いたままにしない）
3. **ブラウザの拡張機能でJavaScriptを制限する**（NoScriptなど）ただし多くのサイトが正常に動かなくなるリスクあり
4. **複数のドライブを持つPCでは、別ドライブでアプリを使う**（ただし効果は限定的）

### 🔮 今後の展望

- ブラウザ側でOPFSのファイルサイズ制限を厳しくする対策が考えられる
- タイマーの精度をさらに下げる対策も検討されうる
- ただし、これらはウェブアプリの利便性とのトレードオフになる

## 過去記事との関連

今回のFROST攻撃は、同じグラーツ工科大学が昨年発表した**「Secret Spilling Drive（秘密を漏らすドライブ）」**という攻撃の進化版です。

- **昨年の手法**：SSDのタイミングを計測してユーザーの行動を推測できるが、**パソコンにネイティブコード（特別なプログラム）のインストールが必要**
- **今回のFROST**：**ブラウザだけで完結**するため、遠隔から誰でも実行可能

また、同グループは**「SnailLoad」**という攻撃も開発しており、こちらはJavaScriptすら使わず**ネットワークの遅延だけ**でどのサイトを見ているか推測できるというものでした。

このグループは「計測できるわずかな差異から情報を盗む」というサイドチャネル攻撃の専門家で、今後も新手法を発表してくる可能性が高いです。

## 用語解説

| 用語 | 説明 |
|------|------|
| **SSD（Solid State Drive）** | パソコンのデータ保存装置。HDDより高速 |
| **RAM（メモリ）** | 一時的にデータを保持する高速な記憶領域。電源を切ると消える |
| **ページキャッシュ** | よく使うデータをRAMに保存しておく仕組み |
| **JavaScript** | ウェブサイトで動く簡易プログラミング言語 |
| **サンドボックス** | プログラムの動作範囲を制限するセキュリティの仕組み |
| **OPFS（Origin Private File System）** | ウェブアプリが使えるブラウザ内ファイル保存機能 |
| **サイドチャネル攻撃** | 処理時間・消費電力・音など「副産物」から情報を盗む攻撃の総称 |
| **フィンガープリント** | ブラウザやPCの特徴から個人を特定する技術 |
| **ニューラルネットワーク** | 人間の脳をまねたAIの学習モデル |
| **F1スコア** | 予測の精度を示す指標。1.0（100%）が完璧 |
| **CVE** | 公式に登録されたセキュリティ脆弱性の識別番号 |
| **クロスオリジン分離** | 異なるウェブサイト間のデータ分離を強化するブラウザの設定 |
| **コバートチャネル** | 通常の通信経路を使わず、こっそりデータを送受信する隠れた通信路 |

---

> 💡 **まとめ**：怪しいサイトを開いただけで、あなたが他に何を見ているかがAIにバレる可能性がある——そんな攻撃手法が発見されました。対策はまだ各ブラウザから出ていませんが、「不審なサイトのタブを開いたまま他のことをしない」という基本的な心がけが、今のところ最善策です。
