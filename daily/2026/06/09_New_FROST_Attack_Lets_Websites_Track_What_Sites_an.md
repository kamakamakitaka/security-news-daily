# FROST攻撃：あなたが見ているサイトやアプリが、SSDの速度差でバレてしまう新手法

**元記事**: [New FROST Attack Lets Websites Track What Sites and Apps You Open via SSD Timing](https://inl03.netline.com/ltr6/?_m=3n.009a.3999.sp0ao46r89.31w0)
**解説日**: 2025年7月11日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な仕組みを押さえておきましょう。

### 💾 SSD（ソリッドステートドライブ）とは？
パソコンのデータを保存する部品です。昔ながらのHDD（ハードディスク）より高速ですが、**複数のプログラムが同時に使おうとすると、少し遅くなる**という特性があります。たとえば、図書館の本棚を複数人が同時に使うと、棚の前で順番待ちが起きるイメージです。

### 🌐 ブラウザのサンドボックスとは？
Webサイトを見るとき、そのサイトのプログラム（JavaScript）はブラウザの「箱の中」で動きます。この「箱」のことをサンドボックスと呼び、**「箱の外のパソコン本体に悪さできないようにする」**安全機能です。

### 📁 OPFS（Origin Private File System）とは？
2023年に各ブラウザが追加した機能で、Webサイトがパソコンのディスクに直接ファイルを保存できる仕組みです。オンラインのメモ帳アプリやコードエディタが、ファイルをローカルに保存するために使います。**許可ダイアログが出ない**のが特徴で、サイトを開くだけで自動的に使われます。

### ⏱ タイミング攻撃とは？
処理にかかる時間（タイミング）を測定することで、秘密の情報を推測する攻撃手法です。「鍵穴に鍵を差し込んで、引っかかりを感じるまでの時間で正しい鍵かどうか判断する」ような感覚です。

---

## 何が起きたのか

オーストリアのグラーツ工科大学の研究チームが、**「FROST（フロスト）」**という新しい攻撃手法を発見・発表しました。

### 🔍 一言でいうと…

> **悪意のあるウェブサイトを開くだけで、あなたが他にどんなサイトを見ているか・どんなアプリを使っているかが、SSDの速度の変化から推測されてしまう**

という攻撃です。

### どんな条件で起きるの？
- 特別なソフトをインストールする必要は**ない**
- ブラウザの拡張機能も**不要**
- 「許可しますか？」のダイアログも**出ない**
- 悪意のあるページを**ブラウザで開くだけ**で攻撃が始まる

現在のところ **macOS と Linux** で動作確認されています（Windowsについては記事内で言及なし）。

---

## 技術的な詳細

では、どうやってSSDの速度差から「あなたが見ているサイト」がわかるのか、順を追って説明します。

### ステップ① ：巨大なファイルをSSDに書き込む

```
悪意のあるサイト
　↓（OPFSを使って）
あなたのSSDに「超巨大なファイル」を書き込む
（パソコンのRAM容量を超えるサイズ＝数GBレベル）
```

ポイントは「RAMより大きいファイル」を作ること。パソコンには **RAM（メモリ）** という超高速な一時記憶領域があり、通常はSSDへのアクセスをメモリでカバー（キャッシュ）してくれます。でも、ファイルがRAMより大きいと**キャッシュしきれず、毎回SSDに直接アクセスする**ことになります。

> 📦 **例え話**：図書館に「棚全部の本を机の上に並べておく」スペースがなければ、必要なたびに棚まで取りに行くしかありません。それと同じです。

### ステップ②：SSDを高速で読み続けながら時間を計る

攻撃コードは**バックグラウンドで延々とそのファイルを読み続け**、各読み込みにかかる時間を `performance.now()` というJavaScriptの関数で計測します。

通常ブラウザはこのタイマーをわざと「ぼかして」精度を落としているのですが、FROSTは**クロスオリジン分離（Cross-Origin Isolation）**という設定を使うことで、タイマーの精度を元の高解像度に戻します。これはサイト自身のページなら自由に設定できてしまいます。

### ステップ③：SSDの「混雑」を検知する

あなたが別のサイトを開いたり、アプリを起動したりすると、そのサイト・アプリも同じSSDにアクセスします。すると…

```
通常時：攻撃コードの読み込み → 速い（0.1ms）
何か開いた瞬間：攻撃コードの読み込み → 少し遅くなる（0.3ms）
```

> 🚗 **例え話**：一本道を一台の車が走っていると速く進めますが、他の車が増えると少し遅くなります。その「遅れ具合」を計測しているわけです。

### ステップ④：AIがパターンを分類

この「遅れパターン」をニューラルネットワーク（AI）に学習させておくと、**「このパターンはYouTubeを開いたとき」「このパターンはSpotifyを起動したとき」**といった判定ができるようになります。

## なぜ重要なのか

### 😰 精度がとても高い

論文で報告された精度は驚くべきものです：

| テスト内容 | 精度（F1スコア） |
|---|---|
| 上位50サイトの識別（既知サイトのみ） | **88.95%** |
| 上位50サイトの識別（未知の300サイトも混在） | **86.95%** |
| macOSアプリ10種の識別 | **95.83%** |

> F1スコアとは精度を示す指標で、100%が完璧、50%はランダムな当てずっぽうと同じレベルです。88〜95%は「かなり正確」といえます。

### 😱 「ブラウザの箱の中」から出ずに攻撃できる

従来の類似攻撃（後述の「Secret Spilling Drive」）は、パソコンにネイティブコードを実行させる必要がありました。つまり、**攻撃者がそのパソコンに物理的またはリモートでログインしている必要があった**のです。

FROSTは**ブラウザだけで完結**するため、悪意のあるサイトを訪問した全ユーザーが対象になります。これは影響範囲が格段に広がることを意味します。

### 🕵️ プライバシーへの直接的な脅威

あなたがどんなサイトを見て、どんなアプリを使っているかは、個人情報そのものです。たとえば：

- 特定の政治系サイトを見ているかどうか
- 医療・健康系サイトを閲覧しているかどうか
- 競合他社のサービスを調べているかどうか

これらが外部から丸見えになる可能性があります。

## 対策・今後の展望

### 😔 今すぐできる対策はほぼない

正直に言うと、**現時点で一般ユーザーが取れる対策は限られています。**

各ブラウザベンダーへの報告結果は以下の通りです：

| ブラウザ | 対応状況 |
|---|---|
| Google Chrome | 「フィンガープリンティングはセキュリティ脆弱性として扱わない」として対応しない方針 |
| Apple Safari | 「対象外」としつつも、将来的な対策の余地を残している |
| Mozilla Firefox | 問題を認識しているが、現時点では対策を出していない |

CVE番号（脆弱性の公式登録番号）も割り当てられておらず、**野外での悪用報告もまだない**状況です。

### 🛡 できることといえば…

強制はできませんが、多少のリスク軽減になりえる行動として：

1. **怪しいサイトを開かない**（当たり前ですが基本中の基本）
2. **使わないタブはすぐ閉じる**（開きっぱなしのタブが攻撃を続けるため）
3. **ブラウザを最新版に保つ**（将来的に修正が入った場合に備えて）
4. **複数のドライブを持つ環境**では、一定の保護になる（アプリが別ドライブにある場合）

### 🔮 今後の展望

研究チームはこの成果を **DIMVA 2026（セキュリティ学会）** で発表予定です。学術的に問題が広く認知されることで、ブラウザベンダーへの対策プレッシャーが高まることが期待されます。

根本的な対策としては：
- OPFSのファイルサイズに厳しい上限を設ける
- タイマーの精度をさらに制限する
- SSDアクセスのノイズを意図的に加える

といった方向が考えられますが、いずれもWebアプリの利便性とのトレードオフになります。

## 過去記事との関連

今回のFROST攻撃は、同じグラーツ工科大学チームによる研究の系譜に位置しています。

- **「Secret Spilling Drive」**（前年発表）：SSDのタイミングでユーザー行動を読み取る攻撃でしたが、**Linuxの`io_uring`というネイティブ機能**が必要でした。つまり「パソコンに直接触れるか、ログインできる人しかできない攻撃」でした。

- **「SnailLoad」**：ネットワークの遅延（通信の遅さ）だけから訪問サイトを推測する攻撃。JavaScriptさえ不要でした。

今回の **FROST** は「ネイティブコード不要・ブラウザだけで完結」という点で前作より危険性が高く、**攻撃者がどこにいても遠隔で実行できる**ようになった点が大きな進化（悪い意味で）です。

## 用語解説

| 用語 | 意味 |
|---|---|
| **SSD（ソリッドステートドライブ）** | パソコンのデータ保存装置。HDDより高速だが、複数アクセスが重なると速度が落ちる特性がある |
| **タイミング攻撃** | 処理時間の差を測って秘密情報を推測する攻撃手法 |
| **JavaScript** | Webサイトを動かすプログラミング言語。ブラウザ上で動く |
| **サンドボックス** | プログラムを「安全な箱」の中に閉じ込めて、外に悪影響を与えないようにする仕組み |
| **OPFS（Origin Private File System）** | ブラウザがWebサイトにローカルファイル保存領域を提供する機能（2023年〜） |
| **RAM（メモリ）** | パソコンの超高速一時記憶領域。SSDより速いが容量が少ない |
| **キャッシュ** | よく使うデータをRAMに一時保存して、毎回ディスクに読みに行かなくていいようにする仕組み |
| **performance.now()** | JavaScriptで高精度な時間計測ができる関数 |
| **クロスオリジン分離** | ブラウザの高度なセキュリティモードの一つ。皮肉なことに、これを有効にするとタイマー精度も上がってしまう |
| **ニューラルネットワーク（AI）** | 人間の脳神経を模した機械学習モデル。パターン認識が得意 |
| **F1スコア** | 分類精度を示す指標（0〜100%）。高いほど正確 |
| **フィンガープリンティング** | ユーザーの環境や行動パターンから個人を特定・追跡する技術 |
| **CVE** | 脆弱性の公式登録番号。セキュリティ上の問題を管理するための番号体系 |
| **ネイティブコード** | OSに直接話しかけるプログラム。ブラウザの外で動く |
| **DIMVA** | ヨーロッパの著名なセキュリティ学会の一つ |

---

> 💡 **まとめ**：FROSTは「怪しいサイトを開くだけで、あなたの行動が筒抜けになりうる」という新しいタイプのプライバシー侵害手法です。現時点で即座にできる対策は少ないですが、「不要なタブはすぐ閉じる」「怪しいサイトは開かない」という基本的な習慣が、リスクを少しでも下げることにつながります。
