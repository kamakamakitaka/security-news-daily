# 自分でコピーして広がるAIウイルスが開発された！ローカルAIだけで動く新型マルウェアの衝撃

**元記事**: [Researchers Build Self-Replicating AI Worm That Operates Entirely on Local, Open-Weight Models](https://inl03.netline.com/ltr6/?_m=3n.009a.3999.sp0ao46r89.31vc)
**解説日**: 2025年6月

---

## 背景知識

まず、この記事を読む前に知っておきたい言葉をいくつか説明します。

### 🐛 コンピュータウイルス・ワームって何？
コンピュータウイルスは、普通のウイルスと同じように「人（この場合はコンピュータ）にくっついて悪さをするプログラム」です。その中でも**ワーム（Worm）**というのは、**人間が操作しなくても自分でコピーして広がっていく**特に厄介な種類です。

> 🐛 例え話：学校でインフルエンザが流行るとき、誰かが「広めよう！」と意図しなくても勝手に広がりますよね。ワームもそれと同じで、ネットワーク（コンピュータの繋がり）の中を勝手に移動して増殖します。

### 🤖 LLM（大規模言語モデル）って何？
ChatGPTやGeminiのような**AIの頭脳**にあたる部分です。大量の文章データを学習して、質問に答えたり文章を作ったりできます。

### 🔓 脆弱性（ぜいじゃくせい）って何？
コンピュータのソフトウェアにある「バグ（欠陥）」のことで、悪用されると不正なアクセスを許してしまう穴のことです。

> 🏠 例え話：家の鍵がゆるくて、特定の方法でドアを叩くと開いてしまう、という感じです。

### 🔧 オープンウェイトモデルって何？
ChatGPTのように会社のサーバーを使って動かすのではなく、**自分のコンピュータにダウンロードして動かせるAI**のことです。誰でも使えて、無料で手に入ります。

## 何が起きたのか

カナダの**トロント大学**の研究チームが、とても怖い「実験用マルウェア（悪意あるプログラム）」を作って発表しました。

その名前は非公式ですが、**「AIワーム（AI駆動型自己複製ウイルス）」**と呼ばれています。

### 📊 実験の結果をわかりやすくまとめると：

| 項目 | 結果 |
|------|------|
| テスト環境のコンピュータ台数 | 33台 |
| 見つけた脆弱性の平均数 | **31.3個** |
| 乗っ取りに成功したコンピュータ | **平均23.1台（全体の約70%）** |
| 自分のコピーを広めた台数 | **平均20.4台（全体の62%）** |
| 広がった世代数（最大） | **7世代** |
| 実験期間 | 7日間 |

しかも、これを行うのに**人間の助けはゼロ**。AIが自分で考えて、自分で攻撃方法を決めて、自分でコピーを作って広がっていきました。

## 技術的な詳細

### 🧠 従来のウイルスとの違い

**従来のワーム（古いタイプ）：**
```
作成時に攻撃方法を固定 → 同じ攻撃を繰り返すだけ
→ パッチ（修正プログラム）を当てれば止まる
```

**今回のAIワーム：**
```
ターゲットを調べる → AIがリアルタイムで攻撃方法を考える
→ 毎回違う攻撃を生成 → パッチを当てても別の方法で攻撃
```

> 🎯 例え話で説明すると…
> 普通の泥棒は「鍵を壊すドリルしか持っていない」ので、ドリルが効かない鍵にすれば防げます。
> でもこのAIワームは「どんな錠前でも、その場で考えて開ける方法を見つける天才泥棒」のようなものです。

### 🔄 どうやって自分でコピーして広がるの？

```
ステップ1: ネットワーク内のコンピュータを探す
     ↓
ステップ2: AIが脆弱性（セキュリティの穴）を分析する
     ↓
ステップ3: その穴に合った攻撃コードをリアルタイムで生成
     ↓
ステップ4: コンピュータへの侵入に成功
     ↓
ステップ5: そのコンピュータにも自分のコピーを植え付ける
     ↓
ステップ6: コピーが次のコンピュータに向けて同じことを繰り返す
```

### 💡 特に怖いポイント：インターネット不要で動く

ChatGPTなどのAIは、インターネットを通じて会社のサーバーに接続して動きます。つまり、会社が「このアクセスは危ない！」と判断すれば止めることができます。

でも今回のワームは**オープンウェイトモデル（自分のコンピュータで動くAI）**を使っているので：

- ✅ インターネット接続なしで動く
- ✅ OpenAIやAnthropicなどの会社に止められない
- ✅ 閉じたネットワーク（会社の内部ネットワークなど）でも動く

### 📰 さらに怖い機能：最新情報を自分で調べる

AIには「学習データの締め切り日」があります（例：2024年12月までの情報しか知らない、など）。しかしこのワームは、**インターネット上に公開されている最新の脆弱性情報（セキュリティアドバイザリ）を自分で読んで**、学習していない新しい攻撃方法も実行できることが確認されました。

つまり「AIが知らないはずの攻撃方法も、公開情報を読んで習得できる」ということです。

### 実際に使われた攻撃手法の例

今回の実験でAIが自分で考えついた攻撃方法には以下のようなものが含まれていました：

- **SambaCry** → Windowsとの共有機能の脆弱性
- **Dirty Pipe** → Linuxの権限を奪う攻撃
- **PrintNightmare** → プリンター機能を悪用した攻撃
- **SQLインジェクション** → データベースへの不正命令
- **JWT bypass** → 認証（ログイン確認）の仕組みを騙す攻撃

これらは「プログラムで事前に教えられた」のではなく、**AIが現場を見て自分で判断して実行**しました。

## なぜ重要なのか

### ⚡ セキュリティの「常識」が通じなくなる可能性

これまでのセキュリティ対策の基本は：
1. 脆弱性（穴）が見つかる
2. 修正プログラム（パッチ）を配布する
3. みんながパッチを当てて安全になる

しかし、このAIワームは**「パッチを当てた穴以外の方法を考える」**ことができます。一つの穴を塞いでも、AIが別のルートを見つけてくる可能性があるのです。

### 🌐 影響を受ける可能性がある場所

- 病院のシステム（医療機器がネットワーク接続されている）
- 工場の制御システム
- 企業の社内ネットワーク
- 政府・自治体のシステム
- IoTデバイス（スマート家電なども対象になりえる）

### 🎓 研究目的であることを忘れずに

この研究は**「悪用」を目的としたものではありません**。トロント大学の研究チームは：
- **完全に隔離された（インターネットに繋がっていない）テスト環境**で実験を行いました
- 「こういう脅威が生まれつつある」と**警告するために**発表しました
- 論文は現在、専門家による審査（査読）中です

> ⚠️ ただし、このような研究が公開されることで、悪意ある人がヒントを得る可能性もあり、「情報を公開すべきかどうか」というセキュリティ研究の倫理問題にもつながっています。

## 対策・今後の展望

### 🛡️ 現時点でできる対策

**個人・学校・企業でできること：**

| 対策 | 内容 |
|------|------|
| **パッチ適用の高速化** | 脆弱性情報が出たらすぐに修正プログラムを当てる |
| **ネットワーク分割** | 重要なシステムを別のネットワークに隔離する |
| **最小権限の原則** | 各コンピュータに「必要最低限の権限」だけ与える |
| **異常検知の強化** | 通常とは違う動きをするプログラムを素早く検知する |
| **多層防御** | 一つの対策ではなく、複数の防衛ラインを作る |

### 🔮 今後の展望

- AIによるサイバー攻撃は**これからも高度化していく**と予想されます
- 一方で、**AIを使った防御（AIでAIを検知・防御する）**の研究も進んでいます
- 「攻撃するAI vs 守るAI」という新しい戦いの時代が始まっているとも言えます

研究チームは「現時点では、ちゃんと守られた本番環境のネットワークでは同じようにはいかないだろう」とも述べています。つまり今すぐ全世界のネットワークが危険、というわけではありませんが、**将来に向けた警鐘**として受け止める必要があります。

## 用語解説

| 用語 | 説明 |
|------|------|
| **ワーム（Worm）** | 人間の操作なしに自動で広がるコンピュータウイルスの一種 |
| **LLM（大規模言語モデル）** | ChatGPTのような、文章を理解・生成できるAIの仕組み |
| **オープンウェイトモデル** | 自分のパソコンにダウンロードして使えるAI（LlamaやMistralなど） |
| **脆弱性（ぜいじゃくせい）** | ソフトウェアのセキュリティ上の欠陥・穴 |
| **CVE** | 脆弱性に付けられる世界共通の識別番号（例：CVE-2024-XXXX） |
| **CVSS** | 脆弱性の危険度を0〜10のスコアで表したもの（10が最も危険） |
| **パッチ** | 脆弱性を修正するための更新プログラム |
| **権限昇格（えすかれーしょん）** | 一般ユーザーが管理者権限を不正に取得すること |
| **IoTデバイス** | インターネットに繋がった家電・カメラ・センサーなどの機器 |
| **プルーフ・オブ・コンセプト（PoC）** | 「こういうことが実際にできますよ」と証明するための実験的なデモ |
| **査読（さどく）** | 研究論文を他の専門家がチェックして正しいか確認すること |
| **推論（inference）** | AIが答えを導き出すこと。計算コストが高く、GPUが必要 |

> 💬 **まとめ**：今回の研究は「SF映画の話」ではなく、実際に動作することが確認された技術です。すぐに世界が危険になるわけではありませんが、**AIがサイバー攻撃に使われる時代**が近づいていることを示す重要なニュースです。セキュリティの世界でも「AIとどう向き合うか」が大きな課題になっています。
