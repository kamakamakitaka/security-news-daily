# 自分でコピーしながら広がるAIワーム、ローカルAIだけで動作することが判明

**元記事**: [Researchers Build Self-Replicating AI Worm That Operates Entirely on Local, Open-Weight Models](https://inl03.netline.com/ltr6/?_m=3n.009a.3999.sp0ao46r89.31vc)
**解説日**: 2025年6月

---

## 背景知識

まず、このニュースを理解するために必要な言葉をいくつか説明します。

### 🐛 コンピューターワームとは？
「ワーム」とは、**ネットワーク上を自動的に広がっていくマルウェア（悪意のあるプログラム）** のことです。  
ウイルスと似ていますが、ウイルスが「他のファイルに寄生する」のに対し、ワームは**自分自身をコピーしながら、次々と別のコンピューターに侵入していきます**。  
有名な例として、2017年に世界中の病院や企業を混乱させた「WannaCry」があります。

### 🤖 大規模言語モデル（LLM）とは？
ChatGPTのような、**文章を読んで考えて答えを生成できるAI**のことです。  
「大規模言語モデル」と呼ばれ、英語では「LLM（Large Language Model）」と略されます。  
今回のニュースのポイントは、このAIが**インターネット上のサービス（OpenAIなど）に頼らず、手元のコンピューターだけで動く**という点です。

### 🔓 脆弱性（ぜいじゃくせい）とは？
コンピューターやソフトウェアの**セキュリティ上の弱点・欠陥**のことです。  
家の鍵で例えると、「鍵穴が壊れていて、特殊な道具があれば誰でも開けられてしまう状態」のようなものです。  
発見された脆弱性には「CVE（シーヴィーイー）」という番号が割り振られ、世界共通で管理されています。

### 🩹 パッチとは？
脆弱性を修正するための**ソフトウェアの更新プログラム**のことです。  
「穴を塞ぐ」イメージで「パッチ（当て布）」と呼ばれます。

## 何が起きたのか

カナダのトロント大学を中心とした研究チームが、**「自分でコピーしながら広がるAIワーム」を実際に作って動かすことに成功しました**。

このワームの特徴は次の3つです：

1. **AIが自分で考えて攻撃方法を決める**  
   事前に「この手順で攻撃しろ」と命令されているのではなく、侵入先のコンピューターを調べて、その場で最適な攻撃方法をAIが考え出します。

2. **ChatGPTなどの外部サービスを使わない**  
   手元のコンピューター（GPU搭載のマシン）だけで動く「オープンウェイトモデル」というAIを使っています。外のサービスに頼らないため、**「不審な通信を遮断する」という対策が効きません**。

3. **ネットワーク全体に自律的に広がる**  
   人間が操作しなくても、自動で次々と別のコンピューターに侵入・コピーし続けます。

研究チームは「FakeCorp（偽会社）」と名付けた**意図的に脆弱な33台のコンピューターからなるテスト環境**でこのワームを動かしました。  
その結果は次のようなものでした：

| 指標 | 結果 |
|------|------|
| 発見した脆弱性（平均） | 31.3個 |
| 管理者権限を奪取したホスト数（平均） | 23.1台（全体の約70%） |
| コピーを増殖させたホスト数（平均） | 20.4台（全体の62%） |
| 自己複製の世代数（最大） | 7世代 |
| テスト期間 | 7日間 |

## 技術的な詳細

### 従来のワームとの違い

**従来のワーム**は、作った時点で「この脆弱性を狙う」という攻撃コードが決まっています。  
家泥棒に例えると、「Aメーカーの鍵しか開けられないピッキングツールを持った泥棒」のようなイメージです。  
→ そのメーカーの鍵を交換すれば（パッチを当てれば）、泥棒は入れなくなります。

**今回のAIワーム**は、現場に来てから「この家の鍵はどうやって開けようかな？」と**その場で考えて行動します**。  
→ 1つの鍵を交換しても、「じゃあ窓から入ろう」と別の方法を考えてきます。

```
【従来のワームの動き】
作成時に攻撃コードを固定 → ネットワークに放つ → 同じ攻撃を繰り返す

【AIワームの動き】
ネットワークに侵入 → AIがターゲットを調査 → その場で攻撃方法を生成 → 侵入成功 → コピーを送り込む → 繰り返し
```

### 「学習データより新しい脆弱性」にも対応できた

特に怖いのが、**このAIが自分の「学習範囲外」の脆弱性にも対応できた**という点です。

AIモデルには「学習データの締め切り日（トレーニングカットオフ）」があります。  
それ以降に発見された脆弱性は、普通は知らないはずです。

しかし今回のワームは、**インターネット上の脆弱性情報（セキュリティアドバイザリ）をリアルタイムで読み込む**機能を持っていました。  
テストでは、モデルが学習した後に公開された3つの脆弱性（CVSSスコア9.3の重大なものを含む）の悪用にも成功しています。

### GPU（高性能グラフィックチップ）を乗っ取って「頭脳」にする

AIを動かすには高性能なGPU（グラフィックス処理装置）が必要です。  
33台のテスト環境のうち5台にGPUが搭載されており、ワームはまずこれらのGPU搭載マシンに侵入し、**そのGPUをAIの「考える頭脳」として使いながら**、GPUを持たない他のマシンにも指示を出して広がっていきました。

## なぜ重要なのか

### ① 「パッチを当てれば安全」が通用しなくなる

これまでのセキュリティ対策の基本は「発見された脆弱性に素早くパッチを当てる」でした。  
しかしこのワームは**複数の脆弱性を組み合わせて攻撃を考えだす**ため、1つの穴を塞いでも別の侵入方法を見つけてきます。

### ② 外部サービスの遮断が効かない

「AIを使った攻撃なら、OpenAIなどへの通信を遮断すれば防げる」という発想がありましたが、今回のワームは**ローカル（手元）で動くオープンウェイトモデルを使う**ため、この対策が無効です。

### ③ 人間の操作が不要

サイバー攻撃の多くは、人間がリアルタイムで操作しています。  
しかしこのワームは**完全自律型**で、攻撃者が一度放てば後は自動で動き続けます。

### ④ 現時点での限界も正直に報告

もちろん、研究チームは問題点も認めています：
- テスト環境は「意図的に脆弱にした環境」であり、実際の企業ネットワークはもっと守りが固い
- 攻撃の成功率は約44%で、特にWebアプリケーションやWindowsの権限昇格は難しかった
- 失敗の多くは「攻撃コードの書き方のミス」によるもの

つまり「**今すぐ世界中に放たれたら大惨事**」というレベルではありませんが、**AIの進化とともにこの精度は上がっていく**ことが懸念されます。

## 対策・今後の展望

### 現時点でできる対策

| 対策 | 説明 |
|------|------|
| **定期的なパッチ適用** | 引き続き重要。「1つ当てれば安心」ではなく、継続的な対応が必要 |
| **ネットワークの分離** | 重要なシステムをインターネットや他のネットワークから切り離す |
| **異常検知の強化** | 通常とは違う動きをするプログラムを検出する仕組みの導入 |
| **最小権限の原則** | ユーザーやプログラムに必要最低限の権限しか与えない |
| **GPUへのアクセス制限** | 重要なGPUマシンへの不審なアクセスを監視・制限する |

### 研究チームの目的

この研究はあくまで「**こんなことができてしまう、だから今のうちに対策を考えよう**」という**警鐘（けいしょう）を鳴らすための研究**です。  
研究チームは悪用防止のため、コードの公開方法について慎重に対応するとしています。

### 今後の懸念

- AIモデルの精度向上 → 攻撃成功率のさらなる上昇
- 小型・高性能なGPUの普及 → ワームが「頭脳」を確保しやすくなる
- オープンウェイトモデルの増加 → 誰でも使える強力なAIが増える
