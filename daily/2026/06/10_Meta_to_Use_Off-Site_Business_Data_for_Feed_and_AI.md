# MetaがSNS外の行動データをフィードやAIチャットにも活用へ

**元記事**: [Meta to Use Off-Site Business Data for Feed and AI Personalization](https://inl03.netline.com/ltr6/?_m=3n.009a.4000.sp0ao46r89.31xw)
**解説日**: 2025年6月12日

---

## 背景知識

このニュースを理解するために、まずいくつかのことを押さえておきましょう。

**Metaとは？**
Facebook・Instagram・Threads・WhatsAppなどを運営している巨大テクノロジー企業です。世界中に何十億人ものユーザーがいます。

**「ターゲット広告」って何？**
みなさんも経験があるかもしれません。「さっきAmazonで見ていた商品が、なぜかInstagramの広告に出てきた！」という現象です。これがターゲット広告です。

仕組みはこうです👇

```
あなたがAmazonで「テント」を検索
        ↓
AmazonがMetaに「このユーザーはテントに興味あり」と通知
        ↓
MetaがInstagramでテント関連の広告を表示
```

この「AmazonがMetaに情報を送る」行為のことを、**「オフサイトデータの共有」**と呼びます。「オフサイト」＝「Meta以外のサイト・アプリ上での行動」という意味です。

**AIチャットボットとは？**
MetaはChatGPTのような会話型AIを自社サービスに組み込んでいます。「Meta AI」と呼ばれるもので、InstagramやFacebook上で質問に答えてくれる機能です。

---

## 何が起きたのか

Metaが2025年6月に発表した内容をわかりやすくまとめると、こうなります👇

> **これまで：** 他サイトのデータ → 広告のカスタマイズ **だけ** に使用
>
> **これから：** 他サイトのデータ → 広告 **＋ フィードの表示内容 ＋ AIの返答内容** にも使用

つまり、あなたが**Metaの外で行った行動**（他のサイトでの買い物・閲覧・ゲームのプレイなど）が、これからはInstagramのフィード（タイムライン）に流れてくる動画や投稿の選び方、さらにMeta AIとの会話の返答内容にまで影響するようになります。

Metaは「新しいデータを集め始めるわけではない」と説明しています。すでに広告用に集めていたデータの**使い道を広げる**、ということです。

対象となる国は、アメリカ・イギリス・ブラジル・タイ・南アフリカ・トルコ・韓国・エクアドル・ナイジェリア・ケニアなど。来月（2025年7月）から順次スタートする予定です。

## 技術的な詳細

**どうやってデータが流れているの？**

企業がMetaにデータを送る方法はいくつかありますが、代表的なのが **「Metaピクセル」** という仕組みです。

```
【ショッピングサイトの裏側で起きていること】

あなたが「テントを購入」ボタンを押す
        ↓
サイトに埋め込まれたMetaのプログラム(ピクセル)が反応
        ↓
「このユーザーがテントを買いました」という情報がMetaに自動送信
        ↓
Metaがその情報を保存・活用
```

これに加えて、企業は**メールリスト**（「ニュースレターに登録した人のメアドリスト」など）をMetaに丸ごと渡すこともできます。Metaはそのメアドと自社のアカウント情報を照合して、「この人だ！」と特定します。

**AIへの活用ってどういうこと？**

例えば、あなたがアウトドア用品サイトでテントを買った翌日、Meta AIに「週末の過ごし方を教えて」と聞いたとします。するとMeta AIは、あなたのオフサイトデータを参照して「キャンプはどうですか？テントもお持ちのようですし！」といった返答をする可能性があります。

**設定の変更点**

| 旧設定名 | 新設定名 |
|---|---|
| 「広告パートナーからのアクティビティ情報」 | 「他のビジネスからのアクティビティ」 |
| 「Meta外のアクティビティ」 | ⚠️ **廃止予定** |

設定を「許可しない」にした場合でも、Metaは完全にパーソナライズをやめるわけではありません。その場合は「Meta内での行動」（いいね！した投稿など）を元にした表示になります。

## なぜ重要なのか

### 🔍 プライバシーの観点から
「自分がどこで何を買ったか」というデータが、SNSやAIの返答に影響するということは、**Metaがあなたの生活をかなり詳しく把握している**ということを意味します。

特に注目すべき点が2つあります：

1. **AIへの活用が新しい**
   これまでも広告への活用は知られていましたが、AIの返答内容に使われるのは新しい展開です。AIはより「自然な会話」として情報を提示するため、「これは広告的な意図があるかも？」と気づきにくくなる可能性があります。

2. **企業のメールリスト共有**
   「メルマガに登録しただけなのに、その企業がMetaに自分の情報を渡している」というケースも含まれます。自分で直接Metaに許可した覚えがなくても、間接的にデータが渡っていることがあります。

### 🌍 影響を受ける人
MetaのサービスはInstagram・Facebook・Threadsなど、日本でも広く使われています。今回の発表では日本は対象国として明記されていませんが、今後の拡大の可能性はあります。

## 対策・今後の展望

### ✅ 今すぐできること

**① Metaアプリの設定を確認する**

Instagramの場合：
```
プロフィール → メニュー(三本線) → 設定とプライバシー
→ 広告 → 「他のビジネスからのアクティビティ」
```

ここをオフにすることで、オフサイトデータを広告・フィード・AIに使われることを制限できます。

**② 「Metaの外のアクティビティ」をクリアする**

すでに収集されているオフサイトデータの履歴を削除・切り離すことができます。ただし「今後のデータ収集をやめる」という設定ではないので、定期的に確認する習慣をつけましょう。

**③ ブラウザの広告ブロッカーやプライバシー設定を活用する**

「Metaピクセル」はウェブサイトに埋め込まれているため、ブラウザ側でトラッキングをブロックするツール（例：uBlock Origin、Firefox の強化されたトラッキング防止機能など）を使うことで、データの送信自体を減らすことができます。

### 🔮 今後の展望

Meta・Google・Appleなど大手テクノロジー企業によるデータ活用は年々範囲が広がっています。特にAIの普及により、「データをどう使うか」の問題はより複雑になっています。EUでは**GDPR（一般データ保護規則）**という厳しいプライバシー保護ルールがあるため、今回の変更がヨーロッパでどう扱われるかも注目ポイントです。

## 過去記事との関連

以前、**「Microsoftが過去最多206件の脆弱性を修正」**というニュースを解説しましたが、あちらはソフトウェアのバグ（セキュリティホール）を悪用した「不正アクセス系」の話でした。

今回のMetaのニュースは、不正アクセスや攻撃とは異なり、**企業が利用規約に基づいて合法的にデータを活用する話**です。どちらも「個人情報・データの安全」に関わるテーマですが、脅威の種類がまったく違います。

| | Microsoftの脆弱性問題 | Metaのデータ活用問題 |
|---|---|---|
| 脅威の種類 | 外部の攻撃者による不正アクセス | 企業による合法的なデータ利用の拡大 |
| 対策の方向性 | パッチ（修正プログラム）を当てる | 設定を見直す・利用規約を読む |
| 緊急性 | 高い（すぐにアップデートが必要） | 中程度（設定を確認する余裕あり） |

セキュリティとプライバシーは、どちらも「自分のデジタル生活を守る」ために大切な視点です。

## 用語解説

| 用語 | 意味 |
|---|---|
| **オフサイトデータ** | Meta（Facebook・Instagramなど）以外のサイトやアプリ上でのユーザーの行動データ |
| **ターゲット広告** | ユーザーの興味・行動履歴に基づいて、その人に合わせて表示される広告 |
| **AIチャットボット** | 人工知能を使って会話形式で質問に答えるプログラム。Metaの場合は「Meta AI」 |
| **フィード** | SNSで縦にスクロールして見るタイムライン・投稿一覧のこと |
| **Metaピクセル** | ウェブサイトに埋め込まれた小さなプログラムで、ユーザーの行動をMetaに自動送信する仕組み |
| **パーソナライズ** | ユーザーごとに合わせて内容をカスタマイズすること |
| **GDPR** | EUが定めた厳しい個人情報保護のルール。違反すると巨額の罰金が科される |
| **カスタマーリスト** | 企業が持つ顧客情報のリスト（メールアドレスなど）。Metaに提供されることがある |

> 💡 **まとめると…**
> Metaが「他のサイトでの行動データ」の使い道を、広告だけでなくフィードやAIにまで広げます。新しいデータを集めるわけではありませんが、データの影響範囲が広がります。設定から「オフにする」ことも可能なので、気になる人はぜひ設定を確認してみましょう！
