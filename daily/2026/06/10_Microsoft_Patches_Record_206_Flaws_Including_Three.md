# マイクロソフトが過去最多206件の脆弱性を修正！ゼロデイ3件・深刻なRCEバグも含む

**元記事**: [Microsoft Patches Record 206 Flaws, Including Three Zero-Days and Critical RCE Bugs](https://inl03.netline.com/ltr6/?_m=3n.009a.4000.sp0ao46r89.31ww)
**解説日**: 2025年7月10日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を押さえておきましょう。

### 🖥️ Windowsと「パッチ（修正プログラム）」とは？
マイクロソフト（Microsoft）は、世界中のパソコンやサーバーで使われている「Windows」というOSを作っています。どんなソフトウェアにも「バグ（欠陥）」が存在することがあり、その中でも悪用される危険があるものを**セキュリティ脆弱性（ぜいじゃくせい）**と呼びます。マイクロソフトは毎月第2火曜日（通称「パッチチューズデー」）に、見つかった脆弱性をまとめて修正するプログラムを公開しています。

### 🔢 CVSSスコアって何？
脆弱性の「危険度」を0〜10点で数値化したものです。
- **9.0〜10.0**：緊急（Critical）→「すぐに対処しないと大変なことに！」
- **7.0〜8.9**：重要（High）→「かなり危ない」
- **4.0〜6.9**：警告（Medium）→「注意が必要」

### 🔑 ゼロデイ脆弱性とは？
修正プログラムが公開されるより**前に**、情報が外部に漏れてしまった脆弱性のことです。修正が間に合っていないため、攻撃者に「先手を取られやすい」非常に危険な状態を指します。

---

## 何が起きたのか

マイクロソフトが、**過去最多となる206件**ものセキュリティの欠陥を一度に修正しました！これは通常の月例パッチと比べても異例の多さです。

### 📊 今回の修正の内訳

| 危険度 | 件数 |
|--------|------|
| 🔴 緊急（Critical） | 39件 |
| 🟠 重要（Important） | 167件 |
| **合計** | **206件** |

### 攻撃の種類別でみると…

| 攻撃の種類 | 件数 | 簡単な説明 |
|-----------|------|-----------|
| 権限昇格 | 63件 | 一般ユーザーが管理者権限を奪う |
| リモートコード実行（RCE） | 56件 | 遠隔からプログラムを実行される |
| 情報漏えい | 30件 | データを盗み見られる |
| なりすまし（スプーフィング） | 27件 | 別人に偽装される |
| セキュリティ機能の回避 | 20件 | セキュリティを無効化される |
| サービス妨害（DoS） | 7件 | システムを使えなくされる |
| 改ざん | 3件 | データを書き換えられる |

また、今回の修正にはGoogleのChromiumブラウザ（EdgeのベースになっているWebブラウザ）の**350件以上**のバグ修正も含まれています。

## 技術的な詳細

### 🚨 最も危険な脆弱性①：CVE-2026-45657（CVSSスコア：9.8）
**Windowsカーネルのリモートコード実行脆弱性**

> 🏠 **例え話**：家の鍵（カーネル）に欠陥があって、郵便受けに特殊な手紙を投げ込むだけで、見知らぬ人が勝手に家の中を自由に動き回れてしまうようなイメージです。

- **Windowsカーネル**とは、OSの一番中心にある「心臓部」のような部分です
- 攻撃者が**特殊に細工したネットワーク通信（パケット）**を送りつけるだけで、
- **ログインなし・ユーザー操作なし**で、システムを完全に乗っ取れてしまいます
- これは「**Use-After-Free（解放済みメモリの再利用）**」という技術的欠陥が原因です

> 💡 **Use-After-Freeとは？**
> コンピュータが「もう使わない」と片付けたメモリ領域を、プログラムが誤って再び使ってしまう欠陥です。攻撃者はこの隙に悪意のあるコードを仕込むことができます。

---

### 🚨 最も危険な脆弱性②：CVE-2026-44815（CVSSスコア：9.8）
**Windows DHCPクライアントのスタックバッファオーバーフロー**

> 🏠 **例え話**：「DHCP」とは、インターネットに接続するためのIPアドレスを自動的に割り振る仕組みです。郵便局が各家庭に住所（IPアドレス）を配るようなイメージ。その郵便局のシステムに欠陥があり、細工された手紙を送るだけで、郵便局ごと乗っ取れてしまいます。

- **資格情報もユーザー操作も不要**で攻撃できるため、非常に危険
- 企業ネットワーク内のDHCPサーバーが攻撃されると…
  - 🦠 マルウェアの拡散
  - 💾 データの盗難
  - 🌐 ネットワーク全体への侵入
  - ⛔ サービスの停止
- セキュリティ専門家は「**DHCP関連システムは最優先でパッチ適用を！**」と警告しています

---

### 🔓 BitLocker回避の脆弱性群：CVE-2026-45585・CVE-2026-50507など

> 💡 **BitLockerとは？**
> Windowsに搭載されているデータ暗号化機能です。パソコンを盗まれても、中のデータを読めなくする「金庫」のような役割を果たします。

今回、この「金庫」を**物理的にアクセスできれば解錠できてしまう**脆弱性が複数発見されました。

- **「YellowKey」**というPoC（実証コード）が研究者によって公開されており、実際に攻撃が可能な状態でした
- **「bitskrieg」**という別の手法も発見されており、暗号化されたデータへのフルアクセスが可能になるとされています
- これらはすでに**情報が公開されたゼロデイ**（公開済みゼロデイ）として分類されています

---

### 💣 サーバーをダウンさせる攻撃：CVE-2026-49160（HTTP2/Bomb）

> 🏠 **例え話**：大きな荷物を圧縮してコンパクトにした状態で送りつけ、受け取った相手のサーバーが解凍しようとした途端、膨大なデータに膨れ上がってシステムがパンクする攻撃です。爆弾のように「中で爆発する」イメージから「HTTP2/Bomb」と呼ばれています。

- 実際のテストでは、**IISサーバー（Webサーバー）が約45秒で64GBのRAMを使い切った**という衝撃的な結果が出ています
- これによりWebサービスを**数十秒でダウンさせる**ことが可能です

## なぜ重要なのか

### 🌍 影響の大きさ
- Windowsは世界中の企業・学校・家庭で使われており、**影響を受けるシステムの数は数億台以上**
- 特にリモートコード実行（RCE）の脆弱性は、**インターネットに接続しているだけで攻撃される可能性**があります

### ⚠️ ゼロデイが3件含まれている
今回の修正には「すでに情報が公開されてしまっているゼロデイ」が3件含まれています。

| CVE番号 | 内容 |
|--------|------|
| CVE-2026-50507 | BitLocker暗号化の完全回避（bitskrieg） |
| CVE-2026-45586 | Windows CTFMONの権限昇格 |
| CVE-2026-49160 | HTTP.sysのサービス妨害（HTTP2/Bomb） |

これらは修正前から攻撃者に知られている可能性があるため、**一刻も早い対応が必要**です。

### 🏢 企業への深刻な影響
特にDHCPやWindowsカーネルの脆弱性は、企業ネットワーク全体に被害が広がる可能性があり、**中小企業から大企業まで全ての組織**にとって深刻なリスクです。

## 対策・今後の展望

### ✅ 今すぐやるべきこと

#### 個人ユーザーの場合
1. **Windowsを最新の状態にアップデートする**
   - スタートメニュー → 設定 → Windows Update → 「更新プログラムの確認」
2. **Microsoft Edgeもアップデートする**
   - Chromiumの350件以上のバグ修正も含まれています

#### 企業・組織の場合
1. **DHCPサーバーを最優先でパッチ適用**（CVE-2026-44815）
2. **Windowsカーネルの更新を緊急対応**（CVE-2026-45657）
3. **BitLockerを使っているシステムの更新**（CVE-2026-45585・CVE-2026-50507）
4. **IISなどのWebサーバーの更新**（CVE-2026-49160のHTTP2/Bomb対策）

### 🔭 今後の展望
- マイクロソフトはHTTP2/Bomb攻撃への対策として、新しい設定パラメーター（`MaxHe...`）を導入したと報告されています
- 今後もゼロデイ脆弱性の悪用報告が出てくる可能性があるため、セキュリティニュースへのアンテナを張ることが大切です
- 「パッチチューズデー」ごとに更新を習慣化することが、最も基本的で効果的な対策です

## 用語解説

| 用語 | 意味 |
|------|------|
| **脆弱性（ぜいじゃくせい）** | ソフトウェアの欠陥・弱点のこと |
| **パッチ** | 脆弱性を修正するためのプログラム |
| **ゼロデイ** | 修正前に情報が公開・悪用された脆弱性 |
| **RCE（リモートコード実行）** | 遠隔から任意のプログラムを実行させられる攻撃 |
| **CVSSスコア** | 脆弱性の危険度を0〜10で表した数値 |
| **カーネル** | OSの中核部分。ハードウェアとソフトウェアを繋ぐ「心臓部」 |
| **DHCP** | ネットワーク接続時にIPアドレスを自動で割り振る仕組み |
| **BitLocker** | Windowsのデータ暗号化機能 |
| **バッファオーバーフロー** | データを格納する領域に許容量以上のデータを流し込む攻撃手法 |
| **Use-After-Free** | 解放済みのメモリを誤って再利用することで生じるプログラムの欠陥 |
| **PoC（Proof of Concept）** | 脆弱性が本当に悪用できることを示す実証コード |
| **DoS（サービス妨害）** | サーバーに過負荷をかけてサービスを停止させる攻撃 |
| **HTTP2/Bomb** | 圧縮データを使ってサーバーのメモリを一気に消費させる攻撃手法 |
| **IIS** | マイクロソフトが提供するWebサーバーソフトウェア |
| **スプーフィング** | 送信元などを偽装してなりすます攻撃 |
| **権限昇格** | 一般ユーザーが管理者などの高い権限を不正に取得すること |
