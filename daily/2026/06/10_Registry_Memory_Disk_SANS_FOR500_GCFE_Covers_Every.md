# レジストリ・メモリ・ディスク：Windowsに残る「デジタルの足跡」を徹底調査する資格講座「SANS FOR500」とは？

**元記事**: [Registry. Memory. Disk. SANS FOR500 (GCFE) Covers Every Windows Artifact That Matters.](https://inl03.netline.com/ltr6/?_m=3n.009a.4000.sp0ao46r89.31x2)
**解説日**: 2025年6月11日

---

## 背景知識

このニュースを理解するために、まず「デジタルフォレンジック」という分野について知っておきましょう。

### 🔍 デジタルフォレンジックって何？

「フォレンジック」とは、もともと「法廷で使う証拠調査」のことです。犯罪現場で指紋や足跡を調べる鑑識作業をイメージしてください。**デジタルフォレンジック**とは、それをコンピューターの世界でやること。つまり「コンピューターに残ったデジタルの足跡を調べて、何が起きたかを解明する」技術です。

> 🏠 **たとえ話**: 空き巣が入った家を調べるとき、刑事は「どこから入ったか」「何を触ったか」「いつ侵入したか」を調べますよね。デジタルフォレンジックでは、ハッカーがコンピューターに侵入した際の「デジタルな足跡」を同じように調べます。

### 🪟 Windowsに残る「証拠の3大保管場所」

Windowsパソコンには、何かが起きると必ず痕跡が残ります。その代表的な場所が記事タイトルにある3つです：

| 場所 | 日本語 | 何が残るか |
|------|--------|-----------|
| **Registry（レジストリ）** | Windowsの設定台帳 | どんなソフトを使ったか、いつ接続したか |
| **Memory（メモリ）** | 一時記憶装置(RAM) | 今まさに動いているプログラムの情報 |
| **Disk（ディスク）** | ハードディスク/SSD | ファイルの作成・削除・アクセス履歴 |

## 何が起きたのか

今回の記事は、**SANS Institute（サンズ・インスティテュート）** というセキュリティ教育の世界最大手機関が提供する資格講座「**FOR500**」の紹介・宣伝記事です。

### 📚 SANS FOR500（GCFE）とは？

- **SANS Institute**: 世界中のセキュリティ専門家が認める、最も権威あるサイバーセキュリティ教育機関の一つ
- **FOR500**: Windowsのデジタルフォレンジックに特化したトレーニングコース
- **GCFE**: このコースを修了することで取得できる資格名（*GIAC Certified Forensic Examiner*の略）

> つまり、「Windowsパソコンを徹底的に調べて証拠を見つける専門家」を育てる資格プログラムの紹介記事です。

## 技術的な詳細

### 🗂️ レジストリ（Registry）で何がわかるの？

Windowsのレジストリは、パソコンのあらゆる設定や使用履歴が記録される「巨大な設定ノート」です。

```
例えばレジストリを調べると…
✅ 最後にUSBメモリを接続した日時と機器名
✅ 最近開いたファイルの一覧
✅ インストール・アンインストールされたソフト
✅ ネットワーク接続の履歴
```

> 🔑 **ポイント**: ファイルを削除しても、レジストリにはアクセス記録が残ることがあります。これが「デジタルの足跡は消しにくい」と言われる理由の一つです。

### 🧠 メモリ（Memory）で何がわかるの？

メモリ（RAM）は電源を切ると消えますが、**調査中は非常に重要な証拠の宝庫**です。

```
メモリを調べると…
✅ 今動いている(動いていた)プログラムの一覧
✅ 暗号化されていたファイルの復号済みデータ
✅ 攻撃者が使ったコマンドの履歴
✅ マルウェア(ウイルス)の動作痕跡
```

> ⚡ **ポイント**: ランサムウェア（身代金を要求するウイルス）などはメモリ上だけで動作することがあります。メモリの解析ができると、そういった高度な攻撃も見つけられます。

### 💾 ディスク（Disk）で何がわかるの？

ハードディスクやSSDには、ファイルを「削除」しても完全には消えない領域があります。

```
ディスクを調べると…
✅ 削除されたファイルの復元
✅ ファイルの作成・変更・アクセス日時（タイムスタンプ）
✅ ブラウザの履歴・ダウンロード記録
✅ ゴミ箱に捨てたファイルの痕跡
```

## なぜ重要なのか

### 🌐 サイバー犯罪捜査には専門家が必要

近年、ランサムウェア・情報漏洩・内部不正など、企業や組織を狙ったサイバー攻撃が急増しています。こうした事件が起きたとき、「**何が起きたのか正確に調べられる人材**」が世界中で不足しています。

### 💼 こんな場面でフォレンジックが活躍する

```
🏢 企業での活用例:
  - 社員が会社の機密情報を持ち出したか調査する
  - ハッカーがいつどこから侵入したか特定する
  - マルウェア感染の経路と範囲を明らかにする

👮 法執行機関での活用例:
  - サイバー犯罪の証拠を裁判で使えるように収集する
  - 詐欺・脅迫などのデジタル証拠を保全する
```

### 📈 資格の市場価値

GCFE資格を持つ専門家は、以下のような職場で高く評価されます：
- セキュリティインシデント対応チーム（CSIRT）
- 警察・検察などの捜査機関
- 大手企業のセキュリティ部門
- サイバーセキュリティ専門のコンサルティング会社

## 対策・今後の展望

### 🛡️ 一般ユーザーへのアドバイス

フォレンジック調査の知識を持つことは、自分自身のセキュリティ意識向上にも役立ちます：

1. **USBメモリの接続履歴は残る** → 会社のPCに私物USBを使うのは注意
2. **削除してもデータは完全には消えない** → 大切なデータを処分するときは専用ソフトで完全削除を
3. **ブラウザの履歴は調べられる** → 閲覧履歴の管理をしっかりと
4. **タイムスタンプは改ざん検知に使われる** → 意図的な改ざんは専門家に見抜かれる

### 🚀 セキュリティ業界を目指す人へ

デジタルフォレンジックは、日本でも非常に需要が高まっている分野です。興味があれば：

- **無料で学べる入口**: 「Autopsy」（無料フォレンジックツール）で基礎を体験
- **日本の資格**: 情報処理安全確保支援士（登録セキスペ）もフォレンジック知識が問われる
- **SANS FOR500**: 本格的に目指すなら世界標準の資格へ

## 用語解説

| 用語 | 意味 |
|------|------|
| **デジタルフォレンジック** | コンピューターに残ったデジタルの証拠を調べる技術・学問 |
| **SANS Institute** | 世界最大手のサイバーセキュリティ教育・資格機関（米国） |
| **GCFE** | GIAC認定フォレンジック試験官。Windowsフォレンジックの国際資格 |
| **レジストリ** | Windowsの設定や使用履歴が記録される巨大なデータベース |
| **アーティファクト(Artifact)** | デジタル調査の文脈で「証拠となるデータの痕跡」のこと |
| **RAM(メモリ)** | パソコンが一時的にデータを置く作業場所。電源を切ると消える |
| **タイムスタンプ** | ファイルの「作成・変更・アクセスした日時」の記録 |
| **マルウェア** | 悪意のあるソフトウェアの総称（ウイルス・ランサムウェアなど） |
| **ランサムウェア** | ファイルを暗号化して「元に戻したければお金を払え」と脅すウイルス |
| **インシデント対応** | セキュリティ事故が起きたときの調査・復旧・再発防止の一連の作業 |
| **ゼロデイ脆弱性** | まだ修正パッチが出ていない、発見されたばかりのセキュリティホール |
