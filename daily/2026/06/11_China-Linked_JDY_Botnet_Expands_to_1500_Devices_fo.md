# 中国と繋がる「JDYボットネット」が1,500台以上に拡大！インターネット上の偵察活動が活発化

**元記事**: [China-Linked JDY Botnet Expands to 1,500+ Devices for Cyber Reconnaissance](https://inl03.netline.com/ltr6/?_m=3n.009a.4001.sp0ao46r89.31ys)
**解説日**: 2025年7月11日

---

## 背景知識

このニュースを理解するために、まず3つの基本的な概念を押さえておきましょう。

### 🏠 SOHOデバイスとIoTデバイスって何？

**SOHOデバイス**（Small Office / Home Office）とは、自宅や小さなオフィスで使うネットワーク機器のことです。
- 例：Wi-Fiルーター、ファイアウォール（外部からの不正接続を防ぐ機器）など

**IoTデバイス**（Internet of Things = モノのインターネット）とは、インターネットに繋がる家電・機器全般です。
- 例：防犯カメラ、スマートテレビ、監視カメラ（Hikvision）など

これらの機器は「パソコンよりセキュリティが弱い」ことが多く、ハッカーに狙われやすいのです。

---

### 🤖 ボットネットって何？

「ボット（bot）」とは、ハッカーに乗っ取られてリモート操作できるようになった機器のことです。これが大量に集まったネットワークを **「ボットネット（botnet）」** と呼びます。

> **例え話**：ゾンビ映画を想像してみてください。ウイルスに感染した人たちが、ゾンビの親玉の命令に従って動く集団が「ボットネット」です。感染した機器の持ち主は、自分の機器が悪用されていることに気づかないことがほとんどです。

---

### 🕵️ 偵察（サイバーリコン）って何？

ハッカーが本格的な攻撃をする前に、まず「どこに弱点があるか？」を調査する活動です。
泥棒が家に侵入する前に、「鍵が開いている窓はないか」と家の周りをぐるっと見て回る行動に似ています。

---

## 何が起きたのか

セキュリティ企業 **Lumen の Black Lotus Labs** が、中国系のハッカー集団と繋がりがある **「JDY ボットネット」** が急拡大していることを警告しました。

### 📊 ポイントまとめ

| 項目 | 内容 |
|------|------|
| ボットネット名 | JDY（別名：KV-ボットネットの一部） |
| 感染台数 | 2024年1月時点の**650台**→現在**1,500台以上**に倍増！ |
| 感染機器の場所 | アメリカ・ブラジルが最多、ヨーロッパ・アジアも |
| 主な目的 | インターネット上の脆弱な機器を探す「大規模偵察活動」 |
| 疑われる背後の勢力 | 中国の国家支援を受けたハッカー集団（例：**Volt Typhoon**） |

### 📅 時系列で整理すると…

```
2023年12月  → JDYがKVボットネットの一部として初めて発見される
2024年初頭  → アメリカ政府がKVボットネットを摘発・解体
2024年以降  → JDYが独自に活動を再開・規模を拡大
現在        → 1,500台超の機器を感染させるまでに成長
```

## 技術的な詳細

### 🔍 JDYボットネットの「仕組み」を図解

```
【ハッカー（中国系）】
        ↓ Torネットワーク経由で匿名で指示
【C2サーバー（司令塔）】
        ↓ 「どこを偵察しろ」という命令を送る
【感染した1,500台以上のSOHO/IoT機器】
        ↓ 世界中のインターネットをスキャン
【脆弱な機器・システムのリストを作成】
        ↓ スキャン結果を中央サーバーへ報告
【ハッカーが結果を分析して次の攻撃対象を選ぶ】
```

### 🦠 どうやって機器に感染するの？

1. **新しく公開された脆弱性（セキュリティの穴）** を悪用します
   - 例：CVE-2026-35616 という識別番号がついた脆弱性
2. 感染すると、まず「シェルスクリプト」（コンピュータへの命令書）がダウンロードされます
3. マルウェア（悪意あるソフト）が機器の中で動き始めます
4. **証拠隠滅のため、マルウェアのファイルはディスクから自動的に削除されます**（見つかりにくくするため！）

### 🛡️ なぜ検知されにくいの？

ハッカーが使う巧妙な手口が2つあります：

**①地理的フィルタリングをすり抜ける**
> 「アメリカのIPアドレスからの通信は怪しくない」と思わせることができます。アメリカ国内の一般家庭のルーターが踏み台になっているので、企業のセキュリティシステムが「普通の通信」と誤認してしまうのです。

**②スキャン活動を分散させる**
> 1台のIPアドレスから大量のスキャンをすると「怪しい」と検知されます。でも1,500台以上に分散させれば、1台あたりの活動量が少なくなり、ブロックリストに載りにくくなります。

## なぜ重要なのか

### 🌏 国家レベルのサイバー攻撃の準備段階

このボットネットの目的は「今すぐ攻撃すること」ではなく、**「将来の攻撃のための下準備（偵察）」** です。

電力会社・水道・通信インフラなど、社会の重要なシステムの「弱点リスト」が作られている可能性があります。

> **例え話**：戦争が始まる前に敵国の地図を詳しく作るような行為です。いつでも攻撃できるように情報を集めているわけです。

### 🏠 一般家庭も無関係ではない

感染している機器の多くは **普通の家庭や小さなオフィスのルーター** です。
つまり、知らないうちに**あなたの家のルーターが中国のハッカーの「手下」になっているかもしれない**のです。

### 📈 スケールの大きさが問題

- 2024年初頭：650台
- 現在：1,500台以上
- **約1年で2倍以上に拡大**しており、拡大傾向が続いています

## 対策・今後の展望

### ✅ 一般ユーザーができる対策

#### 今すぐできること
- [ ] **ルーターのファームウェア（内部ソフト）を最新版に更新する**
  - ルーターの管理画面（通常 192.168.1.1 や 192.168.0.1）からアップデート確認
- [ ] **デフォルトのパスワードを変更する**
  - 「admin/admin」「admin/password」などの初期パスワードは絶対NG！
- [ ] **使っていない機器の電源を切る・ネットから切断する**
- [ ] **購入から数年経ったルーターはサポート終了していないか確認する**
  - サポートが終わった機器は新しいセキュリティパッチが出ないため危険です

#### 機器選びの際のポイント
- セキュリティアップデートが定期的に提供されるメーカーの製品を選ぶ
- 今回感染が確認されたブランド（Hikvision、Linksys、Ubiquitiなど）の機器は特に注意

### 🔭 今後の展望

- アメリカ政府が2024年初頭に一度ボットネットを解体しましたが、**ゾンビのように復活して拡大しています**
- セキュリティ企業や政府機関が監視を強化していますが、いたちごっこの状態です
- 中国の国家支援ハッカーによる活動は今後も続くと予測されており、インフラへの攻撃リスクは高まっています

## 過去記事との関連

今回の記事に登場する「KV-ボットネット」は、2023年末に発見され、2024年初頭にアメリカ政府が摘発した中国系ボットネットです。その際、同じく中国のハッカー集団 **「Volt Typhoon（ボルトタイフーン）」** による活動として大きく報道されました。

今回の JDY ボットネットはその後継・派生版とも言える存在で、一度叩かれても活動を再開・拡大しているという点が重要です。「摘発しても終わらない」サイバー攻撃の継続性を示す事例となっています。

## 用語解説

| 用語 | 意味 |
|------|------|
| **ボットネット（Botnet）** | ハッカーに乗っ取られた機器の集合体。遠隔操作で一斉に動かせる |
| **SOHO** | Small Office/Home Office。自宅や小規模オフィス向けのネットワーク機器 |
| **IoTデバイス** | インターネットに繋がる家電・機器全般（防犯カメラ、スマート家電など） |
| **C2サーバー** | Command & Control Server（司令塔サーバー）。ボットへ命令を送る |
| **脆弱性（CVE）** | ソフトウェアやハードウェアのセキュリティ上の欠陥。CVEは識別番号 |
| **ファームウェア** | 機器の中に組み込まれたソフトウェア。ルーターのOSのようなもの |
| **Tor（トーア）** | 通信経路を匿名化するネットワーク。ハッカーが身元を隠すために利用 |
| **フィンガープリンティング** | 機器の種類やバージョンを遠隔から特定する技術 |
| **ジオフェンシング** | IPアドレスの地域情報をもとにアクセスを制限するセキュリティ手法 |
| **Volt Typhoon** | 中国政府と繋がりがあるとされるハッカー集団の名称 |
| **マルウェア** | 悪意を持って作られたソフトウェアの総称（ウイルス・スパイウェアなど） |
| **偵察（リコン）** | 本格的な攻撃の前に行う、標的の情報収集活動 |
