# LLMエージェントを使ってSalesforceサイトをハッキングする

**元記事**: [Hacking Salesforce Sites With an LLM Agent](https://inl03.netline.com/ltr6/?_m=3n.009a.4001.sp0ao46r89.31yy)
**解説日**: 2025年6月12日

---

## 背景知識

このニュースを理解するために、まずいくつかのキーワードを押さえておきましょう。

### 🏢 Salesforceとは？
Salesforce（セールスフォース）は、企業が顧客情報・営業データ・取引履歴などを管理するために使う**クラウドサービス**です。世界中の大企業が使っており、「顧客の名前・メールアドレス・購入履歴・クレジットカード情報」などの**超重要なデータ**が詰まっています。学校で例えると、生徒全員の成績・住所・家族情報が入った「最重要データベース」のようなものです。

### 🤖 LLM（大規模言語モデル）とは？
ChatGPTやClaudeのような**AI（人工知能）**のことです。文章を読んで理解し、自分で考えて回答を生成できます。最近では「コードを書く」「脆弱性を見つける」といった高度な作業もできるようになっています。

### 🕵️ セキュリティ診断（ペネトレーションテスト）とは？
「自社のシステムに攻撃してみて、穴（脆弱性）がないか確認する」作業のことです。本来はセキュリティ専門家が何日もかけて行うものですが、今回はAIがそれを**自動でやってしまう**というのがポイントです。

### 🔓 脆弱性とは？
システムの「弱点」や「穴」のことです。泥棒に例えると「鍵のかかっていない窓」のようなものです。

---

## 何が起きたのか

セキュリティ企業「**Reco**」の研究チームが、AIを使って**Salesforceのサイトを自動でハッキングするエージェント（AIプログラム）**を作り、実際に動かしてみました。

結果は**非常に衝撃的**でした。

> 「セキュリティに多大な投資をしている大手テクノロジー企業のSalesforceサイトで、**深刻な脆弱性を発見した**」

つまり、「うちはちゃんとセキュリティ対策してるから大丈夫」と思っていた企業のシステムにも、AIが穴を見つけてしまったのです。

また、ハッカーグループ「**ShinyHunters**」がすでに似たような手法で、数千ものSalesforceサイトをスキャン（調査）していたことも明らかになっています。

## 技術的な詳細

### AIエージェントの5つの攻撃フェーズ

このAIは人間のセキュリティ専門家と同じ手順で動きます。URLを1つ渡すだけで、あとは全部自動です。

```
[URLを渡す] → [AI が全部やる] → [脆弱性発見＆データ抜き取り完了]
```

#### 📡 フェーズ1：偵察（どこに何があるか調べる）
まず「このサイトには何が公開されているか？」を調べます。
- データベースのテーブル一覧（何の情報が入っているか）
- サーバー側の処理プログラム（どんな操作ができるか）
- 公開ページの一覧

これは「泥棒が建物の周りをぐるっと歩いて、入口・窓・非常口を全部メモする」作業に相当します。

#### 🔍 フェーズ2：データ分析（どのデータが危険か評価する）
次に「どのデータが重要か？」を判断します。

| 優先度高（狙われやすい） | 優先度低 |
|---|---|
| Contact（顧客連絡先） | BlogPostEntry（ブログ記事） |
| Lead（見込み客情報） | - |
| CreditCardTransaction（クレカ取引） | - |

AIは「クレジットカードの取引データ」と「ブログ記事」を比べて、**自分で「こっちが重要だ」と判断**します。人間と同じように優先順位をつけられるのです。

#### 💥 フェーズ3〜5：攻撃・実行・検証
脆弱性を見つけたら、攻撃コードを**自分でゼロから書いて**、実際に実行して、データが取れたか確認します。さらに必要に応じてインターネット上の公開情報も使いながら攻撃を組み立てます。

### 🔄 柔軟に動くのが最大の特徴

普通のプログラムは「手順1→手順2→手順3」と決まった順番でしか動きません。でもこのAIは「うまくいかなかったから別の方法を試そう」と**自分で判断して戦略を変えられます**。まるで経験豊富なハッカーが試行錯誤するような動き方です。

## なぜ重要なのか

### ⚠️ 「難しすぎて攻撃できない」がもう通用しない

これまでは「この脆弱性は複雑すぎて、悪用するには高い技術が必要だから大丈夫」という考え方がありました。しかしLLMを使えば、技術力の低い攻撃者でも**複雑な脆弱性を自動で見つけて悪用**できるようになります。

### 🌍 影響を受ける可能性がある人たち

Salesforceは世界中の企業が使っています。もし攻撃が成功すると…

- 顧客の**個人情報が流出**（名前・住所・電話番号）
- **クレジットカード情報が盗まれる**
- 企業の**機密ビジネス情報が漏れる**

被害を受けるのは企業だけでなく、そのサービスを使っている**一般の人たち**も含まれます。

### ⏱️ 攻撃のスピードが桁違いに速くなる

人間のセキュリティ専門家がやれば数日かかる作業が、AIなら**数分〜数時間**で完了します。攻撃者はこれを使って大量のサイトを一気に調査・攻撃できてしまいます。

## 対策・今後の展望

### 🛡️ 企業がすべき対策

| 対策 | 内容 |
|---|---|
| **ゲストユーザーの権限を最小限に** | ログインしていない人に見せる情報を必要最小限にする |
| **定期的なセキュリティ診断** | 今回のようなAIツールを使って自社の穴を先に見つける |
| **アクセスログの監視** | 不審なスキャン行為を早期に検知する |
| **Salesforce設定の見直し** | 不要な公開エンドポイントを閉じる |

### 🔮 今後どうなる？

- **攻撃側**：今後さらに高度なAI攻撃エージェントが登場するでしょう
- **防御側**：AIを使って攻撃を自動検知・防御する「AI vs AI」の時代が来ています
- この記事自体が「**防御のためにAI攻撃の実態を公開する**」という研究であり、セキュリティ業界全体への警鐘です

> 💡 **ポイント**: 「AIを使えば誰でも高度な攻撃ができる時代」に入ったということを、セキュリティ担当者は強く認識する必要があります。

## 過去記事との関連

以前、**OceanLotus（ベトナムの投資家をSPECTRALVIPERで狙った攻撃）**について解説しましたが、あちらは「特定の標的を絞った国家レベルの高度な攻撃（APT）」でした。

今回の記事はそれとは少し方向性が違い、「**AIを使って不特定多数のサイトを自動スキャン・攻撃する**」という話です。

両者に共通しているのは、**「攻撃の自動化・効率化が進んでいる」**という点です。国家レベルの攻撃者も、一般的なハッカーグループも、どちらもAIや自動化ツールを積極的に取り込んでいます。セキュリティの脅威が「特別な技術を持つ一部の人間だけのもの」ではなくなりつつある、という流れが読み取れます。

## 用語解説

| 用語 | 説明 |
|---|---|
| **LLM（大規模言語モデル）** | ChatGPTやClaudeのような、文章を理解・生成できるAI |
| **Salesforce** | 企業が顧客情報を管理するためのクラウドサービス |
| **エージェント（AIエージェント）** | 目標を与えると自分で考えて行動するAIプログラム |
| **脆弱性（ぜいじゃくせい）** | システムのセキュリティ上の穴・弱点 |
| **偵察（Reconnaissance）** | 攻撃前にターゲットの情報を集める作業 |
| **エクスプロイト** | 脆弱性を実際に悪用する攻撃コード・手法 |
| **エンドポイント** | サーバーにアクセスするための「窓口」となるURL |
| **ゲストユーザー** | ログインせずにサービスを利用する匿名のユーザー |
| **ペネトレーションテスト** | 許可を得てシステムに擬似攻撃し、脆弱性を調べる作業 |
| **ShinyHunters** | 大規模なデータ漏洩事件を複数起こしているハッカーグループ |
| **AuraInspector** | SalesforceのAuraフレームワークを調査するためのツール |
| **APT（Advanced Persistent Threat）** | 国家などが背景にある高度で持続的なサイバー攻撃 |
