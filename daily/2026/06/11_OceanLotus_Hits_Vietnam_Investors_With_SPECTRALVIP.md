# OceanLotusがベトナムの投資家をSPECTRALVIPERで標的に ～FireAnt攻撃の全容～

**元記事**: [OceanLotus Hits Vietnam Investors With SPECTRALVIPER in FireAnt Attack](https://inl03.netline.com/ltr6/?_m=3n.009a.4001.sp0ao46r89.31ya)
**解説日**: 2026年6月12日

---

## 背景知識

まず、この記事を理解するためにいくつかのキーワードを押さえておきましょう。

### 🌐 APT（Advanced Persistent Threat）とは？
「高度で執拗な脅威」という意味です。普通のハッカーとは違い、**国家や大きな組織に支援された超プロのハッカー集団**のことです。一度ターゲットを決めたら、何ヶ月・何年もかけて攻撃を続けるのが特徴です。

### 🐙 OceanLotusとは？
ベトナム政府と関係があると疑われているAPT集団です。2012年から活動しており、**主にベトナム国内外の政府機関・企業・人権活動家**などを標的にしてきました。別名「APT32」とも呼ばれています。

### 📦 サプライチェーン攻撃とは？
直接ターゲットを攻撃するのではなく、**ターゲットが使っているソフトウェアや部品を汚染する攻撃**です。  
例え話：お弁当屋さん（目標）を直接攻撃する代わりに、お弁当の材料を届ける業者（ソフトウェアの更新サーバー）に毒を仕込む、というイメージです。

### 🔥 FireAnt Metakitとは？
ベトナムの株式投資家の間で広く使われている**人気の投資管理ソフトウェア**です。このソフトが今回の攻撃の踏み台にされました。

### 🐍 バックドアとは？
ソフトウェアやシステムに仕込まれた**「裏口」**のことです。攻撃者はこの裏口を使って、被害者のパソコンに気づかれずに侵入し、情報を盗んだり操作したりできます。

## 何が起きたのか

今回の記事では、**2つの攻撃キャンペーン**が明らかになりました。

### 攻撃① インフラ・運輸建設会社への長期スパイ活動
- **期間**: 2024年半ば〜2026年2月
- **標的**: ベトナムのインフラ・運輸建設会社
- 長期間にわたってこっそりと**企業内情報を盗み見する「サイバースパイ活動」**が行われていました

### 攻撃② FireAnt Metakitを使ったサプライチェーン攻撃
- **期間**: 2025年10月〜2026年3月
- **標的**: ベトナムの株式投資家たち
- FireAnt Metakitという**人気投資ソフトの更新機能を乗っ取り**、悪意あるプログラム（SPECTRALVIPER）をこっそり配布していました

どちらの攻撃も、スロバキアのサイバーセキュリティ企業「ESET」が調査・報告しました。

## 技術的な詳細

### 🔄 サプライチェーン攻撃の仕組み（ステップで解説）

```
【正常な更新の流れ】
投資家のPC → FireAntのサーバーに更新確認 → 安全なsetup.exeをダウンロード → インストール完了

【攻撃された更新の流れ】
投資家のPC → 乗っ取られたサーバーに更新確認 → 悪意あるsetup.exeをダウンロード
→ ①ホスト情報を収集してC2サーバーへ送信
→ ②不正DLLを実行（DtlCrashCatch.dll）
→ ③OneDrive.Sync.Service.exeに寄生
→ ④SPECTRALVIPERが起動して完全に乗っ取り完了
```

### ⚠️ なぜ気づかれなかったのか？
**「署名検証がなかった」**ことが最大の問題です。

> 🔑 **署名検証**とは？  
> ソフトウェアに「本物の開発者が作ったもの」というデジタルの印鑑（署名）がついていることを確認する仕組みです。これがないと、**改ざんされたファイルでも正規品として受け入れてしまいます**。

FireAnt Metakitの更新設定ファイル（`version.xml`）には、この署名検証の仕組みが**まったく存在しなかった**ため、悪意あるファイルがそのまま正規の更新として実行されてしまいました。

### 🦠 SPECTRALVIPERとは？
OceanLotusが使うバックドア型マルウェアです。2023年にElastic Security Labsが初めて発見しました。感染すると：
- 被害者のPCの情報を暗号化して攻撃者のサーバーに送信
- 攻撃者が遠隔でPCを操作できる状態になる

### 🎯 攻撃の特徴：「選択的」なターゲティング
全ての投資家が標的になったわけではなく、**特定の少数のユーザーのみ**に悪意あるファイルが配布されました。これは「目立たないよう、慎重に狙いを絞る」という高度な戦術です。

## なぜ重要なのか

### 1️⃣ 国内向けスパイ活動へのシフト
これまでOceanLotusは中国など**外国**を標的にすることも多かったのですが、今回は**ベトナム国内の一般企業や個人投資家**が標的になっています。「国内監視活動の強化」という新たな方向性が見えており、非常に重要な変化です。

### 2️⃣ 一般人が巻き込まれるリスク
これまでのAPT攻撃は主に政府や大企業が標的でした。しかし今回は**株式投資家という一般市民**が標的になっています。誰もが被害者になり得る時代に入ってきています。

### 3️⃣ 15年以上活動を続けるしぶとさ
2012年から活動し、2020年に正体が暴かれても約3年で復活。今も新しい手口で攻撃を続けています。

### 4️⃣ PyPI（Pythonライブラリ配布サイト）への波及
カスペルスキー（ロシアのセキュリティ企業）は最近、OceanLotusと関係する悪意あるPythonパッケージを発見しました。プログラマーが日常的に使うライブラリ配布サイトにも手を伸ばしており、**IT技術者も標的になりうる**ことがわかります。

## 対策・今後の展望

### ✅ ユーザーができる対策

| 対策 | 理由 |
|------|------|
| ソフトウェアは**公式サイト**から直接ダウンロード | 不正なミラーサイトを避けるため |
| セキュリティソフトを常に最新の状態に保つ | 既知マルウェアの検出率を上げるため |
| 不審な通信やプロセスに注意する | バックドア活動の早期発見のため |
| 投資ソフトなど金融系アプリは特に慎重に扱う | 金融情報は攻撃者に狙われやすいため |

### ✅ ソフトウェア開発者が取るべき対策
- **デジタル署名の導入**：更新ファイルに必ず署名をつけ、改ざんを検出できるようにする
- **ハッシュ値の検証**：ダウンロードしたファイルが本物かを確認する仕組みを実装する
- **更新サーバーのセキュリティ強化**：攻撃者に乗っ取られないよう厳重に管理する

### 🔮 今後の展望
ESETの報告では、2026年3月9日以降は悪意ある更新の配布が止まっています。ただし、OceanLotusが活動を完全に終了したのか、それとも次の作戦に向けて静かに準備しているのかは不明です。15年以上続くこの集団が簡単に引き下がるとは考えにくく、**引き続き監視が必要**です。

## 過去記事との関連

以前「**AIが脆弱性管理を壊した。だからセキュリティ責任者は予算をBAS（攻撃シミュレーション）に移している**」という記事を解説しました。

今回のOceanLotus事例はまさにその文脈と重なります。FireAnt Metakitの「署名検証がない」という脆弱性は、従来型のセキュリティツールでは見逃されがちなものです。BAS（Breach and Attack Simulation：実際の攻撃を模擬してシステムの穴を見つける手法）のようなアプローチを使えば、「更新ファイルを改ざんされたらどうなるか？」というシナリオを事前にテストでき、このような攻撃を未然に防げる可能性があります。**「攻撃者の視点で考える」ことの重要性**が、今回の事件からも改めて浮かび上がってきます。

> 💡 **まとめ**  
> 今回の事件は「信頼していたソフトの更新機能が攻撃に使われた」というとても怖いケースです。私たちがいつも使っているアプリも、同じリスクを抱えている可能性があります。「有名なソフトだから安全」という思い込みは危険で、**ソフトウェア開発者がセキュリティの基本（署名検証など）をしっかり実装することの重要性**が改めて問われています。
