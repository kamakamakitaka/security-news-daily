# ユーロポールが暗号資産マネーロンダリングサービス「AudiA6」を摘発！ランサムウェアグループが使用

**元記事**: [Europol Disrupts AudiA6 Crypto Laundering Service Used by Ransomware Gangs](https://inl03.netline.com/ltr6/?_m=3n.009a.4002.sp0ao46r89.3206)
**解説日**: 2026年6月13日

---

## 背景知識

まず、このニュースを理解するためのキーワードを確認しましょう。

### 🏦 マネーロンダリング（資金洗浄）とは？
「汚いお金をきれいに見せる行為」です。たとえば、犯罪で盗んだお金をそのまま使うと警察にバレてしまいます。そこで犯罪者は、お金の「出所（どこから来たか）」をわからなくするために、複数の口座や取引を経由させて「合法的に稼いだお金」に見せかけます。これがマネーロンダリングです。

> 🎓 **例え話**：お父さんが盗んだ1万円を、友達の財布→コンビニのレジ→自分の口座へとぐるぐる回すことで「どこから来たかわからないお金」にする、というイメージです。

### 💰 暗号資産（仮想通貨）とは？
ビットコインなどの、インターネット上で使えるデジタルなお金のことです。銀行を通さず送金できるため、犯罪者に悪用されることがあります。

### 🔀 ミキシングサービスとは？
複数の人の暗号資産をごちゃ混ぜにして、「どのお金が誰のものか」を追跡できなくするサービスです。洗濯機で複数人の服を一緒に洗ってバラバラに返す、みたいなイメージです。

### 💻 ランサムウェアとは？
パソコンやサーバーのデータを暗号化（鍵をかけて読めなく）して、「元に戻してほしければお金を払え」と脅す悪質なウイルスです。

### 🌑 ダークウェブとは？
通常のブラウザではアクセスできない、匿名性の高いインターネットの隠れた部分です。犯罪の売買や情報のやり取りに使われます。

## 何が起きたのか

2026年6月10日、ヨーロッパの警察組織「ユーロポール」とアメリカ司法省（DoJ）が協力して、**「AudiA6」という大規模な暗号資産マネーロンダリングサービスを摘発しました**。

### 📋 今回の作戦で行われたこと

| 内容 | 詳細 |
|------|------|
| 👮 逮捕者 | ウクライナ国籍とロシア国籍の管理者2名（ジョージアで逮捕） |
| 🌐 ドメイン削除 | 25個のウェブサイトのアドレスを停止 |
| 🖥️ サーバー押収 | 30台以上のサーバーを押収 |
| 🚗 資産押収 | 車80台以上・複数の不動産（ジョージア国内） |
| 💸 資産凍結 | 約1億円相当（€692,000）の暗号資産を凍結 |
| 📱 Telegram遮断 | 犯罪ネットワークが使用したアカウントを停止 |

逮捕されたのは、**ルスラン・イゴレヴィッチ・トカチュク（37歳）**と**アレクサンドル・ウラジミロヴィッチ・レデネフ（25歳）**の2名。有罪となれば、最大**懲役20年**が科される可能性があります。

## 技術的な詳細

### AudiA6はどうやって「お金を洗浄」していたのか？

```
【犯罪者の流れ】
  ┌──────────────────────────────────────────────┐
  │  ① ランサムウェアなどで盗んだ暗号資産を       │
  │     AudiA6のウォレット（財布）に送金           │
  │                ↓                             │
  │  ② AudiA6が複数の架空口座を経由させて         │
  │     「汚いお金の出所」を隠す                   │
  │     （複雑なトランザクションの連鎖）           │
  │                ↓                             │
  │  ③ 1時間以内に「きれいに見えるお金」が        │
  │     戻ってくる（手数料3〜10%を差し引いて）     │
  └──────────────────────────────────────────────┘
```

### 具体的な手口3つ

1. **偽造IDを使った大量の口座開設**
   盗んだり購入したりした他人の個人情報（KYCデータ）を使って、数千もの架空口座を暗号資産取引所に作成。お金の追跡を困難にしました。

2. **マネーミュール（お金の運び屋）の活用**
   ロシア語を話す仲介者を雇い、彼らを通じてお金を移動させることで、主犯の足跡を隠しました。

   > 🎓 **例え話**：自分では運ばず、別の人に「ちょっとこのお金、あっちに届けておいて」と頼む感じです。

3. **プライベートメッセージアプリでの取引**
   TelegramなどのSNSを使って取引を行い、記録が残りにくくしていました。

### 規模感
- **2021年のサービス開始以来、総額336億円以上（約€336百万）を洗浄**
- 10,333ビットコインが預けられ、うち約393BTCが直接ダークウェブ市場やランサムウェア組織から来たものと確認
- **世界15カ国以上の捜査と関連**

## なぜ重要なのか

### 🌍 犯罪エコシステムの「血管」を断ち切った

AudiA6は単なる1つのサービスではなく、世界中のランサムウェアグループや詐欺グループが「稼いだお金を使えるようにする」ための重要なインフラでした。これを止めたことは、犯罪者たちの「資金調達能力」に直接打撃を与えます。

> 🎓 **例え話**：悪の組織の「銀行」を閉鎖させたようなイメージです。お金があっても使えなければ、活動が続けられません。

### 🔗 ダークウェブフォーラムとの二重運営

AudiA6の運営者は「Dark2Web」というダークウェブ上の犯罪フォーラムも管理していたとされています。つまり、**犯罪者同士をつなぐSNS + 資金洗浄サービス**を一体で運営していたわけです。これが摘発されたことで、多くの犯罪ネットワークが同時に打撃を受けました。

## 対策・今後の展望

### 私たちへの影響と対策

今回の摘発は主に大規模犯罪組織に対するものですが、私たちも関係のある教訓があります。

| 教訓 | 私たちにできること |
|------|-----------------|
| 🔐 ランサムウェア対策 | 重要なデータは定期的にバックアップを取る |
| 📧 フィッシング詐欺対策 | 不審なメールのリンクをクリックしない |
| 🆔 個人情報の保護 | 身分証明書の写真を安易に送らない（マネーミュールに悪用される） |
| 💻 KYC情報の管理 | 信頼できる取引所以外で個人情報を提供しない |

### 今後の展望

- ユーロポールは2025年9月にポーランド警察がウクライナ人を逮捕したことをきっかけに、その人物のデバイスを解析→芋づる式に関係者を特定する流れでこの作戦につながりました。**デジタル証拠の分析が今後の国際捜査の鍵**になっています。
- 暗号資産を使った犯罪への国際的な取り締まりはますます強化されており、犯罪者が「安全に逃げられる場所」は着実に狭まっています。

## 過去記事との関連

以前、**INTERPOLが「Sniper Dz」というフィッシング犯罪プラットフォームを摘発・管理者を逮捕した**というニュースを解説しました。

今回のAudiA6摘発と合わせると、**国際的な法執行機関が犯罪インフラ全体を狙い撃ちにする動き**が続いていることがわかります。

```
【犯罪の流れと摘発の関係】

Sniper Dz（フィッシング）  →  お金を騙し取る
       ↓
  AudiA6（ロンダリング）   →  そのお金を「きれいに」する
       ↓
    摘発！摘発！
```

- Sniper Dzは「犯罪でお金を稼ぐ入口」
- AudiA6は「稼いだお金を使えるようにする出口」

この両方が摘発されることで、サイバー犯罪の「入口から出口まで」が締め上げられています。国際的な協力捜査の成果が出てきている流れと言えるでしょう。
