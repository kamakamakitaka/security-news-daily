# INTERPOL作戦が「Sniper Dz」フィッシング犯罪プラットフォームを壊滅・管理者を逮捕

**元記事**: [INTERPOL Operation Takes Down Sniper Dz Phishing Platform, Arrests Administrator](https://inl03.netline.com/ltr6/?_m=3n.009a.4002.sp0ao46r89.3200)
**解説日**: 2025年6月

---

## 背景知識

今回のニュースを理解するために、まずいくつかの重要な概念を説明します。

### 🎣 フィッシング詐欺とは？
「フィッシング（Phishing）」とは、本物そっくりの**偽サイト**や**偽メール**を使って、パスワードやクレジットカード番号などの個人情報をだまし取る攻撃です。

たとえば、「PayPalからのお知らせ」に見せかけたメールを送り、リンクをクリックさせると、本物とそっくりな偽サイトに誘導されます。そこでパスワードを入力してしまうと、情報がまるごと盗まれてしまいます。

### 🛒 PhaaS（フィッシング・アズ・ア・サービス）とは？
「PhaaS（Phishing-as-a-Service）」は、フィッシング詐欺をやろうとしている人に「ツール一式」をサービスとして提供する仕組みです。

わかりやすく言うと、まるで**フィッシング詐欺の「フランチャイズ」**のようなものです。

> 📦 普通のフランチャイズ：「お金を払えば、お店のブランドや調理マニュアル、設備を一式貸します」
>
> 📦 PhaaS：「フィッシングの偽サイトのテンプレート、メール送信ツール、サーバーを一式提供します」

これにより、技術的な知識がほとんどない人でも、簡単に詐欺を実行できてしまうのが問題です。

### 🌐 INTERPOLとは？
**INTERPOL（インターポール）**とは、世界各国の警察が協力して国際犯罪に対処するための国際機関です。日本語では「国際刑事警察機構」といいます。サイバー犯罪のように国境をまたぐ犯罪に対して、各国が共同で捜査します。

---

## 何が起きたのか

2025年10月〜2026年2月にかけて、INTERPOLが主導した **「オペレーション・ラムズ（Operation Ramz）」** という作戦が実施されました。

この作戦の結果：

| 成果 | 内容 |
|------|------|
| 🚔 逮捕者数 | 中東・北アフリカ13か国で **201人** を逮捕 |
| 👨‍💻 主犯逮捕 | プラットフォーム開発者・管理者「Guedz」をアルジェリア警察が逮捕 |
| 🌐 サイト閉鎖 | PhaaS犯罪プラットフォームを閉鎖 |
| 💾 証拠押収 | フィッシングソフトウェア・スクリプトを含むハードウェアを押収 |

壊滅したのは **「Sniper Dz（スナイパーDz）」** というフィッシング犯罪プラットフォームです。2015年頃から活動し、長年にわたって「Joker Dz」「Storm Dz」「Spam Dz」など名前を変えながら活動を続けてきた悪質なサービスです。

## 技術的な詳細

### Sniper Dzはどんなプラットフォームだったのか？

このサービスの特徴を、具体的に見ていきましょう。

#### 🎁 「無料」で使えた
多くのPhaaS（フィッシング詐欺サービス）は利用料金を取りますが、Sniper Dzは**完全無料**でサービスを提供していました。これが他と比べて際立っていた点です。

では、運営者は何で稼いでいたのでしょうか？

```
【Sniper Dzの収益モデル】

利用者が詐欺で集めた情報
        ↓
  運営者もこっそり収集
        ↓
 運営者が別途活用・販売

また、情報を盗めなかった被害者は…
        ↓
「キャリア課金詐欺」や「プレミアムSMS詐欺」に誘導
        ↓
    そこからも収益
```

つまり、「無料で使わせる代わりに、被害者の情報の一部を運営者が横取りする」という仕組みでした。

#### 🎣 狙われたサービス・組織

主に以下のような有名サービスを偽装していました：

- 💳 **PayPal**（決済サービス）
- 📘 **Facebook / Instagram**（SNS）
- 📧 **Yahoo**（メール）
- 🎬 **Netflix**（動画配信）
- 🎮 **Steam**（ゲームプラットフォーム）

合計で**30以上の主要組織**のブランドを偽造した**80種類のテンプレート**が用意されており、アラビア語・英語・フランス語・スペイン語・ヘブライ語の5か国語に対応していました。

#### 📱 Telegramを使った拡散

Sniper Dzは**Telegram（テレグラム）**というメッセージアプリのチャンネル（登録者数7,300人以上）を使って、使い方のチュートリアル動画を配布していました。まるで普通のアプリサービスのように、サポートまで提供していたのです。

#### 👤 SNSでの偽装工作

さらに高度な手口として、中東・北アフリカで知名度のある**政治家や公人のなりすましアカウント**をSNSに作成し、「特別オファー」や「無料インターネット」のように見せかけたフィッシングリンクを拡散していました。

## なぜ重要なのか

### 📊 被害の規模が巨大

- 被害者記録：**45,000件以上**
- 関連ドメイン（偽サイトのURL）：**20,000以上**
- 活動期間：**約10年間**

これだけの規模で長期間にわたって活動していたサービスが初めて壊滅したことは、国際的なサイバー犯罪対策において非常に大きな前進です。

### 🌍 「サービス化」された犯罪の危険性

PhaaS（フィッシング・アズ・ア・サービス）の本当の怖さは、**「素人でも犯罪者になれてしまう」**点です。

> 昔：詐欺サイトを作るには、高いプログラミングスキルが必要
> 今：テンプレートを選んでボタンを押すだけで詐欺サイトが完成

犯罪の「民主化」とも言える現象で、こうしたインフラが存在するだけで、世界中で被害が増え続けてしまいます。

### 🤝 13か国が協力した意義

サイバー犯罪者は、法律の異なる国に拠点を置いて捜査を逃れようとします。今回のように多くの国が協力して一斉に動いたことは、「国際的な連携でサイバー犯罪者を追い詰めることができる」という大きなメッセージになります。

## 対策・今後の展望

### 🛡️ 私たちにできる対策

| 対策 | 具体的な方法 |
|------|------------|
| **URLをよく確認する** | 本物のサイトかどうか、アドレスバーのURLをよく見る（例：`paypa1.com` など微妙に違う場合がある） |
| **メールのリンクを直接クリックしない** | メールに書かれたリンクではなく、ブックマークや検索から公式サイトに行く |
| **多要素認証（MFA）を使う** | パスワードを盗まれても、もう一つの認証があれば不正ログインを防げる |
| **不自然なオファーに注意** | 「無料インターネット！」「特別プレゼント！」などは詐欺の可能性が高い |
| **公式アプリを使う** | ブラウザではなく公式アプリからログインする習慣をつける |

### 🔮 今後の動向

残念ながら、今回のプラットフォームが壊滅しても、**別の後継サービスが生まれる可能性は高い**です。過去にも「Sniper Dz」が「Joker Dz」「Storm Dz」「Spam Dz」と名前を変えて生き残ってきたように、こうした犯罪組織は柔軟に形を変えます。

しかし、今回の作戦で：
- 主要な開発者・管理者が逮捕された
- インフラが物理的に破壊された
- 13か国の連携捜査体制が確立された

これらは、次の犯罪組織への**強い抑止力**になります。

## 過去記事との関連

今回のSniper Dzについては、2024年10月にパロアルト・ネットワークスのセキュリティ研究チーム「Unit 42」が詳細な分析レポートを公開していました。その時点でTelegramチャンネルの存在や、無料でサービスを提供していることなどが明らかになっていました。

今回の逮捕は、こうした**セキュリティ研究者の調査成果が法執行機関の捜査に活かされた**好例と言えます。研究者と警察が連携することで、こうした大規模な摘発が可能になります。

## 用語解説

| 用語 | 解説 |
|------|------|
| **フィッシング（Phishing）** | 本物そっくりの偽サイト・偽メールで個人情報をだまし取る攻撃 |
| **PhaaS（Phishing-as-a-Service）** | フィッシング詐欺のツール・インフラをサービスとして提供する仕組み |
| **INTERPOL（インターポール）** | 国際刑事警察機構。世界各国の警察が協力する国際機関 |
| **フィッシングキット** | 偽サイトを簡単に作れるテンプレートセット |
| **クレデンシャル（Credential）** | IDやパスワードなど、ログインに使う認証情報 |
| **プロキシサーバー** | 通信を中継するサーバー。身元隠しにも使われる |
| **キャリア課金詐欺** | 携帯電話料金に不正な課金を上乗せする詐欺 |
| **多要素認証（MFA）** | パスワード以外にも、スマホへのコード送信などで本人確認する仕組み |
| **ソーシャルエンジニアリング** | 技術的な攻撃だけでなく、人の心理的な弱点をつく騙しのテクニック |
| **Telegram（テレグラム）** | 匿名性が高いメッセージアプリ。犯罪者の連絡手段としても悪用されることがある |

> 💡 **まとめ**：今回の作戦は、10年以上活動してきた大規模なフィッシング犯罪プラットフォームを国際協力で壊滅させた、歴史的な出来事です。ただし、フィッシング詐欺自体はなくなりません。URLをよく確認する・怪しいリンクを踏まない・多要素認証を使う、この3つを日頃から意識することが大切です！
