# 中国系ハッカーが「ログイン機能そのもの」に罠を仕掛け、約10年間も潜伏していた件

**元記事**: [China-Linked Hackers Backdoored Linux Login Software to Hide for Nearly a Decade](https://inl03.netline.com/ltr6/?_m=3n.009a.4003.sp0ao46r89.321e)
**解説日**: 2026年6月13日

---

## 背景知識

まず、この記事を理解するために必要な用語や仕組みを説明します。

### 🐧 Linuxとは？
Windows や macOS と同じ「OS（オペレーティングシステム）」の一種です。企業のサーバーや重要なインフラ（電力・金融・通信など）の多くはLinuxで動いています。私たちが普段使うスマホやパソコンよりも、「裏側で社会を支えるコンピューター」に使われているイメージです。

### 🔐 PAM（Pluggable Authentication Module）とは？
「誰がこのコンピューターにログインできるか」を管理するLinuxの仕組みです。  
玄関の**鍵穴と錠前**のようなもので、すべてのログイン試行はここを通ります。PAMが「OK」と言わないと、どんなユーザーも入れません。

### 🔑 OpenSSHとは？
インターネット越しに安全にコンピューターを遠隔操作するための仕組みです。  
会社のサーバーを自宅から操作するときなどに使います。**「遠隔操作用の安全な扉」**と思ってください。

### 🚪 バックドアとは？
「裏口」という意味で、攻撃者が**正規の認証を無視して侵入できる隠し通路**のことです。正面玄関（ログイン）を使わずに、こっそり家の中に入れる秘密の扉を仕掛けるイメージです。

### 🐜 Velvet Ant（ベルベット・アント）とは？
中国と関係があるとされるハッカーグループの名前です。セキュリティ会社「Sygnia（シグニア）」がこの名前をつけて追跡しています。「ベルベットのアリ」という名前のとおり、**柔らかく静かに、でも執拗に**潜り込むのが特徴です。

## 何が起きたのか

### 📋 事件の概要

セキュリティ会社のSygniaが「**Velvet Ant**」という中国系ハッカーグループの調査結果を発表しました。このグループは驚くべき方法で、**約10年間（2016年頃〜）にわたってシステムに隠れ続けていました**。

彼らがやったことをひとことで言うと：

> **「鍵穴そのものを偽物にすり替えた」**

普通のハッカーはシステムに「マルウェア（悪意のあるソフト）」を新たに入れようとします。しかしVelvet Antは、もともとそこにある**ログイン機能（PAMとOpenSSH）を改ざん（書き換え）**しました。

これは、マンションの管理会社が使うマスターキーを偽物にすり替えるようなもの。住人（ユーザー）は何も気づかず普通に生活していますが、攻撃者はいつでも自由に出入りできる状態になっていたのです。

### 📅 タイムライン

| 時期 | 出来事 |
|------|--------|
| 2016年頃 | 最初の侵入の痕跡 |
| 2024年前半 | F5 BIG-IPという機器を踏み台として悪用 |
| 2024年7月 | Cisco製品の脆弱性（CVE-2024-20399）を悪用 → Ciscoがパッチ公開 |
| 2024年7月翌日 | 米国CISA（サイバーセキュリティ機関）が「実際に悪用された」と警告 |
| 今回 | 「Operation Highland」と名付けられた一連の活動の詳細が明らかに |

## 技術的な詳細

### 🔧 どうやって改ざんしたのか

#### ステップ①：まず「橋頭堡」を確保する
攻撃対象のネットワークはインターネットと直接つながっていない**閉鎖的な環境**でした。そのため攻撃者はまず、インターネットに面した別のサーバー（Webサーバーなど）に侵入し、そこを「踏み台」として内部ネットワークに入り込みました。

```
インターネット → 踏み台サーバー（Webサーバーなど）→ 閉鎖ネットワーク内の標的
```

**例え話**: 厳重なセキュリティの施設に直接入れないので、まず駐車場の警備員小屋に侵入して、そこから内部へ進むイメージです。

#### ステップ②：PAMを「偽物」にすり替える
攻撃者はPAM（ログインを管理するプログラム）を**9種類もの改ざんバージョン**に書き換えました。改ざんされたPAMには2つの機能が仕込まれていました：

- 🗝️ **秘密パスワードで誰でも入れるようにする**（バックドア）
- 📝 **本物のユーザーがログインするたびにパスワードを盗み記録する**（クレデンシャルハーベスティング）

#### ステップ③：OpenSSHも同様に改ざん
OpenSSH（遠隔操作ツール）も書き換えられ、以下の機能が追加されました：

- 📋 ログインしたユーザーの**IDとパスワードをすべて記録**
- ⌨️ ユーザーが**打ったコマンド（命令）をすべて記録**
- 🔕 必要なときだけ記録をオフにできる**隠しスイッチ**

#### ステップ④：なぜ見つからなかったのか
- **新しいファイルを追加していない**ので、ウイルスチェックソフトが反応しない
- **もともとあった信頼されたプログラムを改ざんしただけ**なので、一見すると正常に見える
- **ログインシステム自体が攻撃者のもの**なので、パスワードを変えても意味がない

> 💡 **わかりやすい例え**: 銀行の金庫を守るはずの警備員が、実は強盗の仲間だった場合、警報を鳴らしても意味がないのと同じです。

## なぜ重要なのか

### 🌐 影響の大きさ

| 項目 | 内容 |
|------|------|
| 潜伏期間 | **約10年**（2016年〜） |
| 対象 | Linuxを使う企業・組織のサーバー全般 |
| 被害の種類 | パスワード盗難・コマンド盗聴・長期的な不正アクセス |
| 発見の難しさ | 通常のセキュリティ対策では**ほぼ検知不可能** |

### ⚠️ 特に怖いポイント3つ

1. **パスワードを変えても意味がない**  
   ログインシステム自体が汚染されているので、新しいパスワードを設定した瞬間にそれも盗まれます。

2. **セッションを切っても意味がない**  
   攻撃者は秘密パスワードでいつでも再接続できます。

3. **10年間誰も気づかなかった**  
   「信頼されているプログラム」を悪用するという発想が、従来のセキュリティ監視の盲点をついています。

### 🏗️ 「Operation Highland」が示すもの
このグループは毎回、**「誰も監視していない場所」に移動して潜む**という戦略をとっています：

```
発見される → 別の「誰も見ていない機器・ソフト」に移動 → また潜伏
     ↑_______________________________________________↓
```

- 過去：**F5 BIG-IP**（ロードバランサー）を踏み台に
- 過去：**Cisco NX-OS**（スイッチ）にバックドア
- 今回：**PAM・OpenSSH**（ログインシステム本体）に潜伏

## 対策・今後の展望

### 🛡️ 今すぐできる・すべき対策

#### 1. ログインプログラム自体を監視する
```
✅ PAMとOpenSSHのファイルが「いつ・どのように変更されたか」を常時チェックする
✅ ファイルの変更を検知したら即座にアラートを出す仕組みを導入する
```

#### 2. 「変化」を追う（待つのではなく探す）
```
✅ 正常な状態のプログラムのコピー（ハッシュ値）と、現在のものを定期的に比較する
✅ アラートを待つのではなく、能動的に異常を探す「脅威ハンティング」を実施する
```

#### 3. バックドアを除去してからパスワードをリセットする
```
❌ 間違った順序：パスワード変更 → バックドアがまだ残っている → 新パスワードも盗まれる
✅ 正しい順序：バックドアの完全除去 → 動作確認（テスト環境で） → パスワードリセット
```
> ⚠️ 注意：間違った修正をするとシステム管理者自身もログインできなくなる危険があります！

#### 4. 過去の脆弱性への対応
```
✅ Cisco Nexus製品：CVE-2024-20399のパッチを適用する
✅ F5 BIG-IP：外部への不審な通信がないか監視する
```

#### 5. 監視の「死角」をなくす
```
✅ ロードバランサー・スイッチ・ログインソフトなど「インフラ系」も監視対象に含める
✅ 「重要なシステムだから大丈夫」という思い込みを捨てる
```

## 過去記事との関連

以前、**「400以上のArch Linux AURパッケージが乗っ取られ、情報窃取ツールが仕込まれた事件」**と、**「GoogleがAI『Gemini』を悪用した中国のフィッシング詐欺ネットワークを訴えた件」**を解説しました。

今回の記事はこれらと以下の点で共通しています：

| 共通点 | 内容 |
|--------|------|
| 🎯 **「信頼されているもの」を悪用** | AUR事件はLinuxの公式パッケージ、今回はログインシステム本体を悪用 |
| 🇨🇳 **中国との関連** | Gemini悪用事件も中国系グループ、今回も中国系グループ「Velvet Ant」 |
| 🕵️ **発見が遅れる工夫** | いずれも「正規のもの・信頼されているもの」に見せかける手口 |

特にAUR事件との類似点は顕著です。どちらも「**ユーザーが無意識に信頼しているもの（パッケージ／ログインシステム）**」を改ざんするという発想が共通しています。  
攻撃者たちは「新しい悪いものを入れる」より「もともとある良いものを汚染する」方向にシフトしてきており、これはセキュリティ業界全体にとって大きな課題です。

## 用語解説

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **PAM** | ピーエーエム | Pluggable Authentication Moduleの略。Linuxのログイン認証を管理する仕組み |
| **OpenSSH** | オープンエスエスエイチ | インターネット越しに安全にサーバーを遠隔操作するためのソフトウェア |
| **バックドア** | Backdoor | 正規の認証を無視して侵入できる隠し通路・プログラム |
| **Velvet Ant** | ベルベット・アント | 中国系とされるハッカーグループ。Sygniaが命名 |
| **クレデンシャル** | Credential | ユーザーIDとパスワードのセット。「認証情報」とも呼ぶ |
| **踏み台（ピボット）** | Pivot | 別のシステムに侵入するための中継地点として使われるシステム |
| **CVE** | シーブイイー | Common Vulnerabilities and Exposuresの略。セキュリティの脆弱性に振られる管理番号 |
| **CISA** | シーサ | 米国のサイバーセキュリティ・インフラセキュリティ庁。日本のIPAに相当 |
| **F5 BIG-IP** | エフファイブ・ビッグアイピー | 大企業が使うネットワーク機器（ロードバランサー）のブランド名 |
| **Cisco NX-OS** | シスコ・エヌエックスオーエス | Cisco製のネットワークスイッチで動くOS |
| **ハッシュ値** | Hash | ファイルの「指紋」のようなもの。ファイルが1文字でも変わると別の値になる |
| **脅威ハンティング** | Threat Hunting | アラートを待つのではなく、能動的に侵入の痕跡を探すセキュリティ活動 |
| **Operation Highland** | オペレーション・ハイランド | 今回の一連の攻撃活動につけられたコードネーム |
