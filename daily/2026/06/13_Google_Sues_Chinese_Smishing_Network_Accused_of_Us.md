# GoogleがAI「Gemini」を悪用した中国のフィッシング詐欺ネットワークを訴えた件

**元記事**: [Google Sues Chinese Smishing Network Accused of Using Gemini AI in Phishing](https://inl03.netline.com/ltr6/?_m=3n.009a.4003.sp0ao46r89.3218)
**解説日**: 2026年6月14日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を説明します。

### フィッシング詐欺とは？
「フィッシング（Phishing）」とは、**本物そっくりの偽サイトやメッセージで人をだまし、パスワードやクレジットカード番号などを盗む詐欺**のことです。魚釣り（Fishing）に見立てた名前で、エサ（偽メッセージ）で獲物（個人情報）を釣り上げるイメージです。

### スミッシングとは？
「スミッシング（Smishing）」は、**SMS（携帯のショートメッセージ）を使ったフィッシング詐欺**です。SMS + Phishing = Smishing という造語です。「荷物が届きません」「口座に問題があります」といった文面でリンクを踏ませようとする、あの迷惑メッセージです。

### PhaaS（フィッシング・アズ・ア・サービス）とは？
「サービスとしてのフィッシング」という意味です。詐欺ツール一式をサブスクのように**月額料金で悪人に貸し出す**ビジネスモデルです。プログラミングの知識がない素人犯罪者でも、簡単にフィッシング詐欺ができてしまう仕組みです。

### Gemini（ジェミニ）とは？
GoogleのAIアシスタントです。文章を書いたりコードを生成したりすることができます。ChatGPTのGoogle版と思ってもらえれば大丈夫です。

## 何が起きたのか

Googleは2026年、**「Outsider（アウトサイダー）」**と呼ばれるフィッシング詐欺ツールを運営する中国のサイバー犯罪ネットワークを、ニューヨーク・マンハッタンの連邦裁判所に**訴えました**。

この犯罪ネットワークがとくに問題視されたのは、**GoogleのAI「Gemini」を悪用して詐欺サイトを自動作成していた**という点です。

### 被害の規模（数字で見てみよう）

| 項目 | 数値 |
|------|------|
| 被害者数 | **10万人以上** |
| 被害総額 | **数百万ドル（数億円）** |
| 偽サイト数 | **9,000以上** |
| 不正URL数 | **159万以上** |
| 2週間で送られたスパムSMS | **55,000通**（Androidユーザーが報告） |
| ツールの利用料金 | **週88ドル（約1万3千円）〜月200ドル（約3万円）** |

## 技術的な詳細

### 「Outsider」はどうやって動いているの？

Outsiderは、まるで**詐欺師向けの「商用サービス」**のように設計されていました。構成要素を見てみましょう。

```
【Outsider の仕組み】

① Telegramで購入
     ↓ @OutsiderCodeBotというボットで自動注文
② 290種類以上の偽サイトテンプレートを入手
     ↓ 銀行・通信会社・ECサイトなどの偽サイト
③ AIを使って偽サイトを自動生成
     ↓ GeminiなどのAIに「プレゼント受け取りページのHTMLを書いて」と指示
④ SMSで大量送信
     ↓「口座に問題あり」「報酬があります」などの文面
⑤ 被害者がリンクをクリック
     ↓ 本物そっくりの偽サイトへ誘導
⑥ 入力した個人情報・クレジットカード番号を盗む
```

### AIをどう悪用したの？

**ポイントはAIをだます巧妙な頼み方です。**

犯人たちはGeminiに対して、怪しいことを直接頼まず：

> 「プレゼント引き換えページのHTMLコードを書いて。JavaScriptは使わず、インラインCSSで作って」

といった**一見無害なプログラミング依頼**として指示を出していました。AIは「これは詐欺目的だ」と気づけず、普通のウェブページのコードを生成してしまいます。そのコードをOutsiderに貼り付けると、本格的な詐欺サイトが完成してしまうのです。

### 犯罪組織の分業体制

この組織は、**まるで会社のように役割分担**していました：

| グループ名 | 役割 |
|-----------|------|
| 開発グループ | フィッシングソフトとテンプレートを作る |
| データブローカーグループ | ターゲット（だます相手）のリストを用意する |
| スパムグループ | SMSを大量送信するツールを提供する |
| 窃盗グループ | 盗んだ情報（クレカ等）を換金・マネーロンダリングする |
| Telegramグループ | メンバーの連絡調整・新規メンバーの勧誘をする |

## なぜ重要なのか

### 1. AIが「犯罪の道具」になっている現実
これまでAIの悪用といえば「フェイク画像の生成」などが主でしたが、今回は**AIが詐欺サイトのコードを書かされていた**という新しい脅威です。AIは「善意の道具」として設計されていますが、悪意ある使い方をする人間に利用されてしまいました。

### 2. 「誰でも詐欺師になれる」時代の危険性
週88ドルで詐欺ツール一式が手に入り、プログラミング知識ゼロでも本格的な詐欺が実行できてしまいます。これは**犯罪の「民主化」**とも言える恐ろしい状況です。

### 3. 大企業のブランドが悪用される
銀行、通信会社、ブランド企業の偽サイトが290種類以上用意されていました。私たちが「信頼している」ブランド名を使って詐欺が行われるため、見破るのが非常に難しくなります。

## 対策・今後の展望

### 私たちができること 🛡️

1. **SMSのリンクは絶対にすぐクリックしない**
   「口座の問題」「荷物の不在通知」「報酬のお知らせ」などはほぼ詐欺です。公式アプリやブラウザで直接ログインして確認しましょう。

2. **URLをよく確認する**
   偽サイトのURLは微妙に違います（例：`amazon.co.jp` → `amaz0n-support.com`）。アドレスバーをしっかり見る習慣をつけましょう。

3. **二段階認証を設定する**
   万が一パスワードを盗まれても、SMS認証や認証アプリがあれば不正ログインを防げます。

4. **「急かされている」と感じたら疑う**
   詐欺の常套手段は「今すぐ対応しないと口座が凍結されます！」のような**焦らせる文句**です。冷静に立ち止まりましょう。

### Googleの今後の取り組み
- AT&T、T-Mobile、Verizon（米国の大手通信会社）と協力して、詐欺SMSをブロック
- 訴訟によって犯罪ネットワークのインフラを解体することを目指す
- AIの悪用を防ぐためのシステム改善

以前、**「400以上のArch LinuxパッケージがBotに乗っ取られ、情報窃取ツールが仕込まれた事件」**や**「米国政府がAnthropicの最先端AIモデルへの外国人アクセスを停止命令」**についてお伝えしました。

これらと今回の記事には共通するテーマがあります。それは「**AIと高度なツールが、悪意ある攻撃者に悪用されるリスクが高まっている**」という流れです。

- AIモデルのアクセス制限（Anthropicの件）→ 今回のGeminiの悪用事例は、その規制の必要性を裏付ける事例と言えます
- ソフトウェアサプライチェーンへの攻撃（Arch Linuxの件）→ 今回の「プログラミングツールキットを通じた攻撃」と同様、**正規のツールやプラットフォームを悪用する手口**が増えているトレンドと一致しています

サイバー攻撃はもはや「一匹狼のハッカー」ではなく、**分業化・サービス化された組織的犯罪**へと進化しています。これからもこのトレンドは続くとみられます。

## 用語解説

| 用語 | 意味 |
|------|------|
| **フィッシング（Phishing）** | 偽サイトや偽メールで個人情報を盗む詐欺 |
| **スミッシング（Smishing）** | SMSを使ったフィッシング詐欺（SMS + Phishing） |
| **PhaaS** | 「サービスとしてのフィッシング」。月額制で詐欺ツール一式を貸し出すビジネスモデル |
| **Gemini** | GoogleのAIアシスタント。文章やコードを生成できる |
| **HTML/CSS** | ウェブサイトのデザインを作るためのプログラミング言語 |
| **マネーロンダリング** | 犯罪で得たお金の出所をわからなくする資金洗浄行為 |
| **インフラ** | ここでは犯罪活動を支えるサーバーやシステムの基盤のこと |
| **テンプレート** | あらかじめ用意された「雛形」のこと。今回は偽サイトの雛形 |
| **キーストロークログ** | キーボードの入力内容を記録する機能。パスワードを盗むために使われる |
| **連邦裁判所** | アメリカの国家レベルの裁判所 |
