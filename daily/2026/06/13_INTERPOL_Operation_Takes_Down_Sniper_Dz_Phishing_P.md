# INTERPOLが「フィッシング詐欺の道具貸し屋」Sniper Dzを摘発！201人逮捕

**元記事**: [INTERPOL Operation Takes Down Sniper Dz Phishing Platform, Arrests Administrator](https://inl03.netline.com/ltr6/?_m=3n.009a.4003.sp0ao46r89.3222)
**解説日**: 2026年6月13日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を押さえておきましょう。

### 🎣 フィッシング詐欺とは？
「フィッシング（Phishing）」とは、**本物そっくりの偽サイトを作って、ユーザーのIDやパスワードを盗む詐欺**のことです。たとえば、本物のNetflixとそっくりな偽サイトを作り、「ログインしてください」と誘導して、入力されたパスワードを盗む、という手口です。

### 🛒 PhaaS（フィッシング・アズ・ア・サービス）とは？
「PhaaS」は「Phishing as a Service」の略で、**フィッシング詐欺に必要な道具一式を、他の犯罪者に貸し出すサービス**です。

コンビニに例えると分かりやすいでしょう。フィッシング詐欺をやりたい犯罪者に対して、「偽サイトのデザイン」「サーバー」「マニュアル動画」などをまるごとセットで提供するビジネスです。料理に例えるなら、「料理キット（ミールキット）を配達する会社」のようなもの。自分でゼロから料理（詐欺の道具）を作らなくても、届いたキットを使えばすぐに料理（詐欺）ができてしまう、という仕組みです。

### 🌍 INTERPOLとは？
「INTERPOL（インターポール）」は国際刑事警察機構のことで、**196か国の警察が協力して国際的な犯罪に対処するための組織**です。一つの国だけでは捕まえられない、国をまたぐ犯罪者を追いかけるときに特に力を発揮します。

---

## 何が起きたのか

2025年10月から2026年2月にかけて、INTERPOLが中心となって**「オペレーション・ラムズ（Operation Ramz）」**という大規模な国際合同捜査が行われました。中東・北アフリカの13か国が協力し、その結果、**201人が逮捕**されました。

この作戦の最大のターゲットは、**「Sniper Dz（スナイパー・ディーゼット）」**というフィッシング詐欺サービスの壊滅です。

- 🔴 このサービスは**2015年から約10年間**も活動していた
- 🔴 被害者の情報は**4万5,000件以上**にのぼる
- 🔴 関連する偽サイトのドメイン（URLアドレス）が**2万件以上**確認されている
- 🔴 主な開発者・管理者「Guedz（グエッズ）」がアルジェリア警察によって逮捕された

サービスに使われていたウェブサイトは閉鎖され、フィッシング用のソフトウェアやスクリプト（プログラム）が入ったハードウェア（コンピューター機器）も押収されました。

## 技術的な詳細

### 🧰 Sniper Dzが提供していた「犯罪ツールキット」

Sniper Dzは、フィッシング詐欺をやりたい人に対して以下のものをセットで提供していました：

| 提供物 | 説明 |
|---|---|
| 偽サイトのテンプレート（雛形） | PayPal、Facebook、Netflix など30社以上を模倣した偽ページ（80種類） |
| 多言語対応 | アラビア語・英語・フランス語・スペイン語・ヘブライ語の5言語 |
| サーバー（ホスティング） | 偽サイトを公開するためのインフラを提供 |
| プロキシサーバー | 犯罪者の身元を隠すための中継サーバー |
| Telegramチャンネル | 使い方のチュートリアル動画（登録者7,300人以上！） |

### 💰 驚きのビジネスモデル：「無料で使える」

Sniper Dzの特徴は、**なんと無料で利用できた**ことです。普通のビジネスなら使用料を取るはずですが、このサービスはタダ。その代わり、運営者は次の方法で稼いでいました：

1. **盗んだIDとパスワードを自分たちも収集**して転売
2. **被害者を別の詐欺に誘導**（スパムSMS課金、ブラウザ通知詐欺など）

つまり、犯罪者に「無料の道具」を配ることで、世界中でフィッシング詐欺を量産させ、その流れに乗って自分たちも儲ける仕組みだったのです。

### 🎭 ソーシャルエンジニアリング（人の心理を利用した攻撃）

Sniper Dzはさらに高度な手口も使っていました。中東・北アフリカの有名な政治家や著名人になりすました**偽のSNSアカウント**を作り、「無料インターネットキャンペーン」「お得なプレゼント」などと称してフィッシングリンクを広めていました。有名人が宣伝しているように見えるため、被害者が信じやすくなる手口です。

## なぜ重要なのか

### 📊 規模が桁違い

このサービスは10年間で世界中に被害を広げていました。ターゲットにされた企業・サービスを見てみると：

> PayPal、Facebook、Instagram、Yahoo、Netflix、Steam など、誰もが使う有名サービスばかり

つまり、**日本にいる私たちも潜在的な被害者になり得た**ということです。

### 🌐 「無料」が招く大量の犯罪者

Sniper Dzが無料だったということは、フィッシング詐欺の知識が少ない「初心者の犯罪者」でも簡単に詐欺を実行できてしまいました。プロの泥棒だけでなく、素人まで犯罪に参加できる環境を作ってしまっていたのです。これは非常に深刻な問題です。

### 🚔 国際連携の重要性

1か国の警察では、国境をまたぐネットワーク犯罪を解決するのは非常に困難です。13か国が協力したことで、ようやく壊滅できたという事実は、**サイバー犯罪には国際的な連携が不可欠**であることを示しています。

## 対策・今後の展望

### 🛡️ 私たちができる対策

**① URLをよく確認する**
フィッシングサイトは本物そっくりに見えますが、URLアドレスが微妙に違うことが多いです。例：`paypa1.com`（小文字のLをアラビア数字の1に変えている）など。

**② 公式アプリを使う**
メールやSNSのリンクからログインするのではなく、**公式アプリやブックマークから直接アクセスする**習慣をつけましょう。

**③ 二段階認証（2FA）を設定する**
パスワードが盗まれても、二段階認証があれば不正ログインを防げる可能性が高まります。

**④ 「無料プレゼント」「今すぐログイン」に注意**
有名人が宣伝していても、急かすような内容のリンクは要注意です。

**⑤ 怪しいSMS・通知を無視する**
Sniper Dzは「キャリア課金詐欺」や「プレミアムSMSの不正登録」にも被害者を誘導していました。身に覚えのない通知は無視しましょう。

### 🔮 今後の展望

Sniper Dzは壊滅しましたが、類似のPhaaS（フィッシング詐欺のサービス）は世界中に存在します。今回の摘発は大きな成果ですが、「一つ潰したら次が出てくる」のがサイバー犯罪の現実です。今後も国際的な連携強化が求められます。

前回のGoogleの事例ではAIを使った高度な詐欺が話題になりましたが、今回のSniper Dzは**10年以上にわたって「ローテク（低技術）でも使えるサービス」を提供し続けた**という点が特徴的です。AI活用のような最先端の手口だけでなく、このような「誰でも使えるツール」によるフィッシング詐欺も依然として大きな脅威であることがわかります。

フィッシング詐欺は形を変えながら進化し続けており、AIを使ったものも、ツールキット型も、どちらも私たちの身近な脅威であることを覚えておきましょう。

## 用語解説

| 用語 | 説明 |
|---|---|
| **フィッシング（Phishing）** | 本物そっくりの偽サイトや偽メールで、IDやパスワードを騙し取る詐欺 |
| **PhaaS（フィッシング・アズ・ア・サービス）** | フィッシング詐欺に必要な道具一式を他の犯罪者に提供するビジネスモデル |
| **INTERPOL（インターポール）** | 196か国が加盟する国際刑事警察機構。国際犯罪に協力して対処する |
| **ドメイン** | インターネット上のアドレス（例：google.com の部分） |
| **プロキシサーバー** | 自分の代わりに通信を中継するサーバー。犯罪者が身元を隠すために使う |
| **ソーシャルエンジニアリング** | 技術的な攻撃ではなく、人の心理や信頼感を利用して情報を盗む手法 |
| **テンプレート（雛形）** | あらかじめ用意された偽サイトのデザインの型 |
| **キャリア課金詐欺** | 携帯電話の通信費に不正な料金を上乗せして請求する詐欺 |
| **二段階認証（2FA）** | パスワードに加えて、スマホへの通知や指紋認証など2つ目の確認を行う仕組み |
| **クレデンシャル** | IDやパスワードなどのログイン情報のこと |
