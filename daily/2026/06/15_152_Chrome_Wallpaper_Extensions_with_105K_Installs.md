# 壁紙アプリに潜む罠！15万人が知らずにインストールした危険なChrome拡張機能

**元記事**: [152 Chrome Wallpaper Extensions with 105K Installs Linked to Adware and Fake Traffic](https://inl03.netline.com/ltr6/?_m=3n.009a.4004.sp0ao46r89.322g)
**解説日**: 2025年7月

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な仕組みを押さえておきましょう。

### Chrome拡張機能って何？
Google Chrome（ブラウザ）に追加できる「小さなアプリ」のようなものです。「新しいタブを開いたときにおしゃれな壁紙を表示する」「広告をブロックする」など、ブラウザの機能を拡張できます。スマホのアプリストアと似た「Chrome ウェブストア」から無料でインストールできます。

### 「オーガニック検索」って何？
Googleで何かを検索したとき、検索結果には2種類あります：
- **広告（スポンサー）**: お金を払って上位に表示されるもの
- **オーガニック（自然検索）**: お金を払わず、Googleのアルゴリズムが「このサイトは信頼できる・人気がある」と判断して表示するもの

オーガニック検索で上位に表示されるためには、本物のユーザーが実際にそのサイトを訪問・クリックすることが重要です。

### アドウェアって何？
ユーザーの知らないうちにこっそり広告を表示させたり、個人情報を集めたりする悪質なソフトウェアのことです。

---

## 何が起きたのか

セキュリティ研究者が、**Google Chromeの壁紙アプリを装った152個もの悪質な拡張機能**を発見しました。

🔢 **被害の規模**
- 拡張機能の数：**152個**
- インストール数：**合計10万5000回以上**
- 関わっていた出版者アカウント：**38個**

これらの拡張機能は、人気キャラクターや有名ブランドの名前を使って利用者を引きつけていました。たとえば：

| 拡張機能名 | 内容 |
|---|---|
| Neymar - Football Live Wallpaper | サッカー選手ネイマールの壁紙 |
| Satoru Gojo Manga Live Wallpaper | 呪術廻戦の五条悟の壁紙 |
| Hello Kitty Wallpapers HD | ハローキティの壁紙 |
| Tanjiro - Demon Slayer Live Wallpaper | 鬼滅の刃の炭治郎の壁紙 |
| Death Note Anime Wallpapers | デスノートの壁紙 |

人気アニメや有名キャラクターを使っているのが特徴的ですね。日本のコンテンツも多く含まれており、日本人ユーザーも狙われていた可能性があります。

## 技術的な詳細

### 🎭 嘘のプライバシーポリシー

Chromeウェブストアのページには「ユーザーのデータは収集しません」と記載されていました。しかし実際のプライバシーポリシー（別ページ）には正反対のことが書かれていました：

> 「IPアドレス、インターネット会社名（ISP）、クリック数、参照元サイトを記録し、Google AdSense・DoubleClick・広告パートナーと共有する」

つまり、**「収集しない」と言いながら実はしっかり収集していた**ということです。まるで契約書の小さな文字に「実は嘘でした」と書いてあるようなものです😱

---

### 🤖 「偽のGoogle検索」を作り出す仕組み

これが今回の事件で最も巧妙な部分です。仕組みを図で説明します：

```
【通常のオーガニック検索】
ユーザーがGoogleで検索
　　↓
検索結果をクリック
　　↓
サイトに到着（←Googleが「人気サイト」と認識）

【今回の偽装】
拡張機能をインストール
　　↓
拡張機能が自動でタブを開く
　　↓
「Google経由で来た」という偽のラベルを貼り付け
　　↓
サイトに到着（←Googleが「人気サイト」と誤認識！）
```

具体的には、拡張機能の中に隠されたプログラム（`js/bg.js`というファイル）が、インストール時とアンインストール時に特定のURLへアクセスします。

そのURLには **UTMパラメータ**（サイトへの訪問者がどこから来たかを識別するタグ）が含まれており：

```
utm_source=google&utm_medium=organic&utm_campaign=...
```

これは「Googleのオーガニック検索から来ました！」という意味のタグです。しかし実際には**拡張機能が自動でアクセスしているだけ**で、本物の人間が検索したわけではありません。

### 🎭 アンインストール時も偽装

さらに巧妙なのが、アンインストール（削除）するときの動作です。

削除時にも特定のURLへアクセスするのですが、そのURLは本物のGoogle検索結果クリックと全く同じ形式になっています（`ved`や`usg`という本物のGoogleが使うトークンまで含めて）。これにより、**「人間がGoogleの検索結果をクリックした」ように見せかける**ことができます。

---

### 💣 隠れた危険な機能

さらに、このプログラムには「**IndexedDB（インデックスドDB）を全て削除する**」という機能も隠されていました。

> **IndexedDB**とは：ブラウザの中にデータを保存できる仕組みで、ウェブサービスのキャッシュや一時データが入っています。これを消されると、サービスが正常に動かなくなる可能性があります。

現時点ではこの機能は「眠った状態」とのことですが、いつ起動するかわかりません。

## なぜ重要なのか

### 💰 お金の流れ（犯人の目的）
この攻撃は**「アドウェアとトラフィック詐欺」**のためだと分析されています。

```
①　拡張機能を大量に配布
　　　↓
②　ユーザー情報（IPアドレス等）を収集
　　　↓
③　広告会社に売る（不正な広告収益）
　　　↓
④　偽のオーガニック検索トラフィックを生成
　　　↓
⑤　SEO（検索順位）を不正に操作して広告収益を得る
```

### 👤 あなたへの影響
- あなたのIPアドレス（ネット上の住所）が知らない会社に売られる
- 閲覧履歴・クリック情報が収集される
- ブラウザのデータが削除される可能性がある
- 気づかないうちに広告詐欺の片棒を担がされる

## 対策・今後の展望

### ✅ 今すぐできる対策

**① インストール済みの拡張機能を確認する**
```
Chromeのアドレスバーに「chrome://extensions/」と入力
　→ インストール済みの拡張機能一覧が表示される
　→ 見覚えのないもの・使っていないものは削除！
```

**② 拡張機能をインストールする前に確認する**
- 開発者が信頼できる会社か調べる
- レビューが異常に少ない・怪しくないか確認
- 要求している「権限」が多すぎないか確認
  - 壁紙アプリが「全てのウェブサイトのデータを読み取る」権限を求めていたら要注意！

**③ 「無料の壁紙アプリ」は特に注意**
壁紙や便利ツールを装った拡張機能は、悪用されやすい代表的なパターンです。

**④ 今回関連していたドメインに注意**
以下のサイトに関連する拡張機能は削除を検討してください：
- `tabplugins[.]com`
- `yowgames[.]com`
- `chromewallpaper[.]com`

### 🔮 今後の展望

Googleはこのような悪質な拡張機能を削除する対応をとっていますが、**次々と新しいアカウントと名前で復活してくる**いたちごっこが続いています。今回も38もの出版者アカウントが使われており、一つが削除されても他で活動を続けられる仕組みになっています。

## 過去記事との関連

今回の記事は初めての解説ですが、このような「便利ツールを装った悪質な拡張機能」の問題は以前から繰り返されているパターンです。Chrome拡張機能を使った攻撃は珍しくなく、「無料で使えるから」と気軽にインストールすることの危険性を改めて教えてくれる事例と言えます。

## 用語解説

| 用語 | 説明 |
|---|---|
| **Chrome拡張機能** | Chromeブラウザに追加できる小さなアプリ |
| **PUP（Potentially Unwanted Program）** | 「望ましくない可能性のあるプログラム」。完全なウイルスではないが、迷惑な動作をするソフト |
| **アドウェア** | 勝手に広告を表示したり、情報を収集したりする悪質なソフト |
| **UTMパラメータ** | URLに付け加えて「どこから来たか」を追跡するためのタグ |
| **オーガニック検索** | お金を払わず、Googleのアルゴリズムで自然に表示された検索結果 |
| **SEO（Search Engine Optimization）** | 検索エンジンで上位表示されるための最適化手法 |
| **IPアドレス** | インターネット上の「住所」のようなもの。どこからアクセスしているかがわかる |
| **ISP（Internet Service Provider）** | インターネットを提供する会社（NTT、SoftBankなど） |
| **IndexedDB** | ブラウザ内にデータを保存できる仕組み |
| **トラフィック詐欺** | 本物の人間のアクセスに見せかけて、偽のアクセス数を水増しする不正行為 |
| **Google AdSense / DoubleClick** | Googleの広告配信サービス |
| **サービスワーカー** | ブラウザのバックグラウンドで動く小さなプログラム |

---

> 💡 **まとめ**：「かわいい・かっこいい壁紙が無料で使える！」という魅力的な拡張機能でも、裏では個人情報を盗んだり、Googleを騙したりしている場合があります。拡張機能は「本当に必要なもの」だけをインストールし、定期的に見直す習慣をつけましょう！
