# 人気WordPressプラグインが改ざん！120万サイトに隠しバックドアが仕掛けられた事件

**元記事**: [Popular WordPress Plugin Scripts Tampered to Plant Hidden Backdoors on Sites](https://inl03.netline.com/ltr6/?_m=3n.009a.4004.sp0ao46r89.322s)
**解説日**: 2025年6月16日

---

## 背景知識

まず、今回のニュースを理解するために必要な言葉をおさえておきましょう。

### 🏗️ WordPressって何？
**WordPress（ワードプレス）** は、ブログやウェブサイトを簡単に作れるシステムです。世界中のウェブサイトの約40%がWordPressで作られていると言われており、個人ブログから企業サイトまで幅広く使われています。

### 🔌 プラグインって何？
プラグインとは、WordPressに「機能を追加するための小さなプログラム」です。スマホのアプリをダウンロードするイメージに近いです。今回問題になったのは以下の3つのプラグインです：

| プラグイン名 | 主な機能 | インストール数 |
|---|---|---|
| **OptinMonster** | メール登録フォームの表示 | 100万以上 |
| **TrustPulse** | 「〇〇さんが購入しました」などの通知表示 | 不明 |
| **PushEngage** | ブラウザへのプッシュ通知送信 | 約9,000 |

### 📦 JavaScriptファイルって何？
**JavaScript（ジャバスクリプト）** とは、ウェブページを動かすためのプログラミング言語です。ボタンをクリックしたときにアニメーションが動いたり、フォームの入力チェックをしたりする、「ウェブページに動きをつける」プログラムです。

### 🌐 CDNって何？
**CDN（コンテンツデリバリーネットワーク）** とは、世界中にサーバーを分散配置して、ウェブサイトのファイルを素早く届ける仕組みです。コンビニのように「近くの場所から届ける」イメージです。今回はこのCDNに置かれたJavaScriptファイルが書き換えられました。

---

## 何が起きたのか

### 🚨 事件の概要

2025年6月12〜14日にかけて、**攻撃者が3つの人気WordPressプラグインのJavaScriptファイルを密かに書き換えました。**

書き換えられたファイルは、プラグインの配布サーバー（CDN）から120万以上のウェブサイトに配信されました。

#### 📅 タイムライン

```
4月28日  ── 攻撃者が「tidio[.]cc」という偽ドメインを事前に取得
6月12日  ── 攻撃開始
  22:17  ── OptinMonster・TrustPulseに悪意のあるコードが仕込まれる
  22:42  ── OptinMonster・TrustPulseの悪意あるコードが削除（約25分間）
  ～深夜  ── PushEngageへの攻撃も発生（数時間続く）
6月13日  ── セキュリティ会社「Sansec」が攻撃を発見・公表
6月14日  ── PushEngageのCDNの一部からまだ悪意あるファイルが配信される
6月15日  ── PushEngageが公式に被害を認める（OptinMonster・TrustPulseは沈黙）
```

---

## 技術的な詳細

### 🎭 攻撃の仕組みをわかりやすく説明

この攻撃を「スパイが仕掛けた罠」に例えると、こんな感じです：

> 🏠 ウェブサイトを「お店」  
> 👨‍💼 管理者アカウントを「マスターキーを持つオーナー」  
> 🕵️ 悪意あるスクリプトを「店の入り口に仕掛けられた罠」  

---

#### ステップ1：改ざんされたファイルが普通のサイト訪問者には何もしない

普通のお客さん（一般訪問者）が来ても、罠は反応しません。スパイは「店のオーナーが来た時だけ」動く罠を仕掛けたのです。

#### ステップ2：管理者が来た瞬間に罠が発動

サイト管理者がWordPressにログインした状態でページを開いた瞬間、悪意あるJavaScriptが動き出します。「あ、マスターキーを持った人が来た！」と感知するわけです。

#### ステップ3：攻撃者用の隠し管理者アカウントを作成

管理者の権限を使って、**攻撃者だけが知っている秘密の管理者アカウント**をこっそり作ります。まるで「合鍵を勝手に作る」ようなものです。

#### ステップ4：見えない隠しプラグインをインストール

WordPress管理画面には表示されない（見えない）プラグインをインストールします。これが「**ウェブシェル（web shell）**」という、外から自由に命令を送れる扉を開けます。

#### ステップ5：盗んだ情報を攻撃者に送信

作成した不正アカウントの情報やサイト情報を「**tidio[.]cc**」という偽サイトに送信します（本物の「tidio.com」に似せた偽ドメインです）。

---

### 🔓 ウェブシェルとは？

ウェブシェルとは、**特定のURLにアクセスするだけで、サーバー上で何でも実行できる秘密の扉**です。

これが仕掛けられると攻撃者は：

- 📁 すべてのファイルを読んだり書き換えたりできる
- 🗄️ データベース（個人情報など）を丸ごとコピーできる
- 💳 クレジットカード情報を盗むコードを埋め込める
- 🔄 サイト訪問者を別の悪意あるサイトに飛ばせる
- 🚪 さらに別の隠し扉（バックドア）を増やせる

---

### 🧩 なぜWordPress管理画面では気づけないのか？

通常、WordPressのプラグイン一覧や管理画面を見れば、怪しいものがあれば気づけそうですが…

今回の悪意あるプラグインは**管理画面に表示されないよう設計されていました。** まるで「透明人間」のように管理画面をすり抜けるため、サーバーを直接調べないと発見できません。

---

## なぜ重要なのか

### 📊 影響の規模

```
影響を受けた可能性のあるサイト数：約120万以上
  ├─ OptinMonster  ：約100万サイト（ただし悪意あるコードの配信は約25分）
  ├─ TrustPulse    ：不明（同じく約25分）
  └─ PushEngage    ：約9,000サイト（数時間〜翌日まで）
```

> ⚠️ ただしこれは「プラグインをインストールしているサイトの数」であり、実際に被害を受けたサイトの数はこれより少ないと考えられます。

### 🎯 計画的な攻撃だった証拠

攻撃に使われた偽ドメイン「tidio[.]cc」は、**攻撃の約6週間前（4月28日）にすでに取得されていました。** これは「思いつきでやった攻撃」ではなく、しっかり計画された攻撃であることを示しています。

### 🤐 運営会社の対応の問題

3つのプラグインをすべて運営している「**Awesome Motive**」という会社は、6月15日時点でOptinMonsterとTrustPulseについて公式コメントを出していませんでした。100万サイト以上を持つプラグインの利用者が情報不足のままにされているのは、非常に深刻な問題です。

## 対策・今後の展望

### 🛡️ もし該当プラグインを使っているなら

#### ① まず「被害を受けた可能性がある」と考える
Sansecは「攻撃を受けたサイトはすでに侵害されたものとして扱うべき」と述べています。

#### ② サーバー上を直接確認する
WordPress管理画面だけでは確認できません。サーバーに直接アクセスして：
- 見慣れない管理者アカウントがないか確認
- 見慣れないプラグインファイルがないか確認

#### ③ 隠しバックドアが残っている可能性を考慮する
不審なアカウントやプラグインを削除しても、**別のバックドアが残っている可能性があります。** セキュリティの専門家に相談することを強く推奨します。

#### ④ プラグインを最新版に更新する
PushEngageはすでに修正済みのバージョンをリリースしています。

## 過去記事との関連

以前、「**152個のChrome壁紙拡張機能が広告詐欺に使われていた**」という記事を解説しましたが、今回の事件と共通する重要なポイントがあります。

それは**「信頼できると思っていたソフトウェアが、実は攻撃の道具になっていた」**という点です。

前回はブラウザの拡張機能、今回はウェブサイトのプラグイン。どちらも「便利な機能を追加するためのツール」が攻撃に悪用されました。

このような「**サプライチェーン攻撃（supply chain attack）**」と呼ばれる手法——つまり、ソフトウェアの配布経路そのものを狙う攻撃——が近年増えています。自分が直接ダウンロードしたものでなく、**その配信元が汚染されている**という点が、発見の難しさにつながっています。

## 用語解説

| 用語 | 説明 |
|---|---|
| **WordPress** | ウェブサイトを作るための人気システム。世界中のサイトの約40%で使用 |
| **プラグイン** | WordPressに機能を追加する小さなプログラム。スマホのアプリに相当 |
| **JavaScript** | ウェブページに動きをつけるプログラミング言語 |
| **CDN** | 世界中にサーバーを分散させてファイルを素早く届ける仕組み |
| **バックドア** | 攻撃者が後からこっそり侵入するために仕掛けた「隠し扉」 |
| **ウェブシェル** | 特定のURLにアクセスするだけでサーバーを遠隔操作できる仕組み |
| **管理者アカウント** | ウェブサイトのすべての設定・機能を操作できる最高権限のアカウント |
| **Sansec** | ウェブサイトのセキュリティを専門に研究するセキュリティ企業 |
| **tidio[.]cc** | 本物の「tidio.com」に似せて作られた攻撃者の偽ドメイン |
| **サプライチェーン攻撃** | ソフトウェアの配布経路や開発工程を汚染して多くのユーザーを一度に攻撃する手法 |
| **セッション** | ログイン中のユーザーと認識するための一時的な情報（これを悪用された） |

---

> 💡 **まとめ**：今回の攻撃は「信頼できるツールの配信経路を乗っ取り、管理者が気づかないうちに秘密の扉を仕掛ける」という非常に巧妙な手口でした。プラグインの更新確認と、不審なアカウントの有無を定期的に確認する習慣が重要です。
