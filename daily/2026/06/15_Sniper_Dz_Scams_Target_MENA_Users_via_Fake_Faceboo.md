# 「Sniper Dz」詐欺がFacebookの偽キャンペーンとブラウザ通知を悪用して中東・北アフリカのユーザーを狙う

**元記事**: [Sniper Dz Scams Target MENA Users via Fake Facebook Offers and Browser Alerts](https://inl03.netline.com/ltr6/?_m=3n.009a.4004.sp0ao46r89.322y)
**解説日**: 2025年7月1日

---

## 背景知識

まず、この記事を理解するための基礎知識を説明します。

### 📱 フィッシング詐欺とは？
「フィッシング（Phishing）」とは、**本物そっくりの偽サイトやメッセージを使って、パスワードや個人情報をだまし取る攻撃**のことです。「釣り（fishing）」になぞらえた言葉で、ユーザーを「釣り上げる」イメージです。

### 🛠️ PhaaS（フィッシング・アズ・ア・サービス）とは？
「PhaaS」とは、**詐欺ツールをまるごとレンタルできるサービス**のことです。悪意のある人が「詐欺キット」をサービスとして販売・提供し、技術的な知識がない犯罪者でも手軽に詐欺活動ができるようになってしまいます。いわば「詐欺の道具一式セット」です。

### 🔔 ブラウザ通知（プッシュ通知）とは？
Webサイトを見ているとき、「通知を許可しますか？」というポップアップが出ることがありますよね。「許可」を押すと、そのサイトからスマホやPCに**広告や通知が届くようになります**。これが「ブラウザ通知（プッシュ通知）」です。

### 🔗 リンクまとめサービス（Linktree・Linkbioなど）とは？
InstagramやSNSのプロフィールに「複数のURLをまとめて貼れるページ」を提供するサービスです。信頼されているサービスなので、悪用されると「安全そうに見えてしまう」という問題があります。

## 何が起きたのか

### 事件の概要

セキュリティ企業「Group-IB（グループIB）」の研究者が、**中東・北アフリカ（MENA）地域のユーザーを狙った大規模詐欺キャンペーン**の詳細を明らかにしました。

この詐欺は「**Sniper Dz（スナイパーDz）**」というPhaaS（詐欺ツールのレンタルサービス）を使ったもので、以下のような流れで被害者を騙していました。

1. **偽のFacebookアカウント**を使って政治家や有名人、公的機関になりすます
2. 「**無料モバイルデータ通信**」「**政府の補助金**」「**現金補償**」などの偽キャンペーンを宣伝する
3. リンクをクリックさせて、詐欺サイトへと誘導する
4. ブラウザ通知を悪用して、継続的に広告や詐欺情報を送り続ける
5. 最終的に**個人情報の窃取・課金詐欺・投資詐欺**へと誘導する

なお、「Sniper Dz」のプラットフォーム自体は**先月インターポール（国際刑事警察機構）主導の作戦によって閉鎖**されましたが、その手口の詳細が今回明らかになりました。

## 技術的な詳細

### 🎣 ステップ１：偽キャンペーンで誘い込む

攻撃者は、「**Algérie Télécom（アルジェリア・テレコム）**」などの有名な通信会社になりすましたFacebookアカウントを作成。「今だけ！無料でモバイルデータ通信をゲット！」などのウソの投稿で、ユーザーの興味を引きます。

> **例え話**：コンビニの入り口に「今日だけ！全品半額！」という張り紙があったとします。お店の中に入ると、実は全然違う店で、財布をスラれてしまうようなイメージです。

---

### 🔗 ステップ２：信頼できそうな中継サイトを経由する

リンクをクリックすると、**いきなり詐欺サイトには飛ばず**、「Linktree」「Linkbio」などの**信頼されている正規のリンクまとめサービス**を経由します。

これにより、Facebookなどのセキュリティチェックをすり抜けやすくなります。

```
Facebookの偽投稿
    ↓
Linktree / Linkbio（正規サービス、しかし攻撃者が悪用）
    ↓
悪意のあるWebページ（最終目的地）
```

---

### 🔔 ステップ３：「許可」ボタンでブラウザ通知を乗っ取る

最終的に辿り着いたページでは、「**続けるには「許可」を押してください**」という画面が表示されます。

ユーザーが「許可」を押すと、裏側では「**VAPID（バピッド）公開鍵**」という仕組みを使って、**ブラウザが攻撃者のプッシュ通知システムに登録されてしまいます**。

> **VAPID公開鍵とは？** プッシュ通知を送る「送り主の識別番号」のようなもの。同じ鍵が複数の詐欺キャンペーンで使いまわされていたことから、背後にいる犯罪者グループのつながりが判明しました。

これ以降、攻撃者は**ブラウザを通じて勝手に広告や詐欺通知を送り続けられる**ようになります。

---

### 🚪 ステップ４：「戻る」ボタンも逃げ道も塞ぐ

この詐欺ページは非常に悪質な仕組みを持っています：

| 手口 | 内容 |
|------|------|
| **バックボタン乗っ取り** | 「戻る」を押しても偽の履歴を10個挿入し、延々とサイト内に閉じ込める（「戻るボタン牢獄」） |
| **タブアンダー攻撃** | リンクをクリックすると新しいタブが開くが、元のタブも密かに別の詐欺サイトへリダイレクトされる |

> **例え話**：迷路に入ったら、入り口がどんどん変わっていって、出口が見つからなくなるようなイメージです。

---

### 💰 ステップ５：被害者の情報をもとに詐欺を選択する

通知システムに登録されたユーザーは、「**TDS（トラフィック分配システム）**」と呼ばれる仕組みによって振り分けられます。

使用しているデバイス・場所・携帯キャリアなどの情報をもとに、**その人に最も効果的な詐欺を自動で選んで表示**します：

- 📞 **プレミアム電話詐欺**（高額課金される番号に電話させる）
- 📩 **プレミアムSMS詐欺**（高額な有料SMS登録をさせる）
- 💹 **投資詐欺**（偽の投資案件に誘い込む）

## なぜ重要なのか

### 🌍 影響範囲が非常に広い

この詐欺は中東・北アフリカ地域を主なターゲットにしていますが、同様の手口は**世界中で使われる可能性**があります。特に、Linktreeなどの**日本でもよく使われているサービスが悪用される点**は要注意です。

### 🔄 「許可」ボタン一つで長期被害が続く

一度ブラウザ通知を許可してしまうと、サイトを閉じた後も**ずっと詐欺通知が届き続けます**。被害が一時的ではなく、継続的に起きる点が特に危険です。

### 🎭 インターポール摘発後も手口が残る

Sniper Dzのプラットフォーム自体は閉鎖されましたが、**同じ手口を真似した他の犯罪者グループが活動を続ける可能性**があります。手口が公開されたことで、私たちが知識を持って対策できるのはプラスですが、模倣犯への注意も必要です。

## 対策・今後の展望

### ✅ あなたにできる対策

#### 1. 「通知を許可しますか？」は基本的に「ブロック」！
見慣れないサイトでブラウザ通知の許可を求められたら、**基本的に「ブロック」または「今はしない」を選びましょう**。特に「続けるには許可が必要」と言われたら、ほぼ確実に詐欺です。

#### 2. SNSの「うますぎる話」を疑う
「無料でデータ通信！」「政府から補助金！」などの投稿は、**公式サイトや公式アカウントで直接確認**しましょう。

#### 3. 既に許可してしまった場合の対処法

**Chromeの場合：**
```
設定 → プライバシーとセキュリティ → サイトの設定
→ 通知 → 不審なサイトを「削除」または「ブロック」に変更
```

**Safariの場合：**
```
設定 → Safari → 詳細 → Webサイトの設定
→ 通知 → 不審なサイトを「拒否」に変更
```

#### 4. URLをよく確認する
Linktreeなどの正規サービスのURLが表示されていても、**そこからどこに飛ばされるかが重要**です。最終的に表示されるURLが怪しい場合はすぐに閉じましょう。

### 🔭 今後の展望

- インターポールなどの国際的な連携によるPhaaS摘発が今後も続く見込み
- ブラウザ側でも通知の許可をより厳しく管理する機能の強化が期待される
- SNSプラットフォームによる偽アカウント検出精度の向上が求められる

以前、「**152個のChrome壁紙拡張機能が広告詐欺や偽トラフィックに使われていた**」という記事を解説しました。

今回の記事とその過去記事には、**共通した重要なテーマ**があります：

> 💡 **「普段使うツールやプラットフォームが悪用される」という点**

- 過去記事：Chromeの拡張機能（便利ツール）→ 広告詐欺に悪用
- 今回の記事：Linktree/Linkbio（SNS便利ツール）＋ブラウザ通知（便利機能）→ 詐欺に悪用

どちらも「**便利で信頼されているものほど、悪用されると気づきにくい**」という怖さがあります。インターネットを使う上で、「有名なサービスだから安全」とは限らないという意識を持つことがますます重要になっています。

## 用語解説

| 用語 | 意味 |
|------|------|
| **フィッシング（Phishing）** | 本物そっくりの偽サイト・偽メッセージで個人情報をだまし取る攻撃 |
| **PhaaS（フィッシング・アズ・ア・サービス）** | 詐欺ツール一式をレンタルできるサービス。技術知識のない犯罪者でも使える |
| **Sniper Dz** | 今回解説したPhaaS基盤のプラットフォーム名。先月インターポールに摘発された |
| **MENA** | Middle East and North Africa（中東・北アフリカ）の略称 |
| **VAPID公開鍵** | ブラウザのプッシュ通知を送る「送り主の識別番号」。同じ鍵の使いまわしで犯罪グループのつながりが判明した |
| **TDS（トラフィック分配システム）** | ユーザーの情報（場所・デバイスなど）をもとに、どの詐欺ページに誘導するかを自動で振り分けるシステム |
| **バックボタン乗っ取り** | 「戻る」ボタンを押しても偽の履歴を挿入してサイト内に閉じ込める手口 |
| **タブアンダー攻撃** | 新しいタブを開かせながら、元のタブも密かに別サイトへ誘導する手口 |
| **ソーシャルエンジニアリング** | 技術的な攻撃ではなく、人間の心理や信頼を利用してだます攻撃手法全般 |
| **Group-IB** | シンガポール本社のサイバーセキュリティ企業。今回の調査を実施した |
| **INTERPOL（インターポール）** | 国際刑事警察機構。世界各国の警察が連携する国際機関 |
