# 悪意あるJetBrainsプラグインがAI APIキーを盗み、Chrome拡張機能はAIチャットの会話を丸ごと記録

**元記事**: [Malicious JetBrains Plugins Steal AI API Keys as Chrome Extensions Capture Chatbot Chats](https://inl03.netline.com/ltr6/?_m=3n.009a.4006.sp0ao46r89.325k)
**解説日**: 2026年6月19日

---

## 背景知識

このニュースを理解するために、いくつかの基本的な概念を説明します。

### 🔧 JetBrainsとは？
**JetBrains**は、プログラマーが使う「開発ツール（IDE）」を作っている会社です。IntelliJ IDEAやPyCharmなど、プロのエンジニアが日常的に使うソフトウェアを提供しています。「JetBrains Marketplace」は、これらのツールに追加機能（プラグイン）をインストールできるお店のようなものです。スマホのAppStoreやGoogle Playに近いイメージです。

### 🔑 API キーとは？
**APIキー**とは、有料のAIサービス（OpenAIのChatGPTなど）を使うための「会員証＋お財布」のようなものです。このキーを持っていれば、AIに質問したり、コードを生成させたりできます。使った分だけお金がかかる仕組みで、**キーが盗まれると、勝手にお金を使われてしまいます**。

### 🤖 AIコーディングアシスタントとは？
プログラマーがコードを書くのを手伝ってくれるAIツールです。「このコードのバグを見つけて」「コメントを自動生成して」などができます。近年、DeepSeekやGitHub Copilotなどが人気を集めています。

### 🌐 Chrome拡張機能とは？
Googleのブラウザ「Chrome」に追加できる小さなプログラムです。広告ブロックや翻訳など便利な機能を追加できますが、**ブラウザ上の情報にアクセスできる強力な権限**を持っています。

## 何が起きたのか

### 事件①：JetBrainsの偽AIプラグイン15個が発覚

セキュリティ企業「Aikido Security」の研究者が、JetBrains Marketplaceに**15個の悪意あるプラグイン**が公開されていることを発見しました。

これらのプラグインは**全部本当に動きます**。見た目は普通のAIコーディングアシスタントで、バグ発見・コードレビュー・テスト自動生成なども正常に機能します。ところが、裏側では**ユーザーが入力したAPIキーを攻撃者のサーバーにこっそり送信**していたのです。

この活動は**2025年10月末から始まっており**、最新のプラグインは2026年6月10日にも公開されています。中には25,000回以上ダウンロードされたものも存在します。

### 事件②：Chrome広告ブロック拡張機能がAIチャットを盗み見

同時期に、**2つのChrome拡張機能**が、ユーザーのAIチャットボットとの会話を丸ごと収集していたことも発覚しました。

対象となったAIサービスは以下の通りです：
- ChatGPT（OpenAI）
- Claude（Anthropic）
- Gemini（Google）
- Copilot（Microsoft）
- Grok（xAI）
- DeepSeek、Perplexity、Meta AI

この情報収集活動は研究者によって **「PromptSnatcher（プロンプト泥棒）」** と命名されています。

## 技術的な詳細

### 🕵️ 偽プラグインの仕組み

```
ユーザー
  └→ プラグインにAPIキーを入力
        └→ 表向き：AIに質問を送る（正常に動作）
        └→ 裏側：APIキーを「39.107.60.51」に送信（盗む！）
```

特に巧妙なのは、**プラグインが「有料プラン」を提供している**点です。

> 1. ユーザーがプラグイン内で少額の料金を支払う
> 2. するとサーバーから「AIのAPIキー」が送られてくる
> 3. プラグインはそのキーでAIを使い始める

普通、正規のサービスなら自分のAPIキーを他人に渡すようなことはしません。**これは盗んだ被害者のAPIキーを転売している**と研究者は指摘しています。

つまり構図はこうです：

```
攻撃者
  ├→ 一方から：ユーザーから少額のお金を集める
  └→ もう一方から：被害者のAPIキーを無料で入手
            └→ 被害者が請求書を払わされる😱
```

### 🔓 なぜAPIキーが盗まれやすいのか

盗んだAPIキーは **「LLMジャッキング」** という犯罪に使われます。これは、盗んだAPIキーを使って大量のAIリクエストを送りつける手法で、被害者には高額の料金が請求されます。まるで「人のSuicaを使って乗り放題にする」ような行為です。

### 🧩 15個のプラグインが全て同じ犯人？

研究者は、15個のプラグインが**全て似たコード構造**を持っていることを確認しました。これは「組織的な攻撃キャンペーン」であることを示しています。バラバラに見えて、実は一つの集団による計画的な活動です。

## なぜ重要なのか

### 💸 金銭的な被害が直接発生する

APIキーはクレジットカードと同じです。盗まれれば、知らない間に大量のAIリクエストが送られ、**数万〜数十万円の請求が来る可能性**があります。

### 👨‍💻 開発者を狙い撃ちにしている

エンジニアは日常的にAPIキー・クラウドの認証情報・署名鍵などの「価値の高い秘密情報」を扱います。彼らが使うツール（JetBrainsなど）を狙うことで、**一度に大量の高価値情報が手に入る**わけです。

### 🗣️ プライバシーの深刻な侵害（Chrome拡張機能の件）

AIチャットボットには、仕事の機密情報・個人的な悩み・医療相談など、非常にプライベートな内容が含まれることがあります。それが丸ごと収集されているとしたら、**プライバシーの侵害として非常に深刻**です。

### 📦 「オープンソース・エコシステム」全体への信頼低下

npm（JavaScript）、PyPI（Python）、そしてJetBrains Marketplaceのような公開プラグイン市場は、開発者が当たり前のように使うものです。そこが汚染されると、**ソフトウェア開発の基盤そのものが揺らぎます**。

## 対策・今後の展望

### ✅ 今すぐできる対策

| 対策 | 説明 |
|------|------|
| **プラグインの提供者を確認する** | 公式企業や著名な開発者のものだけをインストールする |
| **APIキーに使用制限をかける** | OpenAIなどのサービスでは、APIキーごとに「月の上限金額」を設定できます |
| **APIキーを定期的に更新する** | 古いキーを無効にして新しいキーを発行する習慣をつける |
| **Chrome拡張機能の権限を確認する** | 「全てのウェブサイトのデータを読み取る」権限を持つ拡張機能は特に注意 |
| **不審なプラグインをアンインストールする** | 上記15個のプラグインを使っていた場合はすぐに削除し、APIキーを無効化する |

### 🔍 プラグインを選ぶ際のチェックリスト

```
□ 開発者は信頼できる企業や個人か？
□ レビューは自然か？（極端に高評価ばかりは怪しい）
□ ソースコードは公開されているか？
□ なぜこの機能にAPIキーが必要なのか、説明は納得できるか？
□ 設定画面でAPIキーを要求するが、公式ドキュメントに記載があるか？
```

### 🔮 今後の展望

今後もこのような「便利そうなツールに偽装した攻撃」は増え続けると予想されます。特にAIブームに乗った偽AIツールは、見分けがつきにくいため注意が必要です。JetBrainsや各マーケットプレイスには、より厳しい審査体制の導入が求められています。

## 用語解説

| 用語 | 説明 |
|------|------|
| **JetBrains Marketplace** | JetBrains社の開発ツール向けプラグイン（追加機能）を配布する公式ストア |
| **プラグイン** | ソフトウェアに後から追加できる拡張機能。スマホアプリのようなもの |
| **APIキー** | 有料AIサービスを利用するための認証コード。クレジットカード番号に近い概念 |
| **マルウェア** | 悪意のあるソフトウェアの総称。ウイルスやスパイウェアなども含む |
| **データ窃取（Exfiltration）** | 機密データを外部のサーバーに密かに送信すること |
| **LLMジャッキング** | 盗んだAPIキーを使ってAIサービスを不正利用し、被害者に費用を負担させる手口 |
| **PromptSnatcher** | AIチャットボットとの会話を盗み取るChrome拡張機能の活動につけられたコードネーム |
| **オープンソース・エコシステム** | 誰でも利用・公開できるソフトウェアやツールの集まり（npm、PyPI、各Marketplaceなど） |
| **HTTP平文通信** | 暗号化されていない通信。データが丸見えの状態で送られるため盗聴されやすい |
| **Chrome拡張機能** | Googleブラウザに追加できる小型プログラム。強力なブラウザアクセス権限を持つ |

---

> 💡 **まとめると...**
> 「便利そうなAIツール」が実は「泥棒」だった、という話です。特にAPIキーは「デジタルの財布」なので、どのツールに渡すかは慎重に。インストール前に「本当に信頼できるの？」と一度立ち止まる習慣が大切です。
