# 悪意あるJetBrainsプラグインがAI APIキーを盗み、Chrome拡張機能がチャットボットの会話を丸ごと記録

**元記事**: [Malicious JetBrains Plugins Steal AI API Keys as Chrome Extensions Capture Chatbot Chats](https://inl03.netline.com/ltr6/?_m=3n.009a.4006.sp0ao46r89.325k)
**解説日**: 2026年6月18日

---

## 背景知識

このニュースを理解するために、まずいくつかのキーワードを押さえておきましょう。

### 🔧 JetBrains（ジェットブレインズ）とは？
プログラマーが使う「統合開発環境（IDE）」というソフトウェアを作っている会社です。IDEとは、コードを書く・テストする・デバッグするといった作業を一か所でできる「プログラマー用の超高機能メモ帳＋ツール箱」のようなものです。IntelliJ IDEAやPyCharmといった製品が有名です。世界中の開発者が日常的に使っています。

### 🧩 プラグイン（Plugin）とは？
IDEやブラウザに「追加機能」を足すための小さなプログラムです。スマートフォンのアプリのようなイメージです。JetBrainsのプラグインは「JetBrains Marketplace（マーケットプレイス）」という公式のお店のようなサイトで配布されています。

### 🤖 AI APIキーとは？
ChatGPTやDeepSeekなどのAIサービスを「プログラムから使う」ためのパスワードのようなものです。

- **API（エーピーアイ）**：アプリとアプリが会話するための「窓口」のようなもの
- **APIキー**：その窓口を使う権限を証明する「合言葉」

このAPIキーがあると、AIを使い放題になります。しかも**利用料金は持ち主のクレジットカードに請求されます**。つまり、盗まれると「知らない間にAIを大量使用されてお金を取られる」という被害が生じます。

### 🦠 マルウェア（Malware）とは？
「悪意のあるソフトウェア（Malicious Software）」を縮めた言葉です。ウイルスやスパイウェアなど、ユーザーに害を与えるプログラムの総称です。

## 何が起きたのか

セキュリティ研究会社「Aikido Security（アイキドセキュリティ）」が、JetBrains Marketplaceに**15個の悪意あるプラグイン**が存在することを発見・報告しました。

これらのプラグインには、次のような共通した特徴があります。

- 🎭 **見た目は正規のAIコーディング補助ツール**（DeepSeekなどのAIをベースにしたと称している）
- 🛠️ **機能は本当に動く**（チャット、コードレビュー、バグ探し、ユニットテスト生成など）
- 🕵️ **しかし裏で、入力されたAPIキーを攻撃者のサーバーに送信する**

該当するプラグインの一覧：

| プラグイン名 | パッケージID |
|---|---|
| DeepSeek Junit Test | org.sm.yms.toolkit |
| DeepSeek Git Commit | com.json.simple.kit |
| DeepSeek FindBugs | org.bug.find.tools |
| DeepSeek AI Chat | org.translate.ai.simple |
| DeepSeek Dev AI | com.yy.test.ai.simple |
| DeepSeek AI Coding | com.dev.ai.toolkit |
| AI FindBugs | com.json.view.simple |
| AI Git Commitor | com.my.git.ai.kit |
| AI Coder Review | org.check.ai.ds |
| DeepSeek Coder AI | com.review.tool.code |
| AI Coder Assistant | org.code.assist.dev.tool |
| DeepSeek Code Review | com.coder.ai.dpt |
| CodeGPT AI Assistant | com.my.code.tools |
| DeepSeek AI Assist | ord.cp.code.ai.kit |
| Coding Simple Tool | com.dp.git.ai.tool |

中でも「CodeGPT AI Assistant」と「DeepSeek AI Assist」はそれぞれ**2万5000回以上ダウンロード**されています（ただし、数字が水増しされている可能性もあります）。

この活動は**2025年10月末から始まっており**、最新のプラグインは2026年6月10日にも公開されていました。

### 同時に：Chrome拡張機能でもAIチャットの会話が盗まれていた！

さらに同じタイミングで、**Google Chromeの広告ブロック拡張機能**2つが、ユーザーのAIチャットボットとの会話を盗み取っていたことも発覚しました。

対象となったAIサービス：
- ChatGPT（OpenAI）
- Claude（Anthropic）
- Gemini（Google）
- Copilot（Microsoft）
- Perplexity、DeepSeek、Grok（xAI）、Meta AI

この盗聴作戦は研究者によって「**PromptSnatcher（プロンプトスナッチャー）**」と名付けられました。「Prompt（プロンプト）」はAIへの入力文のことで、「Snatcher」はひったくり犯のような意味です。

問題の拡張機能：
- **Smart Adblocker**（9万人以上のユーザー／2022年10月公開）
- **Adblock for Browser**（記事が途中で切れているため詳細不明）

これらはChrome Web Storeにまだ掲載されている状態でした。

## 技術的な詳細

### 🔬 APIキー窃取の仕組み（JetBrainsプラグイン）

```
[ユーザー]
  ↓ 設定画面でAPIキーを入力
[悪意あるプラグイン]
  ↓ 表向きはAI機能を正常に動かす
  ↓ 裏でAPIキーを「39.107.60[.]51」という攻撃者のサーバーへ送信
[攻撃者のサーバー]
  ↓ 盗んだAPIキーを他の犯罪者に売る or 直接悪用
```

特に興味深いのが「**有料課金の仕組み**」です。

プラグイン内に「寄付ウォール（Donation Wall）」という課金機能があり、**ユーザーが少額を支払うと、サーバーから別のAPIキーが送られてきて、そのキーでAI機能が動くようになります**。

一見すると「正規サービス」のように見えますが、Aikido Securityは次のように指摘しています：

> 「正規の事業者が、有料AIサービスの使い放題キーを何の制限もなくユーザーに渡すことはありえない。このキーは、他の被害者から盗んだAPIキーを使い回している可能性が非常に高い」

つまり構造はこうです：

```
💸 攻撃者の収益モデル
┌─────────────────────────────────────────┐
│ 左側：被害者からAPIキーを「タダで」盗む    │
│ 右側：別の客に「お金をもらって」そのキーを渡す│
│ → 被害者がAI使用料を払い続ける            │
└─────────────────────────────────────────┘
```

まるで「他人の定期券を盗んで、別の人に販売する」ような詐欺です。

### 🔬 会話盗聴の仕組み（Chrome拡張機能）

広告ブロッカーのふりをしたChrome拡張機能が、ブラウザ上でAIチャットサービスのページを開いているとき、**ユーザーが入力した内容やAIの返答を密かに記録・送信**していました。

## なぜ重要なのか

### 1. 📊 被害規模が大きい
「CodeGPT AI Assistant」だけで2万5000回以上ダウンロードされており、実際にAPIキーを入力したユーザーが多数いる可能性があります。

### 2. 💰 金銭的な被害につながる
AIのAPIキーは**使った分だけ課金される**仕組みです。盗まれたキーが大量に使われると、知らないうちに数万〜数十万円の請求が来る可能性があります。

### 3. 🏢 開発者環境が狙われている
今回の攻撃の標的は「一般ユーザー」ではなく**プログラマー・開発者**です。開発者のパソコンには：
- ソースコード（プログラムの設計図）
- クラウドの認証情報
- APIキー
- デジタル署名キー

など、**企業や組織全体に影響しうる機密情報**が集まっています。つまり、開発者一人を攻撃することで、その人が所属する会社全体を危険にさらせるのです。

### 4. 🤫 AIの会話内容も危険
AIチャットに「仕事の機密情報」「個人的な悩み」「パスワードのヒント」などを入力している人は多いです。これが盗まれると、プライバシー侵害やビジネス情報の流出につながります。

## 対策・今後の展望

### ✅ 今すぐできる対策

#### JetBrainsプラグインについて
1. **上記15個のプラグインを今すぐアンインストールする**
2. **APIキーを今すぐ無効化・再発行する**（OpenAI、DeepSeek、SiliconFlowなどの管理画面から）
3. **プラグインは信頼できるものだけを使う**
   - 開発元が明確か確認する
   - 公式サイトへのリンクがあるか確認する
   - レビューが不自然に高くないか確認する

#### Chrome拡張機能について
1. **不審な広告ブロッカーをアンインストールする**
2. **AIチャットには機密情報や個人情報を入力しない**
3. **拡張機能の「権限」を確認する習慣をつける**
   - 「すべてのサイトのデータを読み取る」などの権限は要注意

### 🔮 全般的な心がけ

Aikido Securityはこうアドバイスしています：

> 「プラグインは、自分と同じ権限で動くソフトウェアと同じように扱うこと。十分に確認していないツールに、長期間有効なシークレット情報を貼り付けるのは危険です」

**信頼できないツールに大切な「鍵」を渡さない**、これが基本です。

以前「**2026年、組織が外部にさらしている危険な設定トップ10**」という記事で、「攻撃者はどこから組織に侵入してくるか」という視点でアタックサーフェス（攻撃される可能性のある入口）についてご紹介しました。

今回の記事はまさにその実例です。**開発者ツール（IDE）のプラグインやブラウザ拡張機能**が、「見落とされがちな攻撃の入口」として積極的に悪用されています。

「組織のセキュリティは、最も弱いリンクによって決まる」と言われます。強固なファイアウォールがあっても、開発者が悪意あるプラグインを入れてしまえば、そこから情報が漏れてしまうのです。

## 用語解説

| 用語 | 意味 |
|---|---|
| **JetBrains** | プログラマー向け開発ツール（IDE）を作る会社 |
| **プラグイン** | ソフトウェアに追加機能を加える小型プログラム |
| **API** | アプリとアプリが通信するための「窓口」 |
| **APIキー** | APIを使う権限を証明する「合言葉・パスワード」 |
| **マルウェア** | 悪意を持って作られたソフトウェアの総称 |
| **エクスフィルトレーション** | 内部の情報を外部に密かに送り出すこと |
| **LLMjacking** | 盗んだAPIキーを使って不正にAIサービスを利用・転売すること |
| **PromptSnatcher** | AIチャットへの入力内容を盗む攻撃の研究者による呼称 |
| **Chrome拡張機能** | Google Chromeブラウザに追加できる小さなプログラム |
| **DeepSeek** | 中国発の大規模言語モデル（AI）サービス |
| **アタックサーフェス** | 攻撃者が侵入できる可能性がある「入口」の総称 |
| **HTTP平文** | 暗号化されていない、そのままの状態でのデータ通信 |
