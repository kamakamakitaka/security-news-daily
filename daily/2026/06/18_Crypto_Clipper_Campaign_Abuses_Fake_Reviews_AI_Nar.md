# 偽レビューとAIナレーター、そしてVirusTotalのコメント欄まで悪用！暗号資産を盗む巧妙な詐欺キャンペーン

**元記事**: [Crypto Clipper Campaign Abuses Fake Reviews, AI Narrators, and VirusTotal Comments](https://inl03.netline.com/ltr6/?_m=3n.009a.4007.sp0ao46r89.326y)
**解説日**: 2025年7月

---

## 背景知識

このニュースを理解するために、いくつかの基本的な概念を押さえておきましょう。

### 🪙 暗号資産（仮想通貨）とウォレットアドレスとは？
暗号資産（ビットコインやイーサリアムなど）は、**「ウォレットアドレス」** と呼ばれる長い文字列（例：`0x1a2b3c4d...`）を使ってやり取りします。銀行の口座番号のようなものです。送金するときはこのアドレスをコピー＆ペーストすることが多いです。

### 📋 クリップボードとは？
パソコンで「コピー（Ctrl+C）」したときに一時的にデータが保存される場所です。「貼り付け（Ctrl+V）」するとここからデータが取り出されます。

### 🛡️ VirusTotalとは？
ファイルやURLが「ウイルスかどうか」を無料でチェックできるGoogleが運営するサービスです。「このファイル、怪しいけど大丈夫かな？」と思ったときに使う、セキュリティ界の「口コミサイト」のようなものです。ユーザーがコメントや評価を付けることもできます。

### 🤖 スナイパーボット・クラッシュゲームとは？
- **ソラナ/Pump.funスナイパーボット**：暗号資産の新しいコイン発行直後に自動で素早く購入し、利益を得ようとする自動プログラムです。
- **クラッシュゲーム予測ツール**：オンラインギャンブルの一種で、数値が「クラッシュ（暴落）」するタイミングを予測して賭けるゲームの結果を予測すると謳うツールです。

どちらも「楽して儲けたい人向け」のツールとして宣伝されています。

## 何が起きたのか

セキュリティ企業「Check Point Research」が、**正規のプラットフォームをフル活用して偽の信頼性を作り上げ、暗号資産を盗むマルウェアを配布している謎の攻撃者グループ**を発見しました。

### 📣 どうやって被害者を集めたか（宣伝方法）

この攻撃者グループは、まるで本物の企業のマーケティング戦略のように、複数のプラットフォームで「信頼性の演出」を行いました。

| プラットフォーム | やっていたこと |
|---|---|
| 正規ニュースサイト | 有料投稿・宣伝記事を掲載（USA TODAYネットワークにも配信） |
| YouTube | 91,000人超の登録者を持つチャンネルでAIナレーターによるチュートリアル動画を公開 |
| GitHub | 少なくとも6つの偽アカウントで相互宣伝、スターやフォーク数を水増し |
| SourceForge | ダウンロード数を44,485件に水増し（うち37,460件はAndroid端末から！） |
| VirusTotal | 偽アカウントで「安全」と評価するコメントや高評価を投稿 |
| WordPress | フィッシング用の中心サイトを運営 |

> 💡 **特に驚きなのは**、EIN Presswireというプレスリリース配信サービスまで使って宣伝したこと。これにより、USA TODAYの関連サイトなど「普段信頼できると思われているニュースサイト」にまで記事が掲載されてしまいました。

## 技術的な詳細

### 🦠 マルウェアの正体：「クリプトクリッパー」

配布されていたのは **「クリプトクリッパー（Cryptocurrency Clipboard Hijacker）」** と呼ばれるマルウェアです。

**仕組みをわかりやすく説明すると…**

```
【通常の送金操作】
① 送り先のウォレットアドレスをコピー（例：abc123...）
② 送金画面に貼り付け（abc123...）
③ 送金 → 正しい相手に届く ✅

【クリッパーに感染した場合】
① 送り先のウォレットアドレスをコピー（例：abc123...）
② マルウェアがクリップボードを監視して、こっそり攻撃者のアドレスに書き換え！
③ 送金画面に貼り付け（xyz999...←攻撃者のアドレス！）
④ 送金 → 攻撃者の口座に届く 💸
```

ウォレットアドレスは長い文字列なので、貼り付けたあとにいちいち確認する人は少なく、気づかないうちに騙されてしまいます。

### 🖥️ 対応OSと使用言語

- **対応OS**：WindowsとmacOS（両方！）
- **プログラミング言語**：Rust（高速で検出されにくい言語）

### 👻 「ゴーストネットワーク」によるVirusTotal汚染

攻撃者は**複数の偽アカウント（ゴーストネットワーク）**を使ってVirusTotalに組織的にアクセスし、

- 悪意あるファイルに「👍 高評価」をつける
- 「このファイルは安全です！」という偽コメントを投稿する

という操作を行いました。セキュリティチェックの「口コミ」を偽造したわけです。

### 📱 Androidファームによるダウンロード数水増し

SourceForgeのダウンロード数のうち、**37,460件がAndroid端末から**というデータがありました。しかし、このツールはWindowsとmacOS専用です。つまり、**大量のAndroid端末を使ったbot（自動プログラム）でダウンロード数を水増し**していたと考えられます。

## なぜ重要なのか

### 🚨 「信頼できる場所」が信頼できなくなる時代

今回の攻撃の最大の問題点は、**「普段信頼している場所の情報が全て偽物だった」** という点です。

- ✅ 有名ニュースサイトに掲載されてる → 本当は有料宣伝記事
- ✅ VirusTotalでウイルス判定なし・高評価コメント → 偽アカウントによる工作
- ✅ GitHubで星がたくさんついてる → 自作自演で水増し
- ✅ YouTubeに丁寧な解説動画がある → AIが自動生成したナレーター
- ✅ ダウンロード数が多い → Androidボットで水増し

**全部が偽物でも、バラバラに見るとどれも「本物っぽく見える」** のが今回の攻撃の巧妙さです。

### 💰 ターゲットは「楽して儲けたい人」

- 暗号資産で素早く利益を出したい人
- オンラインギャンブルで勝ちたい人

こうした層は「便利なツール」を求めて検索し、上記の偽の信頼シグナルを信じてダウンロードしてしまう可能性が高いです。

### 🔮 さらに危険な可能性

Check Pointは「同じ手口で、将来的には**情報を盗むマルウェアやランサムウェア（身代金型ウイルス）**を配布することも容易にできる」と警告しています。今回はクリッパーでしたが、この「偽信頼構築システム」自体が非常に危険です。

## 対策・今後の展望

### 🛡️ あなたにできる対策

#### 1. 暗号資産の送金時は必ず目視確認！
```
⚠️ コピー → 貼り付けたアドレスを、元のアドレスと
   最初の5文字・最後の5文字を必ず目で確認する！
```

#### 2. ダウンロード前の「信頼シグナル」を疑う

| 確認項目 | 怪しいポイント |
|---|---|
| GitHubのスター数 | 急に増えていないか？コードの内容と釣り合っているか？ |
| VirusTotalのコメント | やたらと褒めているコメントが多くないか？ |
| YouTubeの視聴数 | コメント欄が不自然に好意的すぎないか？ |
| ダウンロード数 | SourceForgeなどの数字は水増しの可能性がある |

#### 3. 「楽して儲かるツール」には特に警戒
「スナイパーボット」「予測ツール」などの**「魔法のような利益を約束するツール」は詐欺の温床**です。

#### 4. ソフトウェアは公式サイトから
GitHubやSourceForgeは誰でも公開できます。**必ず公式の開発元サイトを確認**しましょう。

#### 5. クリップボード監視ツールを使う
一部のセキュリティソフトはクリップボードの不審な変更を検知してくれます。

### 📅 今後の展望

- プラットフォーム側（GitHub、VirusTotal、YouTube等）の**偽アカウント検出強化**が求められる
- プレスリリース配信サービスの**コンテンツ審査強化**も必要
- AIによる偽コンテンツ生成が容易になった今、**信頼の判断基準そのものを見直す**時代に来ている

## 用語解説

| 用語 | 解説 |
|---|---|
| **クリプトクリッパー（Crypto Clipper）** | クリップボードの暗号資産ウォレットアドレスをこっそり攻撃者のアドレスに書き換えるマルウェア |
| **ウォレットアドレス** | 暗号資産の「口座番号」にあたる長い文字列 |
| **VirusTotal** | ファイルやURLのウイルス判定を行うGoogleのサービス |
| **ゴーストネットワーク（Ghost Network）** | 組織的な偽装工作のために使われる大量の偽アカウント群 |
| **SourceForge / GitHub** | ソフトウェアを公開・配布できる開発者向けプラットフォーム |
| **Pump.fun** | ソラナブロックチェーン上で新しいコインを簡単に作れるサービス |
| **スナイパーボット** | 新コイン発行直後に自動で素早く購入する自動プログラム |
| **ランサムウェア** | パソコンのデータを暗号化して「解除したければお金を払え」と脅すウイルス |
| **Rust** | 高速・高安全性のプログラミング言語。マルウェアにも使われることがある |
| **EIN Presswire** | プレスリリースを多数のニュースサイトに自動配信するサービス |
| **ソーシャルエンジニアリング** | 技術的手段ではなく、人の心理や信頼を悪用して情報を盗んだり騙したりする攻撃手法 |
| **フィッシングページ** | 本物そっくりに作られた偽サイト。個人情報を盗むために使われる |
