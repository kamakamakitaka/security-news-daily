# 初心者ハッカーがTailscaleとOpenSSHを使って侵入口を確保し続けた話

**元記事**: [Junior Hacker Used Tailscale and OpenSSH to Keep Access After His C2 Went Offline](https://inl03.netline.com/ltr6/?_m=3n.009a.4007.sp0ao46r89.327a)
**解説日**: 2025年6月19日

---

## 背景知識

この記事を理解するために、いくつかの基本的な概念を押さえておきましょう。

### 🏠 「侵入」の基本的な仕組み

サイバー攻撃者がパソコンに不正侵入するのは、泥棒が家に入り込むのと似ています。ただし家の鍵を壊すのではなく、**マルウェア（悪意のあるプログラム）** を仕込んで、遠隔操作できる「裏口」を作ります。

### 📡 C2（シーツー）サーバーとは？

**C2（Command and Control）サーバー**は、攻撃者が感染したパソコンに「命令を出す」ための拠点サーバーです。

```
攻撃者のパソコン ──→ C2サーバー ──→ 被害者のパソコン
　（命令を送る）　　　（中継地点）　　（命令を受け取る）
```

家で例えると、**攻撃者が直接家に来るのではなく、電話（C2サーバー）を通じて家の中にいる手下に指示を出す**イメージです。

### 🔑 OpenSSHとTailscaleとは？

- **OpenSSH**：パソコンをネットワーク越しに安全に操作するための仕組み。IT管理者が普通に使う正規のツールです。
- **Tailscale**：複数のパソコンを「プライベートな仮想ネットワーク」でつなぐ正規のサービス。VPN（仮想プライベートネットワーク）の一種です。

どちらも**合法的なツール**であるため、セキュリティソフトに検知されにくいのが厄介なポイントです。

### 🎹 キーロガーとは？

**キーロガー**は、キーボードで打ったすべての文字を記録するプログラムです。パスワードやIDを「打った瞬間に盗む」ことができます。

## 何が起きたのか

### 事件の概要

フランス語を話す攻撃者（ハンドルネーム「**Poisson（ポワソン）**」、フランス語で「魚」の意味）が、**フランスの小さな自動車関連企業**に侵入しました。

**被害の流れ（全33日間）：**

| 時期 | 出来事 |
|------|--------|
| 侵入初期 | マルウェア仕込み・キーロガー設置 |
| 4月7日 | OpenSSHとTailscaleを密かにインストール |
| 4月8日 | C2サーバーが突然オフライン（停止） |
| 4月8日〜26日 | C2は落ちているが、Tailscale経由で引き続きアクセス可能 |
| 4月26日 | C2が復活、エージェントが自動で再接続 |
| 5月1日 | 攻撃者が活動を停止 |

### 盗まれたもの

- **銀行のログイン情報**
- **メールのパスワード**
- **政府ポータルサイトのID・パスワード**

中小企業のオーナーにとっては、直接的な金銭的被害につながる情報ばかりです。

## 技術的な詳細

### 🧱 攻撃の「積み上げ方」

攻撃者は侵入後、まるで**家に複数の鍵と裏口を作る**ように、アクセス手段を重ねていきました。

```
【通常の攻撃（1本の柱）】
攻撃者 → C2サーバー → 被害者PC
　　　　　※C2が落ちたら終わり

【今回の攻撃（複数の柱）】
攻撃者 → C2サーバー      → 被害者PC
攻撃者 → Tailscaleネット → 被害者PC（←これが残った！）
攻撃者 → RustDesk        → 被害者PC（バックアップ）
```

### 🐛 マルウェアの仕組み（ステップ別）

**Step 1: 入口（VBScript）**
- 「少し待つ」処理（サンドボックス回避）を入れた起動スクリプト
- ※サンドボックス＝セキュリティソフトがマルウェアを試験的に動かすための隔離環境

**Step 2: 本体読み込み（PowerShell → .NETローダー）**
- ディスクにファイルを書き込まず、**メモリ上だけで動作**（フォレンジック調査を難しくするため）
- ※フォレンジック調査＝デジタルの証拠を調べること

**Step 3: 遠隔操作（Havocエージェント）**
- 「Havoc」という攻撃者向けフレームワークの操作エージェントを起動

**Step 4: 権限昇格**
- `Start-Process -Verb RunAs` というコマンドで管理者権限を要求
- ⚠️ただし**Windowsの確認ダイアログが表示される**（こっそりできない方法）
- 被害者が「はい」を押すまで、ある機器では2日間・12回も試し続けた

**Step 5: 居座り（持続化）**
- ログオンのたびに最高権限で起動する**スケジュールタスク**を仕込む
- Explorer.exeというWindowsの基本プロセスに**シェルコードを注入**

**Step 6: 情報収集（キーロガー）**
- たった70行のPythonコードで書かれたシンプルなキーロガー
- 自動送信機能はなく、**攻撃者が手動でファイルを取りに来る**方式
- パソコンがスリープしないよう `powercfg` コマンドを使用

### 🚪 「最重要の一手」：Tailscale＋SSH

4月7日の深夜5時間にわたる作業で：

1. **OpenSSH Server** をインストール（リモートでコマンド操作できる扉）
2. **Tailscale** をインストールして、自分のプライベートネットワークに参加させる
3. 鍵認証でSSH接続できるよう設定
4. リバーストンネルを設置

これにより、C2サーバーとはまったく別のルートで、**ファイアウォールもすり抜けて**被害者PCに接続できるようになりました。

## なぜ重要なのか

### 💡 「C2を落としても終わらない」という教訓

従来のセキュリティ対応では「C2サーバーを特定してブロックすれば侵入を遮断できる」と考えられていました。しかし今回の事件は、それだけでは**不十分**であることを示しています。

> **研究者の結論：「攻撃者が別の入口をすでに作っていたなら、C2をオフラインにしても対処にならない」**

### 😮 「初心者でも4台を乗っ取れた」という現実

攻撃者「Poisson」は、研究者から「初心者レベル」と評されています：

- 自分のSSHキーを5回も外部に漏らした
- ストレージバケットに自分のハンドルネームをつけた
- キーロガーのテストファイルに自分のキーストロークを残した
- 試みた操作の約半分が失敗

それでも**4台のPCを乗っ取りました**。完璧な技術がなくても、既存の正規ツールを組み合わせるだけで、これだけの被害が出るのです。

### 🕐 行動パターンから見えること

- 活動時間：午後3時（CET）以降、昼は長い休憩
- → 研究者は「**学校のスケジュール**」に合わせた行動パターンと分析
- 使用ツールはすべて**無料または格安**（DuckDNS、Backblaze B2、月数百円のVPS）

### 🌐 「正規ツール悪用」という業界的トレンド

今回の攻撃で使われたTailscaleやOpenSSHは、**国家レベルの攻撃者も使う手法**です：

- 中国のAPT31：2024〜2025年にTailscaleを使ってロシアのIT企業から情報を窃取
- Scattered Spider（犯罪グループ）：NgrokやFleetdeckなど正規ツールを悪用
- Akiraランサムウェア：RustDesk（今回の攻撃でも使われたツール）を活用

「ファイルが正規・署名済みだからセーフ」では通用しない時代になっています。

## 対策・今後の展望

### ✅ 個人・企業でできる対策

**1. 「動作」ベースの検知を導入する**
- ファイルの「良し悪し」ではなく、「何をしているか」を監視するEDR（Endpoint Detection and Response）ツールを活用
- 例：「正規のTailscaleが突然インストールされた」という**異常な動作**を検知する

**2. ネットワーク監視を強化する**
- 見慣れないサービス（Tailscaleなど）への接続を検知・ブロック
- 社内PCが突然外部のネットワークに参加していないか確認

**3. スケジュールタスクと自動起動を定期確認**
- 知らない間に設定されたスケジュールタスクがないか定期的にチェック
- Windowsの場合：タスクスケジューラを開いて確認

**4. インシデント対応時の確認事項を増やす**
- C2をブロックして終わりにせず、「別の侵入路が作られていないか」を必ずチェック
- SSH、Tailscale、RustDesk等のインストール履歴を確認

**5. 最小権限の原則**
- 一般ユーザーが管理者権限を持たないようにする
- 今回の攻撃では「管理者権限の確認ダイアログ」を被害者自身がクリックしてしまった

### 🔮 今後の展望

正規ツールを悪用する「LOTL（Living off the Land：現地調達型）攻撃」は今後も増加が予想されます。セキュリティ製品側も「ファイルの署名」ではなく「コンテキスト（状況・文脈）」で判断する技術へのシフトが加速するでしょう。

どちらも「**見えていないリスクを可視化すること**」の重要性を教えてくれています。ネットワーク内に「知らないうちに存在している接続」がないか、定期的に棚卸しすることが、現代のセキュリティにおける基本姿勢と言えるでしょう。

## 用語解説

| 用語 | 意味 |
|------|------|
| **C2（Command and Control）サーバー** | 攻撃者がマルウェアに命令を出すための中継サーバー |
| **キーロガー** | キーボード入力をすべて記録するプログラム |
| **Tailscale** | 複数のPCをプライベートネットワークでつなぐ正規のVPNサービス |
| **OpenSSH** | ネットワーク越しにPCを安全に遠隔操作するための正規ツール |
| **Havoc** | 攻撃者向けのリモート操作フレームワーク（ペネトレーションテストツールとして公開されているが悪用される） |
| **RustDesk** | オープンソースのリモートデスクトップソフト（正規ツール） |
| **サンドボックス** | マルウェアを安全に動かして分析するための隔離環境 |
| **PowerShell** | Windowsに標準搭載されているスクリプト実行環境 |
| **UAC（ユーザーアカウント制御）** | Windowsが管理者権限を要求する操作時に表示する確認ダイアログ |
| **フォレンジック** | デジタル機器からサイバー犯罪の証拠を収集・分析すること |
| **スケジュールタスク** | 指定した条件でプログラムを自動実行するWindowsの機能 |
| **リバーストンネル** | 外部からファイアウォールを越えて内部PCに接続するための仕組み |
| **APT** | Advanced Persistent Threat。国家が支援する高度な持続的サイバー攻撃グループ |
| **LOTL（現地調達型攻撃）** | OSや正規ソフトウェアのツールを悪用して攻撃すること。検知が難しい |
| **EDR** | Endpoint Detection and Response。PCの動作を監視して脅威を検知・対応するセキュリティツール |
| **VPS** | Virtual Private Server。格安で借りられる仮想的なサーバー |
