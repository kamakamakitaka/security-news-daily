# 悪意あるJetBrainsプラグインがAI APIキーを盗み、Chrome拡張機能がAIチャットの会話を丸ごと記録

**元記事**: [Malicious JetBrains Plugins Steal AI API Keys as Chrome Extensions Capture Chatbot Chats](https://inl03.netline.com/ltr6/?_m=3n.009a.4007.sp0ao46r89.327m)
**解説日**: 2026年6月19日

---

## 背景知識

このニュースを理解するために、いくつかの基本知識を押さえておきましょう。

### 🧩 JetBrainsとは？
**JetBrains**は、プログラマーがコードを書くときに使う「統合開発環境（IDE）」を作っている会社です。IntelliJ IDEA、PyCharm、WebStormなどが有名で、世界中の多くのプロのプログラマーが毎日使っています。  
IDEは「コードを書くための高機能なメモ帳＋便利ツール」のようなもの、とイメージしてください。

**JetBrains Marketplace**は、そのIDEに機能を追加できる「プラグイン（拡張機能）」を配布している公式ストアです。スマホのアプリストアと同じ仕組みです。

### 🔑 APIキーとは？
**API（Application Programming Interface）** とは、アプリやサービス同士が「会話」するための窓口です。  
**APIキー**は、その窓口を使うための「合言葉＝パスワード」のようなものです。

例えば、ChatGPT（OpenAI）のAPIキーを持っていれば、自分のプログラムからChatGPTを呼び出して使うことができます。ただし、**使った分だけお金がかかる**ため、このキーはクレジットカード番号と同じくらい大切な秘密情報です。

### 🤖 DeepSeekとは？
**DeepSeek**は、中国発の高性能なAI（大規模言語モデル）です。ChatGPTやGeminiと同じように会話やコード生成ができるAIで、最近注目を集めています。

### 🔒 LLMジャッキングとは？
**LLMジャッキング（LLMjacking）**とは、他人のAI APIキーを盗んで勝手に使う犯罪行為です。被害者は知らないうちに高額なAI利用料を請求されます。

---

## 何が起きたのか

セキュリティ企業「Aikido Security」の研究者が、**JetBrains Marketplace（公式プラグインストア）に15個もの悪意あるプラグインが登録されていた**ことを発見しました。

これらのプラグインは表向きには「DeepSeekなどのAIを使ったコーディング支援ツール」として公開されており、実際にAIコーディング機能も動きます。しかし**裏では、ユーザーが入力したAI APIキーを攻撃者のサーバーに密かに送信していました**。

### 被害の規模
- 🗓️ 活動開始：2025年10月末頃〜（2026年6月10日にも新しいプラグインが確認）
- 📦 悪意あるプラグイン数：**15個**
- 📥 「CodeGPT AI Assistant」と「DeepSeek AI Assist」は**それぞれ25,000件以上のダウンロード**（ただし水増しの可能性あり）

## 技術的な詳細

### 🎭 どうやって騙すのか？

```
【ユーザーの操作】
①プラグインをインストール
②設定画面でAI APIキーを入力（ChatGPT・DeepSeekなど）
③AIコーディング機能を使う

【裏で起きていること】
②のタイミングで → APIキーを攻撃者のサーバー（39.107.60.51）に送信！
                    ※暗号化なし（HTTP平文）でダダ漏れ
```

ポイントは「**プラグインは本当に動く**」という点です。コード補完も、バグ検出も、ちゃんと機能します。だから疑われにくいのです。これは、偽ブランド品のバッグが見た目はそっくりなのに中身が粗悪品、というのと似ています。

### 💰 さらに悪質な「有料サービス」の手口

このプラグイン群は有料プランまで用意していました：

1. ユーザーが少額の「寄付」を払う
2. 攻撃者のサーバーから**別のAPIキー**が送られてくる
3. そのキーを使ってAI機能が動き続ける

この「別のAPIキー」こそ、**他の被害者から盗んだAPIキー**です！

```
攻撃者の収益モデル：

右側の被害者からAPIキーを盗む
        ↓
左側の「有料ユーザー」に盗んだキーを使わせる
        ↓
攻撃者は「寄付金」と「無料のAI利用」の両取り！
        ↓
本当のAPIキーの持ち主だけが高額請求を受ける
```

研究者は「**正規の事業者が、制限なしの有効なAPIキーをユーザーにただ渡すわけがない**」と指摘しており、この動作自体が怪しさの証拠でもあります。

### 😈 同時に発覚したChrome拡張機能の問題

さらに同じタイミングで、Chromeの**広告ブロッカーを装った拡張機能が2つ**、AIチャットの会話内容を盗んでいたことも発覚しました。

**盗聴されていたAIサービス：**
- ChatGPT（OpenAI）
- Claude（Anthropic）
- Gemini（Google）
- Copilot（Microsoft）
- Perplexity
- DeepSeek
- Grok（xAI）
- Meta AI

これらの拡張機能はまだChrome Web Storeに公開されており、合計で**90,000人以上のユーザー**が影響を受けている可能性があります。この攻撃は研究者により「**PromptSnatcher（プロンプト泥棒）**」と命名されました。

## なぜ重要なのか

### 💸 金銭的な被害
AIのAPIキーは、使えば使うほどお金がかかります。OpenAIのAPIを月に数万円分使っているエンジニアも珍しくありません。キーを盗まれると、**知らないうちに数十万〜数百万円の請求が来る**可能性があります。

### 🏢 企業への影響
プロのプログラマーは会社の仕事でこれらのツールを使います。**企業の機密コードや業務データが含まれたAI会話が盗まれる**と、情報漏洩・競合他社への情報流出につながります。

### 🎯 なぜ開発者が狙われるのか？
記事でも指摘されているように、開発者の環境には：
- ソースコード
- クラウドの認証情報
- 署名キー
- 高額なAIサービスのAPIキー

...など、**攻撃者にとって非常に価値の高いものが集まっています**。だからこそ「開発ツール」は格好の標的になっているのです。

### 🔓 公式ストアでも安全ではない
今回の事件で特に怖いのは、**公式のJetBrains Marketplaceに15個もの悪意あるプラグインが長期間（8ヶ月以上）存在していた**という点です。「公式ストアだから安全」という思い込みが危険だということを示しています。

## 対策・今後の展望

### ✅ 今すぐできる対策

#### プラグイン・拡張機能を使う人向け
1. **上記15個のプラグインをすぐにアンインストール**する
2. 使ったことがある場合は、**OpenAI・DeepSeek・SiliconFlowなどのダッシュボードでAPIキーを即座に無効化・再発行**する
3. 利用明細を確認し、身に覚えのないAI利用料がないかチェックする

#### 今後のプラグイン選定時
- ダウンロード数が多くても鵜呑みにしない（水増しされている可能性がある）
- **開発元・レビュー・ソースコード**を確認する
- 有名で信頼できる企業が作ったプラグインを選ぶ
- 「APIキーの入力を求めるプラグイン」には特に注意する

#### Chrome拡張機能について
- Smart Adblocker（ID: iojpcjjdfhlcbgjnpngcmaojmlokmeii）を使っている場合は削除する
- AIとの会話に個人情報・会社の機密情報を含める際は注意する

### 🔮 今後の展望
Aikido Securityは「**プラグインも依存ライブラリと同じ感覚で扱い、十分に検証していないツールに長期間有効な秘密情報を貼り付けないこと**」と強く警告しています。

AIツールの普及に伴い、このような「AI系ツールを装った攻撃」は今後さらに増えると予想されます。JetBrainsなどのプラットフォーム側も、審査体制の強化が求められています。

以前「**初心者ハッカーがTailscaleとOpenSSHを使って侵入口を確保し続けた話**」を解説しましたが、今回の事件とも共通するテーマがあります。

前回の記事では「攻撃者が一度侵入した後、バックドア（裏口）を使って継続的にアクセスし続ける」手法が紹介されました。今回も同様に、**攻撃者は一度プラグインをインストールさせることで、継続的にAPIキーを収集し続けるという「持続的な攻撃」**を行っています。

どちらの事件も「最初の侵入・感染をいかに防ぐか」が重要であり、怪しいツールを安易にインストールしないことの大切さを改めて示しています。

## 用語解説

| 用語 | 解説 |
|------|------|
| **JetBrains Marketplace** | JetBrains製IDEに機能を追加するプラグインの公式配布ストア |
| **プラグイン（Plugin）** | ソフトウェアに後から機能を追加する小さなプログラム。スマホのアプリに似ている |
| **APIキー** | 外部サービスを利用するためのパスワードのようなもの。使用量に応じて課金される |
| **exfiltration（エクスフィルトレーション）** | 機密データを外部に不正に持ち出すこと |
| **LLMジャッキング** | 他人のAI APIキーを盗み、勝手にAIサービスを利用する詐欺・犯罪行為 |
| **HTTP平文送信** | データを暗号化せずにそのままインターネットで送ること。第三者に見られるリスクがある |
| **C2サーバー（C&Cサーバー）** | 攻撃者がマルウェアに命令を送ったり、盗んだデータを受け取ったりするためのサーバー |
| **DeepSeek** | 中国発の高性能AI（大規模言語モデル）。ChatGPTに似た会話・コード生成ができる |
| **PromptSnatcher** | 今回のChrome拡張機能によるAI会話盗聴作戦の研究者命名コードネーム |
| **マルウェア（Malware）** | 悪意を持って作られた不正なソフトウェアの総称 |
| **Chrome Web Store** | GoogleのブラウザChromeに拡張機能を追加できる公式ストア |

---

> 💡 **まとめ**：公式ストアだからといって100%安全ではありません。特に「APIキーの入力を求めるツール」は十分に信頼できる出所かどうか確認してから使いましょう。もし今回の15プラグインを使ったことがある人は、**すぐにAPIキーを無効化して再発行してください！**
