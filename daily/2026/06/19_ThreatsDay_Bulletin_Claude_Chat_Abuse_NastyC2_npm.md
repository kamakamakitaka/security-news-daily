## 背景知識

このニュースを理解するために、いくつかの基本的な概念を先に説明します。

### 🌐 DNSとは？
インターネット上の「住所録」のようなものです。「google.com」と入力したとき、それをコンピューターが理解できるIPアドレス（数字の住所）に変換してくれる仕組みです。通常この通信は「暗号化されていない」ため、第三者に覗き見される可能性があります。

### 🔐 DoH（DNS over HTTPS）とは？
上記のDNS通信を、HTTPS（暗号化された通信）に乗せて安全にする技術です。通信内容が暗号化されるので、「どのサイトにアクセスしようとしているか」を第三者に見られにくくなります。

### 🧩 ブラウザ拡張機能とは？
ChromeやEdgeなどのブラウザに後から追加できる「プラグイン」のことです。「翻訳ツール」「広告ブロッカー」など便利なものが多いですが、悪意のあるものも存在します。

### 🤖 ClickFixとは？
「このエラーを修正するにはこのコマンドを実行してください」と偽の画面を見せ、ユーザー自身に悪意のある命令を実行させる騙しの手口です。まるで「詐欺師が電話で指示を出す」ようなものです。

### 📦 npmパッケージとは？
プログラマーが使う「部品集」のようなもので、JavaScriptというプログラミング言語のライブラリ（便利な機能のセット）が公開されている場所です。誰でも投稿できるため、悪意のある「偽の部品」が混入することがあります。

## 何が起きたのか

今週は特に以下の4つの大きな出来事がありました：

### 1️⃣ Microsoft が DNS暗号化（DoH）をWindows Server 2025に正式導入
Microsoftが、企業向けサーバーOSである「Windows Server 2025」に、DNS通信を暗号化する技術「DoH」を正式に搭載したと発表しました。これは明るいニュースです。

### 2️⃣ 23個の偽ブラウザ拡張機能が75万人以上の検索を横取りしていた
Chromeの拡張機能に見せかけた悪意のあるプログラムが23種類発見されました。「衛星画像ビューア」「ニュースリーダー」「地図ツール」などを装いながら、実際にはユーザーの検索を横取りして収益を得ていました。

### 3️⃣ macOSを狙った「痕跡を残さない」マルウェア攻撃
Macユーザーを狙った攻撃が発見されました。特に巧妙なのは、**ファイルをほとんどディスクに保存せず、コンピューターのメモリ上だけで動作する**という点です。これにより発見が非常に難しくなっています。

### 4️⃣ AI「Claude」のチャット共有機能がマルウェア配布に悪用された
Anthropicが提供するAIチャット「Claude」の「チャット内容を共有するリンク」機能が、マルウェア配布に悪用されました。

## 技術的な詳細

### 🔍 偽ブラウザ拡張機能の仕組み

```
ユーザーがGoogleで検索
　　↓
拡張機能が検索を横取り
　　↓
「マネタイズ業者（仲介業者）」8社を経由
　　↓
（この間にユーザーの検索内容が全部抜き取られる）
　　↓
ようやく検索結果が表示される
```

75万8,000人以上のユーザーが影響を受け、検索するたびに「何を調べたか」が知らないうちに第三者に送られていました。さらに怖いのは、**拡張機能を更新しなくても**、業者側がいつでも「普通の検索結果」から「フィッシングサイトへの誘導」に切り替えられるという点です。

### 🍎 macOSを狙った「ClickFix」攻撃の仕組み

```
① 偽の「マルウェアスキャンツール」ダウンロードページを見せる
　　↓
② 「このコマンドをコピーして実行してください」と指示
　　（curlコマンド：ネットからファイルを取得する命令）
　　↓
③ 悪意のあるスクリプトがメモリ上で直接実行される
　（ファイルとして保存されないので発見されにくい）
　　↓
④ 偽のシステムダイアログ（パスワード入力画面）が表示される
　　↓
⑤ パスワード・ブラウザのクッキー・暗号資産ウォレット情報を盗まれる
```

このマルウェアの名前は「**Meow (DEBUG)**」というコードネームで、ロシア語話者と見られる攻撃者がアジア・北米・オセアニアのIT・メディア企業を狙っています。

### 🤖 Claudeのチャット共有機能の悪用

```
攻撃者がClaudeで「それっぽいチャット」を作成
　　↓
その共有リンクをメールやSNSで拡散
　　↓
被害者がリンクを開く
（「claude.ai」という正規のドメインなので信頼してしまう）
　　↓
「MacSync」というマルウェアをダウンロードさせる
```

ポイントは「**claude.aiという本物のURLだから信頼してしまう**」という点です。詐欺師が有名デパートの名前を使って信頼させるのと同じ手口です。

## なぜ重要なのか

### 📊 影響の大きさ

| 脅威 | 影響規模 |
|------|----------|
| 偽ブラウザ拡張機能 | **75万8,000人以上**が検索内容を盗まれた |
| macOSマルウェア | アジア・北米・オセアニアの企業が標的 |
| Claudeチャット悪用 | 正規URLで偽装するため見破りにくい |

### ⚠️ 特に注意すべきポイント

1. **「正規のサービスだから安全」とは限らない**
   → Claudeやnpmなど、信頼できるサービスの機能が悪用されています

2. **Macは「安全」という神話は崩れつつある**
   → macOSを狙った高度な攻撃が増えています

3. **ブラウザの拡張機能は「見た目の機能」と「実際の動作」が違う場合がある**
   → インストールする前によく確認が必要です

## 対策・今後の展望

### ✅ 今すぐできる対策

#### ブラウザ拡張機能について
- 🗑️ 使っていない拡張機能は今すぐ削除する
- 🔍 インストール済みの拡張機能のレビューや評判を確認する
- ⚠️ 「なんとなく便利そう」で追加しない

#### macOSユーザーへ
- 🚫 「このコマンドをコピーして実行してください」という指示には絶対従わない
- 💻 ダウンロードは公式サイトや App Store のみ利用する

#### AIチャットのリンクについて
- 🤔 「claude.aiのURLだから安全」と思わない
- 📩 SNSやメールで送られてきたAIチャットのリンクは慎重に扱う

#### 全般
- 🔄 OSやブラウザを常に最新版に保つ
- 🛡️ 信頼できるセキュリティソフトを使う

### 🔭 今後の展望

- **DoHの普及**によってDNS通信の盗み見は減少していく見込み
- 一方で、**正規サービスを悪用する攻撃**（Claudeの件など）は今後さらに増える可能性が高い
- AI機能の「共有リンク」や「埋め込み機能」はセキュリティ的な新たなリスクになりつつある

## 用語解説

| 用語 | 意味 |
|------|------|
| **DNS** | インターネットの住所録。ドメイン名をIPアドレスに変換する仕組み |
| **DoH（DNS over HTTPS）** | DNS通信を暗号化して安全にする技術 |
| **ClickFix** | 「エラーを直すためにこのコマンドを実行して」と騙す攻撃手法 |
| **フィッシング** | 偽サイトや偽メールでパスワードなどを騙し取る攻撃 |
| **マルウェア** | 悪意のあるソフトウェアの総称（ウイルスなども含む） |
| **ファイルレス攻撃** | ファイルをディスクに保存せず、メモリ上だけで動く攻撃（発見が難しい） |
| **C2（Command and Control）** | 攻撃者がマルウェアに命令を送るためのサーバー |
| **npmパッケージ** | プログラマー向けのJavaScriptの部品集が公開されている場所 |
| **インフォスティーラー** | パスワード・クッキー・個人情報などを盗むマルウェア |
| **クッキー（Cookie）** | ブラウザに保存される「ログイン状態」などの小さなデータ |
| **マネタイズ** | お金を稼ぐこと。ここでは検索を横取りして広告収益を得ること |
| **Zero Trust** | 「誰も最初から信頼しない」というセキュリティの考え方 |

---

> 💡 **今週の教訓**
> 「正規のサービスのURLだから安全」「MacだからWindowsより安全」という思い込みは危険です。攻撃者は常に「信頼」を武器にして騙しにきます。どんなに有名なサービスのリンクでも、少し立ち止まって「本当に大丈夫か？」と考える習慣をつけましょう。
