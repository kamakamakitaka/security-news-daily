# AIエージェントが乗っ取られる！「AutoJack」攻撃でパソコンを遠隔操作される脆弱性

**元記事**: [AutoJack Attack Lets One Web Page Hijack AI Agent for Host Code Execution](https://inl03.netline.com/ltr6/?_m=3n.009a.4009.sp0ao46r89.329w)
**解説日**: 2026年6月20日

---

## 背景知識

まず、この記事を理解するために必要な用語や仕組みを説明します。

### 🤖 AIエージェントって何？
「AIエージェント」とは、人間のかわりに自動でブラウザを操作したり、ウェブサイトを見て情報を集めたりしてくれるAIのことです。たとえば「このサイトの内容を要約して」と命令すると、AIが自分でブラウザを開いてページを読み、まとめてくれます。まるで「自分専用のAIアシスタント」がパソコンを操作するイメージです。

### 🏠 localhostって何？
「localhost（ローカルホスト）」とは、**自分のパソコン自身のこと**を指します。自分のパソコンの中だけで動いているサービスや機能にアクセスするときに使います。「家の中だから安全」と判断されることが多いのです。

### 🔧 AutoGen Studioって何？
マイクロソフト研究部門が作った、AIエージェントを簡単に試したり開発したりできるツールです。「オープンソース」といって、誰でも無料で使えます。

### 💻 リモートコード実行（RCE）って何？
「Remote Code Execution（遠隔コード実行）」とは、**攻撃者が遠隔から被害者のパソコンで任意のプログラムを実行できる**状態のことです。セキュリティ上、最も危険な脆弱性の一つとされています。鍵を持っていないのに、遠くから家の中を操作できるようなイメージです。

### 📦 PyPIって何？
Pythonというプログラミング言語のソフトウェアを配布する公式サイトです。`pip install`というコマンドでソフトをインストールするときに使われます。「アプリストア」のようなものです。

## 何が起きたのか

マイクロソフトの研究者が、**「AutoJack（オートジャック）」** と名付けられた攻撃手法を発見しました。

### 事件の流れをわかりやすく説明すると…

> 1. あなたのパソコンでAIエージェント（ブラウザを自動操作するAI）が動いている
> 2. 攻撃者が罠のウェブページを用意する
> 3. AIエージェントがその罠ページを開く（メールのリンクや指示を通じて）
> 4. **たったそれだけで、攻撃者があなたのパソコンでプログラムを実行できる！**

しかも怖いのは、**パスワードも、ログイン画面も、追加の操作も一切不要**という点です。AIがページを開いた瞬間に攻撃が成立します。

研究者が実証実験で示したのは、「Webページの内容を要約するAIエージェント」に悪意あるURLを与えたところ、**開発者のデスクトップで勝手に「電卓アプリ（calc.exe）」が起動した**というものです。電卓なら無害ですが、これが悪意あるプログラムだったら…と考えると非常に危険です。

---

## 技術的な詳細

AutoJack攻撃は、**3つの弱点を組み合わせた連鎖攻撃**です。ドアを3つ開けて家に侵入するようなイメージです。

### 弱点①：「localhost＝安全」という思い込み
```
通常のブラウザ → 「localhost」のサービスにアクセス → ブロック！
AIエージェント → 「localhost」のサービスにアクセス → 通過してしまう！
```
AutoGen StudioはWebSocket（リアルタイム通信の仕組み）を使って「localhost（自分のパソコン）からのアクセスだけ信頼する」という設定でした。でも、AIエージェントは**同じパソコン上で動いている**ので、自動的に「localhost扱い」になってしまいます。

👉 **例え話**：「家族だけが使える部屋の鍵」なのに、「家に住んでいる人なら誰でも家族扱い」というルールにしてしまった状態です。

### 弱点②：認証（本人確認）が完全にスルーされていた
```
認証システム「MCP路由は認証しなくていいや、ハンドラーが確認するから」
ハンドラー「え、認証？してないよ？」
→ 結果：誰でも認証なしで接続できてしまう！
```
「中間の担当者」と「窓口の担当者」がお互いに相手が確認してくれると思って、**誰も確認していなかった**状態です。

### 弱点③：受け取ったコマンドをそのまま実行
```
リクエスト「このコマンドを実行して：[悪意あるプログラム]」
サーバー「わかった！実行するね！」→ 🔥 危険！
```
受け取ったURLのパラメータ（条件指定）に書かれたコマンドを、**チェックなしでそのまま実行**していました。

## なぜ重要なのか

### 📊 影響を受ける範囲

| 状況 | 影響 |
|------|------|
| `pip install autogenstudio`（通常インストール） | ❌ 影響なし（バージョン0.4.2.2は問題なし） |
| `pip install --pre autogenstudio`（プレリリース版） | ⚠️ **影響あり！**（0.4.3.dev1 / 0.4.3.dev2） |
| GitHubから最新版を取得している場合 | 修正版あり（後述） |

### 🌍 なぜ今後も重要なのか？
マイクロソフトは「この問題はAutoGen Studio固有のものだが、**同じパターンのセキュリティ上の穴は他のAIツールにも存在する可能性がある**」と警告しています。AIエージェントが普及するにつれ、「AIが勝手にウェブを操作する」という新しいリスクが生まれてきています。

> 💡 **これからのAI時代の新しい脅威パターン**
> 「AIに悪いウェブページを見せる → AIが勝手にシステムを攻撃する」

## 対策・今後の展望

### ✅ あなたがすべきこと（優先順位順）

**まず確認：自分はどのバージョンを使っているか？**
```bash
pip show autogenstudio
```
このコマンドでバージョンを確認できます。

---

**【ケース1】バージョン 0.4.2.2 を使っている（通常インストール）**
→ 問題のある機能自体がないので、**今すぐ対応不要**です。

---

**【ケース2】0.4.3.dev1 または 0.4.3.dev2 を使っている**
→ **脆弱性あり！** PyPIにはまだ修正版がリリースされていないため、以下の対応を取ってください：

1. **GitHubから最新版を取得する**（コミット b047730 以降）
2. それができない場合の暫定対策：
   - AIエージェントと AutoGen Studio を**別々のコンテナ（仮想環境）やVM（仮想マシン）で動かす**
   - AutoGen Studio を**権限の低いアカウント**で実行する
   - 信頼できないウェブサイトをAIエージェントに読み込ませない

---

**【修正版での改善点】**
マイクロソフトは GitHub 上のコードで以下の修正を行いました：
- ✅ URLからコマンドを直接受け取らないように変更
- ✅ コマンドはサーバー側に保存し、一時的なセッションIDで管理
- ✅ MCP経路でも認証を必須に変更

以前、**WordPress プラグイン「Gravity SMTP」の脆弱性**によってAPIキーが盗まれる事件を解説しましたが、今回の AutoJack 攻撃と共通するテーマがあります。

どちらも「便利なツールを導入したら、そこが攻撃の入口になった」という構図です。**新しいツールを使うときは、セキュリティ面での確認が欠かせない**という教訓が共通しています。

また、AI技術の普及とともに「AIが攻撃の道具にされる」という新しいリスクも見えてきており、今後もこういったニュースは増えていくと予想されます。

## 用語解説

| 用語 | 意味 |
|------|------|
| **AIエージェント** | 自動でブラウザ操作や情報収集を行うAIプログラム |
| **AutoGen Studio** | マイクロソフト研究部門製のAIエージェント開発ツール |
| **localhost** | 自分のパソコン自身を指すアドレス。「127.0.0.1」とも呼ばれる |
| **リモートコード実行（RCE）** | 遠隔から被害者のパソコンでプログラムを実行できる脆弱性 |
| **WebSocket** | ウェブでリアルタイムの双方向通信を行う仕組み |
| **MCP（Model Context Protocol）** | AIエージェントがツールや外部サービスと連携するための仕組み |
| **プロンプトインジェクション** | AIへの指示文に悪意ある命令を混ぜ込む攻撃手法 |
| **PyPI** | Pythonソフトウェアの公式配布サイト（アプリストアのようなもの） |
| **プレリリース版** | 正式リリース前のテスト用バージョン。不安定な場合がある |
| **オープンソース** | ソースコードが公開されており、誰でも無料で使えるソフトウェア |
| **認証（Authentication）** | 「あなたは誰ですか？」を確認する仕組み |
| **コンテナ / VM（仮想マシン）** | パソコンの中に仮想的に別の環境を作る技術。隔離に使われる |

---

> 🔒 **まとめ**
> AIが便利になればなるほど、AIを悪用した攻撃も増えていきます。今回の AutoJack は「研究上の発見」であり、実際の攻撃には使われていませんが、AIツールを使う際は**バージョン管理とセキュリティ設定を必ず確認する習慣**をつけましょう！
