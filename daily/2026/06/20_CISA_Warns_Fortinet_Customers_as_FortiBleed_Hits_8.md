# CISAが警告！「FortiBleed」で86,644台のネットワーク機器が被害

**元記事**: [CISA Warns Fortinet Customers as FortiBleed Hits 86,644 FortiGate Devices](https://inl03.netline.com/ltr6/?_m=3n.009a.4009.sp0ao46r89.32a8)
**解説日**: 2025年6月21日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な仕組みを説明します。

### 🔒 ファイアウォール・VPNって何？

**ファイアウォール**とは、会社や学校のネットワークを外部の不正アクセスから守る「門番」のような機器です。家の鍵やセキュリティドアと同じイメージです。

**VPN（仮想プライベートネットワーク）**とは、インターネット上に「秘密のトンネル」を作って、安全に社内ネットワークに接続する仕組みです。テレワーク（在宅勤務）などでよく使われます。

### 🏢 Fortinet（フォーティネット）とは？

アメリカのセキュリティ企業で、世界中の企業・政府機関・学校などが使うネットワーク機器（**FortiGate**）を作っています。「セキュリティを守るための機器」が攻撃された、というのが今回の皮肉な点です。

### 🏛️ CISA（サイバーセキュリティ・インフラセキュリティ庁）とは？

アメリカ政府の機関で、日本でいう「内閣サイバーセキュリティセンター（NISC）」に近い存在です。重大なサイバー攻撃があったとき、公式に警告や対策を出します。CISAが動くということは「それだけ深刻な事態」ということです。

---

## 何が起きたのか

### 📰 事件の概要

**「FortiBleed（フォーティブリード）」**と名付けられた大規模なサイバー攻撃が世界中で発生しました。

- 🗓️ **2026年6月19日時点**で、**86,644台**ものFortiGate機器が不正アクセスの被害を受けた
- 🌍 被害は**インド・アメリカ・メキシコ・コロンビア・タイ**などで確認
- 🎯 特に**通信会社・政府機関・教育機関**が多くの被害を受けた
- 🕵️ 攻撃者は**ロシア語話者のハッカー集団**と見られている

### 🔑 盗まれたアカウントの内訳

| アカウントの種類 | 割合 |
|---|---|
| 組織固有のアカウント（企業・機関が作ったもの） | 36.7% |
| 一般的な管理者アカウント（デフォルト） | 35.0% |
| Fortinetの組み込みシステムアカウント | 28.3% |

注目すべきは、**デフォルト（初期設定のまま）のアカウントが63%以上を占めている**ことです。つまり「鍵を買ったけど、最初についてきた合鍵を捨てていなかった」状態が大量にあったわけです。

## 技術的な詳細

### 🤖 攻撃の仕組みをわかりやすく解説

この攻撃は**完全自動化された2ステップ**で行われました。

```
【ステップ1】インターネットを自動スキャン
    ↓
FortiGateのログイン画面を持つ機器を世界中で検索
    ↓
【ステップ2】パスワードを片っ端から試す（自動）
    ↓
過去のデータ漏洩で流出したIDとパスワードの組み合わせを試す
    ↓
ログイン成功！→ 「確認済み・有効なログイン情報」としてデータベースに保存
    ↓
さらにネットワーク通信を「盗み見」して追加のパスワードを収集
    ↓
それを使って別の機器にも侵入…（連鎖的に被害拡大）
```

#### 使われた攻撃手法（3種類）

| 攻撃名 | 説明 | 例え話 |
|---|---|---|
| **ブルートフォース攻撃** | パスワードを全パターン試す | 南京錠を全番号で試す |
| **辞書攻撃** | よく使われるパスワードのリストで試す | 「123456」「password」など |
| **クレデンシャルスタッフィング** | 過去に漏洩したID・パスワードをそのまま使う | 別サービスで盗んだ鍵で試す |

### 🔓 なぜ攻撃が成功しやすかったのか？（パスワードの保存方法の問題）

ここが少し技術的ですが、重要なポイントです。

パスワードはシステム内に「**ハッシュ**」という暗号化された形で保存されます。ハッシュとは、元のパスワードを変換して「解読しにくい文字列」にしたものです。

```
例）パスワード「apple」→ ハッシュ化→「2ef7bde608ce5404e97d5f042f95f89f1c232871」
```

- **古いバージョン（脆弱）**: 「SHA-256」という比較的古い方式で保存
- **新しいバージョン（安全）**: 「PBKDF2」というより強力な方式を採用（FortiOS 7.2.11以降）

**問題点**: 古いバージョンから新しいバージョンにアップデートしても、**管理者が一度ログインし直すまで**パスワードは古い方式のまま保存され続けます。多くの組織がこれに気づいていませんでした。

## なぜ重要なのか

### 🌐 影響の大きさ

> 「この侵害の規模は世界経済のほぼすべてのセクターに及んでいる」
> — Hudson Rock（セキュリティ企業）

- 86,644台という数字は、**東京ドーム約1.8杯分の観客数**に匹敵する規模
- ファイアウォール・VPN機器は「ネットワークの入口の鍵」なので、一度突破されると**社内の全システムが危険にさらされる**
- 攻撃者は「動作確認済みのログイン情報リスト」を持っており、いつでも再侵入できる状態

### 🏭 特に危険なのは？

**通信・政府・教育**が最も被害を受けているセクターです。

- **政府機関**：国家機密・市民情報が漏洩する可能性
- **通信会社**：多くの人が利用するインフラが攻撃される可能性
- **教育機関**：学生・教職員の個人情報が危険にさらされる可能性

## 対策・今後の展望

### ✅ CISAが推奨する対策（FortiGate利用者向け）

1. **🔌 セッションの強制終了**
   すべてのSSL VPN・管理者セッションを今すぐ切断する

2. **🔑 パスワードの全リセット**
   VPNと管理者のパスワードをすべてリセットし、強力なパスワードに変更する

3. **🛡️ MFA（多要素認証）の有効化**
   パスワードだけでなく、スマホのアプリや SMS でも本人確認を行う仕組みを導入する
   （例：パスワード入力後に「スマホに届いた6桁の数字も入力」するあれです）

4. **⬆️ ソフトウェアのアップデート**
   PBKDF2に対応した最新バージョン（FortiOS 7.2.11、7.4.8、7.6.1以降）に更新する

5. **👤 デフォルトアカウントの削除・改名**
   初期設定のまま使っているアカウントを必ず変更・削除する

### 💡 一般の人ができること（普段使いのヒント）

FortiGateは企業向け製品ですが、今回の教訓は普段の生活にも活かせます：

- ✔️ 同じパスワードを複数のサービスで使い回さない
- ✔️ パスワードは定期的に変更する
- ✔️ MFA（二段階認証）を設定できるサービスでは必ず有効にする
- ✔️ 初期設定のパスワードは必ず変更する（Wi-Fiルーターなども！）

## 過去記事との関連

今回の「FortiBleed」は完全に新しい脆弱性（セキュリティの穴）によるものではなく、**過去の情報漏洩・既知の脆弱性の積み重ね**が引き金になっています。Fortinetは過去にも複数のセキュリティインシデントを経験しており、「古い設定や過去のパスワードが使い回されている」ことが今回の被害を拡大させました。これは「一度起きたインシデントへの対処を怠ると、後で更に大きな被害になる」という典型的な例です。

## 用語解説

| 用語 | 意味 |
|---|---|
| **FortiGate** | Fortinetが作るネットワーク用のセキュリティ機器（ファイアウォール・VPN等） |
| **CISA** | アメリカのサイバーセキュリティ専門政府機関 |
| **FortiBleed** | 今回の大規模攻撃キャンペーンに付けられたコードネーム |
| **SSL VPN** | 暗号化された安全なリモートアクセス（テレワーク等で使用）の仕組み |
| **ブルートフォース攻撃** | パスワードを全パターン試す攻撃手法 |
| **辞書攻撃** | よく使われるパスワードのリストを使った攻撃手法 |
| **クレデンシャルスタッフィング** | 過去に漏洩したID・パスワードをそのまま別のサービスで試す攻撃 |
| **ハッシュ** | パスワードを変換した解読しにくい文字列（元に戻しにくい一方向変換） |
| **SHA-256** | 古いパスワードのハッシュ化方式（今回の攻撃で弱点になった） |
| **PBKDF2** | より安全な新しいパスワードのハッシュ化方式 |
| **MFA（多要素認証）** | パスワード以外にも「スマホの認証コード」など複数の本人確認を使う仕組み |
| **デフォルトアカウント** | 機器・ソフトウェアを買ったときに最初から設定されているアカウント |
| **脅威アクター** | サイバー攻撃を行う個人・グループの総称 |

> 💬 **まとめると…**
> 世界中の86,644台のネットワーク機器が、ロシア語話者のハッカー集団による自動化された攻撃で不正アクセスされました。デフォルトパスワードの放置・古いセキュリティ方式・過去の漏洩情報の悪用が重なって起きた大規模な事件です。「鍵の管理を怠ると、プロ向けのセキュリティ機器でも簡単に突破される」という教訓が、私たちの日常のパスワード管理にも直結しています。
