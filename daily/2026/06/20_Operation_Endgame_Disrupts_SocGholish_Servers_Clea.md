# 作戦「エンドゲーム」、SocGholishサーバーを制圧！約15,000件のWordPressサイトを浄化

**元記事**: [Operation Endgame Disrupts SocGholish Servers, Cleans 14,971 WordPress Sites](https://inl03.netline.com/ltr6/?_m=3n.009a.4009.sp0ao46r89.32a2)
**解説日**: 2026年6月21日

---

## 背景知識

このニュースを理解するために、まず3つのキーワードを押さえておきましょう。

### 🌐 WordPressとは？
ウェブサイトを簡単に作れる世界で最も人気のあるツールです。世界中のウェブサイトの約43%がWordPressで作られているほどメジャーです。ブログから企業サイトまで幅広く使われていますが、その分、ハッカーに狙われやすいという側面もあります。

### 🦠 マルウェアとは？
「悪意のあるソフトウェア」の総称です。ウイルスやランサムウェア（データを人質にして金銭を要求するもの）など、コンピュータやシステムに害を与えるプログラムのことをいいます。

### 🤖 ボットネットとは？
ハッカーに乗っ取られたパソコンやサーバーが、インターネット上で「ゾンビ部隊」のように一斉に操られる状態のことです。持ち主は自分のパソコンが乗っ取られていることに気づかないまま、知らないうちに犯罪の「道具」にされてしまいます。

---

## 何が起きたのか

オランダ・カナダ・ドイツ・アメリカの法執行機関が合同で、**「SocGholish（ソックゴーリッシュ）」** という危険なマルウェアのネットワークを解体しました！

作戦の成果をまとめるとこうなります👇

| 成果 | 数字 |
|------|------|
| 停止したサーバー数 | **106台** |
| ウイルスを除去したWordPressサイト数 | **14,971件** |
| 作戦の開始年 | **2024年** |

この作戦は「**オペレーション・エンドゲーム（Operation Endgame）**」と呼ばれ、2024年から継続している国際的な犯罪組織への取り締まりの一環です。アベンジャーズのラスボス戦みたいなネーミングですね😄

感染していたWordPressサイトの管理者には、以下のような通知が届けられました：
- **CMSのアップデート**（サイトのシステムを最新版にする）
- **パスワードの変更**
- **不審なアカウントの削除**

## 技術的な詳細

### SocGholishってどんなマルウェア？

SocGholishは「**FakeUpdates（フェイクアップデート）**」という別名も持ち、2017年から活動しています。

その仕組みを例え話で説明しましょう。

> 🎭 **詐欺師のナリキリ作戦**
>
> あなたが普通のウェブサイトを訪問すると、突然こんなメッセージが現れます：
> 「⚠️ Chromeのアップデートが必要です。今すぐダウンロードしてください！」
>
> でも実は、これは**偽物のアップデート通知**です。クリックすると、ウイルスが入ったファイルがダウンロードされてしまいます。

これがSocGholishの手口です。Google ChromeやFirefoxなどの有名なブラウザ、あるいは人気ソフトウェアのアップデートに**成りすまして**、マルウェアをダウンロードさせます。

### どうやって広がるの？（感染経路）

```
[正規のWordPressサイト]
      ↓ ハッキングされる
[悪意のあるJavaScriptコードが埋め込まれる]
      ↓
[訪問者に偽のアップデート画面を表示]
      ↓
[ダウンロードするとマルウェアに感染]
      ↓
[そのパソコンがボットネットの一部になる]
      ↓
[さらにランサムウェアやスパイウェアが送り込まれる]
```

**JavaScript（ジャバスクリプト）** というのは、ウェブページを動かすためのプログラム言語です。本来は便利なものですが、SocGholishはこれを悪用して、悪意のある処理をこっそり仕込んでいます。

### TDS（トラフィック配信システム）という巧妙な仕組み

さらに厄介なのが「**TDS（Traffic Distribution System）**」という技術の悪用です。

> 📡 **例え話で理解しよう**
>
> 道路の分岐点に「案内係」がいて、来た人の特徴（どこから来た？スマホ？パソコン？）を見て、「あなたはこっちの道へ」と誘導するイメージです。
>
> 犯罪者はこれを使って、訪問者の **IPアドレス・OS・場所・デバイス・ブラウザの種類** などの情報を収集し、「騙しやすそうな人」をより危険なサイトへ誘導します。また、セキュリティ会社のチェックを回避するのにも使われます。

### どんな犯罪グループが使っていたの？

SocGholishは、いわば「**悪の玄関ドア係**」として、複数の犯罪グループに使われていました。

- **Evil Corp（イービルコープ）** ：ランサムウェアで有名なロシア系犯罪組織
- **LockBit（ロックビット）** ：世界規模のランサムウェアグループ
- **RomCom** ：スパイ活動も行う脅威グループ
- **RansomHub** ：比較的新しいランサムウェアグループ

## なぜ重要なのか

### 🔴 被害の規模感

約15,000件のウェブサイトが感染していたということは、日本全国の市区町村（約1,700）の約9倍ものサイトが「ウイルスをばら撒く罠」になっていたイメージです。それほど広範囲に被害が広がっていました。

### 🔴 社会インフラへの脅威

オランダ当局が特に強調しているのが「**重要インフラへの攻撃リスク**」です。電力・水道・病院・交通などの社会インフラがランサムウェアに感染すると、市民生活に直接影響が出ます。SocGholishはそういった攻撃の「入口」として使われていたため、今回の摘発は非常に大きな意味を持ちます。

### 🟡 今回の作戦の限界

声明の中に「**This marks the beginning of further action（これはさらなる行動の始まりに過ぎない）**」という一文があります。つまり、今回の作戦はあくまで第一歩であり、SocGholishを完全に排除したわけではないということです。

## 対策・今後の展望

### WordPressサイトを運営している人へ ⚠️

1. **WordPressを最新版にアップデートする** → 古いバージョンはセキュリティの穴が多い
2. **パスワードを複雑なものに変更する** → 短くて単純なものはNG
3. **不審なユーザーアカウントを確認・削除する**
4. **プラグインも定期的に更新する**

### 一般のインターネットユーザーへ 🛡️

| やるべきこと | 理由 |
|-------------|------|
| ブラウザのアップデートは**公式の設定画面から行う** | 偽アップデート画面に騙されないため |
| 突然出てくる「アップデートしてください」画面を**すぐに閉じる** | SocGholishの典型的な手口 |
| セキュリティソフトを入れておく | マルウェアの検知・ブロックのため |
| OSやソフトを**常に最新の状態**に保つ | 既知の脆弱性を塞ぐため |

### 今後の展望

Operation Endgameは2024年から継続している作戦で、今回のSocGholish摘発はその最新の成果です。国際的な法執行機関が連携して犯罪インフラを解体するこのアプローチは、今後もさらに拡大していくと見られています。

## 用語解説

| 用語 | 意味 |
|------|------|
| **SocGholish / FakeUpdates** | 2017年から活動するJavaScript製マルウェア。偽アップデートに偽装して感染を広げる |
| **WordPress** | 世界最大シェアのウェブサイト作成・管理ツール |
| **マルウェア** | ウイルス・ランサムウェアなど悪意のあるソフトウェアの総称 |

| **JavaScript（JS）** | ウェブページを動かすプログラム言語。今回は悪用された |
| **TDS（トラフィック配信システム）** | 訪問者を条件に応じて異なるサイトへ誘導する技術。犯罪者に悪用される |
| **CMS（コンテンツ管理システム）** | WordPressのような、ウェブサイトのコンテンツを管理するシステム |
| **Evil Corp / LockBit** | SocGholishを利用した有名な犯罪・ランサムウェアグループ |
| **Operation Endgame** | 2024年開始の、ボットネット等を取り締まる国際的な法執行作戦 |
| **初期アクセスブローカー** | 企業・組織のシステムへの侵入口を確保し、他の犯罪者に「販売」する役割 |
