# 「ザ・ジェントルメン」ランサムウェアグループ — セキュリティソフトを400種類も無力化する恐るべき攻撃ツール群

**元記事**: [The Gentlemen RaaS Uses GentleKiller EDR Framework Targeting 400 Security Processes](https://inl03.netline.com/ltr6/?_m=3n.009a.4009.sp0ao46r89.329q)
**解説日**: 2025年6月20日

---

## 背景知識

このニュースを理解するために、まずいくつかの重要な概念を押さえておきましょう。

### 🔐 ランサムウェアとは？
「ランサム（Ransom）＝身代金」＋「ウェア（Ware）＝ソフトウェア」の組み合わせです。
感染したパソコンやサーバーのファイルをすべて暗号化（鍵をかけて読めなく）して、「お金を払わないとデータを返さないよ」と脅す悪意あるプログラムのことです。

### 💼 RaaS（ランサムウェア・アズ・ア・サービス）とは？
まるでNetflixのようなサブスクリプションサービスをイメージしてください。でも中身は犯罪です。
- **運営者**がランサムウェアのツールや仕組みを作る
- **アフィリエイト（加盟犯罪者）** がそのツールを借りて攻撃する
- 稼いだお金を運営者とアフィリエイトで分け合う

つまり「犯罪のフランチャイズ」のようなものです。

### 🛡️ EDR（エンドポイント検知・対応）とは？
パソコンやサーバー（＝エンドポイント）に入れる高性能なウイルス対策ソフトのことです。
普通のウイルス対策ソフトより賢く、怪しい動きをリアルタイムで監視・検知・対処します。CrowdStrike FalconやKasperskyなどが有名です。

### 🚗 BYOVD（脆弱なドライバを持ち込む）攻撃とは？
少し難しい概念なので、例え話で説明します。

> 🏢 会社のビル（Windows）に入るには、受付（セキュリティソフト）のチェックが必要。
> でも、「正規の社員証」を持っている人なら通れてしまう。
> ハッカーは**古くてセキュリティの穴がある正規のドライバー（プログラム）** を「正規の社員証」として使い、受付を素通りしてビルの中（Windowsの深部）に入り込む。
> そして中から受付（EDRソフト）を内側から無効化してしまう。

これがBYOVD攻撃の仕組みです。「ドライバ」とはOSとハードウェアをつなぐ特権的なプログラムで、Windowsの深い部分にアクセスできます。

## 何が起きたのか

セキュリティ会社ESETが、**「ザ・ジェントルメン（The Gentlemen）」** というランサムウェアグループの実態を詳しく調査・公開しました。

### 主要な事実をまとめると：

| 項目 | 内容 |
|------|------|
| 活動開始 | 2025年3月 |
| 被害者数 | **504件**（判明分） |
| 主な被害地域 | 東南アジア、南米、西ヨーロッパ |
| リーダー | ロシア国籍のアレクサンドル・ヤパーエフ（36歳・通称：hastalamuerte） |
| 主要ツール | GentleKiller（EDR無効化フレームワーク） |

たった数ヶ月で504件もの被害を出した、非常に活発で危険なグループです。

## 技術的な詳細

### 🗡️ GentleKillerとは何か

このグループの中核ツール「**GentleKiller**」は、セキュリティソフトを強制的に停止させる専用のフレームワーク（ツールの枠組み）です。

```
攻撃の流れ（イメージ）

① 標的のPCに侵入
        ↓
② GentleKillerを実行
        ↓
③ セキュリティソフト（EDR）を強制停止 ← 今回の記事のポイント！
        ↓
④ ランサムウェア（暗号化ソフト）を展開
        ↓
⑤ ファイルをすべて暗号化して身代金要求
```

### 📊 GentleKillerの驚異的な規模

- **48種類**のセキュリティ製品を標的に
- **400種類以上**のセキュリティ関連プロセスを終了させる
- **8つのバリエーション**があり、それぞれ異なる正規ソフトに偽装

### 🎭 偽装の手口

GentleKillerはただのツールではなく、**巧妙な偽装機能**を持っています。

| 偽装の方法 | 具体的な内容 |
|------------|--------------|
| ファイル名の偽装 | 有名セキュリティ会社のソフトに似た名前を使用 |
| デジタル署名の偽装 | 正規のデジタル証明書をコピー（「本物の印鑑」を複製するイメージ） |
| アイコンの偽装 | 正規ソフトのアイコンをそのままコピー |
| バージョン情報の偽装 | 本物のソフトのバージョン情報を流用 |

さらに「Enigma」や「Themida」というツールで、コード自体も解析されにくくしています。まるでロシア人形（マトリョーシカ）のように、何重にも偽装しているのです。

### 🔧 悪用されているドライバの一覧

GentleKillerが悪用している「脆弱なドライバ」は以下の通りです。これらはすべて元々は正規のソフトウェアです：

| ドライバファイル名 | 元の正規ソフト |
|---|---|
| `eb.sys` | Kaspersky（ロシアのセキュリティソフト） |
| `nseckrnl.sys` | FACEIT Anti-Cheat（ゲームのチート対策ソフト） |
| `GameDriverX64.sys` | Valorant（人気FPSゲーム） |
| `stpm_old.sys` / `stpm_new.sys` | Javelin |
| `dmx.sys` | WatchDog |
| `360netmon_wfp.sys` | Network Blocker |
| `IMFForceDelete.sys` | Cleaner |
| `PoisonX.sys` | G11（※CrowdStrike Falconを止めるのにも使われた） |

⚠️ 特に注目すべきは `PoisonX.sys`。このドライバは最近、あの有名セキュリティソフト「**CrowdStrike Falcon**」を停止させるためにも使われた実績があります。

### 🤝 外部ツールとの組み合わせ

グループは自作ツール以外にも、他のハッカーが作ったツールも流用しています：

- **HexKiller** — 元々は「Warlock」という別のランサムウェアグループ専用と思われていたツール
- **ThrottleBlood** — 「MedusaLocker」や「DragonForce」というグループの攻撃でも使われたツール
- **HavocKiller（HwAudKiller）** — `havoc.sys`を使うEDR無効化ツール

### ⚡ 新しい攻撃手法への素早い対応

このグループの最も恐ろしい特徴のひとつが、**新しい攻撃手法が公開されると、数日以内に実際の攻撃に組み込んでしまう** スピード感です。

普通、セキュリティの穴（脆弱性）が発見されると、修正プログラム（パッチ）が作られるまでに時間がかかります。その「修正されるまでの間」を素早く突いてくるのです。

## なぜ重要なのか

### 1️⃣ セキュリティソフトを「先に殺す」戦略の高度化

従来のランサムウェアは、セキュリティソフトに検知されることを恐れていました。しかしこのグループは、**侵入後にセキュリティソフトそのものを無効化してから攻撃する** という戦略を組織的に採用しています。これは「鍵を壊してから部屋に入る」ようなものです。

### 2️⃣ わずか数ヶ月で504件の被害

2025年3月に活動を開始し、数ヶ月で500件超の被害。このペースは異常に速く、組織が非常に効率的に運営されていることを示しています。

### 3️⃣ ツールの「標準化」による攻撃の効率化

複数の犯罪者（アフィリエイト）が同じ「GentleKiller」という枠組みを使うことで：
- 新しいドライバをすぐに組み込める
- 攻撃者側が特別な技術知識がなくても使える
- 発見・対策が難しくなる

### 4️⃣ ロシア人リーダーの特定

犯罪者として特定されたアレクサンドル・ヤパーエフ（36歳・通称 hastalamuerte）は、以前は「Qilin」という別のランサムウェアグループでアフィリエイトとして活動していた経歴があります。こうした人物の特定は、国際的な法執行機関による逮捕・訴追への第一歩です。

## 対策・今後の展望

### ✅ 組織・企業が取るべき対策

1. **OSとドライバを常に最新状態に保つ**
   - BYOVDは「古い・脆弱なドライバ」を悪用するため、脆弱なドライバを持ち込まれる前に正規のものを最新に保つことが重要です。

2. **脆弱なドライバのブロックリストを活用する**
   - Microsoftは悪用が知られたドライバのリスト（HVCI/ブロックリスト）を提供しています。これを有効にすることが効果的です。

3. **EDRツールの「自己保護機能」を有効にする**
   - 多くのEDRツールには、自分自身が停止されるのを防ぐ機能があります。これを必ず有効にしましょう。

4. **バックアップを定期的に取る（3-2-1ルール）**
   - データを3箇所・2種類の媒体・1つはオフライン（ネットに繋がっていない場所）に保管する。

5. **ネットワークの監視強化**
   - 怪しいドライバの読み込みをログで監視する。

### 🔮 今後の展望

- セキュリティ各社がGentleKillerの各バリエーションに対応したシグネチャ（検知ルール）を更新中
- Microsoftによる脆弱なドライバのブロックリスト拡充が期待される
- ロシア国籍のリーダーが特定されたことで、国際的な法執行機関による追跡が進む可能性がある
- 一方でグループは「新手法が公開されると数日で組み込む」ため、いたちごっこが続く見通し

## 過去記事との関連

以前、**CrowdStrike FalconのAI搭載セキュリティ機能**について解説しましたが、今回の記事では、その CrowdStrike Falcon 自体が「PoisonX.sys」というドライバを悪用した攻撃によって停止させられた事例が言及されています。

つまり「AI搭載で高性能なEDRツールであっても、OSのカーネル（深部）レベルで動く脆弱なドライバを使われると、機能を停止させられてしまう」という現実が浮かび上がります。これはセキュリティ業界全体にとって非常に深刻なメッセージです。どんなに高性能な鍵も、建物の構造そのものを攻撃されたら意味がない、ということです。

## 用語解説

| 用語 | 意味 |
|------|------|
| **ランサムウェア** | ファイルを暗号化して身代金を要求する悪意あるソフト |
| **RaaS** | Ransomware as a Service。犯罪のフランチャイズ形式のランサムウェアビジネス |
| **EDR** | Endpoint Detection and Response。高性能ウイルス対策・脅威検知ソフト |
| **BYOVD** | Bring Your Own Vulnerable Driver。脆弱な正規ドライバを持ち込んでOSの深部を悪用する攻撃手法 |
| **ドライバ（Driver）** | OSとハードウェアをつなぐ特権的なプログラム。深い権限を持つ |
| **アフィリエイト** | ここでは、RaaSのツールを借りて攻撃する「加盟犯罪者」のこと |
| **PoC（Proof of Concept）** | 「こんな攻撃が可能だ」と示すための実証コード。公開されると悪用されるリスクがある |
| **プロセス** | コンピュータ上で動いているプログラムの実行単位 |
| **Enigma / Themida** | プログラムを解析されにくくする「保護ツール」 |
| **デジタル署名** | ソフトウェアが正規のものであることを証明する電子的な印鑑 |
| **GentleKiller** | The GentlemenグループのEDR無効化ツール群の中核フレームワーク |
| **CrowdStrike Falcon** | 世界的に有名なEDRセキュリティ製品 |
| **hastalamuerte** | ロシア語・スペイン語混じりのハンドルネーム。グループリーダーの通称 |
