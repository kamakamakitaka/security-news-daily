# カナダのスパイ機関が「史上初」の令状でボットネット感染デバイスを一斉クリーンアップ

**元記事**: [Canada's Spy Agency Used First-of-Its-Kind Warrant to Clean Botnet-Infected Devices](https://inl03.netline.com/ltr6/?_m=3n.009a.4010.sp0ao46r89.32b4)
**解説日**: 2026年6月23日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を押さえておきましょう。

### 🤖 ボットネットとは？

「ボットネット（Botnet）」は、**Bot（ロボット）＋ Network（ネットワーク）**を組み合わせた言葉です。

イメージとしては、こんな感じです👇

> 🏘️ あなたの家のWi-Fiルーターが、知らないうちにハッカーに乗っ取られて「手下」にされてしまう。そのような「乗っ取られたデバイス」が何百・何千台と集まって、一つの「悪の軍団ネットワーク」を形成している状態がボットネットです。

所有者は自分のデバイスが乗っ取られていることに気づかず、普通に使い続けています。その裏で、デバイスは犯罪者の命令に従って動いています。

### 📡 IoT機器とは？

**IoT（Internet of Things＝モノのインターネット）**とは、インターネットにつながる家電・機器のことです。

- 玄関カメラ（Ring doorbellなど）
- セキュリティカメラ
- スマートTV
- Wi-Fi対応の家電

これらは便利な反面、**セキュリティ対策が甘い**ものが多く、ハッカーに狙われやすい弱点があります。

### 🕵️ CSIS（カナダ安全情報庁）とは？

**CSIS（Canadian Security Intelligence Service）**は、カナダの**スパイ・諜報機関**です。日本でいうと内閣情報調査室のような組織で、アメリカでいうとCIAに相当します。

## 何が起きたのか

### 事件の概要

2024年5月、カナダの諜報機関CSISは**裁判所から特別な令状（裁判官の許可証）**を取得し、次のことを実施しました。

1. カナダ国内に設置されているサーバー・家庭用ルーター・IoT機器に**リモートでアクセス**
2. それらのデバイスに仕込まれていた**ボットネットのマルウェア（悪意あるプログラム）を削除・無効化**
3. 感染したデバイスを**犯罪者のネットワークから切り離す**

対象となったデバイスは：
- 🏠 家庭用・小規模オフィス用のWi-Fiルーター
- 🔔 玄関カメラ（Ring doorbell）
- 📷 防犯カメラ
- 📺 スマートTV
- その他のWi-Fi接続家電

この作戦は**カナダ史上初めて**CSISがこのような「脅威排除令状」を使った事例として記録されました。裁判所の判決文は2年以上非公開でしたが、2026年6月に（一部黒塗りで）公開されました。

## 技術的な詳細

### 🎮 ボットネットの仕組み

ボットネットがどのように機能するか、ゲームに例えて説明します。

```
【指令塔（コマンドサーバー）】
        ↓ 命令を送る
【乗っ取られたデバイス群（カナダの家庭のルーターやカメラなど）】
        ↓ 命令を中継・実行
【攻撃対象（カナダの電力・政府・軍のネットワーク）】
```

ゲームのRPGで例えると：
> 黒幕（外国の敵対勢力）が、無実の村人（一般市民のルーター）を操り人形にして、城（重要インフラ）を偵察させている状態です。

### 🎭 なぜ「他人のルーターを踏み台にする」のか？

これが非常に巧妙な点です。外国の攻撃者がカナダの家庭のルーターを経由して攻撃を行うと：

- 🔍 追跡すると「カナダの普通の家庭からのアクセス」に見える
- 🕵️ 本当の攻撃者（外国の国家機関）が特定しにくくなる
- 😰 家庭のルーターの持ち主が「犯人扱い」されてしまうリスクがある

### ⚠️ 狙われやすいのは「古くて放置されたデバイス**

記事が強調するのは「退屈だけど重要な教訓」です。ボットネットは主に：

- **製造元のサポートが終了した（End-of-Life）古いルーター**
- **ファームウェア（内部プログラム）を更新していないIoT機器**
- **デフォルトのパスワードのまま使っているデバイス**

...を狙います。「古くて誰も気にかけていない機器」がターゲットになるわけです。

### 📜 令状が必要だった理由

CSISが勝手にアクセスできなかった理由も重要です。

> 他人のデバイスに無断でアクセスしてデータを消す → カナダの刑法では**「コンピュータ不正使用罪」に該当する**

つまり、良いことをしようとしても、裁判官の許可なしにやれば**CSISのスタッフ自身が犯罪者になってしまう**のです。だからこそ裁判所に申請し、「脅威は明白・行為は必要かつ合理的」と認めてもらう必要がありました。

## なぜ重要なのか

### 🏛️ 歴史的な意義

**カナダ初**の「脅威排除令状」の行使という点で、法的・歴史的に重要な出来事です。CSISには2019年からこの権限がありましたが、今回初めて使われました。

### 🌏 攻撃者は外国の国家機関

裁判所は「外国の国家が関与している」と認定しました。黒塗りのため国名は不明ですが、記事では：

- 🇨🇳 中国関連グループ（Volt Typhoon）
- 🇷🇺 ロシア軍情報部（GRU / APT28）

...の可能性が示唆されています（どちらかまたは両方）。

### ⚡ 電力インフラへの脅威

裁判所は**エネルギーセクター（電力・ガスなど）**が標的に含まれていたと明記し、「インフラを混乱させる可能性がある」と警告しています。電力網などの重要インフラが攻撃されると、社会全体に影響が出ます。

### 🇺🇸 アメリカとの比較

同時期、アメリカでも似たような作戦がありました：

| 項目 | アメリカ | カナダ |
|------|----------|--------|
| 実施機関 | FBI・司法省（法執行機関） | CSIS（諜報機関） |
| 法的根拠 | 捜索・押収権限 | 脅威排除措置 |
| 対象ボットネット | Volt Typhoon（中国）・APT28（ロシア） | 外国国家（詳細非公開） |

同じ「裁判所の令状でリモートクリーンアップ」という手法ですが、**法的な枠組みが異なる**点が興味深いです。

## 対策・今後の展望

### 🛡️ 私たちにできること

あなたの家のルーターやIoT機器が「悪の手下」にされないための対策です：

#### すぐできること
1. **🔑 パスワードを変える**
   - ルーターや防犯カメラのデフォルトパスワード（「admin/admin」など）は必ず変更する

2. **🔄 ファームウェアを更新する**
   - ルーターの管理画面にログインして「アップデート」を確認する
   - スマートTV・防犯カメラも同様

3. **📅 古い機器を買い替える**
   - メーカーのサポートが終了した機器は、セキュリティ更新が届かない「穴だらけの状態」なので、できれば新しいものに替える

#### 意識しておくこと
- 自分の家の機器が「知らないうちに攻撃の踏み台になっている」可能性があることを頭に置く
- 「うちは普通の家庭だから狙われない」という考えは危険（むしろ「普通の家庭のルーター」が狙われやすい）

### 🔮 今後の動向

- 各国の諜報・法執行機関が連携して、同様の「リモートクリーンアップ作戦」を増やしていく可能性が高い
- 日本でも同様の脅威は存在しており、法整備や対策の動向が注目される

## 用語解説

| 用語 | 意味 |
|------|------|
| **ボットネット（Botnet）** | ハッカーに乗っ取られた多数のデバイスが形成する「悪の遠隔操作ネットワーク」 |
| **IoT（Internet of Things）** | インターネットに接続された家電・機器全般（カメラ・TV・ルーターなど） |
| **CSIS** | カナダ安全情報庁。カナダのスパイ・諜報機関 |
| **マルウェア（Malware）** | 悪意を持って作られたソフトウェア（ウイルス・スパイウェアなど） |
| **脅威排除令状** | 裁判所が認めた「脅威を積極的に排除する」ための特別許可証 |
| **SOHO ルーター** | Small Office/Home Office（小規模オフィス・家庭用）のWi-Fiルーター |
| **ファームウェア** | ルーターやカメラなどの機器に組み込まれた基本プログラム |
| **Volt Typhoon** | 中国政府と関連するとされるハッカーグループ |
| **APT28** | ロシア軍情報部（GRU）と関連するとされるハッカーグループ |
| **End-of-Life（EoL）** | メーカーのサポートが終了した製品。セキュリティ更新が届かなくなる |
| **コマンドサーバー（C2）** | ボットネットの「指令塔」となるサーバー。感染デバイスに命令を送る |
| **リダクション（Redaction）** | 公開文書の一部を黒塗りにして隠すこと |

---

> 💡 **まとめると**：カナダのスパイ機関が史上初めて、裁判所の許可を得て「他人の家のルーターやカメラに遠隔でアクセスし、外国の国家が仕掛けたボットネットを除去した」という歴史的な出来事です。あなたの家の古いルーターや放置されたスマートTV が、知らないうちに外国の軍事作戦の道具になっているかもしれない——そんな時代に私たちは生きています。
