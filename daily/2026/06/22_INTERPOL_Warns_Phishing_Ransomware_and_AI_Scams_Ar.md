# インターポールが警告：フィッシング・ランサムウェア・AIを使った詐欺がアジア太平洋地域で急増

**元記事**: [INTERPOL Warns Phishing, Ransomware, and AI Scams Are Rising Across Asia-Pacific](https://inl03.netline.com/ltr6/?_m=3n.009a.4010.sp0ao46r89.32bm)
**解説日**: 2026年6月22日

---

## 背景知識

まずこのニュースを理解するために、いくつかの言葉を押さえておきましょう。

**インターポール（INTERPOL）とは？**
世界中の警察が協力するための国際組織です。195の国と地域が加盟しており、国境を越えた犯罪（今回のようなサイバー犯罪など）に対して、各国の警察が情報を共有したり、共同で捜査したりするための仕組みです。

**アジア太平洋地域とは？**
日本・韓国・中国・東南アジア・オーストラリアなどが含まれる広い地域のことです。近年インターネットの普及が急速に進んでいます。

**デジタル化（digitalization）とは？**
社会の様々な活動がインターネットやスマートフォンを通じて行われるようになることです。便利になる一方、サイバー犯罪の「被害に遭う人」も増えるという側面があります。

## 何が起きたのか

インターポールが2025〜2026年版の「アジア・南太平洋地域サイバー脅威評価レポート」を発表し、**この地域でサイバー犯罪が"劇的に増加"している**と警告しました。

主なポイントはこちらです👇

- 📧 **フィッシング詐欺**が最も多く、2024年1月〜2025年3月の間に**1万件以上の被害**を報告した国が、地域内の3分の1に上った
- 💻 **ランサムウェア攻撃**が2024年だけで推定**13万5,000件以上**発生し、不動産・製造・金融業界が特に被害を受けた
- 🤖 **AIやディープフェイク**を使った詐欺が急増し、地域全体で**約370億ドル（約5兆4,000億円）もの被害**が出たと推計されている
- 🌐 **DDoS攻撃**（後述）が前年比で**92%増加**した
- 📱 アジア・南太平洋地域では、1,000人中**5.5人**が毎月フィッシングリンクをクリックしており、世界平均（2.9人）の**約2倍**

## 技術的な詳細

今回の報告で登場する攻撃手法を、わかりやすく解説します。

### 🎣 フィッシング（Phishing）
「釣り（fishing）」から来た言葉で、**偽のメールやWebサイトを使って、パスワードやクレジットカード番号などをだまし取る攻撃**です。
> 例：「あなたのアカウントに問題が発生しました」という偽のメールが届き、偽のログイン画面に誘導される

### 🔒 ランサムウェア（Ransomware）
「ransom（身代金）」＋「ware（ソフトウェア）」の造語です。**パソコンやサーバーのデータを暗号化（鍵をかけて読めなく）して、お金を払わないと元に戻さないと脅す悪意のあるプログラム**です。
> 例：病院のシステムが突然使えなくなり、「100万ドル払えば鍵を渡す」と要求される

さらに最近では**「ランサムウェア・アズ・ア・サービス（RaaS）」**という形態も登場しています。これは、まるでサブスクリプションサービスのように、攻撃ツールを"レンタル"できる仕組みで、技術力のない犯罪者でも簡単に攻撃できるようになっています。怖いですよね…😨

### 🤖 ディープフェイク（Deepfake）
AIを使って**本物そっくりの偽の顔・声・映像を作る技術**です。今回の報告では、会社の社長や幹部に成りすまして、「今すぐこの口座にお金を振り込め」と指示する詐欺に使われています。
> 例：ビデオ会議で「社長」が画面に映っているように見えるが、実はAIが作った偽物

### 💸 ロマンス詐欺（Romance Baiting）
SNSやマッチングアプリで**「親しい友達」や「恋人」を装って関係を築き、最終的に投資詐欺などでお金をだまし取る手口**です。カンボジア・ラオス・ミャンマー・フィリピンなどに設置された「詐欺センター」から、強制労働させられた人々が世界中の被害者に接触しているとされています。

### 🌊 DDoS攻撃（ディードス攻撃）
「Distributed Denial of Service（分散型サービス拒否攻撃）」の略。**大量のアクセスを一気に送りつけてWebサイトやサービスをダウンさせる攻撃**です。
> 例：お店の前に何万人もの人が押し寄せて、本当のお客さんが入れなくなるイメージ

### 🦠 バンキングトロイ・情報窃取マルウェア
**銀行のID・パスワードや個人情報を密かに盗み取るウイルス**です。今回の報告ではRedLine・Lumma・LokiBot・Negasteal・ZBotといった具体的な名前が挙げられています。

## なぜ重要なのか

### 日本も無関係ではない！
アジア太平洋地域には日本も含まれます。インターポールの加盟国の**半数以上で、全犯罪の30%以上がサイバー犯罪**という衝撃的なデータが示されています。もはやサイバー犯罪は「特別な話」ではなく、普通の犯罪と同じくらい身近な脅威になっています。

### 被害規模が桁違い
ディープフェイクを使ったロマンス詐欺だけで、地域全体の損失が**37億ドル（約5,400億円）**というのは、想像を絶する規模です。これは個人の被害だけでなく、企業や国の重要インフラ（電力・医療・金融など）にも影響しています。

### 犯罪が「組織化・産業化」している
今回の報告で特に怖いのは、サイバー犯罪が**もはや個人の犯罪ではなく、組織的な「産業」になっている**という点です。会社のような組織が、AIやツールを使って効率よく、世界中を標的に攻撃を仕掛けています。

## 対策・今後の展望

### 🛡️ 私たちができること

| 脅威 | 対策 |
|------|------|
| フィッシング | 不審なリンクはクリックしない。URLをよく確認する |
| ランサムウェア | 定期的にデータをバックアップする |
| ディープフェイク詐欺 | SNSで知り合った人への送金は特に慎重に。電話で声を確認する |
| マルウェア | OSやアプリを最新の状態に保つ。怪しいソフトをインストールしない |
| DDoS | （個人ではなく企業・組織側の対策が必要） |

### 🌐 国際的な取り組み
インターポールは各国の法執行機関と協力して、以下のような対策を進めています：
- サイバー犯罪インフラへの共同作戦
- 情報共有と共同捜査
- 専門家のトレーニング
- サイバー耐性を高めるための政策づくり

ただし、国ごとにセキュリティの"成熟度"に差があることが課題で、技術や知識のある国とない国の格差を埋めることが急務とされています。

## 用語解説

| 用語 | 意味 |
|------|------|
| **フィッシング** | 偽メール・偽サイトで個人情報をだまし取る攻撃 |
| **ランサムウェア** | データを暗号化して身代金を要求するウイルス |
| **RaaS（ランサムウェア・アズ・ア・サービス）** | 攻撃ツールをレンタルできる犯罪ビジネスモデル |
| **ディープフェイク** | AIで作られた本物そっくりの偽動画・音声 |
| **DDoS攻撃** | 大量アクセスでサービスをダウンさせる攻撃 |
| **バンキングトロイ** | 銀行情報を盗むマルウェア（ウイルス） |
| **情報窃取マルウェア（InfoStealer）** | パスワードや個人情報を盗むウイルス |
| **ソーシャルエンジニアリング** | 技術ではなく「人間の心理の隙」を突いてだます手法 |
| **サイバー耐性（Cyber Resilience）** | 攻撃を受けても被害を最小化し、素早く回復できる能力 |
| **重要インフラ** | 電力・水道・医療・金融など、社会に欠かせないシステム |
