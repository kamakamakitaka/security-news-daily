## 背景知識

このニュースを読む前に、いくつかの基本的な言葉を覚えておきましょう。

### 🔐 VPN（仮想プライベートネットワーク）
インターネット上に「秘密のトンネル」を作って、安全に通信する仕組みです。会社の外から社内ネットワークに安全につなぐために使われます。

### 🛡️ ファイアウォール
家の玄関の「鍵付きの門」のようなものです。外からの怪しい通信を自動的にブロックする防護壁です。

### 🤖 ランサムウェア（身代金ウイルス）
パソコンのファイルを全部暗号化（鍵をかける）して、「お金を払えば元に戻してやる」と脅す悪質なウイルスです。

### 🔍 EDR（エンドポイント検出・対応）
パソコンやスマホなどの端末を常時監視して、怪しい動きを検出・遮断するセキュリティソフトのことです。「端末の番人」と思ってください。

### 🔑 MFA（多要素認証）
パスワードだけでなく、スマホへのSMSや指紋認証なども組み合わせてログインする仕組みです。「二重ロック」のイメージです。

### 🕵️ RaaS（ランサムウェア・アズ・ア・サービス）
ランサムウェアを「サービス」として他の犯罪者に貸し出すビジネスモデルです。開発者が道具を作り、使う側（アフィリエイト）が実際の攻撃を行い、利益を分け合います。まるで「犯罪のフランチャイズ」です。

## 何が起きたのか

今週は複数の大きなセキュリティインシデントが重なりました。特に注目すべき3つのニュースを詳しく見ていきます。

---

### 🚨 ① FortiBleed：8万台以上が標的に！

**Fortinet（フォーティネット）** というセキュリティ会社が作ったファイアウォール・VPN機器が、世界中で大規模な攻撃を受けました。

- **攻撃名**：FortiBleedキャンペーン
- **被害規模**：世界中で **8万台以上** の機器が特定される
- **攻撃者**：ロシア語話者とみられるハッカー集団
- **攻撃期間**：少なくとも2026年2月から継続中

攻撃者たちは24時間365日、自動化ツールを使って機器に不正ログインを試み続けています。

---

### 🔒 ② SalesforceとKlueの情報流出

**Salesforce（セールスフォース）** は世界中の企業が使う顧客管理クラウドサービスです。そのSalesforceと連携していた **Klue（クルー）** というアプリが攻撃され、顧客データが盗まれました。

- **攻撃グループ**：「Icarus（イカロス）」という恐喝グループ
- **侵入経路**：古い連携用アカウントの認証情報（ユーザー名・パスワード）が漏れていた
- 2026年6月11日に発覚し、Salesforceはすぐに連携を無効化

---

### 💣 ③ EDRキラー「GentleKiller」の登場

**The Gentlemen** というランサムウェアグループが、セキュリティソフトを**強制的に無効化するツール**「GentleKiller（ジェントルキラー）」を開発・配布していることが判明しました。

- **攻撃対象**：CrowdStrike、SentinelOne、Microsoft Defender、Sophos、Kaspersky、ESETなど **48種類のセキュリティ製品・400以上のプロセス**
- **変種**：8種類のバリエーションが存在

---

### ⚠️ ④ Splunkの深刻な脆弱性が悪用される

**Splunk（スプランク）** はシステムのログ（記録）を分析する企業向けソフトです。このソフトに深刻な欠陥（CVE-2026-20253）が見つかり、**すでに実際の攻撃に使われています**。

## 技術的な詳細

### FortiBleedの仕組み

```
攻撃者
  ↓
[自動化ツールで24時間攻撃]
  ↓
①過去の情報漏洩から盗んだID・パスワードを試す（クレデンシャルスタッフィング）
②パスワードを総当たりで試す（ブルートフォース）
  ↓
MFAなし・弱いパスワードの機器に侵入成功
  ↓
社内ネットワークへのアクセス権を入手
```

**特に問題なのは**、過去の別の事件（CVE-2026-24858など）で漏れたIDとパスワードが今も使い回されていることです。「以前別のサービスで漏れたパスワードを、今もFortinet機器で使い続けている」という状況が狙われています。

---

### GentleKillerの仕組み

```
ランサムウェア攻撃の手順（従来）
①侵入 → ②セキュリティソフトに検知される → ③攻撃失敗

ランサムウェア攻撃の手順（GentleKiller使用後）
①侵入 → ②GentleKillerでセキュリティソフトを無効化 → ③ランサムウェアを展開 → ④ファイルが暗号化される
```

GentleKillerが巧妙なのは、**正規のソフトウェアに偽装**して、Windowsの深い部分（カーネル）で動く**脆弱なドライバー**を悪用することです。

> 🎭 例え話：
> セキュリティソフトは「警備員」です。GentleKillerは「警備員の制服を着た泥棒」が、警備システムの電源を切ってから本物の泥棒を呼び込むイメージです。

---

### Klue/Salesforce侵害の仕組み

```
古い連携用アカウント（誰も管理していない）
  ↓ パスワードが漏れていた
攻撃者がそのアカウントでSalesforceに接続
  ↓
Klueアプリを通じて顧客データにアクセス・盗む
  ↓
「金払わなければデータを公開する」と脅迫（恐喝）
```

「レガシークレデンシャル（古い認証情報）」が原因です。使われなくなったアカウントでも放置するだけで、それが侵入口になります。

## なぜ重要なのか

### 📊 影響範囲の大きさ

| インシデント | 影響規模 |
|---|---|
| FortiBleed | 世界8万台以上の企業・政府機関の機器 |
| GentleKiller | 48種類のセキュリティ製品が無効化される可能性 |
| Klue/Salesforce | 複数の企業の顧客データが流出 |
| Splunk脆弱性 | 世界中の企業のログ管理システムが危険 |

### 😟 「目新しさがない」のが最大の問題

記事の冒頭でも指摘されていますが、今週の攻撃は**特別に高度なものではありません**。

- 弱いパスワード
- 使い回しのパスワード
- 放置された古いアカウント
- MFAなし

これらは何年も前から「危険だ」と言われてきた問題です。それでも被害が出続けているのは、「基本的な対策が徹底されていない」からです。

> 💡 例え話：
> 「玄関に鍵をかけましょう」と何年も言われ続けているのに、鍵をかけない人が後を絶たない。そして泥棒は「わざわざ窓を割らなくても、開いている玄関から入ればいい」と学んでいる状況です。

## 対策・今後の展望

### ✅ 個人でできること

1. **パスワードの使い回しをやめる**
   - サービスごとに異なるパスワードを使いましょう
   - パスワードマネージャー（1Password、Bitwardenなど）の活用がおすすめ

2. **MFA（多要素認証）を必ず設定する**
   - パスワードだけでは不十分！SMSやアプリの認証コードを追加しましょう

3. **怪しいソフトをダウンロードしない**
   - 公式サイト・公式ストア以外からのダウンロードは危険です

### ✅ 企業・組織でできること

1. **使われていないアカウントをすぐに削除する**
   - Klue事件の教訓：古い連携アカウントが侵入口になります

2. **Fortinet機器を使っている場合**
   - CISAの勧告に従い、すぐにパスワード変更とMFA設定を
   - ファームウェア（機器のOS）を最新版に更新

3. **Splunkを使っている場合**
   - バージョン10.2.4または10.0.7以上に今すぐアップデート

4. **EDRの無効化対策**
   - セキュリティソフトを「改ざん防止モード（タンパープロテクション）」で動かす
   - カーネルドライバーの署名ポリシーを厳格に管理する

### 🔮 今後の見通し

GentleKillerのようなEDRキラーツールは、今後ますます増えると予想されます。攻撃者は「セキュリティソフトを先に倒してから攻める」戦術をますます洗練させていくでしょう。セキュリティ業界は「攻撃者 vs. 防御者」のいたちごっこに備える必要があります。

## 用語解説

| 用語 | 意味 |
|---|---|
| **FortiGate** | Fortinet社が作った企業向けファイアウォール・VPN機器 |
| **SSL VPN** | 暗号化された安全なリモートアクセス用VPN |
| **CVE（シーブイイー）** | 発見されたセキュリティ脆弱性につけられる識別番号（例：CVE-2026-24858） |
| **クレデンシャルスタッフィング** | 過去の情報漏洩で得たID・パスワードを別のサービスに使い回す攻撃 |
| **ブルートフォース** | パスワードを機械的に総当たりで試す攻撃 |
| **カーネル** | OSの中核部分。ここで動くプログラムは非常に強い権限を持つ |
| **カーネルドライバー** | ハードウェアとOSをつなぐ深い部分で動くプログラム |
| **RaaS** | ランサムウェアをサービスとして提供するビジネスモデル |
| **EDR** | 端末の怪しい動作をリアルタイムで検出・対応するセキュリティソフト |
| **恐喝（エクストーション）** | データを盗んで「公開されたくければ金を払え」と脅す犯罪 |
| **Splunk** | システムのログ（記録）を収集・分析する企業向けソフト |
| **リモートコード実行** | 攻撃者が遠隔からターゲットのコンピュータで任意のプログラムを動かせる状態 |
| **CISA** | アメリカのサイバーセキュリティ・インフラセキュリティ庁 |
| **ファームウェア** | 機器に組み込まれたOSやソフトウェア |

---

> 📝 **今週のまとめ**
> 
> 今週の攻撃の共通点は「基本的なセキュリティ対策の欠如」です。強力なパスワード・MFAの設定・古いアカウントの削除・ソフトウェアのアップデート——これらを徹底するだけで、多くの攻撃は防げます。「高度な攻撃」よりも「基本の穴」を突かれることの方がずっと多いのが現実です。
