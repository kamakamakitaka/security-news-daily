# ブロックするだけでは不十分：ソーシャルエンジニアリング攻撃の連鎖を断ち切れ

**元記事**: [Beyond Blocking: Disrupting the Social Engineering Attack Chain](https://inl03.netline.com/ltr6/?_m=3n.009a.4011.sp0ao46r89.32cu)
**解説日**: 2025年7月11日

---

## 背景知識

まず、この記事を読む前に知っておきたいキーワードを説明します。

### 🛡️ サイバーセキュリティの「防御」ってどういうこと？

インターネットの世界では、家のセキュリティと同じように「悪い人を入れない」仕組みがあります。メールの怪しい添付ファイルを開けないようにしたり、不正なサイトへのアクセスをブロックしたりするのが、これまでの主な防御でした。

### 🎭 ソーシャルエンジニアリングとは？

**ソーシャルエンジニアリング**とは、コンピューターを直接ハッキングするのではなく、**人間の心理につけ込んで騙す攻撃**のことです。  
例えば：
- 「銀行からです。パスワードを教えてください」と電話してくる
- 本物そっくりの偽のメールを送って、偽サイトに誘導する
- 信頼できる人のふりをしてお金を振り込ませる

技術的なハッキングよりも「人間を騙す」方が簡単で効果的なため、攻撃者が多く使う手口です。

### 🤖 生成AIとは？

**生成AI（Generative AI）** とは、ChatGPTのように、文章・画像・音声などを自動で作り出すAIのことです。最近では、攻撃者もこのAIを悪用して、リアルな偽メールや偽音声を大量に自動生成するようになっています。

---

## 何が起きたのか

この記事は「特定の事件」の報告ではなく、**現代のサイバー攻撃がどう進化しているかの警告と解説**です。

### 昔の攻撃 vs 今の攻撃

| 昔（数年前まで） | 今（AI時代） |
|---|---|
| 素人が作った雑なフィッシングメール | AIが作る超リアルな偽メール・偽音声 |
| 1つのルート（主にメール）から攻撃 | メール・SMS・SNS・広告など複数ルートを同時に使う |
| 手動で攻撃 | AIが自動で大量に、かつ個人に合わせてカスタマイズ |
| 一発で終わる | 段階的に信頼を積み上げる「多段階攻撃」 |

つまり、**「怪しいメールをブロックすれば安全」という時代は終わった**、というのがこの記事の核心です。

## 技術的な詳細

### ⛓️ 攻撃の「5段階チェーン（連鎖）」

現代の攻撃は映画のような**シナリオが組まれた5つのステップ**で進みます。家に泥棒が入る場合に例えてみましょう。

---

### 🔧 ステージ1：準備（Setup）

> 攻撃はセキュリティチームが気づくよりずっと前から始まっている

**泥棒の例え：** 泥棒が事前に家の周りを観察して、どの窓が弱いか調べる段階

攻撃者がやること：
- **タイポスクワッティング**（例：`amazon.com`の偽物として`arnazon.com`のような似たドメインを作る）
- 実在する社員・役員に成りすましたSNSアカウントを作る
- 本物そっくりの偽サポートサイトや偽ショップを作る

怖いのは、**攻撃者は企業の公式サイト・SNS・インタビュー動画なども学習して、「自然に見える」偽物**を作れるようになっている点です。これらの偽サイトは企業の「外」にあるため、社内のセキュリティツールでは検知できません。

---

### 📤 ステージ2：発射（Launch）

> 作った偽の資産を使って、複数チャンネルから同時に攻撃を開始する

**泥棒の例え：** 仲間に合図を送って、正面・裏口・窓から同時に侵入を試みる段階

攻撃手法：
- **フィッシングメール**（個人に合わせてカスタマイズされた偽メール）
- **スミッシング（Smishing）**：SMS・WhatsAppなどのメッセージアプリを使った詐欺
- **ビッシング（Vishing）**：AIが生成した偽の音声（ディープフェイク音声）で電話をかける
- **偽の広告**：Google検索広告やSNS広告で、本物と見分けがつかない偽リンクを表示する

> 💡 実例として記事に登場するケース：あるソフトウェア会社を標的に、攻撃者がGoogle広告を購入。見た目は完全に本物のURLと会社名を表示しているのに、クリックすると悪意あるファイルをダウンロードさせる仕組みになっていた。既存のセキュリティツールでは「安全」と判断されてしまった。

---

### 📥 ステージ3：接触（Contact）

> 「外からの攻撃」が「内側での存在」に変わる瞬間

**泥棒の例え：** ついに家の中に足を踏み入れた段階

具体例：
- 経理担当者の「重要メール」フォルダにフィッシングメールが届く
- 偽のMFA（多要素認証）の確認通知がスマホに届く
- TeamsやSlackの中に偽のベンダー（取引先）からのメッセージが届く
- LinkedInなどで偽の採用担当者からコンタクトが来る

この段階で、攻撃が「**外の脅威**」から「**内側の問題**」に変化します。

## なぜ重要なのか

### 🏢 企業・組織にとって

- メールフィルターやファイアウォールだけでは**もはや対応できない**
- 攻撃が「社外」の偽サイト・偽広告から始まるため、**既存ツールの死角**になっている
- 攻撃者はAIで**人間よりも速く、大量に、個人に最適化した攻撃**を仕掛けられる

### 👤 個人にとって

- 「怪しい日本語のメール」だけが危険なのではなく、**完璧な日本語・完璧なデザインの偽物**が届く時代になった
- SNS・メッセージアプリ・検索広告など、**日常的に使うツール全て**が攻撃経路になっている
- **音声も偽物（ディープフェイク）**になるため、「電話で確認すれば安心」も通用しなくなりつつある

## 対策・今後の展望

### ✅ 個人ができる対策

| 対策 | 理由 |
|---|---|
| URLを手動で入力するか、公式ブックマークからアクセス | 偽広告・偽リンクを踏まないため |
| 急かされたら一旦立ち止まる | 攻撃者は焦らせて判断力を奪おうとする |
| 別の手段で相手の身元を確認する（電話で確認するなら別のルートで番号を調べる） | スミッシング・ビッシング対策 |
| 定期的にSNSで自分の名前を検索する | なりすましアカウントの早期発見 |

### ✅ 企業・組織ができる対策

- **「ブロック」だけでなく「検知・対応・回復」まで含めた戦略**に移行する
- 社外の偽サイト・偽ドメインを監視するサービスを導入する（**デジタルリスクプロテクション**）
- 社員への継続的なセキュリティ教育（特にAI時代の攻撃手口）
- Teams・Slack・SMSなどの**コラボレーションツールにも**セキュリティ対策を拡張する

### 🔮 今後の展望

生成AIの進化とともに、攻撃はさらに精巧になっていきます。「怪しいかどうか人間が判断する」モデルには限界が来ており、**AIを使った防御側のツール**も急速に進化しています。今後は「攻撃AIと防御AIのイタチごっこ」の時代になると言われています。

## 用語解説

| 用語 | 意味 |
|---|---|
| **ソーシャルエンジニアリング** | 技術ではなく人間の心理を利用して情報を盗む攻撃 |
| **フィッシング（Phishing）** | 偽メールなどで偽サイトに誘導し、パスワード等を盗む攻撃 |
| **スミッシング（Smishing）** | SMS（ショートメッセージ）を使ったフィッシング詐欺 |
| **ビッシング（Vishing）** | 音声（電話）を使ったフィッシング詐欺。AIの偽音声も使われる |
| **ディープフェイク** | AIが生成した偽の音声・動画・画像 |
| **タイポスクワッティング** | 有名サイトのURLのタイプミスを狙った偽ドメイン（例：gooogle.com）|
| **MFA（多要素認証）** | パスワード＋スマホ認証など、複数の方法で本人確認する仕組み |
| **SIEM（シーム）** | セキュリティの異常を一元管理・監視するシステム |
| **SOC** | Security Operations Center。セキュリティを監視・対応する専門チーム |
| **アタックチェーン（攻撃チェーン）** | 攻撃が複数の段階で連鎖的に進む仕組み |
| **生成AI（Generative AI）** | 文章・画像・音声などを自動生成するAI（ChatGPTなど） |
| **スピアフィッシング** | 特定の個人や組織を狙い撃ちにした精密なフィッシング攻撃 |
| **デジタルリスクプロテクション** | 企業の名前やブランドが悪用されていないかネット上を監視するサービス |

> 💬 **まとめると…**  
> 昔の「怪しいメールに注意」という常識は、AIの登場でもはや通用しません。攻撃者は映画の脚本家のように「シナリオ」を作り、複数のルートから時間をかけて信頼を積み上げて騙してきます。私たちもその「シナリオ」の存在を知り、一歩先を考えて行動することが大切です。
