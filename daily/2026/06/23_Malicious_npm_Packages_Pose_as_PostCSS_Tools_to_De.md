# 偽のPostCSSツールを装った悪意あるnpmパッケージがWindowsのRATを配布

**元記事**: [Malicious npm Packages Pose as PostCSS Tools to Deliver Windows RAT](https://inl03.netline.com/ltr6/?_m=3n.009a.4011.sp0ao46r89.32c6)
**解説日**: 2025年7月

---

## 背景知識

このニュースを理解するために、いくつかの基本的な概念を説明します。

### 📦 npmとは？
**npm（Node Package Manager）**は、JavaScriptのプログラムを作るときに使う「部品の倉庫」のようなものです。プログラマーが「このコードを全部自分で書くのは大変だな」というときに、他の人が作った便利な部品（パッケージ）を簡単に入手できる仕組みです。

> 🏪 **例えるなら**：料理でいう「スーパーマーケット」のようなもの。自分で野菜を栽培するのではなく、スーパーで買って料理に使うのと同じように、プログラマーも既成の部品を使って効率よく開発します。毎週1億2700万回以上もダウンロードされているパッケージもあるほど、開発者には必須のサービスです。

### 🎨 PostCSSとは？
**PostCSS**は、ウェブサイトのデザインを記述するCSS（見た目を決めるコード）を自動的に変換・最適化するツールです。多くの開発者が日常的に使っている有名なツールで、今回の攻撃者はこの「有名さ」を悪用しました。

### 🦠 RATとは？
**RAT（Remote Access Trojan）**は「遠隔操作ウイルス」のことです。これに感染すると、攻撃者がインターネット越しに、まるで本人がパソコンの前に座っているかのようにあなたのパソコンを自由に操作できてしまいます。

> 🏠 **例えるなら**：家の鍵を勝手にコピーされて、あなたが外出中に犯人が自由に出入りできる状態になるイメージです。

## 何が起きたのか

セキュリティ企業JFrogの研究者が、**npmに偽物のパッケージが公開されている**ことを発見しました。

### 発見された悪意あるパッケージ（3つ）

| パッケージ名 | ダウンロード数 | 偽装内容 |
|---|---|---|
| `aes-decode-runner-pro` | 145回 | 暗号化ツールのふり |
| `postcss-minify-selector` | 256回 | PostCSSツールのふり |
| `postcss-minify-selector-parser` | 615回 | 有名ライブラリのふり |

これらは全て「abdrizak」というユーザーが過去1ヶ月以内に公開したもので、**記事執筆時点でもまだダウンロード可能な状態**でした。

特に`postcss-minify-selector-parser`というパッケージ名は、**毎週1億2700万回以上ダウンロードされる本物の`postcss-selector-parser`に名前を似せた**巧妙なものです。

> ⚠️ **ポイント**：「ちょっと名前が違うだけで本物っぽい」という手口は、URLの「amazon.com」を「arnazon.com」に似せたフィッシングサイトと同じ発想です。急いでいると見逃してしまいます。

## 技術的な詳細

感染の流れを段階的に説明します。まるで「罠のドミノ倒し」のような仕組みです。

### 🔴 攻撃の流れ（多段階攻撃）

```
[ステップ1] 偽パッケージをインストール
      ↓
[ステップ2] JavaScriptの「仕掛け」が動く
      ↓
[ステップ3] PowerShellスクリプトを密かに作成・実行
      ↓
[ステップ4] 外部サーバー(nvidiadriver[.]net)からZIPファイルをダウンロード
      ↓
[ステップ5] ZIPを解凍してVBScriptを実行
      ↓
[ステップ6] Python製のRATが起動
      ↓
[ステップ7] 攻撃者のサーバーとつながり、パソコンを乗っ取られる
```

### 🔍 各ステップの詳細

**ステップ2〜3：JavaScriptドロッパー**
パッケージをインストールした瞬間に、`settings.ps1`というPowerShellスクリプト（Windowsの自動操作コマンド）がこっそりと作られ、実行されます。

> 💊 **例えるなら**：薬に見せかけた錠剤を飲んだら、体の中で「第二の薬」を作り始めるようなイメージです。

**ステップ4：ダウンロード**
PowerShellスクリプトが、`nvidiadriver[.]net`（NVIDIAの公式サイトに似せた偽ドメイン）からZIPファイルをダウンロードします。

**ステップ5〜6：Python環境の構築**
ZIPの中にはPythonのランタイム（実行環境）まで丸ごと入っており、**被害者のパソコンにPythonがなくても動く**ように設計されています。

### 😈 RATの主な機能

感染後、攻撃者は以下のことができるようになります：

| 機能 | 内容 |
|---|---|
| 📋 情報収集 | パソコンのスペックやOS情報を収集 |
| 🔑 パスワード窃取 | **Google Chromeに保存されたパスワードを盗む** |
| 🧩 拡張機能の悪用 | Chrome拡張機能のデータを盗む |
| 💻 コマンド実行 | 攻撃者の命令でプログラムを実行 |
| 📁 ファイル操作 | ファイルのアップロード・ダウンロード |

これらの機能は複数の`.pyd`ファイル（Pythonの特殊な部品）に分割して隠されており、セキュリティソフトに検出されにくくなっています。

## なぜ重要なのか

### 👨‍💻 開発者が狙われている
npmは世界中のプログラマーが毎日使うサービスです。開発者のパソコンが感染すると、その開発者が作っているソフトウェアやサービスにも被害が及ぶ可能性があります（**サプライチェーン攻撃**と呼ばれます）。

> 🏭 **例えるなら**：食品工場の作業員が病気になると、その工場で作られた食品を食べた多くの人にも影響が出るのと同じです。

### 🎭 「本物そっくり」な偽装の巧妙さ
今回の攻撃の特徴は：
- ✅ 有名な正規パッケージに名前を似せている
- ✅ 正規パッケージへの「依存関係」まで設定して本物らしく見せている
- ✅ NVIDIAドライバーに見せかけた偽ドメインを使っている

### 🌍 同時に発見された他の攻撃
記事では、同じ時期に発見された類似攻撃も紹介されています：

1. **`apintergrationpost`**：Linux向けのRAT「MYRA」を仕込んだパッケージ。インストール時にシステムの奥深くに入り込む「ルートキット」まで組み込まれた悪質なもの。

2. **`@withgoogle/stitch-sdk`**：GoogleのAIデザインツールに偽装し、GitHubのパスワード、SSH鍵、npmの設定情報など**8種類もの開発者情報を盗む**パッケージ。

3. **5つの悪意あるパッケージ群**（`procwire`、`routecraft`など）：Windowsでマルウェアをインストールするもの。

## 対策・今後の展望

### ✅ 開発者ができる対策

**1. パッケージ名をよく確認する**
インストール前に、パッケージ名が本当に正しいか確認しましょう。特に有名パッケージに似た名前には要注意です。

```
本物: postcss-selector-parser
偽物: postcss-minify-selector-parser  ← 微妙に違う！
```

**2. ダウンロード数と公開日を確認する**
npmのページで以下を確認する習慣をつけましょう：
- 📊 ダウンロード数（極端に少ない場合は注意）
- 📅 初回公開日（つい最近公開されたものは慎重に）
- 👤 作者の評判や他のパッケージの実績

**3. セキュリティツールの活用**
- `npm audit`コマンドで既知の脆弱性をチェック
- GitHubのDependabotなどの自動検出ツールを使う

**4. 最小権限の原則**
開発環境と本番環境を分離し、不必要な権限を与えないようにする。

### 🔮 今後の展望

このような「ソフトウェアサプライチェーン攻撃」は今後も増加が予想されます。npmやGitHubなどのプラットフォーム側も対策を強化していますが、**個人の確認習慣が最も重要な防衛線**です。

## 過去記事との関連

今回は特定の過去記事との直接の関連はありませんが、このような**npmパッケージへの偽装攻撃**は近年非常に増えているトレンドです。以前からtyposquatting（タイポスクワッティング：有名なURLや名前に似せた偽物を作る手法）については多くの事例が報告されており、今回の事件もその延長線上にあります。開発者を狙ったサプライチェーン攻撃として、継続的に注意が必要なテーマです。

## 用語解説

| 用語 | 解説 |
|---|---|
| **npm** | JavaScriptの部品（パッケージ）を管理・配布するシステム |
| **RAT（Remote Access Trojan）** | 遠隔操作ウイルス。感染すると攻撃者がパソコンを自由に操作できる |
| **PostCSS** | ウェブのデザインコード（CSS）を自動処理する有名ツール |
| **PowerShell** | Windowsの高機能な自動操作コマンドシステム |
| **ドロッパー** | 他のマルウェアをインストールするための「先発隊」プログラム |
| **Nuitka** | PythonコードをC++に変換するツール。解析を難しくするために使われた |
| **C2サーバー** | Command and Control（指令管制）サーバー。攻撃者がマルウェアに命令を送るための拠点 |
| **サプライチェーン攻撃** | 直接攻撃するのではなく、ソフトウェアの「部品供給ルート」を汚染して広範囲に感染させる攻撃手法 |
| **タイポスクワッティング** | 有名なサービス名やURLに似せた偽名を使う詐欺的手法 |
| **ABE（App-Bound Encryption）** | Chromeのパスワードを守るための暗号化機能。今回のRATはこれを回避する機能も持っていた |
| **ルートキット** | OSの奥深くに潜り込み、自分の存在を隠すマルウェアの一種 |
| **VBScript** | Windowsで動く簡易プログラミング言語。今回は悪用された |

---

> 💬 **まとめ**：今回の事件は「信頼できると思っていた部品倉庫（npm）に偽物が混入していた」というケースです。プログラマーは毎日大量のパッケージを使うため、一つひとつを丁寧に確認することが重要です。「有名なツールに似た名前だから安心」ではなく、「似ているからこそ怪しいかもしれない」という視点を持つことが、現代のサイバーセキュリティでは非常に大切です。
