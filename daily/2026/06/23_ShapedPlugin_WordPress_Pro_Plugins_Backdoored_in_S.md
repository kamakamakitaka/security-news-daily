# ShapedPlugin製WordPressプロプラグインがサプライチェーン攻撃でバックドアを仕込まれる

**元記事**: [ShapedPlugin WordPress Pro Plugins Backdoored in Supply Chain Attack](https://inl03.netline.com/ltr6/?_m=3n.009a.4011.sp0ao46r89.32d0)
**解説日**: 2026年6月24日

---

## 背景知識

まず、この記事を理解するためのキーワードをざっくり整理しておきましょう。

### WordPressって何？
**WordPress（ワードプレス）** は、世界中のウェブサイトの約40%以上で使われている「ウェブサイト作成ツール」です。ブログ、ネットショップ、企業サイトなど、プログラミングの知識があまりなくても本格的なサイトが作れるのが特徴です。

### プラグインって何？
WordPressには「**プラグイン**」という追加機能パーツがあります。スマホのアプリのようなイメージで、「商品スライダーを表示したい」「お客様の声を見せたい」など、必要な機能をあとから追加できます。今回問題になったのは「**Pro（有料版）**」のプラグインです。

### サプライチェーン攻撃って何？
「**サプライチェーン攻撃**」は、製品を直接狙うのではなく、**その製品を届ける流通経路（サプライチェーン）を狙う**攻撃です。  
例えを使うと…

> 🍱「お弁当屋さんを直接襲うのではなく、お弁当を配達する配達員に毒を盛って、正規のルートで毒入り弁当を届ける」

…というようなイメージです。正規のルートで届くため、受け取った側は疑いにくいのが特徴で、非常に危険な攻撃手法です。

### バックドアって何？
**バックドア（裏口）** とは、攻撃者がこっそり仕込む「秘密の入口」のことです。玄関（正面ドア）はちゃんとカギがかかっていても、裏口から自由に出入りできてしまう状態を指します。

---

## 何が起きたのか

**WordPressプラグインの開発会社「ShapedPlugin」** が配布している有料プラグインに、何者かが**悪意あるコード（バックドア）を仕込んだ**ことが発覚しました。

被害を受けたプラグインは以下の3つです：

| プラグイン名 | 被害バージョン | 用途 |
|---|---|---|
| Product Slider Pro for WooCommerce | 3.5.4より前 | ネットショップの商品スライダー表示 |
| Real Testimonials Pro | 3.2.5 | 顧客レビュー・証言の表示 |
| Smart Post Show Pro | 4.0.2より前 | 記事・投稿のスマートな表示 |

重要なポイントとして、**WordPress.org（公式サイト）で配布されている無料版は影響を受けていません**。  
被害を受けたのは「ShapedPlugin公式サイトのライセンス更新システム（EDD）経由でアップデートした**有料ユーザー**」だけです。

つまり、正規にお金を払って使っていた**信頼しているユーザーほど被害を受ける**という、非常に悪質な攻撃です。

## 技術的な詳細

攻撃の流れをステップごとに見ていきましょう。

### Step 1：ビルド・配布パイプラインへの侵入
攻撃者は、ShapedPluginがプラグインを「ビルド（完成品に仕上げる）」して「配布する」仕組みそのものに侵入しました。料理で言えば、工場の製造ラインに毒物を混ぜるようなイメージです。

### Step 2：ローダーコードの埋め込み
悪意あるコードが仕込まれたプラグインをインストールすると、管理者ページを開くたびに**ローダー（悪意あるプログラムを呼び込む仕組み）**が動き出します。このローダーは外部の怪しいサーバー（`194.76.217[.]28:2871`）から**ペイロード（本体の攻撃コード）**を取得します。

> 📦 例えるなら「外から荷物（ウイルス本体）を取り寄せて、こっそり家の中にインストールする配達員」

### Step 3：偽プラグインのインストール
取得したペイロードは「**偽プラグイン**」として自動でインストール・有効化されます。この偽プラグインは：

- ✅ WordPress管理画面のプラグイン一覧に**表示されない**（隠れている）
- ✅ **パスワードを平文（暗号化なし）のまま盗む**
- ✅ **二段階認証（2FA）コードも盗む**
- ✅ 特定のトークン（合言葉）を使ってファイルを自由に書き換えられる
- ✅ **Webシェル**（サーバーを遠隔操作できる仕掛け）を設置する

### Step 4：重要情報の大量窃取
`install-persistent.php` という特別なファイルが以下のデータを盗み出します：

- 🔑 **wp-config.phpの全内容**（データベースのパスワード、認証キーなど）
- 👤 **全管理者アカウントと登録日**
- 📧 **メール送信プラグインの認証情報**（WP Mail SMTP等）
- 🛒 **WooCommerceの過去3ヶ月の注文データ**（支払い方法の内訳含む）

### Step 5：証拠隠滅
情報を盗んだあと、悪意あるプログラムは**自分自身を削除して証拠を消します**。まるでスパイ映画のように、痕跡を消して調査を困難にする仕組みまで持っています。

## なぜ重要なのか

### 深刻度が「最高レベル」
このインシデントには**CVSSスコア（脆弱性の深刻度を表す点数）** が与えられています。

- `CVE-2026-49777`（Product Slider Pro）：**10.0点（最大）**
- `CVE-2026-10735`（インシデント全体）：**9.8点**

10点満点のうち10点というのは「理論上考えられる最悪の状態」を意味します。

### 「信頼」そのものが武器に使われた
今回の攻撃の最大の問題点は、「**正規の有料ライセンスを持っていて、公式のアップデートをした**」というまさに模範的な行動をしたユーザーが被害を受けていることです。  

普通なら「怪しいサイトからダウンロードしない」「公式からアップデートする」という対策が有効ですが、今回はその対策をしていたユーザーが狙われました。

### ネットショップ運営者への影響が大きい
特にWooCommerceを使ってネットショップを運営している場合、顧客の注文データや決済情報が流出した可能性があります。これはビジネス上の信用問題だけでなく、法的な問題にもなりえます。

---

## 対策・今後の展望

### 今すぐやるべきこと（被害を受けた可能性があるサイト管理者向け）

1. 🔑 **全パスワードをリセット**する（管理者、データベース、SMTP等すべて）
2. 🛡️ **二段階認証（2FA）のシークレットキーをすべて無効化・再生成**する
3. 👥 **管理者アカウントの一覧を確認**して、身に覚えのないアカウントを削除する
4. 📧 **メール送信プラグインの設定を確認**して、SMTP認証情報が改ざんされていないか確認する
5. 🔄 **プラグインを最新版（安全が確認されたもの）にアップデート**する（ShapedPluginが安全審査を経て新バージョンを準備中）

### ShapedPluginの対応
ShapedPluginは今回の問題を認め、配布・リリースプロセスの見直しを行うと発表しています。安全審査とテストが完了次第、新しいバージョンのプラグインがリリースされる予定です。

### WordPressユーザーへの教訓
- 有料プラグインのアップデートであっても、**100%安全とは言えない時代**になっています
- セキュリティプラグイン（例：Wordfence）を導入して異常を検知できる環境を整えましょう
- 定期的なバックアップを取っておくことが被害を最小限に抑える鍵になります

## 過去記事との関連

以前「**ソーシャルエンジニアリング攻撃の連鎖を断ち切れ**」という記事で、**人の心理や信頼を利用した攻撃手法**についてご紹介しました。

今回の攻撃はまさにその延長線上にあります。「正規のベンダーから届く公式アップデート」という**信頼関係そのものを悪用**する点で、ソーシャルエンジニアリングと同様の「人の判断を裏切る」攻撃の本質が現れています。  

また、「**偽のnpmパッケージがRATを配布**」という記事でもサプライチェーン攻撃を取り上げましたが、今回はWordPress、前回はnpm（JavaScript開発ツール）と、**開発者・サイト運営者が日常的に使うツールのエコシステムが狙われる**という共通のトレンドが続いています。攻撃者にとって「多くの人が信頼しているもの」は、それだけ魅力的なターゲットと言えます。

## 用語解説

| 用語 | 説明 |
|---|---|
| **WordPress** | 世界で最も使われているウェブサイト作成ツール |
| **プラグイン** | WordPressに機能を追加するパーツ（スマホのアプリのようなもの） |
| **サプライチェーン攻撃** | 製品の配布・流通経路を乗っ取って悪意あるコードを混ぜ込む攻撃 |
| **バックドア** | 攻撃者が仕込む「秘密の裏口」。気づかれずにシステムに侵入できる |
| **ビルドパイプライン** | ソフトウェアを完成品に仕上げて配布するまでの自動化された工程 |
| **ペイロード** | 攻撃コードの「本体」部分。ローダーによって呼び込まれる |
| **ローダー** | 外部から攻撃コードを取り込んで実行する「仕込みプログラム」 |
| **Webシェル** | サーバーをブラウザ経由で遠隔操作できる悪意あるプログラム |
| **2FA（二段階認証）** | パスワードに加えて、もう一段階の確認（ワンタイムコード等）を要求する認証方法 |
| **wp-config.php** | WordPressの設定ファイル。データベースのパスワードなど最重要情報が含まれる |
| **CVSS スコア** | 脆弱性の危険度を0〜10点で表す指標。10点が最大（最も危険） |
| **CVE** | 発見されたセキュリティ脆弱性に付けられる一意の識別番号 |
| **EDD（Easy Digital Downloads）** | デジタル製品の販売・配布に使われるWordPressのシステム |
| **WooCommerce** | WordPressでネットショップを作るためのプラグイン |
| **REST エンドポイント** | ウェブ上でプログラム同士がやりとりするための「窓口URL」 |
| **平文（ひらぶん）** | 暗号化されていない、そのまま読めるテキストのこと |
