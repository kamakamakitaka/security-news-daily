# WhatsApp経由で偽の書類ファイルを使い、遠隔操作ツールをインストールさせる攻撃が発覚

**元記事**: [WhatsApp VBScript Campaign Uses Fake Documents to Install ManageEngine RMM Tool](https://inl03.netline.com/ltr6/?_m=3n.009a.4011.sp0ao46r89.32ci)
**解説日**: 2025年7月10日

---

## 背景知識

このニュースを理解するために、いくつかの言葉を先に説明しておきます。

### 💬 WhatsAppとは？
世界で20億人以上が使っているメッセージアプリです。LINEに似ていますが、海外では非常にポピュラーです。スマホアプリだけでなく、パソコンのブラウザで使える「WhatsApp Web」や、パソコン専用のアプリ「WhatsApp Desktop」もあります。

### 📄 VBScript（VBS）とは？
Windowsのパソコンで動く「簡易プログラム」のようなものです。ファイルの拡張子が「.vbs」になっています。本来はパソコンの作業を自動化するために使われますが、**悪用されると、ウイルスを仕込んだり、勝手にソフトをインストールしたりできます**。「見た目はただのファイルだけど、実は命令書」というイメージです。

### 🖥️ RMM（リモートモニタリング＆マネジメント）ツールとは？
「遠隔操作ソフト」です。会社のIT担当者が遠くからパソコンを操作・管理するために使う正規のソフトウェアです。学校のICT支援員さんが生徒のパソコンを遠隔でサポートするようなイメージ。**正規のソフトなので、セキュリティソフトに検知されにくい**という特徴があり、攻撃者に悪用されることがあります。

### 🛡️ UAC（ユーザーアカウント制御）とは？
Windowsの安全機能のひとつです。「このアプリはあなたのパソコンに変更を加えようとしています。許可しますか？」というダイアログを出して、勝手な操作を防ぐ仕組みです。

---

## 何が起きたのか

セキュリティ会社カスペルスキーが、**WhatsApp経由で悪意あるファイルを送りつける攻撃キャンペーン**を発見しました。

攻撃の流れはこうです👇

1. 攻撃者が**何らかの方法でWhatsAppアカウントを乗っ取る**
2. そのアカウントの**連絡先（友達・知り合い）に向けて**、怪しいファイルを送りつける
3. 受け取った人は「知っている人から来たメッセージ」だと思い、ファイルを開いてしまう
4. ファイルを開くと、**気づかないうちに遠隔操作ソフトがインストールされ、パソコンを自由に操られてしまう**

被害は**マレーシア・ブラジル・インド・メキシコ・シンガポール・イギリス・スペイン・台湾・オーストラリア・ロシア・ベトナム**など世界中に広がっており、最も被害が多いのはマレーシアとのことです。

---

## 技術的な詳細

少し細かいですが、攻撃の仕組みを順番に見ていきましょう。

### ステップ① 偽装ファイルを送りつける

攻撃者は「Financial Reports.vbs（財務レポート）」「Account Statement.vbs（口座明細）」など、**ビジネスや金融に関係しそうなファイル名**を使います。ポルトガル語・フランス語・ドイツ語・マレー語など、**各国の言語に合わせた名前**を使っているのもポイント。まるで本物の書類のように見せかけています。

> 🎭 例え話：「健康診断の結果.pdf」のような名前で「実は爆弾が入った小包」を送りつけるイメージです。

### ステップ② 中身は巧妙に偽装されている

VBSファイルの中身には、**Windowsの正規アップデート機能に見せかけたコメント文**が大量に書き込まれています。しかも**中国語**で書かれており、「Windows Updateモジュール」「証明書の検証」「システム整合性チェック」などのもっともらしい説明が含まれています。これはセキュリティソフトを騙すための偽装工作です。

### ステップ③ 感染の連鎖が始まる

ファイルを開くと、Windowsの「WScript.exe（スクリプト実行プログラム）」が動き出し、インターネット上のサーバーからさらに別の悪意あるスクリプト（命令書）を2つ追加でダウンロードします。

| ダウンロードされるもの | 役割 |
|---|---|
| スクリプト① | WindowsのUAC（安全機能）を無効化・改ざんする |
| スクリプト② | 「ManageEngine RMM Central」という正規の遠隔操作ソフトをインストールする |

### ステップ④ 遠隔操作が完成する

ManageEngine RMM Centralは**正規のビジネスソフト**です。しかし攻撃者の手によってインストールされると、**外部から被害者のパソコンを自由に操作できる「抜け穴」**が完成してしまいます。正規ソフトなのでセキュリティソフトが警告を出しにくく、非常に厄介です。

## なぜ重要なのか

この攻撃が特に怖い理由を3つ挙げます。

### ⚠️ 理由1：「知り合いから来た」から信用してしまう

通常、知らない人からのリンクや添付ファイルには警戒します。しかし今回は**乗っ取られたアカウントの連絡先（友達・同僚・家族）に向けて送られてくる**ため、「あの人から来たから大丈夫だろう」と思って開いてしまいがちです。

### ⚠️ 理由2：正規ソフトを悪用するので発見しにくい

ウイルスそのものをインストールするわけではなく、**正規の遠隔操作ソフトをこっそりインストールする**手口です。セキュリティソフトは「正規ソフト＝安全」と判断しやすいため、検知が難しくなります。

### ⚠️ 理由3：世界規模の攻撃

11か国以上で被害が確認されており、ファイル名も多言語に対応しているため、**日本語版が登場する可能性**も十分あります。今後日本でも注意が必要です。

## 対策・今後の展望

### ✅ 今すぐできる対策

1. **WhatsAppで届いた添付ファイルは、知り合いからでも安易に開かない**
   → 「本当にあなたが送ったの？」とメッセージやLINEなど別の手段で確認するのがベストです

2. **「.vbs」「.exe」「.bat」「.js」などの拡張子のファイルは絶対に開かない**
   → これらは「実行ファイル」と呼ばれ、開くだけでプログラムが動いてしまいます。書類なら「.pdf」「.docx」のはずです。

   > ⚠️ 覚えておこう！危険な拡張子：`VBS / VBE / EXE / BAT / CMD / JS / PS1`

3. **WhatsAppアカウントの二段階認証をオンにする**
   → アカウントを乗っ取られにくくなります

4. **セキュリティソフトを最新の状態に保つ**

5. **Windowsのファイル拡張子を表示する設定にしておく**
   → デフォルトでは拡張子が非表示のため、「財務レポート.vbs」が「財務レポート」に見えてしまいます

### 🔮 今後の展望

攻撃者グループはまだ特定されていませんが、カスペルスキーは過去に「**Gh0st RAT**（有名なハッキングツール）」や「**ValleyRAT**（別のマルウェア）」と関連するインフラとの重複を発見しています。経験豊富な攻撃者集団によるものと見られており、今後も手口の進化が予想されます。

## 用語解説

| 用語 | 説明 |
|---|---|
| **VBScript（VBS）** | Windowsで動く簡易プログラム。ファイルを開くだけで命令が実行される |
| **RMM（リモートモニタリング＆マネジメント）** | 遠隔でパソコンを操作・管理するための正規ソフト |
| **ManageEngine RMM Central** | インドのゾーホー社が開発した正規の遠隔管理ツール |
| **UAC（ユーザーアカウント制御）** | Windowsの安全機能。勝手なソフトのインストールを防ぐ |
| **WScript.exe** | WindowsでVBScriptを実行するためのプログラム |
| **難読化（obfuscation）** | プログラムの中身を読みにくくして、セキュリティソフトや人間に解析されにくくする手法 |
| **Gh0st RAT** | 中国発とされる有名な遠隔操作型マルウェア |
| **ValleyRAT** | 別の遠隔操作型マルウェア。主に標的型攻撃で使われる |
| **多段階感染チェーン** | 一つのファイルが次々と別のファイルをダウンロード・実行し、段階的に攻撃を進める仕組み |
| **カスペルスキー** | ロシア発の大手セキュリティ企業。今回の攻撃を発見・報告した |
