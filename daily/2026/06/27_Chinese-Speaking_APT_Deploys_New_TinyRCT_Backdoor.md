# 中国語話者のハッカー集団が新型バックドア「TinyRCT」を使って東南アジアを攻撃

**元記事**: [Chinese-Speaking APT Deploys New TinyRCT Backdoor in Southeast Asia Campaign](https://inl03.netline.com/ltr6/?_m=3n.009a.4015.sp0ao46r89.32i2)
**解説日**: 2025年7月1日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を押さえておきましょう。

### 🏛️ APT（Advanced Persistent Threat）とは？
「高度で継続的な脅威」という意味です。普通のハッカーとは違い、**国家や組織の支援を受けたプロの攻撃者集団**のことを指します。短期間で終わらず、長期間にわたってターゲットに潜伏し続けるのが特徴です。スパイ映画に出てくるような「プロの諜報員チーム」をイメージするとわかりやすいでしょう。

### 🚪 バックドアとは？
本来の入口（フロントドア）ではなく、**裏口からこっそりシステムに侵入・操作できるようにする仕組み**です。一度仕掛けられると、攻撃者はいつでも好きなタイミングで侵入できます。

### 🏗️ 重要インフラとは？
電力・水道・ガス・政府機関・通信網など、**社会が機能するために欠かせない基盤**のことです。ここが攻撃されると、国民生活に直接影響が出ます。

### 🕵️ C2サーバー（Command and Control）とは？
攻撃者が感染させたコンピューターに**命令を送ったり、盗んだデータを受け取ったりするための「司令塔」サーバー**です。感染した端末はC2サーバーに定期的に「次の指示は？」と問い合わせます。

---

## 何が起きたのか

中国語を使うハッカー集団（**CL-STA-1062**と呼ばれる）が、**東南アジアの政府機関や重要インフラ**に対してサイバー攻撃を行っていることが、セキュリティ企業「Palo Alto Networks Unit 42」の調査で明らかになりました。

### 📅 時系列まとめ

| 時期 | 出来事 |
|------|--------|
| 2022年3月〜 | 東アジアの重要機関を狙った攻撃が開始 |
| 2025年半ば〜 | 東南アジアの重要インフラへの攻撃が本格化 |
| 2025年8月 | 関連グループ「UAT-7237」が台湾への攻撃で初めて特定される |
| 2025年9月 | 東南アジアの政府機関への侵入・データ窃取が確認される |
| 2025年10〜12月 | 東南アジアの少なくとも10組織への侵害が確認される |

### 🎯 攻撃のターゲット
- 東南アジアの**政府機関**（国営企業を含む）
- **エネルギー分野**の重要インフラ
- **ウェブインフラ**（台湾でも確認）

## 技術的な詳細

### 🔧 攻撃者のツールキット（武器庫）

攻撃者は「既製品のツール」と「オリジナルのツール」を組み合わせる**ハイブリッド戦術**を使っています。

```
【既製品ツール（誰でも入手可能）】
├── SoftEther VPN  → 通信を隠すVPNソフト
├── Mimikatz       → パスワードを盗み出すツール
├── Yuze           → 通信を中継するプロキシツール
└── VNT            → もう一つのVPNツール

【オリジナルツール（今回新発見）】
└── TinyRCT        → 新型バックドア（主役）
```

これらの一部は**「VMware」や「XDRエージェント」などの正規ソフトに偽装**されています（例：`XDRAgent.exe`、`vmtools.exe`）。セキュリティ担当者が見ても気づきにくくする工夫です。

---

### 🦠 TinyRCT の仕組み

今回の主役、新型バックドア「TinyRCT」の動作を図解します。

#### 📦 Step 1：感染の入り口
```
「chrome_setup.zip」という偽のファイルを開くと...
│
├── chrome_setup.exe        ← 本物に見えるファイル（囮）
├── chrome_setup.exe.config ← 設定ファイル
└── MyAppDomainManager.dll  ← 悪意のあるDLL（本当の危険）
         ↓
   「AppDomainManager インジェクション攻撃」が発動！
   （正規プログラムに悪意のプログラムを注入する技術）
         ↓
   外部サーバー（139.180.134[.]221）に接続
         ↓
   PerfWatson2.exe（TinyRCT本体）をダウンロード
```

> 💡 **例え話**：まるで普通のお菓子の箱に見せかけて、中に仕掛けを隠したプレゼントを渡すようなイメージです。箱を開けた瞬間に仕掛けが動き出します。

#### 📡 Step 2：C2サーバーとの通信
```
感染したPC ←──── 10秒ごとに「命令ある？」と問い合わせ ────→ C2サーバー
              GET リクエスト（命令を受け取る）               (45.32.113[.]172)
              POST リクエスト（盗んだデータを送る）

※ 通信内容はAES-128暗号化（CBC方式）で隠蔽
```

> 💡 **例え話**：スパイが10秒おきに「司令部」に無線連絡を入れて「次の指示は？」と確認し、指示があれば実行するイメージです。通信は暗号化されているので盗み聞きされても内容がわかりません。

#### 🛠️ Step 3：TinyRCTにできること

| 機能 | 具体的な内容 |
|------|-------------|
| 任意のコマンド実行 | PCを自由に操作できる |
| ファイルの検索・盗み出し | 重要書類や設定ファイルを外部に送信 |
| スクリーンショット取得 | 画面に表示されている内容を撮影 |
| 自己削除 | 証拠を消して存在を隠す |
| サンドボックス回避 | セキュリティ検査環境では動かないようにする |

### 🔍 実際の攻撃の流れ（2025年9月の事例）

```
① 政府機関のウェブサーバーに脆弱性（セキュリティの穴）を発見
         ↓
② ASPXウェブシェル（遠隔操作用の裏口）を設置
         ↓
③ SQLサーバーからデータを盗み出す
         ↓
④ 同じ国の別の政府機関のネットワークも偵察
         ↓
⑤ ウェブサーバーのソースコード（設計図）を丸ごと持ち出す
```

> ⚠️ **ポイント**：一つの組織を攻撃するだけでなく、そこを足がかりに**隣の組織にも侵入しようとする「横移動」**を行っているのが特徴的です。

## なぜ重要なのか

### 🌏 東南アジア・東アジア全体への脅威
2022年から少なくとも3年以上にわたって攻撃が続いており、**日本を含む東アジア地域も無関係ではありません**。エネルギーや政府機関が狙われているということは、社会インフラ全体が危険にさらされる可能性があります。

### 🆕 新型ツールの発見
「TinyRCT」はこれまで**まったく記録されていなかった新しいマルウェア**です。既存のウイルス対策ソフトでは検知できない可能性があり、発見が遅れるほど被害が拡大します。

### 📊 被害の規模
- 2025年10〜12月だけで**東南アジアの10以上の組織**への侵害が確認されています
- ウェブサーバーの**ソースコード（システムの設計図）**まで盗まれており、今後さらなる攻撃に悪用される恐れがあります

### 🤔 「なりすまし」の巧妙さ
- 正規のソフト名（`vmtools.exe`、`chrome_setup.zip`）に偽装
- 一般的なツール（SoftEther VPN）と混ぜて使うことで、**正規の業務か攻撃かの区別を難しくしている**

## 対策・今後の展望

### 🛡️ 組織・企業ができる対策

1. **ウェブシェルの監視強化**
   - ウェブサーバーに不審なファイルが置かれていないか定期チェック

2. **脆弱性への素早い対応**
   - OSやソフトウェアのアップデートを怠らない（攻撃の入り口となる「穴」を塞ぐ）

3. **不審な通信の検知**
   - 10秒ごとに外部サーバーと通信するような不審な動きを監視

4. **ゼロトラスト原則の導入**
   - 「社内にいても信頼しない」という考え方で、横移動（lateral movement）を防ぐ

5. **DLLファイルの取り扱い強化**
   - 不審なアーカイブ（zip）ファイルを不用意に開かない

### 🔮 今後の動向
- このグループは**長期的・継続的な攻撃**を行っており、手口は今後さらに洗練される可能性があります
- 台湾・東南アジアだけでなく、**日本を含む東アジア全域への攻撃拡大**も警戒が必要です
- Unit 42をはじめとするセキュリティ企業が継続的に監視・追跡しています

## 過去記事との関連

以前、**「SharkLoader」という新型マルウェアが「Cobalt Strike」という攻撃ツールを展開するサイバー攻撃（StrikeShark）**について解説しました。

今回の「TinyRCT」と共通するトレンドが見えてきます：

| 共通点 | SharkLoader | TinyRCT |
|--------|-------------|---------|
| 目的 | 別のマルウェアを呼び込む踏み台 | ダウンローダーとしても機能 |
| 手口 | 正規ツールを悪用・偽装 | VMware等の正規名に偽装 |
| 傾向 | 新型・未検知のカスタムツール | 新型・未記録のバックドア |

**「既製品のハッキングツール」と「新型のオリジナルツール」を組み合わせる手口は、現代の高度なAPT攻撃の共通パターン**になっています。どちらの事例も、単純なウイルス対策だけでは防げない高度な攻撃であることを示しています。

## 用語解説

| 用語 | 説明 |
|------|------|
| **APT（高度持続的脅威）** | 国家支援を受けたプロのハッカー集団。長期間・高度な攻撃を行う |
| **バックドア** | システムへの裏口。一度仕掛けると攻撃者がいつでも侵入可能 |
| **C2サーバー** | ハッカーが感染端末に命令を出す「司令塔」サーバー |
| **ウェブシェル** | ウェブサーバーに仕込まれる遠隔操作ツール |
| **DLLインジェクション** | 正規プログラムに悪意のコードを注入する攻撃技術 |
| **横移動（Lateral Movement）** | 侵入後、同じネットワーク内の別の端末へ侵害を広げること |
| **サンドボックス** | マルウェアを安全に動かして分析するための隔離環境 |
| **AES-128暗号化** | 強力な暗号化方式の一つ。通信内容を第三者に読めなくする |
| **SOCKS5プロキシ** | 通信の中継役。攻撃元を隠すために使われる |
| **脆弱性** | ソフトウェアのセキュリティ上の「穴」。攻撃の入り口になる |
| **Mimikatz** | Windowsのパスワードを盗み出す有名なハッキングツール |
| **SoftEther VPN** | 日本発の正規VPNソフト。攻撃者に悪用されることがある |
| **ビーコニング** | マルウェアが定期的にC2サーバーに「生存確認」の通信を送る動作 |

---

> 📝 **まとめ**：今回の攻撃は、長期間・広範囲にわたる国家レベルのサイバースパイ活動です。新型ツール「TinyRCT」の発見は、攻撃者が常に手口を進化させていることを示しています。東南アジアだけの問題ではなく、日本を含む東アジア全体のセキュリティに関わる重要なニュースです。
