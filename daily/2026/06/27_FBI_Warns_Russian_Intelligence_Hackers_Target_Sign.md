# FBIが警告：ロシアのハッカーがSignalの「バックアップ回復キー」を狙っている

**元記事**: [FBI Warns Russian Intelligence Hackers Target Signal Backup Recovery Keys](https://inl03.netline.com/ltr6/?_m=3n.009a.4015.sp0ao46r89.32hk)
**解説日**: 2025年6月27日

---

## 背景知識

まず、この記事を理解するために必要な基礎知識を説明します。

### Signalってどんなアプリ？

**Signal（シグナル）** は、スマートフォン向けの無料メッセージアプリです。LINEやWhatsAppと似ていますが、特に「セキュリティの高さ」で知られています。政府関係者、ジャーナリスト、活動家など、「絶対にメッセージを盗み見られたくない人」に広く使われています。

Signalの最大の特徴は **「エンドツーエンド暗号化（E2EE）」** です。

> 🔐 **エンドツーエンド暗号化とは？**
> 送った人と受け取った人だけがメッセージを読める仕組みです。
> 郵便物を「特殊な鍵がないと開けられない金庫」に入れて送るようなイメージです。
> Signalの会社自身も、あなたのメッセージの中身を見ることができません。

### バックアップ回復キーとは？

Signalには、スマホを機種変更したときなどに **過去のメッセージ履歴を新しい端末に引き継ぐ** 機能があります。このときに必要になるのが「**バックアップ回復キー（Backup Recovery Key）**」です。

> 🗝️ **わかりやすい例え**
> バックアップ回復キーは「マスターキー（合鍵の親玉）」のようなものです。
> この鍵があれば、過去のすべてのメッセージが入った「金庫」を開けることができます。
> 逆に言えば、この鍵を他人に渡してしまったら、その人が金庫の中身を全部見られます。

### ソーシャルエンジニアリングとは？

技術的にシステムをハッキングするのではなく、**人をだましてパスワードや鍵を「自分から教えさせる」** 攻撃手法です。

> 📞 **例え**
> 銀行員のふりをして電話し、「セキュリティ確認のため暗証番号を教えてください」と言う詐欺と同じ発想です。

### FBI・CISAとは？

- **FBI（連邦捜査局）**：アメリカの犯罪捜査機関（日本のNHKドラマにもよく出てくる組織）
- **CISA（サイバーセキュリティ・インフラセキュリティ庁）**：アメリカのサイバーセキュリティ専門政府機関

## 何が起きたのか

FBIとCISAが共同で、**ロシアの情報機関（スパイ組織）によるSignal攻撃の新手口** について警告を発表しました。

この攻撃の流れを簡単にまとめると：

```
①「Signal サポートです」という偽メッセージを送る
　　　　↓
② ターゲットに「バックアップ設定を有効にしてください」と誘導する
　　　　↓
③ 「回復キーを画面に表示して、ここに貼り付けてください」と指示する
　　　　↓
④ 鍵をゲット！→ 過去のメッセージを全部読める＆アカウントを乗っ取れる
```

実は、FBIは**2025年3月にも似たような警告**を出していました。今回は攻撃がさらに巧妙になった「アップデート版」の警告です。

### 誰がターゲットになっているの？

- アメリカや各国の政府関係者（現役・元職員）
- 軍の関係者
- 政治家
- ジャーナリスト（記者）
- ウクライナの関係者

つまり、**国家レベルで機密情報を持っている人たち** が主な標的です。

## 技術的な詳細

### 攻撃の仕組みをもっと詳しく

#### フィッシングメッセージの手口

攻撃者は、Signalアプリの中で **「Signal公式サポート」を装ったメッセージ** を送ってきます。記事によると、次のような2種類の口実が使われています：

| 口実 | 内容 |
|------|------|
| **①二段階認証の強制アップデート** | 「セキュリティ強化のため、必須の設定変更をお願いします」 |
| **②緊急のデータ復旧** | 「あなたのメッセージが消える危険があります！今すぐ回復キーを確認してください」 |

どちらも「緊急性」や「公式っぽさ」を演出して、冷静な判断を奪うのが狙いです。

#### 回復キーを奪われるとどうなるの？

```
⚠️ 奪われた回復キーで攻撃者にできること

✅ 過去のすべてのプライベートメッセージを読む
✅ グループチャットの履歴を読む
✅ アカウントのバックアップをダウンロードする
✅ 同じ電話番号で新しいアカウントを作っても、古いキーでアクセス可能（！）
```

特に怖いのは最後の点です。「やばい！アカウント作り直そう」と思って同じ電話番号で新規登録しても、**古い回復キーがまだ有効で使われ続ける** 可能性があります。

#### でも、Signalの暗号化は破られていない

記事は重要なことを強調しています：

> **「Signalの暗号化自体は突破されていない」**

攻撃者は技術的にSignalをハックしたわけではありません。**人をだまして「正規の機能」を使わせた** だけです。

> 🏠 **例え話**
> 家の鍵（暗号化）はびくともしない頑丈なものです。
> でも攻撃者は「鍵を貸してください」と頼んで、自分で渡してもらいました。
> 家のドアは破られていないけど、中には入られています。

### 攻撃グループについて

今回の警告で、攻撃グループに公式な追跡名が付けられました：

- **UNC5792**（ユーエヌシー5792）
- **UNC4221**（ユーエヌシー4221）

これらはロシアの情報機関（**FSB**＝ロシア連邦保安庁、**GRU**＝軍参謀本部情報総局）に関連していると見られています。

> 💡 アメリカ国務省は、UNC5792の情報提供者に最大**1,000万ドル（約15億円）** の懸賞金を出すと発表しています。

## なぜ重要なのか

### ① 世界中で数千アカウントがすでに被害に

3月の警告時点で、すでに**世界中で数千ものアカウントが侵害されている**と報告されています。

### ② 手口がどんどん巧妙になっている

3月の時点では「SMS認証コード」や「PINコード」を盗む手口でした。今回は「回復キー」というより強力な情報を盗む手口に進化しています。攻撃は止まっておらず、**アップグレードされ続けています**。

### ③ 一般ユーザーへの教訓

今回の主なターゲットは政府関係者などですが、**この詐欺の手口は誰にでも応用できます**。

- 「公式サポートのふりをしてキーを聞き出す」という手法は、LINEや他のアプリでも同様の詐欺が考えられます
- 「緊急です！今すぐ対応を！」という焦らせ方は、フィッシング詐欺の典型的な手口です

### ④ 国際的な懸念

オランダ・ドイツ・フランスのインテリジェンス機関も同様の警告を出しており、**ヨーロッパ全体でも問題視されています**。

## 対策・今後の展望

### 今すぐできる対策（Signalユーザー向け）

#### 🚨 絶対にやってはいけないこと

- アプリ内で「Signal サポート」を名乗る相手に、コードや回復キーを送る
- 「緊急」「必須」と言われて焦って操作する
- チャットに回復キー・認証コード・PINを貼り付ける

> ⚠️ **重要**: 本物のSignalサポートは、**アプリ内メッセージでキーやコードを聞いてきません！**

#### ✅ やるべきこと

| 対策 | 方法 |
|------|------|
| **連携デバイスを確認する** | Settings（設定）→ Linked Devices（連携デバイス）を開き、見覚えのない端末があれば即削除 |
| **回復キーを再生成する** | Settings → Backups → 新しい回復キーを生成（古いキーが無効化される） |
| **もし渡してしまったら** | すぐに新しい回復キーを生成し、「バックアップは相手に見られた」と考えて行動する |

### 覚えておきたい基本ルール

```
🛡️ セキュリティの鉄則

「公式サポート」を名乗る人物からの
コード・パスワード・キーの要求は、
100%詐欺です。
```

### 今後の展望

記事の最後はこう締めくくられています：

> 「暗号化は守られている。アカウントが弱点であり、それを持っている人間がターゲットだ」

技術がいくら発達しても、**人間をだます手口（ソーシャルエンジニアリング）は永遠になくなりません**。今後も「新しい機能を悪用した詐欺」は形を変えて登場し続けると考えられます。

## 過去記事との関連

今回の記事は、**2025年3月にFBI・CISAが出した最初の警告の続報・アップデート**です。

3月の警告では：
- SMS認証コードを盗む手口
- 偽のグループ招待リンクで端末を連携させる手口

が報告されていました。

今回はそれに加えて「**バックアップ回復キーを盗む**」という、より危険な手口が追加されたことが明らかになりました。攻撃者は一段階上の情報を狙うようにレベルアップしており、**手口は継続的に進化している**ことがわかります。

また、Googleの脅威インテリジェンスグループ（TAG）が2025年初頭にUNC5792によるSignalの「連携デバイス機能」悪用を最初に記録しており、Signal以外にもWhatsAppやTelegramでも同様の手口が確認されています。

## 用語解説

| 用語 | 意味 |
|------|------|
| **Signal** | 高いセキュリティで知られる無料メッセージアプリ |
| **エンドツーエンド暗号化（E2EE）** | 送受信者だけがメッセージを読める暗号化技術。第三者（通信会社やアプリ会社）も読めない |
| **バックアップ回復キー** | Signalのメッセージ履歴を別の端末に移すときに必要な「マスターキー」。盗まれると全履歴が読まれる |
| **フィッシング** | 公式機関や信頼できる人物を装ってパスワード等を騙し取る詐欺手法 |
| **ソーシャルエンジニアリング** | 技術的なハッキングではなく、人をだますことで情報を入手する攻撃手法 |
| **FBI** | アメリカ連邦捜査局。犯罪捜査を担当 |
| **CISA** | アメリカのサイバーセキュリティ専門政府機関 |
| **FSB** | ロシア連邦保安庁（旧KGB）。ロシアの情報・諜報機関 |
| **UNC5792 / UNC4221** | 今回の攻撃グループの追跡コード名。ロシアの情報機関に関連 |
| **連携デバイス（Linked Devices）** | Signalを複数の端末で使うための機能。悪用されると攻撃者の端末が追加される |
| **二段階認証（2FA）** | パスワードに加えて、SMSコードなど別の確認手段を使うセキュリティ設定 |
| **Rewards for Justice** | アメリカ国務省が運営する、テロ・国家安全保障に関わる情報提供者への懸賞金プログラム |

---

> 💬 **まとめ**
> 今回の攻撃は「Signalが壊れた」わけではありません。
> **「人をだます」という最も古典的な手口**で、最も大切なカギを盗む作戦です。
> どんなに安全なアプリでも、使う人がだまされたら意味がありません。
> 「緊急！今すぐキーを教えて！」という要求は、**どんな状況でも詐欺**と思って大丈夫です。
