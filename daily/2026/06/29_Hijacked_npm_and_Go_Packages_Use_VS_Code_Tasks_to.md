# ハイジャックされたnpm・Goパッケージが「VS Codeのタスク機能」を悪用してPython製情報窃取マルウェアを配布

**元記事**: [Hijacked npm and Go Packages Use VS Code Tasks to Deploy Python Infostealer](https://inl03.netline.com/ltr6/?_m=3n.009a.4016.sp0ao46r89.32jy)
**解説日**: 2026年6月30日

---

## 背景知識

まず、この記事を理解するためのキーワードを整理しましょう。

### 📦 npmとGoパッケージって何？

プログラマーは「ゼロからすべてのコードを書く」のではなく、他の人が作った便利な「部品（パッケージ）」を組み合わせてアプリを作ります。

- **npm（エヌピーエム）**: JavaScriptというプログラミング言語の「部品置き場」のようなサービスです。世界中の開発者が部品を公開・共有しています。例えば「画像を圧縮する機能」「日付を計算する機能」などが無料で手に入ります。
- **Goパッケージ**: 同じように、Go（ゴー）というプログラミング言語の部品置き場です。

**「ハイジャック」とは？**  
本来は飛行機の乗っ取りを意味しますが、ITの世界では「正規のパッケージ名を乗っ取る」ことを指します。信頼できる名前のパッケージのふりをして、中に悪意のあるコードを仕込むのです。

---

### 🖥️ VS Code（ビジュアル スタジオ コード）って何？

Microsoftが作った、世界で最も人気のある「コードエディター（プログラムを書くためのツール）」です。メモ帳の超高機能版と思ってください。世界中のプログラマーの多くが毎日使っています。

**「タスク機能」とは？**  
VS Codeには「プロジェクトフォルダを開いたときに自動で特定の処理を実行する」機能があります。例えば「フォルダを開いたら自動でサーバーを起動する」といった使い方ができます。今回はこの機能が悪用されました。

---

### 🐍 インフォスティーラー（情報窃取マルウェア）って何？

「インフォ（Info）= 情報」＋「スティーラー（Stealer）= 盗む人」で、**あなたのパソコンに保存された情報をこっそり盗むウイルス**のことです。パスワード、クレジットカード情報、暗号通貨（ビットコインなど）の財布の情報などが標的になります。

---

## 何が起きたのか

セキュリティ会社の**JFrog（ジェイフロッグ）**が、危険なパッケージを発見しました。

### 発見されたパッケージ
- `html-to-gutenberg`（HTMLをWordPressのブロック形式に変換するツールを装ったもの）
- `fetch-page-assets`（Webページの素材を取得するツールを装ったもの）

これらは**2026年5月25日にnpmに登録**されており、現在はすでに削除されています。

### 攻撃の流れを簡単に言うと…

> 1. 開発者が「便利そうなパッケージだな」と思ってインストールする
> 2. そのパッケージが含むフォルダをVS Codeで開く
> 3. **自動的に**悪意のあるコードが実行される
> 4. パソコン内の情報がすべて盗まれる

まるで、「おいしそうなお菓子の箱」を家に持ち込んで開けたとたん、部屋中に罠が仕掛けられるようなイメージです。

## 技術的な詳細

### ステップ①：隠れたVS Codeタスクが起動のきっかけ

パッケージの中には `.vscode/tasks.json` というファイルが隠されています。これは「**フォルダを開いたら自動で実行してね**」という命令書です。タスク名は `eslint-check`（コードの品質チェックツールの名前）という、いかにも無害そうな名前で偽装されています。

```
普通の開発者がよく使う名前 → 怪しまれにくい
フォルダを開くだけで起動 → クリックすら不要
```

### ステップ②：マルウェアをフォントファイルに偽装

実行されるファイルは `public/fonts/fa-solid-400.woff2` という**フォントファイル（文字のデザインデータ）に見せかけています**が、実際の中身はJavaScript（プログラム）です。

🎭 例えるなら「図書館の本に見せかけて、中身がまったく違う危険な内容」のようなものです。

### ステップ③：ブロックチェーンを「命令サーバーの隠れ家」として使用

通常、マルウェアは「命令を受け取るサーバー（C2サーバー）」に接続します。しかしそのサーバーは当局に見つかって閉鎖される危険があります。

そこでこのマルウェアは**ブロックチェーン（仮想通貨の技術）**を利用しています。

> ブロックチェーンのトランザクション（取引記録）の中に、暗号化した「次の命令」を埋め込む

ブロックチェーンの記録は**削除できない**ため、当局が取り締まっても命令が消えません。バックアップとして**TronGrid**と**Aptos**という2つのブロックチェーンサービスが使われています。

### ステップ④：Socket.ioバックドアで遠隔操作

**Socket.io（ソケット・アイオー）**というリアルタイム通信の仕組みを使って、攻撃者がパソコンを**遠隔操作できる裏口（バックドア）**を設置します。

攻撃者ができること：
- 🖥️ コマンドの実行（パソコンを操作する）
- 📋 クリップボードの中身の盗み見（コピーしたパスワードなど）
- 📁 ファイルのアップロード・操作
- ⚙️ プロセス（動いているプログラム）の管理

### ステップ⑤：Pythonインフォスティーラーが情報を根こそぎ盗む

最終的に展開されるPython製マルウェアが盗む情報の一覧：

| カテゴリ | 具体的なターゲット |
|---|---|
| ブラウザ | ChromeやFirefoxのパスワード・Cookie |
| 暗号通貨 | 仮想通貨ウォレット（財布） |
| 開発者情報 | GitHubのログイン情報、VS Codeの設定 |
| システム | Windowsパスワード管理、macOSキーチェーン |
| クラウド | Dropbox、Google Drive、OneDriveなどのメタデータ |

## なぜ重要なのか

### 🎯 ターゲットはプログラマー（開発者）

このマルウェアは一般ユーザーではなく、**ソフトウェアを作る開発者を狙っています**。なぜなら：

1. **開発者は信頼できるパッケージと思って何でもインストールしがち**
2. **開発者のパソコンには企業のソースコード・APIキー・顧客データへのアクセス権限がある**
3. 開発者のパソコンが乗っ取られると、**そこから企業の内部システム全体に侵入できる**

つまり、開発者1人を騙すことで、その人が関わる**会社全体を攻撃できる**のです。

### 🇰🇵 北朝鮮との関連

記事では、この手口（VS Codeタスクの悪用＋フォントファイルへの偽装）が**北朝鮮のハッカーグループ**のものと酷似していると指摘しています。

これは「**Contagious Interview（コンタジャス・インタビュー）**」と呼ばれる、**2023年から続く北朝鮮の長期作戦**の一部とみられます。この作戦では、「採用面接」を装って開発者を騙し、マルウェアをインストールさせます。

## 対策・今後の展望

### 開発者の方へ

1. **知らないパッケージを安易にインストールしない**
   - 公開日が最近・ダウンロード数が少ない・作者不明のパッケージは要注意

2. **VS Codeのタスク自動実行に注意**
   - 「このワークスペースのタスクを信頼しますか？」というポップアップが出たら**内容をよく確認する**

3. **パッケージのソースコードを確認する習慣を**
   - `.vscode/tasks.json` ファイルが含まれていたら中身をチェック

4. **npm auditコマンドを使う**
   - `npm audit` というコマンドで既知の危険なパッケージを検出できます

### 一般の方へ

直接の影響は少ないですが、**あなたが使っているWebサービスやアプリを作った開発者が被害に遭う**ことで、間接的にあなたの情報が危険にさらされる可能性があります。

## 用語解説

| 用語 | 意味 |
|---|---|
| **npm** | JavaScriptのプログラム部品（パッケージ）を管理・配布するサービス |
| **Goパッケージ** | Go言語のプログラム部品 |
| **パッケージのハイジャック** | 正規のパッケージ名を乗っ取り、悪意のあるコードを仕込むこと |
| **VS Code（Visual Studio Code）** | Microsoftが作った人気のプログラム編集ツール |
| **タスク（VS Code Tasks）** | VS Codeでフォルダを開いたときに自動実行できる処理 |

| **C2サーバー** | マルウェアに命令を送る攻撃者のサーバー（Command & Control） |

| **Contagious Interview** | 北朝鮮系ハッカーによる「偽の就職面接」を使った長期攻撃作戦 |
| **InvisibleFerret** | 本攻撃作戦で使われるPython製バックドアの名前 |
| **dead drop resolver** | スパイ活動の「秘密の受け渡し場所」をブロックチェーンで代替する技術 |
