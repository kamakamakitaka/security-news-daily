# Microsoftが悪意ある拡張機能119個を削除！画像やフォントにマルウェアを隠す巧妙な手口

**元記事**: [Microsoft Removes 119 Edge Extensions That Hid Malware in Images and Fonts](https://inl03.netline.com/ltr6/?_m=3n.009a.4016.sp0ao46r89.32jm)
**解説日**: 2025年7月2日

---

## 背景知識

このニュースを理解するために、いくつかの基本的な概念を説明します。

### ブラウザ拡張機能（エクステンション）とは？
Google ChromeやMicrosoft Edgeなどのウェブブラウザに後から追加できる「プラグイン」のことです。「広告をブロックする」「翻訳する」「動画をダウンロードする」など、ブラウザの機能を拡張してくれる便利なツールです。スマホのアプリと同じように、公式ストアからインストールできます。

### マルウェアとは？
「悪意のあるソフトウェア（Malicious Software）」の略で、パソコンやスマホに害を与えるプログラムの総称です。ウイルスもその一種です。

### ステガノグラフィーとは？
「情報を別のものの中に隠す技術」です。歴史的には、文字を画像に隠して秘密の手紙を送ることが行われていました。今回の事件では、**見た目は普通の画像やフォントファイルの中に、悪意あるプログラムを隠す**ために使われました。
> 🔑 **例え話**: 普通の料理レシピの文章の中に、文字の頭文字だけを拾うと別のメッセージが読める暗号文を隠すのと同じ発想です。

---

## 何が起きたのか

Microsoftは、自社のブラウザ「Microsoft Edge」の拡張機能ストアから、**119個の悪意ある拡張機能を一斉に削除**しました。

### 事件の概要

| 項目 | 内容 |
|------|------|
| 削除された拡張機能数 | **119個** |
| 影響を受けた可能性のあるユーザー数 | 最大 **260万人** |
| 活動期間 | **少なくとも2021年から** |
| 背後にいる犯罪者 | 1つの組織（脅威アクター） |

### どんな拡張機能に偽装していたか？

悪意ある拡張機能は、誰もが疑わずにインストールするような**便利なツールに偽装**していました：

- 🚫 広告ブロッカー
- 🔒 VPN（通信を暗号化するツール）
- 🌐 翻訳ツール
- 📥 動画ダウンローダー

しかも、これらは**実際に機能していた**うえにユーザーレビューも獲得していたため、見分けることが非常に困難でした。

---

## 技術的な詳細

### 仕組みをわかりやすく説明します

この攻撃が「StegoAd（ステゴアド）」と名付けられた理由は、**ステガノグラフィー**（隠し技術）と**アドウェア**（広告詐欺ソフト）を組み合わせたものだからです。

#### ステップ1：インストール直後はおとなしくしている

拡張機能をインストールしてすぐには、悪さをしません。**数日間は"眠った状態"**を保ちます。これは、セキュリティ研究者に発見されないようにするためです。

```
インストール → 数日間はおとなしく動作 → 「安全チェック」をパス → 悪意ある動作を開始
```

さらに、ブラウザの開発者ツール（DevTools）が開かれているのを検知すると、再び「眠り状態」に戻るという巧妙な仕掛けも持っていました。

#### ステップ2：画像やフォントにコードを隠す

> 🎨 **例え話で説明**
> 
> 普通の絵画を思い浮かべてください。その絵を見ても普通の風景画に見えますが、実は絵の具の微妙な色の違いの中に、暗号化されたメッセージが隠されている——これがステガノグラフィーです。

今回の手口では：

1. **初期の手口**：PNG画像ファイルの末尾に、不正なJavaScriptコードをこっそり追加。画像は普通に表示されるので誰も気づかない
2. **進化した手口**：WebP画像やWOFF2フォントファイル（文字のデザインデータ）の中にコードを埋め込み
3. **さらに巧妙な手口**：悪意あるコードをローカルに持たず、**外部のサーバーから「普通の画像」を取得**し、その中から解読してプログラムを実行

#### ステップ3：発覚を避けるための「盾」

外部サーバー（C2サーバー＝指令を出すサーバー）は、研究者のアクセスを見抜いて**空のデータを返す**ようになっていました。まるで「見張り番がいる秘密基地」のようなものです。

---

### 実際に何をしていたか？

この拡張機能は**2段階の悪事**を働いていました：

#### 表に見える被害（広告詐欺）
- 勝手に広告を表示させる
- Amazon・eBay・AliExpressでの購入時に、犯罪者のアフィリエイトリンクにすり替えて報酬を横取り
- 検索結果を書き換える

#### 隠れた深刻な被害（情報窃取）
- 🔓 **Googleアカウントのパスワードと2段階認証コードを盗む**
- 📝 WordPressの管理者ログイン情報を盗む
- 🍪 Cookieを大量に盗んでセッションハイジャック（ログイン状態を乗っ取る）
- 💻 任意のプログラムをリモートで実行できるバックドア（裏口）を設置

## なぜ重要なのか

### 規模と巧妙さが過去最大級

- **260万人**が影響を受けた可能性（日本の政令指定都市1〜2都市分の人口）
- 少なくとも**4年間**も発見されずに活動を続けた
- ブラウザのセキュリティチェックをくぐり抜け続けた高度な技術

### 「信頼できる場所」が安全ではなかった

今回の問題で特に怖いのは、**公式ストアから入手した拡張機能が危険だった**という点です。多くの人が「公式ストアなら安全」と思ってインストールしますが、それが覆された事件です。

### セキュリティ業界にとっての衝撃

Microsoftは「ブラウザ拡張機能のエコシステムでこれほどの規模のステガノグラフィー利用は珍しい」と述べています。画像にコードを隠す手法は、従来のウイルス対策ソフトではほとんど検知できません。

---

## 対策・今後の展望

### 今すぐやること

#### 1. Edgeの拡張機能を確認する
ブラウザのアドレスバーに `edge://extensions` と入力し、インストール済みの拡張機能を確認しましょう。Microsoftが公開している[不正な拡張機能のIDリスト](https://inl03.netline.com/ltr6/?_m=3n.009a.4016.sp0ao46r89.32jm)と照合してください。

#### 2. 心当たりがある場合の対応手順

```
① 該当する拡張機能をすぐに削除
② Google・銀行・SNS等の重要なパスワードをすべて変更
③ 最近のログイン履歴を確認（見知らぬ場所からのログインがないか）
④ 2段階認証を設定する（SMSよりハードウェアキーが安全）
```

#### 3. 拡張機能を入れる前に心がけること

| ✅ 安全のためにすべきこと | ❌ やってはいけないこと |
|--------------------------|------------------------|
| 本当に必要なものだけ入れる | とりあえず便利そうなものを入れる |
| 開発元を調べる | レビューだけで信用する |
| 定期的に不要なものを削除する | 入れっぱなしにする |
| アクセス権限を確認する | 求める権限が多すぎても無視する |

### 今後の展望

Microsoftは今回の事件を受けて、拡張機能の審査を強化するとみられます。また、Manifest V3という新しいセキュリティ基準への移行が進んでいますが、今回の犯罪者グループはすでにそれにも対応済みだったことが判明しており、**いたちごっこが続く**ことが予想されます。

## 過去記事との関連

以前、「**ガマレドン**がクラウドサービスを悪用してウクライナへのサイバー攻撃を拡大している」というニュースを解説しました。今回の事件とは直接の関連はありませんが、**どちらも「信頼されているサービスやツールを悪用する」という共通点**があります。

- ガマレドン事件：信頼されているクラウドサービスを指令サーバーとして使った
- 今回の事件：信頼されている公式ストアの拡張機能・画像ファイル・GitHubを悪用した

攻撃者は常に「ユーザーや管理者が信頼しているもの」を踏み台にする傾向があります。「信頼できるはずのものを疑う視点」が、現代のセキュリティには欠かせません。

## 用語解説

| 用語 | 意味 |
|------|------|
| **拡張機能（エクステンション）** | ブラウザに機能を追加するプログラム |
| **ステガノグラフィー** | データを別のファイル（画像など）の中に隠す技術 |
| **マルウェア** | 悪意あるソフトウェアの総称（ウイルス等を含む） |
| **C2サーバー** | 攻撃者がマルウェアに指令を送るための「司令塔」サーバー |
| **アドフラウド（広告詐欺）** | 広告の表示やクリックを不正に操作してお金を稼ぐ行為 |
| **セッションハイジャック** | ログイン中のユーザーのセッション（接続状態）を乗っ取ること |
| **バックドア** | 攻撃者が後から侵入するために仕掛ける「裏口」 |
| **Base64** | データをテキストに変換するエンコード方式。隠蔽に悪用されることも |
| **XOR** | データを変換する演算の一種。暗号化に使われる |
| **Manifest V3** | Chromeなどの拡張機能の新しいセキュリティ仕様 |
| **DevTools** | ブラウザに内蔵された開発者向け調査ツール |
| **アフィリエイト** | 商品の紹介リンク経由で購入されると報酬が発生する仕組み |
| **2段階認証** | パスワードに加えてもう一つの確認方法を使うセキュリティ設定 |

---

> ⚠️ **まとめ**：今回の事件は「公式ストアだから安全」という思い込みを打ち砕くものでした。260万人もの人が影響を受けた可能性があり、パスワードや2段階認証コードまで盗まれる深刻な被害が起きていました。ブラウザの拡張機能は「必要最小限」に抑え、定期的に見直す習慣をつけましょう。
