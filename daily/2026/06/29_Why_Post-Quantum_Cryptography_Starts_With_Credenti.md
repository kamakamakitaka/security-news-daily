# 量子コンピュータ時代のセキュリティ対策は「パスワード管理」から始めよ

**元記事**: [Why Post-Quantum Cryptography Starts With Credentials](https://inl03.netline.com/ltr6/?_m=3n.009a.4016.sp0ao46r89.32j4)
**解説日**: 2025年7月14日

---

## 背景知識

まず、この記事を理解するための基礎知識を整理しましょう。

### 🔐 暗号化って何？
インターネットで情報を送るとき、そのまま送ると盗み見られてしまいます。そこで「暗号化」という技術を使って、データをぐちゃぐちゃに変換してから送ります。受け取った人だけが「鍵」を使って元のデータに戻せます。

### 🔑 公開鍵暗号方式とは？
今のインターネットで広く使われている暗号の仕組みです。「南京錠（公開鍵）」と「その鍵（秘密鍵）」の2つをセットで使うイメージです。

- 誰でも使える「南京錠（公開鍵）」でデータを施錠してもらう
- 本人だけが持つ「鍵（秘密鍵）」でしか開けられない

この仕組みが使われているのが **RSA** や **楕円曲線暗号（ECC）** という技術です。現在のコンピュータでは解読に何億年もかかるため、安全とされています。

### ⚛️ 量子コンピュータとは？
普通のコンピュータは「0か1か」でデータを処理しますが、量子コンピュータは「0と1を同時に」扱える特殊なコンピュータです。これにより、従来のコンピュータでは不可能なほど複雑な計算が爆速でできるようになります。

> **例え話**: 普通のコンピュータが迷路を「全部の道を1本ずつ試して」ゴールを探すなら、量子コンピュータは「全部の道を同時に試す」ようなイメージです。

### 🔑 クレデンシャルとは？
「認証情報」のこと。パスワード、APIキー（システム同士が通信するための合言葉）、サービスアカウントの鍵など、「あなたは本物だ」と証明するための情報全般を指します。

## 何が起きたのか

この記事は「緊急の事件」というよりも、**近い将来に起きる重大な危機への警告**です。

現在インターネットを守っている暗号技術（RSA・楕円曲線暗号）は、量子コンピュータが実用化されれば**簡単に解読されてしまう**ことがわかっています。

セキュリティの専門家たちが特に警戒しているのは、以下の流れです：

1. 悪意のある攻撃者が**今すぐ**暗号化された通信やデータを大量に盗み取って保存する
2. 数年〜十数年後、量子コンピュータが実用化されたら
3. 保存していたデータをまとめて解読する

これを **「今収穫して、後で解読する（Harvest Now, Decrypt Later）」攻撃**と呼びます。

## 技術的な詳細

### ⚠️ なぜ量子コンピュータで暗号が破れるのか

1994年、ピーター・ショアという数学者が「**ショアのアルゴリズム**」という計算方法を発見しました。これは量子コンピュータを使えば、RSAや楕円曲線暗号の根拠となっている「大きな数の素因数分解」を爆速で解けることを示したものです。

```
【普通のコンピュータ】
→ 2048桁の数を素因数分解するのに… 宇宙の年齢より長い時間が必要

【量子コンピュータ（ショアのアルゴリズム使用）】
→ 同じ計算が… 数時間〜数日で完了してしまう可能性
```

> ⚡ ただし！ AES-256（共通鍵暗号）やハッシュ関数（パスワードの保管などに使う技術）は量子コンピュータでも簡単には破れません。公開鍵暗号が特に危ないということです。

### 🤖 特にヤバい「非人間アイデンティティ（NHI）」

企業のシステムには、人間が使うパスワードだけでなく、**機械同士が通信するためのAPIキーやサービスアカウントの鍵**が大量に存在します。これを「非人間アイデンティティ（NHI: Non-Human Identity）」と呼びます。

これらが特に危険な理由：
- 🔄 **誰も定期的に更新しない**（担当する人間がいない）
- 📋 **どこに何があるか把握されていない**ことが多い
- ⏳ **何年も同じ鍵が使い続けられる**（長期間有効）

攻撃者にとっては「今盗んで長期保存する価値が高い」まさにターゲットです。

## なぜ重要なのか

### 🚨 「まだ15年先の話」では済まない理由

「量子コンピュータが実用化されるまで15年あるなら余裕じゃない？」と思うかもしれません。でも、実はそうではありません：

**① 移行には5〜15年かかる**
大企業が暗号方式を全面的に切り替えるには、準備・検証・移行で5〜15年かかります。今すぐ始めても2035年のギリギリになる可能性があります。

**② 「今収穫して後で解読」攻撃は今すでに始まっている可能性**
国家レベルの攻撃者（スパイ活動をする国など）はすでに暗号化データを収集・保存しているかもしれません。今日盗まれたデータは、将来解読されるリスクがあります。

**③ 企業の8〜9割は暗号の棚卸しができていない**
「うちのシステムでどんな暗号を使っているか」を完全に把握している企業はほとんどありません。移行作業の前提となる「現状把握」だけで1〜2年かかることも珍しくありません。

## 対策・今後の展望

### 📋 クレデンシャル優先の量子移行アプローチ

記事では「クレデンシャル（認証情報）から先に移行を始めよ」と提言しています。具体的なステップは：

#### ステップ1：暗号の棚卸し（インベントリ）
まず「今どこで何の暗号を使っているか」を調べます。
- パスワードマネージャー
- APIキーの管理場所
- 証明書の管理システム
- サービスアカウント の洗い出し

> **例え話**: 家の中にある鍵の種類と場所を全部リストアップするイメージです。交換する前に「何が何個あるか」を知る必要があります。

#### ステップ2：リスクの優先順位付け
すべてを一度に変えることはできないので、「長期間使われるもの」「重要な情報を守るもの」から優先して対応します。

#### ステップ3：量子耐性アルゴリズムへの移行
NISTが2024年に正式標準化した新しい量子耐性暗号（**ML-KEM、ML-DSA**など）に切り替えます。

#### ステップ4：クレデンシャルの定期ローテーション
APIキーやサービスアカウントも、人間が管理するパスワードと同様に**定期的に更新する仕組み**を作ります。

### 🌐 日本企業への影響
日本でも金融機関・政府機関・重要インフラを中心に、量子耐性暗号への移行計画の検討が求められ始めています。「まだ先の話」ではなく、今から準備を始める時期に来ています。

## 用語解説

| 用語 | 解説 |
|------|------|
| **公開鍵暗号（RSA・ECC）** | 「南京錠と鍵」のペアで暗号化・複合化する現代の主流暗号技術 |
| **量子コンピュータ** | 量子力学の原理を使い、従来と桁違いの計算能力を持つコンピュータ |
| **ショアのアルゴリズム** | 量子コンピュータで公開鍵暗号を効率的に解読できることを示した計算方法（1994年発見） |
| **Q-Day** | 量子コンピュータが現行の暗号を破れるようになる日（X-Dayのようなイメージ） |
| **Harvest Now, Decrypt Later** | 今は解読できなくても暗号化データを収集・保存し、将来解読する攻撃戦略 |
| **クレデンシャル** | パスワード・APIキー・証明書など「本人確認に使う情報」の総称 |
| **NHI（非人間アイデンティティ）** | 人間ではなくシステム・機械が使う認証情報（APIキー、サービスアカウントなど） |
| **NIST** | アメリカの国立標準技術研究所。暗号の標準規格を策定する機関 |
| **NSA** | アメリカ国家安全保障局。国家レベルのサイバーセキュリティを管轄 |
| **量子耐性暗号（PQC）** | 量子コンピュータでも解読が困難な次世代の暗号技術 |
| **AES-256** | 現在も安全とされる共通鍵暗号方式。量子コンピュータでも簡単には破れない |
| **APIキー** | アプリやシステム同士が通信するときに使う「合言葉」のような認証情報 |

> 💡 **まとめると...**
> 量子コンピュータはまだ完成していないけれど、「今のうちに暗号化データを盗んでおいて後で解読する」攻撃はすでに始まっている可能性があります。特に長期間使われるパスワードやAPIキーは格好のターゲット。企業は「暗号の棚卸し」を今すぐ始め、量子耐性のある新しい暗号への移行計画を立てる必要があります。「15年後の問題」ではなく、**今日から対策を始めなければ間に合わない問題**なのです。
