# ログイン不要でroot権限を乗っ取れる！Progress Kemp LoadMasterの深刻な脆弱性

**元記事**: [Progress Kemp LoadMaster Flaw Could Let Attackers Run Root Commands Pre-Auth](https://inl03.netline.com/ltr6/?_m=3n.009a.4017.sp0ao46r89.32l6)
**解説日**: 2026年7月1日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を押さえておきましょう。

### 🏢 ロードバランサーって何？
大企業のウェブサービスには、同時に何万人ものユーザーがアクセスしてきます。1台のサーバーだけでは処理しきれないので、**複数のサーバーにアクセスを振り分ける「交通整理役」**が必要になります。それが「ロードバランサー（負荷分散装置）」です。

図で表すとこんな感じです：

```
ユーザー → [ロードバランサー] → サーバーA
                            → サーバーB
                            → サーバーC
```

**Progress Kemp LoadMaster** はこのロードバランサーの製品名です。世界中の企業で使われています。

### 🔑 「root権限」って何？
コンピューターには「管理者（root）」というすべての操作が許可された特別なアカウントがあります。学校で例えるなら、**「校長先生の鍵」を持っているようなもの**で、どの教室も倉庫も自由に開けられる状態です。rootで命令を実行されてしまうと、攻撃者はそのコンピューターで何でもできてしまいます。

### 🚪 「認証前（Pre-Auth）攻撃」って何？
通常、システムを操作するにはIDとパスワードでログインが必要です。しかし今回の脆弱性は、**ログインする前の段階でも攻撃できてしまう**というものです。鍵がかかっていないはずの玄関から、いきなり侵入できるイメージです。

## 技術的な詳細

少し難しい話になりますが、できるだけわかりやすく説明します！

### 🔍 脆弱性の場所：`escape_quotes()` 関数

問題が見つかったのは、`escape_quotes()`（エスケープ・クォーツ）という関数の中です。

この関数の**本来の役割**は、ユーザーが入力した文字を「無害化」することです。

#### 具体的なイメージで説明すると…

コンピューターへの命令文（シェルコマンド）は、こんな形をしています：

```bash
実行する命令 '入力された値'
```

ここで悪意のあるユーザーが `'` （シングルクォート）を含む文字を入力すると：

```bash
実行する命令 '値' ; 悪意のある命令'
```

のように「`'`で命令文を途中で切って、後ろに別の命令を差し込む」攻撃（**コマンドインジェクション**）ができてしまいます。

`escape_quotes()` はこれを防ぐために、入力の中の `'` を無害化（エスケープ）する役割を担っていました。

### 🐛 バグの正体：「ヌル終端文字がない」問題

ここからが今回のバグの核心です。

コンピューターが文字列を扱うとき、文字列の「終わり」を示す特別な印（**ヌル終端文字 `\0`**）が必要です。

📦 正常な状態のメモリ（記憶領域）のイメージ：
```
[ H ][ e ][ l ][ l ][ o ][ \0 ][ ゴミデータ ][ ゴミデータ ]...
                              ↑ここで終わり！
```

⚠️ 今回のバグがある状態：
```
[ H ][ e ][ l ][ l ][ o ][ ゴミデータ ][ ゴミデータ ]...
                          ↑終わりの印がない！どこまでも読み続ける
```

このバグには**2つの問題**がありました：

1. **メモリの確保方法が間違っていた** → 中身をゼロにしない関数を使ったため、前に使ったデータのカス（ゴミデータ）が残っていた
2. **終端文字（`\0`）を書き忘れた** → どこで文字列が終わるかわからなくなった

### 💣 攻撃者はどう悪用したか

攻撃者はこの「終わりを知らない」特性を利用しました。

#### 攻撃の手順（ざっくり）：

```
攻撃者がAPIに送るデータ（JSONという形式）:
{
  "apiuser": "細工された値",
  "dummy_key1": "悪意のある命令; rm -rf /",
  "dummy_key2": "悪意のある命令; cat /etc/passwd",
  ... (大量のダミーデータ)
}
```

1. `apiuser` の値が `escape_quotes()` で処理される
2. ヌル終端文字がないので、処理後も読み込みが止まらない
3. メモリ上の隣にある「大量のダミーデータ」まで読み込んでしまう
4. そのダミーデータに「悪意のある命令」が仕込まれている
5. **root権限で実行される** 💀

しかも、攻撃対象は `/accessv2` というAPIの入り口エンドポイントで、**ログイン認証の処理を担当している部分**です。認証の前に処理されるので、**正しいIDもパスワードも不要**で攻撃が成立します。

### 🔧 修正方法（パッチの内容）

修正はたった**2行のコード変更**でした：

| 変更点 | 修正前 | 修正後 |
|--------|--------|--------|
| メモリ確保方法 | 中身が未初期化（ゴミが残る）`malloc()` | ゼロで埋める `calloc()` に変更 |
| 終端文字 | なし | `\0` を明示的に追加 |

> 「たった2行の変更が、root乗っ取りを防いでいた」——これがセキュリティの難しさを象徴しています。

## なぜ重要なのか

### ⚡ 3つの危険な要素が重なっている

| 危険要素 | 内容 |
|----------|------|
| **認証不要** | ログインなしで攻撃できる |
| **最高権限** | rootとして命令が実行される |
| **ネットワークの入り口** | ロードバランサーはインターネットに直接さらされている位置にある |

### 🌍 影響を受ける製品バージョン

| ブランチ | 危険なバージョン | 安全なバージョン |
|----------|-----------------|-----------------|
| GA（一般リリース） | v7.2.63.1 以下 | **v7.2.63.2** ✅ |
| LTSF（長期サポート） | v7.2.54.17 以下 | **v7.2.54.18** ✅ |

### 🏴‍☠️ 攻撃の実証コードが公開済み

2026年6月29日に、watchTowr Labsが**実際に動く攻撃コード（PoC）を公開**しました。これにより、高度な技術がない攻撃者でも攻撃できる可能性が高まっています。

## 対策・今後の展望

### ✅ 今すぐやるべきこと

1. **パッチを適用する**
   - GA版 → `v7.2.63.2` にアップデート
   - LTSF版 → `v7.2.54.18` にアップデート

2. **APIを外部に公開する必要があるか見直す**
   - APIをインターネットから直接アクセスできないようにする
   - VPN経由のみに限定するなどの対策を検討する

3. **カナダサイバーセキュリティセンターもアップデートを推奨**
   - 公式機関からも警告が出ているほど深刻な脆弱性です

### 🔮 今後の動向

現時点では「CVE-2026-8037を使った実際の攻撃は報告されていない」とのことです。しかし、攻撃の手順が公開されてしまった今、**時間との戦い**になっています。

## 過去記事との関連

以前、**SimpleHelp（CVE-2026-48558）の脆弱性を悪用した攻撃**についてご紹介しました。あの事例でも「サービス管理ツールへの認証前アクセス」が問題の根本でした。

今回のLoadMaster脆弱性も同様に、**「企業インフラの核となるツール」の認証前段階に潜む穴**を突くものです。

また記事でも触れられていますが、Progress社はかつて「**MOVEit**」というファイル転送ツールでも深刻な脆弱性が発覚し、Cl0pランサムウェアグループによる大規模攻撃の踏み台にされた歴史があります。さらに2024年11月には別のLoadMasterの脆弱性（CVE-2024-1212、深刻度10.0満点！）がCISAの「既知の悪用脆弱性カタログ」に掲載されました。

**「Progress社の製品には継続して注意が必要」**という認識を持っておくことが重要です。

## 用語解説

| 用語 | 解説 |
|------|------|
| **ロードバランサー** | 複数のサーバーに通信を振り分ける交通整理役の機器 |
| **root権限** | コンピューターの全操作が許可された最高管理者権限 |
| **Pre-Auth（認証前）攻撃** | ログインせずに実行できる攻撃 |
| **CVE** | 脆弱性に割り振られる世界共通の識別番号（例：CVE-2026-8037） |
| **CVSS** | 脆弱性の深刻度を0〜10で数値化したスコア。9.8は「超危険」 |
| **コマンドインジェクション** | 悪意のある命令文をシステムに無理やり実行させる攻撃 |
| **エスケープ処理** | 特殊文字を無害化して、誤動作を防ぐ処理 |
| **ヌル終端文字（`\0`）** | 文字列の「終わり」を示す特別な記号。これがないとコンピューターはどこまで読めばいいか分からなくなる |
| **バッファ（メモリ領域）** | データを一時的に保存しておくコンピューターの記憶領域 |
| **API** | プログラム同士が会話するための「窓口」。今回はここが攻撃対象になった |
| **PoC（Proof of Concept）** | 「この攻撃は本当に機能する」と証明するためのサンプルコード。公開されると攻撃者に悪用される危険が増す |
| **パッチ** | ソフトウェアの問題を修正するための更新プログラム |
| **ZDI（Zero Day Initiative）** | 脆弱性を発見した研究者とソフトウェアメーカーの間を取り持つ、脆弱性公開調整プログラム |
| **CISA** | アメリカのサイバーセキュリティ専門機関 |
| **WAF（Web Application Firewall）** | ウェブアプリを不正アクセスから守るファイアウォール |

---

> 💡 **まとめ**: ログイン不要でコンピューターの最高権限を乗っ取れるという、非常に危険な脆弱性です。攻撃の手順が公開された今、LoadMasterを使っている企業はすぐにアップデートを行うことが求められています。「たった2行のコードの書き忘れ」が大きな被害につながりうる——これがセキュリティの怖さです。
