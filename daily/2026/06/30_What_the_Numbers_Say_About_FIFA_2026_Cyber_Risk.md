# FIFA 2026ワールドカップを狙ったサイバー犯罪の実態

**元記事**: [What the Numbers Say About FIFA 2026 Cyber Risk](https://inl03.netline.com/ltr6/?_m=3n.009a.4017.sp0ao46r89.32kc)
**解説日**: 2025年6月13日

---

## 背景知識

まず、このニュースを理解するために必要な基礎知識をおさえておきましょう。

### 🏟️ FIFAワールドカップ2026とは？
2026年のFIFAワールドカップは、アメリカ・カナダ・メキシコの3カ国で開催される史上最大規模のサッカーの祭典です。6月11日に開幕しました。観客・視聴者・スポンサーが世界中に存在するため、**「お金が動く巨大なイベント」**として、サイバー犯罪者にとっても格好のターゲットになります。

### 💡 なぜ大きなイベントはサイバー攻撃のターゲットになるの？
大きなイベントでは以下のような状況が生まれます：

- 🎫 チケット・ホテル・航空券などの**大量購入**が発生する
- ⏰ 人々が**急いで購入しようとする**（焦りが判断力を下げる）
- 🏢 多くの企業・スポンサー・業者が**複雑なネットワーク**でつながる
- 🌍 世界中の人々が**慣れない外国サイト**を使う

これらの条件が重なると、詐欺師が「偽サイト」や「偽メール」で人々を騙しやすくなるのです。

## 何が起きたのか

セキュリティ企業「**チェック・ポイント・リサーチ**」と「**プルーフポイント**」が調査したところ、FIFA 2026を狙ったサイバー犯罪の準備が**開幕の数ヶ月前から**組織的に進められていたことがわかりました。

### 📊 主な発見（3つの驚くべき数字）

| 発見内容 | 数字 |
|---|---|
| FIFAパートナー企業の「なりすましメール対策が不十分」な割合 | **3社に1社** |
| 偽スポーツ賭博アプリの増加倍率 | **通常の約60倍** |
| 偽ホテル・旅行サイトのドメイン登録のピーク月(4月)のシェア | **全体の21.9%** |

攻撃は**金融・交通・ホテル・ギャンブル**の4分野をターゲットにし、**少なくとも10言語**で展開されていました。

## 技術的な詳細

それぞれの攻撃手法を、わかりやすく説明します。

### 🔍 発見①：FIFAスポンサー企業の3社に1社がなりすましメールを防げない

#### まず「DMARC」って何？

> **DMARC（ディーマーク）**とは、メールの「送信元が本物かどうか」を確認する技術的な仕組みです。

📬 郵便で例えるなら…

普通の郵便は「差出人の住所・名前」を誰でも自由に書けてしまいます。DMARCは「この住所から送られた手紙は本物と証明できる」という**封印シール**のようなものです。このシールがない会社の名前は、誰でも偽って使えてしまいます。

**調査結果**：FIFAの公式スポンサー企業の**3社に1社以上**がこのDMARCを適切に設定していないことが判明。つまり、攻撃者はスポンサー企業や物流パートナーのふりをして、本物そっくりのメールを送ることができてしまいます。

```
【攻撃の流れ】
犯罪者
  ↓
「FIFA公式スポンサー○○社」を名乗る偽メールを送信
  ↓
「お支払いの振込先が変わりました」などと偽の請求書を送る
  ↓
企業の担当者が騙されて送金してしまう
```

ワールドカップは航空会社・ホテル・放送局・グッズ業者など**巨大なサプライチェーン（物の流通網）**で成り立っており、毎日大量のビジネスメールが飛び交います。これが攻撃者にとって格好の狙い目になっています。

### 🎰 発見②：偽スポーツ賭博アプリが通常の**60倍**に急増

#### 何が起きた？

大手スポーツ賭博サービス8社を装った偽アプリが、**Google Play**に大量に出現しました。

- 🔍 大会前でない時期（基準期間）：**偽アプリ0件**
- 🔍 大会直前（2026年4〜5月）：**偽アプリ64件**（約60倍！）

さらに悪質なのが、**少なくとも5つの不正な開発者アカウント**が、複数の賭博サービスのふりをしたアプリを次々と公開していたこと。これは**組織ぐるみの計画的犯罪**です。

#### Telegramの「偽予想屋」手口も発見

> **Telegram（テレグラム）**とは、メッセージアプリの一種です。プライバシー保護が強く、犯罪者にも利用されることがあります。

ロシア語で運営される怪しいTelegramチャンネルが「試合の勝敗を予想してあげる」と称して、実際には**アフィリエイト（紹介料）詐欺**を行っていました。

```
【巧妙な詐欺の仕組み】
チャンネル登録者を2グループに分ける
  ↓
グループAには「Aチームが勝つ」と予想を送る
グループBには「Bチームが勝つ」と予想を送る
  ↓
どちらのチームが勝っても「半分の人は予想が当たる」
  ↓
「当たった！この予想屋は本物だ！」と信じた人が
紹介リンクから賭博サイトに登録・入金する
  ↓
犯罪者はその紹介料（アフィリエイト報酬）を受け取る
```

これは**コインを投げて表か裏かを当て続けているだけ**なのに、「予言の才能がある」と思わせる古典的なトリックのデジタル版です。

### 🏨 発見③：偽ホテル・旅行サイトが**キックオフ2ヶ月前**に大量登場

#### ドメインって何？

> **ドメイン**とは、ウェブサイトのアドレス（URL）の名前部分のことです。例えば「google.com」の「google」の部分です。

調査によると、FIFAワールドカップに関連した**偽の旅行・ホテルサイト**のドメイン登録が急増しました。

```
【偽ドメインの例（イメージ）】
本物: official-worldcup-hotel.com
偽物: official-worldcup-hotel-booking.top  ← ← 要注意！
     worldcup2026-hotel-deals.top
```

#### 数字で見る偽サイトの規模

- 📅 **2026年4月だけ**で全体の**21.9%**のドメインが登録された
- 🏨 偽サイトの内訳：ホテル・宿泊系 **56%**、旅行・ツアー系 **27%**
- 🌐 よく使われたドメイン末尾（TLD）：**「.top」が全体の28%**

#### 「.top」が多い理由

> **TLD（トップレベルドメイン）**とは、URLの末尾の「.com」「.jp」「.org」などの部分です。

「**.top**」というドメインが犯罪者に好まれる理由は：
- 💰 **登録費用が安い**
- 🛡️ **不正報告への対応が遅い**（偽サイトが長く生き残れる）
- 🔍 **一般人に認知されていない**（「.com」より怪しまれにくい場合がある）

さらに怖いのは、これらの偽ドメインの一部が**メール受信機能（MXレコード）**を設定していたことです。これにより：

```
【さらに巧妙な攻撃】
① 偽サイトでユーザーが「パスワードを忘れた」と入力
② 「パスワードリセットのメールを送りました」と表示
③ 実はそのメールを犯罪者が受け取り、
   本物のサービスに不正ログインする！
```

## なぜ重要なのか

### 1. 被害を受けるのは一般の人たち
チケット・ホテル・旅行を予約しようとする**普通のサッカーファン**が主なターゲットです。慌てて予約しようとする心理を突かれます。

### 2. 攻撃が「事前に計画されていた」
開幕数ヶ月前から準備されていたという事実は、これが**衝動的な犯罪ではなく、組織的な計画犯罪**であることを示しています。プロの犯罪グループが大規模に動いています。

### 3. 被害規模が巨大になりうる
FIFA 2026は世界中で何十億人もが注目するイベントです。少しの詐欺成功率でも、**莫大な被害総額**になります。

### 4. 企業も被害者になりうる
なりすましメール攻撃（**BEC：ビジネスメール詐欺**）によって、企業が**数億円単位の誤送金**をしてしまうケースも世界では起きています。

## 対策・今後の展望

### 👤 一般の人ができる対策

| 場面 | やること |
|---|---|
| チケット・宿泊予約 | **公式サイトのURLを直接確認**する。検索結果の上位広告は偽物の可能性がある |
| URLの確認 | **「.top」「.xyz」などのドメインには特に注意**。公式は通常「.com」「.org」など |
| アプリのダウンロード | **公式サイトからのリンク**でのみダウンロード。GooglePlayでも偽物は存在する |
| メールの確認 | 送信元アドレスを**ドメインレベルで確認**。「fifa-official@worldcup2026support.top」などは偽物 |
| 予想サービス | 「必ず当たる」「高勝率」を謳うサービスは**すべて詐欺と思ってよい** |
| 急かされたら | 「今すぐ購入しないと売り切れ！」は詐欺の常套句。**一度立ち止まる** |

### 🏢 企業・組織ができる対策

- **DMARC・SPF・DKIMの設定**を正しく行い、メールなりすましを防ぐ
- 取引先からの**支払い口座変更メール**は、電話で必ず確認する
- 社員への**フィッシング訓練・セキュリティ教育**を実施する

### 🔮 今後の展望

ワールドカップのような大型イベントを狙った攻撃は今後も続くと予想されます。2028年のオリンピック（ロサンゼルス）や各種スポーツ大会でも同様の手口が使われるでしょう。セキュリティ企業による**事前の脅威インテリジェンス（情報収集・分析）**の重要性がますます高まっています。

## 用語解説

| 用語 | 意味 |
|---|---|
| **DMARC** | メールが本物の送信元から来ているかを確認する技術。設定が不十分だと他人がなりすましメールを送れてしまう |
| **ドメインスプーフィング** | 本物のウェブサイトやメールアドレスに見せかけて偽物を作ること |
| **フィッシング** | 偽サイト・偽メールで個人情報やパスワードを盗み取る攻撃 |
| **サプライチェーン** | 商品やサービスが作られて届くまでの企業・業者のつながり |
| **アフィリエイト詐欺** | 紹介リンクから人を誘導して、不正に紹介料を得る手口 |
| **TLD（トップレベルドメイン）** | URLの末尾の「.com」「.jp」「.top」などの部分 |
| **MXレコード** | そのドメインがメールを受信できるように設定する技術的な設定 |
| **BEC（ビジネスメール詐欺）** | 企業の担当者になりすまして、取引先などに誤送金させる攻撃 |
| **脅威インテリジェンス** | 攻撃者の手口・計画を事前に収集・分析する情報活動 |
| **Telegram** | 強力なプライバシー機能を持つメッセージアプリ。匿名性が高いため犯罪者にも悪用される |
| **攻撃面管理（ASM）** | 企業が外部から攻撃されうるポイントを継続的に監視・管理すること |
