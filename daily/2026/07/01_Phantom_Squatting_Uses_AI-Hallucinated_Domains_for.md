# ファントム・スクワッティング：AIが「でっち上げたURL」を使ったフィッシング詐欺と悪意あるソフトウェアの拡散

**元記事**: [Phantom Squatting Uses AI-Hallucinated Domains for Phishing and Malware](https://inl03.netline.com/ltr6/?_m=3n.009a.4018.sp0ao46r89.32m8)
**解説日**: 2025年7月14日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を押さえておきましょう。

### 🤖 LLM（大規模言語モデル）とは？
ChatGPTやGeminiのような「AIチャット」の中核技術です。大量のテキストデータを学習して、自然な文章を生成します。ただし、**「それらしい答えを作り出す」のが得意な反面、存在しない情報を堂々と答えてしまう**ことがあります。

### 🌀 AIの「ハルシネーション（幻覚）」とは？
AIが**事実ではないことを、まるで事実のように答えてしまう現象**です。たとえば「〇〇銀行の公式サイトは？」と聞いたとき、実際には存在しないURLを自信満々に答えることがあります。これは「嘘をついている」のではなく、「それっぽいパターンを生成してしまった」結果です。

### 🌐 ドメインとは？
`amazon.co.jp` や `google.com` のような、ウェブサイトの「住所」にあたる文字列です。誰でもお金を払えば購入・登録できます。

### 🎣 フィッシング詐欺とは？
本物そっくりの偽サイトに誘導して、パスワードやクレジットカード番号などを盗む攻撃です。「釣り（fishing）」に例えられています。

### 🦆 スクワッティングとは？
「squat（不法占拠）」から来た言葉で、**人気ブランドに似たドメイン名を先に取得してしまう行為**です。たとえば `amaz0n.co.jp` のようなものです。

## 何が起きたのか

セキュリティ企業パロアルトネットワークスの研究チーム「Unit 42」が、新しい攻撃手法を発見・報告しました。

### 📋 調査の概要

研究チームは次のような実験を行いました：

| 項目 | 数値 |
|------|------|
| AIへの質問数 | **685,339回** |
| 対象ブランド数 | **913社**（テクノロジー・金融・医療・政府機関など） |
| AIが生成したURL数 | **約210万件** |
| そのうち既知の悪意あるURL | **13,229件** |
| まだ誰も持っていない（登録済みでない）ドメイン | **約25万件** |

AIは質問に答える中で、**存在しないウェブサイトのURLを大量に「でっち上げて」いた**のです。そしてその偽URLのいくつかは、すでに攻撃者に登録・悪用されていました。

### 🕵️ 実際に起きた2つの事件

**事件①：偽の郵便局ショッピングサイト**

1. Unit 42のシステムが「AIが特定の国の郵便局のネットショップに似た偽ドメインを生成し続けている」と予測
2. 予測から**23日後**、攻撃者がそのドメインを実際に登録
3. 「Montana Empire」という名前のフィッシングキット（詐欺サイト作成ツール）を使って、本物そっくりの偽サイトを構築
4. 被害者からクレジットカード番号・銀行振込情報・国民IDを窃取
5. しかも攻撃者もAIを使ってこのサイトを作っていたことが、残留ファイルから判明

**事件②：偽の郵便局アプリ配布サイト**

1. Unit 42が偽ドメインを検出してから**51日後**に攻撃者が登録
2. 本物そっくりのサイトに「評価4.8星・200万ユーザー以上」という偽情報を掲載
3. 訪問者に悪意あるAndroidアプリをダウンロードさせた

## 技術的な詳細

### 🔄 攻撃の流れ（図解）

```
① ユーザーがAIに質問
　　「〇〇銀行の公式サイトはどこですか？」
　　　　　↓
② AIが存在しないURLを生成してしまう
　　「https://oobank-official-service.com です」（←実際は存在しない！）
　　　　　↓
③ 攻撃者が同じ質問をして、そのURLを予測・先に登録
　　　　　↓
④ 偽サイトを立ち上げる（本物そっくりに作成）
　　　　　↓
⑤ AIを信じたユーザーが偽サイトを訪問
　　　　　↓
⑥ 個人情報・パスワード・クレジットカード情報が盗まれる
```

### 😈 なぜ防御が難しいのか？

通常のフィッシング対策は「悪いサイトのリストを作って弾く」仕組みです。ところが**偽ドメインを登録したばかりの時点では、そのサイトはまだ「クリーン（無害）」と判定されてしまいます**。

> 例え話：新しく引っ越してきた人は、前科がないので最初は疑われない。でも実は詐欺師だった、というイメージです。

### 🎯 AIが同じ偽URLを繰り返す理由

AIは「言語のパターン」から回答を生成します。そのため、**同じ質問をすれば異なるAIでも同じ偽URLを作り出すことがあります**。攻撃者にとっては「次のターゲットが予測しやすい」ということを意味します。

さらに、AIの「創造性設定（temperature）」を上げると、でっち上げドメインがむしろ増えることも確認されています。

研究チームは「**これはLLMの構造的な特性であり、根本的に修正できない（inherently unpatchable）**」と述べています。

### 📦 関連する攻撃「スロップ・スクワッティング」

今回の「ファントム・スクワッティング」は、以前から問題になっていた**「スロップ・スクワッティング」**のウェブサイト版です。

- **スロップ・スクワッティング**：AIがプログラムのライブラリ名（パッケージ名）をでっち上げる → 攻撃者がそのパッケージ名でマルウェアを公開
- **ファントム・スクワッティング**：AIがウェブサイトのURL（ドメイン）をでっち上げる → 攻撃者がそのドメインを取得してフィッシングサイトを立てる

実際に「PhantomRaven」という攻撃では、AIが生成した偽パッケージ名を使ったマルウェアが**npmに126個公開され、86,000回以上インストールされた**という報告もあります。

## なぜ重要なのか

### 🚨 「AIを信頼している」ことが弱点になる

これまでのフィッシング詐欺は「怪しいメールのリンクをクリックしてしまった」などが原因でした。しかし今回の攻撃は**「信頼しているAIツールが教えてくれたURL」だから疑わない**という心理を悪用します。

### 👨‍💻 開発者も危険にさらされる

プログラマーがAIに「このAPIのドキュメントはどこですか？」と質問し、でっち上げURLが返ってきた場合、そのURLが攻撃者に悪用されている可能性があります。

### 🌍 影響範囲が広い

今回の調査では、以下の地域・業種が標的になっていることが確認されました：
- UAE（アラブ首長国連邦）の大手銀行
- ヨーロッパの銀行
- バングラデシュのスポーツベッティングサイト
- 各国の郵便局サービス

## 対策・今後の展望

### ✅ 今すぐできる対策

**一般ユーザー向け：**

1. **AIが教えてくれたURLは、そのままクリックしない**
   - 必ず公式アプリや検索エンジンで別途確認する習慣を
2. **URLをよく見る**
   - `amazon.co.jp`（本物）と `amazon-co-jp.xyz`（偽物）は全然違います
3. **個人情報を入力する前にURLバーを確認する**
   - 鍵マーク🔒があっても安心しない（偽サイトでもhttpsは使える）

**開発者・IT担当者向け：**

1. **AIが提案したドメインやパッケージ名は必ず手動で検証する**
2. **ドメイン監視サービスを利用する**
   - 自社ブランドに似た新規登録ドメインをアラート通知
3. **セキュリティツールのURL検証機能を活用する**

### 🔮 今後の展望

Unit 42の研究チームは「**これはAIの設計上の根本的な問題であり、簡単に修正できない**」と警告しています。AIが社会に深く浸透すればするほど、この問題は深刻化する可能性があります。

今後は：
- AI企業によるハルシネーション低減の取り組み
- ドメイン登録業者による不審な新規登録の監視強化
- セキュリティツールのリアルタイムURL検証機能の向上

といった対策が求められるでしょう。

## 過去記事との関連

今回の「ファントム・スクワッティング」は、AIが生成した**偽パッケージ名**を悪用する「スロップ・スクワッティング」と同じ発想から生まれた攻撃です。どちらも「AIの出力をそのまま信じる」という人間の行動を悪用している点で共通しています。

AI活用が進む現代において、「**AIの答えを鵜呑みにしない**」という姿勢がセキュリティの基本になりつつあります。

## 用語解説

| 用語 | 意味 |
|------|------|
| **LLM（大規模言語モデル）** | ChatGPTなどのAIチャットの中核技術。大量のテキストから言語パターンを学習する |
| **ハルシネーション（幻覚）** | AIが事実でない情報をまるで事実のように答えてしまう現象 |
| **ドメイン** | ウェブサイトの「住所」。`google.com`など |
| **ファントム・スクワッティング** | AIが生成した存在しないドメインを攻撃者が先に登録して悪用する手法 |
| **スロップ・スクワッティング** | AIが生成した存在しないソフトウェアパッケージ名を攻撃者が先に登録して悪用する手法 |
| **フィッシング** | 本物そっくりの偽サイトに誘導して個人情報を盗む攻撃 |
| **フィッシングキット** | 偽サイトをすばやく構築するためのツール一式 |
| **Unit 42** | セキュリティ企業パロアルトネットワークスの脅威調査チーム |
| **npm** | JavaScriptのプログラムパーツ（パッケージ）を共有する公開サービス |
| **temperature（創造性設定）** | AIの回答のランダム性を調整するパラメータ。高いほど多様（かつ不正確）な回答を生成しやすい |
| **ブロックリスト** | 既知の悪意あるサイトや迷惑メール送信元を記録したリスト |
