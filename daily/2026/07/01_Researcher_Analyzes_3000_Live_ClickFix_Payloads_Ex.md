# 研究者が3,000件の「ClickFix」攻撃データを分析、APIを使ったマルウェア配布の実態が明らかに

**元記事**: [Researcher Analyzes 3,000 Live ClickFix Payloads, Exposing API-Driven Malware Delivery](https://inl03.netline.com/ltr6/?_m=3n.009a.4018.sp0ao46r89.32mq)
**解説日**: 2026年7月2日

---

## 背景知識

まず、この記事を理解するために必要な言葉をいくつか説明しておきましょう。

### 🤖 CAPTCHAとは？
Webサイトにアクセスするとき「私はロボットではありません」というチェックボックスや、「横断歩道が写っている画像を選んでください」というテストを見たことはありませんか？あれが「CAPTCHA（キャプチャ）」です。「本物の人間かどうか確認する仕組み」です。

### 📋 クリップボードとは？
パソコンで「コピー＆ペースト」をするとき、コピーしたデータを一時的に保存する場所です。Ctrl+Cでコピーすると、クリップボードに保存され、Ctrl+Vで貼り付けができます。

### 💻 PowerShellとは？
Windowsに標準搭載されているコマンド操作ツールです。プログラムを動かしたり、ファイルを操作したりと、強力な命令をコンピューターに与えられます。悪用されると危険な道具にもなります。

### 🦠 マルウェアとは？
「悪意のあるソフトウェア」の総称です。ウイルス、スパイウェア、ランサムウェアなどが含まれます。

### 🔑 APIとは？
「Application Programming Interface」の略で、ソフトウェア同士が会話するための「窓口」です。たとえばお天気アプリが気象サービスに「今日の天気を教えて」と問い合わせる仕組みがAPIです。

## 何が起きたのか

セキュリティ研究者のベルト＝ヤン・パルス氏が、「**ClickFix（クリックフィックス）**」という攻撃手法について約3,000件の実際の攻撃データを分析し、その詳細な実態を2025年6月末に公開しました。

### ClickFixって何？
ClickFixは「**自分でマルウェアを実行させる**」という、ちょっと変わった（しかしとても巧妙な）攻撃手法です。

流れはこんなイメージです👇

```
①  偽のWebページを開く
        ↓
②  「あなたが人間かどうか確認してください」という
    偽CAPTCHAや偽エラー画面が表示される
        ↓
③  こっそりと悪意あるコマンド（命令文）が
    あなたのクリップボードにコピーされる
        ↓
④  「Windows+R を押して、貼り付けて、Enterを押してください」
    と画面に指示される
        ↓
⑤  あなた自身がマルウェアを実行してしまう 😱
```

ポイントは「**被害者自身が実行する**」こと。これにより、多くのセキュリティソフトがアラートを出しにくくなります。

## 技術的な詳細

### 📦 「注文ごとに変装する」マルウェア配布システム

パルス氏が発見した新しい点は、攻撃の「バックエンド（裏側の仕組み）」です。

以前は攻撃者が手動でコマンドを用意していましたが、今はまるで**ネット通販の自動倉庫**のように機能するAPIサーバーが悪意あるコマンドを自動で生成・配布しています。

| 従来の方法 | 新しい方法 |
|---|---|
| 攻撃者が手作業でコマンドを用意 | APIサーバーが自動生成 |
| 全員に同じコマンド | アクセスするたびに異なる見た目 |
| 1言語対応が多い | 25言語対応 |
| Windows専用が多い | macOSにも対応 |

パルス氏が1つのサーバーに「100個のコマンドをください」と要求したところ、**100個すべて異なる見た目のコマンド**が返ってきました。Base64、AES、TripleDESなどの暗号化で包まれていましたが、中身を開けると同じマルウェアでした。

> 💡 **例え話**: 同じ内容のプレゼントを、毎回違う包装紙・リボン・袋で包んで渡すイメージです。外見が違うのでセキュリティソフトに「怪しいもの」と気づかれにくくなります。

---

### 🥷 セキュリティソフトをすり抜ける新手法「ダウンロードフォルダ経由」

さらに発見された新しい攻撃手法があります。セキュリティソフトが「クリップボードの中身を監視している」ことを知った攻撃者が、新しいやり方を編み出しました。

**新手法の流れ：**

```
①  ページを開くと、こっそりファイルが
    「ダウンロードフォルダ」に保存される
        ↓
②  クリップボードにコピーされるのは
    「無害に見える短い命令文」だけ
        ↓
③  その命令文は「ダウンロードフォルダのファイルを
    移動して、解凍して、実行する」というもの
        ↓
④  悪意あるコードはファイルの中に隠れているため
    クリップボード監視をすり抜けられる
```

実際にクリップボードにコピーされたコマンドの例：
```powershell
powershell -C "$t=$env:TMP;Move-Item "$HOME\Downloads\tmp.zip" "$t\7947.zip";
tar -xf "$t\7947.zip" -C "$t";conhost --headless powershell 
-ExecutionPolicy Bypass -File "$t\tmp.ps1" 
# "* I am not a robot reCAPTCHA Verification ID:7947 *"
```
（訳：ダウンロードフォルダのzipファイルを移動・解凍して実行する、という意味の命令文。コメントで「ロボットではありません」と書いて無害そうに見せかけています）

---

### 🕵️ 証拠を残さない進化

操作手順も巧妙に変化しています。

| 2024年頃（古い手口） | 2025〜2026年（新しい手口） |
|---|---|
| Windows+R（ファイル名を指定して実行） | Windows+X（Windowsターミナル） |
| 実行履歴がレジストリに残る | **履歴が残らない** |
| 調査しやすい | 調査が難しい |

「レジストリ」とはWindowsの設定情報を保存する場所のことで、セキュリティ調査官がよく確認する場所です。新手口はその証拠を残さないように設計されています。

## なぜ重要なのか

### 📈 急増している攻撃

- セキュリティ会社**ESET**の調査では、2024年後半〜2025年前半で **517%増加**（約6倍！）
- **Microsoft**の報告では、初期侵入手口の**47%**がClickFixを使用

### 🌍 国家レベルの攻撃者も使用

もはや一般的な犯罪者だけでなく、**国家が支援する攻撃グループ**も使っています：

- 🇷🇺 ロシア：APT28（別名：Fancy Bear）
- 🇮🇷 イラン：MuddyWater
- 🇰🇵 北朝鮮：Kimsuky（偽の求人を使った「ClickFake Interview」も実施）

### 🏪 「サービスとして売られる」犯罪ビジネス

ClickFixは今や**犯罪者向けに販売される商品**になっています。ツールを作る人、それを使って攻撃する人というように分業化が進んでいます。まるで闇の「SaaS（サービスとしてのソフトウェア）」ビジネスです。

## 対策・今後の展望

### ✅ あなたが今日からできる対策

**1. 「貼り付けて実行してください」には絶対従わない**
> Webページが「このコマンドをコピーして実行してください」と求めてきたら、それは攻撃のサインです。どんな理由があっても従わないようにしましょう。

**2. 知らないWebページでのキーボード操作に注意**
> 「Windows+R」「Windows+X」「Ctrl+V」などを促すページは危険です。

**3. ダウンロードフォルダを定期的に確認する**
> 身に覚えのないファイルが入っていないか、時々チェックしましょう。

**4. セキュリティソフトを最新の状態に保つ**
> ClickFixに特化した検知機能を持つ製品が増えてきています。

**5. 「人間確認」の手順がおかしいと感じたらすぐ閉じる**
> 本物のCAPTCHAは「コマンドを実行してください」とは言いません。

### 🔮 今後の動向

研究者のパルス氏は「近い将来、マルウェアの中身も被害者ごとに変化するようになる可能性が高い」と警告しています。攻撃はより自動化・個別化される方向に進化しています。

## 過去記事との関連

以前「**ファントム・スクワッティング：AIが『でっち上げたURL』を使ったフィッシング詐欺と悪意あるソフトウェアの拡散**」について解説しましたが、今回の記事もその流れで読むことができます。

前回はAIが存在しないURLを生成し、それを悪用してフィッシング詐欺を行うという「**入口の偽装**」の話でした。今回のClickFixは「**入口に誘い込んだ後、被害者自身に実行させる**」という「**行動の偽装**」の話です。

共通しているのは、どちらも「**ユーザーを信頼できるものだと思い込ませる**」という人間の心理を利用している点です。技術的なセキュリティが進化するほど、攻撃者は「人間の判断ミスを誘う」方向にシフトしてきているといえます。

## 用語解説

| 用語 | 意味 |
|---|---|
| **ClickFix** | 偽のCAPTCHA等でユーザー自身にマルウェアを実行させる攻撃手法 |
| **CAPTCHA** | 人間とロボットを区別するための認証テスト（「私はロボットではありません」等） |
| **クリップボード** | コピー＆ペーストで使うデータの一時保存場所 |
| **PowerShell** | Windowsの強力なコマンド操作ツール |
| **API** | ソフトウェア同士が通信するための窓口・仕組み |
| **ペイロード** | 攻撃の「本体」となる悪意あるコード |
| **Base64 / AES / TripleDES** | データを変換・暗号化する方法（見た目を変えて検知を回避するために使用） |
| **AMSI** | Windowsのスクリプトスキャン機能。実行前にコードの危険性を確認する |
| **レジストリ** | Windowsの設定や操作履歴を保存するデータベース |
| **APT28 / MuddyWater / Kimsuky** | 国家が支援するとされるハッカーグループ |
| **MITRE ATT&CK** | サイバー攻撃の手口を分類・整理した世界標準のカタログ |
| **マルウェア** | 悪意を持って作られたソフトウェアの総称 |
| **SaaS（サービスとしてのソフトウェア）** | インターネット経由でソフトウェアを提供するビジネスモデル。今回は犯罪者向けに攻撃ツールが販売されている |
