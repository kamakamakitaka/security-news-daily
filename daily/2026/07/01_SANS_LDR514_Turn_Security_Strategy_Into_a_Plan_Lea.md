# セキュリティ戦略をお金を出してもらえる計画に変える方法

**元記事**: [SANS LDR514: Turn Security Strategy Into a Plan Leaders Fund](https://inl03.netline.com/ltr6/?_m=3n.009a.4018.sp0ao46r89.32m2)
**解説日**: 2025年7月14日

---

## 背景知識

まず、このニュースを理解するための基礎知識を押さえましょう。

### 🏫 SANSとは？
**SANS Institute（サンズ・インスティテュート）** は、世界最大規模のサイバーセキュリティ教育・研究機関です。プロのセキュリティ担当者向けに研修コースや資格を提供しています。学校で言えば「セキュリティ専門の予備校」のようなイメージです。

### 💼 LDR514とは？
**LDR514** はSANSが提供するコースの番号です。「LDR」は「Leadership（リーダーシップ）」の略で、技術者向けではなく**セキュリティのリーダー・管理職向け**の内容です。つまり「どうやってセキュリティを技術的に実装するか」ではなく、「どうやって組織にセキュリティ予算を確保するか」を学ぶコースです。

### 💰 なぜ「お金の話」がセキュリティに関係するの？
セキュリティの世界には、こんな問題があります：

> 「ハッカーから守る技術はわかっている。でも、上司や経営陣がお金を出してくれない！」

技術者がいくら「このシステムは危険です！」と言っても、会社のお偉いさんが「でもお金かかるよね？本当に必要なの？」と言ったら、予算がもらえません。これが**世界中のセキュリティ担当者が抱える悩み**なのです。

---

## 何が起きたのか

今回の記事は、**SANS LDR514というコース・プログラムの紹介・告知**です。

具体的には：

- 🎯 **セキュリティの戦略（計画）を、経営者がお金を出したくなるような提案書に変換する方法**を教えるプログラム
- セキュリティ担当のリーダーや管理職を対象にしている
- 「技術的に正しいセキュリティ計画」を「ビジネス的に説得力のある投資計画」として経営層に伝えるスキルを養う

> **一言で言うと**：「セキュリティのプロが、経営陣の言葉で話せるようになるための研修」です。

---

## 技術的な詳細

今回は「技術的な攻撃手法」の話ではありませんが、このコースで扱われるであろう概念を解説します。

### 📊 セキュリティ戦略とは？
「セキュリティ戦略」とは、**会社をサイバー攻撃から守るための大きな計画**のことです。例えば：

- どのシステムを優先的に守るか
- 万が一攻撃されたときにどう対応するか
- 社員にどんな教育をするか

### 🗣️ 「経営者の言葉」への翻訳
セキュリティ担当者と経営者では、**気にしていることが全然違います**：

| セキュリティ担当者が言いたいこと | 経営者が聞きたいこと |
|---|---|
| 「このシステムに脆弱性があります」 | 「それで損失はいくらになりますか？」 |
| 「ファイアウォールを強化すべきです」 | 「投資対効果（ROI）はどのくらい？」 |
| 「ランサムウェアのリスクがあります」 | 「競合他社と比べてどう？」 |

LDR514は、この**「翻訳」のスキル**を磨くためのコースだと考えられます。

### 📈 リスクをお金で表す方法
例えば、こんな考え方を使います：

```
もし情報漏洩が起きたら...
  └── 顧客への補償費用：○○円
  └── システム復旧費用：○○円
  └── ブランドイメージの損失：○○円
  └── 合計：△△円

セキュリティ対策の費用：□□円
→ 対策する方が△△ - □□ = ××円 お得！
```

このように**リスクを金額で見える化**することで、経営者に納得してもらいやすくなります。

## なぜ重要なのか

### 🌍 現実の大問題
過去の調査でも明らかになっていますが、多くの組織では：

- セキュリティ担当者は「危険だ」とわかっている
- でも予算が足りない、または承認が下りない
- 結果として対策が後手に回り、被害を受けてしまう

これは「技術力の問題」ではなく、**「コミュニケーションと説得力の問題」**です。

### 🏢 組織全体への影響
セキュリティの予算が確保できないと：

1. **システムが古いまま放置** → 脆弱性（弱点）が残る
2. **人材が不足** → 攻撃に気づけない
3. **訓練ができない** → 攻撃を受けたときに対応できない

逆に言えば、**セキュリティリーダーが経営者を説得できるようになれば、組織全体のセキュリティが向上する**という大きな効果があります。

## 対策・今後の展望

### ✅ セキュリティ担当者がやるべきこと

| アクション | 内容 |
|---|---|
| **リスクの数値化** | 「危険です」ではなく「被害額は○○円になりえます」と伝える |
| **経営用語を学ぶ** | ROI（投資対効果）、KPI（重要評価指標）などのビジネス言葉を使う |
| **業界の事例を集める** | 「同じ業界の○○社がこんな被害を受けました」と具体例を示す |
| **段階的な計画を立てる** | 一気に大きな予算を求めず、小さな成功を積み重ねる |

### 🔮 今後の流れ
セキュリティは今後も**経営レベルの重要課題**になり続けます。特に：

- 法律・規制の強化（個人情報保護法の改正など）
- サイバー保険の普及
- 取締役会レベルでのセキュリティ責任

これらの流れから、**「セキュリティをビジネス的に語れる人材」の価値はますます高まる**と予想されます。

## 過去記事との関連

以前、「**2026年サイバーセキュリティ調査：『わかっている』と『できている』の大きなギャップ**」について解説しました。

その記事では、**多くの組織がリスクを認識しているにも関わらず、実際の対策が追いついていない**という現実が明らかになりました。

今回のLDR514コースは、まさにその**ギャップを埋めるための解決策の一つ**と言えます：

```
【問題】認識はある → でも対策できていない
         ↓ なぜ？
【原因】予算が出ない・経営層の優先度が低い
         ↓ どうする？
【解決】セキュリティリーダーが経営者を説得できるスキルを身につける
         ↓ それを学ぶのが
【コース】SANS LDR514
```

「わかっている」と「できている」のギャップは、技術だけでなく**組織・予算・コミュニケーション**の問題でもあることが、この2つの記事から見えてきます。

## 用語解説

| 用語 | 意味 |
|---|---|
| **SANS Institute** | 世界最大規模のサイバーセキュリティ教育機関 |
| **LDR514** | SANSのリーダーシップ向けセキュリティコースの番号 |
| **セキュリティ戦略** | 組織を守るための大きな方針・計画 |
| **ROI（投資対効果）** | かけたお金に対してどれだけのリターンがあるかを示す指標 |
| **KPI（重要評価指標）** | 目標の達成度を測るための数値 |
| **脆弱性** | システムやソフトウェアの弱点・欠陥 |
| **ランサムウェア** | データを暗号化して身代金を要求するマルウェア（悪意あるソフト） |
| **リスクの数値化** | 「何が起きたらどのくらいの損害になるか」を金額で表すこと |
| **経営層（C-Suite）** | CEO・CFO・CISOなど会社の最高幹部 |
| **CISO** | 最高情報セキュリティ責任者（会社のセキュリティ責任者トップ） |

> 💡 **まとめ**：セキュリティは「技術だけ」では成り立ちません。どんなに優れた技術者でも、予算がなければ対策できません。SANS LDR514は、セキュリティのプロが「経営者の言葉で話す」スキルを身につけ、組織全体のセキュリティレベルを上げることを目指したプログラムです。「守る技術」と「動かす力」の両方が、現代のセキュリティには必要なのです。
