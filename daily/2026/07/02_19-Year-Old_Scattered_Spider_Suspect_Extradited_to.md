## 背景知識

### ハッカー集団って何？

よくゲームやアニメで「ハッカー」という言葉が出てきますが、ここでいうハッカーとは**他人のコンピューターシステムに無断で侵入して、データを盗んだりお金を要求したりする犯罪者グループ**のことです。

### 「ソーシャルエンジニアリング」とは？

今回の事件で特に大事な概念です。  
一般的なサイバー攻撃は「システムの弱点を技術的に突く」ものですが、スキャッタード・スパイダーが使う手口は少し違います。

> **人間の心理的な弱点を突いてだます攻撃**のことを「ソーシャルエンジニアリング」と言います。

たとえば、こんな感じです：

```
攻撃者「もしもし、ITヘルプデスクですか？
        山田ですが、パスワードを忘れてしまって
        ログインできないんです。急いでいるので
        リセットしてもらえますか？」

ヘルプデスク担当者「わかりました、リセットしますね」

→ 実は攻撃者だった！
  会社のシステムに侵入されてしまった…😱
```

技術的な「鍵のこじ開け」ではなく、**「人をだまして鍵を渡させる」**というわけです。

### エクストラディション（身柄引き渡し）とは？

外国で逮捕された犯罪容疑者を、犯罪が行われた国に引き渡す国際的な手続きのことです。今回はフィンランドで逮捕された人物が、アメリカに引き渡されました。

### インターポール・レッドノーティスとは？

国際刑事警察機構（インターポール）が発行する**国際的な手配書**です。  
「この人物を見つけたら逮捕・拘留してください」という国際的なお知らせで、世界中の警察が連携して容疑者を追いかけることができます。

## 何が起きたのか

### 事件の概要

2025年7月1日、アメリカ司法省が発表したニュースです。

**ピーター・ストークス**（19歳、米国・エストニアの二重国籍）という若者が、ハッカー集団「**スキャッタード・スパイダー**」のメンバーとして疑われており、フィンランドからアメリカへ身柄を引き渡されました。

彼の罪状は以下の3つです：
- 🔴 **共謀罪**（仲間と一緒に犯罪を計画した）
- 🔴 **不正コンピューターアクセス罪**（他人のシステムに不正侵入した）
- 🔴 **詐欺罪**（お金をだまし取ろうとした）

### 逮捕の経緯

```
📅 2025年4月
  → フィンランド警察がインターポールのレッドノーティスを受けて逮捕

✈️ 逮捕場所：ヘルシンキ空港
  → 日本行きの飛行機に乗ろうとしていたところを捕まえた！
  → 2テラバイトのハードディスク2台を押収
     （2TBって、映画約1,000本分のデータ量です）

📅 2025年6月末
  → フィンランドからアメリカへ身柄引き渡し

📅 2025年6月30日
  → シカゴの連邦裁判所に出廷、拘留命令
```

### 彼が何をしたか

裁判記録によると、ストークス容疑者はオンライン上では「**Bouquet（ブーケ）**」という名前を使っていました。

最初の不正侵入は**16歳のとき**だったとされています。

特に注目されるのは2025年5月の事件です：
- 高級ジュエリー店に不法侵入（デジタル上で）
- データをコピーして盗み取る
- 「データを公開されたくなければ**約8億円相当の暗号通貨を払え**」と要求
- 店側は拒否し、追い出す作業に**約2億円**を費やした

## 技術的な詳細

### スキャッタード・スパイダーの正体

このグループは従来のマフィアのような組織ではありません。

| 特徴 | 内容 |
|------|------|
| メンバー | アメリカ・イギリス・ヨーロッパの若者たち（10代も含む） |
| 組織形態 | 緩やかなつながり（固定した組織ではない） |
| 使用言語 | 主に英語 |
| 別名 | Octo Tempest / UNC3944 / 0ktapus |

### 攻撃の仕組み（ステップバイステップ）

```
🎭 ステップ1：なりすまし
  会社のITヘルプデスクに電話をかけ、
  「社員がパスワードを忘れてログインできない」とウソをつく

🔑 ステップ2：侵入
  だまされたヘルプデスク担当者がパスワードをリセット
  → 攻撃者が社内システムにログイン成功！

👀 ステップ3：潜伏
  会社のチャットツール（SlackやTeamsなど）に潜り込み、
  情報を収集。なんと「セキュリティ対応の会議」にも
  こっそり参加して、追われていないか監視する

💾 ステップ4：データ窃取
  重要なファイルやデータを全部コピーして外部に持ち出す

💰 ステップ5：脅迫（ランサム）
  「このデータを公開されたくなければお金を払え」と要求
  （これを「ランサムウェア攻撃」の一種と言います）
```

### 過去の主な被害

このグループが最も有名になったのは**2023年のカジノ攻撃**です：

- 🎰 **MGMリゾーツ**（世界的なカジノチェーン）：ホテルやカジノのシステムが完全にダウン
- 🃏 **シーザーズ・エンターテインメント**：同じく大規模な被害

2025年には**イギリスの大手小売店**にも攻撃が及びました：
- マークス&スペンサー（英国の有名デパート）
- ハロッズ（世界的に有名な高級百貨店）
- コープ（英国のスーパーマーケットチェーン）

その後もアメリカの保険会社や航空会社にも攻撃が広がっています。

## なぜ重要なのか

### 被害の規模が巨大

米国司法省によると：
> **「100件以上の不正侵入が確認されており、合計1億ドル（約150億円）以上の身代金が支払われた」**

### 犯人が「普通の若者」という衝撃

このグループの特徴として衝撃的なのは、**メンバーが10代〜20代前半の若者**であることです。

ストークス容疑者は最初に侵入を行ったとき、まだ**16歳**でした。  
専門的な技術よりも「人をだます話術」を使った攻撃だからこそ、年齢に関係なく実行できてしまうのです。

### 逮捕が続いているが、手口は拡散中

最近の逮捕・有罪の流れ：

| 人物 | 国籍 | 処分 |
|------|------|------|
| タイラー・ブキャナン（24歳） | スコットランド | 2026年4月に詐欺・個人情報窃盗で有罪認定、最大22年の刑 |
| ノア・アーバン | フロリダ | 2025年8月に懲役10年、約20億円の返還命令 |
| タルハ・ジュバイル＆オーウェン・フラワーズ | イギリス | 2026年6月にロンドン交通局（TfL）への攻撃で有罪認定 |

しかし問題なのは、**逮捕されても手口がコピーされ広まっている**ことです。  
セキュリティ会社マンディアントによると「別のグループが同じ手口を真似し始めている」とのことです。

## 対策・今後の展望

### 会社側ができること

このグループの攻撃の「弱点（=攻撃の入口）」は**ファイアウォールではなく、人間（ヘルプデスク担当者）**です。

だから、技術的なセキュリティ強化だけでは防げません。

#### 🛡️ 効果的な対策

**1. パスワードリセットの本人確認を厳しくする**
```
❌ 今まで：「山田です、パスワード忘れました」→ 即リセット

✅ これから：
  「本当に社員か確認するために、
   上司に電話して確認します」
  「顔認証/社員証を直接確認します」
```

**2. フィッシングに強い認証方法を使う**
- **パスキー（Passkey）** や **ハードウェアセキュリティキー** を使う
- これらはだまされても使えないように設計されているため、パスワードを「教えてしまっても」ログインされない

**3. 社内チャットツールの監視を強化する**
- 攻撃者は侵入後、SlackやTeamsなどの社内ツールに潜伏する
- 不審なアカウントの活動を監視することが重要

### 今後の捜査の展開

ヘルシンキ空港で押収された**2台のハードディスク（各2TB）**が鍵を握るかもしれません。

> セキュリティ捜査では、一人のメンバーのデバイスから**他のメンバーの情報が芋づる式に出てくる**ことがよくあります。

ストークス容疑者はまだ「無罪推定」の状態（=有罪が確定していない）なので、今後の裁判の行方も注目です。

## 用語解説

| 用語 | 解説 |
|------|------|
| **エクストラディション（身柄引き渡し）** | 外国で逮捕された容疑者を、事件の起きた国に引き渡す手続き |
| **インターポール・レッドノーティス** | 国際刑事警察機構が発行する国際手配書。世界中の警察が連携して容疑者を追う |
| **ソーシャルエンジニアリング** | 技術ではなく「人間の心理」をだます攻撃手法 |
| **ヘルプデスク詐欺** | ITサポート担当者をだまして、パスワードリセットや不正ログインを行う手口 |
| **ランサム（身代金要求）** | データを盗んで「公開されたくなければお金を払え」と脅す攻撃 |
| **暗号通貨** | ビットコインなどのデジタルお金。追跡が難しいため、身代金の支払いに使われやすい |
| **ファイアウォール** | 不正なネットワーク通信をブロックするセキュリティの「壁」 |
| **パスキー（Passkey）** | パスワードの代わりに使う新しい認証方法。フィッシング詐欺では盗めない設計 |
| **フィッシング** | 偽のメールやサイトで個人情報やパスワードをだまし取る攻撃 |
| **Octo Tempest / UNC3944 / 0ktapus** | スキャッタード・スパイダーの別名（セキュリティ会社によって呼び名が異なる） |
| **無罪推定** | 裁判で有罪が確定するまでは「無実である」とみなす法律上の原則 |
