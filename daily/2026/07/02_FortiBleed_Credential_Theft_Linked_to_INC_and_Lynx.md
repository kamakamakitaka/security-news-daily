# FortiBleed：大量の認証情報盗難がランサムウェア攻撃につながった事件

**元記事**: [FortiBleed Credential Theft Linked to INC and Lynx Ransomware Operations](https://inl03.netline.com/ltr6/?_m=3n.009a.4019.sp0ao46r89.32nm)
**解説日**: 2025年7月10日

---

## 背景知識

今回のニュースを理解するために、いくつかのキーワードを先に説明しておきましょう。

### 🔒 FortiGate（フォーティゲート）とは？
FortiGateとは、**Fortinet（フォーティネット）という会社が作ったネットワーク用のセキュリティ機器（ファイアウォール）**です。ファイアウォールとは、会社や学校のネットワークへの不正侵入を防ぐ「門番」のような装置です。病院・工場・大企業など世界中で数十万台が使われています。

### 🔑 認証情報（クレデンシャル）とは？
**ログインに使うIDとパスワードの組み合わせ**のことです。これを盗まれると、泥棒が合鍵を手に入れたような状態になり、正規のユーザーとして不正にシステムに侵入できてしまいます。

### 💰 ランサムウェアとは？
**ランサムウェア（Ransomware）**とは、感染したコンピューター内のファイルを暗号化（鍵をかけて読めなくする）し、「元に戻してほしければお金（身代金）を払え」と脅迫する悪意のあるプログラムです。「ランサム（Ransom）＝身代金」＋「ウェア（ware）＝ソフトウェア」という造語です。

### 🕵️ IAB（初期アクセスブローカー）とは？
**企業や組織のネットワークに不正侵入する「入り口」を作り、それを他の犯罪者に売る専門の犯罪者グループ**のことです。泥棒で例えると「鍵を開ける専門家」が「金庫破り専門家」に仕事を売るようなイメージです。

## 何が起きたのか

### 事件の概要

**「FortiBleed（フォーティブリード）」**と名付けられた大規模なサイバー攻撃キャンペーンが発覚しました。これは、世界中の**FortiGateファイアウォール約43万台**を標的に認証情報を大量に盗み、その情報を使ってランサムウェア攻撃へとつなげていた事件です。

### 時系列で整理すると…

```
① インターネット上のFortiGate機器を自動的にスキャン（探索）
        ↓
② 既知のID・パスワードの組み合わせを試して侵入を試みる
        ↓
③ 侵入成功後、「パケットスニファ」という盗聴ツールを仕掛ける
        ↓
④ ネットワークを流れる通信から認証情報を大量収集
        ↓
⑤ 盗んだ認証情報をランサムウェア攻撃に活用
```

被害の規模は驚くべきもので、以下のようになっています：

| 項目 | 数値 |
|------|------|
| スキャンされたFortiGateポータル数 | 約11,250台（150カ国以上） |
| 管理者レベルのアクセスが確認された標的 | 409件 |
| 完全な攻撃チェーンが完了した標的 | 354件 |
| 実際にランサムウェアが展開された件数 | 少なくとも12件 |
| 盗まれた認証情報の総数 | **1億1千万件以上** |
| パケットスニファが仕掛けられた機器数 | 約12,000台 |

## 技術的な詳細

### 🎣 パケットスニファって何？

「パケット（Packet）」とは、**ネットワーク上を流れるデータの小さな塊**のことです。インターネット通信はすべてこのパケットに分割されてやりとりされています。

「スニファ（Sniffer）」とは**「嗅ぎ取る」という意味**で、ネットワーク上を流れるパケットをこっそり傍受・記録するツールです。

> 📌 例え話：郵便物を開封せずに中身を読む「X線スキャナー」のようなものが、ネットワークの通り道に仕掛けられているイメージです。

今回使われたスニファは**Golang（ゴーラング）**というプログラミング言語で作られており、Fortinet機器に静かに潜り込み、通過する通信から認証情報をこっそり収集し続けていました。

### 🔓 攻撃者はどうやって見つかったのか？

**攻撃者自身のミス（ OpSec エラー）**によって発覚しました。攻撃者が管理していたサーバー（盗んだ認証情報が保存されていた）が、なんと**インターネット上に誤って公開された状態**になっていたのです。

> 📌 例え話：泥棒が盗んだ宝物を自分の家の玄関前に堂々と積み上げてしまったようなものです。

このサーバーには以下のものが含まれていました：
- 標的企業のリスト
- 盗んだ認証情報
- 自動化スクリプト（攻撃を自動で行うプログラム）
- 設定ファイルや作業ログ

### 👥 攻撃グループの実態

調査会社 **SOCRadar** の分析によると、この攻撃グループには以下の特徴があることが判明しています：

- **約20人**で構成された組織的なグループ
- **役割分担**が明確（リーダー格、専門家、サポートスタッフ）
- **ロシア語話者**である可能性が高い（ツールや作業時間帯から推測）
- **INC Ransom** と **Lynx** という2つのランサムウェアグループのパネル（管理画面）に同一オペレーターがログインしているのを確認

さらに、今後の攻撃拡大の兆候も：
- **Nextcloudのゼロデイ脆弱性**（まだ修正パッチが出ていない脆弱性）を保有している可能性
- **Citrix（シトリックス）環境**も標的にしようとしている痕跡（約29,000件のIPアドレスと37ドメインのリスト）

## なぜ重要なのか

### 🌏 影響の広さ

**150カ国以上**が標的になっており、日本も例外ではありません。特に以下の業界が狙われています：

- 🏭 **製造業**
- 💻 **テクノロジー企業**
- 📦 **物流・流通業**

主な標的地域は**ラテンアメリカとアジア太平洋地域**とされており、日本企業も十分に注意が必要です。

### 🆕 今回の「新しさ」

セキュリティの専門家が特に注目しているのは、**「大規模な認証情報の盗難」と「ランサムウェア攻撃」が直接つながっていることが初めて明確に証明された**という点です。

今まで：「認証情報を盗む攻撃者」と「ランサムウェアを使う攻撃者」は別々に活動していることが多かった

今回：**同一グループが一連の流れとして実行**していることが判明

これは、攻撃がより組織化・効率化されていることを示しています。

## 対策・今後の展望

### ✅ 企業・組織が取るべき対策

**今すぐできること：**

1. **FortiGateのファームウェアを最新版に更新する**
   - 既知の脆弱性を修正したパッチを必ず適用しましょう

2. **管理者パスワードを強力なものに変更する**
   - 簡単に推測できるパスワードは絶対にNG
   - 多要素認証（MFA）を有効にする

3. **FortiGateの管理画面をインターネットから直接アクセスできないようにする**
   - 管理ポータルをVPNの内側に置くなどの対策

4. **ネットワーク機器のログを定期的に確認する**
   - 不審なログインや通信がないかチェック

5. **Citrixを使っている場合も同様の確認を**
   - 攻撃グループがCitrix環境も標的にしようとしている

### 🔮 今後の展望

- Nextcloudのゼロデイ脆弱性については、SOCRadarがベンダー（開発元）と連携して対応中
- 攻撃グループはFortinetだけでなく、他のリモートアクセス技術にも攻撃を拡大しようとしている可能性あり
- 同グループのランサムウェア活動は継続中と見られ、引き続き監視が必要

## 用語解説

| 用語 | 説明 |
|------|------|
| **FortiGate** | Fortinet社製のネットワークセキュリティ機器（ファイアウォール） |
| **ファイアウォール** | 不正なネットワーク通信をブロックする「門番」役の機器・ソフト |
| **認証情報（クレデンシャル）** | ログインに使うIDとパスワードの組み合わせ |
| **ランサムウェア** | ファイルを暗号化して身代金を要求するマルウェア |
| **パケットスニファ** | ネットワーク通信を盗み聞きするツール |
| **IAB（初期アクセスブローカー）** | 企業への侵入経路を作って他の犯罪者に売る攻撃者 |
| **ゼロデイ脆弱性** | まだ修正パッチが公開されていない未知のセキュリティ上の欠陥 |
| **Golang** | Googleが開発したプログラミング言語。高速で効率的 |
| **OpSecエラー** | 攻撃者が自分の身元や活動を隠す「作戦上のセキュリティ」に失敗すること |
| **SOCRadar** | 脅威インテリジェンス（サイバー攻撃情報分析）を提供するセキュリティ企業 |
| **INC Ransom / Lynx** | 現在活動中のランサムウェアグループの名称 |
| **Nextcloud** | オープンソースのファイル共有・コラボレーションプラットフォーム |
| **Citrix** | 企業向けのリモートアクセスソリューションを提供する企業・製品群 |
| **多要素認証（MFA）** | パスワード以外にもう1つの確認手段（スマホのコード等）を使う認証方式 |

> 💡 **まとめると…**
> 世界中の約43万台のセキュリティ機器が狙われ、1億1千万件もの認証情報が盗まれた大事件です。攻撃者は約20人の組織的なグループで、盗んだ情報をもとにランサムウェア攻撃まで実行していました。ネットワーク機器の管理画面をインターネットに直接さらさないこと、パスワードを強固にすること、常に最新のアップデートを適用することが重要な対策です。
