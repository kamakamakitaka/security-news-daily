# ペガサススパイウェアで調査委員のスマホがハッキングされていた！

**元記事**: [European Parliament Member Investigating Spyware Was Hacked With Pegasus](https://inl03.netline.com/ltr6/?_m=3n.009a.4020.sp0ao46r89.32oi)
**解説日**: 2025年6月

---

## 背景知識

このニュースを理解するために、まずいくつかの重要なキーワードを押さえておきましょう。

### 🔍 ペガサス（Pegasus）スパイウェアとは？

**スパイウェア**とは、こっそりスマホやパソコンに侵入して、持ち主の知らないうちにメッセージ・写真・通話内容などを盗み見るプログラムです。

**ペガサス**は、イスラエルの企業「NSO Group（エヌエスオーグループ）」が開発した、世界最高レベルのスパイウェアです。各国の政府機関だけに販売されており、「テロリスト対策」などの名目で使われることになっています。しかし実際には、ジャーナリストや政治家、人権活動家などを監視するために悪用されてきた事例が多数報告されています。

> 🏠 **例え話**: ペガサスは「超高性能な盗聴器」みたいなもの。しかも、スマホに触れることなく、気づかれないうちに仕込まれてしまいます。

### 🏛️ 欧州議会のPEGA委員会とは？

**欧州議会（EU）** はヨーロッパの国々が加盟する、日本でいう「国会」のような機関です。

2022年3月、この欧州議会の中に **「PEGA委員会（ペガ委員会）」** という特別調査委員会が設置されました。これは「ペガサスなどのスパイウェアが、EU内で違法に使われていないか調査する」ための委員会です。

つまり、**「スパイウェアを取り締まるために作られた委員会のメンバーが、そのスパイウェアでハッキングされていた」** というなんとも皮肉な事件です。

### 🔬 シティズン・ラボ（Citizen Lab）とは？

カナダのトロント大学に所属する研究機関で、政府や企業によるデジタル監視・スパイウェアの実態を調査・告発することで有名です。世界中のスパイウェア被害を発見してきた実績があります。

## 何が起きたのか

### 事件の概要

```
📅 2022年10月21日 & 2023年3月6〜7日
📱 被害者: ステリオス・クロゴル氏（元欧州議会議員）
🦠 使われたスパイウェア: Pegasus（ペガサス）
🔎 発見者: シティズン・ラボ（2026年5月にiPhoneを解析）
```

ステリオス・クロゴル氏は、スパイウェアの違法利用を調査するPEGA委員会のメンバーでした。シティズン・ラボが彼のiPhoneを詳しく調べたところ、**その調査活動まっただ中に、2回にわたってペガサスに感染していた**ことが判明しました。

### タイムラインで見てみよう

| 時期 | 出来事 |
|------|--------|
| 2022年3月 | PEGA委員会が設置される |
| 2022年10月21日 | クロゴル氏のiPhoneに**1回目のペガサス感染** |
| 2023年3月6〜7日 | **2回目の感染**（PEGA最終報告書の作成が佳境の時期） |
| 2023年7月 | クロゴル氏がPEGA委員会を退任 |
| 2026年5月 | シティズン・ラボがiPhoneを解析し感染を確認 |

### 誰がやったのか？

現時点では、**どの国の政府がやったかは特定されていません**。ギリシャ政府が関与したという証拠もないとされています。しかし調査から、**複数のEU加盟国でスパイ活動ができるライセンスを持つ、ペガサスの顧客（＝何らかの政府）** が関与していると推定されています。

## 技術的な詳細

### ゼロクリック攻撃とは？

通常のサイバー攻撃は、「怪しいリンクをクリックする」「悪意のあるファイルを開く」など、被害者が何らかの操作をしてしまうことで感染します。

しかし今回使われた攻撃は **「ゼロクリック攻撃」** と呼ばれる手法で、**被害者が何もしなくても感染してしまう**、非常に恐ろしいものです。

> 🏠 **例え話**: 普通の泥棒は「ドアを開けてもらう必要がある」けれど、ゼロクリック攻撃は「鍵をかけていても、壁をすり抜けて侵入できる」イメージです。

### 今回使われた脆弱性（PWNYOURHOME）

```
攻撃ルート: Apple HomeKit（アップルのスマートホーム機能）
コードネーム: PWNYOURHOME（パウンユアホーム）
対象: iOS 15.5（iOSのバージョン）
修正: AppleがiOS 16.3.1でパッチを適用済み
```

攻撃の痕跡として、`rauharepo888[@]gmail.com` というメールアドレスが **HomeKit向けのメールアドレス照会** に使われたことが記録されていました。その2分後、ペガサスのプロセスがモバイルデータ通信を使用しており、ここで感染が起きたと考えられています。

> 💡 **iOSのバージョンに注意！** クロゴル氏のiPhoneはどちらの感染時も **iOS 15.5** を使用していました。この脆弱性はiOS 16.3.1で修正済みなので、**OSを常に最新にしておくことが重要**だとわかります。

### Appleからの警告通知

実はAppleは、スパイウェア攻撃を検知した際にユーザーへ通知を送るシステムを持っています。クロゴル氏には以下の3回、Appleから「傭兵スパイウェアに狙われている」という警告が届いていました：

- 📩 2023年3月2日
- 📩 2023年8月29日
- 📩 2024年4月10日

## なぜ重要なのか

### 🚨 「調査する側」が監視されていた衝撃

これは単なるハッキング事件ではありません。**スパイウェアの違法利用を調査するために作られた委員会のメンバーが、まさにその調査中に、そのスパイウェアで監視されていた**という前代未聞の事件です。

映画で例えれば、「汚職を捜査している刑事が、その汚職グループに監視されていた」ようなものです。

### 🔒 漏れていたかもしれない情報

シティズン・ラボの研究者によれば、攻撃者は以下の情報にアクセスできた可能性があります：

- 機密文書
- 委員会の審議内容（まだ公開されていない議論）

2回目の感染（2023年3月）は、PEGA委員会の最終報告書の草稿が作られていた最も重要な時期と重なっています。つまり、**報告書の内容が外部に筒抜けだった可能性**があります。

### 🌍 欧州全体の民主主義への脅威

欧州議会はEUの法律を作る場所です。そこで行われている機密の審議が監視されていたとすれば、**民主主義の根幹が侵害されていた**ことになります。

## 対策・今後の展望

### 私たちができる対策

今回の事件は「政府機関が政府機関を監視する」という高度な話ですが、私たちも参考にできる対策があります：

| 対策 | 理由 |
|------|------|
| ✅ **iOSやAndroidを常に最新版に更新する** | 今回の脆弱性はiOS 16.3.1で修正済み。アップデートは最大の防御 |
| ✅ **Appleやメーカーからの「脅威通知」を無視しない** | Appleはスパイウェアを検知すると通知を送ってくれる |
| ✅ **使っていないアプリや機能をオフにする** | 今回はHomeKitが悪用された。使わない機能は無効化を |
| ✅ **重要な会話は端末の状態に注意する** | 政治家や記者など標的になりやすい人は特に注意 |

### 今後の展望

- **EU規制の強化**: この事件は「スパイウェア規制をもっと厳しくすべき」という議論に拍車をかけるでしょう
- **NSO Groupへの圧力**: ペガサスの開発・販売元への国際的な批判・制裁がさらに強まる可能性があります
- **犯人の特定**: シティズン・ラボは引き続き調査中で、今後新たな情報が出てくる可能性があります

## 過去記事との関連

今回の記事の中で、ギリシャの調査報道ジャーナリスト **タナシス・クカキス氏** も登場します。彼はイスラエル系企業Intellexa（インテレクサ）が開発した **「Predator（プレデター）」** というスパイウェアの被害者で、PEGA委員会で証言もしていました。

ペガサスとプレデターは、どちらも「政府向け商業スパイウェア」という同じカテゴリに属する製品です。ジャーナリストや政治家が標的にされるという点でも共通しており、欧州でのスパイウェア問題が一つの大きな流れとして続いていることがわかります。
