# 偽のMaccyサイトとPAM認証を悪用してMacのログインパスワードを盗む「PamStealer」

**元記事**: [PamStealer Uses Fake Maccy Sites and PAM Checks to Steal Mac Login Passwords](https://inl03.netline.com/ltr6/?_m=3n.009a.4020.sp0ao46r89.32oo)
**解説日**: 2025年7月

---

## 背景知識

このニュースを理解するために、いくつかの基本的な知識を先に押さえておきましょう。

### 🍎 Macとは？
Appleが作っているパソコン（macOS搭載）のことです。「セキュリティが高い」というイメージが強いですが、最近はMacを狙ったマルウェア（悪意のあるプログラム）も増えています。

### 📋 Maccyとは？
「Maccy（マッシー）」は、Macで使えるオープンソース（誰でも中身を見られる無料）のクリップボード管理アプリです。クリップボードとは、コピー（Ctrl+C / ⌘+C）したときに一時的にデータを保存しておく場所のことで、Maccyはその履歴を管理してくれる便利なツールです。今回の攻撃者は、**この有名なアプリになりすまして**ユーザーをだましました。

### 🔐 PAM（プラガブル認証モジュール）とは？
「PAM」とは「**P**luggable **A**uthentication **M**odules」の略で、macOS（やLinux）がパスワードなどの認証を処理する仕組みです。「パスワードが正しいかどうかを確認する係」だと思えばOKです。今回のマルウェアは、このPAMを悪用して、ユーザーが入力したパスワードが**本当に正しいかどうかをその場で確認する**という巧妙な手口を使っています。

### 🛡️ Gatekeeperとは？
Appleが用意している**安全でないアプリの実行を防ぐ機能**です。信頼できる開発者が署名していないアプリを起動しようとすると警告を出します。「知らない人が作ったソフトは動かすな」と監視している門番のようなものです。

### 🦀 Rustとは？
プログラミング言語の一つです。速度が速く、発見されにくいマルウェアを作るのにも使われるようになってきています。

## 何が起きたのか

セキュリティ企業「Jamf Threat Labs（ジャムフ・スレット・ラボズ）」が、**Macを狙った新しい情報窃取マルウェア「PamStealer（パムスティーラー）」**を発見しました。

このマルウェアの特徴をひとことで言うと：

> **「本物そっくりの偽サイト・偽アプリで騙して、Macのパスワードや個人情報をまるごと盗む」**

攻撃の流れを簡単に言うと：

1. 🎭 **偽サイト**（`maccyapp[.]com`）を作り、本物のMaccyアプリ公式サイト（`maccy.app`）に見せかける
2. 📦 そこからダウンロードさせたファイルを実行させる
3. 🔑 **パスワードを入力させて盗む**
4. 📤 ブラウザの保存データや暗号資産のウォレット情報なども**外部サーバーに送信**する

---

## 技術的な詳細

### ステップ1：偽サイトからの感染

攻撃者は `maccyapp[.]com` という**本物にそっくりな偽サイト**を用意しました（本物は `maccy.app`）。URLの微妙な違いに気づかないユーザーが偽サイトにアクセスし、マルウェアをダウンロードしてしまいます。

---

### ステップ2：偽アプリの実行（2段階攻撃）

ダウンロードされるのは「**ディスクイメージ（.dmgファイル）**」と呼ばれる形式のファイルで、中に「**Maccy.scpt**」というAppleScriptファイルが入っています。

> 📝 **AppleScriptとは？** Macの操作を自動化できるスクリプト言語です。「Script Editor（スクリプトエディタ）」というMac標準アプリで開けます。

このスクリプトファイルを開くと、**「⌘+Rを押して実行してください」という指示が表示**されます。これはユーザーに自分でマルウェアを起動させる**ソーシャルエンジニアリング（人の心理を利用した騙し）**の手口です。

さらに巧妙なのは、**悪意のあるコードがファイルの下のほうに大量の空白行で隠されている**こと。スクロールしないと見えない位置に隠してあります。

---

### ステップ3：環境チェックで「自分が解析されていないか」を確認

スクリプトは実行前に、**今動いている環境が本当の攻撃対象かどうか**を厳密に確認します。

| チェック内容 | 目的 |
|---|---|
| CPUがApple Silicon（M1/M2/M3チップ）かどうか | Intelチップ（古いMac）では意図的に失敗させる |
| タイムゾーン・言語・キーボード設定 | 東ヨーロッパ（ロシア、ウクライナなど）のPCでは動かない |
| サンドボックス環境かどうか | セキュリティ研究者の解析環境では動かない |

> 🤔 **なぜ東ヨーロッパ除外？** マルウェアの作者が「自国のユーザーを攻撃しない」ようにしている、または「自分たちがいる地域で誤って動かないようにする」ためと考えられています。これはロシア語圏のサイバー犯罪グループによくある手法です。

---

### ステップ4：本体マルウェアのダウンロードと実行

チェックをパスすると、外部サーバーから**Rust製の本体マルウェア**がダウンロードされます。このマルウェアは「Finder（ファインダー）」という**Macの標準ファイル管理アプリに偽装**しています。

盗む情報の一覧：

| 盗む情報 | 説明 |
|---|---|
| Webブラウザの保存データ | パスワード・Cookie・履歴など |
| 暗号資産ウォレットの拡張機能 | ビットコインなどの仮想通貨情報 |
| iCloud Keychain | Appleのパスワード管理機能に保存されたデータ |
| クリップボードの内容 | 直近にコピーしたテキストなど |

---

### ステップ5：パスワードを絶対に盗む仕組み

これが今回最も巧妙な部分です。

1. **偽のパスワード入力ダイアログ**を表示して、MacのログインパスワードをＵーザーに入力させる
2. **PAM APIを使って「本当に正しいパスワードか」をその場で確認**する
3. もし間違いなら「もう一度入力してください」と繰り返す
4. **正しいパスワードを入力するまでループする**

これは例えて言うと、「**偽の銀行窓口で、本当の暗証番号を確認するまでATMを解放しない**」ようなイメージです。

---

### ステップ6：盗み終わったら証拠隠滅

パスワードを盗んだ後、マルウェアは本物のmacOSが出すメッセージにそっくりな**偽のエラーメッセージ**を表示します：

> *「Maccy is damaged and can't be opened. You should move it to the Trash.」*
> （Maccyは壊れているため開けません。ゴミ箱に移動してください）

これは本物のGatekeeperエラーに見せかけた**偽メッセージ**です。ユーザーは「ダウンロードに失敗したんだな」と思ってアプリをゴミ箱に捨てますが、**その時点ですでにマルウェアは実行・情報窃取・自動起動の登録（パーシスタンス）まで完了**しています。

盗んだデータは `avenger-sync[.]live` というサーバーに暗号化して送信されます。

## なぜ重要なのか

### 😨 Macの「安全神話」が崩れている
「MacはWindowsよりウイルスに強い」という認識は過去のものになりつつあります。今回のPamStealerは、Appleのセキュリティ機能（Gatekeeper）を**正面突破**しています。

### 🎯 非常に高度な回避技術
- セキュリティ研究者の解析環境では動かない
- GatekeeperやTerminalの制限を回避
- Rustという発見されにくい言語で作られている
- パスワードを「確認してから盗む」という新しい手口

### 💰 被害が広範囲に及ぶ
ブラウザのパスワード、暗号資産、iCloudのデータなど、**デジタル生活のほぼすべてが盗まれる可能性**があります。

## 対策・今後の展望

### ✅ 今すぐできる対策

| 対策 | 説明 |
|---|---|
| 📌 **公式サイトのURLを必ず確認する** | `maccy.app` と `maccyapp.com` は全くの別物！ |
| 🚫 **「⌘+Rで実行して」と指示するファイルは疑う** | 正規のアプリはこんな操作を求めない |
| 🔍 **ダウンロード前にURLをよく確認** | 1文字違いの偽サイトに注意 |
| 🔐 **パスワードマネージャーを使う** | 万が一のときの被害を限定できる |
| 🛡️ **macOSを常に最新にアップデートする** | Appleは定期的にセキュリティパッチを出している |
| 🧩 **知らないアプリを「フルアクセス許可」しない** | システム設定で確認を求められたら立ち止まって考える |

### 🔮 今後の展望
- Appleは今後もGatekeeperを強化していくと思われますが、攻撃者もそれをかいくぐる手口を開発し続けています
- **Macを狙うマルウェアは今後さらに増加する**と予測されており、「Macだから安全」という考え方は捨てる必要があります

## 過去記事との関連

今回は参照できる過去記事はありませんが、**MacやApple製品を狙った情報窃取マルウェア**は近年急増しています。特に暗号資産（仮想通貨）ユーザーを狙ったマルウェアのトレンドは世界的に拡大しており、PamStealerもその流れの一つです。今後もmacOSを狙った攻撃ニュースが増えていく可能性が高いため、引き続き注目していきましょう。

## 用語解説

| 用語 | 解説 |
|---|---|
| **マルウェア** | 悪意を持って作られたソフトウェアの総称。ウイルスも含む |
| **インフォスティーラー** | 個人情報や認証情報を盗み出すマルウェアの一種 |
| **AppleScript / .scpt** | Macの操作を自動化するためのスクリプト言語とそのファイル形式 |
| **PAM（プラガブル認証モジュール）** | macOSがパスワードなどの認証を処理する仕組み |
| **Gatekeeper** | Appleの安全でないアプリの実行を防ぐセキュリティ機能 |
| **ディスクイメージ（.dmg）** | Macでよく使われるインストール用ファイル形式。CD-ROMのような仮想ディスク |
| **Rust** | 高速で安全なプログラミング言語。最近マルウェア作成にも使われる |
| **ソーシャルエンジニアリング** | 人の心理や行動を利用して情報を盗む手口 |
| **iCloud Keychain** | Appleのパスワード管理機能。サイトのパスワードなどを保存できる |
| **パーシスタンス（persistence）** | マルウェアがMacを再起動しても自動で起動するよう設定すること |
| **サンドボックス** | プログラムを隔離された安全な環境で動かす仕組み。解析に使われることが多い |
| **Mach-Oバイナリ** | macOS用の実行可能ファイルの形式（WindowsでいうEXEファイルに相当） |
| **JXA（JavaScript for Automation）** | MacをJavaScriptで操作・自動化できるAppleの機能 |
| **エクスフィルトレーション** | 盗んだデータを外部サーバーに送信すること |

> 💡 **まとめ**：PamStealerは「偽サイト→偽アプリ→パスワードを正しいか確認しながら盗む→証拠隠滅」という非常に巧妙な手口を持つMac向けマルウェアです。「MacはWindowsより安全」という思い込みを捨て、**ダウンロードするファイルのURLと出所を必ず確認する**習慣をつけることが何より大切です！
