# ランサムウェアグループが新たな脆弱性・正規ツール悪用・サプライチェーン侵害を組み合わせて攻撃

**元記事**: [Ransomware Groups Turn to Citrix Bleed 2, BYOVD, and Supply Chain Credentials](https://inl03.netline.com/ltr6/?_m=3n.009a.4020.sp0ao46r89.32p6)
**解説日**: 2026年7月4日

---

## 背景知識

このニュースを理解するために、いくつかの基本的な概念を先に説明します。

### ランサムウェアって何？
「ランサム（身代金）」＋「ウェア（ソフトウェア）」を組み合わせた言葉です。  
コンピュータ内のファイルを**暗号化（鍵をかけて読めなく）して、「お金を払えばファイルを返す」と脅迫するマルウェア（悪意あるプログラム）**のことです。病院や工場などが狙われると、業務が完全に止まってしまうため、非常に危険です。

### RaaS（ランサムウェア・アズ・ア・サービス）って何？
ランサムウェアを「サービス」として売り出す仕組みです。  
例えるなら、**「フランチャイズのお店」**のようなイメージです。本部（開発者）がランサムウェアを作り、加盟店（アフィリエイト＝実際に攻撃する人）が実行して、得た身代金を山分けします。今回の「Anubis」は加盟店に**80%** を渡す好条件を提示していました。

### Citrix NetScaler ADC/Gateway って何？
大企業や組織が使う**ネットワーク機器（ルーターの高機能版のようなもの）**です。  
社外から社内ネットワークに安全に接続する「入口」の役割を果たします。銀行や病院など多くの重要組織が使っているため、ここに脆弱性があると被害が広がりやすいです。

### VPN って何？
「Virtual Private Network（仮想プライベートネットワーク）」の略で、**インターネット上に"専用の安全なトンネル"を作って通信する仕組み**です。テレワークで会社のシステムに接続するときによく使われます。

## 何が起きたのか

セキュリティ企業「Arctic Wolf」が調査レポートを発表し、**「Anubis（アヌビス）」というランサムウェアグループ**が新しい脆弱性を悪用して企業・組織への侵入を繰り返していることが明らかになりました。

### Anubis グループとは？
- 2024年末に「Sphinx」というグループの名前を変えて登場
- 2025年2月に地下フォーラム（犯罪者が集まるダークウェブ上の掲示板）で正式に活動を宣言
- **これまでに91の組織**が被害を受けたと主張（2026年6月だけで11件！）
- 被害者の50%以上がアメリカ企業・組織。次いでイギリス、オーストラリア、フランス、カナダ

### 狙われている業種
| 業種 | なぜ狙われやすいか |
|------|------------------|
| 医療・病院 | データが止まると命に関わるため、すぐ払いやすい |
| ビジネスサービス | 機密データが多い |
| 製造業 | 生産ラインが止まると損失が膨大 |
| テクノロジー | 知的財産が狙い目 |
| 金融サービス | 金融データの価値が高い |

## 技術的な詳細

攻撃の流れを、**泥棒が建物に侵入するプロセス**に例えながら説明します。

### STEP 1｜建物への侵入（初期アクセス）

攻撃者は2つの方法で最初の侵入口を見つけます。

#### 方法①：Citrix Bleed 2（CVE-2025-5777）の悪用
- **危険度スコア：9.3/10**（非常に高危険）
- Citrix NetScaler ADC/Gatewayという機器に存在する**認証をすり抜けられる欠陥**
- 例えるなら、**「建物の鍵が特定の方法で操作すると開いてしまう」**ようなバグです
- 本来はIDとパスワードが必要なのに、それをバイパス（スキップ）できてしまいます

#### 方法②：盗んだVPN認証情報の利用
- 正規のCisco AnyConnect VPNに、**盗み取ったIDとパスワードで正規ユーザーのふりをして**ログイン
- 情報の入手経路：
  - 過去の別の侵害事件で流出したデータ
  - **IAB（Initial Access Broker）**：侵入済みの企業アクセス権を売買するブローカー（仲介業者）
  - クレデンシャルスタッフィング（大量のID/PW組み合わせを試す自動攻撃）
  - インフォスティーラー（パスワードを盗むマルウェア）

### STEP 2｜建物内を移動する（横展開）

侵入後、攻撃者は**RDP（リモートデスクトップ）**や**PsExec**（Windowsの管理ツール）を使って、社内の別のコンピューターへどんどん侵入していきます。  
例えるなら、**「1つの部屋に入ったら、マスターキーを使って他の部屋も次々と開けていく」**イメージです。

### STEP 3｜正規ツールに変装して居座る（持続的アクセス）

ここが特に巧妙なポイントです。攻撃者は**本来は正規のIT管理ツール**を悪用します。

| 悪用されたツール | 本来の用途 |
|----------------|-----------|
| ScreenConnect | リモートサポートツール |
| Zoho Assist | リモートアクセス管理 |
| MeshAgent | デバイス管理 |
| UltraVNC | リモートデスクトップ |

これらは**普段のIT業務でも使われる正規ソフト**なので、セキュリティソフトに検知されにくいのです。  
例えるなら、**泥棒が警備員の制服を着て堂々と歩き回っているようなもの**です。

さらに「**Cloudflare Tunnel（クラウドフレアトンネル）**」という正規のサービスを悪用して、攻撃者との秘密の通信路を作ります。

### STEP 4｜パスワードをさらに収集する（資格情報アクセス）

社内に深く入り込んだ後、**より権限の強いアカウントのパスワード**を集めていきます。管理者権限を手に入れれば、何でもできてしまいます。

### STEP 5｜データを盗み出す（情報窃取）

以下のツールを使ってデータをクラウドや外部へ送り出します：

- **S3 Browser / s5cmd**：Amazon S3クラウドストレージへのアップロード
- **rclone / WinSCP**：ファイル転送ツール
- **PuTTY**：リモート接続ツール

### STEP 6｜証拠隠滅と防御の無効化

- **Windows Defenderのリアルタイム保護を無効化**（ウイルス対策を止める）
- **Sophosというセキュリティ製品をアンインストール**
- **ログ（操作記録）を削除・改ざん**して証拠を消す

### STEP 7｜最後の一撃：WIPEMODEとランサムウェア展開

そして最終段階で、2つの恐ろしい機能が使われます：

1. **ランサムウェアでファイルを暗号化** → 身代金を要求
2. **WIPEMODEモジュール** → これが特に悪質！

> 💀 **WIPEMODEとは？**  
> ファイルを暗号化するだけでなく、**ファイルサイズを0KBにしてしまう（完全に中身を消す）機能**。  
> しかも怖いのが、**「身代金を払っても元に戻らない」**という点。「今すぐ払わないと全部消すぞ」という究極の脅迫ツールです。

## なぜ重要なのか

### 被害の深刻さ
- 病院が狙われれば**患者の命に関わる**
- 製造業が狙われれば**工場が止まり多大な経済損失**
- WIPEMODEにより、**身代金を払っても助からない**ケースがある

### 検知が非常に難しい
正規ツールを使うため、**「これは攻撃だ」と判断するのが難しい**。セキュリティ担当者でも見逃しやすいのが現状です。

### 日本も無関係ではない
記事ではアメリカ中心と書かれていますが、グローバルに活動するグループであり、**日本の企業・病院・インフラ企業も潜在的なターゲット**です。

## 対策・今後の展望

### 今すぐできる対策

#### 🔧 システム管理者向け
1. **Citrix NetScalerのパッチ（修正プログラム）を即時適用する**  
   CVE-2025-5777は危険度9.3の重大脆弱性。すでにパッチが提供されているはずなので、早急に更新を。

2. **VPN認証に多要素認証（MFA）を導入する**  
   パスワードが漏れても、スマホへの確認コードがないとログインできない仕組みを作る。

3. **ログ監視を強化する**  
   不審なRMMツールの起動や、大量のファイル転送を検知する仕組みを整える。

4. **定期的なバックアップ（オフライン保存）**  
   WIPEMODEに備え、**ネットに繋がっていないバックアップ**を複数保持する。

#### 🏠 一般ユーザー向け
1. **パスワードを使い回さない**  
   1つのサービスで漏れたパスワードが他サービスへの侵入に使われる（クレデンシャルスタッフィング対策）

2. **不審なソフトをインストールしない**  
   インフォスティーラーはフリーソフトに潜んでいることがある

3. **OSやソフトを最新状態に保つ**

### 今後の動向
Anubisのような**RaaSモデルは今後さらに増加**すると予想されます。身代金の80%という好条件が参加者を集め、攻撃の規模が拡大していく危険性があります。また、WIPEMODEのような「払っても助からない」機能が増えることで、**被害者の絶望感を利用した脅迫が巧妙化**していくでしょう。

## 過去記事との関連

以前「**PamStealer（パムスティーラー）**」について解説しました。これはMacのログインパスワードを盗むマルウェアでしたが、今回の記事と深く繋がっています。

Anubisグループが使う**「VPNの認証情報（ID/パスワード）」の入手経路の一つが「インフォスティーラー（情報窃取マルウェア）」**です。PamStealerのようなパスワードを盗むマルウェアが、最終的にランサムウェア攻撃の**"鍵"として使われる**という流れがあります。

> 🔗 つまり「パスワードを盗む小さなマルウェア感染」→「盗んだ情報がダークウェブで売買される」→「ランサムウェアグループが購入・利用」→「大規模侵害」という**一連のサイバー犯罪エコシステム**が動いているのです。

## 用語解説

| 用語 | 解説 |
|------|------|
| **ランサムウェア** | ファイルを暗号化して身代金を要求するマルウェア |
| **RaaS（ランサムウェア・アズ・ア・サービス）** | ランサムウェアをフランチャイズ形式で運営するビジネスモデル |
| **アフィリエイト** | RaaSの"加盟店"。実際に攻撃を実行する人たち |
| **CVE（シーブイイー）** | 脆弱性に付けられる識別番号。数字が高いほど危険 |
| **CVSSスコア** | 脆弱性の危険度を0〜10で示す点数 |
| **IAB（Initial Access Broker）** | 企業への侵入アクセス権を売買するダークウェブ上の業者 |
| **クレデンシャルスタッフィング** | 漏洩したID/PW一覧を使って大量ログイン試行する攻撃 |
| **インフォスティーラー** | パスワードや個人情報を盗む専用マルウェア |
| **RMM（リモートモニタリング＆マネジメント）** | IT管理者がPCをリモートで管理するツール群 |
| **RDP（リモートデスクトップ）** | 別のPCを遠隔操作する仕組み（Windows標準機能） |
| **PsExec** | Windowsで別のPCにコマンドを実行させる管理ツール |
| **横展開（ラテラルムーブメント）** | 最初の侵入後、社内の他のPCへ次々と侵入していく行動 |
| **Cloudflare Tunnel** | 正規のトンネリングサービス。攻撃者に悪用されることも |
| **WIPEMODE** | ファイルを0KBにして復元不可能にするAnubis独自の脅迫機能 |
| **多要素認証（MFA）** | パスワード以外にもう一段階の認証（スマホ確認など）を追加する仕組み |
| **パッチ** | ソフトウェアの欠陥を修正するプログラム（更新プログラム） |

> ⚠️ **まとめると…**  
> Anubisランサムウェアグループは、新しい脆弱性・盗んだパスワード・正規ツールの悪用・完全データ消去の脅しを組み合わせた**非常に巧妙で執拗な攻撃**を行っています。「自分には関係ない」ではなく、**パスワード管理とソフトウェア更新**から始める習慣が、こうした攻撃の連鎖を断ち切る第一歩になります。
