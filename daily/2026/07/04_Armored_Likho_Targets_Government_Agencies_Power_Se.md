# 「武装したLikho」が政府機関・電力会社を狙う！BusySnakeという情報泥棒マルウェアが発見される

**元記事**: [Armored Likho Targets Government Agencies, Power Sector with BusySnake Stealer](https://inl03.netline.com/ltr6/?_m=3n.009a.4021.sp0ao46r89.32r2)
**解説日**: 2026年7月8日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を押さえておきましょう。

### 🏛️ サイバースパイとは？
国家や重要インフラ（電力・水道・交通など）を狙って、機密情報を盗み出すことを目的としたハッキング活動です。泥棒が金庫を開けてお金を盗む代わりに、コンピュータに侵入して「情報」を盗んでいくイメージです。

### 🐍 マルウェアとは？
「悪意のあるソフトウェア」のことです。ウイルスやスパイウェアなど、コンピュータに害を与えるプログラム全般を指します。

### 📧 スピアフィッシングとは？
普通のフィッシング詐欺は「不特定多数」に偽メールを送りますが、スピアフィッシングは**特定の組織や人物**を狙い打ちにした、非常に巧妙な偽メールです。「政府からの公式通知」など、信用させやすい内容を使います。

### 🎯 RAT（遠隔操作ツール）とは？
Remote Access Trojan（リモートアクセス型トロイの木馬）の略です。感染したコンピュータを、攻撃者がまるで自分のパソコンのように遠くから操作できるようにする悪意あるプログラムです。

---

## 何が起きたのか

セキュリティ会社の**カスペルスキー**が、「**Armored Likho（武装したリコ）**」という今まで知られていなかった新しいハッカー集団を発見・分析しました。

このグループは以下の国の重要施設を狙っています：

| 標的の国 | 標的の組織 |
|----------|----------|
| 🇷🇺 ロシア | 政府機関・電力会社 |
| 🇧🇷 ブラジル | 政府機関・電力会社 |
| 🇰🇿 カザフスタン | 政府機関・電力会社 |

このグループの特徴は**二刀流**であることです：
- 💰 **一般の人を狙ったお金目的の攻撃**
- 🕵️ **組織を狙ったスパイ活動**

という両方の目的を持っている、非常に厄介な存在です。

また、「**BusySnake（忙しいヘビ）**」という新しい情報窃取マルウェアも今回初めて発見されました。

## 技術的な詳細

### 🎣 攻撃の入口：スピアフィッシングメール

攻撃はまず**偽メール**から始まります。

```
「政府からの公式通知です」
「社会保障プログラムについてのお知らせ」
```

このような、いかにも本物っぽいメールに**RARファイル（圧縮ファイル）**が添付されています。ファイルを解凍すると、中に悪意あるプログラムが入っています。

### 🪜 攻撃の流れ（ステップバイステップ）

```
【Step 1】偽メールを受信
      ↓
【Step 2】添付の圧縮ファイルを開く
      ↓
【Step 3】中のEXEファイル（実行ファイル）を実行
      ↓
【Step 4】GitHubから追加の悪意あるプログラムを自動ダウンロード
      ↓
【Step 5】BusySnakeが起動・インストール完了
      ↓
【Step 6】攻撃者のサーバーに接続して命令を受け取る
```

> **GitHubって普通のサービスでは？**
> そうです！GitHubは本来、プログラマーがコードを共有する正規のサービスです。攻撃者はこういった**信頼されているサービスを悪用**することで、セキュリティソフトの検知をかわします。

### 🔓 脆弱性（CVE-2025-9491）の悪用

別の攻撃パターンでは、**Windowsのショートカットファイル（.lnkファイル）の欠陥**を利用します。

- `.lnkファイル`とは：デスクトップにある「ショートカット」のこと
- この欠陥は**2017年から少なくとも12のハッカー集団に悪用されていた**という衝撃的な事実も判明
- Microsoftは2025年11月のアップデートで修正済み

**つまり、Windowsを最新の状態にしていない人は今でも危険な状態です！**

### 🐍 BusySnakeの機能一覧

BusySnakeはPythonというプログラム言語で作られた情報窃取ツールで、以下のことができます：

| 機能 | 具体的な被害 |
|------|------------|
| 📋 クリップボード監視 | コピーしたパスワードや文章を盗む |
| 📁 ファイル一覧収集 | どんなファイルがあるか把握される |
| 📤 ドキュメント送信 | 重要書類を攻撃者に送られる |
| 🍪 ブラウザのクッキー窃取 | ログイン情報やセッション情報が盗まれる |

> **クッキー（Cookie）って何？**
> ウェブサイトがあなたのブラウザに保存する小さなデータです。「ログインしたまま」の状態を保つために使われますが、これを盗まれると**パスワードなしでもアカウントにログインされてしまいます**。

### 🥷 見つかりにくくする工夫

このマルウェアは非常に巧妙で、セキュリティソフトに検知されないよう複数の仕掛けがあります：

- **難読化**：プログラムコードをわざと読みにくくして分析を困難に
- **証拠隠滅**：最初に実行されたファイルの痕跡を自動削除
- **タスクスケジューラ悪用**：Windowsの正規機能を使って定期的に起動し、削除されにくくする
- **おとり文書の表示**：怪しまれないよう、本物っぽい文書を表示しながら裏で動作

## なぜ重要なのか

### ⚡ 電力インフラへの脅威

電力会社が攻撃されると、最悪の場合**大規模停電**が引き起こされる可能性があります。過去にウクライナでは実際にサイバー攻撃が原因で停電が発生しています。

### 🌍 複数の国が標的

ロシア・ブラジル・カザフスタンという地理的にバラバラな国が標的になっており、**特定の政治的目的**を持った組織である可能性が高いです。

### 🕰️ 長年にわたる活動

関連するとみられる「Eagle Werewolf（鷲狼人間）」グループは**2023年5月から活動中**で、ドローン関連の組織なども標的にしています。2026年2月には、ドローン情報を扱うTelegramチャンネルを乗っ取ってマルウェアを配布した事例も確認されています。

## 対策・今後の展望

### ✅ 今すぐできる対策

**🔄 OSを最新にアップデートする**
今回悪用されたWindowsの脆弱性（CVE-2025-9491）は、2025年11月のアップデートで修正されています。**Windowsの自動更新をオンにしておきましょう。**

**📧 怪しいメールの添付ファイルを開かない**
「政府からのお知らせ」「社会保障の通知」など、急かすような内容のメールには特に注意。添付ファイルを開く前に、送信元を慎重に確認しましょう。

**🔑 パスワードマネージャーを使う**
クリップボードにパスワードをコピーする機会を減らすことで、情報窃取のリスクを下げられます。

**🛡️ セキュリティソフトを導入・更新する**
信頼できるセキュリティソフトを常に最新の状態に保ちましょう。

**🌐 ブラウザのセッション管理に注意**
使い終わったウェブサービスは**ちゃんとログアウト**する習慣をつけましょう。クッキーを盗まれても、ログアウト済みなら悪用されにくくなります。

### 🔭 今後の動向

Armored Likhoの正確な素性（どの国の組織なのかなど）はまだ不明です。カスペルスキーをはじめとしたセキュリティ企業が引き続き追跡・分析を行っています。

## 過去記事との関連

以前、**北朝鮮のハッカーが「PolinRider作戦」で108個の悪意あるパッケージを公開した**というニュースを解説しました。

今回の記事と共通しているのは、**「信頼できる場所・サービスを悪用する」**という手口です。

- PolinRider作戦：正規のパッケージ配布サービスに悪意あるコードを紛れ込ませた
- Armored Likho：正規のGitHubやTelegramを悪用してマルウェアを配布した

このように、ハッカー集団は**私たちが普段使っている信頼できるサービスを踏み台にする**という手口を多用しています。「有名なサービスだから安全」という思い込みは危険です。

## 用語解説

| 用語 | 意味 |
|------|------|
| **脅威アクター** | 悪意を持って攻撃を行うハッカー個人やグループのこと |
| **RAT** | Remote Access Trojan。感染したPCを遠隔操作するマルウェア |
| **インフォスティーラー** | 情報窃取型マルウェア。パスワードやファイルを盗み出す |
| **難読化（オブファスケーション）** | プログラムコードを意図的に読みにくくして解析を妨げること |
| **C2サーバー** | Command & Control Server（命令と制御のサーバー）。攻撃者がマルウェアに命令を送るための拠点 |
| **ドロッパー** | 他のマルウェアをダウンロード・インストールするための「運び屋」プログラム |
| **SSHトンネル** | 暗号化された通信経路。攻撃者がこれを使うと通信内容が見えにくくなる |
| **スケジュールタスク** | Windowsが特定の時間に自動でプログラムを実行する機能。マルウェアの永続化に悪用される |
| **CVE** | Common Vulnerabilities and Exposures。発見されたセキュリティの欠陥につけられる識別番号 |
| **LNKファイル** | Windowsのショートカットファイル（.lnk拡張子）。今回の攻撃で脆弱性が悪用された |
| **Cookie（クッキー）** | ウェブサイトがブラウザに保存する小さなデータ。ログイン状態の維持などに使われる |
| **VBScript** | Windowsで動作するスクリプト言語。マルウェアの実行や痕跡消去に悪用された |
