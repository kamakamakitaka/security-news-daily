# 北朝鮮に繋がるnpmパッケージが開発ツールに偽装して開発者の秘密情報を盗もうとしている

**元記事**: [North Korea-Linked npm Packages Mimic Rollup Polyfills to Steal Developer Secrets](https://inl03.netline.com/ltr6/?_m=3n.009a.4021.sp0ao46r89.32qw)
**解説日**: 2026年7月

---

## 背景知識

まず、このニュースを理解するために必要な言葉をいくつか説明します。

### 🧰 npmって何？
**npm（Node Package Manager）** は、プログラマーが使う「便利な道具の倉庫」のようなものです。JavaScriptというプログラミング言語で開発するとき、「誰かが作ってくれた便利な部品（パッケージ）」をここからダウンロードして自分のプログラムに組み込めます。世界中の開発者が日常的に使っており、現在200万個以上のパッケージが公開されています。

### 🔧 Rollup・Polyfillって何？
- **Rollup**：JavaScriptのファイルをまとめて整理するツール（本の原稿を製本するようなイメージ）
- **Polyfill（ポリフィル）**：古いブラウザや環境でも最新の機能が使えるようにする「互換性パッチ」のこと

つまり **Rollup polyfill** とは、開発者がよく使う「信頼性の高い定番ツール」のひとつです。

### 🦠 悪意あるパッケージ（マルウェア入りパッケージ）とは？
本物そっくりの偽物のパッケージをnpmに登録しておき、開発者がうっかりインストールしてしまうのを待ちます。インストールされると、パソコンの中でこっそり悪いプログラムが動き出します。まるで「本物の薬に見せかけた毒薬」のようなものです。

## 何が起きたのか

セキュリティ企業の **JFrog** が調査したところ、**北朝鮮と繋がりのある攻撃グループ**が、npmに偽物のパッケージを登録して開発者を騙そうとしていることが発覚しました。

### 発見された偽物パッケージ（計6個）

| パッケージ名 | 役割 |
|---|---|
| `rollup-packages-polyfill-core` | 第1段階の偽物（入口） |
| `rollup-runtime-polyfill-core` | 第1段階の偽物（入口） |
| `swift-parse-stream` | 第2段階の悪意あるコード |
| `quirky-token` | 第2段階の悪意あるコード |
| `react-icon-svgs` | 偽のSVGユーティリティ |
| `rollup-plugin-polyfill-connect` | 第2段階の悪意あるコード |

これらはすでにnpmから削除されていますが、**インストールしてしまった開発者の端末は危険な状態**の可能性があります。

## 技術的な詳細

### 🎭 Step 1：本物そっくりに偽装する

本物のパッケージ名は `rollup-plugin-polyfill-node` ですが、偽物は `rollup-packages-polyfill-core` や `rollup-runtime-polyfill-core` という名前を使っています。

- パッケージの説明文 → 本物とほぼ同じ
- リポジトリの情報 → 本物に見せかける
- 名前の構成（rollup・polyfill・core・node）→ 本物と似た単語を並べる

**素早くチェックするだけでは本物と区別がつかない**のがポイントです。

### 🪆 Step 2：入れ子構造で悪意あるコードを隠す

ロシアの「マトリョーシカ人形」のように、パッケージの中にパッケージが入っています。

```
rollup-packages-polyfill-core（偽の入口）
  └─ swift-parse-stream（第2段階）
       └─ JSONKeeperからJavaScriptコードを取得 → 実行！
```

このような「多段階構造」にすることで、セキュリティチェックをくぐり抜けやすくしています。

### 🔍 Step 3：監視されていないか確認する

悪意あるコードは動き出す前に、次のような環境かどうかを確認します：

- クラウドの開発環境（本物の開発者の端末ではない）
- サンドボックス（ウイルス検査用の隔離環境）
- セキュリティ分析ツール

**「監視されていない」と判断したときだけ本番の攻撃を開始**します。まるで泥棒が「見張りがいないか確認してから行動する」ようなものです。

### 💀 Step 4：実際の攻撃内容

外部のサーバー（`216.126.236[.]244`）から暗号化された攻撃コードをダウンロードして実行します。できることは：

| 機能 | 内容 |
|---|---|
| リモートアクセス | 攻撃者が遠隔からパソコンを操作 |
| 画面キャプチャ | 今の画面を撮影して送信 |
| キーボード操作 | キーを押す・クリックする |
| ブラウザ情報の盗難 | 保存されたパスワードなど |
| 暗号資産ウォレットの盗難 | 仮想通貨を盗む |
| ファイル収集 | 特定の拡張子のファイルを盗む |
| クリップボード監視 | コピーした内容を定期的に盗む |

### 🎯 特に狙われているもの

開発者が使うツールの設定ファイルや認証情報が標的です：

- **VS Code / Windsurf / Cursor**（コードエディタの履歴）
- **AWS / Microsoft Azure / Google Gemini**（クラウドサービスの認証キー）
- **Anthropic Claude / Foundry**（AIツールの設定）
- **SSH / Zshの設定**（サーバーへのアクセスキー）

## なぜ重要なのか

### 👨‍💻 開発者の環境は「宝の山」
開発者のパソコンには、普通のユーザーと比べて非常に多くの機密情報があります：

- **ソースコード**（会社の製品・サービスそのもの）
- **npmトークン**（パッケージを公開・更新する権限）
- **Gitの認証情報**（コードの履歴や管理システムへのアクセス）
- **クラウドのAPIキー**（AWS・Azureなどへの接続情報）

開発者1人が感染すると、その会社全体・さらにはそのツールを使う多くの人に被害が広がる可能性があります。

### 🌍 国家レベルの攻撃
このキャンペーンは北朝鮮の **Lazarusグループ**（または関連グループ）に紐づいていると分析されています。これは趣味のハッカーではなく、**国が支援するプロの攻撃集団**です。資金調達や情報収集を目的とした、組織的で継続的な活動です。

## 対策・今後の展望

### ✅ 開発者ができる具体的な対策

1. **パッケージ名を慎重に確認する**
   - `rollup-plugin-polyfill-node`（本物）
   - `rollup-packages-polyfill-core`（偽物）
   - 似ているけど違う！インストール前に必ず公式サイトで確認を

2. **ダウンロード数・更新日・作者を確認する**
   - 本物の定番パッケージは通常ダウンロード数が多い
   - 作られたばかりで使用数が少ないパッケージは要注意

3. **`npm install`の前にパッケージを調査する**
   - JFrog XRay、Socket.devなどのツールで安全性をチェック

4. **最小権限の原則を守る**
   - 開発環境のAPIキーには必要最低限の権限だけ与える

5. **CIパイプラインにセキュリティスキャンを組み込む**
   - 自動的に怪しいパッケージを検出する仕組みを入れる

## 用語解説

| 用語 | 説明 |
|---|---|
| **npm** | JavaScriptの「部品ライブラリ」のようなサービス。開発者が便利なツールをダウンロードできる |
| **パッケージ** | npmに登録されている「プログラムの部品」のこと |
| **Rollup** | JavaScriptファイルをまとめる開発ツール |
| **Polyfill** | 古い環境でも新機能が使えるようにする互換性パッチ |
| **マルウェア** | 悪意を持って作られた不正なプログラム |
| **リモートアクセス** | 攻撃者がインターネット越しに被害者のパソコンを操作すること |
| **サンドボックス** | ウイルスを安全に調べるための隔離された仮想環境 |
| **Lazarusグループ** | 北朝鮮政府と繋がりがあるとされるハッカー集団 |
| **OtterCookie / BeaverTail** | 北朝鮮系グループが使うマルウェアの名前 |
| **APIキー** | クラウドサービスなどにアクセスするためのパスワードのようなもの |
| **クリップボード** | Ctrl+Cでコピーしたときに内容が一時保存される場所 |
| **Base64** | データを別の文字列に変換してわかりにくくするエンコード方式 |
| **CI（継続的インテグレーション）** | コードの変更を自動的にテスト・確認する仕組み |
