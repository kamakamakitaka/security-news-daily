# 数百万台の組み込み機器に使われているファイルシステムに未修正の欠陥が発覚

**元記事**: [Unpatched Flaws Disclosed in Filesystem Bundled Into Millions of Embedded Devices](https://inl03.netline.com/ltr6/?_m=3n.009a.4021.sp0ao46r89.32q2)
**解説日**: 2025年7月

---

## 背景知識

このニュースを理解するために、いくつかの基本的な概念を説明します。

### 📦 「組み込み機器（Embedded Device）」とは？
スマートフォンやパソコンのような「汎用コンピュータ」とは違い、特定の目的だけのために作られた機器のことです。たとえば：
- 防犯カメラ
- ドローン（無人航空機）
- 工場の制御装置
- ATM（現金自動預け払い機）
- 仮想通貨のハードウェアウォレット（物理的な財布型の機器）

これらの機器は小さなコンピュータが内蔵されており、専用のプログラム（**ファームウェア**）で動いています。

### 💾 「FAT・exFAT」って何？
USBメモリやSDカードにデータを保存するときの「整理方法（形式）」です。図書館でいえば「本の並べ方のルール」のようなもの。WindowsのパソコンでUSBを使うとき、ほぼ必ずこの形式が使われています。

### 📚 「ライブラリ」とは？
プログラマーが「よく使う機能をあらかじめまとめたプログラム部品集」です。料理でいえば「市販の合わせ調味料」みたいなもの。自分でイチから作らなくて済むので、多くの製品で使い回されます。今回問題になった **FatFs（ファットエフエス）** もそういう部品集のひとつです。

### 🔓 「脆弱性（ぜいじゃくせい）」とは？
プログラムの「欠陥・バグ」の中でも、攻撃者に悪用される可能性があるものを指します。建物でいえば「鍵のかかっていない窓」のようなイメージです。

---

## 何が起きたのか

セキュリティ企業 **runZero（ランゼロ）** が、**FatFs** というプログラムライブラリに **7つの脆弱性** を発見・公開しました。

FatFsは「USBメモリやSDカードのデータを読み書きする機能」を提供するプログラムで、世界中の無数の機器に組み込まれています。

> 🔑 **ポイント**: 問題は「FatFs一つ」にとどまらず、それを使っている**数百万台の機器すべてに影響する**ということです。

### 深刻な点

- **7つの脆弱性のうち6つは現在も修正されていない**
- FatFsを管理しているのは**たった1人の開発者**で、連絡が取れない状態
- 修正の通知を受け取る仕組み（メーリングリストなど）が存在しない
- 攻撃に使えるサンプルコード（**PoC**）がすでにネット上に公開されている

---

## 技術的な詳細

### 🎯 攻撃の仕組み（基本）

7つの脆弱性はすべて同じような仕組みで動作します：

```
① 攻撃者が「細工した」USBメモリ・SDカード・アップデートファイルを用意する
        ↓
② 機器がそのファイルを読み込もうとする
        ↓
③ FatFsが「おかしなデータ」をうまく処理できずに誤動作する
        ↓
④ メモリが壊される、または攻撃者のプログラムが実行される
```

### 📋 7つの脆弱性の一覧

深刻度は **CVSS（シーブイエスエス）スコア** という数値で示します（10点満点で点数が高いほど危険）。

| CVE番号 | 深刻度 | スコア | 内容 |
|--------|--------|--------|------|
| CVE-2026-6682 | 🔴 高 | 7.6 | FAT32の読み込み時に計算ミスが起き、メモリ破壊・勝手なプログラム実行が可能 |
| CVE-2026-6687 | 🔴 高 | 7.6 | exFATのボリュームラベル（名前）が長すぎるとメモリが壊れる |
| CVE-2026-6688 | 🔴 高 | 7.6 | 長いファイル名でメモリが壊れる |
| CVE-2026-6685 | 🟡 中 | 6.1 | データの計算ミスでデータが静かに壊れる |
| CVE-2026-6683 | 🟡 中 | 4.6 | exFATのゼロ割り算でクラッシュ・最悪起動不能に |
| CVE-2026-6686 | 🟡 中 | 4.6 | 削除したはずのデータが漏れる |
| CVE-2026-6684 | 🟡 中 | 4.6 | ディスクの地図（パーティションテーブル）がおかしいと機器がフリーズ ※唯一修正済み |

### 🔢 最も危険な脆弱性を具体的に説明（CVE-2026-6682）

**「整数オーバーフロー」** という問題が原因です。

> 🎒 **例え話**: 電卓で「99999999 + 1」を計算したとき、桁が足りなくて「0」になってしまう現象に似ています。

細工されたUSBを挿すと：
1. FatFsがファイルのサイズを計算するとき、計算結果が「桁あふれ」を起こす
2. 実際よりずっと小さい（または大きい）サイズだと勘違いする
3. その誤った数値を使って読み込みを行うので、**本来触ってはいけないメモリ領域を書き換えてしまう**
4. 攻撃者はこれを利用して、自分のプログラムを機器で動かせる

### 🏠 なぜ組み込み機器は特に危ないのか

スマホやPCには「**メモリ保護機能**」があり、プログラムが勝手に他の領域を触れないようになっています。しかし多くの組み込み機器にはこの保護が**ない**ため、メモリが壊れたときのダメージがより大きくなります。

runZeroは「**物理的なアクセスがあれば機器を乗っ取れる**」と表現しています。

## なぜ重要なのか

### 🌐 影響を受ける機器・プラットフォームの例

以下の有名な開発プラットフォームがFatFsを使っています：

- **Espressif ESP-IDF**（スマート家電などに使われるマイコン）
- **STM32Cube**（工場の機械などに使われる）
- **Zephyr / MicroPython / Mbed**（IoT機器向けOS・環境）
- **ArduPilot**（ドローンの制御ソフト）
- **Samsung TizenRT**（サムスンのIoT向けOS）

### ⚠️ 具体的にどんな場面が危ないか

| 場面 | 危険のシナリオ |
|------|---------------|
| 公共のATM | USBポートに細工したUSBを挿すだけで乗っ取り |
| 選挙の投票機 | USBで不正プログラムを実行 |
| 防犯カメラ | SDカードを差し替えて制御を奪う |
| ドローン | ファームウェア更新ファイルを細工してハイジャック |
| 仮想通貨ウォレット | 物理アクセスで資産を盗む |

### 🚨 「修正されていない」ことの深刻さ

通常、脆弱性が発見されたら：
1. 発見者 → 開発者に連絡
2. 開発者が修正版をリリース
3. 各製品メーカーが修正版を取り込む

しかし今回は**ステップ1が機能しませんでした**。開発者と連絡が取れず、日本の **JPCERT/CC（ジェーピーサート）**（サイバーセキュリティの調整機関）を通じた連絡も無反応。

結果として、6つの重大な脆弱性が**修正なしで公開**される事態になりました。

## 対策・今後の展望

### 🛠️ 機器を作る開発者・メーカーへの対策

1. **自分の製品にFatFsが含まれているか確認する**（ファームウェアの中身を調べる）
2. FatFsを最新版（R0.16）に更新する（GPTフリーズ問題のみ修正される）
3. FatFsを呼び出す周辺のコード（ラッパーコード）を安全に書き直す
4. ファイル名やファイルサイズの扱いを特に注意して見直す

### 🔒 機器を使う一般ユーザー・管理者への対策

- **知らない人がUSBやSDカードを機器に挿せないようにする**
- ATMやキオスク端末などは物理的なポートへのアクセスを制限する
- メーカーからのファームウェア更新を注意して待つ
- **不審なUSBメモリは絶対に使わない**（これは普段からの基本！）

### 🔮 今後の展望

- 2025年7月1日時点でこの脆弱性を使った攻撃の報告はまだない
- しかし攻撃サンプルが**すでに公開されている**ため、今後悪用される可能性がある
- 各メーカーが個別に修正パッチを作る必要があるが、対応速度はメーカーによりまちまち
- FatFsのメンテナンス体制の改善が業界全体の課題となっている

## 用語解説

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **FatFs** | ファットエフエス | FAT/exFAT形式のファイルを読み書きするための小型プログラムライブラリ |
| **ファームウェア** | - | 機器に組み込まれた基本プログラム。機器の「脳みそ」 |
| **脆弱性** | ぜいじゃくせい | プログラムの欠陥で、攻撃者に悪用される可能性があるもの |
| **CVE** | シーブイイー | 脆弱性に割り当てられる世界共通の識別番号 |
| **CVSS** | シーブイエスエス | 脆弱性の深刻度を0〜10点で示すスコア |
| **整数オーバーフロー** | - | 数値の計算結果が扱える範囲を超えて、おかしな値になるバグ |
| **メモリ破壊** | - | プログラムが本来触れないメモリ領域を書き換えてしまうこと |
| **PoC（概念実証コード）** | ピーオーシー | 「この攻撃は実際に可能だ」と証明するためのサンプルコード |
| **IoT** | アイオーティー | インターネットにつながった家電・機器の総称（Internet of Things） |
| **JPCERT/CC** | ジェーピーサート | 日本のサイバーセキュリティ調整機関 |
| **ラッパーコード** | - | 既存のプログラムを包んで使いやすくするための追加コード |
| **パーティションテーブル** | - | ディスクの「区画の地図」。どこに何のデータがあるかを記録したもの |
| **exFAT** | イーエックスファット | FAT形式の拡張版。大きなファイルも扱えるUSB・SDカード向けの形式 |
