# 「Bad Epoll」— 普通のユーザーがLinuxの管理者権限を乗っ取れる新たな欠陥が発見

**元記事**: [New "Bad Epoll" Linux Kernel Flaw Lets Unprivileged Users Gain Root, Hits Android](https://inl03.netline.com/ltr6/?_m=3n.009a.4022.sp0ao46r89.32sg)
**解説日**: 2026年7月7日

---

## 背景知識

まず、このニュースを理解するためのキーワードをおさらいしましょう。

### 🐧 Linuxとは？
Windowsと並ぶ有名なOS（オペレーティングシステム）の一つです。サーバー（インターネットの裏側で動くコンピューター）や、Androidスマートフォン、スーパーコンピューターなど、世界中のインフラを支えています。

### 🫀 カーネルとは？
OSの「心臓部」です。ハードウェア（CPU・メモリなど）とアプリケーションの橋渡しをする、最も重要なプログラムです。カーネルに欠陥があると、コンピューター全体に影響が及びます。

### 👑 rootとは？
Linuxにおける「最高権限を持つ管理者アカウント」のことです。rootになれると、システム上のあらゆることができてしまいます。ファイルの削除、ウイルスの埋め込み、パスワードの盗取など、何でも可能です。

### 🪲 権限昇格（Privilege Escalation）とは？
「一般ユーザー」として入り込んだ攻撃者が、何らかの欠陥を使って「管理者（root）」にまで権限を上げてしまうことです。泥棒が一般客として店に入り、こっそり倉庫の鍵まで手に入れてしまうようなイメージです。

---

## 何が起きたのか

セキュリティ研究者の **Jaeyoung Chung** 氏が、Linuxカーネルに存在する深刻な脆弱性（セキュリティ上の欠陥）を発見しました。

この脆弱性は **「Bad Epoll（バッド・イーポール）」** と名付けられ、**CVE-2026-46242** という識別番号が付与されています。

### 🔑 ポイントをひとことで言うと…
> **「普通のユーザー権限しか持っていない人でも、この欠陥を使えば管理者（root）になれてしまう」**

影響を受けるのは以下の環境です：

| 対象 | 影響 |
|------|------|
| Linuxデスクトップ | ✅ 影響あり |
| Linuxサーバー | ✅ 影響あり |
| Android（特定機種） | ✅ 影響あり |
| 古いAndroid（Pixel 8等） | ❌ 影響なし（カーネルバージョンが古いため） |

幸い、すでに**修正パッチ（バグを直すプログラム）は公開されています**。

## 技術的な詳細

### 🔍 そもそも「epoll」って何？

**epoll（イーポール）** とは、Linuxの機能の一つで、「複数のファイルやネットワーク接続を同時に監視する」仕組みです。ウェブサーバーやブラウザなど、ほぼすべてのサーバーソフトウェアが使っています。スイッチのようにオフにすることができないため、影響を回避するための「迂回策」がありません。

### 🐛 バグの仕組み：「ユーズ・アフター・フリー（Use-After-Free）」

このバグは **「Use-After-Free（UAF）」** と呼ばれる種類の欠陥です。

> **わかりやすい例え話**
> 
> 図書館で本の返却係が2人いるとします。  
> Aさんが「この本はもう棚に戻したよ」と言いながらまさに棚に戻す瞬間、  
> Bさんが「じゃあ廃棄しよう」と同時にその本を捨てようとする。  
> その**一瞬のすれ違い**で、棚の状態が壊れてしまう——これがUse-After-Freeです。

技術的には：
1. カーネル内部の2つの処理が、**同じメモリ領域を同時にクリーンアップしようとする**
2. 一方がメモリを解放している間に、もう一方がそこに書き込む
3. この**一瞬の衝突**を利用してメモリを壊す
4. その壊れたメモリを踏み台に、一般ユーザーからrootへ権限を昇格させる

### ⏱️ 「タイミング勝負」の攻撃だが、ほぼ確実に成功する

この種のバグは「レースコンディション（競合状態）」とも呼ばれ、**絶妙なタイミングでしか発動しない**のが普通です。

- 衝突が起きる時間は、わずか**6命令分（コンピューターが6つの計算をする間）** という極めて短い時間
- 普通にやると、ほぼ偶然に頼るしかない
- **しかし**、Chung氏はその「窓」を人工的に広げる技術を開発し、**成功率約99%** で攻撃を再現することに成功しました

### 🛡️ さらに怖いのは「Chrome sandbox を突破できる可能性」

通常、Chromeブラウザは**サンドボックス（隔離された安全な箱）** の中で動作しており、他のカーネル欠陥のほとんどはそこから外に出られません。ところがBad Epollは、そのサンドボックスの中からでも攻撃できる可能性があると言われています。

## なぜ重要なのか

### 📱 Androidにも影響する珍しい脆弱性

多くのLinuxの権限昇格バグはAndroidには影響しませんが、**Bad EpollはAndroidにも到達できる**点が特に危険です。世界中で使われるAndroidスマートフォンに影響する可能性があります。

### 🤖 AIが見つけた「兄弟バグ」を人間が追いかけて発見

非常に興味深いことに、このバグには「兄弟」がいます：

- 2023年に `epoll` のコードに変更が加えられた
- その変更に**2つの欠陥**が含まれていた
- **1つ目の欠陥（CVE-2026-43074）** は、Anthropic社（ChatGPTのライバルとも言えるAI企業）の最新AIモデル「**Mythos**」が発見
- **2つ目の欠陥（Bad Epoll）** は、同じコードを見ていたにもかかわらず、AIが見落とし、**人間の研究者が発見**

### 🤔 なぜAIは2つ目を見落としたのか？

Chung氏は2つの理由を挙げています：

1. **タイミングの窓が非常に狭い** → コードを見ているだけでは「ここで同時に何かが起きる」とイメージしにくい
2. **実行時の証拠が残りにくい** → 1つ目のバグが修正された後、2つ目は通常のバグ検出ツール（KASAN）にも引っかからないため、「問題ない」と誤認されやすい

これはAIの限界を示すと同時に、**「AIと人間の研究者が協力する重要性」** を示す事例でもあります。

### 📋 現時点では実際の攻撃被害はなし

- CISAの「既知の悪用された脆弱性リスト」には未掲載
- 公開されているのは研究用のPoCコード（攻撃の仕組みを証明するためのコード）のみ
- Androidへの攻撃コードはまだ開発中の段階

## 対策・今後の展望

### ✅ 今すぐできる対策

> **「迂回策はない」** — epollは無効にできないため、修正パッチを適用するしかありません。

| 環境 | 対策 |
|------|------|
| **Linuxサーバー・デスクトップ** | カーネルのアップデートを適用（コミット `a6dc643c6931`）|
| **各Linuxディストリビューション（UbuntuなどLinuxの種類）** | 各ディストリビューションのアップデートが提供され次第、速やかに適用 |
| **Android（カーネル6.4以降）** | セキュリティアップデートを待って適用 |
| **古いAndroid（Pixel 8など カーネル6.1ベース）** | このバグの影響なし（ただし他のバグの対策は引き続き必要） |

### 🔮 今後の展望

- Androidへの攻撃コードは現在も開発中のため、今後公開される可能性がある
- AIによるバグ探索はますます進化しているが、今回のケースが示すように**人間の目も依然として不可欠**
- 2026年は「Linuxカーネルの欠陥が多く発見される年」になりつつある

## 用語解説

| 用語 | 説明 |
|------|------|
| **カーネル** | OSの心臓部。ハードウェアとソフトウェアをつなぐ最重要プログラム |
| **root** | Linuxの最高権限管理者アカウント。何でもできてしまう |
| **権限昇格** | 一般ユーザーが管理者権限を不正に取得すること |
| **epoll** | 複数の接続を同時監視するLinuxの機能。無効化できない |
| **Use-After-Free（UAF）** | 解放済みのメモリに別の処理が書き込んでしまう欠陥の種類 |
| **レースコンディション** | 2つの処理が競い合うタイミングの微妙なズレで発生するバグ |
| **CVE** | 脆弱性に付けられる世界共通の識別番号（例：CVE-2026-46242）|
| **PoC（Proof of Concept）** | 「この脆弱性は本当に悪用できる」と証明するためのサンプルコード |
| **サンドボックス** | プログラムを外部から隔離して動かす安全な「箱」 |
| **KASAN** | Linuxカーネルのメモリエラーを検出するデバッグツール |
| **CISA** | アメリカのサイバーセキュリティ機関。危険な脆弱性リストを管理 |
| **パッチ** | バグや脆弱性を修正するための追加プログラム |
| **ゼロデイ** | まだ修正パッチがない状態で公開・発見された脆弱性 |

> 💡 **まとめると…**
> 「Bad Epoll」は、LinuxとAndroidに影響する危険な脆弱性です。悪用されると、一般ユーザーがシステムの全権限を乗っ取れてしまいます。幸い修正パッチは出ているので、**Linuxを使っている人はすぐにアップデートを！** スマートフォンも、セキュリティアップデートが来たら速やかに適用しましょう。
