# Javaで作られた新型マルウェア「QuimaRAT」— Windows・Mac・Linuxすべてを狙う

**元記事**: [New Java-Based QuimaRAT MaaS Built to Run on Windows, Linux, and macOS](https://inl03.netline.com/ltr6/?_m=3n.009a.4022.sp0ao46r89.32rs)
**解説日**: 2025年7月8日

---

## 背景知識

まず、いくつかの重要なキーワードを押さえておきましょう。

### 🖥️ OSって何？
**OS（オペレーティングシステム）** とは、パソコンを動かす基本ソフトのことです。WindowsやMac（macOS）、Linuxが代表例です。普通、ウイルスやマルウェアは「Windowsだけに感染する」「Macには効かない」といったように、**特定のOSにしか対応していない**ことが多いです。

### 🐛 RATって何？
**RAT（Remote Access Trojan）＝リモートアクセス型トロイの木馬** とは、感染したパソコンを**遠くから勝手に操作できるようにする悪意あるソフトウェア**のことです。ギリシャ神話の「トロイの木馬」のように、無害に見せかけて侵入します。攻撃者はRATを使うことで、ファイルを盗んだり、カメラを起動したり、キーボードの入力を記録したりできます。

### 💰 MaaS（Malware as a Service）って何？
**MaaS（マルウェア・アズ・ア・サービス）** とは、まるでNetflixやSpotifyのように、**マルウェアを月額課金で「サービス」として提供する悪のビジネスモデル**です。サイバー犯罪の知識が少ない人でも、お金さえ払えば強力な攻撃ツールを使えてしまうため、非常に危険です。

### ☕ Javaって？
**Java** はプログラミング言語の一つで、最大の特徴は「**一度書けばどのOSでも動く（Write Once, Run Anywhere）**」という点です。この特徴が悪用されると、1つのマルウェアでWindows・Mac・Linuxすべてを同時に狙えてしまいます。

## 技術的な詳細

### 🧩 4つのツールセット

このQuimaスイート（道具のセット）には、以下の4つのツールが含まれています：

#### 1️⃣ Quima Control（QuimaRAT本体）
感染したパソコンを遠隔操作するメインのツールです。
- **Windows用モジュール**: 74種類
- **Mac・Linux用モジュール**: 46種類

「モジュール」とは**機能の追加パーツ**のこと。あとから機能を足したり外したりできる、非常に柔軟な設計です。

#### 2️⃣ Quima Builder
マルウェアを様々な形式のファイルに変換するツールです。
- `.exe`（Windowsの実行ファイル）
- `.app`（Macのアプリ）
- `.sh`、`.bat`（スクリプトファイル）
- `.docm`、`.xlsm`（Wordや**Excelのマクロ付きファイル**）

> 💡 **例え話**: 同じ内容の本を、日本語版・英語版・中国語版と様々な形で出版するイメージです。

#### 3️⃣ Quima Loader（特に巧妙！）
これが特に危険な仕組みです。ブラウザのキャッシュ（一時保存領域）を悪用してマルウェアを届けます。

**感染の流れ：**

```
①攻撃者が罠のリンクを作成
        ↓
②被害者がリンクをクリック
        ↓
③ブラウザに「偽のCAPTCHA認証」や「ソフトウェア更新」の
　偽ページが表示される
        ↓
④裏でマルウェアがブラウザのキャッシュに保存される
        ↓
⑤「ダウンロードボタン」が出てきてクリックさせる
        ↓
⑥小さな「クリーンな起動ファイル」がダウンロードされる
（ウイルス対策ソフトに引っかかりにくい）
        ↓
⑦起動ファイルがキャッシュに隠れたマルウェアを読み込む
        ↓
⑧Windowsのセキュリティ機能(SmartScreen)を
　回避しながら本体が実行される！
```

> 💡 **例え話**: 不審な荷物を直接送らず、一度コンビニのロッカーに預けて、別の人が受け取りに行くようなイメージです。

#### 4️⃣ Quima Dropper
HTMLやSVGファイル（Webページで使うファイル）を使って、マルウェアを仕込むツールです。

---

### 🔧 マルウェアの賢い仕組み

**① 1台に1つしか動かない**
感染後、同じマルウェアが二重起動しないよう「鍵ファイル（ロックファイル）」を作ります。これにより、挙動が不審になって発見されるリスクを減らしています。

**② プラグインで機能を追加できる**
Javaのプラグイン（機能拡張パーツ）を**暗号化した状態で遠隔から追加・削除・更新**できます。まるでスマホアプリのアップデートのように、攻撃者がいつでも機能を強化できます。

**③ OSの深い部分まで操作できる**
「JNA（Java Native Access）」という技術を使い、Javaでありながらパソコンの低レベルな操作（OSの内部機能）まで実行できます。

**④ 完全に隠れて動く（Windowsの場合）**
画面上にウィンドウやアイコンなど、**ユーザーに見える要素が一切表示されません**。動いていることに気づきにくい設計になっています。

## なぜ重要なのか

### 🌍 「全OS対応」は非常に珍しく危険
従来のマルウェアの多くはWindowsだけを狙っていました。「Macは安全」「Linuxは大丈夫」という認識が一般的でしたが、QuimaRATは**3つのOSすべてを同じツールで狙えます**。

### 🛒 技術知識ゼロでも使える
MaaSモデルにより、プログラミングを知らない人でも購入して使えます。これは**サイバー犯罪の「民主化」**とも言える現象で、攻撃者の数が爆発的に増える可能性があります。

### 🎭 ウイルス対策ソフトをすり抜ける設計
製作者自身が「AVには何も異常に見えない。ユーザーにもわからない」と宣伝しています。既存のセキュリティ対策をすり抜けることを前提に設計されています。

### 🏢 企業・個人問わず被害の可能性
Linuxはサーバーに多く使われています。企業のサーバーが感染すれば、大規模な情報漏洩につながる恐れがあります。

## 対策・今後の展望

### ✅ 今すぐできる対策

| 対策 | 理由 |
|------|------|
| 不審なリンクをクリックしない | Quima Loaderは偽ページへの誘導が起点 |
| 知らないファイルを実行しない | .exe・.sh・.batなどの実行ファイルに注意 |
| Wordや**Excelのマクロを安易に有効にしない** | .docm・.xlsmファイルによる感染経路がある |
| OSとソフトウェアを常に最新に保つ | セキュリティパッチで既知の脆弱性を塞ぐ |
| 信頼できるセキュリティソフトを使う | 完全ではないが検知の可能性を高める |
| 「本物そっくりの偽ページ」に注意 | 偽CAPTCHA・偽ソフトウェア更新に騙されない |

### 🔮 今後の展望
- セキュリティ各社がQuimaRATの検知パターンを更新していく見込みです
- MaaSモデルの拡大により、類似ツールが今後も登場する可能性が高いです
- 「Macは安全」という神話がさらに崩れていく時代になっています

## 過去記事との関連

以前、**「TrojPix攻撃」**（ビデオケーブルの電波漏れで、インターネット未接続のPCからデータを盗む手法）について解説しました。

今回のQuimaRATと合わせて考えると、現代のサイバー攻撃には大きく2つの方向性があることがわかります：

- **QuimaRAT**: ネットに繋がったPCを、ソフトウェアで直接・遠隔操作して情報を盗む
- **TrojPix**: ネットに繋がっていないPCを、物理的な電磁波を使って間接的に攻撃する

「ネットに繋がっていれば危ない」も「繋がっていないから安全」も、**どちらも通用しない時代**になっているということです。攻撃者は常に新しい手口を開発しており、私たちのセキュリティ意識も継続的にアップデートしていく必要があります。

## 用語解説

| 用語 | 意味 |
|------|------|
| **RAT (Remote Access Trojan)** | 感染したPCを遠隔操作する悪意あるプログラム |
| **MaaS (Malware as a Service)** | マルウェアを月額課金などで販売・提供するビジネスモデル |
| **Java** | どのOSでも動くプログラミング言語。「一度書けばどこでも動く」が特徴 |
| **モジュール** | プログラムに後から追加・削除できる機能パーツ |
| **C2 (Command & Control)** | 攻撃者がマルウェアに命令を送るための「指令サーバー」 |
| **SmartScreen** | Windowsに内蔵された、悪意あるファイルやWebサイトをブロックするセキュリティ機能 |
| **キャッシュ** | ブラウザがWebページのデータを一時的に保存しておく場所 |
| **プラグイン** | 既存のソフトに機能を追加するための拡張パーツ |
| **トロイの木馬** | 無害なファイルに偽装して侵入するマルウェアの総称 |
| **JNA (Java Native Access)** | JavaからOSの深い機能（低レベルAPI）を直接呼び出す技術 |
| **CAPTCHA** | 「人間かロボットかを確認する認証」。偽サイトに悪用されることがある |
| **マクロ** | WordやExcelに組み込める自動操作スクリプト。悪用されることがある |
