# Opera GXの欠陥：悪意あるサイトが勝手にMODをインストールしてデータを盗める問題が発覚

**元記事**: [Opera GX Flaw Let Malicious Sites Auto-Install Mods to Steal Data From Visited Pages](https://inl03.netline.com/ltr6/?_m=3n.009a.4022.sp0ao46r89.32ry)
**解説日**: 2025年7月7日

---

## 背景知識

まず、このニュースを理解するためのキーワードをおさらいしましょう。

### 🎮 Opera GXとは？
ゲーマー向けにカスタマイズされた **Webブラウザ** です。普通のOpera（ウェブを見るためのソフト）のゲーム特化版で、CPUやメモリの使用量を制限したり、ゲームのリリース情報を確認できたりします。Chromeや Firefoxと同じ「ブラウザ」の仲間です。

### 🎨 GX MODとは？
Opera GXには「MOD（モッド）」と呼ばれる **見た目カスタマイズ機能** があります。ゲームのBGMっぽいサウンド、壁紙、テーマカラーなどをブラウザに追加できる仕組みです。`.crx`というファイル形式で配布されます。

### 🖼️ CSSとは？
**CSS（シーエスエス）** とは、Webページの「見た目（デザイン）」を決めるための言語です。文字の色やサイズ、背景画像などを指定します。プログラムのように「動作」はしませんが、**条件によって特定の画像を読み込む** ことはできます。

### 📧 XS-Leak（クロスサイトリーク）とは？
**別のWebサイトから情報をこっそり「漏らさせる」攻撃技術** のことです。直接データを盗むのではなく、「このページにこの情報があるか？」という問いへの反応の違いを観察して、情報を間接的に推測します。

---

## 何が起きたのか

セキュリティ研究者が、**ゲーマー向けブラウザ「Opera GX」に深刻な脆弱性（弱点）を発見しました。**

この脆弱性を悪用すると、攻撃者が用意した悪意あるWebページに一度アクセスするだけで、以下のことが **ユーザーが何もクリックしなくても** 自動的に起こります：

1. 🕵️ 悪意あるMODが勝手にブラウザにインストールされる
2. 🔀 ブラウザがGoogleアカウントのページに自動でリダイレクトされる
3. 📤 そのページからGmailアドレスが攻撃者のサーバーに漏れる

実際に研究者がテストしたところ、**Gmailのフルアドレスを1回のページ訪問で完全に取得できた**ことが確認されました。

Opera社はこの問題をすでに修正済みで、**Opera GX バージョン 130.0.5847.89** 以降では対策されています。また、この脆弱性が実際の攻撃に使われた証拠は見つかっていないとのことです。

---

## 技術的な詳細

### ステップ①：MODの自動インストールを悪用する

Opera GXのMODは、本来は「見た目を変えるだけ」の無害なものです。しかし問題は **インストールの仕組み** にありました。

通常、ブラウザに拡張機能を追加しようとすると「許可しますか？」という確認ダイアログが出ます。しかしOpera GXのMODは、**確認なしに自動でインストールされる仕組み** になっていました。

悪意あるページは、ページの中に **見えない隠しフレーム（iframe）** を仕込み、そこから悪意あるMODファイル（`.crx`）を静かにインストールさせます。ユーザーに気づかれないように、です。

> 🏠 **たとえるなら**：家に来た宅配業者が「確認なしで勝手に荷物を置いていく」ようなイメージです。普通は「受け取りますか？」と聞くはずなのに、それがなかった。

唯一のサインは、アドレスバーの下に「MODが追加されました」という小さなバーが表示されるだけ。それも気づかないうちに消えてしまいます。

---

### ステップ②：インストールされたMODがCSSを「全サイト」に適用する

通常、Webページに注入されたCSSは **そのページだけ** に影響します。しかし、Opera GXのMODのCSSは **ブラウザで開くすべてのページに適用されます**。

研究者はこれを **「ユニバーサルCSSインジェクション（注入）」** と呼んでいます。

> 🎨 **たとえるなら**：通常のCSSは「1枚の壁紙を1つの部屋に貼る」ようなもの。でもMODのCSSは「家全体のすべての部屋の壁紙を一気に変えられる」ようなイメージです。

---

### ステップ③：CSSを使って文字を1文字ずつ「漏らす」

ここが最も巧妙な部分です。

CSSには「**属性セレクタ**」という機能があります。これは「もし、このHTMLの要素に〇〇という文字が含まれていたら、△△の画像を読み込む」という条件分岐ができる機能です。

```
(わかりやすく書くと)
もしメールアドレスが "a" で始まるなら → 攻撃者のサーバーから画像Aを読み込む
もしメールアドレスが "b" で始まるなら → 攻撃者のサーバーから画像Bを読み込む
...
```

攻撃者のサーバー側では、「どの画像のリクエストが来たか」を観察するだけで、**どの文字が含まれているかがわかります**。これを繰り返すことで、文字を1文字ずつ（実際には3文字ずつ）解読します。

研究者は約 **15万個のCSSルール** を詰め込んだMODを作り、Googleアカウントページ（`myaccount.google.com/contactemail`）に書かれたGmailアドレスを見事に復元しました。

> 🔍 **たとえるなら**：「あなたの誕生日は1月？2月？…」と総当たりで聞いていくイメージ。ただし自動的に超高速でやるので、一瞬で答えがわかります。

---

### 攻撃の流れ（まとめ）

```
① 被害者が悪意あるページにアクセス（クリック不要）
        ↓
② 悪意あるMODが数秒で自動インストール
        ↓
③ JavaScriptがGoogleアカウントページへ自動リダイレクト
        ↓
④ MODのCSSが全15万ルールを実行し、Gmailアドレスを1文字ずつ漏らす
        ↓
⑤ 攻撃者のサーバーにGmailアドレスが届く（ユーザーは気づかない）
```

---

### おまけ：クラッシュ攻撃も発見

研究者はもう一つ、**プライベートモード（シークレットウィンドウ）で`.crx`ファイルを読み込ませるとブラウザが強制終了し、開いている全タブが消える**という問題も発見しました。こちらは通常のOperaでも起きるとのこと（ただしOpera社の修正発表にはこの件への言及がありません）。

## なぜ重要なのか

### 🚨 被害者が「何もしなくてよい」という恐怖

通常のサイバー攻撃の多くは、「怪しいファイルをダウンロードする」「偽のリンクをクリックする」など **ユーザーが何らかのアクションを取る** ことで成立します。

しかしこの攻撃は **ページを開くだけで完結します**。知らないうちに個人情報が盗まれる可能性があります。

### 📊 Opera社の評価も「最高severity（深刻度）」

Opera社の脆弱性報告プログラム（バグバウンティ）では、この問題を **最高深刻度「P1」** と評価し、**$5,000（約75万円）の最大賞金** を研究者に支払いました。それほど重大な問題だったということです。

### 🔁 根本的な問題は以前から指摘されていた

実は、MODの「自動インストール」という仕組み自体は **2023年から問題視されていました**。当時の研究者（Renwa氏）がこれを利用した別の攻撃を報告し、Opera社はその特定の攻撃は修正しましたが、**根本原因である「自動インストール」の仕組みは残したまま**でした。今回の攻撃はその残った問題を土台にしています。

## 対策・今後の展望

### ✅ 今すぐできる対策

| 対策 | 方法 |
|------|------|
| **Opera GXをアップデートする** | ブラウザのアドレスバーに `opera://about` と入力してバージョンを確認。130.0.5847.89以上であればOK |
| **自動更新を有効にしておく** | 常に最新版を使うことで既知の脆弱性から守られる |

> ⚠️ **今回の脆弱性はすでに修正済みです。** 現在のバージョンを使っていれば心配不要です。

### 🔮 今後の展望

- Opera社は今回、MODの自動インストールそのものを見直すことになったと考えられます
- 「便利さ」と「安全性」のバランスが問われる典型的なケースで、**「確認なしの自動処理」は常にリスクを伴う**という教訓を示しています
- 今後も同様の「拡張機能・MOD系の攻撃」には注意が必要です

## 用語解説

| 用語 | 意味 |
|------|------|
| **Opera GX** | ゲーマー向けにカスタマイズされたWebブラウザ |
| **MOD（モッド）** | ブラウザの見た目を変えるカスタマイズファイル |
| **.crx ファイル** | ChromeやOpera系ブラウザの拡張機能ファイル形式 |
| **CSS（シーエスエス）** | Webページのデザイン（見た目）を決める言語 |
| **CSSインジェクション** | 悪意あるCSSをページに注入して情報を操作・盗む攻撃 |
| **属性セレクタ** | CSSで「特定の属性が〇〇の場合」という条件を書く機能 |
| **XS-Leak（クロスサイトリーク）** | 別サイトからの反応の違いを見て情報を推測する攻撃技術 |
| **iframe（アイフレーム）** | Webページの中に別のページを埋め込む仕組み |
| **バグバウンティ** | 脆弱性を発見・報告した研究者に報奨金を払う制度 |
| **P1（Priority 1）** | Operaの脆弱性評価の最高深刻度レベル |
| **CVE（シーブイイー）** | 脆弱性を世界共通で管理する番号制度（今回は未割り当て） |
| **責任ある開示** | 発見した脆弱性をすぐ公開せず、先にメーカーに報告する行動規範 |
