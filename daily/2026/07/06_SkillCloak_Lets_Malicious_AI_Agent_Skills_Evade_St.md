# SkillCloak：AIアシスタントの「スキル」を偽装してセキュリティスキャナーを騙す新手法が発見された

**元記事**: [SkillCloak Lets Malicious AI Agent Skills Evade Static Scanners with Self-Extracting Packing](https://inl03.netline.com/ltr6/?_m=3n.009a.4022.sp0ao46r89.32s4)
**解説日**: 2025年7月8日

---

## 背景知識

まず、この記事を理解するために必要な基礎知識を整理しましょう。

### 🤖 AIコーディングエージェントとは？

最近、「Claude Code」や「OpenAI Codex」など、プログラマーの代わりにコードを書いてくれるAIツールが急速に普及しています。これらは単にコードを提案するだけでなく、**あなたのパソコンの中のファイルを読み書きしたり、コマンドを実行したり**できる、非常に強力なツールです。

### 📦 「スキル（Skill）」とは？

AIエージェントは「スキル」という小さなプログラムパッケージを追加することで、新しい機能を覚えることができます。たとえば「Gitの操作方法」や「特定のフレームワークの使い方」などを教えるファイルのセットです。

> **例え話**：スマートフォンのアプリストアからアプリをダウンロードするのと似ています。ただし、このスキルはAIが「あなたのパソコンの中身にアクセスできる状態」でインストールされる点が大きな違いです。

### 🔍 スキャナーとは？

スキルをインストールする前に「危険なコードが含まれていないか」をチェックするセキュリティツールです。ウイルス対策ソフトのようなものだとイメージしてください。

---

## 何が起きたのか

香港科技大学の研究者チームが、**「SkillCloak（スキルクローク）」**という手法を開発・発表しました。

これは悪意のあるスキルを**見た目だけ無害に見せかけて、セキュリティスキャナーの検知をすり抜けさせる技術**です。

### 📊 衝撃的な結果

| 手法 | スキャナー突破率 |
|------|----------------|
| 重い偽装（自己展開型パッキング） | 8つ全スキャナーで **90%以上**、多くは **99%以上** |
| 軽い偽装（文字書き換え）| ほとんどのスキャナーで **80%以上** |

テストには実際の悪意あるスキル **1,613件**を使用しており、結果は非常に深刻です。

---

## 技術的な詳細

### 🎭 SkillCloakの2つの偽装手法

#### 手法①：軽い偽装（文字書き換え）

スキャナーは「危険なキーワードや命令文のパターン」を見つけると警告を出します。そこで、

- `o`（英語のo）を`о`（ロシア語のо）に置き換える（見た目は同じ！）
- 危険なコマンドを途中で改行して2行に分ける

このように**見た目だけ変えても、実際のコンピュータは同じように実行してしまう**のです。

> **例え話**：「爆弾」という単語を「爆　弾」と空白を入れて書いても、読んだ人には同じ意味で伝わりますよね。スキャナーは「爆弾」という完全な単語しか検索しないので引っかからない、というイメージです。

#### 手法②：重い偽装（自己展開型パッキング）

こちらが最も強力な手法です。

1. 悪意あるコード本体を、スキャナーがスキップする隠しフォルダ（`.git/`など）の中に隠す
2. 表面上は「無害なデコーダー（解凍プログラム）」だけが見えている
3. AIエージェントが実際に動かした**その瞬間に**、隠されたコードが展開・実行される

> **例え話**：税関検査（スキャナー）では、箱の中に「使い方の説明書（無害）」しか入っていないように見えるが、実は説明書の中に「組み立て方」が書いてあり、それを読んだ人が初めて武器を作れる状態になる、というイメージです。

### 🛡️ 対抗策として開発された「SkillDetonate」

同じ研究チームが、偽装されたスキルも検知できる新ツール「**SkillDetonate**」も開発しました。

スキャナーが「ファイルの見た目」をチェックするのに対して、SkillDetonateは**「実際にどんな動きをするか」**を観察します。

- 専用の隔離環境（サンドボックス）でスキルを実際に動かす
- OS（オペレーティングシステム）レベルで「何のファイルを読んだか」「どこにデータを送ったか」を監視する
- 暗号化やBase64エンコードで情報が隠されていても、**データの流れを追うことで検知**できる

#### 検知精度

| 場面 | 検知率 |
|------|--------|
| 偽装されたスキル（制御環境） | **97%** 検知（誤検知はわずか2%）|
| 実際の悪意あるスキル | **87%** 検知 |

## なぜ重要なのか

### 😨 AIエージェントは強い権限を持っている

悪意あるスキルがインストールされると、AIエージェントの権限を使って以下が可能になります：

- 💀 **パスワードや認証情報の盗難**
- 💀 **ソースコード（プログラムの設計図）の流出**
- 💀 **バックドア（裏口）の設置**（後から何度でも侵入できる穴）

### 😰 公開マーケットプレイスに審査がほとんどない

「ClawHub」などの公開スキルマーケットには、**見知らぬ人が審査なしでスキルをアップロード**できます。これは野放しのアプリストアのようなものです。

### 🌍 すでに実際の被害が起きている

記事によれば、これは仮定の話ではなく、**すでに悪意あるスキルが公開マーケットに大量に存在**しており、現行のスキャナーでは検知できていない状態です。以前の別の研究では、偽スキルが**数万のAIエージェントに届いた**ことも報告されています。

## 対策・今後の展望

### ✅ 今すぐできる対策

1. **知らない人が作ったスキルを安易にインストールしない**
   　→ アプリと同じで、信頼できる開発者のものだけを使う
2. **スキルが求める権限を確認する**
   　→ 「なぜこのスキルがパスワードフォルダにアクセスする必要があるの？」と疑問を持つ習慣を
3. **AIエージェントに与える権限を最小限にする**
   　→ 必要最低限のフォルダやファイルだけアクセスできるように設定する

### 🔮 今後の展望

- **SkillDetonate**のような「動作ベースの検査」が次世代の防御として期待されている
- ただし、スキャン時間が「数秒→数分」になるため、速度改善が課題
- この研究はまだ**査読前（プレプリント）**であり、今後さらに精査される予定

## 用語解説

| 用語 | 意味 |
|------|------|
| **AIエージェント** | 人間の代わりに自律的にタスクをこなすAIプログラム。コードを書いたりファイルを操作したりできる |
| **スキル（Skill）** | AIエージェントに新機能を追加する小さなプログラムパッケージ |
| **スキャナー** | インストール前にファイルを検査して危険なコードを検出するセキュリティツール |
| **パッキング（Packing）** | 中身を圧縮・隠蔽して、スキャナーに見えないようにする技術 |
| **サンドボックス** | 本物の環境に影響を与えないように、隔離された安全な実行環境 |
| **バックドア** | 正規の手続きを経ずに侵入できる裏口プログラム |
| **Base64** | データを別の文字列に変換するエンコード方式。見た目を無害に見せるために使われることがある |
| **プレプリント** | 学術論文の査読（専門家による審査）が完了する前の段階の論文 |
| **静的スキャン** | プログラムを実際に動かさず、コードの見た目だけを検査する方法 |
| **動的解析** | プログラムを実際に動かして、その振る舞いを観察する検査方法 |

---

> 💡 **まとめ**：AIツールがどんどん便利になる一方で、その「拡張機能」が新たな攻撃の入り口になっています。スマホのアプリと同じように、「知らない人が作ったスキルはインストールしない」という基本的な意識が、これからのAI時代にも大切です。
