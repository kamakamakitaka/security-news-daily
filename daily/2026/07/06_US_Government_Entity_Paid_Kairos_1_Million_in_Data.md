# 米国の行政機関がデータ窃盗グループ「Kairos」に約1億5000万円を支払っていた件

**元記事**: [U.S. Government Entity Paid Kairos $1 Million in Data-Theft Extortion Case](https://inl03.netline.com/ltr6/?_m=3n.009a.4022.sp0ao46r89.32sa)
**解説日**: 2026年7月7日

---

## 背景知識

まず、このニュースを理解するためにいくつかの言葉を説明します。

### 💡 ランサムウェアって何？
「ランサム（Ransom）」は英語で「身代金」という意味です。ランサムウェアとは、**コンピューターに侵入して中のファイルを暗号化（鍵をかけて読めない状態）にし、「お金を払えば元に戻してやる」と脅迫するウイルス**のことです。

たとえると、泥棒が家に入って金庫の中身をガムテープでぐるぐる巻きにして「剥がしてほしければお金を払え」と言う感じです。

### 💡 今回はちょっと違う「恐喝」の手口
今回の「Kairos（カイロス）」というグループは、ファイルに鍵をかけませんでした。代わりに、**「盗んだファイルをインターネットに公開するぞ」と脅す手口**を使いました。

金庫の中身を"持ち去って"「返してほしければお金を払え、払わなければ中身をSNSにばらまく」と言う感じです。これは「**データ恐喝（Data Extortion）**」と呼ばれます。

### 💡 ビットコインって？
ビットコインは、銀行を通さずにやり取りできる「仮想通貨（暗号資産）」です。犯罪者がよく使う理由は、表面上は匿名に見えるからです。しかし実は、すべての取引記録がブロックチェーンという公開台帳に残るため、専門家が追跡できることもあります。

## 何が起きたのか

### 📋 事件の流れをわかりやすく整理！

**2025年5月ごろ**
アメリカ・オハイオ州のユニオン郡（人口約7万人の小さな行政区）が、ネットワークへの不正侵入を検知しました。

**被害の規模**
- 約45,487人の住民・職員のデータが盗まれる
- 盗まれた情報：**マイナンバーに相当する社会保障番号・銀行情報・指紋・パスポート番号**など非常に機密性の高いもの
- 盗まれたファイル数：約**160万ファイル（2テラバイト以上）**

**その後の「交渉」の流れ**

| タイミング | 出来事 |
|-----------|--------|
| 交渉開始 | Kairosが**30億円相当**（3百万ドル）を要求 |
| 郡の反論 | 「1千万円（10万ドル）しか出せない」と返答 |
| 値上げ交渉 | 郡は2550万円→4300万円と少しずつ増額 |
| Kairosの最終通告 | 「**金曜日までに1億5000万円（100万ドル）払え、払わなければ全データを公開する**」 |
| 2025年6月13日 | 郡が**約9.44ビットコイン（約1億5000万円）を支払い** |

交渉は約1か月続き、最初の提示額の**10倍**を支払う結果になりました。

## 技術的な詳細

### 🔍 Kairosの攻撃手口

```
① 郡のネットワークに侵入
      ↓
② ファイルをこっそり盗み出す（暗号化はしない）
      ↓
③ 「検察局」フォルダなど特に機密性の高いデータを見せる
      ↓
④ 「払わなければこれをネットに公開する」と脅す
      ↓
⑤ カウントダウンタイマーで心理的プレッシャーをかける
      ↓
⑥ お金を受け取る
```

**特徴的なのは「暗号化しない」こと！**
従来のランサムウェアはPCを使えなくする（鍵をかける）のが特徴でしたが、Kairosは**一切ファイルに鍵をかけていません**。それでも「データを公開する」という脅しだけで、1億5000万円を引き出すことに成功しました。

### 💰 ビットコインの追跡

セキュリティ研究者のクリシュナン氏は、支払われたビットコインの動きをブロックチェーンで追跡しました。

```
郡が支払った約9.44ビットコイン
      ↓（数時間以内）
2つに分割して複数のウォレット（財布）に転送
      ↓
仮想通貨取引所「Bybit」「OKX」
ロシア系サービス「BELQI」の口座へ
```

追跡はできても、**「誰が」受け取ったかを特定するのは難しい**のが現状です。

### 📄 「削除の証明書」は信用できる？

Kairosはお金を受け取った後、「ファイルを削除しました」という証明書を送りましたが…

> **「ファイルの名前一覧」があっても、本当に削除したかどうかはわかりません。**
> 証明書を書いたのは泥棒本人。信用できる保証はどこにもありません。

## なぜ重要なのか

### ⚠️ 3つの重要ポイント

**① 「ランサムウェア」の定義が変わりつつある**

セキュリティ会社Sophosの2025年の調査によると、**ランサムウェア攻撃のうち暗号化を使うのはもう約半分だけ**。6年間で最低の割合です。今や「ファイルを人質に取る」より「データをバラまくぞと脅す」ほうがシンプルで効果的と気づいた犯罪者が増えています。

**② 小さな行政機関が標的になりやすい**

ユニオン郡は「リソース（資金・人員）が限られた小さな郡」と自ら認めています。大企業と違い、専門のセキュリティチームを持てない行政機関は狙われやすい状況です。

**③ 支払いは「秘密」にされていた**

郡は住民に「ランサムウェア被害があった」とは伝えましたが、**1億5000万円を支払ったことは公表していませんでした**。税金で運営される公的機関がこうした支払いを秘密にすることは、住民への説明責任の観点から大きな問題です。

## 対策・今後の展望

### 🛡️ あなたの組織・身近な場所で使える対策

| 対策 | 内容 |
|------|------|
| **定期的なバックアップ** | データを別の場所にコピーしておく。ネットから切り離した場所に保存するのが理想 |
| **アクセス制限** | 必要な人だけが必要なファイルにアクセスできるよう管理する |
| **通信の監視** | 大量のデータが外部に送られていないか監視する |
| **従業員教育** | フィッシングメール（偽メール）に騙されないよう訓練する |
| **身代金を払わない方針の確立** | 払っても解決しない可能性が高く、「払う組織」として再び狙われる危険がある |

### 🔮 今後の展望

Kairosのリークサイト（盗んだデータを公開する専用サイト）は現在閉鎖されています。しかし、**2026年5月時点でもビットコインウォレットが動いていた**ことが確認されており、グループが完全に消滅したとは言えません。

また、「Silent Ransom Group」など同様の手口を使うグループが複数存在しており、この「暗号化なしのデータ恐喝」というトレンドは今後も続くと予想されます。

## 過去記事との関連

以前、**Opera GXブラウザの欠陥**（悪意あるサイトが勝手にデータを盗む問題）や**TrojPix攻撃**（ビデオケーブルの電波を悪用したデータ窃取）を解説しましたが、今回の記事も根本は同じ「**いかにしてデータを盗み出すか**」という問題です。

手口は違えど、「データを盗まれること」がどれだけ深刻な結果（今回は1億5000万円の支払い）につながるかを示す、非常にわかりやすい実例です。データを盗まれた時点で、攻撃者は強力な交渉カードを持ってしまうのです。

## 用語解説

| 用語 | 意味 |
|------|------|
| **ランサムウェア** | ファイルを暗号化して身代金を要求するウイルス |
| **データ恐喝（Data Extortion）** | 盗んだデータを公開すると脅してお金を要求する手口。暗号化は行わない |
| **ブロックチェーン** | ビットコインなどの仮想通貨の取引記録を全て公開で記録する仕組み |
| **ビットコイン** | 銀行を通さずにやり取りできる仮想通貨（暗号資産） |
| **ウォレット** | 仮想通貨を保管するデジタルの財布 |
| **Ransom-ISAC** | ランサムウェア被害に関する情報を共有・分析する専門機関 |
| **リークサイト** | 犯罪者がお金を払わない被害者のデータを公開する専用のウェブサイト |
| **暗号化** | データに鍵をかけて、正しい鍵がないと読めない状態にすること |
| **社会保障番号** | アメリカ版マイナンバー。個人を識別する重要な番号 |
| **Conti / Black Basta** | 過去に活動していた有名なランサムウェアグループ。内部チャットが流出したことで、交渉の実態が明らかになった |

---

> 💬 **まとめ一言**: 「鍵をかけなくても、盗んだデータを"ちらつかせる"だけで1億5000万円が取れる時代になった」というのが今回の教訓です。データを守ることは、お金を守ることと同じです。
