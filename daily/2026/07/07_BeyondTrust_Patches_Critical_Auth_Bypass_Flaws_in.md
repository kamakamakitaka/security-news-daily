# BeyondTrustの遠隔サポートソフトに重大な認証回避の脆弱性が発見・修正される

**元記事**: [BeyondTrust Patches Critical Auth Bypass Flaws in Remote Support and PRA](https://inl03.netline.com/ltr6/?_m=3n.009a.4023.sp0ao46r89.32t6)
**解説日**: 2025年7月14日

---

## 背景知識

このニュースを理解するために、まずいくつかの基礎知識を押さえておきましょう。

### 🏢 BeyondTrustって何をしている会社？
BeyondTrustは、企業向けの**セキュリティソフトウェア**を作っているアメリカの会社です。特に「**リモートアクセス**（遠隔操作）」の分野で有名です。

### 💻 「Remote Support（RS）」と「Privileged Remote Access（PRA）」とは？
- **Remote Support（リモートサポート）**：会社のIT担当者が、離れた場所にあるパソコンを遠隔で操作してトラブルを直すためのソフトです。例えば、社員のパソコンが壊れたとき、IT担当者が画面を操作して修理するイメージです。
- **Privileged Remote Access（特権リモートアクセス）**：「特権」とは、システムを管理する強い権限のことです。サーバーや重要なシステムに、管理者が安全に遠隔でアクセスするためのソフトです。

### 🔐 「認証」って何？
認証とは「あなたは誰ですか？」を確認する仕組みです。たとえば、スマホのパスコードやパスワードがこれにあたります。正しいパスワードを入力した人だけが中に入れます。

### ⚠️ 「脆弱性（ぜいじゃくせい）」って何？
ソフトウェアのプログラムに存在する「弱点」や「バグ」のことです。この弱点を悪用されると、悪意のある攻撃者に不正アクセスされたり、情報を盗まれたりする可能性があります。

---

## 何が起きたのか

BeyondTrustは、自社のソフトウェア「Remote Support（RS）」と「Privileged Remote Access（PRA）」に、合計**4つの深刻な脆弱性**を発見し、修正するアップデートをリリースしました。

これらの脆弱性は、悪用されると**ログインしていない攻撃者でも**システムに不正に侵入できてしまう、非常に危険なものです。

### 🆕 興味深いポイント：AIが脆弱性発見を助けた！
今回の脆弱性は、BeyondTrust社内のセキュリティ調査の中で発見されましたが、その際に**Anthropic社のAI「Claude Opus」**などの生成AIツールを活用したと発表されています。AIがセキュリティの穴を見つけるのを助けるという、最新の取り組みが行われていました。

## 技術的な詳細

4つの脆弱性を一つずつ、わかりやすく解説します。

---

### 🚨 CVE-2026-40138（深刻度スコア：9.2／10点）

| 項目 | 内容 |
|---|---|
| 対象製品 | Remote Support・Privileged Remote Access 両方 |
| 危険度 | 超高（9.2点） |
| 攻撃者の条件 | ログイン不要 |

**わかりやすく言うと…**
認証（パスワード確認）の仕組みが、データの検証をきちんとしていませんでした。

🏠 **例え話**：マンションの入口に警備員がいるのに、「ニセの身分証明書を見せたら何も確認せずに通してしまった」イメージです。しかも管理者用の部屋にも自由に入れてしまいます。

特定の認証設定が有効になっている場合にのみ悪用可能です。

---

### 🚨 CVE-2026-40139（深刻度スコア：9.2／10点）

| 項目 | 内容 |
|---|---|
| 対象製品 | Remote Support のみ |
| 危険度 | 超高（9.2点） |
| 攻撃者の条件 | ログイン不要 |

**わかりやすく言うと…**
認証リクエスト（「ログインしたい」というお願い）の処理に問題があり、認証をスキップできてしまいました。

🏠 **例え話**：「受付に何も言わずにこっそり裏口から入ったら、なぜか管理者バッジを渡してもらえた」イメージです。

こちらも特定の設定が有効な場合のみ悪用可能です。

---

### 🔶 CVE-2026-40140（深刻度スコア：8.7／10点）

| 項目 | 内容 |
|---|---|
| 対象製品 | Remote Support・Privileged Remote Access 両方 |
| 危険度 | 高（8.7点） |
| 攻撃者の条件 | ログイン不要 |

**わかりやすく言うと…**
通信の仕組みに問題があり、攻撃者が大量の不正なデータを送りつけることで、システムをダウン（停止）させることができます。これを「**DoS攻撃（サービス拒否攻撃）**」と言います。

💥 **例え話**：お店に大量の嫌がらせ電話をかけて、本当のお客さんが電話できないようにする、というイメージです。

---

### 🔷 CVE-2026-40141（深刻度スコア：8.5／10点）

| 項目 | 内容 |
|---|---|
| 対象製品 | Remote Support・Privileged Remote Access 両方 |
| 危険度 | 高（8.5点） |
| 攻撃者の条件 | **ログイン済みの一般ユーザー** |

**わかりやすく言うと…**
ウェブアプリの部品（Webコンポーネント）に入力値の検証が不十分な箇所があり、本来アクセスできないはずのデータやリソースを見ることができてしまいます。

🏫 **例え話**：学校のシステムにログインした生徒が、自分のクラスのデータしか見られないはずなのに、他のクラスや先生の成績データまで見えてしまうイメージです。

## なぜ重要なのか

### 🎯 企業の「急所」を狙われる製品
BeyondTrustのソフトは、世界中の大企業・政府機関・医療機関など、多くの重要な組織で使われています。リモートアクセスツールは、システムの深部にアクセスできる「鍵」のようなものなので、ここに脆弱性があると被害が非常に大きくなります。

### 📊 深刻度スコアについて
セキュリティの深刻度は「CVSS（シーブイエスエス）スコア」という指標で測られます。

```
0点         5点         7点         9点        10点
 ├───────────┼───────────┼───────────┼───────────┤
 低          中          高         超高       最高
                                    ↑
                              今回の主な脆弱性はここ！
```

今回の主要な脆弱性は9.2点と、ほぼ最高レベルの危険度です。

### 🌐 過去に実際に攻撃された実績がある
BeyondTrustの製品は、過去に実際にサイバー攻撃に悪用された前歴があります（詳しくは後述）。そのため、今回も早急な対応が求められています。

## 対策・今後の展望

### ✅ すぐにやるべきこと（BeyondTrust利用者向け）

修正済みバージョンへのアップデートが最優先です！

| 製品 | 脆弱なバージョン | 安全なバージョン |
|---|---|---|
| Remote Support (RS) | 25.3.2 以下 | **25.3.3 以上** ✅ |
| Privileged Remote Access (PRA) | 25.3.2 以下 | **25.3.3 以上** ✅ |

### 🛡️ 一般的なセキュリティ対策の観点から
今回のニュースから学べる大切なポイントがあります。

1. **ソフトウェアは常に最新版に保つ**：パソコンやスマホのアップデートを「後で」と後回しにしがちですが、こうした脆弱性が修正されています
2. **多要素認証（MFA）の活用**：パスワードだけでなく、スマホへの通知など複数の確認手段を使う
3. **不要なリモートアクセスを制限する**：使っていない機能は無効化することで攻撃の機会を減らせます

### 🤖 AIを活用した脆弱性発見という新潮流
今回、BeyondTrustがAIを使って自社製品の脆弱性を見つけたことも注目すべき点です。これは「**攻撃者よりも先にAIを使って弱点を見つける**」という新しいセキュリティアプローチです。今後、AIがセキュリティの世界でますます重要な役割を果たすようになるでしょう。

## 過去記事との関連

今回の記事の中で、BeyondTrustの過去の脆弱性として **CVE-2024-12356** と **CVE-2026-1731** が言及されています。

これらは過去に実際に攻撃者に悪用され、**Webシェル**（サーバーを遠隔操作するための裏口プログラム）や**バックドア**（こっそり侵入するための隠し通路）を仕込まれるという深刻な被害をもたらしました。

つまり、BeyondTrustの製品は「攻撃者から見てとても魅力的なターゲット」であることが実証されており、今回の脆弱性も放置すれば同様の被害が発生する可能性が十分にあります。記事が「素早くアップデートを適用することが不可欠」と強調しているのはこのためです。

## 用語解説

| 用語 | 読み方 | 意味 |
|---|---|---|
| **脆弱性** | ぜいじゃくせい | ソフトウェアの弱点・バグ。悪用されると攻撃に利用される |
| **認証（Authentication）** | にんしょう | 「あなたは誰ですか？」を確認する仕組み（パスワードなど） |
| **認証バイパス** | にんしょうバイパス | 認証の仕組みを迂回（スキップ）して不正アクセスすること |
| **リモートアクセス** | リモートアクセス | インターネット経由で遠隔地のコンピュータを操作すること |
| **特権（Privilege）** | とっけん | システムを管理するための強い権限・アクセス権 |
| **CVSS スコア** | シーブイエスエス | 脆弱性の危険度を0〜10点で表す国際的な指標 |
| **DoS攻撃** | ディーオーエス攻撃 | 大量のリクエストを送ってサービスをダウンさせる攻撃 |
| **Webシェル** | ウェブシェル | サーバーを遠隔操作するために仕込まれる悪意のあるプログラム |
| **バックドア** | バックドア | 攻撃者が後でひそかに侵入するために作る「裏口」 |
| **プリオーセンティケーション** | Pre-authentication | ログイン前の段階。この段階で攻撃できると特に危険 |
| **CVE** | シーブイイー | 脆弱性に付けられる世界共通の識別番号 |
| **パッチ** | パッチ | 脆弱性を修正するための更新プログラム |

> 💡 **まとめ**：BeyondTrustという企業向けセキュリティ会社のリモートアクセス製品に、ログインせずに管理者権限を奪える超危険な脆弱性が4つ発見されました。現時点では実際の攻撃は確認されていませんが、過去に同製品が狙われた前例があるため、利用している企業は今すぐバージョン25.3.3以上にアップデートすることが強く推奨されます。
