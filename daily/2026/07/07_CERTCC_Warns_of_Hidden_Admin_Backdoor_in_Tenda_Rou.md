# CERT/CCがTendaルーターのファームウェアに隠れた管理者用バックドアを警告

**元記事**: [CERT/CC Warns of Hidden Admin Backdoor in Tenda Router Firmware](https://inl03.netline.com/ltr6/?_m=3n.009a.4023.sp0ao46r89.32su)
**解説日**: 2025年7月14日

---

## 背景知識

このニュースを理解するために、まず基本的な仕組みを押さえておきましょう。

### 🏠 ルーターってなに？
ルーターとは、インターネットと家庭・会社のネットワークをつなぐ「門番」のような機器です。スマホやパソコンがインターネットを使えるのは、このルーターのおかげです。

### 🔒 ルーターの「管理画面」とは？
ルーターには、設定を変更するための「管理画面（Web管理インターフェース）」があります。ブラウザからアクセスして、パスワードを入力することで管理者だけが設定を変更できる仕組みです。家のドアに「鍵」がかかっているイメージです。

### 🚪 バックドアってなに？
バックドアとは、**正規の入口（玄関）を使わずに、こっそり裏から入るための隠し通路**のことです。

> 🔑 例え話：マンションの玄関には普通の鍵がついているけれど、管理会社だけが知っている「特殊な合言葉を言えば裏口から入れる仕組み」がこっそり仕掛けられているようなものです。

### 📦 ファームウェアってなに？
ファームウェアとは、ルーターのような機器の中で動く「組み込みソフトウェア（プログラム）」のことです。パソコンでいうOSやアプリのようなものです。

### 🏢 Tenda（テンダ）ってどんな会社？
中国のネットワーク機器メーカーで、Wi-Fiルーターなどを世界中に販売しています。価格が手頃なため、家庭や中小企業でも広く使われています。

### 🛡️ CERT/CCってなに？
CERT/CC（カーネギーメロン大学のコンピュータ緊急対応チーム）は、セキュリティの脆弱性を調査・警告するアメリカの公的機関です。日本でいう「JP-CERT」のような存在です。

---

## 何が起きたのか

Tendaという中国のルーターメーカーが販売している複数のルーターに、**誰でも管理者として侵入できる「隠し通路（バックドア）」が仕込まれていた**ことが発覚しました。

この問題は **CVE-2026-11405** というID番号で管理されており、CERT/CCが2025年7月に公式警告を発しました。

### 影響を受けるルーターの種類
以下のファームウェアが搭載されたTenda製ルーターが対象です：

| モデル名 | ファームウェアバージョン |
|---|---|
| FH1201 | V1.2.0.14 |
| W15E | V15.11.0.5 |
| AC10 | V15.03.06.46 |
| AC5 | V15.03.06.48 |
| AC6 | V15.03.06.51 |

## 技術的な詳細

### 🔍 バックドアはどこに隠されていた？

バックドアは、ルーターの中で動いている **Webサーバーのプログラム（`/bin/httpd`）** の中の **`login()` という関数（ログイン処理の部品）** に仕込まれていました。

### 🔓 どうやって侵入できるのか？

通常のログインの仕組みを図で見てみましょう：

```
【通常のログイン】
ユーザーがIDとパスワードを入力
        ↓
パスワードが正しいか確認（MD5という方式で暗号化して比較）
        ↓
正しければ → ✅ ログイン成功
間違えれば → ❌ ログイン失敗
```

ところがこのルーターでは、通常のパスワード確認に失敗したあと、**こっそり別のパスワードと照合する処理**が動いていました：

```
【バックドアのログイン】
ユーザーがIDとパスワードを入力
        ↓
通常のパスワード確認 → ❌ 失敗
        ↓
【ここが問題！】隠れたパスワードと照合
　"sys.rzadmin.password" という設定から別パスワードを取り出す
        ↓
一致すれば → ✅ 管理者として完全ログイン成功！
```

### 😱 さらに怖い点

- **ユーザー名は何でもいい！**
  `rzadmin` というユーザー名に関連しているものの、実際にはどんなユーザー名を入力しても、**隠しパスワードさえ合っていれば管理者としてログインできてしまいます**。

- **管理画面には一切表示されない！**
  この隠しパスワードや仕組みは、ルーターの設定画面のどこを見ても表示されません。つまり、ふつうのユーザーは気づくことができません。

> 🔑 例え話で整理すると…
> マンションの玄関ロックが「1234」というパスワードで開く設定になっているとします。でも実は、ドアの裏側に「合言葉：xyzzy を言えば誰でも開く」という隠し機能があって、しかもその合言葉は管理会社のマニュアルにも書かれておらず、住民は誰も知らない——というような状態です。

## なぜ重要なのか

### 🌐 影響の大きさ

| 項目 | 内容 |
|---|---|
| 影響を受ける人 | 対象ルーターを使っている全ユーザー |
| 攻撃の難しさ | **非常に簡単**（専門知識があまりなくても可能） |
| 修正パッチ | **現時点でなし（未修正）** |

### 💀 攻撃者にできること

管理者権限を乗っ取られると、以下のことが可能になります：

1. **ルーターの設定を勝手に変更する**（通信先を悪意あるサイトに誘導するなど）
2. **セキュリティ機能を無効化する**（ファイアウォールをオフにするなど）
3. **通信を盗聴する**（インターネットの内容を見られる）
4. **ルーターを完全に乗っ取る**（ボットネットの一部として悪用するなど）
5. **家庭内の他のデバイスへの攻撃の踏み台にする**

> ⚠️ ルーターは家や会社のネットワークの「入口」なので、ここを乗っ取られると、繋がっているスマホやパソコンすべてが危険にさらされます。

## 対策・今後の展望

### ✅ 今すぐできる対策

CERT/CCは以下の対策を推奨しています：

#### 1️⃣ リモート管理を無効にする
ルーターの管理画面からインターネット経由での管理（リモート管理）をオフにしましょう。
これにより、外部からのアクセスを遮断できます。

#### 2️⃣ デフォルトのLAN IPアドレスを変更する
多くのルーターは `192.168.1.1` や `192.168.0.1` といったデフォルトIPアドレスを使っています。これを別のアドレスに変えることで、自動スキャンツールに発見されにくくなります。

#### 3️⃣ 対象ルーターの買い替えを検討する
根本的な解決策はファームウェアの修正ですが、**現時点でTendaからの修正パッチは出ていません**。長期的には、修正が提供されるまで別のルーターへの乗り換えも検討してください。

#### 4️⃣ Tendaの公式情報を注視する
今後、Tendaがセキュリティアップデートを配布した場合は、**すぐに適用すること**が重要です。

### 🔮 今後の見通し

- 報告者は匿名の研究者で、Tendaへの事前通知があったかは不明
- The Hacker News（セキュリティ専門メディア）がTendaにコメントを求めているが、記事執筆時点では回答なし
- 修正パッチのリリース時期は未定

## 過去記事との関連

今回は特定の過去記事との直接的な関連はありませんが、**家庭用・中小企業向けルーターのバックドア問題は過去にも繰り返し発生しています**。

同様の事例として、過去にはTP-Link、D-Link、Netgearなどのルーターでも隠しアカウントやバックドアが発見されています。特に中国メーカーの製品では、こうした「工場出荷時から埋め込まれた隠し機能」が問題になるケースが多く、今回のTendaの件もその流れの一つとして見ることができます。

## 用語解説

| 用語 | 解説 |
|---|---|
| **バックドア（Backdoor）** | 正規の認証を迂回して不正にシステムへアクセスするための隠し機能 |
| **ファームウェア（Firmware）** | ルーターなどのハードウェア機器に組み込まれているソフトウェア |
| **CVE（Common Vulnerabilities and Exposures）** | セキュリティの脆弱性に付けられる国際的な識別番号。例：CVE-2026-11405 |
| **CERT/CC** | カーネギーメロン大学が運営するセキュリティ脆弱性の調査・警告機関 |
| **MD5** | パスワードなどを暗号化（ハッシュ化）するための計算方式の一つ |
| **管理者権限（Admin）** | システムの設定をすべて変更できる最上位の権限 |
| **リモート管理** | インターネット経由でルーターを遠隔操作できる機能 |
| **LAN IPアドレス** | 家庭や会社の内部ネットワーク内で使われるアドレス番号 |
| **ボットネット** | 攻撃者に乗っ取られた機器を大量につなげた悪意ある遠隔操作ネットワーク |
| **脆弱性（Vulnerability）** | ソフトウェアやシステムの「セキュリティ上の弱点・穴」 |
| **認証バイパス** | 本来必要なIDやパスワードの確認を飛ばして不正ログインすること |
