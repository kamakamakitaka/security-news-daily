## 背景知識

### 🏢 ガートナー（Gartner）って何？

**ガートナー**とは、世界で最も有名なIT調査・コンサルティング会社のひとつです。企業のCEOやIT部門の責任者たちが「次に何をすべきか」を判断するために参考にする、いわば **「IT業界の羅針盤」** のような存在です。

---

### 🛡️ そもそも「セキュリティテスト」って何？

コンピューターやシステムには、**脆弱性（ぜいじゃくせい）**＝弱点が存在します。

セキュリティテストとは、簡単に言うと：

> 🔑 **「泥棒（ハッカー）に入られる前に、自分たちで鍵の弱さをチェックする作業」**

家に例えると、鍵屋さんに頼んで「この鍵、本当にちゃんとかかりますか？こじ開けられませんか？」と試してもらうようなイメージです。

---

### ⚔️ 「攻撃的セキュリティテスト（Offensive Security Testing）」とは？

セキュリティには大きく2つのアプローチがあります：

| アプローチ | 説明 | 例え |
|-----------|------|------|
| **守備型（Defensive）** | 壁を作る・監視する | 家に鍵をかける、監視カメラを設置する |
| **攻撃型（Offensive）** | わざと攻撃してみて弱点を探す | 鍵師に「この鍵を開けられますか？」と試してもらう |

**攻撃的セキュリティテスト**とは、後者の「わざと攻撃側の視点でシステムを試す」手法です。

主な種類には以下があります：

- **ペネトレーションテスト（Pentest / ペンテスト）**：専門家が実際にシステムへの侵入を試みる
- **レッドチーム演習**：本格的な攻撃者をシミュレーションして組織全体の対応力を試す
- **バグバウンティ**：「脆弱性を見つけたら報奨金を出す」という制度

---

### 🔄 「継続的（Continuous）」が重要なポイント

従来のセキュリティテストは「年に1回」「システム更新のタイミングで」といった**スポット（一時的）**なものが多かったです。

しかし現代のサイバー攻撃は毎日・毎時間進化しています。

```
【従来のやり方】
1月: テスト実施 → 問題なし！
   ↓
4月: 新しい攻撃手法が登場 → でも次のテストは12月...
   ↓
8月: ハッカーに侵入される 😱
```

```
【継続的なやり方】
毎日・毎週・継続的にテスト
   ↓
新しい攻撃手法が出たら → すぐに検知・対応 ✅
```

## 技術的な詳細

### 継続的な攻撃的セキュリティテストの主な手法

#### 1️⃣ ASM（アタック・サーフェス・マネジメント）
**攻撃対象領域の管理**という意味です。

🏠 **例え話**: 「自分の家のドアや窓が何箇所あるか、全部把握する」
企業が持つシステム、サーバー、ウェブサイトなどを常に監視して、「攻撃者から見えているものは何か」を把握します。

---

#### 2️⃣ BAS（ブリーチ・アンド・アタック・シミュレーション）
**侵害・攻撃シミュレーション**という意味です。

🤖 **自動的に「模擬攻撃」を繰り返すツール**を使って、システムの弱点を常にチェックします。

```
【BASのイメージ】
ロボットが毎日「攻撃のふり」をする
  ↓
「この入り口から入れました！」→ すぐ対策
  ↓
また翌日も試す → 常に最新状態を確認
```

---

#### 3️⃣ ペネトレーションテストのサービス化（PTaaS）
**Pentest as a Service**の略です。

従来は「大きなプロジェクトを組んで年1回」だったペネトレーションテストを、クラウドサービスのように**継続的・定期的に提供**する新しいモデルです。

---

#### 4️⃣ レッドチーム演習の継続化

| 従来 | 継続的 |
|------|--------|
| 年に1〜2回、大規模な演習 | 小規模な演習を頻繁に繰り返す |
| 結果が出るまで数ヶ月 | リアルタイムでフィードバック |

---

### 「継続的テスト」の流れ（サイクル）

```
①発見（Discover）
  └ 自社のシステムや資産を把握する

②テスト（Test）
  └ 模擬攻撃・脆弱性スキャンを実施

③分析（Analyze）
  └ 「どこが弱かったか」を分析する

④修正（Remediate）
  └ 弱点を直す・パッチを当てる

⑤再テスト（Retest）
  └ ちゃんと直ったか確認する

→ ①に戻る（繰り返す）
```

このサイクルを自動化・継続化することが重要とされています。

## なぜ重要なのか

### 📈 サイバー攻撃の現実

現代のサイバー攻撃は想像以上に速く、巧妙です：

- 🌍 **1日に何百万件**もの攻撃が世界中で発生
- ⚡ 新しい脆弱性が発見されてから攻撃されるまで**平均15日以内**
- 💰 企業への被害額は**1件あたり平均4億円以上**（世界平均）

### 🏢 企業が直面している課題

```
問題① セキュリティ人材不足
  → 日本だけで数万人規模の不足

問題② システムが複雑化
  → クラウド、スマホ、IoTなど攻撃面が急増

問題③ 攻撃手法の進化が速い
  → 去年の対策が今年は通用しないことも
```

ガートナーがこのレポートを出したのは、これらの現実に対して「**継続的な攻撃的テストが最も効果的な対応策**」と判断したからです。

## 対策・今後の展望

### 企業・組織ができること（規模別）

#### 🏫 小規模（学校・中小企業レベル）
- **無料ツール**（OpenVAS、Nessus Essentialsなど）で定期的な脆弱性スキャンを実施
- **バグバウンティプログラム**への参加を検討
- セキュリティ意識向上トレーニングを定期実施

#### 🏢 中規模（中堅企業レベル）
- **PTaaS（ペネトレーションテストのサービス）**の導入
- **BASツール**の試験導入
- セキュリティ専任担当者の設置

#### 🏗️ 大規模（大企業・インフラ企業レベル）
- 常設の**レッドチーム**の設置
- **ASMプラットフォーム**の導入
- 継続的テストと防御（SOC）の統合

## 用語解説

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **脆弱性** | ぜいじゃくせい | システムの弱点・セキュリティ上の穴 |
| **ペネトレーションテスト** | ぺねとれーしょんてすと | 専門家が実際に侵入を試みるセキュリティ検査。略して「ペンテスト」 |

| **ブルーチーム** | ぶるーちーむ | 防御側のチーム（レッドチームの相手役） |
| **ASM** | えーえすえむ | Attack Surface Management。自社への攻撃口を把握・管理すること |
