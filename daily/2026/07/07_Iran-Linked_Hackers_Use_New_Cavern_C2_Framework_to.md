# イランに関連するハッカーが「Cavern」という新しい攻撃ツールを使ってイスラエルの組織を標的に

**元記事**: [Iran-Linked Hackers Use New Cavern C2 Framework to Target Israeli Organizations](https://inl03.netline.com/ltr6/?_m=3n.009a.4023.sp0ao46r89.32tc)
**解説日**: 2025年7月8日

---

## 背景知識

このニュースを理解するために、いくつかのポイントを先に押さえておきましょう。

### 🌍 地政学的背景
イランとイスラエルは長年にわたって対立関係にあります。現実の戦場だけでなく、**サイバー空間（インターネット上）でも攻撃・防衛の応酬**が続いており、「サイバー戦争」と呼ばれることもあります。

### 🖥️ C2（コマンド＆コントロール）フレームワークとは？
まるでスパイ映画の「司令部」を想像してください。
- ハッカーが他人のパソコンやサーバーに侵入した後、そこを**遠隔操作するための仕組み**が「C2フレームワーク」です
- 「司令部（C2サーバー）」からの命令を受け取り、感染した機器が動く、という構造です
- 例えるなら、ハッカーがリモコンを持っていて、乗っ取ったコンピューターを操り人形のように動かすイメージです

### 🏭 ITプロバイダー（IT事業者）とは？
企業や政府機関にシステム管理やソフトウェアを提供している会社のことです。たとえばセキュリティ管理ツールやサーバー管理サービスを提供しています。**これらの会社は多くの顧客と深くつながっているため、ここを攻撃すると、芋づる式に多くの組織に侵入できる**という特性があります。

## 何が起きたのか

チェック・ポイント・リサーチ（イスラエルのサイバーセキュリティ企業）が、**「Cavern Manticore（ケイバーン・マンティコア）」**というイランの諜報機関（MOIS：イラン情報・安全保障省）に関連するハッカーグループを発見・追跡しました。

このグループは**「Cavern（ケイバーン）」**という、これまで世界中のどのセキュリティ研究者も文書化したことのなかった**まったく新しい攻撃ツール（C2フレームワーク）**を使い、イスラエルのIT企業や政府機関を狙っていました。

### ポイントまとめ
| 項目 | 内容 |
|------|------|
| 攻撃者 | イランの情報機関に関連するハッカーグループ |
| 新ツール名 | Cavern（Cav3rnとも表記） |
| 標的 | イスラエルのIT企業・政府機関 |
| 発見者 | チェック・ポイント・リサーチ |

## 技術的な詳細

少し難しいですが、なるべくわかりやすく説明します！

### 🚪 Step 1：最初の侵入口 ─ SysAidの悪用

**SysAid**とは、企業のITシステム管理に使われる有名なソフトウェアです。ハッカーたちは、このソフトの**「アップデート機能」を悪用**して侵入を開始しました。

> 💡 例え話：正規の宅配便に偽装して、悪意のある荷物を届けるイメージです。

### 📦 Step 2：DLLサイドローディングという巧妙な手口

**DLL（ディーエルエル）**とは、Windowsのプログラムが使う「部品ファイル」のようなものです。
ハッカーたちは **`uxtheme.dll`** という、Windowsが普段から使っている正規ファイルと**同じ名前の偽物**を用意しました。

- Windowsが「いつもの部品を使おう」と読み込んだら、実は**ウイルスが仕込まれた偽物**だった、という手口です
- これを「DLLサイドローディング」と言います

### 🔧 Step 3：5つの攻撃モジュール

侵入後、ハッカーたちはC2サーバー（司令部、ドメイン名：`hospitalinstallation[.]com`）に接続し、目的に応じた攻撃ツールを追加でダウンロードします。それが以下の5つです：

| ファイル名 | できること |
|------------|-----------|
| `mhm.dll` | ファイルの検索・盗み出し・アップロード |
| `db.dll` | データベース（情報の保管庫）への不正アクセス・情報抜き取り |
| `ode.dll` | 組織内のユーザー情報を調べる（Active Directoryを探索） |
| `n-ten.dll` | ネットワーク内を調査・別の機器への侵入準備 |
| `n-sws.dll` | 通信を隠すためのトンネル（SOCKS5プロキシ）を作る |

> 💡 例え話：強盗団が建物に侵入した後、「金庫担当」「見張り担当」「逃走経路担当」に役割分担するイメージです。

### 🛡️ Step 4：解析を困難にする工夫

このフレームワークの最大の特徴は**「セキュリティ研究者が解析しにくいように設計されている」**点です。

- ツールの部品ごとに**異なるプログラムの書き方（コンパイル形式）**を使っています
- `.NET Framework`、`.NET Mixed-Mode C++/CLI`、`.NET Native AOT`の3種類を組み合わせています
- これは「解析するのに、バラバラな専門ツールが必要になる」ようにする、わざとわかりにくくする戦術です

> 💡 例え話：ある文書が「一部は日本語、一部は暗号、一部は古代文字」で書かれていたら解読が大変ですよね。それと同じです。

### 🔗 Step 5：信頼関係の悪用（サプライチェーン攻撃）

最も巧妙なのが、**「信頼されているIT企業を踏み台にして別の企業に侵入する」**という手口です。

```
[攻撃者]
    ↓ 侵入
[ITプロバイダーA（踏み台1）]
    ↓ 信頼関係を利用
[ITプロバイダーB（踏み台2）]
    ↓ 信頼関係を利用
[本当の標的：政府機関や重要企業]
```

これを**「サプライチェーン攻撃」**と言います。直接攻撃するより、信頼されている業者経由で入り込む方が、セキュリティを突破しやすいのです。

## なぜ重要なのか

### 🆕 完全に新しい攻撃ツール
「Cavern」はこれまで世界中のどのセキュリティ機関にも記録されていなかった新しいツールです。**未知の攻撃は既存のセキュリティソフトでは検知しにくい**という深刻な問題があります。

### 🎯 標的は社会インフラの中枢
IT企業や政府機関が標的になっているということは、最終的には**国家の重要な情報や社会インフラ**が狙われている可能性があります。

### 🔍 検出が非常に難しい
- 正規のソフトウェアのアップデート機能を悪用
- 正規ファイルに偽装したDLL
- 解析困難な複数のプログラム形式の組み合わせ
- 信頼された業者経由の侵入

これらすべてが重なり、**発見と防御が非常に難しい攻撃**になっています。

## 対策・今後の展望

### 企業・組織向けの対策

1. **ソフトウェアのアップデートを慎重に**
   - 更新プログラムが本当に正規のものかを確認する仕組みを導入する

2. **取引先・協力会社のセキュリティも確認**
   - 自社だけでなく、ITサービスを提供している外部業者のセキュリティレベルも把握する（サプライチェーンリスクの管理）

3. **ゼロトラストセキュリティの導入**
   - 「社内から来た通信だから安全」という考えをやめ、すべての通信を疑って検証する考え方

4. **RMM（リモート監視・管理）ツールの利用を厳格に管理**
   - 遠隔管理ツールの使用ログを細かく監視し、不審な操作を早期検知する

5. **DLLファイルの整合性チェック**
   - 正規のWindowsファイルが改ざんされていないかを定期確認する

### 今後の展望
- このグループ（Cavern Manticore）は今後も活動を続けると見られています
- セキュリティ企業が詳細を公開したことで、同様の攻撃の検知・防御がしやすくなることが期待されます
- 国家ぐるみのサイバー攻撃は今後さらに高度化していくと予想されます

あの記事では「正規のルーターファームウェアに隠れた裏口（バックドア）が仕込まれていた」という問題を取り上げました。

今回の記事も共通するテーマがあります：

> **「正規のもの・信頼されているもの」を悪用する攻撃が増えている**

- Tendaの件 → 正規のルーターファームウェアにバックドア
- 今回の件 → 正規のソフトウェアアップデート・正規ファイル名を悪用

いずれも「普段信頼しているものが実は危険だった」というパターンです。**「信頼しているから大丈夫」という思い込みがサイバーセキュリティでは最大の弱点になりえる**、という教訓を改めて示しています。

## 用語解説

| 用語 | 説明 |
|------|------|
| **C2フレームワーク** | 攻撃者が乗っ取ったコンピューターを遠隔操作するための仕組み全体。「司令部システム」のようなもの |
| **DLL（ダイナミックリンクライブラリ）** | Windowsのプログラムが使う「部品ファイル」。複数のプログラムで共有される |
| **DLLサイドローディング** | 正規のDLLファイルと同じ名前の悪意あるファイルをすり替えて実行させる攻撃手法 |
| **C2サーバー** | 攻撃者の「司令部」となるサーバー。感染した機器はここから命令を受け取る |
| **サプライチェーン攻撃** | 直接標的を攻撃するのではなく、信頼されている取引先・ベンダーを踏み台にして侵入する攻撃 |
| **HTTPS/WebSocket** | インターネット通信の方式。HTTPSは一般的なWeb通信、WebSocketはリアルタイム双方向通信に使われる |
| **Active Directory** | 企業内のユーザーやパソコンを一元管理するWindowsの仕組み。これが乗っ取られると組織全体が危険に |
| **SOCKS5プロキシ** | 通信を別の経路（中継点）を通じて送る仕組み。攻撃者が自分の正体を隠すために使う |
| **RMM（リモート監視・管理）ツール** | IT管理者がネットワーク上の機器を遠隔で管理するためのソフトウェア |
| **Native AOT（Ahead-of-Time）コンパイル** | プログラムを実行前にネイティブコードに変換しておく技術。解析を難しくする効果もある |
| **.NET Framework** | Microsoftが開発したアプリケーション実行環境。多くのWindowsアプリに使われる |
| **MOIS** | イラン情報・安全保障省。イランの諜報機関 |
| **Manticore（マンティコア）** | 中東の伝説上の怪物。セキュリティ企業がイラン系ハッカーグループの名前によく使う |

> 📌 **まとめ**: イランに関連するハッカーグループが、世界初公開の新型攻撃ツール「Cavern」を使ってイスラエルを狙っています。正規ソフトのアップデート機能を悪用し、信頼されたIT企業を踏み台にしながら、解析が困難な高度な技術を駆使している点が特に危険です。「信頼できると思っているものほど疑う」というゼロトラストの考え方がますます重要になっています。
