# 中国系ハッカー集団UAT-7810が新マルウェア「LONGLEASH」で攻撃網を拡大中

**元記事**: [China-Linked UAT-7810 Expands ORB Network With New LONGLEASH Malware](https://inl03.netline.com/ltr6/?_m=3n.009a.4024.sp0ao46r89.32uq)
**解説日**: 2026年7月10日

---

## 背景知識

今回の記事を理解するために、まずいくつかの重要な概念を説明します。

### 🌐 ORBネットワークとは？

「ORB（Operational Relay Box）ネットワーク」は、一言で言うと**「踏み台マシンの網」**です。

イメージしてみてください。悪意のある人が犯罪を行うとき、自分の家から直接行動すると足がつきますよね。そこで「複数の他人の家を経由して」行動することで、追跡を困難にします。

ORBネットワークはまさにこれと同じで、**乗っ取ったルーター（家庭用や企業用のネットワーク機器）を中継点として連結**し、本当の攻撃者の居場所を隠すための仕組みです。

```
攻撃者（中国）
    ↓
乗っ取ったルーターA（日本）
    ↓
乗っ取ったルーターB（米国）
    ↓
乗っ取ったルーターC（台湾）
    ↓
本当の攻撃対象（政府・インフラ等）
```

経由するほど、攻撃元の追跡が難しくなります。

### 🖥️ マルウェアとバックドアとは？

- **マルウェア**: 悪意のあるソフトウェアの総称（ウイルスなどを含む広い言葉）
- **バックドア**: コンピュータに「裏口」を作るソフトウェア。感染した機器に、攻撃者がいつでもこっそり入り込める「隠し扉」を作ります

### 📡 APT（Advanced Persistent Threat）とは？

「高度持続型脅威」と呼ばれる、**国家や大きな組織が背後にいる、高度で継続的なサイバー攻撃グループ**のことです。一回の攻撃で終わりではなく、長期間にわたって静かに潜伏し続けることが特徴です。

## 何が起きたのか

セキュリティ企業「Cisco Talos（シスコ・タロス）」が、**中国と関連するハッカー集団「UAT-7810」**の新たな活動を発見・報告しました。

このグループは以下のことをしています：

1. **家庭・企業向けの古いルーターの脆弱性（セキュリティの穴）を悪用**して乗っ取る
2. 乗っ取ったルーターに**新型マルウェア「LONGLEASH」などをインストール**する
3. これらを繋いで**「LapDogs（ラップドッグス）」という大規模な踏み台ネットワーク**を作り上げる
4. 作り上げたネットワークを**別の中国系ハッカー集団（UAT-5918など）に提供**して、台湾などの重要インフラへの攻撃に使わせる

つまり、UAT-7810は「攻撃のための高速道路を整備する業者」のような役割を担っているわけです。

## 技術的な詳細

### 🦠 新マルウェア群の紹介

UAT-7810は複数のマルウェアツールを組み合わせて使っています。すべて「LEASH（リーシュ＝犬のリード）」という言葉が含まれているのが特徴的です。

| マルウェア名 | 役割 |
|---|---|
| **ShortLeash（旧型）** | 基本的なバックドア。外部サーバーと連絡・命令受信 |
| **LONGLEASH（新型）** | ShortLeashの進化版。より多機能 |
| **DOGLEASH** | Linuxデバイスで任意のプログラムを実行できる受動型バックドア |
| **LEASHTEST** | MIPS系組み込み機器での動作テスト用ツール |
| **JARLEASH** | Java製の管理用バックドア（ファイル管理・FTP等） |

### 🔧 LONGLEASH（ロングリーシュ）の仕組み

LONGLEASHは旧型の「ShortLeash」をより強力にした新型マルウェアです。主な機能は以下の通りです。

```
LONGLEASHができること：
├── HTTP, DNS, SOCKS, TCP, ICMP, UDPなど
│   多様な通信プロトコルを使って中継（追跡をかわすため）
├── 他のサーバーへのネットワーク接続管理
├── 接続してきたクライアントの認証（正規の仲間か確認）
├── 改ざんを検知したら自動的に自分を消去（証拠隠滅）
└── 主要な指令サーバーからの命令を仲間のルーターへ転送
```

特に注目すべきは「**改ざんを検知したら自分を消去する機能**」です。セキュリティ研究者に解析・追跡されそうになったら、証拠を自動的に消してしまうという巧妙な仕掛けです。

### 🔓 攻撃に使われた脆弱性（セキュリティの穴）

主に**パッチ（修正プログラム）が当たっていない古いルーター**が狙われています。

- **CVE-2020-22653 / CVE-2020-22658**: Ruckus製ワイヤレスルーターの古い脆弱性（2020年発見）
- **CVE-2023-25717**: 同じくRuckus製ルーターの脆弱性（2023年発見）
- **CVE-2025-2492**: ASUS AiCloudルーターの新しい脆弱性

> ⚠️ **ポイント**: 2020年に発見された脆弱性が2026年現在もまだ使われているということは、多くの人が何年もルーターのアップデートをしていないということを意味します

## なぜ重要なのか

### 🎯 攻撃対象が「重要インフラ」

UAT-7810が整備した踏み台ネットワークを利用するグループ「UAT-5918」は、少なくとも2023年から**台湾の重要インフラ**（電力・通信・交通など国民生活に欠かせない設備）を標的にしています。

日本も同様の地政学的リスクを抱えており、他人事ではありません。

### 🔄 「攻撃ツールを貸す」ビジネスモデル

今回特に怖いのは、UAT-7810が**自分で攻撃するのではなく、攻撃インフラを他のグループに提供している**点です。これは：

- 攻撃元の特定がより困難になる
- 複数の攻撃グループが同時に同じインフラを使える
- 攻撃の規模が一気に拡大できる

という意味で、従来の「1つのグループが1つの攻撃をする」パターンより、はるかに対処が難しくなります。

### 📈 継続的な進化・開発が続いている

「ShortLeash → LONGLEASH」という進化や、LEASHTESTで新しい環境のテストを続けていることから、このグループは**今まさに活発に開発・拡張を続けています**。一時的な活動ではなく、長期的な作戦であることが伺えます。

## 対策・今後の展望

### 個人・企業ができること

**1. ルーターのファームウェアを今すぐアップデートする**
> ルーターのファームウェア（ルーター内蔵のソフトウェア）は、パソコンと同様に定期的な更新が必要です。設定画面から確認できます。特にRuckus製・ASUS製ルーターをお使いの方は至急確認を！

**2. 使っていない機能は無効にする**
> ルーターの「リモート管理機能」など、外部からアクセスできる機能は、必要がなければ無効にしましょう。

**3. 古い機器はサポート終了を確認する**
> メーカーのサポートが終了した機器は、脆弱性が修正されないまま放置されます。新しい機器への買い替えを検討しましょう。

**4. 組織・企業の場合は通信ログの監視**
> 不審な通信パターンがないか、定期的なネットワーク監視が有効です。

### 今後の展望

- Cisco Talosはこのグループを引き続き監視しており、さらなる新型マルウェアが登場する可能性があります
- LEASHTESTの存在から、**MIPS系の組み込み機器（IoT機器など）への攻撃拡大**も懸念されています
- 国家レベルの対応として、各国のサイバーセキュリティ機関が連携して対処することが求められています

## 用語解説

| 用語 | 意味 |
|---|---|
| **UAT-7810** | 中国と関連するとみられるハッカー集団のコードネーム |
| **APT（高度持続型脅威）** | 国家や大組織が背後にいる、長期的・高度なサイバー攻撃グループ |
| **ORBネットワーク** | 乗っ取った機器を中継点として連結した「踏み台ネットワーク」 |
| **マルウェア** | 悪意のあるソフトウェアの総称 |
| **バックドア** | コンピュータに作られた「裏口」。攻撃者がいつでも侵入できる |
| **C2サーバー** | Command & Control（指令管制）サーバー。マルウェアに命令を出す司令塔 |
| **CVE** | 公式に登録されたセキュリティ脆弱性の識別番号（例：CVE-2025-2492） |
| **ファームウェア** | ルーターなどのハードウェアに組み込まれたソフトウェア |
| **MIPS** | 組み込み機器（ルーター・IoT機器）でよく使われるCPUの種類 |
| **ELFバイナリ** | Linux系のOSで動くプログラムファイルの形式 |
| **プロトコル** | コンピュータ同士が通信する際の「言語・ルール」（HTTP、DNSなど） |
| **Cisco Talos** | 世界的なセキュリティ企業Ciscoのセキュリティ研究チーム |
