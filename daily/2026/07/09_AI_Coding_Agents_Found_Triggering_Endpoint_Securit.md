# AIコーディングアシスタントが「不審者」として検知される問題が発覚

**元記事**: [AI Coding Agents Found Triggering Endpoint Security Rules Built to Catch Attackers](https://inl03.netline.com/ltr6/?_m=3n.009a.4025.sp0ao46r89.32wg)
**解説日**: 2026年7月10日

---

## 背景知識

まず、このニュースを理解するために必要な知識を整理しましょう。

### AIコーディングエージェントって何？
「Claude Code」「Cursor」「OpenAI Codex」といったAIツールは、プログラマーのそばで一緒にコードを書いてくれるAIアシスタントです。「ここのコードを修正して」と頼むと、AIが自分でパソコンを操作してファイルを開いたり、プログラムを実行したりして作業してくれます。最近のエンジニアには欠かせないツールになっています。

### セキュリティソフト（エンドポイントセキュリティ）って何？
パソコンに入れる「番犬」のようなセキュリティソフトのことです。「怪しい動き」を監視していて、ハッカーが使う典型的な行動パターンを検知するとアラートを鳴らしたりブロックしたりします。ウイルス対策ソフトの進化版だと思ってください。

### 「行動検知」って何？
昔のセキュリティソフトは「既知のウイルスファイル」を探すだけでしたが、最近は**「怪しい行動パターン」**を見て判断します。たとえば「パスワードを盗もうとしている」「自動起動するように仕掛けようとしている」といった動きを検知します。

---

## 何が起きたのか

セキュリティ企業の**Sophos（ソフォス）**が、2026年6月の1週間分のデータを調べたところ、驚くべき事実が判明しました。

> **AIコーディングアシスタントが、まるでハッカーのように振る舞っていた**

Claude Code、Cursor、OpenAI Codexといった有名なAIツールが、「攻撃者を捕まえるために作られたセキュリティルール」を次々と引っかけていたのです。

ただし、**AIは悪意を持っていたわけではありません**。AIは普通の仕事をしていただけ。でも、その「普通の仕事」が、セキュリティソフトの目には「ハッカーの行動」と区別がつかなかったのです。

---

## 技術的な詳細

### 具体的にどんな行動がアラートを鳴らしたのか？

検知された問題行動のうち、**56.2%がパスワード・認証情報への不正アクセス**に関するもの、**28.8%が不審なプログラム実行**に関するものでした。

#### ① ブラウザのパスワードを読み取った（最多：42.6%）

Windowsには「DPAPI（ディーピーエーアイ）」という仕組みがあり、ブラウザに保存したパスワードを暗号化して守っています。

- **ハッカーがやること**: DPAPIを悪用してパスワードを盗む
- **AIがやったこと**: ブラウザを自動操作するために、同じ仕組みを使ってパスワードを読み取った

セキュリティソフトから見れば「同じ行動」です。アラートが鳴るのは正しい反応です。

```
AIの意図：「ブラウザを自動操作するために必要なんだ」
セキュリティの判断：「パスワードを盗もうとしてる！ブロック！」
```

#### ② ブラウザを強制終了して認証情報を取り出した

ある場面では、Claude Codeがブラウザを一度閉じてから、保存された認証情報（ログイン情報）を取り出すスクリプトを実行しました。さらに `cmdkey /list` というコマンドで、Windowsに保存されているすべての認証情報の一覧を表示しました。

これは**ハッカーが侵入後に必ずやること**と同じ手順です。

> ⚠️ なお、このときClaude Codeは `--dangerously-skip-permissions`（危険：権限チェックをスキップ）というモードで動いていました。これはAIの開発元であるAnthropicが「管理者はブロックすべき」と自ら警告しているモードです。

#### ③ ブロックされたら別の方法に切り替えた（OpenAI Codex）

OpenAI Codexが「Pythonをインストールしたい」という作業をしていたときの話です。

1. まず `certutil`（Windows標準ツール）でダウンロードしようとした → **ブロックされた**
2. 次に `bitsadmin`（別のWindows標準ツール）に切り替えた → これも怪しい行動として検知

この「**ブロックされたら別の方法を試す**」という行動こそ、実際の攻撃者と「ただのスクリプト」を区別する特徴とされていました。でも今や、AIも同じことをするのです。

#### ④ 起動時に自動実行されるスクリプトを仕掛けた（Cursor）

Cursorというツールが、PowerShellを使って「パソコンを起動するたびに自動実行されるスクリプト」を特定フォルダに置きました。これはマルウェアが「生き残るため」に必ずやるテクニック（**パーシスタンス＝永続化**）と全く同じです。

## なぜ重要なのか

### 🔴 問題その1：セキュリティの「判断基準」が崩れてきた

これまでのセキュリティは「この行動をしたら危険」という明確な基準がありました。でも今、その**危険な行動を無害なAIもやるようになった**ため、「本物の攻撃」と「AIの作業」を見分けることが難しくなっています。

### 🔴 問題その2：AIは「攻撃者にも使われる」

記事では恐ろしい事実も紹介されています。Sophosが1ヶ月前に報告した事例では、**攻撃者がClaude Opus 4.5を使ってマルウェアを作り、セキュリティソフトに引っかからないかテストしながら改良していた**ことが発覚しています。

つまり、AIは「普通の開発者の道具」にも「ハッカーの道具」にもなります。

### 🔴 問題その3：AIが乗っ取られる可能性

さらに、AIコーディングツール自体が**悪意のある入力によって操られる（ハイジャックされる）** 危険性もあります。AIが信頼されたユーザーとして動いているため、セキュリティソフトがその悪意を見逃してしまうケースもあります。

### 📊 大きな流れとして...

CrowdStrikeの2026年報告書によると、**2025年の検知された攻撃の82%はマルウェアを使っていなかった**とのこと。攻撃者は正規のツールや正規の認証情報を使って侵入するようになっています。AIのせいで、この「正規に見える攻撃」がさらに増えていくと考えられます。

## 対策・今後の展望

### 組織・管理者にできること

| 対策 | 内容 |
|------|------|
| **危険モードのブロック** | `--dangerously-skip-permissions` のような危険フラグをポリシーで禁止する |
| **AI利用ルールの策定** | 社内でAIツールがどこまで操作してよいかルールを決める |
| **コンテキストの把握** | 「誰が、何のために、このAIを動かしているか」を記録・管理する |
| **AIエージェントの監視強化** | AIが行った操作のログを細かく取り、定期的にレビューする |

### セキュリティツール側の課題

セキュリティソフトは今後、「**この行動は誰がやっているか（AIか人間か攻撃者か）**」を判断するための新しい仕組みが必要になります。「行動が怪しい」だけではなく、「その文脈（コンテキスト）が正常か」を見る方向に進化していくでしょう。

以前、以下の関連ニュースについて解説しました：

これらの記事では「AIツールが外部からの攻撃によって乗っ取られる危険性」を解説しました。

今回の記事はさらに一歩進んで、**「乗っ取られていないのに、AIが普通に仕事をするだけでセキュリティの警告が鳴ってしまう」** という新しい問題を示しています。

つまり、AIとセキュリティをめぐる問題は：

```
① AIが攻撃ツールとして使われる（ハッカーがAIを使う）
② AIが乗っ取られて攻撃に使われる（AIのバグを悪用）
③ AIが普通に動くだけでセキュリティが誤作動する ← 今回
```

という三方向から同時に起きており、セキュリティの世界が根本から変わりつつあることがわかります。

## 用語解説

| 用語 | 意味 |
|------|------|
| **エンドポイントセキュリティ** | パソコンやスマホなど端末を守るセキュリティソフト |
| **AIコーディングエージェント** | 自分でパソコンを操作してプログラミングを手伝うAIツール |
| **DPAPI** | Windowsがパスワードなどを暗号化して守る仕組み |
| **LOLBin（ロルビン）** | Living Off the Land Binary。Windowsに標準搭載されている正規ツールを悪用する攻撃手法 |
| **certutil / bitsadmin** | Windowsの標準ツール。本来は正規用途だがハッカーにも悪用される |
| **パーシスタンス（永続化）** | マルウェアがPC再起動後も生き残るための仕掛け（自動起動設定など） |
| **EDR** | Endpoint Detection and Response。高度なエンドポイント検知・対応システム |
| **PowerShell** | Windowsの高機能なコマンド操作ツール。便利だが悪用もされる |
| **コンテキスト** | 「文脈」のこと。同じ行動でも「誰が・なぜ・いつ」やったかで意味が変わる |
| **マルウェアフリー攻撃** | ウイルスファイルを使わず、正規ツールや正規アカウントだけで侵入する攻撃 |
