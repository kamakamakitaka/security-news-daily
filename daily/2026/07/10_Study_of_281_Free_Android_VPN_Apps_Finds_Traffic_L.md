# 281個の無料AndroidVPNアプリを調べたら、通信の漏洩・暗号化なし・追跡が続々発覚

**元記事**: [Study of 281 Free Android VPN Apps Finds Traffic Leaks, Unencrypted Data, and Tracking](https://inl03.netline.com/ltr6/?_m=3n.009a.4026.sp0ao46r89.32xi)
**解説日**: 2026年7月10日

---

## 背景知識

まず、このニュースを理解するために必要なキーワードを押さえましょう。

### VPN（仮想プライベートネットワーク）とは？
VPNとは、インターネット通信を「暗号化されたトンネル」で包んで、第三者に中身を見られないようにするサービスです。

🎒 **わかりやすい例え**：
- 普通のインターネット通信 → 透明な封筒で手紙を送るようなもの（中身が丸見え）
- VPN通信 → 鍵のかかった金属製のケースで手紙を送るようなもの（外からは中身が見えない）

主に以下のような目的で使われます：
- 公共のWi-Fiで通信内容を盗み見られないようにする
- アクセス制限のかかったサービスを利用する
- 自分の閲覧履歴をプロバイダに見られないようにする

### 「無料VPNアプリ」の落とし穴
VPNサービスの運営にはお金がかかります。無料で提供しているアプリは、どこかで収益を得ている場合があります。その手段として「ユーザーのデータを広告会社に売る」ことが行われているケースもあるのです。

### DNSとは？
インターネット上のサービスを「住所（IPアドレス）」で管理するための仕組みです。

🗺️ **例え**：「google.com」という名前を「142.250.x.x」という数字の住所に変換する「電話帳」のような役割です。

あなたがどのサイトを訪問したかは、このDNSへの問い合わせを見るとバレてしまいます。

## 何が起きたのか

ミシガン大学・ニューメキシコ大学・IITデリーの研究者たちが、**Google Playストアで人気の無料VPNアプリ281個**を「MVPNalyzer（エムブイピーエヌアライザー）」という専用のテストシステムで調査しました（2026年2月のNDSSセキュリティカンファレンスで発表）。

その結果、驚くべき問題が次々と明らかになりました：

| 問題の種類 | 該当アプリ数 | 主な内容 |
|---|---|---|
| 通信の「漏れ」 | 29個 | 暗号化トンネルの外に通信が漏れている |
| 暗号化なしのデータ送信 | 61個 | 平文（裸）で通信している |
| 設定ファイルを暗号化なしで送信 | 5個 | 攻撃者に通信を乗っ取られる可能性あり |
| 広告追跡IDを送信 | 76個 | ユーザーを追跡している |
| 広告・追跡サーバーへの接続 | 246個（全体の約87%） | ほぼほとんどのアプリが対象 |

😨 **最も衝撃的な数字**：問題が見つかったアプリは合計で**24億回以上インストール**されています。

## 技術的な詳細

### 🔴 最も危険な問題：「トンネルの乗っ取り」（5つのアプリ）

これが今回の調査で最も深刻な発見です。

**仕組みをわかりやすく説明すると：**

1. VPNアプリを起動すると、アプリは「どのサーバーに接続するか」が書かれた「設定ファイル」をインターネットから取得します
2. 問題のある5つのアプリは、この設定ファイルを**暗号化なし（平文）**でダウンロードしていました
3. カフェや空港などの公共Wi-Fiに悪意のある攻撃者がいた場合、この設定ファイルを**書き換えて**、攻撃者が用意した偽サーバーに接続させることができます

🕵️ **具体的なシナリオ**：
```
【正常な場合】
あなたのスマホ → VPNサーバー（正規）→ インターネット

【攻撃された場合】
あなたのスマホ → 攻撃者のサーバー → インターネット
                    ↑
             全通信を盗み見られている！
```

しかもユーザーの画面には「接続済み ✅」と表示されるので、**被害を受けていることに全く気づけません**。

研究者たちは実際にこの攻撃が機能することをテストで確認しました。

5つのアプリ開発者に連絡したところ：
- 2社は「HTTPSに移行する」と回答
- 3社は無反応（記事執筆時点）

---

### 🟠 通信の「漏れ」問題（29個のアプリ）

VPNの本来の役割は「全ての通信をトンネルで包む」ことですが、29個のアプリはトンネルの外に通信が漏れていました。

- **24個**：どのサイトを訪問したかがわかるDNS通信が漏れていた（これだけで約3億6千万インストール！）
- **6個**：ウェブの閲覧内容そのものが漏れていた
- **4個**：そもそも暗号化が全くなかった（「VPNのふり」をしているだけ）

---

### 🟡 「追跡しないはずなのに追跡している」問題

「プライバシーを守るため」にVPNを入れたのに、そのVPNアプリ自体がユーザーを追跡している、という皮肉な状況です。

- **76個**のアプリが「広告ID」を送信していた
  - 広告IDとは：スマホ1台ごとに割り当てられた固有の番号で、広告会社がユーザーを追跡するために使います
- **246個（87%）**のアプリが広告・追跡サーバーに接続していた
- 機種名・OSバージョン・画面サイズなどを送信しているアプリも多数
  - これらを組み合わせると「デジタル指紋（フィンガープリント）」になり、個人を特定できます
- **1つのアプリ**はGPSの正確な位置情報を送信していた😱

---

### 🟡 「VPNだとバレバレ」問題（169個）

VPN通信は、うまく設計すれば「普通のHTTPS通信」に見せかけることができます。しかし169個のアプリは何の偽装もしていなかったため、**ネット管理者や政府機関がVPN使用を簡単に検出・ブロックできます**。

しかも、そのうち約3分の2は「検閲を突破できる！」「ブロックを回避できる！」と宣伝しながら、実際には何も対策していませんでした。

---

## なぜ重要なのか

### 1. 「安全のため」に入れたものが逆に危険
VPNを使う人の多くは「安全を高めたい」と考えています。しかし今回の調査では、多くの無料VPNアプリが安全を高めるどころか、**追加のリスクをもたらしている**ことが明らかになりました。

### 2. 被害規模が巨大
問題のあるアプリの合計インストール数は**24億回以上**。日本の人口（約1.2億人）の約20倍に相当する数のインストールがされています。

### 3. 「信頼の移し替え」問題
記事が鋭く指摘しているポイントです：

> 「VPNを使うことは、信頼の対象を（インターネットプロバイダから）VPNアプリの開発者に移し替えることに過ぎない」

プロバイダを信頼できなくてVPNを使ったのに、そのVPN開発者も信頼できなければ意味がありません。

### 4. 危険な国・地域の人への影響が特に深刻
VPNの使用が法的に問題となる国では、「VPNを使っていること」がバレるだけで危険です。「ブロック回避できる」と宣伝しながら実際にはバレバレな169個のアプリは、そうした人たちを欺いていることになります。

## 対策・今後の展望

### 今すぐできる対策

**① 無料VPNアプリは慎重に選ぶ**
「無料」には理由があります。特に今回問題になったような無名の無料アプリは避けましょう。

**② 信頼できるVPNサービスを選ぶ基準**
- ✅ 第三者機関によるセキュリティ監査を受けている
- ✅ 「ノーログポリシー」（通信ログを保存しない）が実証されている
- ✅ 運営会社の所在地・情報が明確
- ✅ オープンソース（プログラムのソースコードが公開されている）

**③ 特定のVPNが安全かチェックする**
- 今回の研究で使われた「MVPNalyzer」のような調査結果を参考にする
- 各種セキュリティ専門メディアのVPNレビューを確認する

**④ 使うネットワーク環境に注意**
公共Wi-Fiでは、たとえVPNを使っていても、今回のような「設定ファイル乗っ取り」攻撃のリスクがあります。重要な操作（ネットバンキングなど）は公共Wi-Fiでは行わないのが安全です。

### 今後の展望

- 研究チームの「MVPNalyzer」は、今後も継続的にアプリの安全性を監査できる仕組みとして設計されています
- Google PlayストアにおけるVPNアプリの審査が強化されることが期待されます
- 有害と判定されたアプリがストアから削除されることも今後起こりえます

## 過去記事との関連

今回の記事は直接的な関連はありませんが、過去に解説した記事でも「管理できていないものはリスクになる」というテーマが共通しています。

以前「**ルーメン・テクノロジーズが自社の資産管理を1万7千から110万台へ拡大した話**」を解説しましたが、あの記事では「把握できていないシステムは守れない」という教訓がありました。今回の話も同じです：「自分のスマホにどんなアプリが入っているか把握できていないと、知らないうちにリスクを抱える」ということです。

自分のデジタル環境を「見える化・管理する」という意識が、個人レベルでも組織レベルでも大切だということが改めてわかりますね。

## 用語解説

| 用語 | 説明 |
|---|---|
| **VPN**（Virtual Private Network） | 通信を暗号化して、第三者に内容を見られないようにするサービス |
| **暗号化トンネル** | VPNが通信を包む「見えない保護カプセル」のようなもの |
| **DNS**（Domain Name System） | ドメイン名（google.com）をIPアドレス（数字の住所）に変換する仕組み。どのサイトを訪問したかが漏れると閲覧履歴がバレる |
| **平文（ひらぶん）** | 暗号化されていない、そのままの状態のデータ。誰でも読める状態 |
| **HTTPS** | ウェブ通信を暗号化するプロトコル（通信方式）。南京錠マーク🔒のついたサイト |
| **設定ファイル** | VPNアプリが「どのサーバーに接続するか」などを記録したファイル |
| **トンネル乗っ取り（Tunnel Hijacking）** | 攻撃者がVPNの接続先を偽のサーバーにすり替える攻撃 |
| **広告ID（Advertising ID）** | スマホ1台ごとに割り当てられた固有の番号。広告会社がユーザーの行動を追跡するために使用 |
| **フィンガープリント** | 機種・OS・画面サイズなど複数の情報を組み合わせて個人を特定する技術。指紋のように固有の特徴から特定する |
| **MVPNalyzer** | 今回の研究で開発された、AndroidのVPNアプリを自動で安全性テストするシステム |
| **OpenVPN** | 広く使われているVPNの通信方式（プロトコル）のひとつ |
| **ノーログポリシー** | VPN事業者が「ユーザーの通信ログを記録・保存しない」と約束するポリシー |
| **NDSS** | Network and Distributed System Securityの略。権威あるサイバーセキュリティの学術カンファレンス |

---

> 💡 **まとめると**：「無料VPNアプリ＝安全」は大きな誤解です。今回の調査で281個中、実質ほぼ全てのアプリに何らかの問題が見つかりました。VPNを使う目的が「安全とプライバシーの保護」なら、信頼できる有料サービスや監査済みのサービスを選ぶことを強くおすすめします。
