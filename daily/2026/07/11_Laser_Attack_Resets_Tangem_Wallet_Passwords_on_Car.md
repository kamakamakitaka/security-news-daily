# レーザー光線でパスワードをリセット！？暗号資産ウォレットカードに物理的な攻撃が発覚

**元記事**: [Laser Attack Resets Tangem Wallet Passwords on Cards That Can't Be Patched](https://inl03.netline.com/ltr6/?_m=3n.009a.4027.sp0ao46r89.32z2)
**解説日**: 2025年7月14日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を押さえておきましょう。

### 暗号資産（仮想通貨）ウォレットって何？

暗号資産（ビットコインなど）は、銀行口座のように「どこかのサーバーに保管されている」のではなく、**「秘密鍵（ひみつかぎ）」と呼ばれる特別な暗号データを持っている人が所有者**とみなされます。この秘密鍵を安全に保管するための道具が「ウォレット（財布）」です。

### ハードウェアウォレットって何？

スマホアプリだけで管理するソフトウェアウォレットと違い、**専用の物理的な機器（ハードウェア）に秘密鍵を保存する**のがハードウェアウォレットです。インターネットに直接つながらないため、オンライン攻撃に強いとされています。

### Tangemカードって何？

**Tangem（タンジェム）** は、クレジットカードそっくりの形をしたハードウェアウォレットです。カードの中に特殊なチップが入っており、スマホにタッチするだけで暗号資産を操作できます。パスワードを設定することで、カードを盗まれても中身を守れる仕組みになっています。

### セキュアエレメント（Secure Element）って何？

カードの中核となる**特殊なチップ**のことです。普通のチップと違い、「物理的に壊そうとしても中のデータが守られる」よう設計されています。クレジットカードやICカードにも同様のチップが使われています。

### EAL6+って何？

セキュアエレメントの**安全性の認定レベル**です。EAL（Evaluation Assurance Level）は1〜7まであり、EAL6+は「かなり高いレベルで安全性が検証されている」ことを示します。銀行カードや政府機関のカードなどにも使われるレベルです。

## 何が起きたのか

大手ハードウェアウォレットメーカー**Ledger（レジャー）** 社のセキュリティ研究チーム「**Donjon（ドンジョン）**」が、競合製品であるTangemのカードに対して、**レーザー光線を使ってパスワードをリセットできる攻撃手法**を発見し、公表しました。

簡単に言うと：

> 🔴 **カードを物理的に入手し、レーザーを正確なタイミングで照射するだけで、知らないはずのパスワードをリセットして、中の暗号資産を盗み出せる**

という問題が発覚したのです。

さらに深刻なのは、**Tangemカードはソフトウェアの更新（アップデート）ができない設計**になっているため、すでに販売されているすべてのカードにこの欠陥が永遠に残り続けるという点です。

## 技術的な詳細

### 通常の仕組み（カードがどう守っているか）

```
[あなた] → カードにタッチ → パスワード入力 → 秘密鍵で暗号資産を操作
```

Tangemカードには「パスワードを忘れた時の回復機能」があります。同じセットで購入した別のカードを近づけることで、古いパスワードを知らなくても新しいパスワードを設定できる仕組みです。

この時、カードの内部では「**今、回復モード（リカバリーモード）になっているか？**」という確認（チェック）が行われます。

```
[回復モードの確認]
  → YES（回復モード中）→ 新しいパスワードを受け入れる
  → NO（通常モード）  → パスワードなしでは変更できない
```

### レーザー攻撃の仕組み

攻撃者はカードを物理的に切り開き、チップを剥き出しにします。そして、**カードがチェックを実行するまさにその瞬間**に、チップの特定の箇所にレーザーを照射します。

```
[攻撃のイメージ]
  チェック実行の瞬間 → レーザー照射 → 回路が一瞬誤動作
  → カードが「回復モードだ」と誤認識
  → パスワードなしで新しいパスワードを設定可能に！
```

これは「**フォルト・インジェクション（障害注入）攻撃**」と呼ばれる手法です。データを書き換えるのではなく、**回路に一瞬の誤動作を起こして、間違った判断をさせる**ものです。

よく似た例え話をするなら…

> 🏦 銀行の金庫の鍵を探す代わりに、**金庫を開ける判断をするコンピューターに向けて特殊な電磁波を当て、「鍵が合っている」と誤認識させて開けてしまう**ようなイメージです。

### なぜ回復機能を無効にしても意味がないのか？

重要なのは、「**回復機能をオフにしても、そのチェック自体は内部で実行され続ける**」という点です。外から見えない深い部分での処理なので、設定を変えても根本的な問題は解決しません。

## なぜ重要なのか

### ✅ ほとんどの人にとって現実的なリスクは低い

この攻撃を実行するには：

| 必要なもの | 詳細 |
|-----------|------|
| **物理的なカード** | カードを直接手に入れる必要がある |
| **約2,500万円の機器** | 高精度レーザー装置など高額な設備が必要 |
| **高度な専門知識** | チップの解析・レーザーの調整など |
| **約2時間** | カード1枚につき攻撃に2時間かかる |
| **カードの物理破壊** | カードを切り開くため、明らかに痕跡が残る |
| **オフライン環境** | インターネット越しには絶対にできない |

「どこの馬の骨かわからない暗号資産カードに2500万円かけて攻撃する」のは、普通の窃盗犯には現実的ではありません。

### ⚠️ 注意すべき状況

以下に当てはまる人は要注意です：

- **カードを紛失した、または盗まれた**
- **カードに多額の暗号資産を保管している**

カードには「誰のものか」「いくら入っているか」という情報が書かれていないため、攻撃者にとっては「このカードには価値があるのか？」が事前にわかりません。ただし、高額の資産を持っていることが別の手段で知られてしまった場合は話が変わります。

### ⚠️ 修正不可能という問題

Tangemはセキュリティ上の設計方針として「**ファームウェア（カードを制御するプログラム）を更新できない**」仕様にしています。「外から変更できない＝安全」という考えですが、今回は逆に「バグがあっても永遠に直せない」という弱点になってしまいました。

> 🖥️ スマホのアプリをアップデートで修正できるのと違い、Tangemカードは「作った時のまま」で使い続けるしかないのです。

## 対策・今後の展望

### Tangemカード利用者がとれる対策

| 状況 | 対策 |
|------|------|
| カードを持っていて安全に保管できている | 今すぐ行動する必要はないが、紛失リスクを意識しよう |
| カードを紛失・盗難された | **すぐに資産を別のウォレットに移動させる** |
| 大量の資産を保管している | **保管場所を複数に分けることを検討する** |

### Tangemの見解

Tangemは「これは自社カード固有の問題ではなく、セキュアエレメントチップ全般に対する物理攻撃の一種。実用的なリスクはほぼゼロ」と反論しています。また、Donjonチームがライバル社Ledgerの所属であることも指摘しており、情報の受け取り方に注意が必要です。

### 研究チームの見解

Donjonチームは「欠陥が実在し、すべてのカードに存在し、永遠にパッチが当たらないことは事実」と主張しています。

### 今後の展望

- ソフトウェア更新ができないハードウェアウォレットの設計思想が見直される可能性がある
- 暗号資産の保管においては、**単一の手段に頼らない分散管理**の重要性が改めて示された

## 過去記事との関連

以前、**Injective LabsのGitHubアカウントが乗っ取られ、暗号資産ウォレットの秘密鍵を盗む悪意のあるプログラムが公開された事件**を解説しました。

あの事件はインターネット経由でソフトウェアを改ざんする「サプライチェーン攻撃」でしたが、今回は**物理的にハードウェアを攻撃する手法**です。

二つの事件から見えてくるのは：

> 💡 **「デジタル（ソフトウェア）」からでも、「物理（ハードウェア）」からでも、暗号資産を狙う攻撃は多様化している**

ということです。「ハードウェアウォレットなら絶対安全」「オフラインなら大丈夫」という過信は禁物で、適切な保管と分散管理が重要だということが改めてわかります。

## 用語解説

| 用語 | 意味 |
|------|------|
| **暗号資産（仮想通貨）** | ビットコインなど、インターネット上で管理される通貨の一種 |
| **秘密鍵（プライベートキー）** | 暗号資産の「所有権」を証明する特殊な暗号データ。これを持つ人が所有者とみなされる |
| **ハードウェアウォレット** | 秘密鍵を物理的な専用機器に保存するタイプのウォレット |
| **セキュアエレメント** | 改ざんや物理攻撃に強い特殊なセキュリティチップ |
| **EAL6+** | セキュリティ評価の国際基準。数字が大きいほど厳しく検証されている |
| **ファームウェア** | ハードウェアを制御する基本的なプログラム。スマホのOSに相当 |
| **フォルト・インジェクション攻撃** | チップに意図的な誤動作を引き起こして、誤った判断をさせる攻撃手法 |
| **回復モード（リカバリーモード）** | パスワードを忘れた時に新しいパスワードを設定するための特別な状態 |
| **Ledger / Donjon** | 大手ハードウェアウォレットメーカーとその内部セキュリティ研究チーム |
| **Tangem（タンジェム）** | カード型ハードウェアウォレットを製造するスイスの企業 |
| **パッチ** | ソフトウェアやファームウェアの欠陥を修正するための更新プログラム |

---

> 📌 **まとめ**: 今回の発見は「実際に今すぐ危ない」というよりも、「ハードウェアであっても絶対安全はない」「更新できない設計はリスクにもなりえる」という教訓を示した事例です。暗号資産を扱う際は、複数の手段に分散して保管することが大切です。
