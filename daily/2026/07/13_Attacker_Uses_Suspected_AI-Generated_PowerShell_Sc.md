# AIが書いたスクリプトで社内ネットワークの地図を作られた！新しいサイバー攻撃の手口

**元記事**: [Attacker Uses Suspected AI-Generated PowerShell Script to Map Active Directory](https://inl03.netline.com/ltr6/?_m=3n.009a.4028.sp0ao46r89.3304)
**解説日**: 2025年7月14日

---

## 背景知識

まず、この記事を理解するためにいくつかの基本的な仕組みを説明しますね。

### 🏢 Active Directory（アクティブ・ディレクトリ）とは？

会社や学校のパソコンを使うとき、「ネットワークにログイン」することがありますよね。**Active Directory（AD）** とは、Microsoftが作った「社内のユーザー・パソコン・権限を一元管理するシステム」です。

> **例え話**: 学校の「生徒名簿＋座席表＋鍵の管理台帳」が全部まとまったもの、というイメージです。「誰がどの部屋に入れるか」「どのパソコンにログインできるか」がすべてここで管理されています。

### 💻 PowerShell（パワーシェル）とは？

Windowsに標準で入っている「コマンドで操作できるツール」です。正規の管理ツールですが、悪用されることも多いです。

> **例え話**: 車の「エンジン直結の操作パネル」みたいなもの。正しく使えば便利ですが、悪人が使えばなんでもできてしまいます。

### 🤖 「バイブコーディング（Vibe-coded）」とは？

最近出てきた言葉で、**ChatGPTなどのAIにプログラムを書いてもらうこと**を指します。プログラミングの知識がなくても、AIに「こんなプログラムを作って」と頼めばコードが出来上がってしまうことから、こう呼ばれています。

## 何が起きたのか

2026年6月上旬、正体不明のハッカーが、**AIに書かせたプログラム**を使って企業の社内ネットワーク全体の「地図」を作り、情報を盗み出す攻撃を行いました。

セキュリティ企業「Huntress」の研究者がこの攻撃を発見・分析し、報告しました。

### 攻撃の流れ（ざっくり）

```
① 盗んだID・パスワードでリモートログイン
        ↓
② AIが書いたプログラムで社内の「地図」を作成
        ↓
③ ネットワーク上の共有ファイルを探索
        ↓
④ 情報をまとめて外部サーバーに送信
```

---

## 技術的な詳細

### ステップ① 不正ログイン

攻撃者はまず、**事前に入手していた社員のID・パスワード**を使って「RDP（リモートデスクトッププロトコル）」でサーバーに接続しました。

> **RDP**とは: 離れた場所からパソコンを遠隔操作する仕組みです。テレワークでよく使われますが、悪用されることも多い技術です。

### ステップ② AIが書いたプログラムで社内地図を作成

ここが今回の事件の最大の注目ポイントです。

攻撃者は **ChatGPTなどのAI（大規模言語モデル）** に頼んで、Active Directoryを調べるプログラムを書かせました。

研究者がAI製だと判断した根拠：

| 証拠 | 意味 |
|------|------|
| タイトルが「100% Working AD Information Gathering Script - FULLY FIXED」 | AIと何度もやりとりしてデバッグした様子がうかがえる |
| コードが「過剰に丁寧」に書かれている | AIが余計なほど丁寧にコードを書く特徴がある |
| 出力が色分けされて美しい | AIが「見やすく」仕上げた典型的なパターン |
| ドメインコントローラーを探す方法が5種類も実装されている | AIが「念のため」複数の方法を詰め込みがち |

> **例え話**: 「宿題をAIに頼んだら、先生も驚くほど丁寧な解説付きで提出してしまった」みたいな状況です。AIらしさが滲み出てしまっています。

このプログラムは社内の以下の情報を丸ごと収集しました：
- 👤 全ユーザーの一覧
- 💻 全パソコンの一覧
- 👥 グループ・組織の構造
- 🔗 ネットワークの信頼関係

最終的に **「AD_Report.html」** という見やすいレポートファイルまで自動で作成。まるで正規の管理者が作ったような、きれいなレポートです。

### ステップ③ ファイル共有の探索

約30分後、攻撃者は正規ツールを2つ使ってファイル探索を行いました：

- **as5cmd**: 大量ファイルの操作ツール（本来はクラウドストレージ管理用）
- **SharpShares**: 社内ネットワークの共有フォルダを探すツール

> **例え話**: 建物の見取り図（ADの地図）を手に入れた後、今度は「どこに金庫があるか」を探し回っている状態です。

### ステップ④ データの持ち出し

集めた情報はCSVファイルにまとめられ、圧縮・暗号化されて**外部のサーバーに送信**されました。

## なぜ重要なのか

### 🚨 AIが「犯罪の敷居」を下げてしまっている

これまで高度なサイバー攻撃には、プログラミングの深い知識が必要でした。しかし今や、**AIに頼めば誰でも高度な攻撃ツールが作れてしまいます**。

```
従来: 高い技術力 → 高度な攻撃ツール
今後: AIに頼むだけ → 高度な攻撃ツール
```

### ⚡ 攻撃のスピードが劇的に上がっている

別のセキュリティ企業「Sygnia」の報告によると、AIを使った攻撃では**わずか72時間でAWS（クラウドサービス）の広範囲を侵害**した事例もあります。

人間のセキュリティ担当者が気づいて対応するより、攻撃の方が圧倒的に速くなっています。

### 💰 目的は金銭的な脅迫

今回の攻撃の目的は、盗んだ情報を使って企業を**脅迫・恐喝**することだったと分析されています。「情報を公開されたくなければお金を払え」という手口です。

---

## 対策・今後の展望

### ✅ 企業・組織が取るべき対策

| 対策 | 説明 |
|------|------|
| **多要素認証（MFA）の導入** | ID・パスワードが盗まれても、スマホ認証などがあれば不正ログインを防げる |
| **RDPのアクセス制限** | 必要な人だけがリモート接続できるように絞り込む |
| **PowerShellの実行ログ監視** | 不審なスクリプトの実行を素早く検知する |
| **最小権限の原則** | 各ユーザーに必要最低限の権限だけを与える |
| **異常検知の強化** | 短時間で大量のAD情報を取得する動作をアラートで検知する |

### 🔮 今後の展望

Huntressは「攻撃の基本的な手口は昔と変わっていないが、AIによって**速度と規模が大幅に拡大**している」と指摘しています。

> セキュリティの世界でも、AIを使った**防御側のツール**の開発が急ピッチで進んでいます。「AI vs AI」の攻防が今後の主戦場になっていくでしょう。

## 用語解説

| 用語 | 意味 |
|------|------|
| **Active Directory (AD)** | 社内のユーザー・パソコン・権限を一元管理するMicrosoftのシステム |
| **PowerShell** | Windowsに標準搭載されているコマンド操作ツール |
| **RDP（リモートデスクトッププロトコル）** | 遠隔地からパソコンを操作するための仕組み |
| **ドメインコントローラー (DC)** | Active Directoryの「司令塔」となるサーバー |
| **バイブコーディング** | AIにプログラムを書いてもらう行為 |
| **LLM（大規模言語モデル）** | ChatGPTなどのAI。大量のテキストを学習してあらゆる文章を生成できる |
| **列挙（Enumeration）** | ネットワーク上のユーザーやデバイスの情報を体系的に収集すること |
| **エクスフィルトレーション** | 盗んだデータを外部に持ち出すこと |
| **多要素認証 (MFA)** | パスワード以外にスマホ認証などを組み合わせるログイン方法 |
| **AWS** | Amazonが提供するクラウドサービス |

---

> 💡 **まとめると**: 「AIが攻撃ツールを書いてくれるので、技術力の低い攻撃者でも高度な攻撃ができるようになってきた」という時代の変化を示す事件です。パスワード管理と多要素認証の徹底が、今まで以上に重要になっています。
