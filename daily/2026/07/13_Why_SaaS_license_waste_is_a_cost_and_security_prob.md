## 背景知識

### 🏫 SaaSってなに？

**SaaS（サース）** とは「**Software as a Service**」の略で、簡単に言うと「**インターネット越しに使うソフトウェアのサービス**」のことです。

昔のソフトウェアは、CDなどを買ってパソコンにインストールして使うものでした。でも最近は…

| 昔のやり方 | 今のSaaS |
|-----------|---------|
| CDを買ってインストール | ブラウザやアプリで即利用 |
| 一度買えば終わり | 月額・年額で「ライセンス（使用権）」を購入 |
| 自分でアップデート | 自動でアップデート |

身近な例で言うと：
- **Microsoft 365**（Wordやメールなど）
- **Google Workspace**（GoogleドキュメントやGmail）
- **Slack**（チャットツール）
- **Zoom**（ビデオ会議）
- **Salesforce**（営業管理）

これらはすべてSaaSです。企業は「社員の人数分のライセンス（使用権）」を毎月・毎年お金を払って使っています。

### 💳 ライセンスってどういう仕組み？

「ライセンス」とは、「このソフトを使う権利」のことです。

例えば、Slackを100人の会社で使うなら「100ライセンス分」を購入します。

```
1ライセンス × 月1,000円 × 100人 = 月10万円
```

これが「ライセンスコスト」です。

## 何が起きたのか

この記事が伝えているのは、企業が **「SaaSのライセンスを無駄に持ちすぎている」** ことが、単なる「お金のムダ」だけでなく、**セキュリティ上の危険**にもなっているという問題です。

### 📦 ライセンスの無駄遣いとはどういうこと？

こんな状況を想像してみてください：

```
🏢 社員200人の会社

SaaSツール：Zoom、Slack、Salesforce、Notion...など20種類

でも実際には...
・退職した社員のアカウントがそのまま残っている 🚨
・使っていない部署にもライセンスが割り当てられている
・同じ機能のツールが重複して契約されている
・誰も使っていないのに契約し続けているサービスがある
```

これが「**ライセンスの無駄遣い（License Waste）**」です。

### 実際の規模感

業界調査によると：
- 企業が契約しているSaaSツールの平均は **数十〜数百種類**
- そのうち **実際に使われているのは30〜50%程度** という調査結果もある
- 大企業では年間で **数百万〜数千万円** のライセンス費用が無駄になっているケースも

## 技術的な詳細

### 💸 コストの問題（お金のムダ）

まずわかりやすいのは「お金のムダ」です。

```
例：
退職した社員のアカウント × 10人
各ツールのライセンス料 × 月5,000円
使用しているSaaSツール × 15種類

→ 月75万円、年間900万円のムダ！
```

でも実はこれだけではありません。

---

### 🔐 セキュリティの問題（こっちが本題）

ここが今回の記事の核心です。ライセンスの無駄遣いは、**セキュリティの穴**を生み出します。

#### ① 退職者のアカウントが残る問題

```
【危険なシナリオ】

田中さんが会社を退職
    ↓
でも、SaaSのアカウント（ID・パスワード）が消えていない
    ↓
悪意ある第三者（または田中さん本人）がログイン
    ↓
会社の機密情報にアクセスできてしまう！
```

これは「**幽霊アカウント（Ghost Account）**」と呼ばれる問題です。

#### ② シャドーIT（野良ツール）の問題

**シャドーIT** とは、会社が公式に認めていないのに、社員が勝手に使っているツールのことです。

```
例：
「公式はSlackだけど、個人的にDiscordも使ってる」
「会社のツールが使いにくいから、個人のGoogleドライブに保存してる」
```

これが問題なのは：
- IT部門が管理できない
- セキュリティチェックが入らない
- 機密情報が意図せず外部に漏れる

#### ③ アクセス権限の肥大化問題

```
【権限の腐敗（Permission Creep）と呼ばれる現象】

新入社員Aさん（営業部）
→ 営業ツールのみアクセス権限 ✅

1年後：部署移動（開発部）
→ 開発ツールのアクセス権限が追加 ✅
→ でも営業ツールの権限は消えていない ⚠️

3年後：さらに別の部署へ
→ また権限が追加 ✅
→ 過去の権限もすべて残り続ける ⚠️⚠️
```

こうして、本来必要ない情報にアクセスできる状態が生まれます。

#### ④ ライセンスが多いほど攻撃面が増える

セキュリティの世界では **「攻撃面（Attack Surface）」** という考え方があります。

```
🏰 お城にたとえると...

出入り口（ドア・窓）が多いほど
→ 敵（攻撃者）が侵入できる場所が増える

SaaSツールも同じ！
使っていないSaaSが10個あれば
→ そのすべてがハッカーの侵入口になりうる
```

## なぜ重要なのか

### 📊 企業への影響

| リスク | 内容 |
|--------|------|
| 💰 財務リスク | 不要なライセンス費用で年間数百万〜数千万円のムダ |
| 🔓 情報漏洩リスク | 退職者アカウントや未管理ツールから機密情報が流出 |
| ⚖️ コンプライアンスリスク | GDPR（EU個人情報保護法）などの法律違反になる可能性 |
| 🎯 ランサムウェアリスク | 管理されていないアカウントから組織全体に感染拡大 |

### 実際に起きた事例（参考）

- **退職した元従業員が、アカウントが削除されていなかったため、会社のシステムに不正アクセス** → 情報漏洩（こうした事例は世界中で多数報告されています）
- **社員が個人Dropboxに顧客データを保存 → Dropboxの別の漏洩事故で顧客データも流出**

## 対策・今後の展望

### ✅ すぐにできる対策

#### 1. SaaSの棚卸し（インベントリ管理）
```
まず「どんなSaaSを使っているか」を全部リストアップする
→ 会社全体で何個のツールが使われているか把握する
→ 誰が使っているか確認する
```

#### 2. アカウントのライフサイクル管理
```
【理想の流れ】
入社 → アカウント作成・必要な権限のみ付与
部署移動 → 不要な権限を削除し、必要な権限を追加
退職 → 即日全アカウント無効化・削除
```

#### 3. SSO（シングルサインオン）の導入
**SSO** とは「1つのIDとパスワードで、複数のSaaSに一括ログインできる仕組み」です。

```
メリット：
・一箇所でアクセスを管理できる
・退職時に1つ無効化するだけで全サービスのアクセスが止まる
・不審なログインを一元的に監視できる
```

#### 4. 定期的なアクセスレビュー
```
月に1回または四半期に1回：
「このアカウント、本当にまだ必要？」
を全員分確認する
```

#### 5. SSPM（SaaSセキュリティ態勢管理）ツールの活用
最近は **SSPM（SaaS Security Posture Management）** という専門ツールが登場しています。これは「SaaSのセキュリティ状態を自動でチェックしてくれるツール」です。

### 🔮 今後の展望

- **AI活用による自動監視**：使われていないアカウントを自動検出する仕組みが普及中
- **ゼロトラスト**の考え方：「社内だから安全」ではなく「すべてを疑って確認する」セキュリティモデルへの移行
- **SaaS管理ツール市場の拡大**：企業のSaaS管理を助けるツールが急成長中

## 過去記事との関連

今回は過去の関連記事がないため省略しますが、この記事のテーマは以下のような概念と深く関わっています：

- **最小権限の原則**（Principle of Least Privilege）：必要最小限のアクセス権限のみ与えるという考え方
- **ゼロトラストセキュリティ**：「信頼しない、常に確認する」という現代のセキュリティ思想
- **CASB（キャスビー）**：クラウドサービスの利用を管理・監視するツール

## 📝 まとめ

```
SaaSライセンスの無駄遣い問題

💰 コストの問題
  └ 使っていないライセンスへの無駄な出費

🔐 セキュリティの問題
  ├ 退職者の幽霊アカウント
  ├ シャドーITによる情報漏洩リスク
  ├ 権限の肥大化
  └ 管理できないSaaSの増加

✅ 解決策
  ├ SaaSの棚卸し（何を使っているか把握）
  ├ アカウントの適切な管理（退職時即削除）
  ├ SSOの導入（一元管理）
  └ 定期的なアクセスレビュー
```

「お金の節約」と「セキュリティの強化」は、一見別の話に見えますが、**SaaS管理という共通の課題でつながっている**ことがこの記事の大切なメッセージです。

家に鍵のかかっていない出入り口を減らすように、使わないSaaSアカウントを整理することが、安全で効率的な企業運営につながります🔑
