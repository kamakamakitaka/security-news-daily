# 85種類の暗号資産ウォレット拡張機能の調査で判明：アドレス漏洩とサイト横断追跡のリスク

**元記事**: [Study of 85 Crypto Wallet Extensions Finds Address Leaks and Cross-Site Tracking Risks](https://inl03.netline.com/ltr6/?_m=3n.009a.4029.sp0ao46r89.3310)
**解説日**: 2025年7月

---

## 背景知識

まず、この記事を理解するために必要な基礎知識を整理しましょう。

### 暗号資産（仮想通貨）ウォレットとは？
暗号資産（ビットコインやイーサリアムなど）を管理するための「財布」のようなソフトウェアです。銀行口座の代わりに使うイメージです。

### ブラウザ拡張機能とは？
ChromeやFirefoxなどのウェブブラウザに追加できる小さなプログラムです。例えば「広告ブロッカー」や「翻訳ツール」と同じ仕組みで動いています。今回の調査対象である「MetaMask（メタマスク）」などが代表例です。

### ウォレットアドレスとは？
銀行の口座番号のようなものです。例えば `0xAbCd1234...` という形式の文字列で、これを使って暗号資産の送受信を行います。多くのユーザーはプライバシーのために**複数のアドレスを使い分けています**（本名を複数のペンネームで隠すイメージ）。

### Web3とは？
ブロックチェーン技術を使った次世代インターネットのことです。ウォレットを使ってサービスにログインしたり、取引したりします。「ウォレットでサインイン」する機能を持つサイトが該当します。

### フィンガープリンティングとは？
クッキー（Webサイトが保存する識別情報）を使わなくても、ブラウザの細かい特徴を組み合わせて個人を特定する技術です。指紋のように「あなただけの特徴」をデジタルで読み取るようなイメージです。

---

## 何が起きたのか

ベルギーの**KUルーヴェン大学**のセキュリティ研究チームが、人気の暗号資産ウォレット拡張機能**85種類**を調査しました（Chromeウェブストアで合計約**3,500万人**のユーザーがいる）。

その結果、**ウォレット自体の設計・動作に起因するプライバシーリスク**が5種類見つかりました。

> ⚠️ 重要ポイント：これはハッキングではありません。ウォレットが「設計通りに動いた結果」として情報が漏れているのです。

この研究は2025年7月にカナダのカルガリーで開催される「**PETS 2026プライバシー会議**」で発表予定です。

---

## 技術的な詳細

研究チームが発見した主な問題点を3つ、わかりやすく解説します。

---

### 🔴 問題1：別々のアドレスが「同一人物のもの」とバレてしまう

**例え話で説明すると…**
あなたが「Aさん」「Bさん」「Cさん」という3つの別名を使い分けていたとします。でも、ある日「AさんとBさんが同じ人物だ」と気づかれてしまったら、プライバシーは崩壊しますよね。

**技術的な仕組み：**

```
ウォレット → 「アドレスAとアドレスBの残高を教えて」→ 外部サーバー
                ↑
         1つのリクエストに2つのアドレスが含まれる！
         → サーバー側は「同一人物のもの」と判断できる
```

- **13種類のウォレット**は、1つの通信に複数のアドレスをまとめて送信していた
- **4種類のウォレット**は、ほぼ同時（数ミリ秒以内）に別々の通信を送ることで同じ問題を引き起こしていた
- これらのウォレットのユーザーは合計**約2,300万人**

---

### 🔴 問題2：「ログアウト」しても実はログアウトできていない

**例え話で説明すると…**
お店の鍵を借りて、「返却しました」と店員に言ったのに、実は鍵のコピーがまだ手元に残っていた…そんな状態です。

**技術的な仕組み（2段階の問題）：**

#### ①Webサイト側の問題
調査した30種類の人気Web3サイトのうち、「切断」ボタンを押したときに**本当にウォレットへ切断命令を送っていたのはたった11サイト**。残り19サイトは、自分の画面表示を消しただけで、ウォレットとの接続は残ったまま。

#### ②ウォレット側の問題
切断命令が来ても、**36種類中22種類のウォレット**はそれを無視していました。

```
ユーザー：「切断してください」
  ↓
Webサイト：（自分の画面から接続表示を消すだけ）
  ↓
ウォレット：（まだアクセス許可が残っている）
  ↓
悪意あるスクリプト：「まだアドレスが読み取れる！」
```

**なぜ怖いのか：**
- クッキーと違って、**ブラウザをクリアしても消えない**
- **ブラウザを再起動しても残る**
- 手動でウォレットの「接続済みサイト」リストから削除しない限り、永遠にアクセスが続く

---

### 🔴 問題3：過去に接続したサイト経由で、他のサイトでもバレる

**例え話で説明すると…**
あなたが昔、会員登録したショッピングサイトAがあります。全く関係のないニュースサイトBを見ていたら、ニュースサイトBにいる「追跡業者」がこっそりショッピングサイトAを裏で呼び出して、あなたの個人情報を取得する…というイメージです。

**技術的な仕組み：**

```
あなたが「ニュースサイトB」を見ている
  ↓
ニュースサイトBに埋め込まれた追跡スクリプトが動く
  ↓
スクリプトが「過去に接続したことのある暗号資産アプリA」を
invisible（見えない）なフレームとして裏で読み込む
  ↓
アプリAはすでにあなたのウォレットの許可を持っている
  ↓
スクリプトはあなたのウォレットアドレスを取得！
  ↓
「ニュースサイトBを見ていたのは、暗号資産アドレス0xAbCd...の人物だ」と特定される
```

これにより、**匿名のはずの暗号資産の使用履歴が、現実世界の本名やメールアドレスと紐付けられる可能性**があります。

## なぜ重要なのか

### 影響の大きさ

| 問題 | 影響を受けるウォレット数 | 影響を受けるユーザー数 |
|------|------------------------|----------------------|
| 問題1（アドレスの紐付け） | 17種類 | 約2,300万人 |
| 問題2・3（ログアウト不全・追跡） | 36種類 | 調査対象の約82% |

### プライバシーへの深刻な影響

暗号資産は「**匿名性**」が売りの一つです。しかし今回の調査で：

- 🔍 複数のウォレットアドレスが同一人物のものだと特定される
- 🌐 サイトをまたいで行動が追跡される
- 👤 「匿名」のはずの暗号資産の持ち主に、現実の名前・メールが紐付けられる

これは金融プライバシーの根本を脅かす問題です。

### ウォレット開発者の反応が衝撃的

研究チームが最も深刻な問題をウォレット開発者に事前報告したところ、**多くの開発者が「これはバグではない」と回答**しました。設計上の仕様と考えているためです。つまり、開発者が自主的に修正する動機が薄い状況です。

## 対策・今後の展望

### 今すぐできる対策

#### ✅ ユーザーとして
1. **接続済みサイトを定期的に確認・削除する**
   - ウォレットの設定から「接続済みサイト（Connected Sites）」を開いて、不要なサイトとの接続を手動で解除しましょう
   
2. **使い終わったら必ず手動でウォレットの接続を切る**
   - サイト側のログアウトボタンだけでなく、ウォレット側の操作も忘れずに
   
3. **ウォレットごとにアドレスを厳密に分ける**
   - 同じウォレットアプリで複数アドレスを管理すると紐付けリスクがある
   - 用途ごとに**別のウォレットアプリ**を使い分けると安全性が上がる
   
4. **不審なWebサイトに安易にウォレットを接続しない**

#### ✅ 開発者・業界として
- ウォレット開発者が「プライバシー保護」を設計の優先事項にする必要がある
- Web3サイト側も、ログアウト時に正しく切断命令を送る実装を行うべき
- ブラウザ側での制限（拡張機能の権限管理の強化）も求められる

### 今後の展望
この研究がPETS 2026で発表されることで、業界全体への圧力が高まることが期待されます。また、EU（ヨーロッパ連合）のGDPRなどのプライバシー規制の観点からも、今後規制当局が注目する可能性があります。

## 過去記事との関連

今回は特定の過去記事との直接的な関連はありませんが、**「使っているツール自体が情報を漏らしている」** という問題は、セキュリティの世界でよく起きるパターンです。

例えば以前から指摘されている「VPNサービスが逆にユーザー情報を記録・販売している問題」や「セキュリティソフトがデータを収集している問題」と同じ構造です。「安全のために使っているツールが、実は情報を漏らしている」というのは、非常に重要なセキュリティ上の教訓です。

## 用語解説

| 用語 | 説明 |
|------|------|
| **暗号資産（仮想通貨）** | ビットコイン・イーサリアムなど、ブロックチェーン上で管理されるデジタルな通貨 |
| **ウォレット拡張機能** | ブラウザに追加してインストールする、暗号資産管理ツール |
| **ウォレットアドレス** | 暗号資産の送受信に使う、口座番号のような識別文字列 |
| **ブロックチェーン** | 取引履歴を分散管理する技術。改ざんが困難 |
| **Web3** | ブロックチェーンを基盤とした次世代インターネットサービスの総称 |
| **フィンガープリンティング** | クッキーを使わずにブラウザの特徴を組み合わせて個人を特定する技術 |
| **クッキー** | Webサイトがブラウザに保存する小さなデータ。閲覧履歴や認証情報を保持する |
| **iframeフレーム** | Webページの中に別のWebページを埋め込む技術。今回は悪用される形で登場 |
| **PETS** | Privacy Enhancing Technologies Symposium。プライバシー技術の国際学会 |
| **KUルーヴェン大学** | ベルギーの名門大学。セキュリティ・プライバシー研究で世界的に著名 |
| **リクエスト** | ブラウザやアプリが外部サーバーに情報を要求する通信のこと |
| **GDPR** | EU（欧州連合）の個人情報保護規則。違反には巨額の制裁金が課される |

---

> 💡 **まとめ**：暗号資産ウォレットは「匿名性」を守るために使われることが多いですが、そのウォレット自体がプライバシーを漏らしている可能性があります。「便利なツールだから安全」とは限りません。使い方とリスクをしっかり理解した上で活用することが大切です。
