# マイクロソフトが過去最多622件の脆弱性を修正！そのうち2件はすでに攻撃に悪用中

**元記事**: [Microsoft Patches Record 622 Flaws, Including Two Zero-Days Under Active Attack](https://inl03.netline.com/ltr6/?_m=3n.009a.4030.sp0ao46r89.333e)
**解説日**: 2026年7月15日

---

## 背景知識

まずこのニュースを理解するために、いくつかのキーワードを説明します。

### 🗓️ Patch Tuesday（パッチチューズデー）とは？
マイクロソフトが毎月第2火曜日に行う「セキュリティ修正プログラムの一斉配布日」のことです。家の鍵穴のほころびをまとめて修理する日、とイメージするといいでしょう。

### 🔓 ゼロデイ脆弱性とは？
「修正パッチが存在しない（＝ゼロ日）のに、すでに攻撃者に悪用されている穴」のことです。鍵屋さんが新しい鍵を作る前に、泥棒がその穴を使い始めている状態です。

### 🏢 SharePoint Serverとは？
会社の中で使う「文書や情報を共有するためのシステム」です。社内のファイルサーバーや社内Wikiのようなものと思ってください。

### 🔑 Active Directory Federation Services（AD FS）とは？
「社内のさまざまなシステムへのログインを一括管理する認証サーバー」です。学校でいうと、生徒証1枚で図書館も体育館も使えるようにする仕組みの管理者、みたいなイメージです。

### 🔒 BitLockerとは？
Windowsに搭載されている「ハードディスクを丸ごと暗号化する機能」です。パソコンを盗まれてもデータを読めなくする仕組みです。

---

## 何が起きたのか

2026年7月のPatch Tuesdayで、マイクロソフトが**史上最多となる622件**もの脆弱性（セキュリティの穴）を修正しました。これは昨年6月の最多記録（約200件）の**3倍以上**という驚異的な数字です。

その中でも特に注意が必要なのが、**すでに攻撃者に悪用されている2つのゼロデイ脆弱性**です。

| 脆弱性番号 | 対象システム | 概要 |
|---|---|---|
| CVE-2026-56164 | SharePoint Server | ログインなしで権限を昇格できる |
| CVE-2026-56155 | AD FS | ログイン済みユーザーがより高い権限を取得できる |

また、公開はされているがまだ攻撃には使われていない3つ目のゼロデイ（BitLockerのバイパス：CVE-2026-50661）も修正されています。

---

## 技術的な詳細

### ① SharePointの脆弱性（CVE-2026-56164）

> 「ログインすらしていない外部の攻撃者が、ネットワーク越しに管理者権限を奪える」

これは非常に危険です。例えるなら、**「鍵を持っていない人が、玄関の前に立つだけでドアが開いて、しかも家の主になれてしまう」**状態です。

- 発見したのは：セキュリティ会社MandiantとGoogleのFLAREチーム（実際の攻撃現場で発見）
- 追い打ち情報：**SharePoint Server 2016と2019は本日をもってサポート終了**。延長サポートの有料プログラムも存在しない

### ② AD FSの脆弱性（CVE-2026-56155）

> 「一度ログインした攻撃者が、そのサーバー上でより高い権限を取得できる」

AD FSは「全システムへのログインを管理する親玉」なので、ここを乗っ取られると会社中のシステムへのアクセスが危うくなります。例えるなら、**「学校の生徒証発行担当者を乗っ取ると、全生徒の偽造証明書が作り放題になる」**イメージです。

- 発見したのは：マイクロソフト自身のインシデント対応チーム（DART）
- 「ローカル（local）」な脆弱性と表示されているが、**AD FSは全システムの根幹**なので実際の危険度は表示より高い

### ③ SharePointの別の脆弱性（CVE-2026-55040）

セキュリティコンテスト「Pwn2Own Berlin」でRapid7 Labsが発見した脆弱性で、**「認証（ログイン確認）をすり抜ける脆弱性」**です。

ただし、これはさらに別の「遠隔コード実行（RCE）」の脆弱性と組み合わせることで、完全な攻撃チェーン（一連の攻撃手順）が成立します。今月はこの「入り口を突破する部分」だけ修正され、**RCE部分の修正は2026年8月に延期**されています。

深刻度の評価についても混乱があり、Rapid7は「5.3（中程度）」、ZDIは「9.1（緊急）」と評価が割れているのも今回の特徴です。

### ④ KerberosのRC4暗号化廃止

少し専門的な話になりますが、Windows認証に使われる「Kerberos（ケルベロス）」というシステムで、古くて脆弱な暗号方式「RC4」の使用が今月のアップデートで完全に廃止されます。長年の「移行猶予機能」が削除されるため、設定が古いままだとログインができなくなるケースもあります。

## なぜ重要なのか

### 📊 規模が前例がない
622件という数字は、これまでの記録の3倍超。企業のIT部門にとって、優先順位をつけるだけでも大変な作業になります。

### ⚠️ 深刻度ラベルが当てにならない
今回特に注意が必要なのが、**「深刻度が低く表示されているのに、実際の危険度は高い」**ケースが複数あることです。

- SharePointの脆弱性は深刻度評価が「低め」でも実際にはすでに攻撃されている
- AD FSの脆弱性は「ローカル」と書かれているが、全システムの認証基盤を握るサーバーの脆弱性

過去記事「CVSSスコアだけでパッチを当てるのをやめよう」でも指摘されていましたが、まさにそれが今月の現実として起きています。

### 🏢 企業インフラへの影響
SharePointとAD FSは多くの企業で使われている基幹システムです。これらが攻撃されると、**社内の文書が盗まれる、全社員のアカウントが乗っ取られる**といった深刻な被害が起こりえます。

## 対策・今後の展望

### ✅ 今すぐやるべきこと（優先順位順）

1. **SharePoint Serverを最新バージョンにアップデート**
   - 特にSharePoint 2016/2019を使っている場合は本日でサポート終了なので、移行計画も必要
   - サーバー設定で「AMSIフルモード」を有効化することで攻撃を防ぎやすくなる

2. **AD FSサーバーにパッチを適用**
   - こちらもすでに攻撃に使われているため一刻も早く対応を

3. **Windowsの月例アップデートを適用**
   - BitLockerバイパスや、その他620件の修正も含まれる

4. **Kerberos/RC4設定の確認**
   - RC4を使い続けている古いシステムがないか確認する（ログイン不能になるリスク）

### 🔮 今後の注目点

- CVE-2026-55040（SharePoint認証バイパス）とセットになるRCE脆弱性の修正が**8月に予定**されているため、8月のPatch Tuesdayも要注目
- CISAの「既知の悪用された脆弱性カタログ（KEV）」にはまだ未掲載だが、マイクロソフト自身が「悪用確認済み」と言っているため、**掲載を待たずに対応すること**を強く推奨

## 過去記事との関連

以前「**CVSSスコアだけでパッチを当てるのをやめよう**」という記事を紹介しましたが、今回の件はまさにその教訓の実例です。SharePointの脆弱性は深刻度スコアが低いにもかかわらずすでに攻撃に使われており、「数字だけ見ていると見逃す」典型例になっています。

また、「**Patch Tuesday直後に研究者がゼロデイPoCを公開**」という記事でも触れたように、パッチが出ると同時に攻撃者側も動き出すことがわかっています。今月は特に攻撃がすでに始まっているケースが複数あるため、**いつも以上に早急な対応が求められる月**といえます。

## 用語解説

| 用語 | 意味 |
|---|---|
| **Patch Tuesday** | マイクロソフトが毎月第2火曜日に行うセキュリティ修正の配布日 |
| **CVE** | 脆弱性に振られる世界共通の識別番号（例：CVE-2026-56164） |
| **ゼロデイ脆弱性** | パッチが存在しないのにすでに攻撃に使われている脆弱性 |
| **権限昇格（EoP）** | 通常よりも高い権限（管理者など）を不正に取得すること |
| **RCE（リモートコード実行）** | ネットワーク越しに攻撃者が好きなプログラムを実行できる脆弱性 |
| **SharePoint Server** | 会社内で文書や情報を共有するためのマイクロソフトのシステム |
| **AD FS** | 社内の各システムへのログインを一括管理する認証サーバー |
| **AMSI** | マルウェアを検知するWindowsのセキュリティ機能 |
| **Kerberos** | Windowsネットワークで使われる認証プロトコル（仕組み） |
| **RC4** | 古い暗号化方式。現在は脆弱として廃止が進んでいる |
| **JWT** | ログイン情報などをやり取りするためのデジタル証明書の一種 |
| **CVSS** | 脆弱性の深刻度を0〜10点で評価するスコア |
| **KEV** | CISAが管理する「実際に攻撃に悪用された脆弱性のリスト」 |
| **DART** | マイクロソフト社内のインシデント対応チーム |
| **Mandiant / FLARE** | サイバーセキュリティ専門企業Googleグループのチーム |
| **Pwn2Own** | ハッカーたちが脆弱性発見を競うセキュリティコンテスト |
