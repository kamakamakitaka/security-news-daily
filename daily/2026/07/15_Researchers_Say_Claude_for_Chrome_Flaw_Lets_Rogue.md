# Claude for Chromeの欠陥：悪意ある拡張機能がGmailを勝手に読み取れる

**元記事**: [Researchers Say Claude for Chrome Flaw Lets Rogue Extensions Trigger Gmail Reads](https://inl03.netline.com/ltr6/?_m=3n.009a.4030.sp0ao46r89.333k)
**解説日**: 2025年7月15日

---

## 背景知識

まず、今回の記事を理解するための前提知識をざっくり説明します。

### 🤖 Claude（クロード）とは？
AnthropicというAI企業が作った、ChatGPTと似たAIアシスタントです。ブラウザ拡張機能「Claude for Chrome」をインストールすると、ChromeブラウザからGmailやGoogleドキュメント、Googleカレンダーの内容をAIが読み取って、要約したり操作したりできます。

### 🧩 ブラウザ拡張機能（エクステンション）とは？
Chromeに追加できる「アドオン（小さなプログラム）」のことです。広告ブロッカーや翻訳ツールなどがこれにあたります。拡張機能は、Webページのデータを読んだり変更したりする「権限」を持てます。

### 🖱️ 「信頼できるクリック」と「偽クリック」
ブラウザには、**本当に人間がマウスでクリックしたか**、**プログラムが自動的に発生させたクリックか**を区別する仕組み（`isTrusted`フラグ）があります。今回の問題はここに関係しています。

### 🔐 CVSS（シービーエスエス）スコアとは？
脆弱性（セキュリティの弱点）の深刻さを0〜10点で表す指標です。7〜8.9は「High（重大）」、9以上は「Critical（致命的）」とされます。

---

## 何が起きたのか

セキュリティ研究会社「Manifold Security」が、**Anthropicの「Claude for Chrome」拡張機能に深刻な脆弱性**を発見しました。

簡単に言うと、こういうことです：

> 👿 **悪意ある別の拡張機能が、ユーザーに気づかれないまま、Claudeにあなたの Gmail・Googleドキュメント・Googleカレンダーを勝手に読ませることができる**

この問題は、2025年7月14日時点でまだ修正されていない（パッチ未提供）状態です。現在のバージョン（v1.0.80）でも影響を受けます。

## 技術的な詳細

### 🏠 例え話でイメージしてみよう

Claude for Chromeを「あなたの家の秘書ロボット」に例えてみましょう。

- この秘書ロボットは、決まった9種類のお使い（タスク）しかできません
- お使いを頼むには「玄関の特定のボタンを押す」必要があります
- でも、このボタン、**押した人が本物の人間かどうか確認していない**んです！

つまり、**悪者（不正な拡張機能）が「人間のふりをして偽のボタン押し」を作り出せる**というわけです。

---

### 🔧 実際の仕組み（もう少し詳しく）

**Step 1：許可されたタスク一覧**

以前の問題（ClaudeBleed）への対策として、Anthropicは「Claudeが外部から頼まれてできること」を9つだけに制限しました：

| カテゴリ | タスク |
|---|---|
| 練習用 | 3種類のチュートリアル |
| 外部サービス | DoorDash・Salesforce・Zillow操作 |
| **問題のタスク** | **Gmail読み取り・Googleドキュメント読み取り・カレンダー読み取り** |

**Step 2：偽クリックの仕組み**

拡張機能は「`#claude-onboarding-button`（特定のボタン要素）がクリックされたら動く」という設計になっています。しかしここで確認していないことが…

```
✅ 確認していること：タスクIDが9つのリストに含まれているか
❌ 確認していないこと：クリックが本物の人間によるものか（isTrustedの確認なし）
```

悪意ある拡張機能は、**プログラムで偽のボタンと偽のクリックを作り出すことができ**、Claude for Chromeはそれを本物のクリックと同じように扱ってしまいます。

**Step 3：2つのシナリオ**

| 設定モード | リスクレベル | 動作 |
|---|---|---|
| 「実行前に確認する（デフォルト）」 | CVSS 7.7（重大） | 確認ダイアログが出るが、偽タスクは起動される |
| 「確認なしで実行する（オフにした場合）」 | CVSS 9.6（致命的） | 何の確認もなくGmailなどが読み取られる |

**Step 4：隠れた2つ目の問題**

さらに、ClaudeのサイドパネルのURLに`?skipPermissions=true`というパラメータがつくと、**確認画面を完全にスキップして自動実行モードで起動**します。現時点では拡張機能自身しかこのURLを作れませんが、将来的に別の脆弱性と組み合わされると、ユーザーが何も気づかないまま全自動でアカウント情報が読み取られる可能性があります。

## なぜ重要なのか

### 📧 あなたの個人情報が危ない
GmailやGoogleカレンダーには、住所・電話番号・仕事の予定・個人的なやりとりなど、**かなりプライベートな情報**が含まれています。それが攻撃者に筒抜けになる可能性があります。

### 😱 攻撃が「意外と簡単」
研究者によると、攻撃のトリガー（引き金）は**たった6行のコードで動作確認できた**とのことです。これはセキュリティの世界では「再現ハードルが低い＝悪用されやすい」ことを意味します。

### 🔓 修正がまだない
2025年7月14日現在、パッチ（修正プログラム）は提供されていません。Anthropicは以前の問題（ClaudeBleed）の対策は行いましたが、今回の問題は残っています。

---

## 対策・今後の展望

### ✅ 今すぐできる対策

**① 「確認なしで実行する」モードをオフにする**（最重要！）
> Claude for Chromeの設定で「Act without asking（確認なしで実行）」がオンになっている場合は、今すぐオフにしてください。これでリスクレベルが「致命的」から「重大」に下がります。

**② claude.ai にアクセス権のある拡張機能を確認・整理する**
> Chromeの拡張機能管理画面（`chrome://extensions/`）を開き、`claude.ai` のデータを「読み取り・変更」できる拡張機能を確認しましょう。不要なものは削除または権限を制限してください。

**③ 信頼できない拡張機能をインストールしない**
> 今回の攻撃には「すでにclaude.aiにアクセスできる悪意ある拡張機能」が必要です。怪しい拡張機能をインストールしないことが根本的な予防策です。

### 🔧 本来の修正（開発者側）
研究者によると、修正は**ハンドラーの先頭に「偽クリックを拒否する1行を追加するだけ**」とのこと。シンプルな修正なのに、まだリリースされていないのが現状です。

### 🔮 今後の展望
Anthropicがパッチをリリースするまで、上記の自衛策を続けることが重要です。セキュリティメディアでも注目されているため、修正は近いうちに来る可能性はありますが、現時点では未定です。

## 用語解説

| 用語 | 意味 |
|---|---|
| **Claude for Chrome** | AnthropicのAI「Claude」をChromeで使うための拡張機能 |
| **ブラウザ拡張機能（エクステンション）** | Chromeなどに追加できる小さなプログラム |
| **ClaudeBleed** | 以前発見されたClaude for Chromeの脆弱性の名前 |
| **isTrusted** | ブラウザが「本物の人間のクリックかどうか」を判定するフラグ（印） |
| **コンテンツスクリプト** | 拡張機能がWebページの中で動かす小さなプログラム |
| **DOM（ドム）** | Webページの構造（タグ・ボタン・テキストなどの配置情報） |
| **CVSS（シービーエスエス）** | 脆弱性の深刻さを0〜10で表すスコア。9以上はCritical（致命的） |
| **skipPermissions=true** | 確認画面をスキップして自動実行するURL上の指示 |
| **パッチ** | ソフトウェアの欠陥を修正するための小さなアップデート |
| **XSS（クロスサイトスクリプティング）** | Webページに悪意あるスクリプトを埋め込む攻撃手法 |
| **サイドパネル** | ブラウザの画面の横に表示される補助画面 |
