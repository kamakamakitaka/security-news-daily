# 20以上の政府ウェブサイトが乗っ取られ、攻撃の踏み台にされた

**元記事**: [20+ Hijacked Government Websites Became an Attack Channel](https://inl03.netline.com/ltr6/?_m=3n.009a.4031.sp0ao46r89.333s)
**解説日**: 2025年7月11日

---

## 背景知識

今回の記事を理解するために、まずいくつかの基本的な概念を説明します。

### 🏛️ 政府ウェブサイトって信用できるんじゃないの？
私たちは「gov.jp（日本の政府サイト）」や「gov.br（ブラジルの政府サイト）」のようなドメインを、なんとなく「安全」「信頼できる」と感じますよね。実はそれが今回の攻撃の**核心的なポイント**です。悪い人たちは、その「信頼感」を逆手に取りました。

### 📧 メールの「本物認証」の仕組み（SPF・DKIM・DMARC）
普段のメールには「このメール本当に正規の送信者から来てますよ」を証明する仕組みがあります。
- **SPF**：「このサーバーから送ったメールは本物ですよ」という証明
- **DKIM**：「このメールは改ざんされていないですよ」という電子署名
- **DMARC**：上の2つを組み合わせて「偽物メールを弾く」ルール

これらをすべてパスしたメールは、メールセキュリティの目をくぐり抜けてしまいます。

### 🎭 バックドアとは？
「裏口」のことです。泥棒が家の鍵を複製して、いつでも忍び込めるようにすることを想像してください。コンピュータの世界でも同様に、ウイルスが「裏口」を作って、攻撃者がいつでも侵入・操作できる状態にします。

### 🧩 C2（コマンド＆コントロール）インフラとは？
攻撃者が感染したコンピュータに「命令を送るための司令塔サーバー」のことです。軍隊でいう「司令部」のようなものです。

## 何が起きたのか

### 概要
ブラジルで「**PhantomEnigma（ファントム・エニグマ）**」と名付けられたサイバー攻撃キャンペーンが発覚しました。マルウェア分析企業「ANY.RUN」の調査により、以下のことが明らかになりました。

> 🚨 **20以上のブラジル政府ウェブサイトが乗っ取られ、マルウェア（悪意あるプログラム）を配布する踏み台として使われていた！**

攻撃の対象は銀行や公共機関。被害者は気づかないまま、信頼できるはずの「政府サイト」からウイルスをダウンロードさせられていました。

### 被害を受けたサイトの例
- `timon.ma.gov.br`（市町村ポータル）
- `loginam.sesp.es.gov.br`（州の公安部門）
- `aplicacao.cbm.mt.gov.br`（消防署）
- `prodoc.ap.gov.br`（行政文書サイト）

## 技術的な詳細

### 攻撃の流れ（ステップ・バイ・ステップ）

攻撃は下記のような**7段階**で被害者を追い詰めます。わかりやすくたとえ話で説明します。

```
【攻撃のステップ図】

 ① 偽メール受信
      ↓
 ② 政府サイトへリダイレクト（見た目は本物）
      ↓
 ③ 悪意あるインストーラーをダウンロード
      ↓
 ④ 改ざんされた正規アプリが起動
      ↓
 ⑤ バックドア（裏口）が開く
      ↓
 ⑥ 追加ウイルスが次々ダウンロード
      ↓
 ⑦ 認証情報盗難・不正アクセス・詐欺被害
```

#### ① フィッシングメールが届く
警察からの公式通知に見せかけた偽メール（「Ofício Polícia Civil＝民事警察公文書」「Procuração Digital＝デジタル委任状」）が届きます。QRコードや公式っぽいリンクが含まれています。

📮 **たとえ話**：「警察から封書が届いた。開けると『あなたに重要な通知があります。このURLにアクセスしてください』と書いてある」—そんなイメージです。

#### ② 本物そっくりな政府サイトを経由させる
メールのリンクをクリックすると、**実際の政府ドメイン（.gov.br）を経由**してリダイレクト（転送）されます。ここが巧妙なポイントで、URLに本物の政府サイトのアドレスが含まれているため、セキュリティチェックを通過しやすい状態になっています。

#### ③〜④ 悪意あるインストーラーが動く
最終的に「Inno Setup」や「MSI」形式のインストーラー（一見すると普通のソフトウェア）がダウンロードされます。これを実行すると、「Boostnote（実在するメモアプリ）」などの**正規ソフトを改ざんしたもの**がインストールされます。

🎭 **たとえ話**：「本物のコーラの缶に毒を入れて渡す」ようなイメージです。外見は正規のソフトなのに、中身が入れ替わっています。

#### ⑤ バックドア（裏口）が開く
インストールされたアプリの中に`index.js`という**悪意あるスクリプト**が仕込まれており、これが実行されると：
- 感染したコンピュータの情報を収集
- 起動するたびに自動で動く「永続化」を設定
- 攻撃者の司令塔サーバー（C2）に接続

#### ⑥ 追加の悪意あるプログラムが送り込まれる
バックドアが開くと、攻撃者はそこから追加のウイルスを何でも送り込めます：
- **情報窃取ツール（Stealer）**：パスワードや銀行情報を盗む
- **RMMソフトウェア**：リモートで操作できるツール（本来は正規のリモートサポートソフト）
- **追加のローダー**：さらに別のウイルスを呼び込む

#### ⑦ 最終的な被害
- 認証情報（ID・パスワード）の盗難
- 不正アクセス
- 金融詐欺
- データ漏洩
- 業務停止

### なぜ見つかりにくかったのか？3つの理由

| 理由 | 説明 |
|------|------|
| 🏛️ **信頼されたインフラの悪用** | 本物の政府サイトを経由するため、セキュリティツールが怪しいと思わない |
| 📧 **認証メールの通過** | SPF・DKIM・DKIMをすべてパスした正規に見えるメール |
| 🔄 **ころころ変わるC2** | 司令塔サーバーのアドレスを頻繁に変えることで、ブロックリストを無効化 |

## なぜ重要なのか

### 1. 「信頼できるもの」が武器にされた
今回最も恐ろしいのは、**私たちが信頼していたもの（政府サイト・公式メール）が攻撃に使われた**という点です。

「URLに gov.br が入っているから安全」という常識が通用しなくなっています。

### 2. 攻撃が進化し続けている
記事によると、このPhantomEnigmaは段階的に進化しています：

- **2025年**：銀行に特化したマルウェアとして活動
- **2026年**：政府サイト・メールアカウントを悪用した高度な攻撃に進化

単純なウイルスから、**モジュール型（部品を入れ替えられる）バックドア**へと変化しており、攻撃の対応が非常に難しくなっています。

### 3. 日本への教訓
これはブラジルの話ですが、同様の手法は世界中で使われる可能性があります。日本の「go.jp」ドメインも同様に悪用される可能性は理論的にゼロではありません。公共機関のセキュリティ強化が世界的に求められています。

## 対策・今後の展望

### 🙋 一般ユーザーができること

#### メールを受け取ったとき
- [ ] URLが政府ドメインでも、**リンクをむやみにクリックしない**
- [ ] 添付ファイルやインストーラーは、**本当に必要かどうか確認してから実行**
- [ ] QRコードを使った誘導も**偽物の可能性がある**と疑う
- [ ] 不審なメールは**公式の電話番号に直接確認**する

#### ソフトウェア・端末の管理
- [ ] OSやアプリを**常に最新の状態に保つ**
- [ ] 信頼できるセキュリティソフトを使う
- [ ] 多要素認証（2段階認証）を設定する

### 🔐 セキュリティ担当者・IT部門向けのポイント

1. **静的ブロックリストに頼りすぎない**：C2ドメインは頻繁に変わるため、IPやドメインのブロックだけでは不十分
2. **振る舞い検知（ビヘイビア分析）を導入**：「何をしているか」でウイルスを検出する
3. **継続的な脅威ハンティング**：異常な通信パターンを常に監視する
4. **政府系ドメインへの過信をなくす**：信頼できるインフラも侵害される可能性がある

### 今後の展望
ANY.RUNのような**インタラクティブなサンドボックス分析**（ウイルスを安全な隔離環境で実際に動かして調べる）が、このような巧妙な攻撃を見つけるうえで有効です。今後は、AIを活用した異常検知や、リアルタイムの脅威インテリジェンス共有がより重要になっていくでしょう。

## 過去記事との関連

今回は特定の過去記事との直接的な関連は示されていませんが、**サプライチェーン攻撃**（信頼されたインフラや組織を踏み台にする攻撃）や**フィッシング攻撃の高度化**については、セキュリティニュースで繰り返し取り上げられているテーマです。

「信頼できるはずのものを悪用する」という手口は、過去のSolarWinds事件（2020年）やMicrosoft Exchange脆弱性悪用事件（2021年）とも共通しています。攻撃者は常に「人が信頼しているもの」を狙い続けています。

## 用語解説

| 用語 | わかりやすい説明 |
|------|-----------------|
| **マルウェア** | 悪意を持って作られたプログラムの総称。ウイルスもその一種 |
| **バックドア（裏口）** | 攻撃者が侵入するために仕込んだ「秘密の入り口」 |
| **フィッシング** | 本物そっくりの偽メールや偽サイトで、個人情報を騙し取る攻撃 |
| **SPF / DKIM / DMARC** | メールが「本物の送信者から来た」ことを証明する技術的な仕組み |
| **リダイレクト** | あるURLにアクセスすると、自動的に別のURLに転送されること |
| **C2（コマンド＆コントロール）** | 感染したPCに命令を送る攻撃者の司令塔サーバー |
| **Inno Setup / MSI** | Windowsで使われるプログラムのインストーラー形式 |
| **Electron アプリ** | Webブラウザのエンジンをベースにしたデスクトップアプリのフレームワーク（DiscordやVSCodeもこれで作られている） |
| **モジュール型マルウェア** | 部品（モジュール）を入れ替えることで機能を変えられる、柔軟なウイルス |
| **RMMソフトウェア** | 本来はリモートサポート用の正規ツール。悪用されると遠隔操作に使われる |
| **サンドボックス** | ウイルスを安全な隔離環境の中で動かして、挙動を分析する仕組み |
| **脅威インテリジェンス** | 攻撃者の手口・インフラ・目的などをまとめた「攻撃者情報」 |
| **永続化（Persistence）** | PCを再起動してもマルウェアが自動的に起動し続けるよう設定すること |
| **.gov.br** | ブラジルの政府機関が使う公式ドメイン（日本の go.jp に相当） |
