# Firefox・Chrome・Adobe・VMwareのアップデートで複数の重大なセキュリティ欠陥を修正

**元記事**: [Firefox, Chrome, Adobe, and VMware Updates Fix Multiple Critical Security Flaws](https://inl03.netline.com/ltr6/?_m=3n.009a.4031.sp0ao46r89.334y)
**解説日**: 2025年7月14日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な知識を押さえておきましょう。

### 🔑 ソフトウェアの「脆弱性（ぜいじゃくせい）」って何？

脆弱性とは、ソフトウェアの「穴」や「バグ」のことです。家に例えると、**鍵のかかっていない窓**のようなもので、そこから悪意のある人（ハッカー）が侵入できてしまう状態です。

### 🔑 CVE番号って何？

`CVE-2026-XXXXX` という形式の番号は、発見されたセキュリティの穴に世界共通でつけられる「欠陥の整理番号」です。世界中のセキュリティ研究者が同じ問題を話し合えるように、住所のような役割を果たしています。

### 🔑 CVSSスコアって何？

脆弱性の「危険度ランク」を0〜10点で表した数字です。

| スコア | 危険度 |
|--------|--------|
| 9.0〜10.0 | 🔴 緊急（Critical）|
| 7.0〜8.9  | 🟠 重要（High）|
| 4.0〜6.9  | 🟡 中程度（Medium）|
| 0〜3.9    | 🟢 低（Low）|

今回の記事は、**9点台のスコアが並ぶ、非常に深刻なニュース**です。

## 何が起きたのか

今回、私たちが日常的に使っている有名なソフトウェアで、一度に大量の重大な脆弱性が発見・修正されました。関係する製品をまとめると以下の通りです。

### 🦊 Firefox（ブラウザ）
- **2件**の重大な脆弱性を修正
- 修正済みバージョン: **Firefox 152.0.6**

### 🌐 Google Chrome（ブラウザ）
- **15件**のセキュリティ欠陥を修正（うち2件が重大）
- 修正済みバージョン: **Chrome 150.0.7871.124/.125**

### 🎨 Adobe（ソフトウェア会社）
- **88件**もの脆弱性を修正（過去最大級の規模！）
- 影響製品: ColdFusion、Commerce、Experience Manager、Illustratorなど

### 🖥️ VMware（仮想化ソフト）
- Avi Load Balancerで**最高危険度クラス**（CVSSスコア9.8）の脆弱性を修正

## 技術的な詳細

各製品の脆弱性の「仕組み」をわかりやすく解説します。

---

### 🦊 Firefoxの脆弱性

#### CVE-2026-15718｜無効なポインタ（WebAssembly）
- **難しい言葉**: 「JavaScript の WebAssembly コンポーネントにおける無効なポインタ」
- **わかりやすく言うと**: プログラムが「存在しないはずの場所」にアクセスしようとしてしまうバグです。本来は読んではいけないメモリの場所を読んでしまい、悪用されると悪意あるプログラムが動いてしまう可能性があります。

#### CVE-2026-15719｜サイト分離の欠陥（DOM / Navigation）
- **難しい言葉**: 「DOM の Navigation コンポーネントにおけるサイト分離の問題」
- **わかりやすく言うと**: ブラウザは本来、「A というサイトのデータ」と「B というサイトのデータ」を完全に分けて管理しています。この分離が破れてしまうと、悪意のあるサイトが別のサイトの情報（ログイン状態など）を盗めてしまう恐れがあります。

> ⚠️ **特に注意！**: Mozillaは「この脆弱性を悪用するためのコードがすでにインターネット上に公開されている」と発表しています。つまり、ハッカーが使える「道具」がすでに出回っているということです。

---

### 🌐 Google Chromeの脆弱性

#### CVE-2026-15764 / CVE-2026-15765｜Use-After-Free（Ozone）
- **難しい言葉**: 「Ozone における Use-After-Free バグ」
- **わかりやすく言うと**:
  - **Use-After-Free** = 「もう使わなくなった（捨てた）データの置き場所」を、間違えて再度使ってしまうバグ
  - 捨てたはずのゴミ箱の中身を別の人が書き換えてしまい、それを自分が読み込んでしまうイメージです
  - **Ozone** = ChromeがLinuxなどで画面表示をするための部品
- **危険性**: 特定の操作をさせる罠を仕込んだWebページを開くだけで、パソコンが攻撃者に乗っ取られる可能性があります

---

### 🎨 Adobeの脆弱性（ColdFusion 編）

Adobeの「ColdFusion（コールドフュージョン）」はWebサイトを動かすためのサーバーソフトです。ここに8件の重大な脆弱性が見つかりました。

| 脆弱性の種類 | わかりやすい説明 | 危険度 |
|---|---|---|
| **パストラバーサル** | 「入ってはいけないフォルダ」に侵入できる穴 | 9.9 / 9.1 |
| **コードインジェクション** | サーバーに悪意あるプログラムを送り込む攻撃 | 9.6 |
| **不適切な入力検証** | 入力チェックが甘く、悪意あるデータが通ってしまう | 9.6 |
| **不正な認可** | 本来アクセスできないはずの人がアクセスできてしまう | 9.3 / 9.0 |
| **認証なしで重要機能を実行** | パスワードなしで重要な操作ができてしまう | 9.3 |
| **SQLインジェクション** | データベースに不正な命令を送り込む攻撃 | 9.1 |

---

### 🖥️ VMwareの脆弱性

- **製品**: VMware Avi Load Balancer（大規模なシステムで通信を振り分けるソフト）
- **脆弱性の種類**: 認証バイパス（CVSSスコア: **9.8**）
- **わかりやすく言うと**: 「パスワードチェックをすり抜けられる穴」です。ネットワークにアクセスできる悪意のある人が、本来ならログインが必要な管理画面に**パスワードなしで侵入できてしまう**という非常に危険な欠陥です。
- **発見者**: NATO（北大西洋条約機構）のサイバーセキュリティセンターの研究者が発見しました。

## なぜ重要なのか

### 📌 あなた自身への影響

| 製品 | あなたへの影響 |
|---|---|
| Firefox / Chrome | 毎日使うブラウザなので、古いバージョンのままだと悪意のあるサイトを開くだけで被害を受ける可能性がある |
| Adobe製品 | デザインやWebサービスをよく使う人、仕事でAdobeを使っている企業が対象 |
| VMware | 主に企業のITシステムに影響。でも企業が被害を受けるとサービス停止などで一般ユーザーにも影響が出ることがある |

### 📌 「エクスプロイトコードが公開されている」の深刻さ

Firefoxの脆弱性について、「エクスプロイトコード（攻撃に使うプログラム）がすでに公開されている」という点は特に重要です。

```
🔓 脆弱性発見
    ↓
🔓 エクスプロイトコードが公表される ← 今ここ！（Firefoxの場合）
    ↓
🔴 ハッカーが実際の攻撃に使い始める（まだ確認されていないが時間の問題）
```

つまり、**今すぐアップデートしないと危険**という状況です。

## 対策・今後の展望

### ✅ 今すぐできること

#### 🦊 Firefox を使っている人
1. Firefoxを開く
2. 右上のメニュー（≡）→「ヘルプ」→「Firefoxについて」
3. 自動的に最新版（152.0.6以上）に更新される

#### 🌐 Google Chrome を使っている人
1. Chromeを開く
2. 右上のメニュー（⋮）→「設定」→「Chromeについて」
3. 最新版（150.0.7871.124以上）に更新される

#### 🎨 Adobeを使っている人（企業・クリエイター向け）
- Adobe Creative Cloudのアップデートを確認し、最新版に更新する
- ColdFusion を使っている場合: バージョン 2025 Update 11 または 2023 Update 22 に更新

#### 🖥️ VMwareを使っている企業の方
- Broadcomの公式サイトから最新のパッチを適用する

---

### 🔭 今後の展望

- 現時点では「実際の攻撃に悪用された」という報告はありませんが、エクスプロイトコードが公開されている以上、**攻撃者が使い始めるのは時間の問題**です。
- 企業のIT担当者は、今回の脆弱性が「攻撃者に人気の標的」になりやすいAdobeやVMware製品であることを念頭に、迅速な対応が求められます。

## 過去記事との関連

今回は特定の過去記事との直接の関連はありませんが、このような「複数製品の重大な脆弱性が同時に公開される」ケースは、**月例パッチ（定期的なアップデート）** のタイミングに合わせて起きることがよくあります。特にAdobeは毎月第2火曜日（通称「パッチチューズデー」）に合わせてアップデートを公開する傾向があります。ブラウザ（Firefox・Chrome）も定期的にアップデートが配信されており、「面倒くさい」と後回しにせず、こまめに更新することがセキュリティの基本です。

## 用語解説

| 用語 | 意味 |
|---|---|
| **脆弱性（ぜいじゃくせい）** | ソフトウェアのセキュリティ上の「穴」や「バグ」 |
| **CVE番号** | 脆弱性に割り振られる世界共通の整理番号 |
| **CVSSスコア** | 脆弱性の危険度を0〜10で表したスコア |
| **エクスプロイトコード** | 脆弱性を実際に攻撃するために使うプログラム |
| **Use-After-Free** | 解放済みのメモリ領域を再利用してしまうバグ |
| **SQLインジェクション** | データベースに不正な命令を送り込む攻撃手法 |
| **コードインジェクション** | 悪意あるプログラムをシステムに送り込む攻撃 |
| **パストラバーサル** | 本来アクセスできないフォルダに不正侵入する攻撃 |
| **認証バイパス** | パスワード認証をすり抜けて不正アクセスする攻撃 |
| **WebAssembly** | ブラウザ上で高速にプログラムを動かす技術 |
| **DOM** | Webページの構造を表すデータの仕組み |
| **Load Balancer** | 大量のアクセスを複数のサーバーに振り分ける装置 |
| **パッチ** | バグや脆弱性を修正するための更新プログラム |
