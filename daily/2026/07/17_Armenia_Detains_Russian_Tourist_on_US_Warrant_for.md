# アルメニアでロシア人観光客がREvil（ランサムウェア）ハッカーとして拘束される――弁護士は「人違い」と主張

**元記事**: [Armenia Detains Russian Tourist on U.S. Warrant for REvil Hacker, Lawyers Say Wrong Man](https://inl03.netline.com/ltr6/?_m=3n.009a.4032.sp0ao46r89.335o)
**解説日**: 2025年7月11日

---

## 背景知識

このニュースを理解するために、いくつかのキーワードを押さえておきましょう。

### 🔐 ランサムウェアとは？
「ランサム（Ransom）」は英語で「身代金」という意味です。ランサムウェアとは、**被害者のコンピューターのファイルを暗号化（鍵をかけて読めなくする）し、元に戻す代わりにお金（多くは暗号通貨）を要求するウイルス（マルウェア）** のことです。

> 🏠 **例え話**: 誰かがあなたの家の中身を全部鍵のかかった箱に詰め込んで、「お金を払わないと鍵を渡さないよ」と脅すイメージです。

### 💀 REvil（リービル）とは？
REvil（別名：Sodinokibi／ソディノキビ）は、**世界最悪レベルのランサムウェア犯罪グループ** です。ロシアを拠点とし、2019年〜2021年ごろに活発に活動していました。被害者は病院、学校、企業、政府機関など1,000社以上にのぼり、**グループ全体で数百億円規模の身代金を稼いだ** とされています。

### 🏥 Medibank（メディバンク）とは？
オーストラリア最大級の民間医療保険会社です。2022年10月にサイバー攻撃を受け、**970万人分の個人情報（氏名・住所・病歴など）が盗まれ、一部がダークウェブ（闇のインターネット）に流出** しました。

### 🌐 インターポール（Interpol）とは？
**国際刑事警察機構**のことで、190か国以上が加盟する国際的な警察の連絡組織です。ある国が指名手配犯を「国際手配」すると、加盟各国の空港や国境で自動的にチェックが入る仕組みがあります。

### 📜 制裁（サンクション）とは？
特定の人物や組織に対して、**資産凍結・入国禁止・取引禁止などの罰則を科す国際的な措置**です。アメリカ（OFAC）・オーストラリア・イギリスが2024年1月に今回の人物に制裁を科しました。

## 何が起きたのか

### 事件の流れ

```
2019年〜2021年
└─ REvilがランサムウェア攻撃（被害者1,000社以上）

2022年10月
└─ Medibankがサイバー攻撃を受け970万件の個人情報流出

2024年1月
└─ 米・英・豪が「Aleksandr Gennadievich Ermakov（アレクサンドル・ゲンナジエヴィチ・エルマコフ）」を制裁対象に指定

2025年6月26日
└─ アメリカのテキサス州連邦裁判所が逮捕状を発行

2025年6月28日
└─ アルメニアの空港で「Aleksandr Ermakov」という名のロシア人観光客を拘束
      ↓
   弁護士「この人はErmakov（別人）で、オムスク出身の元弁護士です！」
```

### 具体的に何があったか

アルメニア（コーカサス地方の国）の首都エレバンにある空港で、**ロシア人観光客のアレクサンドル・エルマコフさん**が出発ロビーから連行されました。係員はSNS（VKontakte＝ロシア版Facebook）から取った写真をスマホで見せ、「あなたですね？」と確認して別室へ連れて行ったとのことです。

アメリカが求めているのは **「Aleksandr Gennadievich Ermakov（ゲンナジエヴィチ）」** というREvil関係者ですが、拘束されたのは **「Aleksandr Yuryevich Ermakov（ユーリエヴィチ）」** という、オムスク出身の元刑務所弁護士だと弁護士たちは主張しています。

> 🇯🇵 **例え話**: 「田中太郎」という指名手配犯がいるのに、同じ「田中太郎」という名前の無関係な人が逮捕されてしまったようなイメージです。

## 技術的な詳細

### なぜ「人違い」が起きたのか？

弁護士のDylan Rajavi氏は次のように説明しています。

> 「アメリカの書類には**名字と名前しか記載されておらず**、自動照合システムがそれに反応してしまった可能性が高い」

ロシアのパスポートには、日本の名前でいう「○○ **の** 息子」「○○ **の** 娘」を意味する **「父称（パトロニミック）」** という第3の名前が含まれています。

| 名前の種類 | 意味 | 今回の例 |
|-----------|------|---------|
| 名（Given name） | ファーストネーム | Aleksandr |
| 父称（Patronymic） | 父親の名＋子を意味する語尾 | **Gennadievich**（ゲンナジエヴィチ）= ゲンナジーの息子 |
| 姓（Surname） | 苗字 | Ermakov |

アメリカの制裁リスト（OFAC）には、この**父称が記載されていなかった**ことが指摘されています。オーストラリアやイギリスの制裁リストには「Gennadievich」という父称がちゃんと入っていたにもかかわらず、です。

```
🇦🇺 オーストラリアの制裁リスト → Aleksandr [Gennadievich] Ermakov ✅
🇬🇧 イギリスの制裁リスト    → Aleksandr [Gennadievich] Ermakov ✅
🇺🇸 アメリカの制裁リスト    → Aleksandr Ermakov のみ ⚠️
                                ↑父称なし！
```

さらに、弁護士は「指紋照合や完全なパスポートデータなどの本人確認が行われていない」とも主張しており、「あるのは逮捕状だけだ」と述べています。

### REvil犯罪の手口

REvilは **「RaaS（Ransomware as a Service＝サービスとしてのランサムウェア）」** というビジネスモデルを使っていました。

> 🛒 **例え話**: まるで「フランチャイズ」のように、ランサムウェアの開発者グループが攻撃ツールを「貸し出し」、別の攻撃者（アフィリエイト）が実際に企業を攻撃して、身代金の一部を開発者グループに上納する仕組みです。

今回の容疑者は、このプラットフォームの**管理者（アドミニストレーター）** の一人で、1,370万ドル（約20億円）以上を得たと報じられています。

### 容疑者の特定はどうやって行われたか？

オーストラリア当局は**「オペレーション・アクイラ」**と呼ばれる捜査を18か月かけて実施し、以下の手がかりをもとに特定しました。

1. **ニックネーム（ハンドル名）の追跡**
   - `JimJones`、`blade_runner`、`GustaveDore` などのオンライン上の別名
2. **フォーラム投稿の分析**
   - `JimJones` というアカウントが2019〜2020年、「Exploit」というハッカー向けフォーラムでマルウェア開発サービス「Shtazi-IT」を宣伝していた
3. **情報企業による逆引き調査**
   - サイバー情報企業「Intel 471」が過去のフォーラムデータを遡って調査し、複数のニックネームが同一人物に紐づくことを確認

## なぜ重要なのか

### 1. 🌍 国際的な法執行の限界が露わになった

今回の件は、**国際的な指名手配システムの脆弱性**を示しています。名前だけでの自動照合は同姓同名の一般市民を危険にさらす可能性があります。

### 2. ⚖️ 無実の市民が拘束されるリスク

もし本当に人違いなら、まったく無関係な元弁護士が国際犯罪者として拘束されていることになります。これは深刻な人権問題です。

### 3. 🇺🇸🇷🇺 米ロ間の地政学的緊張

本物の容疑者はロシア国内にいて**ロシアの裁判所から出国禁止命令が出ている**とされています（皮肉なことに）。ロシアは自国民をアメリカに引き渡すことを原則として拒否しているため、このような「第三国での拘束」が重要になってきます。

### 4. 📰 情報源の偏りにも注意

この件を報じているロシアのメディア（Izvestia、REN TV、Channel Five）は、実は**すべて同じ「National Media Group」傘下**です。弁護団に有利な情報が選択的に流れている可能性も考慮が必要です。

## 対策・今後の展望

### 今後どうなるか

- アルメニア当局は現在、**インターポールの30日間拘留命令**に基づいて身柄を拘束中
- ロシア政府はアルメニアに対して**領事アクセス（自国民への面会権）**を求めている
- 指紋照合などで本人確認が行われれば、人違いかどうか明らかになる見込み

### 私たちが学べること

| 教訓 | 内容 |
|------|------|
| 📋 制裁リストの精度 | 国際的な制裁・手配書には、父称・生年月日・その他識別情報を必ず含めるべき |
| 🤖 自動照合の限界 | AIや自動システムだけに頼らず、人間による確認が必要 |
| 🛡️ サイバー犯罪への国際連携 | REvilのような犯罪グループを追うには国際協力が欠かせないが、精度も重要 |

## 用語解説

| 用語 | 説明 |
|------|------|
| **ランサムウェア** | ファイルを暗号化して身代金を要求するウイルス |
| **REvil / Sodinokibi** | ロシア系の大規模ランサムウェア犯罪グループ（2019〜2021年ごろ活発） |
| **RaaS（Ransomware as a Service）** | ランサムウェアをサービスとして提供するビジネスモデル |
| **ダークウェブ** | 通常のブラウザではアクセスできない、匿名性の高いインターネット空間。違法取引などに悪用される |
| **制裁（サンクション）** | 特定人物への資産凍結・取引禁止などの国際的罰則 |
| **OFAC** | アメリカ財務省外国資産管理局。制裁対象リスト（SDNリスト）を管理する機関 |
| **インターポール（Interpol）** | 190か国以上が加盟する国際刑事警察機構 |
| **父称（パトロニミック）** | ロシアなどの国で使われる「父親の名前由来の第3の名前」 |
| **Intel 471** | サイバー犯罪情報を専門に収集・分析する民間企業 |
| **ハンドル名（Handle）** | オンライン上で使うニックネーム・別名 |
| **領事アクセス** | 外国で自国民が拘束された場合、大使館・領事館の職員が面会できる権利 |
| **暗号化** | データに鍵をかけて読めなくする技術 |
