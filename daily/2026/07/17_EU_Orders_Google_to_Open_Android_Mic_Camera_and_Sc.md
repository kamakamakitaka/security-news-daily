# EUがGoogleに命令：AndroidのマイクやカメラをライバルのAIアシスタントにも開放せよ

**元記事**: [E.U. Orders Google to Open Android Mic, Camera and Screen to Rival AI Assistants](https://inl03.netline.com/ltr6/?_m=3n.009a.4032.sp0ao46r89.3356)
**解説日**: 2025年7月18日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を押さえておきましょう。

### 🤖 AIアシスタントって何？
スマートフォンに向かって「Hey Siri」「OK Google」と話しかけると、音楽を流してくれたり、調べ物をしてくれたりしますよね。これがAIアシスタントです。Googleの場合は「Gemini（ジェミニ）」、Appleは「Siri」などが有名です。

### 📱 Androidとは？
Googleが作ったスマートフォン用の基本ソフト（OS＝オペレーティングシステム）です。世界中のスマホの多くはAndroidで動いており、ヨーロッパでは約60%のスマホユーザーがAndroidを使っています。

### 🇪🇺 EU（欧州連合）とデジタル市場法とは？
EUはヨーロッパの27か国が加盟する政治・経済の連合体です。「デジタル市場法（DMA＝Digital Markets Act）」は、GoogleやAppleなどの巨大IT企業が市場を独占しないようにするためにEUが作ったルールです。「ゲートキーパー（門番）」と呼ばれる大企業に対して、公平な競争ができるよう義務を課します。

### 🔒 なぜGoogleが「有利」なの？
今のAndroidでは、GoogleのAIアシスタント「Gemini」はスマホのマイク・カメラ・画面の内容などを自由に使えます。しかし他の会社が作ったAIアシスタント（例：ChatGPTなど）は同じことができず、不公平な状態になっていました。

---

## 何が起きたのか

2025年7月16日、EUの欧州委員会（EU全体のルールを作る機関）がGoogleに対して**法的拘束力のある命令**を出しました。

### 📋 命令の内容をざっくり言うと

> **「GoogleのAIがスマホで使える機能は、ライバルのAIアシスタントにも同じように使えるようにしなさい」**

具体的には、以下の機能をライバル企業のAIにも開放することが求められています：

| 機能 | 説明 |
|------|------|
| 🎤 マイク | 音声を常時聞き取る機能 |
| 📷 カメラ | カメラ映像を利用する機能 |
| 🖥️ 画面の内容 | 今スマホに何が表示されているかを読み取る機能 |
| 🗣️ ウェイクワード | 「OK Google」のような起動フレーズ（画面OFF時でも動作） |
| 📲 アプリ操作 | 他のアプリをバックグラウンドで自動的に動かす機能 |

### ⏰ いつまでに？
- 次のAndroidの大型アップデート「**Android 18**」に含めること
- 遅くとも**2027年8月1日まで**に対応すること

---

## 技術的な詳細

### 11個の機能を「開放レベル」で2種類に分類

EUの命令では、Androidの11個の機能を以下の2グループに分けています。

---

#### 🔓 グループ①：完全開放（認証なし）6つの機能

これらはどんなAIアプリでも自由に使えるようにしなければなりません：

1. **環境データ（Ambient Data）**
   - マイク音声、カメラ、画面の内容、位置情報、センサー（傾きなど）を常時・バックグラウンドで取得できる
   - GoogleのAIと同じ「軽い」同意プロセスで使えるようにする

2. **ホットワード検出（常時起動フレーズ）**
   - 画面がロックされていても、バッテリー節約モードでも動作
   - スマホ内部の省電力チップ（DSP）を使って実現
   - ただし、複数のAIが同時に聞き取れる機能はAndroid 19（2028年8月まで）に先送り

3. **長押し起動**：ホームボタン長押しでAIを起動する機能
4. **端末内AI モデルへのアクセス**：スマホ内蔵のAI処理機能
5. **サードパーティモデルの実装**：外部のAIモデルを組み込む機能
6. **バックグラウンド実行**：裏側でAIが動き続ける機能

---

#### 🔐 グループ②：認定制度あり（認証が必要）5つの機能

より高度な機能については、安全性確認のための認証は必要ですが、それさえ通れば使えます：

1. **AppSearch**：端末内のアプリデータへのアクセス
2. **コンテキスト認識AI**：状況を読んで先回り提案する機能（Googleの「Magic Cue」など）
3. **アプリ連携機能（App Actions等）**：他のアプリを呼び出して操作する機能
4. **画面自動化（Computer Control）**：AIが自動でタップ・文字入力する機能
5. **システム統合**：設定・通知・スクリーンショット・メディア操作など

---

#### 📬 アプリ連携の具体例（記事の「第55段落」より）

認定を受けたAIアシスタントは、以下のことができるようになります：

- **Gmail**のメール取得・下書き作成
- **Googleカレンダー**の予定作成・管理
- **Googleドライブ/ドキュメント**のコンテンツ取得
- **Googleマップ**のナビ起動
- **YouTube**の再生操作・視聴履歴確認
- **SMS/MMS/RCS（メッセージ）** の読み書き
- 電話の発信

---

### 🏛️ 認定制度の仕組み

Googleは「**Qualified AI Assistant Programme（認定AIアシスタントプログラム）**」という制度を作らなければなりません：

```
サードパーティのAI企業
        ↓ 認定申請（無料）
第三者認定機関（TCA）
        ↓ 認定証発行
Google（認定を拒否できない）
        ↓
Androidの高度な機能が使えるようになる
```

ポイントは、**GoogleはTCAが認定したAIアシスタントを拒否できない**という点です。ただし、認定機関（TCA）そのものをGoogleが承認する仕組みは残っています。

## なぜ重要なのか

### 🏆 競争の公平性の問題

これはセキュリティの問題というより、**デジタル市場の公平性**に関するニュースです。

これまでの状況を学校で例えると：

> 「体育の授業でバスケをするとき、先生（Google）は自分のチームにだけ良いシューズを貸して、他のチームは裸足でプレーしていた」

ようなイメージです。今回のEUの命令で、全員に同じシューズが貸し出されることになります。

### 📊 影響の大きさ

- ヨーロッパのAndroidユーザー（全体の約60%）が対象
- ChatGPT、Perplexity、Samsung BixbyなどのAIアシスタントがGeminiと同じ土俵に立てる
- AI業界全体の競争が活発になる可能性がある

### 🔒 プライバシーへの影響

一方で、**AIがマイクやカメラに常時アクセスできる**ということは、プライバシーの観点から注意も必要です：

- **良い面**：Googleだけでなく複数のAIから選べるようになる
- **注意点**：使うAIアシスタントのプライバシーポリシーを確認することがより重要になる

## 対策・今後の展望

### 👤 一般ユーザーとして気をつけること

| チェックポイント | 内容 |
|-----------------|------|
| 🔍 アプリの権限確認 | どのアプリにマイク・カメラのアクセス権を与えているか定期的に確認する |
| 📄 プライバシーポリシー | 使うAIアシスタントがデータをどう扱うか確認する |
| ⚙️ 同意設定の見直し | AIアシスタントの「常時聞き取り」設定をオン/オフできるか確認する |

### 📅 今後のスケジュール

```
2025年7月16日 ──── EUが命令を正式発表
       ↓
Android 18リリース時 ── 一部機能の開放（時期未定）
       ↓
2027年8月1日 ──── 5つの制限機能の開放期限
       ↓
2028年8月1日 ──── 複数AIの同時ホットワード検出（Android 19）
```

### 🌍 世界への波及効果

EUの規制はしばしば世界標準になります（「ブリュッセル効果」とも呼ばれます）。今回の決定が、日本やアメリカのAndroid端末にも将来的に影響を与える可能性があります。

今回の記事は、特定の「サイバー攻撃」や「セキュリティ脆弱性」に関するニュースではなく、**デジタル市場の規制**に関するニュースです。ただし、セキュリティの観点では、「どのアプリがマイク・カメラにアクセスできるか」という問題は、プライバシーやデータ保護と深く関わっており、セキュリティ分野でも重要なテーマです。

## 用語解説

| 用語 | 説明 |
|------|------|
| **EU（欧州連合）** | ヨーロッパ27か国が加盟する政治・経済の連合体 |
| **欧州委員会** | EUの行政機関。法律の提案や規制の執行を行う |
| **デジタル市場法（DMA）** | 巨大IT企業の独占を防ぐためのEUの法律（2023年施行） |
| **ゲートキーパー** | DMAが対象とする、市場を支配する巨大IT企業（Google、Apple、Metaなど） |
| **Gemini（ジェミニ）** | GoogleのAIアシスタント（旧Google Assistant） |
| **Android OS** | Googleが開発したスマートフォン用の基本ソフト |
| **DSP（デジタルシグナルプロセッサ）** | 音声処理専用の省電力チップ。常時起動フレーズの検出に使われる |
| **ホットワード（ウェイクワード）** | AIを起動するための合言葉（例：「OK Google」） |
| **バックグラウンド実行** | 画面に表示されていない状態でも動き続けること |
| **TCA（Trusted Certification Authority）** | 信頼できる第三者認定機関。AIアシスタントの安全性を審査する |
| **AppSearch** | Android端末内のアプリデータを横断的に検索できる機能 |
| **拘束力のある決定** | 法的に従わなければならない命令。違反すると制裁金の対象になりうる |
| **Computer Control** | AIがユーザーの代わりにタップや文字入力を自動で行う機能 |
| **RCS** | 次世代SMS。既読確認や高画質画像送信ができるメッセージ規格 |

---

> 💡 **まとめ**：EUがGoogleに「AndroidでライバルのAIアシスタントにもマイク・カメラ・画面情報などを使えるようにしなさい」と命令しました。2027年8月までに対応が必要です。これによってAI業界の競争が活発になる一方、プライバシーの観点からは、自分のスマホのアプリ権限設定をしっかり確認することがますます大切になります。
