# 今週のセキュリティ脅威まとめ：ゲームチート偽装スパイウェア・24時間ランサムウェア・Chromeストーカーウェアほか

**元記事**: [ThreatsDay: Game Cheat Spyware, 24-Hour Ransomware, Chrome Sync Stalking + 12 More Stories](https://inl03.netline.com/ltr6/?_m=3n.009a.4032.sp0ao46r89.3366)
**解説日**: 2025年7月18日

---

## 背景知識

今回の記事は「今週起きた複数のセキュリティ事件のまとめ」です。いくつかの事件が同時に紹介されているので、まず理解に必要な基本的な言葉を押さえておきましょう。

### 🎮 NuGet（ニューゲット）って何？
NuGetとは、プログラマーが使う「部品ショップ」のようなものです。  
料理で例えると、「レシピ本を一から書かずに、市販のソースを買ってきて使う」イメージです。プログラマーは「NuGetパッケージ」という便利なソフト部品をダウンロードして、自分のプログラムに組み込みます。このショップに「偽物の部品」が紛れ込んでいた、というのが最初の事件です。

### 🦠 RAT（ラット）って何？
**Remote Access Tool（遠隔操作ツール）** の略です。  
本来はIT管理者が遠隔でパソコンをサポートするための正当なツールですが、悪用されると「ハッカーがあなたのパソコンをインターネット越しに自由に操作できる」ツールになります。まるで「見えない侵入者があなたの部屋にいて、全部見られている」状態です。

### 🔒 ランサムウェアって何？
ランサムウェアとは、パソコンやサーバーの中のファイルを**暗号化（鍵をかけて読めなくすること）**して、「元に戻してほしければお金を払え」と脅すウイルスです。  
「身代金（ランサム）」を要求するところから「ランサムウェア」と呼ばれます。

## 何が起きたのか

今週は特に大きく分けて**3つの事件**が報告されました。

---

### 事件①：ゲームチートに偽装したスパイウェア
**「ゲームのチートツールを装った悪意あるソフトウェアがばらまかれた」**

ゲームを有利に進める「チートツール」や「Bot（自動操作ツール）」に見せかけた偽のソフトウェアが、NuGetというプログラマー向けのサイトに**11個**も公開されていました。

これをダウンロードした人のパソコンでは、裏側で**スパイウェア（監視ソフト）**が動き出し、スクリーンショット（画面の写真）をハッカーのTelemgramに送信したり、パソコンの情報を盗み出したりしていました。

---

### 事件②：偽のインストーラーを使ったパソコン乗っ取り
**「ZoomやWebExなどの有名ソフトの偽インストーラーから遠隔操作ウイルスが仕掛けられた」**

**UAT-11795**というロシア語を話すハッカーグループが、アメリカ・ヨーロッパのユーザーを狙った攻撃を2025年6月から行っています。

手口は、**ZoomやWebEx、MobaXtermなどの有名ソフトのインストーラーに見せかけた偽ファイル**を用意し、それをダウンロードさせること。インストールすると、知らぬ間に「Starland RAT」というウイルスと「WLDR agent」という追加の遠隔操作ツールがパソコンに仕込まれます。

狙いは主に：
- ログインのパスワード
- 暗号通貨ウォレット（仮想通貨の財布）の中身
- 会社のネットワーク情報（Active Directory）

---

### 事件③：24時間以内にネットワーク全体を暗号化するランサムウェア
**「新種のランサムウェアが、侵入からわずか24時間以内にネットワーク全体を壊滅させた」**

南アジアのIT企業が「Spirals（スパイラルズ）」という新種のランサムウェアの被害を受けました。

最も恐ろしい点は、**最初の侵入から24時間以内**にネットワーク内の全コンピューターにウイルスが広まり、ファイルが暗号化されてしまったことです。

攻撃者はインターネットに公開されていたWebサーバーの脆弱性（弱点）をついて侵入し、そこを足がかりにして社内全体に広がりました。

## 技術的な詳細

### 🎮 ゲームチート偽装スパイウェアの仕組み

```
[ユーザーがNuGetで偽パッケージをダウンロード]
        ↓
[第1段階：ダウンローダーが起動]
        ↓
[GitHubやHugging Faceから「pepesoft.exe」を取得]
        ↓
[第2段階：Pythonのウイルスが動き出す]
        ↓
[スクリーンショットをハッカーのTelegramに送信]
[AWSっぽい認証情報でリモート設定を読み込み]
[Googleスプレッドシートに接続して指令を受ける]
```

**ポイント**：GitHubやHugging Faceは「AIや開発者が普通に使う信頼されたサービス」です。信頼されたサービスを経由することで、セキュリティソフトに見つかりにくくしています。まるで「宅配業者のふりをして荷物に爆弾を仕込む」ようなイメージです。

---

### 🖥️ 偽インストーラー攻撃（UAT-11795）の仕組み

```
[ClickFix（偽のポップアップ）でユーザーを騙す]
        ↓
[HTAスクリプト（悪意あるWebプログラム）をダウンロード]
        ↓
[偽インストーラーが起動 → Starland RATがインストール]
        ↓
[curl.exeでPowerShellスクリプトを実行]
        ↓
[WLDR agentが暗号化通信でハッカーと常時接続]
        ↓
[パスワード・仮想通貨・会社情報が盗まれる]
```

**ClickFix（クリックフィックス）** というのは、「あなたのパソコンに問題があります。ここをクリックして修正してください」という**偽のポップアップ画面**でユーザーを騙す手法です。最近急増しています。

---

### 🔐 Spiralsランサムウェアの仕組み

```
[公開Webサーバー（IIS）の脆弱性を突いて侵入]
        ↓
[社内ネットワークを素早く調査・移動（横展開）]
        ↓
[24時間以内にネットワーク全体にウイルスを配布]
        ↓
[Rust言語で書かれた強力なプログラムで全ファイルを暗号化]
        ↓
[「お金を払わないとファイルは戻らない」と脅迫]
```

**Rust（ラスト）** は最近のハッカーが好んで使うプログラミング言語で、「動作が速く、解析されにくい」という特徴があります。

## なぜ重要なのか

### 👤 個人への影響
- ゲームチートツールを探している人は**スパイウェアに感染するリスク**があります
- ZoomやWebExなど**有名ソフトの偽物を誤ってインストール**する可能性があります
- パスワードや仮想通貨が**盗まれる**危険があります

### 🏢 企業・組織への影響
- **24時間以内にシステム全体が使えなくなる**という速度の速さは、従来の対応手順では間に合わない可能性があります
- ITサービス会社が狙われたということは、**その顧客も連鎖的に被害を受ける**可能性があります（サプライチェーン攻撃）

### 🌐 社会全体への影響
- 「信頼されたサービス（GitHub・Hugging Face・Googleスプレッドシート）を悪用する」手口が増えており、**普通のセキュリティ対策では検知しにくい**状況になっています
- ロシア語圏のハッカーグループが組織的に活動しており、**国際的なサイバー犯罪の脅威が継続**しています

## 対策・今後の展望

### ✅ 個人でできる対策

| やるべきこと | 理由 |
|---|---|
| ゲームチートやBot系ツールをダウンロードしない | 偽物が非常に多い |
| ソフトは**公式サイト**からのみダウンロード | 偽インストーラー対策 |
| 「問題があります」系のポップアップを信用しない | ClickFix対策 |
| セキュリティソフトを最新の状態に保つ | 既知のウイルス検知 |
| 仮想通貨ウォレットのソフトを慎重に扱う | 標的になっている |

### ✅ 企業・IT担当者でできる対策

- **インターネットに公開しているサーバー（IIS等）のパッチ（修正プログラム）を常に最新に保つ**
- **ネットワークの通信を監視**して、異常な動き（大量のファイル暗号化など）をすぐに検知できる仕組みを作る
- 万が一に備えて**定期的なバックアップ**を取り、バックアップはネットワークから切り離した場所に保管する
- 社内のソフトウェアインストール権限を制限する（誰でも自由にインストールできないようにする）

### 🔮 今後の展望
- ClickFix（偽のポップアップ）を使った攻撃は今後もさらに増加すると予想されます
- RustやPythonを使った検知されにくいウイルスが増えていく傾向にあります
- AIサービス（Hugging Faceなど）を踏み台にした攻撃が増える可能性があります

## 用語解説

| 用語 | 読み方 | 意味 |
|---|---|---|
| **NuGet** | ニューゲット | .NETプログラマー向けのソフト部品配布サービス |
| **スパイウェア** | スパイウェア | ユーザーの知らないうちに情報を盗む悪意あるソフト |
| **RAT** | ラット | Remote Access Tool。パソコンを遠隔操作するツール（悪用版） |
| **ランサムウェア** | ランサムウェア | ファイルを暗号化して身代金を要求するウイルス |
| **ClickFix** | クリックフィックス | 「問題を修正してください」と偽るポップアップ攻撃手法 |
| **C2サーバー** | シーツーサーバー | Command & Control。ウイルスに命令を送るハッカーの司令塔 |
| **HTA** | エイチティーエー | HTML Applicationの略。Windowsで動くスクリプトファイル |
| **PowerShell** | パワーシェル | Windowsの強力な操作ツール。悪用されることも多い |
| **Active Directory** | アクティブディレクトリ | 会社内のユーザー・パソコン管理システム |
| **Rust** | ラスト | 高速で安全なプログラミング言語。最近マルウェアにも使われる |
| **Hugging Face** | ハギングフェイス | AIモデルを共有する人気のオープンソースプラットフォーム |
| **IIS** | アイアイエス | MicrosoftのWebサーバーソフトウェア |
| **脆弱性** | ぜいじゃくせい | ソフトウェアの「穴」や「弱点」のこと |
| **暗号通貨ウォレット** | あんごうつうかウォレット | ビットコインなどの仮想通貨を管理するアプリ |

> 💡 **まとめると...**
> 今週のセキュリティ事件に共通するテーマは「**信頼できるものに見せかける**」です。有名なソフト、有名なサービス、便利なツール——それらを巧みに偽装して攻撃してきます。「無料で便利そう」「有名なソフトと同じ名前」というものほど、一度立ち止まって「本当に公式のものか？」を確認する習慣が身を守る第一歩です。
