# 偽のコーディングテストで配られるマルウェア — SVG画像の旗ファイルに隠された罠

**元記事**: [Fake Coding Tests Deliver OtterCookie-Aligned Malware Hidden in SVG Flag Images](https://inl03.netline.com/ltr6/?_m=3n.009a.4033.sp0ao46r89.337k)
**解説日**: 2026年7月18日

---

## 背景知識

このニュースを理解するために、いくつかのキーワードを先に押さえておきましょう。

### 🇰🇵 北朝鮮のハッカーグループとは？
北朝鮮は国家として、外貨獲得や情報収集のためにサイバー攻撃を組織的に行っています。「Contagious Interview（コンテイジャス・インタビュー）」はその中でも有名な作戦で、**エンジニアを偽の就職面接に誘い込み、マルウェアを仕込む**手口を使っています。2022年12月から続く、非常に巧妙な詐欺作戦です。

### 🖼️ SVGファイルって何？
SVG（Scalable Vector Graphics）は、Webサイトなどでよく使われる**画像ファイルの形式**です。普通の写真（JPEGなど）と違い、SVGは**テキスト（コード）で書かれた画像**です。「国旗の画像ファイル」と言われれば誰も疑いません。

### 🪄 ステガノグラフィとは？
ステガノグラフィとは、**データを別のデータの中に隠す技術**のことです。例えば、絵画の中に暗号メッセージを隠す、昔のスパイが使ったような手法です。今回はこれをデジタルで応用し、**画像ファイルの中にウイルスを隠す**という手口に使われました。

### 📦 マルウェアって何種類あるの？
今回登場するのは以下の種類です：
- **RAT（Remote Access Trojan）**：遠隔操作ウイルス。攻撃者がパソコンを外から自由に操作できるようにする
- **情報窃取マルウェア（Stealer）**：パスワードや暗号資産の情報などを盗み出すウイルス
- **クリップボード窃取**：コピー＆ペーストした内容を盗み見るウイルス

## 何が起きたのか

2026年5月下旬、セキュリティ企業「Elastic Security Labs」のSlackの求人チャンネルに、「Maxwell」というユーザーが現れました。

> 「Next.js・NestJS・PostgreSQL・Stripe を使ったECサイトの改修を手伝ってくれるエンジニアを探しています！」

という、いかにも本物らしい求人メッセージを投稿。興味を持ったエンジニアにはDMで連絡を取り、「採用試験としてこのプロジェクトを動かして評価を受けてください」と**コーディングテスト（GitHub等のリポジトリ）を送りつけました**。

しかしそのプロジェクトには、**仕掛けが施されたウイルスが埋め込まれていた**のです。

---

## 技術的な詳細

### 🏴 国旗の画像に毒が仕込まれていた

プロジェクトの中には `assets` というフォルダがあり、その中に各国の国旗のSVGファイルが入っています（`AE.svg`＝UAE国旗、`AF.svg`＝アフガニスタン国旗など）。

一見すると普通の画像ファイルですが、実は各ファイルの中に**HTMLコメント（<!-- -->）**という「プログラムには無視される注釈」の形で、ウイルスのコードが **Base64（べース64）** というエンコード形式に変換して隠されています。

```
<!-- aGVsbG8sd29ybGQhCg==  ← こういう謎の文字列に見えるが、実はウイルスのコード -->
```

> 💡 **例え話**：本の余白に鉛筆で薄く暗号を書いておくようなイメージです。一見すると普通の本ですが、知っている人が読むと「次の指示はここ」とわかる仕掛けです。

### ⚙️ 4段階の攻撃の流れ

プロジェクトを実行すると、`serverValidation.js` というJavaScriptファイルが動き出し、バラバラに隠された国旗ファイルのデータを**1つのウイルスに組み立て直して実行**します。

しかもこのウイルスは、**サーバーを起動するたびに自動実行される**よう設定されています。被害者が「テストのために1回だけ動かした」つもりでも、ずっと動き続けるのです。

攻撃は以下の **4段階**で進みます：

| 段階 | 内容 |
|------|------|
| ① | **ブラウザのパスワード・暗号資産ウォレットの窃取** |
| ② | **特定の拡張子のファイルを盗み出す** |
| ③ | **Socket.IOを使ったRAT（遠隔操作）の設置** |
| ④ | **クリップボードの監視・窃取** |

### 🤖 AIツールのデータまで狙っている

特に注目すべきは、盗まれるファイルの中に **AIコーディングツールの設定ファイル** が含まれている点です：

- `.claude`（Claude）
- `.cursor`（Cursor）
- `.gemini`（Gemini）
- `.windsurf`（Windsurf）
- `.pearai`（PearAI）

最近エンジニアの間で普及しているAIアシスタントの設定・認証情報まで狙っており、攻撃者が**時代に合わせて手口を進化させている**ことがわかります。

## なぜ重要なのか

### 💰 暗号資産（仮想通貨）の窃取が目的
北朝鮮は経済制裁を受けているため、暗号資産のハッキングが重要な外貨獲得手段となっています。エンジニアは暗号資産ウォレットを持っていることが多く、格好の標的にされています。

### 🛡️ セキュリティソフトをすり抜ける巧妙さ
画像ファイルの中にウイルスを隠すというのは、**ウイルス対策ソフトによる検出を逃れるための工夫**です。「国旗の画像」は一見無害なため、スキャンをすり抜けやすいのです。

### 👨‍💻 ターゲットはエンジニア（あなたかも！）
「求人」「コーディングテスト」という**エンジニアが日常的に経験する行動**に巧みに組み込まれているため、ベテランエンジニアでも引っかかる可能性があります。

### 📡 Slackという新しい侵入経路
これまでの Contagious Interview では LinkedIn などが使われていましたが、今回は **Slack のコミュニティワークスペース** が使われました。攻撃者は常に新しい場所を探しています。

## 対策・今後の展望

### ✅ 個人でできる対策

1. **知らない人から送られてきたコードは実行しない**
   - たとえ採用試験でも、出所不明のリポジトリをそのまま動かすのは危険です

2. **コードを実行する前に中身を確認する習慣を**
   - `assets` フォルダや画像ファイルの中に奇妙なコメントがないか確認しましょう
   - `package.json` の `scripts` 欄に不審な自動実行がないか見てみましょう

3. **仮想環境（サンドボックス）で動かす**
   - 見知らぬコードはDockerや仮想マシンの中だけで動かし、本番PCへの影響を遮断する

4. **採用担当者の素性を確認する**
   - LinkedInやSlackで突然連絡してきた人物が本当に存在する会社の人間か確認しましょう

5. **AIツールの認証情報を定期的に更新・管理する**
   - `.claude` や `.cursor` などの設定ファイルが盗まれると、AIサービスのアカウントも乗っ取られる恐れがあります

### 🔮 今後の展望
攻撃者は手口を常に進化させており、今後も「普通の開発作業」に紛れ込む形の攻撃が増えると予想されます。AIツールの普及に合わせて、AIの設定情報を狙う攻撃はさらに増加するでしょう。

## 過去記事との関連

以前、「**7つの悪意あるvite npmパッケージがブロックチェーンを司令塔にして遠隔操作ウイルスを配布**」という記事を解説しました。

あの記事では、開発者がよく使う **npmパッケージ（プログラムの部品）** に罠を仕込む手口を紹介しました。今回の記事も同様に、「**開発者が普段使うツールやワークフロー（コーディングテスト・リポジトリ）**」を悪用するという点で共通しています。

つまり攻撃者は、**エンジニアが「仕事として当然やること」の中に罠を埋め込む**という戦略を一貫して採用しています。npmパッケージ、GitHubリポジトリ、Slack求人チャンネル……攻撃の入口はどこにでもある、という認識が必要です。

## 用語解説

| 用語 | 意味 |
|------|------|
| **Contagious Interview** | 北朝鮮系ハッカーが行う「偽の就職面接」を使ったサイバー攻撃作戦 |
| **ステガノグラフィ** | 画像や音声などのファイルの中にデータを隠す技術 |
| **SVG** | テキスト（コード）で記述されるベクター画像ファイル形式 |
| **Base64** | データを文字列に変換するエンコード方式。一見無害に見えるが解読するとデータが出てくる |
| **RAT（Remote Access Trojan）** | 感染したPCを攻撃者が遠隔操作できるようにするウイルス |
| **Socket.IO** | リアルタイム通信を実現するライブラリ。今回はC2通信（攻撃者との連絡）に悪用された |
| **C2（Command & Control）** | マルウェアが攻撃者から命令を受け取るための通信サーバー・仕組み |
| **OtterCookie** | 2024年9月に初めて発見された北朝鮮系のマルウェア。今回の攻撃と関連が深い |
| **クリップボード窃取** | コピー＆ペーストした内容（パスワードや暗号資産アドレスなど）を盗む手法 |
| **サンドボックス** | 本物の環境から隔離された安全なテスト用環境 |
| **トロイの木馬（Trojan）** | 無害に見せかけて悪意ある機能を持つソフトウェア |
| **DPRK** | 朝鮮民主主義人民共和国（北朝鮮）の英語略称 |
