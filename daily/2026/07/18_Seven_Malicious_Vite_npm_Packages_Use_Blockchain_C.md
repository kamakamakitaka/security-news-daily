# 7つの悪意あるVite npmパッケージが、ブロックチェーンを「司令塔」にして遠隔操作ウイルスを配布

**元記事**: [Seven Malicious Vite npm Packages Use Blockchain C2 to Deliver a RAT](https://inl03.netline.com/ltr6/?_m=3n.009a.4033.sp0ao46r89.3372)
**解説日**: 2025年7月10日

---

## 背景知識

このニュースを理解するために、いくつかの言葉を先に説明しておきます。

### 📦 npmパッケージとは？
**npm（Node Package Manager）**とは、プログラマーが「便利な部品（パッケージ）」を公開・共有するための巨大な倉庫のようなものです。料理に例えると「レシピ集」のようなもので、プログラマーはゼロから全部作らなくても、誰かが作った便利な部品を自分のプログラムに組み込んで使えます。

### ⚡ Viteとは？
**Vite（ヴィート）**は、ウェブサイトやアプリを作るためのツールです。特に「爆速でビルド（プログラムを動かせる形に変換）できる」ことで人気の開発ツールで、世界中の多くの開発者が使っています。

### 🔗 ブロックチェーンとは？
**ブロックチェーン**は、暗号通貨（ビットコインなど）で有名な技術です。「誰も消せない・改ざんできない記録帳」をインターネット上で分散管理する仕組みです。普通は「お金の取引を記録する」ために使われますが、今回の攻撃者はこれを「悪さの指令を隠す場所」として悪用しました。

### 🎮 RAT（リモートアクセストロイ）とは？
**RAT（Remote Access Trojan）**は、感染したパソコンを遠くから勝手に操作できるようにする悪意あるプログラムです。まるで「合鍵を勝手に作られた状態」で、攻撃者はあなたのパソコンを自由に操れるようになります。

### 🕹️ C2（Command & Control）とは？
**C2（コマンド＆コントロール）**とは、攻撃者がウイルスに「次はこれをやれ」と命令を送るための「司令塔サーバー」のことです。警察がC2サーバーを発見・閉鎖すると、攻撃者は感染パソコンを操れなくなります。

## 何が起きたのか

セキュリティ企業「Checkmarx（チェックマークス）」の研究者が、**「ViteVenom（ヴァイト・ヴェノム）」**と名付けられた攻撃キャンペーンを発見しました。

2026年6月29日〜7月3日の間に、以下の**7つの偽パッケージ**がnpmに公開されました：

| パッケージ名 | ダウンロード数 |
|---|---|
| @uw010010/vite-tree | 1,070回 |
| @vite-tab/tab | 289回 |
| @vite-ln/build-ts | 252回 |
| @vite-mcp/vite-type | 239回 |
| @vite-pro/vite-ui | 200回 |
| @vitets/vite-ts | 194回 |
| @vite-ts/vite-ui | 176回 |

これらは**本物の「@vitejs」パッケージを騙る偽物**で、うっかりインストールした開発者のパソコンに悪意あるプログラムを仕込む罠でした。

> 🎭 **例え話**: スーパーの棚に「コカ・コーラ」そっくりのラベルを貼った別の飲み物を紛れ込ませるようなイメージです。見た目は本物っぽいですが、中身は全然違うものです。

## 技術的な詳細

### 😈 どうやって感染させるか

通常のマルウェア（悪意あるソフト）は「インストールした瞬間」に動き出すことが多いですが、今回は**「インポート（プログラムの中で読み込んだ）した時」**に初めて動き出します。

```
❌ 普通のマルウェア: インストール → すぐ動く → セキュリティソフトに検知されやすい
✅ ViteVenom:    インストール → 何もしない → 実際に使った瞬間に動く → 検知されにくい
```

これにより、セキュリティソフトに見つかりにくくなっています。

---

### 🔗 ブロックチェーンを「司令塔隠し」に使う仕組み

これが今回の攻撃の最もユニークな部分です。通常の攻撃では「C2サーバー」というウェブサーバーを使いますが、警察やセキュリティ企業に見つかるとすぐ閉鎖されてしまいます。

そこで攻撃者は、**ブロックチェーンの「誰も消せない」性質**を悪用しました：

```
【4段階の指令伝達システム】

①感染パソコン
    ↓ 「Tron（トロン）」というブロックチェーンに問い合わせ
②攻撃者のウォレット（取引履歴）から次の指令場所を解読
    ↓ 「BSC（バイナンス・スマートチェーン）」の取引IDを取得
③BSCの取引データから暗号化された「次のステップ」を取り出す
    ↓ ハードコードされた鍵で復号（解読）
④最終的なRAT（遠隔操作ウイルス）を受け取り実行
```

> 🗺️ **例え話**: 宝探しゲームのヒント紙を「誰も消せない公共の掲示板」に貼っておくイメージです。警察が「掲示板を撤去しよう」としても、ブロックチェーンは世界中に分散しているため物理的に不可能なのです。

また、Tronが失敗した場合は**Aptos（アプトス）**というブロックチェーンがバックアップとして使われ、さらにそれも失敗した場合は**直接HTTPで**悪意あるファイルを取得する「3重の保険」もあります。

---

### 🦠 感染後にできること

無事にRATが仕込まれると、攻撃者は以下のことができるようになります：

- 🖥️ **リバースシェル**: パソコンを遠隔操作できる「裏口」を開く
- 🔑 **資格情報の盗取**: パスワードやAPIキーなどを盗む
- 📁 **ファイルの流出**: パソコン内のファイルを攻撃者に送る
- 🚪 **永続的なバックドア**: パソコンを再起動しても消えない裏口を設置（`.bashrc`などの設定ファイルを改ざん）

## なぜ重要なのか

### 1. 開発者を標的にしているため影響が広い
Viteは世界中の開発者に使われている人気ツールです。開発者のパソコンには**企業のソースコード・データベースのパスワード・クラウドサービスの鍵**など、非常に価値の高い情報が詰まっています。

### 2. ブロックチェーンC2は「新次元の脅威」
従来のC2サーバーは「法執行機関が閉鎖できる」手段がありました。しかし**ブロックチェーンは誰も消せない**ため、攻撃インフラを壊滅させることが極めて困難です。

> 💡 これは「悪の指令書を、誰も書き換えられない石板に刻んだ」ようなものです。

### 3. ソフトウェアサプライチェーン攻撃
今回の手口は**「開発者を騙すことで、最終的にそのソフトを使うエンドユーザーにも被害が広がる可能性がある」**という連鎖型の攻撃です。開発者が感染すれば、その人が作ったアプリを使う何千・何万人にも影響が及びます。

## 対策・今後の展望

### 🛡️ すでにインストールした人がやるべきこと

1. **今すぐ該当パッケージを削除する**
2. **依存関係を全て確認する**（package.jsonを見直す）
3. **全てのパスワード・APIキーを変更する**（漏れた可能性があるため）
4. **以下のファイルに不審な変更がないか確認する**：
   - `~/.bashrc`
   - `~/.zshrc`
   - `~/.profile`

### 🔍 今後インストールする時の注意点

```
✅ 正しいパッケージ名: @vitejs/plugin-react （公式）
❌ 偽物の例:          @vite-ts/vite-ui    （今回の偽物）
```

- **パッケージ名のスペルを慎重に確認する**（タイポスクワッティング対策）
- **ダウンロード数・公開日・メンテナーを確認する**
- **npmのページで公式リポジトリへのリンクがあるか確認する**
- 企業での開発なら**許可されたパッケージのリスト（allowlist）を作る**ことを検討する

### 🔮 今後の展望

ブロックチェーンをC2インフラとして使う攻撃は「ChainVeil」から始まり「ViteVenom」へと進化しています。今後さらにこの手法が他の攻撃者にも模倣される恐れがあり、セキュリティ業界全体での新しい対策の研究が急務となっています。

## 過去記事との関連

今回の「ViteVenom」は、以前から観測されていた**「ChainVeil」キャンペーンの発展版**です。ChainVeilではTailwindやSass、ORM（データベース操作ツール）などを装った偽パッケージが使われていました。

今回のViteVenomとの違いをまとめると：

| 項目 | ChainVeil（旧） | ViteVenom（新） |
|---|---|---|
| 標的 | Tailwind・Sass・ORM利用者 | Vite利用者 |
| パッケージ名 | 普通の偽名（rate-limit-flexible等） | 公式風スコープ名（@vite-xx/xx） |
| C2インフラ | ブロックチェーン（Tron・Aptos・BSC） | 同左（共通インフラ使用） |

**同じ攻撃者グループ「SuccessKey」**が、標的を変えながら手法を洗練させていることが伺えます。まるで詐欺師が「同じ手口で違う人をターゲットにしている」ようなイメージです。

## 用語解説

| 用語 | 意味 |
|---|---|
| **npm** | JavaScriptのパッケージ（部品）を共有する巨大な倉庫サービス |
| **Vite** | ウェブアプリを爆速で開発するためのツール |
| **RAT** | 感染PCを遠隔操作するウイルス（Remote Access Trojan） |
| **C2サーバー** | 攻撃者がウイルスに命令を送る「司令塔」（Command & Control） |
| **ブロックチェーン** | 誰も書き換えられない分散型の記録帳技術 |
| **Tron / Aptos / BSC** | 今回C2として悪用された3つの異なるブロックチェーン |
| **タイポスクワッティング** | 有名なサービス名のスペルを少し変えた偽物を作る手口 |
| **サプライチェーン攻撃** | 開発者・ツールを標的にして最終的に多くのユーザーに被害を広げる攻撃 |
| **バックドア** | PCに仕込む「裏口」。再起動しても消えない |
| **リバースシェル** | 感染PCから攻撃者側に接続することで、攻撃者がPCを操作できる状態にする仕組み |
| **スコープパッケージ** | `@組織名/パッケージ名` の形式の、信頼できる組織が発行したように見えるnpmパッケージ名 |

---

> ⚠️ **まとめ**: 今回の攻撃は「開発者が使うツールを騙す」→「ブロックチェーンで指令を隠す」→「遠隔操作ウイルスを仕込む」という非常に巧妙な3段構えです。開発者の方は、パッケージをインストールする際に**「本当に正規のパッケージか？」を一度立ち止まって確認する習慣**をつけることが最大の防衛策です。
