# 「Bit2Watt」攻撃：クラウドのGPUを使って電力網を不安定にできる!?

**元記事**: [New Bit2Watt Attack Could Let Cloud Tenants Disrupt Power Grids Without an Exploit](https://inl03.netline.com/ltr6/?_m=3n.009a.4035.sp0ao46r89.339u)
**解説日**: 2025年7月22日

---

## 背景知識

このニュースを理解するために、まずいくつかのキーワードを押さえておきましょう。

### 🏢 クラウドコンピューティングとは？
「クラウド」とは、インターネット経由で使えるコンピューター資源のことです。AmazonやGoogleが巨大なデータセンター（コンピューターが何千台も並んだ施設）を運営していて、企業や研究者はお金を払ってその計算能力を「借りる」ことができます。自分でサーバーを買わなくていいので、非常に便利です。借りている人を「テナント（入居者）」と呼びます（マンションの借り主のイメージです）。

### 🎮 GPUとは？
GPU（Graphics Processing Unit）は、もともとゲームの映像を描くために作られたチップです。しかし今では、AIの学習（機械学習）にも大量に使われています。GPUは「同時にたくさんの計算を並列でこなす」のが得意で、フル稼働時には非常に大きな電力を消費します。

### ⚡ 電力グリッドとは？
「グリッド」とは、発電所から家庭や工場に電気を届けるための送電ネットワーク全体のことです。電力は「需要と供給のバランス」が崩れると周波数が乱れ、最悪の場合は停電が起きます。最近は太陽光発電などの再生可能エネルギーが増えて、このバランス管理がより難しくなっています。

### 🔬 「脆弱性（ぜいじゃくせい）を突かない攻撃」とは？
普通のサイバー攻撃は、ソフトウェアのバグや設定ミスを悪用します。しかし今回の研究は、**バグや不正アクセスなしに**、「普通の使い方」だけで攻撃できると主張しています。これが非常に厄介なポイントです。

---

## 何が起きたのか

中国の浙江大学（Zhejiang University）の研究者3名が、「**Bit2Watt（ビット・トゥ・ワット）**」と名付けた新しい攻撃手法を発表しました。この研究は2026年のセキュリティカンファレンス「CHES 2026」に採択された査読済みの学術論文です。

### 📌 ひと言で言うと？
> **「クラウドで借りたGPUを、AIの学習などに使いながら、こっそり電力の上げ下げを繰り返すことで、データセンターが繋がっている電力網を不安定にできる」**

という攻撃の可能性を研究者たちが示したものです。

重要なのは、これが：
- ✅ ハッキングなし
- ✅ 特別な権限なし
- ✅ マルウェア（悪意あるソフト）なし
- ✅ 普通のクラウド利用の範囲内でできる

という点です。

## 技術的な詳細

### ⚙️ 基本的な仕組み：電力のON/OFFを繰り返す

GPUは、たくさん計算させると電力消費が急増し、待機状態にすると急減します。これを**高速に交互に繰り返す**と、壁のコンセントに届く電力が「ブルブル」と振動するような状態になります。

> 🎸 **例え話**：ギターの弦を一定のリズムでつまみ続けると、特定の音（周波数）が出ます。GPUの電力消費も同じように、スイッチングのリズムで「電力の波」を作り出せます。

### 🛠️ 2つの攻撃方法

研究者は2つのやり方を提案・実験しました。

#### 方法①：SWMA（スイッチング・ワークロード・モジュレーション）
- 専用に作った計算プログラム（CUDAカーネル）を使う
- フル稼働 ↔ ほぼ待機を高速で切り替える
- RTX 4090（最新の高性能ゲーミングGPU）でテストし、**毎秒1,500〜6,000回のペースで電力を振動**させることに成功
- データセンター用のGPU（A100、Tesla V100）でも同じ効果を確認
- **弱点**：特殊なプログラムを使うため、管理者に「怪しいぞ」と気づかれる可能性がある

#### 方法②：LTMA（LLMトレーニング・モジュレーション）
- 本物のAI学習（LLM＝大規模言語モデルの訓練）の中に、こっそり振動を埋め込む
- AIの学習パラメーター（設定値）を微妙に調整して、電力の上げ下げを作り出す
- 周波数は毎秒約1,200〜3,000回と少し低いが、**振れ幅が大きく**、普通のAI学習のノイズに紛れ込むため**検出がはるかに難しい**
- **特別な権限は不要**（テナントは自分のAI学習スクリプトを自由に書けるので）

> 💡 **例え話**：方法①は「エアコンを1秒ごとに全力ON・OFFする」感じ。方法②は「料理しながら、絶妙なタイミングで電子レンジやオーブンをON/OFFして、ブレーカーに負荷をかける」感じです。後者の方が自然に見えてバレにくいです。

### 📊 シミュレーション結果：どのくらい危険なのか？

研究者は「もし1,000台のGPUが同時に連動してこの攻撃をしたら？」というシミュレーションを行いました。

| 条件 | 結果 |
|------|------|
| 1MWの小規模ローカルグリッド、GPU×1,000台 | 電流のTHD（高調波歪み率）が**46.8%**に（国際基準の13%をはるかに超える） |
| 減衰比（安定性の指標） | **-0.27**（マイナスは「不安定」を意味する） |
| ヨーロッパの送電網モデルで試算 | 局所的な2%の負荷変動が連鎖し、**電力供給の約81%が失われる**結果に |

> 📐 **THD（高調波歪み率）**：電力の波形がどれだけ乱れているかを示す数値。高いほど機器が壊れやすくなったり、電力網が不安定になります。

### ⚠️ ただし、重要な注意点

研究者自身も認めていますが、**実際の攻撃には大きなハードルがあります**：

- 1,000台のGPUを**完全に同期させる**のは現実には非常に難しい
- タイミングのズレ（標準偏差100マイクロ秒）だけで攻撃の効果が約20%減少する
- 物理的に近い場所にあるGPUが大量に必要
- 81%停電のシミュレーションは「最悪の仮定を重ねたモデル」であり、現実の予測ではない

## なぜ重要なのか

### 🚨 「合法的な行動」が武器になる

これまでのサイバー攻撃は「不正アクセス」や「マルウェア」が前提でした。しかし今回は、**契約の範囲内でGPUを「普通に」使うだけで攻撃できる可能性**を示しています。これを防ぐのは非常に難しいです。

### 🏭 データセンターと電力網の依存関係

AIブームで、世界中にデータセンターが急増しています。日本でも大規模なデータセンター建設が続いています。これらが消費する電力は膨大で、地域の電力網に大きな影響を与えます。その「影響力」が悪用される可能性があると研究者は警告しています。

### 🌍 インフラへの新しい脅威の形

電力網・水道・交通などの「重要インフラ」へのサイバー攻撃は世界中で増えています。しかしこれまでは制御システムへの直接ハッキングが主でした。今回は**物理インフラへの影響を、クラウドの計算レイヤーから間接的に引き起こす**という、まったく新しい攻撃モデルです。

## 対策・今後の展望

### 🔍 現時点で考えられる対策

| 対策 | 内容 |
|------|------|
| **電力消費パターンの監視** | 異常な電力の振動パターンを検出するシステムを導入する |
| **ワークロードのフィンガープリント** | 不自然なスイッチングパターンを持つ計算ジョブを識別する |
| **電力システム側の対策** | スマートインバーターや電力コンディショナーで高調波を吸収する |
| **テナントの行動制限** | 電力消費の変動速度に上限を設けるレート制限の導入 |

### 🔭 今後の課題

- 研究者自身が「複数GPUの同期」は未解決の問題だと認めており、今後この部分の研究が進む可能性があります
- クラウドプロバイダー（AWS、Google、Azureなど）がこのリスクをどう評価し対策するかが注目されます
- 電力会社とデータセンター事業者の**連携した対策**が必要になるかもしれません

> 🔐 **この研究は「攻撃できる！」という発表ではなく「こういうリスクがあるから対策しよう」という警告です。** セキュリティ研究者が脆弱性を先に見つけて公表することで、社会全体が備えることができます。これを「責任ある開示（Responsible Disclosure）」の精神と言います。

## 過去記事との関連

以前、「**オープンソースのAndroid AIエージェントに潜む危険：見えない文字がパソコンを乗っ取る**」という記事を解説しました。あの記事では、AIエージェントが「見えない悪意あるテキスト」に騙されてコードを実行してしまう「プロンプトインジェクション」という問題を扱いました。

今回のBit2Watt攻撃と共通しているのは、**「AIを使った正当に見える操作が、予想外の危険な結果を引き起こす」** という点です。

- 前回：AIが「見えない指示」に騙されてパソコンを操作される
- 今回：AIの学習という「正当な作業」に見せかけて電力網を攻撃する

どちらも「普通の使い方に見えるのに実は危険」という、**検出が難しい新世代の脅威**です。AIの普及とともに、このような「AIを悪用した攻撃」の研究が増えていくと予想されます。

## 用語解説

| 用語 | 解説 |
|------|------|
| **GPU** | 画像処理やAI学習に使われる高性能チップ。フル稼働時に大量の電力を消費する |
| **クラウドテナント** | クラウドサービスを契約して計算資源を借りている利用者（マンションの「入居者」に相当） |
| **CUDA** | NVIDIAのGPUでプログラムを動かすための開発環境・言語 |
| **LLM（大規模言語モデル）** | ChatGPTのようなAIの基盤となる大規模なAIモデル。学習には膨大な計算資源を使う |
| **THD（全高調波歪み率）** | 電力の波形の乱れ具合を示す数値。高いほど電力品質が悪く、機器への悪影響が大きい |
| **電力グリッド** | 発電所から家庭・企業に電気を届けるための送電ネットワーク全体 |
| **分散エネルギー資源（DER）** | 太陽光パネルや家庭用蓄電池など、小規模・分散型の電源。管理が複雑 |
| **減衰比** | 電力系統の安定性を示す数値。マイナスになると「不安定（振動が増幅する）」を意味する |
| **CHES 2026** | 暗号ハードウェアとセキュリティに関する国際的な学術会議 |
| **フィンガープリント（検出）** | 特徴的なパターンから不審な動きを識別・検出すること |
