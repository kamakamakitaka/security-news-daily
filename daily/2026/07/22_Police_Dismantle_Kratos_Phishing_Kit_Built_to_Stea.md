# 「クラトス」フィッシングキット摘発！Microsoft 365のログインを盗む巨大詐欺基盤が壊滅

**元記事**: [Police Dismantle Kratos Phishing Kit Built to Steal Microsoft 365 Sessions and Bypass MFA](https://inl03.netline.com/ltr6/?_m=3n.009a.4036.sp0ao46r89.33be)
**解説日**: 2025年7月14日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な仕組みを押さえておきましょう。

### 📧 フィッシング詐欺とは？
「フィッシング（Phishing）」とは、本物そっくりの偽サイトや偽メールを使って、パスワードなどの個人情報を盗み取る詐欺です。魚釣り（fishing）をもじった言葉で、「餌を使ってターゲットを釣る」イメージです。

### 🔐 MFA（多要素認証）とは？
パスワードだけでなく、スマホへの確認コードなど「もう一つの証明」を求めるセキュリティの仕組みです。「合言葉を知っているだけじゃなく、本人の持ち物も確認する」ようなイメージ。銀行のATMでキャッシュカード＋暗証番号を使うのと似た発想です。

### 🍪 セッションクッキーとは？
ウェブサービスにログインすると、ブラウザに「この人はさっきちゃんとログインしたよ」という証明書のようなものが一時的に保存されます。これが「セッションクッキー」です。このクッキーを持っていれば、パスワードを再入力しなくてもログイン済み状態のまま操作できます。

### 🎭 AiTM（中間者攻撃）とは？
「Adversary-in-the-Middle（敵が真ん中に入る）」の略です。攻撃者がユーザーとサービスの**間**に入り込んで、やり取りをすべて盗み見る手口です。郵便物を配達途中で開けてコピーするようなイメージです。

### 🛠️ フィッシングキットとは？
フィッシング詐欺を「誰でも簡単に実行できるツールセット」のことです。プログラミングの知識がなくても詐欺キャンペーンを展開できるよう、偽サイトの作成から情報収集まで一式がまとまっています。

## 何が起きたのか

2025年7月、**ドイツと米国の法執行機関が協力**して、「**Kratos（クラトス）**」と呼ばれる世界最大級のフィッシングキットを壊滅させました。

主な出来事をまとめると：

| 項目 | 内容 |
|------|------|
| 摘発した機関 | ドイツ検察庁（ZIT）、ドイツ連邦刑事庁（BKA）、米国当局 |
| 停止したサーバー数 | **200台以上** |
| 利用していた犯罪者数 | 約**1,800人** |
| 月あたりの詐欺キャンペーン数 | 約**15,000件** |
| 被害者数（2024年末以降） | **数十万人**（30か国以上） |
| 運営者の推定収益 | **30万ユーロ以上**（約5,000万円） |
| 開発・運営者 | インドネシア人男性（逮捕済み） |

また、Microsoftはこの同じツールを「**SneakyLog（スニーキーログ）**」という名前で追跡しており、少なくとも2025年初頭からMicrosoft 365への攻撃に使われていたと報告しています。

## 技術的な詳細

### 🏭 フランチャイズ型の犯罪ビジネス

Kratosは、まるでコンビニのフランチャイズのように運営されていました。

```
開発者（インドネシア人）
    ↓ ツールを提供・販売
犯罪者A（加盟者）  犯罪者B（加盟者）  犯罪者C（加盟者）
    ↓                  ↓                  ↓
標的に詐欺メール送信  標的に詐欺メール送信  標的に詐欺メール送信
```

- 加盟者は**暗号通貨で利用料を支払い**、専用ウェブサイトやTelegramで申し込む
- プログラミングの知識がなくても使えるため、**素人の犯罪者でも詐欺が実行可能**に

### 🎯 どうやってMFAを突破したのか？

Kratosには2つのモードがありました：

**モード①（シンプル版）**
> 偽のログインページを作ってパスワードだけを盗む。昔ながらのフィッシング。

**モード②（高度版）＝AiTM攻撃**

これが今回の最大の脅威です。仕組みをわかりやすく説明します：

```
【通常のMFA認証の流れ】
ユーザー → パスワード入力 → MFAコード入力 → Microsoft → ログイン成功 → クッキー発行

【Kratosのモード②（AiTM）の流れ】
ユーザー → 偽サイトにパスワード入力 → 攻撃者がリアルタイムで本物Microsoftに中継
                                         ↓
                              MFAコードも中継して認証を完了
                                         ↓
                              発行されたセッションクッキーを横取り！
                                         ↓
                              攻撃者が「ログイン済み状態」のまま乗っ取り成功
```

**ポイント**：パスワードを変えても、盗まれたセッションクッキーが有効な間は攻撃者がアカウントに入り続けられます。これが「MFAをバイパス（回避）する」という意味です。

### 📮 実際の攻撃事例（2025年2月10日）

Microsoftが捉えた実際の攻撃事例がこちら：

- **標的**：米国の製造業・小売業・医療機関 約100社
- **手口**：「W-2フォーム（米国の源泉徴収票）」を装ったメールを送信
- **仕掛け**：メールに添付されたPDFのQRコードを読み取ると、**受信者専用にカスタマイズされた**偽のMicrosoft 365ログインページへ誘導

## なぜ重要なのか

### 1. 🔢 規模が桁違い
月15,000件のキャンペーン、数十万人の被害者という規模は、個人の犯罪者レベルをはるかに超えています。これはサービスとして販売された「**犯罪のプラットフォーム**」です。

### 2. 🛡️ MFAが万能ではないと証明された
「MFAをかけていれば安全」と思っていた人も多いかもしれませんが、このツールはMFAを**すり抜けられる**ことを実証しました。セキュリティの常識を更新する必要があります。

### 3. 🔗 被害が連鎖する
Microsoft 365のアカウントを乗っ取られると：
- 社内メールを使ったさらなるフィッシング詐欺
- 盗んだ情報を別の犯罪者に販売
- 会社のシステム全体への侵入（**ビジネスメール詐欺＝BECへの発展**）

一つのアカウントが入口になって、会社全体が危険にさらされます。

### 4. 🌍 日本も無関係ではない
記事では「30か国以上」「ヨーロッパと米国が中心」とあります。Microsoft 365は日本でも広く使われており、同様の手口が日本を標的にする可能性も十分あります。

## 対策・今後の展望

### ✅ あなたが今すぐできる対策

**1. MFAをより強力なものに変える**
通常のSMSや認証アプリのコードよりも、**パスキー（Passkey）** や **FIDOセキュリティキー**（物理的なUSBキーなど）を使うと、AiTM攻撃に対してはるかに強くなります。

**2. 不審なリンク・QRコードに注意**
メールのQRコードをそのまま読み取るのは危険です。公式サイトは自分でブックマークからアクセスする習慣を。

**3. Microsoft通知が来たら即対応**
Microsoftは今回の被害ユーザーに通知を送っています。受け取ったら：
- **パスワードだけ盗まれた場合** → パスワードを変更し、MFAを見直す
- **セッションも盗まれた場合** → アカウントのセッションをすべて強制ログアウトし、重要アカウントはパスキーに移行する

### 🔍 IT担当者向け：侵害の痕跡を探すヒント

セキュリティ会社のANY.RUNによると、Kratosのフィッシングページには特徴的なファイルが使われています：

- `barr.svg` と `lg.svg` の2つのファイルが必ずロードされる
- 盗んだ情報は `next.php` や `save.php` というファイルに送信される

この組み合わせを検出することで、Kratosのページを高精度（約90%）で識別できます。

### 🔮 今後の展望

今回の摘発は大きな成果ですが、**完全な解決ではありません**：

- 約1,800人の「加盟者（利用していた犯罪者）」はまだ捕まっていない
- ツールのコードはすでに流出している可能性がある
- 過去にも別名で復活したケースがあり、「Kratos 2.0」のような後継が登場するリスクがある

ドイツ当局は今回の作戦を「インフラそのものを壊滅させる」アプローチと表現しており、犯罪者を逮捕するだけでなく**土台ごと崩す戦略**に意義を見出しています。

## 過去記事との関連

今回は直接関連する過去記事はありませんが、AiTM（中間者攻撃）フィッシングは近年急増しているトレンドです。「MFAを設定しているから安全」という考えを見直すきっかけとして、以前もEvilginxやModlishtaなど同様のAiTMツールに関する報告が出ています。Kratosはその流れの中でも特に大規模・組織的なケースとして記録されることになりました。

## 用語解説

| 用語 | 意味 |
|------|------|
| **フィッシング（Phishing）** | 偽サイト・偽メールで個人情報を盗む詐欺 |
| **フィッシングキット** | フィッシング詐欺を誰でも簡単に実行できるツールセット |
| **MFA（多要素認証）** | パスワード以外にもう一つの認証を求めるセキュリティ機能 |
| **セッションクッキー** | ログイン状態を維持するためにブラウザに保存される一時的な認証情報 |
| **AiTM（中間者攻撃）** | 攻撃者がユーザーとサービスの間に入り込んで通信を傍受・横取りする手口 |
| **フィッシング・アズ・ア・サービス（PhaaS）** | フィッシング詐欺ツールをサービスとして販売するビジネスモデル |
| **BEC（ビジネスメール詐欺）** | 企業の担当者を騙って不正送金などを行う詐欺 |
| **リバースプロキシ** | ユーザーと本物サーバーの間に入って通信を中継する仕組み |
| **クレデンシャル** | ログインに使うID・パスワードなどの認証情報 |
| **パスキー（Passkey）** | パスワードを使わない次世代の認証方法。AiTM攻撃に強い |
| **ZIT** | ドイツのサイバー犯罪専門検察庁 |
| **BKA** | ドイツ連邦刑事庁（日本のNPAにあたる機関） |
| **W-2フォーム** | 米国の源泉徴収票。税金関連の書類として信頼されやすく詐欺に悪用される |

---

> 💡 **まとめ**: 今回の摘発は、「MFAをかければ安全」という常識を崩すレベルの攻撃ツールが大規模に流通していたことを示しています。重要なアカウントには**パスキーやセキュリティキーなどのフィッシング耐性のある認証**を使うことが、今後ますます重要になってきます。
