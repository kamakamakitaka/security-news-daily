# NodeBBの8つの脆弱性をAIが発見！管理者アクセスや非公開チャットが丸見えに

**元記事**: [NodeBB Patches Eight AI-Found Flaws Exposing Admin Access and Private Chats](https://inl03.netline.com/ltr6/?_m=3n.009a.4038.sp0ao46r89.33ec)
**解説日**: 2026年7月25日

---

## 背景知識

まず、今回の記事を理解するためにいくつかの言葉を押さえておきましょう。

### NodeBBとは？
**NodeBB（ノードビービー）**は、インターネット上に「掲示板・フォーラム」を作るためのソフトウェアです。学校のクラス掲示板や趣味のコミュニティサイトのようなものを、誰でも自分のサーバーで運営できます。世界中の企業や個人が使っているポピュラーなツールです。

### フェデレーション（連合）とは？
**フェデレーション**とは、複数の独立したSNSやコミュニティサイトが「互いにつながる」仕組みのことです。たとえば、Twitterのような中央集権型とは違い、**Mastodon（マストドン）**などのサービスがこの仕組みを使っています。「異なる学校のSNSが、お互いに投稿を見せ合える」イメージです。このつながりの総称を**フェデバース（fediverse）**と呼びます。

### 脆弱性とペネトレーションテストとは？
- **脆弱性（ぜいじゃくせい）**：ソフトウェアのセキュリティ上の「穴」や「弱点」のことです。泥棒が入りやすい「鍵のかかっていない窓」のようなものです。
- **ペネトレーションテスト（ペンテスト）**：専門家が「わざと攻撃者の真似をして」システムの弱点を見つける調査のことです。「泥棒役を雇って、どこから侵入できるか試す」ようなイメージです。

## 何が起きたのか

2026年、セキュリティ企業**Aikido Security**のAIが、NodeBBというフォーラムソフトウェアを**わずか6時間で調査**し、**8つの深刻な脆弱性**を発見しました。

これらの脆弱性は、**バージョン4.14.0より前のすべてのNodeBB**に存在しており、次のような被害が起こりえました：

- 👤 一般ユーザーが**管理者画面**にアクセスできてしまう
- 🔒 アカウントなしで**他人のプライベートメッセージ**を読める
- 📂 非公開カテゴリの内容が**誰でも見られる**状態になる
- 💉 悪意のあるコードをサイトに**埋め込める**

NodeBBはすでにこれらをすべて修正済みで、**現在は4.14.2が安全な最新版**です。

---

## 技術的な詳細

8つの脆弱性を、わかりやすく分類して説明します。

---

### 🚪 脆弱性①：管理者画面に簡単に入れてしまう

> 「パスワードなしで校長室に入れてしまう」

本来、一般ユーザーは管理者（admin）のページにアクセスできないはずです。しかし、**自分のホームページ設定に管理者のアドレスを指定してページを再読み込みする**だけで、管理者画面が表示されてしまいました。

なぜこうなったのかというと、「この設定はできない」というチェックが**ブラウザ（画面の表示側）でしか行われていなかった**からです。攻撃者はブラウザのチェックを迂回し、直接サーバーに命令を送ることで、管理者画面を開けてしまいました。

> 🏫 例え話：「校長室への入室は受付でチェックする」というルールがあっても、「受付を通らずに裏口から直接入れてしまった」ような状態です。

---

### 📩 脆弱性②③：アカウントなしで非公開情報を見られる

2つの脆弱性により、**サイトにアカウントを持っていない完全な部外者でも**：

- 他人のふりをして**プライベートメッセージを1件ずつ読む**ことができた
- **非公開カテゴリの投稿**を閲覧できた

> 🏫 例え話：「会員制の図書館なのに、外から窓を覗いて本の内容が全部読めてしまった」状態です。

---

### 💉 脆弱性④：悪意のあるコードの埋め込み（XSS攻撃）

これが8つの中で最も影響が広かった脆弱性です。

NodeBBはページを作るとき、次の2段階の処理をします：
1. ページの枠を作る
2. 翻訳テキストを後から差し込む

問題は、**ユーザーが入力した文字がステップ1でページに入った後**、ステップ2の翻訳処理がそれを「翻訳コマンド」として誤解して実行してしまったことです。

これを利用すると、攻撃者は**普通の投稿文の中に悪意のあるリンクを仕込む**ことができ、閲覧者がそのリンクをクリックすると攻撃者のコードが実行されてしまいます。これを**XSS（クロスサイトスクリプティング）**と呼びます。

> 🏫 例え話：「掲示板に『ここをクリックすると面白いことが起きます』という罠リンクを貼って、クリックした人のアカウントを乗っ取る」ようなイメージです。

---

### ⬆️ 脆弱性⑤⑥⑦⑧：その他の攻撃

- **投票数の不正操作**：いいね！の数を水増しできる
- **投稿の乗っ取り**：他人の投稿内容を書き換えられる
- **フェデバース経由のコード実行**：Mastodonなど外部SNSとの連携部分を悪用し、偽のサーバーを使って悪意のあるコードを実行できる（2件）

## なぜ重要なのか

### 影響を受けるユーザーの分類

| 必要な条件 | 該当する脆弱性の数 |
|---|---|
| アカウントすら不要（誰でも攻撃可能） | 3つ |
| 一般ユーザーアカウントがあれば攻撃可能 | 2つ |
| 被害者にリンクをクリックさせる必要がある | 3つ |

特に**アカウント不要の3つ**は非常に危険で、インターネット上の誰でも攻撃者になれる状態でした。

### フェデレーション設定による影響の違い

- **バージョン4から新規インストール**したフォーラム → フェデレーションがデフォルトでON → **8つ全部が危険**
- **バージョン3からアップグレード**したフォーラム → フェデレーションがデフォルトでOFF → **3つが危険**

### CVEについて

セキュリティの脆弱性には通常、**CVE（シーブイイー）**と呼ばれる管理番号が付きます。しかし今回の8つにはCVE番号がまだありません。また、別途発見された**CVE-2026-58593**という脆弱性は、外部サーバーが管理者を含む任意のアカウントになりすますことができるもので、現時点では修正バージョンが不明です。

## 対策・今後の展望

### ✅ 今すぐやるべきこと

NodeBBを運営している管理者の方は、**すぐにバージョン4.14.2にアップグレード**してください。

ただし注意点があります：
- バージョン4.14.0でページテンプレートの仕組みが大きく変わった（**325ものファイルが変更**された）ため、カスタムテーマやプラグインが動かなくなる可能性があります
- **フェデレーションをオフにするだけでは不十分**です。8つのうち3つはフェデレーションと無関係だからです

### 🤖 AIによるセキュリティ調査の進化

今回の発見で注目すべきポイントは、**AIが6時間という短時間で8つの深刻な脆弱性を発見した**ことです。従来の人間によるセキュリティ調査と比べて、AIの活用が急速に進んでいることがわかります。

ただし、皮肉なことに、NodeBBのバグ報告ページには「**AIが自動生成したレポートは受け付けない**」と書かれているそうです。

### 📅 修正の経緯

NodeBBは、脆弱性を公表する前に静かに修正を進めていました：
- **5月**：4つ修正
- **6月**：2つ修正
- **7月9日**：最大の修正（バージョン4.14.0）
- **7月23日**：4.14.2リリース（管理者はこれを適用してください）

## 用語解説

| 用語 | 説明 |
|---|---|
| **NodeBB** | インターネット掲示板を作るためのオープンソースソフトウェア |
| **脆弱性（ぜいじゃくせい）** | ソフトウェアのセキュリティ上の「穴」や「弱点」 |
| **ペネトレーションテスト** | わざと攻撃者の真似をしてシステムの弱点を探す調査 |
| **フェデレーション / フェデバース** | 独立したSNSやフォーラムが互いにつながる仕組み・その総称 |
| **Mastodon** | フェデバースに参加しているオープンソースのSNSサービス |
| **XSS（クロスサイトスクリプティング）** | Webサイトに悪意のあるスクリプト（プログラム）を埋め込む攻撃手法 |
| **管理者（admin）** | サイト全体の設定やユーザー管理ができる最高権限のアカウント |
| **CVE** | セキュリティ脆弱性に付けられる国際的な管理番号（例：CVE-2026-58593） |
| **バグバウンティ** | 脆弱性を発見・報告してくれた人に報奨金を払う制度 |
| **オープンソース** | プログラムのソースコード（設計図）が公開されているソフトウェア |
