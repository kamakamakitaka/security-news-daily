# BlueNoroffのZoomフィッシング詐欺：仮想通貨ウォレットを事前に調査してからマルウェアを送り込む新手口

**元記事**: [BlueNoroff Zoom Phishing Kit Profiles Crypto Wallets Before Malware Delivery](https://inl03.netline.com/ltr6/?_m=3n.009a.4039.sp0ao46r89.33fq)
**解説日**: 2025年7月25日

---

## 背景知識

このニュースを理解するために、いくつかの基本的な言葉を最初に説明します。

**🇰🇵 BlueNoroff（ブルーノロフ）とは？**
北朝鮮の政府に関係していると言われているハッカーグループです。主に**仮想通貨（暗号資産）を盗む**ことを目的としており、世界中の企業や個人を狙っています。国家が背後にいると言われているため、非常に組織的で高度な攻撃を行います。

**💰 仮想通貨ウォレットとは？**
ビットコインやイーサリアムなどの仮想通貨を管理するための「デジタルな財布」です。ブラウザの拡張機能（MetaMaskなど）として使われることが多く、パソコンにインストールされています。

**🎭 フィッシング詐欺とは？**
本物そっくりの偽サイトや偽メッセージを使って、パスワードや個人情報を盗む詐欺です。釣り（フィッシング）のように「えさ」で人を釣ることからこの名前がついています。

**🖥️ Zoomとは？**
ビデオ会議ができるアプリ。コロナ禍以降、多くの会社や学校で使われるようになりました。

**📱 Telegramとは？**
メッセージのやり取りができるスマートフォン・PCアプリ。世界中で使われているチャットサービスです。

## 何が起きたのか

セキュリティ企業「JUMPSEC」の調査により、北朝鮮のハッカーグループ「BlueNoroff」が、**Zoomや Microsoft Teamsに見せかけた偽のビデオ会議サイトを使った精巧な詐欺システム**を運用していることが明らかになりました。

この攻撃の特徴は以下の3点です。

1. **事前調査を行う**：マルウェア（ウイルス）を送り込む**前に**、被害者のパソコンに仮想通貨ウォレットが入っているかを確認し、「お金になりそうな相手」だけを狙う
2. **信頼できる人を装う**：被害者がすでに知っている人のアカウントを乗っ取って連絡してくる
3. **自動的に広がる**：1人が被害に遭うと、その人の連絡先にいる次の人が狙われる「連鎖感染」のような仕組みになっている

## 技術的な詳細

この攻撃は、まるで映画のような複数のステップで構成されています。順番に見ていきましょう。

### ステップ1：侵入口は「信頼できる友人」

```
攻撃者 → 仮想通貨業界の人のTelegramアカウントを乗っ取る
  ↓
乗っ取ったアカウントから、被害者に「会議しましょう」とメッセージを送る
  ↓
被害者は「知っている人からの連絡だ」と信じる ← ここが最大のポイント！
```

> 🏫 **例え話で説明すると**：クラスの友達のLINEアカウントが乗っ取られて、その友達のふりをした悪者から「このURLを見て！」とメッセージが来るようなイメージです。

### ステップ2：偽のZoom会議に誘い込む

- メッセージには「Calendly（カレンドリー：予約管理サービス）」のリンクが貼られている
- リンクをクリックすると、**本物そっくりの偽Zoomページ**に飛ぶ（実際はドメイン名が微妙に違う）
- 偽サイトで名前を入力させ、**カメラへのアクセス許可**を求める
- 許可すると、**カメラの映像が密かに攻撃者に送られる**

### ステップ3：仮想通貨ウォレットの「事前調査」

ここが今回の攻撃の**最も重要な特徴**です。

```
被害者が偽サイトにアクセスした時点で...
  ↓
ブラウザ上のどんな仮想通貨ウォレット拡張機能が入っているか自動チェック
  ↓
「高額な仮想通貨を持っていそう」な人だけに攻撃を継続
  ↓
「価値がない」と判断された人への攻撃は中止（無駄を省くため）
```

> 🏫 **例え話で説明すると**：泥棒が家に入る前に「この家にお金はあるか？」と窓からこっそり確認するようなものです。

### ステップ4：偽の「Zoom通話」でだます

- 被害者が会議に「参加」すると、画面には「他の参加者を待っています」というメッセージが表示される
- しばらくすると、**AI（ChatGPT）で作られた顔の動画**が相手として表示される
- この動画は、以前の攻撃で録画した実際の人物の動きに、**AIが生成した顔を合成したもの**
- 「マイクが動いていません」という偽メッセージを送り、被害者に「Zoom SDKのアップデート」をさせようとする

### ステップ5：ClickFix攻撃でマルウェアをインストールさせる

「アップデートが必要です」という画面で、実際には**悪意のあるコマンド（命令文）をコピー＆ペーストさせる**手口（ClickFix）を使います。

- **Windowsの場合**：PowerShell（ウィンドウズに内蔵されているプログラム実行ツール）を使って悪いプログラムを実行させる
- **Macの場合**：同様の手口でmacOS向けのマルウェアを実行させる

### ステップ6：感染が次の人へと連鎖する

```
被害者AのTelegramが乗っ取られる
  ↓
Aの知人Bに偽の会議リンクが送られる
  ↓
BのTelegramが乗っ取られる
  ↓
Bの知人Cに…（繰り返し）
```

さらに、Aを騙した時の動画素材が、次のBを騙すための**AI合成動画の材料**として使われます。攻撃が成功するたびに、詐欺の精度が上がっていくのです。

## なぜ重要なのか

### 📊 この攻撃が特別に危険な理由

| 従来のフィッシング詐欺 | 今回の攻撃 |
|---|---|
| 知らない人からメールが来る | **知っている人から**メッセージが来る |
| 怪しいサイトに誘導される | **本物そっくりの偽Zoom**に誘導される |
| 全員に同じ攻撃をする | **事前調査で価値ある人だけを狙う** |
| 静止画の偽人物 | **AIで本物そっくりの動画を使う** |
| 手動で広げる | **自動的に感染が広がる** |

### 💡 特に標的にされやすい人
- 仮想通貨関連の会社で働いている人
- ビットコインなどの仮想通貨を大量に持っている人
- 業界の有名人・幹部クラスの社員

### 🌍 社会への影響
北朝鮮はこうして盗んだ仮想通貨を、ミサイル開発などの資金源にしていると言われています。つまり、これは単なる個人の被害にとどまらず、**国際的な安全保障の問題**にも関わっています。

## 対策・今後の展望

### ✅ 今すぐできる対策

**1. Zoomのリンクは必ず本物か確認する**
- 本物のZoomのURLは `zoom.us` です
- 少しでも違うドメイン名（例：`z0om.us` や `zoom-meeting.com`）はすぐに疑いましょう

**2. 知人からのリンクでも油断しない**
- 「いつもと違う雰囲気のメッセージ」が来たら要注意
- 別の連絡手段（電話など）で本人に確認する習慣をつけましょう

**3. ブラウザの「カメラ許可」は慎重に**
- よく知らないサイトにカメラへのアクセスを許可しない

**4. コピー＆ペーストを求める指示には従わない**
- 「このコマンドをコピーして実行してください」という指示は、ほぼ確実に詐欺です
- 正規のZoomアップデートは、このような方法では行いません

**5. 仮想通貨ウォレットは慎重に管理する**
- ブラウザ拡張機能のウォレットは、使わないときは無効にしておく
- 大きな金額は「ハードウェアウォレット」（インターネットに繋がっていない専用機器）で管理する

**6. Telegramのセキュリティを強化する**
- 二段階認証を必ず設定する
- 見知らぬリンクはクリックしない

### 🔮 今後の展望
- AI技術の進歩とともに、偽動画（ディープフェイク）はさらにリアルになっていく可能性があります
- 企業はセキュリティ研修で、このような「信頼できる人からの連絡」でも疑う文化を作ることが重要です
- セキュリティ各社がこの攻撃を詳しく分析・公開していることで、対策ツールの開発が進むと期待されています

## 過去記事との関連

以前「**保険フィッシング詐欺がリアルタイム口座乗っ取りに進化している**」という記事を解説しましたが、今回の事例はさらに進化した形と言えます。

- **前回（保険フィッシング）**：偽サイトで入力された情報を使い、リアルタイムで本物サイトにログインして口座を乗っ取る
- **今回（BlueNoroff）**：被害者を偽のビデオ会議に誘い込み、AIで作った偽人物まで登場させて、段階的に信頼を構築してから攻撃する

共通しているのは、**「リアルタイムで人間が操作している」攻撃**という点です。単純なプログラムの自動攻撃ではなく、攻撃者が状況に応じて対応するため、自動検知システムをかいくぐりやすくなっています。フィッシング詐欺は全体的に「より人間らしく、より信頼できるように見せる」方向に進化しています。

## 用語解説

| 用語 | 意味 |
|---|---|
| **BlueNoroff** | 北朝鮮系の仮想通貨窃取を専門とするハッカーグループ |
| **フィッシング（Phishing）** | 本物に見せかけた偽サイトや偽メールで情報を盗む詐欺 |
| **ClickFix** | 「修正が必要」と嘘をついて、悪意のあるコマンドをユーザー自身に実行させる攻撃手法 |
| **タイポスクワッティング** | `zoom.us` を `zo0m.us` のようにわずかに変えた偽ドメイン名を使う手口 |
| **ソーシャルエンジニアリング** | 人間の心理的な隙を突いて情報を盗む攻撃。技術的な手法より「人をだます」ことに重点 |
| **マルウェア** | パソコンに害を与える悪意のあるプログラムの総称（ウイルスも含む） |
| **仮想通貨ウォレット** | ビットコインなどを管理するデジタルな財布。ブラウザ拡張機能として使われることが多い |
| **ディープフェイク** | AIで本物そっくりに作られた偽動画や偽画像 |
| **WebRTC** | ブラウザ間でリアルタイムに音声・映像をやり取りするための技術 |
| **PowerShell** | Windowsに標準搭載されている、コマンドで操作できる強力なツール |
| **二段階認証** | パスワードに加えて、スマートフォンへの確認コードなど2つの方法で本人確認する仕組み |
| **Calendly** | オンラインで会議の予約・スケジュール管理ができるサービス。今回は偽リンクの入り口として悪用された |
