# Cl0pランサムウェア集団が製造業向けソフトの脆弱性を悪用した新たな攻撃を展開中

**元記事**: [Cl0p Affiliates Target Internet-Exposed PTC Windchill and FlexPLM with Unauthenticated RCE](https://inl03.netline.com/ltr6/?_m=3n.009a.4039.sp0ao46r89.33fe)
**解説日**: 2026年7月28日

---

## 背景知識

まず、このニュースを理解するために必要な基本知識を整理しましょう。

### 🏭 PTC WindchillとFlexPLMって何？

**PTC Windchill（ウィンドチル）** は、主に製造業・自動車・航空宇宙などの大企業が使う「製品設計・開発データを管理するためのソフトウェア」です。設計図や部品情報、製造ノウハウなど、企業にとって超重要な機密データが詰まっています。

**FlexPLM** も同じPTCという会社が作った、アパレル・小売業向けの製品管理ソフトです。

> 💡 **例えるなら**：WindchillやFlexPLMは「企業の設計図や製品情報が入った金庫のような管理システム」です。これがインターネットに接続されている場合、外部から狙われるリスクがあります。

### 🦹 Cl0p（クロップ）って誰？

**Cl0p** は、世界的に有名なサイバー犯罪集団（ランサムウェアグループ）です。過去にも多くの大企業を攻撃し、データを盗んで「お金を払わなければデータを公開する」と脅す手口で知られています。「FIN11」「Lace Tempest」など複数の別名を持つほど、長い歴史のある危険なグループです。

### 🔑 ランサムウェアと「二重脅迫」とは？

- **ランサムウェア**：データを暗号化して使えなくし、お金（身代金）を要求するウイルス
- **二重脅迫（Double Extortion）**：「データを暗号化する」＋「盗んだデータをネットに公開する」の2段構えで脅す手口

## 何が起きたのか

Cl0pというサイバー犯罪集団と関係のある攻撃者たちが、インターネットに公開されている**PTC WindchillとFlexPLM**という企業向けソフトウェアの深刻な脆弱性（セキュリティの穴）を悪用して、攻撃を行っていることが確認されました。

### 📋 被害を受けている業界
| 業界 | 被害の深刻度 |
|------|------------|
| 製造業 | 🔴 高 |
| 自動車 | 🔴 高 |
| 航空宇宙 | 🔴 高 |
| 小売業 | 🟠 中〜高 |

攻撃者はシステムに侵入した後、設計データや製品情報などの機密データを盗み出し、「お金を払わなければデータを公開する」と脅すダブル脅迫を行っています。

## 技術的な詳細

ここが少し難しいですが、できるだけわかりやすく説明します！

### 🔓 攻撃の流れ（2段階の脆弱性を組み合わせる）

攻撃者は「**2つのセキュリティの穴を組み合わせる**」という巧妙な手口を使っています。

```
【Step 1】FlexPLMの情報漏えい脆弱性を突く
    ↓
ログインしなくても内部情報（認証に使うトークンなど）が取れる
    ↓
【Step 2】Windchillのログイン処理の欠陥を突く
    ↓
取得した情報を使って、ログインせずにサーバーを操作できる状態になる
    ↓
【Step 3】JSPウェブシェルを設置する
    ↓
サーバーを自由に遠隔操作できるようになる！
```

> 💡 **例えるなら**：
> - Step1は「鍵の型を遠くから盗み見る」こと
> - Step2は「盗み見た型でコピーキーを作る」こと
> - Step3は「コピーキーで扉を開けて、勝手口を作る」こと

### 🐚 JSPウェブシェルって何？

**ウェブシェル（Web Shell）** とは、サーバーに仕掛けるバックドア（裏口）のようなプログラムです。攻撃者はこれを使って、まるで正規の管理者のようにサーバーを遠隔操作できるようになります。

### 📊 脆弱性のスコア

この攻撃に使われた脆弱性は **CVE-2026-12569** と識別されており、深刻度スコア（CVSSスコア）は **9.3/10** という「超危険」レベルです。

> 💡 **CVSSスコアの目安**：
> - 0〜3.9：低（軽微）
> - 4.0〜6.9：中（注意）
> - 7.0〜8.9：高（危険）
> - **9.0〜10.0：緊急（超危険）** ← 今回はここ！

## なぜ重要なのか

### 🎯 被害が非常に大きい理由

1. **認証なしで攻撃できる（Unauthenticated RCE）**
   普通、システムを操作するにはIDとパスワードが必要です。でも今回の攻撃は、**ログインしなくても**サーバーを乗っ取れてしまいます。つまり、誰でも攻撃できてしまう非常に危険な状態です。

2. **狙われているのは超重要な機密データ**
   WindchillやFlexPLMには、製品の設計図、製造ノウハウ、部品情報など「企業の命綱」とも言えるデータが保存されています。これらが盗まれると、競合他社や敵対国に技術が漏れる恐れがあります。

3. **Cl0pはこういう攻撃の"プロ"**
   このグループは過去にも多くの有名ソフトウェアの脆弱性を使って大規模攻撃を行ってきた実績があります（後述）。

4. **アメリカのCISA（サイバーセキュリティ機関）も警告中**
   米国の政府機関CISAが「悪用が確認された脆弱性リスト（KEV）」に追加しており、国家レベルで警戒されています。

## 対策・今後の展望

### ✅ 企業・管理者がすべきこと

| 対策 | 詳細 |
|------|------|
| **即座にパッチ適用** | PTCが提供するセキュリティアップデートを今すぐ適用する |
| **インターネット公開の見直し** | WindchillやFlexPLMをインターネットに直接公開している場合は、VPNなどの保護を入れる |
| **IoC（攻撃の痕跡）を確認** | 記事に書かれた4つのIPアドレスからのアクセスがないか確認する |
| **ウェブシェルの有無を確認** | `/Windchill/login/` 配下に不審なファイルがないか確認する |
| **不審なメールに注意** | 恐喝メールが社員100人以上に一斉送信されるケースがあるため、社員教育も重要 |

### 🔍 確認すべき不審なIPアドレス（IoC）
```
216.152.148.54
216.152.151.204
104.243.35.63
5.180.41.35
```
これらのIPからのアクセスがログにあれば、すでに攻撃されている可能性があります。

### 🔮 今後の動向

Cl0pは過去に**MOVEit Transfer**など大規模な攻撃を繰り返してきた組織であり、今後もこのような「企業の基幹システムの脆弱性」を狙った攻撃は続くと考えられます。製造業や航空宇宙産業など、高価値データを持つ企業は特に注意が必要です。

## 過去記事との関連

以前、**「認証済みユーザーがgitサーバー上でコマンドを実行できるGitLabの深刻な脆弱性（RCE）」** についてご紹介しました。

今回の攻撃と共通しているのは「**RCE（リモートコード実行）**」という攻撃手法です。

| 比較項目 | 過去のGitLab脆弱性 | 今回のWindchill脆弱性 |
|----------|------------------|---------------------|
| 認証の要否 | **認証済みユーザーが必要** | **認証不要（より危険）** |
| 影響対象 | 開発者・エンジニア | 製造業・航空宇宙など |
| 攻撃の目的 | コマンド実行 | データ窃取＋恐喝 |

GitLabの場合は「ログインした人だけが悪用できる」脆弱性でしたが、今回はログインすら不要という点で**さらに深刻**です。RCE（リモートコード実行）という攻撃手法は、攻撃者にとって「システムを完全支配できる最強の武器」であり、どのシステムでも最優先で対処が必要です。

## 用語解説

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **Cl0p（クロップ）** | クロップ | 世界的に有名なランサムウェア犯罪集団 |
| **RCE** | アールシーイー | Remote Code Execution（リモートコード実行）。遠隔からサーバーにプログラムを実行させる攻撃 |
| **Unauthenticated** | アンオーセンティケーテッド | 「認証なし」の意味。ログインせずに攻撃できることを指す |
| **JSPウェブシェル** | ジェイエスピー・ウェブシェル | サーバーに仕掛けるバックドア（裏口）プログラム。遠隔操作に使われる |
| **CVE** | シーブイイー | セキュリティの脆弱性に付けられる識別番号（Common Vulnerabilities and Exposures）|
| **CVSSスコア** | シーブイエスエス・スコア | 脆弱性の深刻度を0〜10で表したスコア。高いほど危険 |
| **CISA** | シーサ | 米国のサイバーセキュリティ・インフラセキュリティ庁 |
| **KEV** | ケーブイ | Known Exploited Vulnerabilities。実際に悪用が確認された脆弱性のリスト |
| **IoC** | アイオーシー | Indicators of Compromise。攻撃の痕跡を示す情報（IPアドレスなど） |
| **二重脅迫** | にじゅうきょうはく | データ暗号化＋データ公開の2段構えで脅すランサムウェアの手口 |
| **PLM** | ピーエルエム | Product Lifecycle Management。製品の設計〜製造〜廃棄までを管理するシステム |
| **WSDL** | ダブリューエスディーエル | Webサービスのインターフェース定義ファイル。ここに情報漏えいの脆弱性があった |
| **VPN** | ブイピーエヌ | Virtual Private Network。インターネット上に安全な通信経路を作る仕組み |
