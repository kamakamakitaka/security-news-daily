## 背景知識

このニュースを理解するために、まずいくつかの基本的な考え方を押さえておきましょう。

### 🤖 AIエージェントって何？

普通のプログラムは「こうなったら、こうする」という**決まった手順（コードパス）**で動きます。たとえば「ボタンを押したら画面が切り替わる」という動作は、どんな状況でも同じです。

一方、**AIエージェント**は違います。目標（ゴール）を与えられると、そこに向かって自分で「次に何をするか」を考えながら動きます。まるで人間のように状況を判断し、使うツールを自分で選んで行動するのです。

> 📌 **例え話**: 普通のプログラムは「レシピ通りに料理するロボット」。AIエージェントは「冷蔵庫の中身を見て、自分でメニューを考えて料理する料理人」のようなイメージです。

### 🔒 従来のセキュリティの限界

これまでのセキュリティ対策は「**何を送ったか・何が返ってきたか**」という**内容（コンテンツ）を検査する**ものでした。たとえば怪しい言葉が含まれていたらブロックする、といった仕組みです。

しかしAIエージェントは同じ入力でも、状況や会話の流れによって**全く違う行動をとる**ことがあります。だから「内容を見るだけ」では守りきれないのです。

## 何が起きたのか

セキュリティ企業「**Lasso**（ラッソ）」が、AIエージェント専用のセキュリティプラットフォームを開発・公開しました。

これは従来の「コンテンツをチェックする」セキュリティとは一線を画す、**AIの「行動そのもの」を監視・管理する**まったく新しいアプローチです。

具体的には以下の4つの機能を一つにまとめたプラットフォームです：

1. **ディスカバリー（発見）**: 社内にどんなAIエージェントが存在するかを把握する
2. **リスク管理**: 各AIエージェントの危険度を評価する
3. **レッドチーミング**: 攻撃者の視点でAIの弱点を事前に探す
4. **ランタイム強制**: AIが実際に動いている最中に異常な行動を止める

## 技術的な詳細

### 🎯 「インテント（意図）セキュリティ」という新発想

Lassoが提唱するのは「**インテント セキュリティ**」という考え方です。

従来の問い：「このメッセージに危険な言葉が含まれているか？」
Lassoの問い：「**このAIは、今この状況で、このユーザーに対して、本来やるべきことをやっているか？**」

これを実現するために、Lassoは各AIエージェントの「**ベースライン（通常の行動パターン）**」を学習し、それから外れた行動を検知し続けます。

> 📌 **例え話**: 学校の先生が「この生徒はいつもこういう行動をする」と把握しておいて、突然おかしな行動をしたらすぐ気づける、というイメージです。

---

### 🔄 「閉じた防御ループ」のアーキテクチャ

Lassoの最大の特徴は、4つの機能がバラバラではなく**互いに連携している**点です。

```
【発見】→【リスク分析】→【攻撃テスト】→【リアルタイム防御】
   ↑________________________________↓
        （学習結果がフィードバック）
```

多くの企業は現在、それぞれの機能を別々のツールで対応しています。その結果、**ツール間の「隙間」にリスクが溜まってしまう**という問題があります。

Lassoはこの隙間をなくし、ある段階で得た情報が次の段階に自動的に活かされる**一体型のループ**を実現しています。

---

### 🔍 ディスカバリー（AI発見）機能の仕組み

「社内にどんなAIエージェントがいるか把握できていない」は、多くのセキュリティチームが抱える最大の課題です。

特に最近は、**エンジニア以外のチームでもAIエージェントを作れる**ローコード・ノーコードツールが普及しています。

> 📌 **例え話**: 「会社の中に、IT部門が知らないところで誰かが勝手に鍵のかかっていないドアを増やしている」ような状況です。

Lassoは以下の環境を横断してAIエージェントを自動検出します：

## なぜ重要なのか

### 1️⃣ AIエージェントの爆発的な普及

「コードを書かなくてもAIを作れるツール」が増えたことで、営業部門・人事部門・経理部門など、**IT部門以外のチームが独自にAIエージェントを作る時代**になっています。

これらのAIが社内の重要データ（人事情報・顧客データ・生産データなど）にアクセスできる場合、セキュリティの穴になり得ます。

### 2️⃣ AIの攻撃面は「行動」そのもの

AIエージェントは同じ質問でも、状況によって**異なる行動をとります**。これは便利な反面、「想定外の行動」が起きやすいことを意味します。

攻撃者がこれを悪用すれば、AIを**意図しない行動**（データの漏洩、不正な操作など）に誘導できてしまいます。

### 3️⃣ 「後から気づく」では遅い

バラバラなセキュリティツールを使っていると、問題が発生してから対応するまでに時間がかかります。Lassoのような一体型プラットフォームは、**リアルタイムで検知・対処**できる点で大きなアドバンテージがあります。

## 対策・今後の展望

### 企業・組織ができること

✅ **まず「棚卸し」をする**
自社でどんなAIエージェントが使われているか、IT部門が把握していないものも含めてリストアップしましょう。

✅ **作る人だけでなく、守る人も教育する**
ローコード・ノーコードツールでAIを作れる人が増えた今、「作り方」だけでなく「セキュリティリスク」も一緒に学ぶ文化が必要です。

✅ **AIの「通常の行動」を定義しておく**
「このAIは何をするべきか・すべきでないか」を事前に明確にしておくことで、異常検知の精度が上がります。

### 今後の動向

AIエージェントのセキュリティは**2025年以降のセキュリティ業界の最重要テーマの一つ**です。LassoのようなAI専用セキュリティプラットフォームの需要は今後急速に高まると予想されます。

## 用語解説

| 用語 | 解説 |
|------|------|
| **AIエージェント** | 目標を与えられると自分で判断して行動するAIプログラム。チャットbotより高度で、ツールを使ったり複数のステップを踏んで作業を完了させる |
| **コードパス（実行パス）** | プログラムが実行される際に通る処理の流れ。通常のプログラムは決まった経路を通るが、AIは状況によって変わる |
| **インテント セキュリティ** | 「何を送ったか」ではなく「AIが今やっていることは本来の目的通りか」を監視するセキュリティの考え方 |
| **ベースライン** | 「通常の状態・行動パターン」のこと。これと比較することで異常を検知する |
| **レッドチーミング** | 攻撃者の立場に立って自社のシステムの弱点を探す作業。本番環境に被害が出る前に問題を発見するために行う |
| **ランタイム（実行時）** | プログラムが実際に動いている最中のこと。「事前の設定」ではなく「動きながらリアルタイムで監視・制御する」イメージ |
| **ローコード・ノーコード** | プログラミングの知識がほとんどなくてもアプリやツールを作れる開発環境のこと |
| **ポスチャー分析** | システムの現在のセキュリティ状態（姿勢）を評価・診断すること |
| **ガードレール** | AIが「やってはいけないこと」を制限するための設定・ルールのこと。道路の欄干（ガードレール）のように、逸脱を防ぐ |
| **AWS Bedrock / Azure AI Foundry / Google Vertex AI** | それぞれAmazon、Microsoft、GoogleのAI開発プラットフォーム。企業がAIエージェントを構築するために使う |
