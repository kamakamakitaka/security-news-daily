# マイクロソフトが新しいサイバーセキュリティAIを発表！コストを半減しながら高スコアを達成

**元記事**: [Microsoft Says New Cybersecurity AI Model Helps MDASH Score 95.95% at Half the Cost](https://inl03.netline.com/ltr6/?_m=3n.009a.4041.sp0ao46r89.33ic)
**解説日**: 2026年7月29日

---

## 背景知識

このニュースを理解するために、いくつかの基本的な概念をおさえておきましょう。

### 🤖 AIモデルって何？
AIモデルとは、大量のデータを学習して「賢くなった」プログラムのことです。ChatGPTのようなものをイメージしてください。今回の話には複数のAIモデルが登場します。

### 🛡️ サイバーセキュリティとAIの組み合わせ
最近、AIをセキュリティの分野に使う動きが活発です。具体的には、「ソフトウェアの弱点（脆弱性）を自動で見つけて、修正方法まで提案してくれるAI」を作ることが注目されています。

### 🔍 「脆弱性」とは？
脆弱性（ぜいじゃくせい）とは、ソフトウェアやシステムに存在する「セキュリティ上の穴」のことです。泥棒が家に入るための「鍵のかかっていない窓」のようなイメージです。攻撃者はこの穴を使ってシステムに不正に侵入します。

### 📊 ベンチマークって何？
ベンチマークとは、AIや技術の「実力テスト」のことです。学校の模擬試験のようなもので、点数が高いほど性能が良いとされます。今回の記事では「CyberGym」というベンチマーク（セキュリティAI専用の試験）が登場します。

---

## 何が起きたのか

マイクロソフトが、**セキュリティ専用の新しいAIモデル「MAI-Cyber-1-Flash」**を発表しました。

この新モデルは、マイクロソフトが開発中の脆弱性発見・修正システム「**MDASH（エムダッシュ）**」に組み込まれています。

### 注目ポイントをまとめると…

| ポイント | 内容 |
|----------|------|
| スコア | セキュリティAIの試験「CyberGym」で**95.95%**を達成 |
| コスト | 以前の構成と比べて**50%のコスト削減** |
| 役割分担 | 普通のタスクはMAI-Cyber-1-Flash、難しいタスクはGPT-5.4が担当 |
| 公開範囲 | 一般公開はされておらず、**限定的なプレビュー**のみ |

**わかりやすく言うと…**

これまでマイクロソフトは「複数の高性能AIを組み合わせる」という方法でセキュリティ問題に対応していました。それを「普通の仕事は安くて速い専用AIに任せ、本当に難しい仕事だけ高性能AIに任せる」という効率的な仕組みに変えたのです。まるでコンビニのアルバイトと専門家の医師を上手に使い分けるようなイメージです。

## 技術的な詳細

### MAI-Cyber-1-Flashの仕組み

このAIモデルの特徴を、できるだけわかりやすく解説します。

#### 📐 モデルの規模
- **総パラメータ数**: 1370億個
  - パラメータとはAIの「思考の細かさ」を表す数値です。数が多いほど複雑なことを考えられますが、処理に時間・コストがかかります
- **実際に動くパラメータ数**: 50億個
  - これが「スパース混合専門家（MoE）」という仕組みのポイントで、全部のパラメータを毎回使うのではなく、必要な部分だけを選んで使います

> 📌 **例え話**: 1370億個のパラメータを持つのに、実際に使うのは50億個。これはまるで「百科事典を全部持ち歩かず、必要なページだけを開いて読む」ようなイメージです。これにより、処理が速くなりコストも下がります。

#### 🔀 役割分担（ルーティング）の仕組み

```
【MDASHシステムの役割分担】

全タスクの90%
→ MAI-Cyber-1-Flash（安くて速い専用AI）が担当

残りの難しいタスク10%
→ GPT-5.4（高性能AI）が担当

この組み合わせで → CyberGym 95.95% を達成！
```

#### ⚠️ スコアについての注意点（重要！）

記事をよく読むと、いくつか気をつけるべき点があります：

1. **95.95%はMAI-Cyber-1-Flash単独のスコアではない**
   - これはMDASHシステム全体（MAI-Cyber-1-Flash + GPT-5.4の組み合わせ）のスコアです

2. **公開ランキングには載っていない**
   - 2026年7月28日時点で、CyberGymの公式ランキングには95.95%の結果が掲載されておらず、1位はWizという会社の「Atlasエージェント」で90.9%でした
   - マイクロソフトの公式登録スコアは88.4%のままです

3. **CyberGymのテスト内容は限定的**
   - このテストは「既知の脆弱性を再現できるか」を測るもので、「新しい脆弱性を一から発見できるか」は測定していません

> 💡 **わかりやすく言うと**: 「模擬試験で95点取ったよ！」と言っているけれど、その点数は学校の公式記録には載っておらず、どういうルールで採点したかも完全には明らかにされていない、という状況です。

### MAI-Cyber-1-Flashのその他のテスト結果

一方、単体のモデルテストでは気になる結果も：

| テスト名 | スコア | 内容 |
|----------|--------|------|
| CVEBench | 0.314 | 既知の脆弱性対応力 |
| ExploitGym | **0点** | 実際に動く攻撃コードを作れるか |
| CRSBench | 0.651 | セキュリティ対応力の総合評価 |

特に**ExploitGym**でのスコア「0点」は注目すべき点で、「実際に動く攻撃コード（エクスプロイト）を生成する」テストでは全く機能しなかったことを示しています。これはセキュリティ上の「使われ方の制限」が意図的にかけられている可能性があります。

## なぜ重要なのか

### 🌟 良い面

1. **コストの大幅削減**
   AIを使ったセキュリティ分析は非常に高コストでした。それが半額になれば、より多くの企業がセキュリティ対策にAIを活用できるようになります。

2. **効率的な役割分担の実証**
   「安いAIと高性能AIを賢く組み合わせる」というアイデアが、セキュリティ分野でも有効であることを示しました。

3. **サイバーセキュリティ専用AIの登場**
   汎用AIではなく、セキュリティに特化したAIが登場したことで、より高度な自動分析が期待できます。

### ⚠️ 懸念される面

1. **透明性の不足**
   - コスト50%削減の根拠となるデータ（処理量・処理速度など）が開示されていません
   - 公式ランキングへの申請状況が不明です

2. **AIによる脆弱性発見の両刃の剣（もろはのつるぎ）**
   - セキュリティ専門家が守るためにAIを使う一方、攻撃者も同じAI技術を悪用できます
   - 以前お伝えした「AIがLinuxの脆弱性発見を手助けした」ニュースと同様の懸念です

3. **限定公開のため独立した検証が困難**
   - 現在はAzure AI Foundryのプライベートプレビュー（承認された顧客のみ）での提供のため、第三者が性能を確認できません

## 対策・今後の展望

### 一般ユーザー・学生が今すぐできること

このサービス自体は限定公開なので、直接使えるわけではありませんが、このニュースから学べることがあります：

- **AIはツールであり、それを使うシステム全体が重要**
  記事の中でマイクロソフト副社長が述べているように、「モデルは部品の一つ。その周りのシステムこそが製品だ」という考え方は、AIツールを使う上での重要な視点です。

- **ベンチマークのスコアを鵜呑みにしない**
  「〇〇%達成！」という数字は、どんな条件で測られたかをセットで確認することが大切です。

### 今後の動向

- セキュリティAIの競争は激化しており、マイクロソフト、Wiz（Google傘下）などが高いスコアを競い合っています
- AIによる脆弱性発見の自動化が進むことで、企業のセキュリティ対応速度が向上すると期待されています
- 一方で、AIが生成するコードへの信頼性の問題（誤った修正コードを生成する可能性）も今後の課題です

## 過去記事との関連

以前、「**AIがLinuxの脆弱性（root権限を取得できる危険なバグ）の発見を手助けした**」というニュースをお伝えしました。

あの記事では、AIが「攻撃に使える脆弱性を発見・開発するツール」として機能した事例でした。

今回のマイクロソフトのニュースは、その**反対側の立場**——つまり「AIを使って脆弱性を自動的に見つけ、守る側が先手を打てるようにする」という取り組みです。

```
【AIとセキュリティの構図】

攻撃側 → AIで脆弱性を発見・悪用コードを開発
            ⬇
防御側 → AIで脆弱性を先に発見・修正（今回のMDASH）
```

この「AIを使った攻防」はますます激しくなっており、どちらの技術が速く進歩するかが、今後のサイバーセキュリティの鍵を握っています。
