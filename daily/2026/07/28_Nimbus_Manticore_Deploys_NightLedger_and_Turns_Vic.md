# ニムバス・マンティコアがNightLedgerを展開し、被害者のシステムを秘密の中継基地に変える

**元記事**: [Nimbus Manticore Deploys NightLedger and Turns Victim Systems Into Covert Relays](https://inl03.netline.com/ltr6/?_m=3n.009a.4041.sp0ao46r89.33ho)
**解説日**: 2025年7月10日

---

## 背景知識

このニュースを理解するために、まず以下の基本的な概念を押さえておきましょう。

### 🏛️ 国家支援型ハッカーグループとは？
普通のハッカーは個人や犯罪組織ですが、「国家支援型」とは**国の政府がお金や技術を提供して動かしているハッカーグループ**のことです。目的はお金儲けよりも、**スパイ活動・情報収集・他国へのサイバー攻撃**です。今回登場する「Nimbus Manticore（ニムバス・マンティコア）」はイランの政府に支援されていると言われています。

### 🚪 バックドアとは？
「バックドア（裏口）」とは、**コンピュータに秘密の入り口を作るプログラム**のことです。泥棒が家の裏口に合鍵を仕掛けるようなイメージで、攻撃者はいつでも被害者のパソコンに侵入できるようになります。

### 🔀 トンネリングとは？
インターネット上の通信を**他のシステムを経由させて、発信元を隠す技術**です。例えば、攻撃者が「Aのパソコン」を踏み台にして「Bのサーバー」を攻撃すると、Bから見ると攻撃はAから来ているように見えます。まるで**代理人を使って悪事を働くようなイメージ**です。

### 📡 WebSocketとは？
ウェブサイトとサーバーがリアルタイムで双方向に通信するための技術です。チャットアプリや株価表示などによく使われます。今回はこの技術が**悪用されて**秘密の通信路を作るために使われています。

### 🎭 フィッシングとは？
**有名な企業や機関になりすまして、偽のメールやページで個人情報やパソコンへの侵入経路を騙し取る攻撃**です。今回は「求人情報」を偽装したフィッシングが使われています。

## 何が起きたのか

イランの国家支援型ハッカーグループ「**Nimbus Manticore**」（別名：GalaxyGato、Mirage Kitten、Smoke Sandstorm など複数の名前で追跡されています）が、**中東・アフリカ・南アジア**の複数の国や組織を標的にした新しいサイバー攻撃を行っていたことが、セキュリティ会社「Kaspersky（カスペルスキー）」の調査で明らかになりました。

### 🎯 攻撃の標的となった国・組織
| 国 | 標的となった組織 |
|---|---|
| エジプト | 中小企業・政府機関 |
| ヨルダン | 中小企業・政府機関 |
| タンザニア | 中小企業・政府機関 |
| パキスタン | 航空関連組織 |
| エチオピア | 通信会社 |
| ブルキナファソ | 金融関連機関 |

### 🛠️ 使用された新しい武器
今回の攻撃で**初めて発見された**マルウェア（悪意のあるプログラム）が3種類確認されました：

1. **NightLedger（ナイトレジャー）** → Windowsに仕込む「裏口」プログラム
2. **BridgeHead（ブリッジヘッド）** → 通信を秘密裏に中継するトンネルツール
3. **ArcBridge（アークブリッジ）** → WebSocketを使った別の秘密通信ツール

## 技術的な詳細

### 🎣 Step 1：どうやって侵入するのか（フィッシング攻撃）

攻撃の入口は**偽の求人情報メール**です。

```
例えばこんな偽メール：
「〇〇航空会社の採用担当者より、あなたのプロフィールに
 興味を持ちました。詳細はこちらのリンクから確認ください。」
```

リンクをクリックすると、本物そっくりの偽サイトに誘導され、**悪意のあるファイルをダウンロード**させられます。また、偽のビデオ会議ページも使われています。

### 💉 Step 2：NightLedgerの仕込み方（DLLサイドローディング）

> **DLL（ディーエルエル）とは？**
> Windowsのプログラムが「部品」として使う共通のファイルです。複数のソフトが同じDLLを使い回します。

**DLLサイドローディング**という手口は、正規のソフトウェアが読み込もうとするDLLファイルを、**悪意のある偽物にすり替える**技術です。正規のソフトが代わりに悪意のあるプログラムを起動してしまうので、セキュリティソフトに検出されにくいのが特徴です。

```
【イメージ図】
正規ソフト「あ、部品ファイル(DLL)を読み込もう」
　　↓
実は、悪意ある偽DLL（NightLedger）を読み込んでしまう！
　　↓
悪意のあるプログラムが裏で動き出す...
```

### 🕵️ Step 3：NightLedgerができること

NightLedgerは攻撃者のサーバーに**HTTPSで接続**（普通の暗号化ウェブ通信に見せかけて）し、以下のような指令を受け取って実行します：

| 機能 | 内容 |
|---|---|
| 情報収集 | ユーザー名・コンピュータ名・ネットワーク情報を盗む |
| プログラム実行 | 攻撃者が指定したプログラムを動かす |
| ファイル操作 | ファイルのコピー・削除・ダウンロード・アップロード |
| スクリーンショット | 画面を撮影して攻撃者に送信 |
| プロセス調査 | どんなソフトが動いているか調べる |
| 診断ログの収集 | Windowsのドメイン参加に関するログファイルを盗む |

### 🔀 Step 4：BridgeHeadで被害者のPCを「中継基地」にする

ここが今回のニュースで特に重要な部分です。

**BridgeHead**は**SOCKS5プロキシ**（通信の中継器）として機能します。

```
【通常の攻撃の場合】
攻撃者 ──→ 標的のサーバー
（攻撃元がバレる）

【BridgeHeadを使った場合】
攻撃者 ──→ 被害者PC（中継基地） ──→ 別の標的
           ↑ここが「BridgeHead」
（攻撃は「被害者PCから来た」ように見える）
```

攻撃者のサーバーがWebSocketで命令を送ると、被害者のPCが**まるで自分が発信源であるかのように**別の場所への通信を中継します。つまり、**被害者のPCが知らないうちに犯罪の踏み台にされている**わけです。

### 🌐 Step 5：ArcBridgeとの違い

ArcBridgeも同様のWebSocketトンネリングツールですが、2026年4月に中東での攻撃で新たに発見されました。BridgeHeadとArcBridgeを**組み合わせて使う**ことで、追跡をさらに困難にしています。

## なぜ重要なのか

### 🌍 影響の広さ
今回の攻撃は**6か国以上、政府・航空・通信・金融という社会インフラ**に関わる重要な組織を標的にしています。これらの組織への侵入は、国家の安全保障や社会生活に直結する情報の漏えいにつながる可能性があります。

### 🔍 発見が難しい理由
- **正規のHTTPS通信に偽装**しているため、普通の通信と見分けがつきにくい
- **DLLサイドローディング**で正規ソフトウェアを悪用するため、怪しいプログラムが単独で動いているように見えない
- **WebSocketトンネリング**で通信を隠すため、どこが本当の攻撃元か特定しにくい

### 🆕 新しいツールの発見
NightLedger・BridgeHead・ArcBridgeはいずれも**これまで知られていなかった新しいマルウェア**です。新種のマルウェアはセキュリティソフトのデータベースに登録されていないため、**検知が遅れる**リスクがあります。

### 🤝 被害者が「加害者」に？
BridgeHeadによって、**自分のPCが他者への攻撃の踏み台にされる**可能性があります。これは、自分が被害者でありながら、調査上は「攻撃者」として記録されてしまうという二重の被害につながります。

## 対策・今後の展望

### 🛡️ 組織・企業ができる対策

1. **フィッシングメールへの警戒**
   - 求人情報や採用担当者を名乗るメールの添付ファイル・リンクは慎重に扱う
   - URLをよく確認する（本物そっくりのドメインに注意）

2. **エンドポイントセキュリティの強化**
   - DLLの読み込みを監視するEDR（エンドポイント検知・対応）ツールの導入
   - 不審なDLLファイルのサイドローディングを検知する設定

3. **ネットワーク監視の強化**
   - WebSocket通信の異常な挙動を検知する仕組みの整備
   - HTTPS通信の中身を検査するSSLインスペクションの導入

4. **ゼロトラストの考え方**
   - 「社内のシステムは安全」と思わず、すべての通信・アクセスを疑う設計にする

### 🔮 今後の展望

Nimbus Manticoreは**継続的にツールを進化させており**、今後も新たなマルウェアが登場する可能性が高いです。カスペルスキーをはじめとするセキュリティ研究者たちがこうした攻撃グループを継続的に追跡・分析することで、早期の対策が可能になります。

## 過去記事との関連

今回の記事では、関連グループとして「**Cavern Manticore（カバーン・マンティコア）**」という別のイラン系ハッカーグループにも言及されています。こちらのグループは「**HOLLOWGRAPH**」というマルウェアを使い、**Microsoft 365のカレンダー機能を悪用して**秘密の指令チャンネルを構築していることが別のセキュリティ会社「Group-IB」によって発覚しました。

同じ「Manticore（マンティコア）」という名前がつくグループが複数存在し、それぞれ異なる手法でサイバー攻撃を行っているのは、イランのサイバー作戦が**複数のチームに分かれて組織的に運用されている**ことを示唆しています。今後もこれらのグループへの注目が必要です。
