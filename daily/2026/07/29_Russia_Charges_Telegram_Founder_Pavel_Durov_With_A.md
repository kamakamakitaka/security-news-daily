# ロシア、テレグラム創設者パベル・ドゥロフを「テロ活動幇助」で起訴

**元記事**: [Russia Charges Telegram Founder Pavel Durov With Aiding Terrorist Activity](https://inl03.netline.com/ltr6/?_m=3n.009a.4042.sp0ao46r89.33jk)
**解説日**: 2025年7月10日

---

## 背景知識

このニュースを理解するために、いくつかの基礎知識を押さえておきましょう。

### 📱 Telegram（テレグラム）とは？
LINEやInstagramのDMのような**メッセージアプリ**です。特徴は「プライバシーの高さ」で、暗号化された通信や、管理者がいない匿名のグループチャット（チャンネル）を作れます。世界中に数億人のユーザーがいます。

### 👤 パベル・ドゥロフとは？
Telegramを作ったロシア出身の実業家（現在はUAE・ドバイ在住）。「デジタル世界の自由を守る」という強い信念を持ち、政府からの検閲要求に応じないことで知られています。

### 🏛️ FSB（ロシア連邦保安庁）とは？
ロシアの情報機関・治安機関で、かつてのKGB（旧ソ連の秘密警察）の後継組織です。いわば「ロシアのFBI＋CIA」のような存在です。

### 🌍 ロシア・ウクライナの対立
2022年2月以降、ロシアとウクライナは戦争状態にあります。今回の記事はこの紛争を背景にしたニュースです。

---

## 何が起きたのか

2025年、ロシアのFSBが**Telegram創設者のパベル・ドゥロフ**に対して、**「テロ活動を助けた」という罪で刑事告訴**を行い、国際手配リストにも登録しました。

FSBの主な主張は2点あります。

### 主張①：Telegramがロシアに不利なチャンネルを削除しなかった
> 「Telegramはウクライナやテロリストがロシアでのテロ・破壊工作・詐欺に使っているチャンネル・チャット・ボットを削除しなかった」

### 主張②：Telegramのチャットボットが若者をスパイ活動に誘い込む道具に使われた
> 「ウクライナの諜報機関が『Daivinchik（ダイビンチク）』というTelegramの出会い系ボットを使って、12歳〜22歳のロシア人46人を騙し、テロ・放火に加担させた」

## 技術的な詳細

### 🤖 チャットボットを使った「騙しの手口」を詳しく解説

今回最も注目すべきは、**SNSを使った「ハニートラップ＋脅迫」**のサイバー工作の手口です。

ステップに分けてみてみましょう👇

```
【STEP 1】接触
Telegramの出会い系ボット「Daivinchik」で
若い女性を装ったウクライナ工作員が
ロシア人の若い男性にアプローチ
         ↓
【STEP 2】信頼関係の構築
恋愛感情を演出しながら親しくなる
（これを「ロマンス詐欺」的アプローチと言います）
         ↓
【STEP 3】情報収集
「会いたい！どこかで会おう」と誘い、
ショッピングモールや重要施設の近くを
待ち合わせ場所として指定させ、
位置情報（ジオロケーション）を送らせる

さらに「映画のチケットや贈り物を買って」と
フィッシングリンク（偽サイト）に誘導し
クレジットカード情報や送金をさせる
         ↓
【STEP 4】脅迫
今度は別の人物（ロシアの警察官を装った工作員）が
外国のメッセージアプリで連絡してきて…

「あなたが送ったお金はウクライナ軍に渡った」
「あなたが教えた場所はミサイル攻撃に使われた」

と告げる
         ↓
【STEP 5】強要
「このままでは犯罪者として逮捕される。

```

### 🔑 ここで使われている技術・手法

| 手法 | 説明 |
|------|------|
| **フィッシングリンク** | 本物そっくりの偽サイトに誘導してお金や情報を盗むリンク |
| **ソーシャルエンジニアリング** | 技術ではなく「人の心理」を操って情報を盗む手法 |
| **ハニートラップ** | 恋愛感情を利用して相手を罠にはめる工作 |
| **なりすまし** | 警察官や政府機関を装って被害者を脅す |
| **暗号資産（仮想通貨）送金** | 追跡されにくい形で資金を移動させる |
| **ジオロケーション（位置情報）収集** | 相手の居場所・待ち合わせ場所を聞き出す |

## なぜ重要なのか

### 1️⃣ プラットフォームの「責任」が問われている
Telegramは「プライバシーを守るため、内容を検閲しない」という方針をとってきました。しかしロシアは「それが犯罪の温床になっている」として、**アプリの創設者を個人として刑事責任に問う**という強硬手段に出ました。

これは「SNSやアプリは、利用者がやった犯罪に責任を持つべきか？」という世界中で議論されている問題に関わります。

### 2️⃣ 国家レベルのSNS工作が明らかに
今回の手口は「フィッシング詐欺＋ロマンス詐欺＋脅迫」を組み合わせた**高度な情報工作**です。個人でも簡単に被害に遭いうるという点で、私たちにとっても無関係ではありません。

### 3️⃣ 12歳の子どもも被害に
被害者には**12歳から22歳の若者46人**が含まれていると言われています。若い人ほどオンラインの「なりすまし」に騙されやすく、深刻な問題です。

### 4️⃣ Telegramのロシアでの規制が強化中
- 2026年1月：速度制限（スロットリング）開始
- 2026年4月：ほぼ完全な接続遮断
  
ロシアはTelegramを事実上**使えない状態**にしていっています。

## 対策・今後の展望

### 🛡️ あなた自身を守るために

今回の事件から学べることは、国際情勢に関わらず「日常でも使える対策」ばかりです。

**✅ オンラインで知り合った人を簡単に信用しない**
- 会ったことのない相手から「お金を送って」「位置情報を教えて」と言われたら要注意です。

**✅ 不審なリンクはクリックしない**
- 「チケットを買うためのリンク」「プレゼントはこちら」などの不審なリンクはフィッシングの可能性があります。

**✅ 心理的に追い詰められたら立ち止まる**
- 「今すぐやらないと逮捕される！」などと急かされたら、一度冷静になりましょう。本物の警察は急にSNSで連絡してきません。

**✅ 信頼できる大人や機関に相談する**

### 🔮 今後の展望

- Telegramがロシアの要求に従うかどうかが注目されます
- ドゥロフはドバイに住んでおり、現時点では逮捕されていませんが、国際手配により行動が制限される可能性があります
- 他国でも「SNSプラットフォームの責任」をめぐる法整備が進む可能性があります

## 過去記事との関連

今回の記事では触れられていますが、**約2年前（2024年）にもドゥロフはフランスで逮捕・起訴されています**。そのときもTelegramが違法活動に使われたことへの対応不足が理由でした。

つまり、ドゥロフとTelegramはロシアとフランス（西側諸国）の**両方から**法的プレッシャーをかけられているという、非常に特殊な状況にあります。「プライバシーの自由」と「安全保障」のどちらを優先するか、という問題はここでも核心にあります。

## 用語解説

| 用語 | 意味 |
|------|------|
| **FSB（ロシア連邦保安庁）** | ロシアの情報・諜報機関。旧KGBの後継組織 |
| **テロ活動幇助** | テロ行為を助けること。今回はドゥロフ個人が容疑者 |
| **チャットボット** | 自動で会話するプログラム。人間のふりをすることもある |

| **ソーシャルエンジニアリング** | システムではなく「人の心理の隙」を突く攻撃・詐欺手法 |
| **ハニートラップ** | 恋愛や色仕掛けを利用した情報収集・工作活動 |
| **なりすまし（インポスター）** | 警察や政府機関など別の人物・組織を装うこと |
| **スロットリング** | 通信速度をわざと遅くする規制手段 |
| **国際手配** | 国際刑事警察機構（インターポール）などを通じた全世界への指名手配 |
| **Rosfinmonitoring** | ロシア連邦金融監視局（マネーロンダリングなどを監視する機関） |
