# Azure Cosmos DBの重大な欠陥：全顧客のデータベースにアクセスできる「マスターキー」が流出していた

**元記事**: [Azure Cosmos DB Flaw Exposed Platform-Wide Key That Could Access Any Database](https://inl03.netline.com/ltr6/?_m=3n.009a.4044.sp0ao46r89.33mu)
**解説日**: 2026年8月1日

---

## 背景知識

まず、このニュースを理解するために必要な基本知識をおさえましょう。

### ☁️ クラウドデータベースって何？
企業がWebサービスやアプリを作るとき、データ（ユーザー情報・購入履歴など）を保存する「データベース」が必要です。昔は自社のサーバーに置いていましたが、最近はマイクロソフトやAmazonなどが提供する「クラウドサービス」に預けるのが主流です。

**Azure（アジュール）** はマイクロソフトが提供するクラウドサービスで、世界中の企業が利用しています。

**Cosmos DB（コスモスDB）** はAzureが提供するデータベースサービスの一つ。企業が自分のデータをマイクロソフトのクラウド上に預けて使います。

### 🔑 「プライマリキー」って何？
Cosmos DBでは、データベースにアクセスするために「プライマリキー」という特別なパスワード（のようなもの）が発行されます。これを持っていると、そのデータベースの**すべてのデータを読み書きできます**。

### 🏠 マルチテナントとは？
「テナント（tenant）」は英語で「借り主」という意味。クラウドでは、1つの大きなシステムの中に、たくさんの会社（借り主）のデータが別々に保管されています。本来は**互いに見えないように壁で仕切られている**はずです。

### 🔍 Gremlin（グレムリン）とは？
データベースに問い合わせをするための「クエリ言語（データベースへの指令文）」の一種です。Cosmos DBはGremlinという方式にも対応しています。

---

## 何が起きたのか

セキュリティ研究会社の **Wiz（ウィズ）** が、Azure Cosmos DBに**重大な脆弱性（セキュリティの穴）** を発見しました。この脆弱性を使うと、攻撃者は**他の会社のデータベースに自由にアクセスできる**状態でした。

### 📋 事件の流れ

```
【攻撃者がやること】
  ↓
① 普通のAzureアカウントを作成（数分でできる・特別な権限不要）
  ↓
② 自分用のGremlin（グレムリン）データベースを作る
  ↓
③ 特別に細工した「クエリ（指令文）」を送る
  ↓
④ システムの内部に侵入 → 「Cosmos マスターキー」を入手！
  ↓
⑤ そのキーを使って世界中の任意の会社のデータベースを操作
```

**Wiz社は2025年11月にマイクロソフトにこの問題を報告。** マイクロソフトは48時間以内に応急処置を行い、2026年7月までに完全な修正を完了させました。

## 技術的な詳細

少し難しいですが、できるだけわかりやすく説明します！

### 🧱 サンドボックスとは？
「サンドボックス」とは、砂場のように**「ここだけで遊んでね」という隔離された安全なエリア**のことです。危険なプログラムが他の部分に影響を与えないよう、限られた空間の中で動かす仕組みです。

### 🚪 どうやってサンドボックスを脱出したの？

Cosmos DBのGremlinエンジンは、ユーザーが送ったGremlinクエリを**「.NET（ドットネット）コード」というプログラムに変換**してから、サンドボックスの中で動かす仕組みでした。

ここに問題がありました。

> 🎯 **.NETの「リフレクション（reflection）」という機能への対策が不十分だった**

**リフレクション**とは、プログラムが「自分自身の構造を調べたり操作したりする」技術のこと。例えるなら…

> 🏠「この部屋だけ使ってね」と言われた人が、**壁の素材や構造を調べる特殊な道具を使って、隠し扉を見つけて別の部屋に入り込んだ**イメージです。

これにより、研究者たちはサンドボックスを突破し、**ファイルの読み書き**ができるようになり、最終的に**自由にコードを実行**できる状態になりました。

### 🗝️ 「Cosmos マスターキー」の発見

コードが動かせるようになった場所は「**DBゲートウェイ**」と呼ばれるコンポーネント（部品）でした。このゲートウェイは：

- すべての顧客のクエリを処理する
- **Cosmos マスターキー**（全データベース共通の署名用鍵）を保持していた

このマスターキーは、**Cosmos DBのすべてのAPI（SQL・MongoDB・Cassandra・Gremlin）** と**すべての地域（リージョン）** で有効でした。つまり…

> 🔓 **世界中のすべてのCosmos DB顧客のデータベースを開けられる、万能鍵だった！**

### 📂 「Config Store（設定ストア）」にもアクセス可能

さらに、このキーで「Config Store」という内部データベースにもアクセスできました。ここには：

- どの会社がどんなデータベースを持っているか
- ネットワーク設定
- サブスクリプション・テナント情報

…などが記録されており、**攻撃したい特定の企業を狙い打ちにすることも可能**でした。Wiz社の調査では、ある1つのリージョン（地域）だけで**マイクロソフト社内のデータベースが数千件**含まれていたことも確認されました。

## なぜ重要なのか

### 💥 影響の大きさ

| 項目 | 内容 |
|------|------|
| 必要なもの | 普通のAzureアカウントのみ（無料で作成可能） |
| 特別な権限 | 不要 |
| 内部の協力者 | 不要 |
| 攻撃の難易度 | 低い（自分のデータベースから実行） |
| 影響範囲 | **全Cosmos DB顧客** |

### 🌍 クラウドサービスの怖いところ

これは「**テナント分離の失敗**」と呼ばれる非常に深刻な問題です。

普通のソフトウェアの脆弱性なら、自分のPC・自分のサーバーが危険なだけです。しかし**クラウドサービスの脆弱性**は、1つの穴から**そのサービスを使っている全員**が影響を受ける可能性があります。

> 📦 例えるなら、マンションの管理会社が「マスターキー」を盗まれたようなもの。**全室の鍵が同時に危険**になる状況です。

### 🛡️ 幸いだったこと

- Wiz社は**悪意のある攻撃者ではなく、セキュリティ研究者**だった
- **協調的な脆弱性開示（Coordinated Vulnerability Disclosure）** というルールに則り、マイクロソフトに先に報告した
- マイクロソフトの調査では、研究者のテスト以外に**不正アクセスの証拠は見つからなかった**

## 対策・今後の展望

### ✅ マイクロソフトが取った対策

1. **48時間以内**：Gremlinの脆弱な入口をブロック（応急処置）
2. **2026年7月**：全リージョンで完全な修正を完了
3. **プラットフォーム全体共通のキー（マスターキー）を廃止**

### 👤 一般ユーザー・企業への影響

マイクロソフトは「**顧客側での対応は不要**」と発表しています。すでにマイクロソフト側で修正済みです。

### 🔬 今後の発表

Wiz社は、**2026年8月6日のBlack Hat USA（ブラックハットUSA）** というセキュリティの大きな国際会議で、攻撃の完全な手順を発表する予定です。

> 💡 **Black Hat USA** は毎年アメリカで開催される世界最大級のセキュリティカンファレンス（会議）。新しい攻撃手法や脆弱性の研究発表が行われます。

## 用語解説

| 用語 | 解説 |
|------|------|
| **Azure（アジュール）** | マイクロソフトが提供するクラウドサービス全般の名前 |
| **Cosmos DB** | AzureのNoSQL系クラウドデータベースサービス |
| **Gremlin（グレムリン）** | グラフ型データベースへの問い合わせ言語 |
| **脆弱性（ぜいじゃくせい）** | システムのセキュリティ上の弱点・穴 |
| **サンドボックス** | 安全のために隔離されたプログラム実行環境 |
| **リフレクション（reflection）** | プログラムが自分自身の構造を調べ・操作する技術 |
| **プライマリキー** | データベースへの完全なアクセス権を持つ認証情報 |
| **マルチテナント** | 複数の利用者・企業が1つのシステムを共有する仕組み |
| **テナント分離** | 共有システム上で各利用者のデータを互いに見えなくする仕組み |
| **任意コード実行（RCE）** | 攻撃者が対象のコンピュータで自由にプログラムを動かせる状態 |
| **協調的脆弱性開示** | 発見した脆弱性を公表前にメーカーに報告して修正を待つルール |
| **Black Hat USA** | 毎年アメリカで開催される世界最大級のセキュリティ研究発表会 |
| **Config Store** | Cosmos DBの顧客情報・設定情報が入った内部データベース |
| **.NET（ドットネット）** | マイクロソフトが開発したプログラム実行環境・フレームワーク |
| **API（エーピーアイ）** | システム同士が通信するための窓口・インターフェース |
