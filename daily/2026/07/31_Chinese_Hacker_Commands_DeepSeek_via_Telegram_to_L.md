# 中国人ハッカーがAI「DeepSeek」をTelegram経由で操り、自動攻撃を仕掛けた

**元記事**: [Chinese Hacker Commands DeepSeek via Telegram to Launch Autonomous Attacks](https://inl03.netline.com/ltr6/?_m=3n.009a.4044.sp0ao46r89.33mc)
**解説日**: 2025年7月

---

## 背景知識

まず、この記事を読む上で必要な前提知識をおさえておきましょう。

### 🤖 DeepSeekとは？
中国企業が開発した**AI（人工知能）**です。ChatGPTのような「質問に答えてくれるAI」ですが、今回はそれが「攻撃ツール」として使われました。

### 📱 Telegramとは？
メッセージアプリの一種です（LINEのようなもの）。セキュリティが高いとされるため、悪意のある人物が連絡手段として使うことがあります。

### 🛡️ Palo Alto Networks / Unit 42とは？
「Palo Alto Networks」はアメリカの大手セキュリティ企業です。その調査部門「**Unit 42**」は、世界中のサイバー攻撃を調査・分析しています。今回の発見もUnit 42によるものです。

### 🤖 「AIエージェント」って何？
AIが**人間のような判断をしながら、自動で作業を進める仕組み**です。「次に何をすべきか」を自分で考え、実行できます。プログラムを動かしたり、インターネットを検索したりすることもできます。

### 🧰 Hermes Agentとは？
オープンソース（誰でも使える無料のプログラム）で公開されている**AIエージェントのフレームワーク（土台となる仕組み）**です。TelegramでAIに指示を出し、パソコンのコマンドを自動実行させることができます。

## 何が起きたのか

### 📋 事件の概要

中国語を使うハッカー（ネット上では「**knai**」「**KnYuan**」という名前を使っていた）が、以下のような手口でサイバー攻撃を仕掛けました。

```
① Telegramでたった一回、AIに「攻撃開始」と指示を出す
         ↓
② DeepSeek（AI）が自動で攻撃対象を探す
         ↓
③ 脆弱性（セキュリティの穴）を調べ、攻撃方法を選ぶ
         ↓
④ 自動で攻撃を実行する
```

ポイントは、**最初の一言だけで、あとはAIが全部自動でやってしまった**という点です。ハッカーはその後、ほぼ何も操作していません。

### 🎯 攻撃のスケール
- 攻撃対象：**460以上のシステム**
- 実際に侵入に成功したと確認できた件数：**3件**

## 技術的な詳細

### 🔍 AIがやったこと（攻撃の流れ）

**Step 1: ターゲット探し**
AIは「**FOFA**」というインターネット上の検索エンジン（セキュリティ調査用のツール）を使って、攻撃できそうなシステムを自動で検索しました。

**Step 2: 攻撃方法の選択**
AIは「CVE」と呼ばれる**脆弱性の情報データベース**をもとに、どの穴を狙うか自動で判断しました。CVEとは「コンピューターのプログラムに見つかった欠陥・バグ」に番号をつけて管理する仕組みです（例：CVE-2026-33017）。

> 💡 **たとえ話**：泥棒が街を歩き回って「この家は鍵が古いぞ」「あの家は窓が開いているぞ」と調べて、一番入りやすい家を自動で選ぶようなイメージです。

**Step 3: 攻撃の実行と判断**
AIは攻撃を試みて、うまくいかなければ**別の方法に切り替える**という判断も自動でしました。人間が介在せず、試行錯誤を繰り返したのです。

---

### 🎯 主な攻撃ターゲット（3種類）

| ソフトウェア | 何をするもの | 狙われた脆弱性 |
|---|---|---|
| **Langflow** | AIを使ったワークフロー（作業の流れ）を作るツール | CVE-2026-33017（コード注入） |
| **n8n** | 業務の自動化ツール | CVE-2026-21858、CVE-2025-68613の組み合わせ |
| **Marimo** | Pythonのノートブックツール | CVE-2026-39987（コマンド実行） |
| **NetScaler** | ネットワーク機器（Citrix製） | CVE-2026-3055（メモリ読み取り） |

> 💡 **コード注入（インジェクション）とは**：本来受け付けてはいけない「命令文」をシステムに送り込み、不正な動作をさせる攻撃手法です。

### 😅 ハッカー自身のミス！

実は、このハッカーが使っていたツールが**自分のデータを丸ごと外部に公開してしまう**という大きなミスをしていました。

```
Hermes Agentが「python3 -m http.server 8888」というコマンドを
誤って実行してしまった
        ↓
ハッカーのパソコンの中身がインターネットから丸見えに！
```

外部から見えてしまった情報：
- 🔑 APIキー（AIサービスを使うための鍵）
- 📋 攻撃対象のリスト
- 📝 攻撃スクリプト（プログラム）
- 📜 コマンドの操作履歴
- 🗒️ AIとのやり取りのログ

**このミスがあったおかげで、Unit 42が攻撃の全容を把握できた**というのが、なんとも皮肉な話です。

## なぜ重要なのか

### ⚡ 「AIによる自動攻撃」時代の幕開けかもしれない

今までのサイバー攻撃は、ハッカーが**手動で一つひとつ操作**することが多かったです。しかし今回は：

- ✅ **人間の操作なし**で攻撃が自動進行
- ✅ **失敗しても自分で別の方法を選択**
- ✅ **460以上のシステムを自動でスキャン**

これは「AIを武器にした攻撃の自動化」が現実になったことを示しています。

### 🌍 影響の広がり
- n8n（攻撃対象の一つ）は中国だけで**25,000件以上**のシステムが使われていた
- 一度の指示で数百のシステムへの攻撃が可能になった

### ⚠️ 注意点
ただし、今回の攻撃は**成功率が低かった**という点も重要です。  
460以上を狙って確実に侵入できたのは**わずか3件**。LangflowやN8nへの攻撃は設定の違いで失敗しました。「AIは万能ではない」ということも、今回示されています。

## 対策・今後の展望

### 🛠️ 今すぐできる対策

**1. 該当ソフトウェアを最新版に更新する**

| ソフトウェア | 安全なバージョン |
|---|---|
| Langflow | **1.9.0以降** |
| n8n | **1.121.1以降**（両方の脆弱性に対応） |
| Marimo | **0.23.0以降** |
| NetScaler ADC/Gateway | Citrixの指示に従ってパッチを適用 |

**2. 不要な公開アクセスを閉じる**
- ワークフローツール（n8n、Langflowなど）のインターフェース（操作画面）をインターネットから直接アクセスできないようにする

**3. 認証を必須にする**
- ログインなしで使えるフォームや機能を無効化する

### 🔮 今後の展望

今回の事例は「AIエージェントが攻撃ツールになる未来」のほんの始まりかもしれません。セキュリティ企業も、AIを使った**防御の自動化**を進めており、「AI対AI」の攻防が激しくなる可能性があります。

## 用語解説

| 用語 | 説明 |
|---|---|
| **DeepSeek** | 中国製のAI（大規模言語モデル）。ChatGPTに似た性質を持つ |
| **AIエージェント** | 人間の指示なしに自律的に判断・行動するAIの仕組み |
| **Hermes Agent** | AIエージェントを動かすためのオープンソースフレームワーク（土台） |
| **CVE（シーブイイー）** | コンピューターの脆弱性（欠陥）に付けられる識別番号 |
| **脆弱性（ぜいじゃくせい）** | ソフトウェアやシステムのセキュリティ上の欠陥・弱点 |
| **エクスプロイト** | 脆弱性を突いて攻撃するためのプログラムや手法 |
| **FOFA** | インターネット上のシステムを検索できるセキュリティ調査ツール |
| **APIキー** | AIやWebサービスを使うための「合言葉」のようなもの |
| **コード注入（インジェクション）** | システムに不正な命令を送り込む攻撃手法 |
| **データ流出（エクスフィルトレーション）** | 組織の内部データが外部に盗み出されること |
| **パッチ** | ソフトウェアの欠陥を修正するためのアップデート |
| **オープンソース** | プログラムのコードが公開されていて、誰でも使えるもの |
| **SAML** | ログイン情報を安全にやり取りするための仕組み |
| **Unit 42** | Palo Alto Networksのサイバー脅威調査チーム |
