# サービスとしての詐欺の台頭：闇のビジネスモデルを解剖する

**元記事**: [The Rise of Fraud-as-a-Service: Deconstructing the Underground Stack](https://inl03.netline.com/ltr6/?_m=3n.009a.4044.sp0ao46r89.33m6)

## 背景知識

まず、このニュースを理解するために必要な「前提知識」をおさえましょう。

### 🏪「〇〇 as a Service（サービスとしての〇〇）」とは？

みなさんはNetflixやSpotifyを使ったことがありますか？ソフトウェアを「買う」のではなく、月額料金を払って「使う」サービスですよね。ITの世界ではこれを**「SaaS（Software as a Service）」**と呼びます。

実は、サイバー犯罪の世界でも同じことが起きています。

| 正規のビジネス | 犯罪版 |
|---|---|
| Netflix（動画配信サービス） | Phishing-as-a-Service（フィッシング詐欺サービス） |
| AWS（クラウドサーバー） | Bulletproof Hosting（摘発されにくい違法サーバー） |
| Shopify（EC構築ツール） | Fraud-as-a-Service（詐欺構築ツール） |

つまり、**「詐欺をやりたい人」が、技術的な知識がなくても、お金さえ払えばすぐに詐欺を始められるサービス**が存在する、ということです。

### 🌑 ダークウェブとアンダーグラウンドとは？

普通のインターネット（Google検索で出てくる場所）を「サーフェスウェブ」と言います。それに対して、特殊なソフトウェアを使わないとアクセスできない、匿名性の高いネットワーク空間を**「ダークウェブ」**と呼びます。ここは、犯罪者たちが売買や情報交換を行う「闇の市場」になっていることがあります。

## 何が起きたのか

> ⚠️ 今回の記事は本文を直接取得できなかったため、タイトルと業界動向をもとに解説します。

**「Fraud-as-a-Service（FraaS：詐欺のサービス化）」** というビジネスモデルが、サイバー犯罪の世界でどんどん巨大化・組織化されています。

かつてのサイバー犯罪は、

```
犯罪者個人 → 自分でツールを作る → 自分で攻撃する → 自分でお金を奪う
```

という「一人でなんでもやる」スタイルでした。

しかし今は、

```
【ツール開発者】→ 詐欺キットを販売
      ↓
【インフラ業者】→ 摘発されにくいサーバーを貸し出し
      ↓
【詐欺実行者】→ 知識ゼロでも詐欺メールを大量送信
      ↓
【マネーロンダリング業者】→ 盗んだお金を洗浄して現金化
```

という**完全分業制の「詐欺産業」**が成立しています。まるで、普通の会社のように役割が分かれているのです。

## 技術的な詳細

### 🧱 「アンダーグラウンドスタック」の構造

「スタック（Stack）」とは、複数の技術やサービスが積み重なって動いている構造のことです。詐欺の世界にも、このような「層」があります。

```
┌─────────────────────────────────┐
│  【Layer 5】 マネタイズ層         │
│  盗んだ情報をお金に換える         │
│  例：暗号資産での送金、ギフトカード│
├─────────────────────────────────┤
│  【Layer 4】 実行層              │
│  フィッシングメール・SMS送信       │
│  偽サイトへの誘導                │
├─────────────────────────────────┤
│  【Layer 3】 ツール層            │
│  フィッシングキット（詐欺サイト   │
│  の「テンプレート」）             │
├─────────────────────────────────┤
│  【Layer 2】 インフラ層          │
│  ブレットプルーフホスティング     │
│  （摘発されにくい違法サーバー）   │
├─────────────────────────────────┤
│  【Layer 1】 データ層            │
│  流出した個人情報・パスワードの   │
│  売買（コンボリスト）            │
└─────────────────────────────────┘
```

### 💡 各レイヤーをわかりやすく説明

#### Layer 1：データ層（材料の仕入れ）
過去に流出したメールアドレスとパスワードのセットを「**コンボリスト**」と呼びます。これはダークウェブで数百円〜数千円で購入できます。
> 例え話：料理で言えば「食材の仕入れ」

#### Layer 2：インフラ層（店舗の準備）
「**ブレットプルーフホスティング**」とは、法執行機関からの削除要請を無視するサーバー貸しサービスです。ロシアや東ヨーロッパなど、捜査が届きにくい国に設置されていることが多いです。
> 例え話：警察が立ち入れない「闇の倉庫」を借りること

#### Layer 3：ツール層（調理器具）
「**フィッシングキット**」とは、銀行やAmazonなどの偽サイトを簡単に作れるテンプレートセットです。HTMLやCSS（ウェブページを作る技術）の知識がなくても、数クリックで本物そっくりの偽サイトが完成します。
> 例え話：料理キット（ミールキット）のような「詐欺サイト作成キット」

#### Layer 4：実行層（集客）
大量のSMSや電子メールを自動送信するシステムです。「あなたのアカウントに不正アクセスがありました」「荷物が届いています」などのメッセージを何百万通も一気に送ります。

#### Layer 5：マネタイズ層（売上の回収）
盗んだクレジットカード情報や個人情報を現金化する工程です。暗号資産（ビットコインなど）への変換や、ギフトカードの購入などが使われます。

## なぜ重要なのか

### 📈 3つの深刻な理由

#### ① 参入障壁がゼロに近い
以前は「高度な技術力を持つ人間しかサイバー犯罪はできない」とされていました。しかし今は、**プログラミングの知識ゼロでも、月数千円払えば詐欺師になれる**時代です。

これは「包丁の使い方を知らなくても、料理済みの毒入り食品を買って人に渡せる」ようなものです。

#### ② 犯罪の検挙が難しくなった
分業化が進んだことで、一部の犯罪者を逮捕しても**他の部分は動き続けます**。一人の「胴元」を捕まえれば解決した昔と違い、今は芋づる式に追いかけるのが非常に困難です。

#### ③ 被害規模が爆発的に拡大
自動化・量産化により、**1日に数百万人に詐欺メールが届く**ことも珍しくなくなりました。たとえ成功率が0.1%でも、100万通送れば1,000人が被害を受けます。

## 対策・今後の展望

### 🛡️ 私たちができる対策

#### ✅ 個人レベルの対策

| 対策 | 理由 |
|---|---|
| **多要素認証（MFA）を必ず設定する** | パスワードが漏れても、スマホに届くコードがないとログインできない |
| **パスワードを使い回さない** | コンボリストによる「リスト型攻撃」を防ぐ |
| **SMSやメールのリンクを安易にクリックしない** | フィッシングサイトへの誘導を防ぐ |
| **公式アプリ・公式サイトを直接開く習慣をつける** | 偽サイトに飛ばされるリスクを減らす |

#### 🔍 多要素認証（MFA）とは？
ログイン時に「パスワード」だけでなく、「スマホに届くコード」や「指紋」なども必要にする仕組みです。鍵が2重・3重になっているイメージです。

### 🌐 社会・企業レベルの対策

- **AI（人工知能）を使った詐欺メール検出**：不審なパターンを自動でブロック
- **国際的な法執行機関の連携**：Interpol（国際刑事警察機構）などによる国境を越えた捜査
- **ドメイン（Webサイトのアドレス）の監視**：偽サイトを素早く発見・削除

## 用語解説

| 用語 | 意味 |
|---|---|
| **Fraud-as-a-Service（FraaS）** | 詐欺をサービスとして提供するビジネスモデル。お金を払えば詐欺の「道具一式」が手に入る |
| **ダークウェブ** | 通常の検索エンジンではアクセスできない、匿名性の高いインターネット空間 |
| **フィッシング** | 本物そっくりの偽サイトや偽メールで、パスワードや個人情報をだまし取る詐欺 |
| **フィッシングキット** | 偽サイトを簡単に作れるテンプレートセット。プログラミング不要 |
| **コンボリスト** | 流出したメールアドレスとパスワードのリスト |
| **ブレットプルーフホスティング** | 法的な削除要請を無視する、摘発されにくい違法なサーバー貸しサービス |
| **多要素認証（MFA）** | パスワード以外にも、スマホのコードや指紋などでログインを確認する仕組み |
| **マネーロンダリング** | 犯罪で得たお金を、出所がわからないように「洗浄」して合法的なお金に見せかけること |
| **リスト型攻撃** | 流出したIDとパスワードのリストを使い、様々なサービスへのログインを試みる攻撃 |
| **アンダーグラウンドスタック** | 犯罪のために積み重なった複数のサービス・技術の層構造 |

---

> 💬 **まとめ**：サイバー犯罪はもはや「天才ハッカーの仕業」ではなく、**誰でも参加できる分業制の産業**になっています。だからこそ、私たち一人ひとりが「パスワードの使い回しをしない」「多要素認証を設定する」といった基本的な対策を徹底することが、以前にも増して重要になっています。
