### 🖥️ 「信頼できる画面」という錯覚
記事の冒頭にこんな一文があります。

> 「セキュリティの問題の多くは、間違った画面を信頼してしまうことから始まる」

これはとても重要な考え方です。ログインページ、インストール手順、採用担当者からの電話……どれも「本物っぽく見える偽物」である可能性があります。私たちは毎日、画面に表示されるものを無意識に信頼しています。ハッカーはその心理を巧みに利用するのです。

## 何が起きたのか

今週は非常に多くのサイバーセキュリティ事件が報告されました。記事に登場する主な出来事を、わかりやすくまとめます。

---

### 🦠 ① ロシアを狙ったフィッシング攻撃（XWorm）

**「xplogs22」というサイバー犯罪グループ**が、ロシアやCIS諸国（旧ソ連の国々）を狙っています。

#### 何をしているの？
- **フィッシングメール**（偽のメール）を送りつけて、「**XWorm**」というウイルスをインストールさせようとしています
- このグループは2023年11月から活動しており、以前は「Formbook」「Snake Keylogger」という別のウイルスを使っていましたが、2025年7月頃からXWormに乗り換えました

#### さらに怖い「LunaSpy」も登場
ロシアの銀行ユーザーを狙った**Androidトロイの木馬（スマホウイルス）**「**LunaSpy**」も発見されました。

> 💡 **トロイの木馬**とは、ギリシャ神話の「トロイの木馬」から来た言葉で、無害なふりをしてシステムに侵入する悪意のあるソフトウェアのことです。

LunaSpyは**「ウイルス対策アプリ」に偽装**しているのが厄介なポイントです。インストールすると、こんなことができてしまいます：

- 📷 カメラの映像を盗み見る
- 🎤 音声を録音する
- 📱 画面を録画する
- 💾 個人情報を盗み取る

まるでスマホに小さなスパイが住み着くようなイメージです。

---

### 💰 ② ロシア企業を狙ったカスタムランサムウェア（GenieLocker）

**「Toy Ghouls」（別名：Bearlyfy、Labubu）**というグループが、2026年3月から活動しています。

#### 標的は？
- ロシアの製造業、金融、小売、テクノロジー系企業

#### 何が新しいの？
以前は「RedAlert」「LockBit」「Babuk」という他人が作ったランサムウェアを使い回していたのですが、今回は**自分たちだけの「GenieLocker」というオリジナルのランサムウェアを開発**しました。

> 🏠 例え話：これまでは「市販の合カギ」を使って家に侵入していたのが、「自分だけのオーダーメイドの合カギ」を作るようになったイメージです。より検知されにくくなります。

#### 攻撃の手順（ちょっと詳しく）

```
① 外部パートナーのVPN（安全な通信路）を経由して侵入
　　↓
② ネットワーク内を偵察（どこに何があるか調査）
　　↓
③ パスワードを盗むツールをインストール
　　↓
④ RDP・SSHでWindowsサーバーやLinuxサーバーに横展開
　　↓
⑤ ファイルをすべて暗号化 → 身代金要求！
```

特に注目すべきは「**信頼された外部パートナーのネットワーク**」を入口に使っているという点。取引先や協力会社が踏み台にされることもある、という怖い現実です。

---

### 🔐 ③ 仮想通貨を狙う「CastleLoader」の進化

**CastleLoader**という「マルウェアの運び屋（ローダー）」が、新しい機能を追加して活動中です。

#### 新しい武器は？
- **Rust製のウォレットスプーファー**：仮想通貨の財布アプリを偽物にすり替えて、送金先を攻撃者のアドレスに変えてしまう
- **Golang製の悪意ある拡張機能インストーラー**：ブラウザに悪い拡張機能をこっそり入れる

> 💡 **ClickFix（クリックフィックス）とは？**
> 「クリックして修正してください」という偽のメッセージで、ユーザー自身に悪意のあるコマンドを実行させる手口です。「自分でドアを開けさせる」という巧妙な詐欺です。

---

### ⌨️ ④ ClickFix攻撃の新しい手口（ファイルレス実行）

ClickFix攻撃がさらに巧妙になっています。

#### 何が新しいの？

従来：悪いファイルをダウンロードさせる → セキュリティソフトに検知される

今回：**ファイルをディスクに保存しないまま実行（ファイルレス実行）**

具体的には：
1. 被害者を騙して、**Windowsの「ファイル名を指定して実行」にコマンドを貼り付けさせる**
2. そのコマンドが**WebDAV**（インターネット上のファイル共有サービス）に接続
3. **rundll32.exe**（Windowsの正規ツール）を悪用して、ファイルを保存せずにウイルスを実行

> 🕵️ **なぜこれが危険？**
> セキュリティソフトは「怪しいファイル」を検知しますが、ファイルが存在しないと検知が非常に難しくなります。まるで、犯人が証拠を残さずに犯行に及ぶようなイメージです。

## 技術的な詳細

今回の記事で登場した攻撃手法を、もう少し深く見てみましょう。

### 🌐 WebDAVとファイルレス攻撃の仕組み

```
[攻撃者のサーバー（WebDAV）]
        ↑ 通信
[被害者のPC]
  └─ rundll32.exe（正規のWindowsツール）
       └─ 悪意のあるコードをメモリ上で直接実行
          ※ディスクにファイルは残らない！
```

| 従来の攻撃 | 新しいファイルレス攻撃 |
|-----------|----------------------|
| 悪いファイルをダウンロード | ファイルを保存しない |
| セキュリティソフトが検知しやすい | 検知が非常に難しい |
| 証拠が残る | 証拠が残りにくい |

### 🔄 ランサムウェアの「カスタム化」トレンド

GenieLockerのように、最近は攻撃グループが**自前のランサムウェアを開発する**傾向が強まっています。

理由は：
- 市販のランサムウェアは各国のセキュリティ機関に把握されている
- カスタム版は検知されにくい
- 逮捕リスクが下がる（使い回しツールは追跡されやすい）

## なぜ重要なのか

### 🌍 影響範囲

今週の一連の事件で見えてきた重要なポイントをまとめます：

1. **「信頼」を悪用する攻撃が増えている**
   - 取引先・パートナー企業の接続を踏み台にする
   - 公式ツール（rundll32.exeなど）を悪用する
   - ウイルス対策アプリに偽装する

2. **仮想通貨ユーザーが特に危険**
   - ウォレットを偽物にすり替えるツールが登場
   - ブラウザ拡張機能経由の攻撃が増加

3. **攻撃グループが「プロ化」している**
   - 自前のツールを開発するほど組織的になっている
   - Windows/Linux/ESXiなど複数のOSに対応した攻撃

4. **スマホも安全ではない**
   - AndroidのLunaSpyは「ウイルス対策アプリ」に偽装
   - カメラ・マイク・画面すべてを盗まれる可能性

## 対策・今後の展望

### 🛡️ 私たちにできること

#### 個人ユーザー向け

| やること | 理由 |
|----------|------|
| アプリは公式ストアからのみインストール | LunaSpyのような偽アプリを避けるため |
| 不審なメールのリンク・添付ファイルを開かない | フィッシング攻撃への対策 |
| パスワードを使い回さない | クレデンシャル攻撃への対策 |
| 二段階認証を設定する | アカウント乗っ取りを防ぐ |
| ブラウザ拡張機能は信頼できるものだけ | CastleLoader系の攻撃を防ぐ |

#### 企業・組織向け

- **取引先・外部パートナーの接続権限を最小限に**（GenieLocker対策）
- **「ゼロトラスト」の考え方を導入**：社内ネットワークでも無条件に信頼しない
- **EDR（高度なウイルス検知ツール）の導入**：ファイルレス攻撃を検知するため
- **社員へのセキュリティ教育**：ClickFix攻撃はユーザーを騙すため

#### 今すぐチェック！
> ⚠️ **Windowsユーザーへの注意**
> 「ファイル名を指定して実行」ダイアログにコマンドを貼り付けるよう指示するサイトや広告は、絶対に信頼しないでください。これはClickFix攻撃の典型的な手口です！

### 🔮 今後の動向

- ClickFix攻撃は今後もさらに進化していくと予想されます
- 仮想通貨ユーザーを狙った攻撃は増加傾向
- ランサムウェアグループの「自前ツール開発」は今後も続く見込み

## 用語解説

| 用語 | 解説 |
|------|------|
| **XWorm** | ロシア・CIS諸国を標的にしたマルウェア。フィッシングメールで配布される |
| **LunaSpy** | Androidスマホを狙うスパイウェア。ウイルス対策アプリに偽装する |
| **ランサムウェア** | ファイルを暗号化して身代金を要求する悪意のあるソフトウェア |
| **GenieLocker** | Toy Ghoulsグループが独自開発したランサムウェア |
| **CastleLoader** | 他のマルウェアを読み込む「運び屋」プログラム |
| **ClickFix** | 「修正のためクリックしてください」と偽り、ユーザー自身に悪意のあるコマンドを実行させる手口 |
| **WebDAV** | インターネット経由でファイルを共有・管理するしくみ。今回は攻撃に悪用された |
| **rundll32.exe** | Windowsに標準搭載された正規のツール。今回はこれを悪用してウイルスが実行された |
| **ファイルレス攻撃** | ファイルをディスクに保存せず、メモリ上だけで実行する攻撃。検知が難しい |
| **ESXi** | VMwareの仮想マシン管理ソフト。企業のサーバー環境でよく使われる |
| **RDP** | Remote Desktop Protocol。離れた場所からパソコンを操作するしくみ |
| **SSH** | Secure Shell。サーバーにリモート接続するための安全な通信方式 |
| **CIS諸国** | 旧ソビエト連邦を構成していた国々（ロシア・ウクライナなど）の連合体 |
| **クレデンシャル** | ユーザーIDとパスワードのセット。これが盗まれると不正ログインされる |
| **ゼロトラスト** | 「何も信頼しない」を前提にしたセキュリティの考え方 |
