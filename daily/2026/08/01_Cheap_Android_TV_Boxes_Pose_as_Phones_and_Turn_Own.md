# 安いAndroid TVボックスがスマホのふりをして、あなたの自宅ネットワークを「踏み台」にする

**元記事**: [Cheap Android TV Boxes Pose as Phones and Turn Owners' Broadband Into Proxies](https://inl03.netline.com/ltr6/?_m=3n.009a.4045.sp0ao46r89.33nw)
**解説日**: 2025年7月

---

## 背景知識

このニュースを理解するために、いくつかの基本的な概念を先に説明しておきましょう。

### 📺 Android TVボックスとは？
テレビに接続するだけで、YouTubeやNetflixなどが見られるようになる小型の機械です。スマートTVを持っていない人でも、数千円〜1万円程度の安価な機器を買うことで動画配信サービスが楽しめます。特にAmazonやAliExpressなどで売られている中国製の格安品が多く流通しています。

### 🖥️ プロキシ（Proxy）とは？
インターネット通信の「中継地点」のことです。たとえば、「Aさん → プロキシ → 目的のウェブサイト」という経路を通ると、ウェブサイト側にはAさんではなくプロキシのIPアドレスが見えます。犯罪者がプロキシを使うと、自分の本当の場所を隠しながらネットを使えるため、悪用されることがあります。

### 💰 広告詐欺（アド・フロード）とは？
ウェブサイトに表示される広告は、「クリックされた回数」に応じてお金が発生します（クリック課金）。これを悪用して、**ロボット（プログラム）に広告を自動でクリックさせ**、不正に広告収入を稼ぐ行為が「広告詐欺」です。実際には誰も商品を見ていないのに、広告主のお金だけが奪われていきます。

### 🤖 SOCKS5プロキシとは？
インターネット通信を中継するための技術のひとつです。犯罪者はこれを使って「自分のパソコンから直接ではなく、他人の家のネット回線を経由して」不正アクセスなどを行います。まるで「他人の家の住所を借りて悪事を働く」ようなイメージです。

---

## 何が起きたのか

セキュリティ企業「**Bitsight**」の研究者たちが、格安のAndroid TVボックスに**悪意のあるアプリ**が最初から仕込まれていたことを発見しました。

この不正操作は「**Fuyao（扶揺）作戦**」と名付けられ、2019年に設立された中国・浙江省の企業「**浙江豊沃IoTテクノロジー（Zhejiang Fengwo IoT Technology）**」が関与していると特定されました。

具体的に何が起きていたかというと、大きく**2つの不正行為**が確認されています：

1. **スマホのふりをして広告を不正クリック**  
   TVボックスなのに、SamsungやHuaweiのスマートフォンに成りすまし、広告を自動でクリックして不正に収益を得ていた。

2. **所有者のインターネット回線を「出口」として悪用**  
   TVがテレビ映像を表示していないとき（HDMIケーブルからの信号がないとき）、他人のネット通信を自宅の回線経由で中継する「踏み台」にされていた。

被害を受けたユーザーは、**自分の知らないうちに犯罪の片棒を担がされていた**可能性があります。

## 技術的な詳細

### 🎭 「なりすまし」の仕組み

TVボックスの内部には「**Rockchip・Amlogic・Allwinner**」といった、いわゆる格安TVボックスによく使われるチップが入っています。しかし悪意のあるアプリは、これらのチップ情報を**上書き・隠蔽**して、Samsung・Huawei・Xiaomi・Vivoなどの人気スマートフォンに見せかけます。

犯罪者が運営するサーバー（**C2サーバー**＝指令を出すサーバー）から「今日はGalaxy S21のふりをしろ」という命令が送られてくると、TVボックスはその通りに自分のIDを書き換えます。

```
[犯罪者のC2サーバー] → 「Samsung Galaxy に化けろ」という命令
        ↓
[TVボックス] → 自分のIDをSamsungに書き換え
        ↓
[広告サイト] → 「あ、Samsungのスマホからアクセスがあった」と認識
        ↓
[自動クリック] → 広告収入がGET！
```

### 👁️ AIを使った広告クリックの自動化

この不正クリックには、なんと**AI技術（機械学習）**が使われています。

- 「**YOLOv8s**」という画像認識AIモデルを使って、画面上の広告バナーを自動で見つける
- Googleの「**ML Kit**」という文字認識技術で、画面に書いてある文字を読み取る
- これらを組み合わせて、人間が操作しているかのように広告をクリックする

さらに、不正クリックの「シナリオ（手順）」を**Blockly**というプログラムを使って作成します。BlocklyはGoogleが作った「ブロックを組み合わせるだけでプログラムが作れる」ツールで、プログラミングの知識が少ない人でも使えます。これにより、少人数のエンジニアが多数の不正キャンペーンを効率よく管理できる体制が整っていました。

### 📡 ネット回線の「踏み台」にされる仕組み

```
[犯罪者] → あなたのTVボックス経由 → 目的のサイト
              ↑
  あなたのIPアドレスが使われる！
```

TVがHDMIケーブルから映像信号を受け取っていない（＝テレビが使われていない）とき、TVボックスは自動的に**SOCKS5プロキシ**として動作し始めます。つまり、テレビを見ていない時間帯に、あなたの自宅のネット回線が犯罪者に貸し出されているのです。

### 🔍 どうやって発見されたか

Bitsightの研究者たちは、期限切れになっていた**ドメイン（ウェブアドレス）を取得**する手法で発見しました。このドメインは元々、TVボックスの動作状況を収集するために使われていた「裏口（バックドア）」でした。期限切れになったあとにBitsightが取得したところ、世界中の約**38,000台のTVボックス**から接続が来ていることがわかりました。

## なぜ重要なのか

### 💸 被害の規模感

Bitsightの試算によると：
- 1台あたり**1日$1.25（約190円）**の不正収益
- 38,000台が稼働している場合、**1日あたり約$47,500（約720万円）**
- 年間では**最大約4,000万ドル（約60億円）**の不正収益の可能性

### 😰 あなたへの影響

| 影響 | 内容 |
|------|------|
| **知らぬ間に犯罪に加担** | あなたの自宅IPアドレスが不正アクセスや詐欺に使われる |
| **通信速度の低下** | ネット回線が他人に使われるため、動画が重くなるなどの影響がある可能性 |
| **セキュリティリスク** | 犯罪者がいつでもTVボックスを通じてあなたのネットワークに侵入できる状態 |
| **法的リスク** | IPアドレスを元にした捜査で、あなたが疑われる可能性がある（濡れ衣） |

### 🌍 社会的な影響

広告詐欺によって**広告主（企業）のお金が不正に盗まれ**、その損失は最終的に消費者への価格転嫁などの形で影響します。また、Googleなどの広告プラットフォームへの信頼も損なわれます。

### ⚠️ Googleの見解

Googleはこれらの格安デバイスについて「**Play Protect認定を受けていないAndroidデバイスである**」と表明しました。つまり、Googleの安全基準を満たしていない野良デバイスということです。

## 対策・今後の展望

### ✅ 今すぐできる対策

**① 購入前のチェック**
- 「**Google Play Protect認定**」を受けているデバイスを選ぶ
- Amazonや公式ストアで販売されている有名ブランド品（Chromecast、Fire TV Stickなど）を選ぶ
- 極端に安いAndroid TVボックスは避ける（「安すぎる」には理由がある！）

**② 購入後のチェック**
- ルーターの管理画面で、TVボックスの通信量を確認する（異常に多い場合は要注意）
- 使っていないときはTVボックスの電源を切る習慣をつける

**③ すでに持っている場合**
- 機種名が「**H96_MAX_V11**」の場合は特に注意が必要
- 心配な場合は、使用を停止するか、信頼できるメーカーの製品に交換することを検討する

### 🔮 今後の展望

- セキュリティ企業・広告プラットフォーム・製造業者の三者間での対策協力が求められています
- GoogleのPlay Protect認定制度の強化や、格安Android端末への審査強化が進む可能性があります
- 関連する中国特許（CN117421142B など）の存在から、さらに高度な「デジタルヒューマン」技術への発展も懸念されています

## 用語解説

| 用語 | 説明 |
|------|------|
| **Android TVボックス** | テレビに接続してNetflixなどを見られるようにする小型端末 |
| **マルウェア** | 悪意のあるソフトウェアの総称（ウイルスの仲間） |
| **プロキシ** | インターネット通信の中継地点。悪用されると自分の場所を隠すために使われる |
| **SOCKS5** | 通信を中継するためのプロトコル（手順）の一種 |
| **広告詐欺（アド・フロード）** | ロボットに広告をクリックさせて不正に収益を得る行為 |
| **C2サーバー** | Command and Control（指令と制御）サーバー。マルウェアに命令を送るサーバー |
| **IPアドレス** | インターネット上の住所。どのデバイスからアクセスしたかを特定できる |
| **MACアドレス** | ネットワーク機器に割り当てられた固有の番号（機器の指紋のようなもの） |
| **YOLOv8s** | リアルタイムで画像から物体を認識するAIモデルの名前 |
| **Blockly** | Googleが開発した、ブロックを組み合わせてプログラムを作るツール |
| **Play Protect認定** | GoogleがAndroidデバイスの安全性を審査して与える認証マーク |
| **バックドア** | 正規の手順を踏まずにシステムに侵入するための「裏口」 |
| **サプライチェーン** | 製品が製造されて消費者に届くまでの一連の流れ |
| **TLS証明書** | ウェブサイトの通信を暗号化するための証明書。攻撃者特定の手がかりになることも |

> 💡 **まとめると…**
> 安いAndroid TVボックスの中には、最初から悪意のあるプログラムが仕込まれているものがあります。そのTVボックスはスマホのふりをして広告を不正クリックしつつ、あなたのネット回線を犯罪者に「貸し出す」踏み台にしていました。格安デバイスを買うときは、Google Play Protect認定の有無を必ず確認しましょう！
