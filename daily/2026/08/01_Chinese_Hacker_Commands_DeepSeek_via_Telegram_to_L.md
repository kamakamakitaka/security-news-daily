# 中国人ハッカーがAI「DeepSeek」をTelegramで操り、自動攻撃を実行！

**元記事**: [Chinese Hacker Commands DeepSeek via Telegram to Launch Autonomous Attacks](https://inl03.netline.com/ltr6/?_m=3n.009a.4045.sp0ao46r89.33oe)
**解説日**: 2026年8月

---

## 背景知識

このニュースを理解するために、いくつかの重要な概念を先に説明します。

### 🤖 AIエージェントって何？
普通のAI（例：ChatGPT）は「質問したら答える」という使い方です。でも**AIエージェント**は、人間が最初に「〇〇をやっておいて」と指示するだけで、**あとは自分で考えて、複数の作業を次々と自動でこなす**ことができます。まるでロボット秘書のようなイメージです。

### 💬 Telegramって？
メッセージアプリです。LINEのようなものですが、**ボット（自動プログラム）と連携する機能**が強力で、ハッカーがこのボット機能を悪用するケースが増えています。

### 🧠 DeepSeekって何？
中国企業が開発した**高性能なAIモデル**です。ChatGPTやClaudeと同じような大規模言語モデル（AIの頭脳）で、コードを書いたり、複雑な問題を考えたりするのが得意です。

### 🔍 CVE（シーブイイー）って？
ソフトウェアの「セキュリティ上の欠陥（脆弱性）」に付けられる**世界共通の番号**です。例えば「CVE-2026-33017」のように書かれます。図書館の本の管理番号みたいなものだと思ってください。

### 🛡️ Palo Alto Networks / Unit 42って？
アメリカの大手セキュリティ企業「パロアルトネットワークス」の中にある**エリートセキュリティ調査チーム**です。世界中のサイバー攻撃を追いかけて分析しています。

## 何が起きたのか

今回発覚した事件を、順番に整理すると次のようになります。

### 📋 事件の流れ

```
①「knai」「KnYuan」というニックネームの中国語話者ハッカーが
　　↓
② Telegram（メッセージアプリ）でたった一言命令を送る
　　↓
③ AIエージェント「Hermes Agent」が起動し、DeepSeekが頭脳として動き始める
　　↓
④ DeepSeekが自動で標的を探し、攻撃方法を選び、攻撃を試みる
　　（この間、ハッカーはほぼ何もしていない！）
　　↓
⑤ 460以上のシステムへの攻撃を試みる
```

**ポイント**: ハッカーが最初にTelegramで命令を送った後は、**AIが全部自動でやっていた**という点が非常に衝撃的です。

### 🎯 攻撃の標的
以下のソフトウェアが標的になりました：

| ソフトウェア名 | 何をするものか | 被害状況 |
|---|---|---|
| **Langflow** | AIワークフロー構築ツール | 攻撃失敗 |
| **n8n** | 業務自動化ツール | 攻撃失敗 |
| **Marimo** | Pythonノートブックツール | 11件で命令実行成功 |
| **NetScaler** | ネットワーク機器（シトリックス社） | 3組織からデータ流出 |

## 技術的な詳細

### 🤖 Hermes Agentの仕組み

**Hermes Agent（ヘルメスエージェント）** は、オープンソース（誰でも使えるソフト）のAIエージェントフレームワークです。

```
Hermes Agent の構成イメージ
┌─────────────────────────────────────┐
│  指示受信：Telegram（メッセージ）    │
├─────────────────────────────────────┤
│  頭脳：DeepSeek（AIモデル）         │
│  補助：Claude Code, Qwen Code       │
├─────────────────────────────────────┤
│  手足：ターミナル（コマンド実行）    │
│       スキル集（再利用可能な機能）   │
│       スケジューラー（自動実行）     │
└─────────────────────────────────────┘
```

まるで**優秀なアシスタントロボット**を、Telegramで遠隔操作しているイメージです。

### 🔍 DeepSeekが自動でやったこと（Langflow攻撃の例）

```
Step 1: CVE-2026-33017（脆弱性）の公開されている攻撃ツールをダウンロード
　　↓
Step 2: FOFAという検索エンジンで、世界中のLangflowシステムを84件発見
　　↓
Step 3: バージョンを確認し、攻撃できるバージョン（1.3.4）を1件発見
　　↓
Step 4: 攻撃を試みる → しかし設定条件が合わず失敗
　　↓
Step 5: 「この攻撃は無理」と判断し、自動的に別の標的（n8n）に切り替える
```

**すごいところ**: 人間が「次どうしよう…」と考える部分を、**AIが自動で判断して切り替えた**のです。

### 💥 n8n攻撃（2つの脆弱性を組み合わせた高度な攻撃）

DeepSeekはGitHubで新しい攻撃方法を探し、**2つの脆弱性を組み合わせる高度な手法**を選びました。

```
CVE-2026-21858（認証なしでファイルにアクセスできる欠陥）
　　　　　　　　+
CVE-2025-68613（コードを無理やり実行させる欠陥）
　　　　　　　　↓
組み合わせると → システムを完全に乗っ取れる可能性
```

FOFAの検索では**中国国内だけで25,209件のn8nシステム**が見つかりましたが、攻撃に必要な条件が整わず、結果的に0件の侵害にとどまりました。

### 😅 ハッカー自身のミスで発覚！

実はこの攻撃が発覚したのは、**ハッカー自身のうっかりミス**がきっかけです。

```
ハッカーが誤って実行したコマンド：
python3 -m http.server 8888

これは「ファイルを公開するWebサーバー」を起動するコマンド。
/home/worker フォルダの中身がインターネット上に丸見えに！
```

公開されてしまった内容：
- 🔑 AIサービスのAPIキー（パスワードのようなもの）
- 📝 攻撃スクリプト（攻撃プログラム）
- 🎯 標的リスト
- 💻 コマンド履歴
- 📊 AIの自動攻撃セッションのログ

これを Unit 42 が発見し、攻撃の全貌が明らかになりました。**「泥棒が自分で証拠を公開してしまった」**ような状況です。

## なぜ重要なのか

### 🚨 AIが「自律的に」攻撃した初の本格的事例

これまでのサイバー攻撃は、「ハッカーが直接操作する」か「単純な自動スクリプトで動く」かのどちらかでした。しかし今回は…

> **「AIが状況を判断し、戦略を立て直し、自律的に攻撃を継続した」**

という、新しい脅威の時代の到来を示しています。

### 📊 規模感を理解しよう

```
攻撃を試みたシステム数：460件以上
n8nの検索結果（中国内）：25,209件
Langflowの調査件数：84件

確認された成功した侵害：3組織
```

今回は失敗が多かったですが、ツールやAIの精度が上がれば、**同じ労力で何倍もの被害が出る**可能性があります。

### 🌏 地政学的な懸念
ハッカーが中国語話者であること、使われたAIが中国製のDeepSeekであることから、**国家が関与している可能性**も研究者たちは注目しています（ただし記事では断言していません）。

## 対策・今後の展望

### 🔧 すぐにやるべき対策

**ソフトウェアをアップデートする！**

| ソフトウェア | 安全なバージョン |
|---|---|
| Langflow | **1.9.0以上** |
| n8n | **1.121.1以上**（両方の脆弱性を修正） |
| Marimo | **0.23.0以上** |
| NetScaler ADC/Gateway | Citrix社のパッチを適用 |

### 🔐 一般的なセキュリティ対策

1. **不要な公開アクセスを閉じる**
   - ワークフローツールや開発ツールを、インターネット上に無防備にさらさない
   - 必要な人だけがアクセスできるよう、VPN（仮想プライベートネットワーク）や認証を設ける

2. **定期的なアップデートの徹底**
   - 今回のような脆弱性は、パッチ（修正プログラム）を当てることで防げます

3. **APIキーの管理を厳重に**
   - 今回はハッカーのAPIキーが流出しましたが、自分のAPIキーも同様のミスで漏れないよう注意

### 🔮 今後の展望

今回の事件は「AIを使った自動攻撃の時代の始まり」を告げるものです。防御側も：
- AIを使った**自動防御システム**の開発
- 公開ツールや脆弱性情報のより迅速な管理
- AIエージェントが生成するトラフィックの**検知・ブロック**

といった対策が急務になっています。

## 用語解説

| 用語 | 意味 |
|---|---|
| **AIエージェント** | 自分で考えて複数の作業を自律的にこなすAIプログラム |
| **DeepSeek** | 中国企業が開発した高性能なAIモデル（ChatGPTの競合） |
| **Hermes Agent** | 誰でも使えるオープンソースのAIエージェントフレームワーク |
| **CVE** | ソフトウェアの脆弱性（セキュリティ上の欠陥）に付ける世界共通の番号 |
| **FOFA** | インターネット上のシステムを検索できるサービス（Shodan等と同類） |
| **エクスプロイト** | 脆弱性を実際に攻撃するためのプログラムや手法 |
| **脆弱性** | ソフトウェアやシステムにある「セキュリティ上の弱点・バグ」 |
| **Langflow** | AIのワークフロー（作業手順）を視覚的に組み立てるツール |
| **n8n** | 業務プロセスを自動化するワークフローツール |
| **Marimo** | Pythonコードを対話的に実行するノートブックツール |
| **NetScaler** | シトリックス社のネットワーク機器（企業の入口部分を担う） |
| **APIキー** | AIサービスなどを使うための「鍵となるパスワード文字列」 |
| **Unit 42** | パロアルトネットワークス社の精鋭サイバー脅威調査チーム |
| **オープンソース** | 誰でもソースコードを見たり使ったりできるソフトウェア |
| **データ流出（エクスフィルトレーション）** | 攻撃者が標的のデータを盗み取ること |
| **SAML** | シングルサインオン（1つのIDで複数サービスにログイン）の仕組み |
