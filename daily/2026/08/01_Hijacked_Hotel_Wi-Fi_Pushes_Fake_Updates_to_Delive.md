# ホテルのWi-Fiが乗っ取られ、偽のアップデートでスパイウェアが配布される

**元記事**: [Hijacked Hotel Wi-Fi Pushes Fake Updates to Deliver Surveillance Malware](https://inl03.netline.com/ltr6/?_m=3n.009a.4045.sp0ao46r89.33nk)
**解説日**: 2025年7月22日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な仕組みを知っておきましょう。

### ホテルのWi-Fiの仕組み（キャプティブポータル）

ホテルや空港のWi-Fiに接続したとき、最初に「利用規約に同意してください」という画面が表示されることがありますよね。あの画面のことを **「キャプティブポータル」** といいます。

仕組みをざっくり説明すると：

```
あなたのパソコン
    ↓ Wi-Fiに接続
キャプティブポータル（ゲートウェイ）← ここが乗っ取られた！
    ↓ 認証後にインターネットへ
インターネット
```

このゲートウェイは「**DNS**（ドメインネームシステム）」という仕組みも管理しています。DNSとは、「google.com」のような名前を実際のIPアドレス（住所）に変換する電話帳のような仕組みです。

> 🎓 **例え話**: DNSは「渋谷駅ってどこ?」と聞いたら「東京都渋谷区...」と教えてくれる案内所のようなもの。これが乗っ取られると、「渋谷駅はここだよ」と**嘘の住所**を教えられてしまいます。

### RAT（リモートアクセストロイの木馬）とは

**RAT（Remote Access Trojan）** とは、感染したパソコンを遠隔操作できるようにする悪意のあるプログラムのことです。トロイの木馬（ギリシャ神話の「木馬に兵士を隠した」話）のように、**無害なものに見せかけて侵入する**のが特徴です。

## 何が起きたのか

マイクロソフトが2025年5月以降に調査・報告した内容によると、**「CaptiveCrunch（キャプティブクランチ）」** と名付けられた攻撃作戦が複数の国のホテルで確認されました。

### 攻撃の流れ（簡単に）

```
① 攻撃者がホテルのWi-Fiゲートウェイを乗っ取る
        ↓
② 宿泊客がホテルのWi-Fiに接続する
        ↓
③ 「ブラウザのアップデートが必要です」という偽の画面が表示される
        ↓
④ 指示通りに操作すると、悪意のあるプログラムがインストールされる
        ↓
⑤ パソコン内の情報（パスワード、カメラ映像、音声など）が盗まれる
```

### 誰がやっているの？

マイクロソフトの調査によると、この攻撃は **「Storm-2945」** というグループが関与しており、さらにその背後には **「Midnight Blizzard（ミッドナイト・ブリザード）」**（別名：APT29、Cozy Bear）という組織との関連が疑われています。アメリカとイギリス政府は、この組織を **ロシアの対外情報機関（SVR）** と関連付けています。

> 🌐 つまり、これは一般的なハッカーによる犯罪ではなく、**国家が背後にいる可能性が高いスパイ活動**だということです。

## 技術的な詳細

### ステップ1：DNS乗っ取りによるリダイレクト

攻撃者はホテルのゲートウェイを管理下に置くことで、**DNS（名前解決）の回答を偽造**できるようになります。

たとえば、パソコンが「インターネットにつながっているか確認する」ために自動的にアクセスするURLがあります。これを攻撃者の用意した偽サイトに**すり替える**ことができます。

### ステップ2：ClickFix（クリックフィックス）という罠

偽のページには「**ClickFix**」という手口が使われることがあります。これは：

> 「エラーが発生しました。以下の手順でコマンドを実行してください」

のような指示で、**被害者自身に悪意のあるコマンドを実行させる**手法です。

> 🎓 **例え話**: まるで「この薬を飲めば治るよ」と言われて、自分で毒を飲んでしまうようなものです。

⚠️ 重要なポイント：**攻撃者はこっそり感染させるのではなく、ユーザー自身に操作させる**という点が巧妙です。そのため「自分でやってしまった」という形になります。

### ステップ3：CornFlakeマルウェアの動作

インストールされる **「CornFlake（コーンフレーク）」** というマルウェアは以下のことができます：

| 機能 | 内容 |
|------|------|
| 📸 スクリーンショット | 操作していないときも自動的に画面を記録 |
| 🎤 音声・カメラ | マイクやウェブカメラの映像を盗む |
| ⌨️ キーロガー | キーボードの入力を記録（パスワードも！） |
| 🍪 Cookie盗難 | ブラウザに保存されたログイン情報を盗む |
| 💾 USBスキャン | 接続されたUSBメモリの中身も調べる |
| 🐚 リモートシェル | 攻撃者がパソコンを遠隔操作できるようにする |

**隠れ方も巧妙**：自分自身を `svchost32.exe`（Windowsの正規プロセスに似た名前）として偽装し、「**Cloud Sync Service**」という一見無害なサービス名で動作します。削除しても自動的に復活する仕組みも持っています。

### ステップ4：ChocoShellによるトークン盗難

さらに **「ChocoShell（チョコシェル）」** というツールは、Microsoft 365などのサービスの **「トークン」**（ログイン済みの証明書のようなもの）を盗みます。

> 🎓 **例え話**: トークンは「映画館の半券」のようなもの。一度入場確認を受けた後、その半券を盗まれると、**パスワードなしで**「本人のふりをして」再入場されてしまいます。

### ステップ5：デバイスコード認証の悪用

7月16日以降、さらに巧妙な手口も確認されました。偽のページが **マイクロソフトの本物のサインインページ** に誘導し、攻撃者が用意したコードを入力させます。これにより、**多要素認証（MFA）** をクリアした状態でアカウントが乗っ取られます。

> 🎓 **例え話**: 銀行のATMで「このコードを入力して確認してください」と言われて入力したら、実は**犯人の口座に送金する承認**をしてしまった、というイメージです。

## なぜ重要なのか

### 🌍 ビジネス旅行者・外交官が標的になりやすい

ホテルのWi-Fiを使う人は、特にビジネス旅行中の企業関係者や政府関係者が多いです。これらの人たちのパソコンには**機密情報が含まれている**可能性が高く、国家レベルの諜報活動に悪用される危険があります。

### 🔓 信頼できるはずの場所が危ない

「大きなホテルのWi-Fiだから安全」と思いがちですが、今回の事件はその**思い込みが危険**だということを示しています。

### 🤝 複数のホテルに影響している可能性

マイクロソフトは、複数のホテルで**共通の機器や管理システムが使われていた**ことを確認しており、同じキャプティブポータルのシステムを使う複数の施設が一度に影響を受けた可能性を指摘しています。

## 対策・今後の展望

### ✅ あなたにできる対策

#### 🔒 最も効果的な対策：常時接続VPNの使用

**VPN（仮想プライベートネットワーク）** を「常時フルトンネル」モードで使うことで、ホテルのゲートウェイを経由する前に会社のDNSサーバーに接続できます。

```
【VPNなし】 あなたのPC → ホテルのゲートウェイ(乗っ取り済み) → インターネット
【VPN使用】 あなたのPC → VPN暗号化トンネル → 安全なサーバー → インターネット
```

#### 📋 キャプティブポータルで絶対にやってはいけないこと

- ❌ ソフトウェアアップデートの指示に従う
- ❌ ブラウザのアップデートをインストールする
- ❌ セキュリティ証明書をインストールする
- ❌ 「コマンドを実行してください」という指示に従う
- ❌ 見慣れないコードをMicrosoftのサインインページに入力する
- ✅ 接続後は、自分で正規のサイトから最新情報を確認する

#### 🏢 企業・組織ができる対策

- **条件付きアクセスポリシー**でデバイスコード認証フローを制限する
- 社員が出張時に使うVPNのルールを整備する

### 🔭 今後の動向

今回の記事では「何人が実際に被害を受けたか」は明らかになっていません。攻撃の範囲を完全に把握するには、さらなる調査が必要です。マイクロソフトはまだ被害を受けたホテルや提供業者の名前を公表していません。

## 過去記事との関連

今回の記事には直接関連する過去記事はありませんが、**APT29（Cozy Bear）** は過去にも多くの注目すべき攻撃に関与しています。たとえば2020年のSolarWinds攻撃（米国の政府機関多数に影響）でも同じグループが関与しているとされています。今回もその延長線上にある**国家規模の継続的スパイ活動**と見られています。

また **ClickFix** という手口は、近年さまざまな攻撃で多用されている新しい手法で、「ユーザー自身に操作させる」という点でセキュリティソフトによる検知が難しく、今後もさまざまな形で悪用される可能性があります。

## 用語解説

| 用語 | 読み方 | 解説 |
|------|--------|------|
| **RAT** | ラット | Remote Access Trojan。感染パソコンを遠隔操作するマルウェア |
| **キャプティブポータル** | - | ホテルや空港のWi-Fiで最初に表示される認証画面 |
| **DNS** | ディーエヌエス | ドメイン名をIPアドレスに変換する仕組み。インターネットの電話帳 |
| **VPN** | ブイピーエヌ | 暗号化された通信トンネル。安全な通信経路を作る |
| **ClickFix** | クリックフィックス | ユーザー自身に悪意のある操作をさせる攻撃手法 |
| **CornFlake** | コーンフレーク | 今回使われたスパイウェア（RATの一種）の名前 |
| **ChocoShell** | チョコシェル | ログイントークンを盗むツールの名前 |
| **MFA** | エムエフエー | Multi-Factor Authentication。パスワード以外の認証も必要にする仕組み |
| **トークン** | - | ログイン済みであることを証明するデジタルの"半券" |
| **APT29** | エーピーティー29 | ロシアの情報機関と関連があるとされるハッカーグループ |
| **Storm-2945** | - | マイクロソフトが今回の攻撃グループに付けたコード名 |
| **Cookie** | クッキー | ブラウザがウェブサイトのログイン情報などを保存する小さなデータ |
| **キーロガー** | - | キーボードの入力を記録するプログラム |
| **SVR** | エスブイアール | ロシア対外情報庁。ロシアの対外情報機関 |

---

> 💡 **まとめ**: 「ホテルのWi-Fiは無料で便利」ですが、**国家レベルの攻撃者**がその仕組みを悪用してスパイウェアを仕込むことができます。出張や旅行の際は「キャプティブポータルで何かインストールを求められたら即拒否」「VPNを使う」の2点を心がけましょう！
