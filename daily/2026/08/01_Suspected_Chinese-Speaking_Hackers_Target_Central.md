# 中央アジアの政府機関を狙う！謎の中国語話者ハッカーが新型スパイツールを使った攻撃を展開

**元記事**: [Suspected Chinese-Speaking Hackers Target Central Asian Governments With OctLurk and SilkLurk](https://inl03.netline.com/ltr6/?_m=3n.009a.4045.sp0ao46r89.33nq)
**解説日**: 2025年7月

---

## 背景知識

まず、このニュースを理解するために知っておきたいことをざっくり説明します。

### 「バックドア」って何？
普通、家に入るためには玄関のドアを使いますよね。「バックドア（裏口）」とは、ハッカーがこっそり作る**秘密の入り口**のことです。一度このバックドアを仕掛けられると、ハッカーはいつでもコンピュータの中に侵入できるようになります。鍵のかかっていない裏口を作られてしまうイメージです。

### 「C2サーバー（C&Cサーバー）」って何？
C2は「Command & Control（命令と制御）」の略です。ハッカーが感染させたコンピュータに**遠隔で命令を出すための司令塔**となるサーバーです。感染したパソコンはこのサーバーと秘密に通信しながら、ハッカーの指示に従って動きます。

### 「APT（高度持続的脅威）」って何？
国家や大きな組織が関与していると疑われる、**非常に計画的・長期的なサイバー攻撃**のことです。単純なウイルスと違い、ターゲットを絞って、長期間かけてじっくり情報を盗んだりシステムを破壊したりします。

### なぜ中央アジアが狙われやすいのか？
中央アジア（カザフスタン、ウズベキスタンなど）は、中国・ロシア・中東に囲まれた地政学的に重要な地域です。エネルギー資源も豊富で、各国が情報収集を行いやすい「外交・諜報活動の舞台」になりやすい場所です。

## 何が起きたのか

2025年1月から、**中国語を話すと疑われるハッカーグループ**が、中央アジアを中心とした国々の政府機関などに対してサイバー攻撃を仕掛けていることが、ロシアのセキュリティ企業**カスペルスキー**によって発見されました。

### 攻撃のターゲットになった国と地域
- 🇦🇫 アフガニスタン
- 🇰🇬 キルギスタン
- 🇹🇯 タジキスタン
- 🇺🇿 ウズベキスタン
- 🇰🇿 カザフスタン
- 🇸🇾 シリア・アラブ共和国

### 狙われた分野
医療機関、研究機関、政府機関、外務省、物流、法執行機関（警察など）、都市計画機関、公教育機関など、**国の根幹に関わる重要な組織**が標的にされています。

### 使われた3つの新型ツール
| ツール名 | 役割 |
|----------|------|
| **OctLurk** | メインのバックドア。情報収集・遠隔操作 |
| **SilkLurk** | サブのバックドア。プラグイン追加対応 |
| **LurkProxy** | 通信を隠すための中継ツール |

## 技術的な詳細

### OctLurk（オクトラーク）の仕組み

OctLurkは「メモリインジェクション」という手法で動きます。これは、コンピュータの**一時記憶領域（メモリ）に直接プログラムを注入**することで、ファイルとしてディスクに保存されないようにする高度な技術です。ウイルス対策ソフトに見つかりにくくなります。

OctLurkが感染すると、以下のような恐ろしいことができるようになります：

```
🔍 情報収集系
  ├── スクリーンショットの撮影（画面を盗み見）
  ├── キーロギング（キーボードの入力を全部記録）
  ├── ブラウザからパスワードを盗む（ChromeやFirefox）
  └── クリップボードの内容を監視（コピーした内容を盗む）

🖥️ 遠隔操作系
  ├── コマンドシェルの起動（コンピュータを自由に操作）
  ├── マウス・キーボードの操作を乗っ取る
  └── リモートアクセスツール（Pandora RC）の設置

🌐 ネットワーク系
  ├── 内部ネットワークのスキャン（どんな機器があるか調査）
  └── メールサーバーへの不正接続・メール収集
```

特に巧妙なのが、**AnyDesk（アニーデスク）に偽装したキーロガー**を仕込む点です。AnyDeskは正規のリモートアクセスソフトなので、セキュリティソフトに怪しまれにくいわけです。服を着替えて変装するようなイメージですね。

また、**Impacket（インパケット）**という正規のセキュリティツールを悪用して、Windowsサーバーから**パスワードのハッシュ（暗号化されたパスワード）**を盗み出す手口も確認されています。

### LurkProxy（ラークプロキシ）の仕組み

LurkProxyは「プロキシ（中継）」ツールです。ハッカーとターゲット組織の通信を**まるで第三者を通して話しているかのように隠す**ための道具です。

```
通常の場合：
ハッカー → 被害者のパソコン（すぐバレる）

LurkProxyを使った場合：
ハッカー → LurkProxy（中継） → 被害者のパソコン（追跡が難しい）
```

「SOCKS5プロキシ」と「透過プロキシ」の2種類のモードが使えます。

### SilkLurk（シルクラーク）の仕組み

SilkLurkは「DLLサイドローディング」という手法で起動します。これは、**正規のプログラムのふりをして、本来とは別の悪意あるプログラムを読み込ませる**テクニックです。正規社員の名刺を偽造して会社に潜入するようなイメージです。

## なぜ重要なのか

### 国家レベルのスパイ活動の可能性
このような高度な攻撃は、単なる金銭目的ではなく**国家によるスパイ活動（諜報活動）**である可能性が高いとされています。外務省や法執行機関が狙われていることからも、外交情報や捜査情報を盗もうとしている疑いがあります。

### 完全に新しいツールで既存の防御をすり抜ける
OctLurkもSilkLurkも、これまで知られていない**まったく新しいマルウェア（悪意あるプログラム）**です。既存のウイルス対策データベースに登録されていないため、発見が非常に困難でした。

### 広範な被害の可能性
医療・教育・物流など様々な分野が狙われているため、**市民の個人情報や国家機密**が盗まれている可能性があります。

### 攻撃の入り口がまだ不明
カスペルスキーの調査でも、**最初にどうやって侵入したのかが未だ不明**です。これは防御策を立てにくいことを意味し、特に危険な状況です。

## 対策・今後の展望

### 組織・企業への対策
1. **多層防御の徹底** — ウイルス対策ソフトだけでなく、ネットワーク監視ツールも導入する
2. **メモリ上の不審な動作を監視** — OctLurkはファイルを作らないため、メモリ上の動作を監視するEDR（エンドポイント検出・対応）ツールが有効
3. **パスワード管理の強化** — 多要素認証（2段階認証）の導入でパスワードが盗まれても侵入を防ぐ
4. **不審な通信の遮断** — 記事中で示されたC2サーバーのアドレス（`dns.multitoconference[.]com`など）をブロックする

### 一般ユーザーへの心がけ
- 🔐 パスワードは使い回さない
- 📧 不審なメールの添付ファイルは絶対に開かない
- 🔄 ソフトウェアは常に最新版に更新する
- 🛡️ 信頼できるセキュリティソフトを使う

### 今後の動向
カスペルスキーはこの攻撃グループを引き続き追跡中です。今のところ既知のグループとは一致していないため、**新たなAPTグループ**として認識されつつあります。今後、さらなる標的や新しいツールが発見される可能性があります。

## 用語解説

| 用語 | 意味 |
|------|------|
| **バックドア** | ハッカーが秘密裏に作る不正な裏口プログラム |
| **C2サーバー（C&Cサーバー）** | ハッカーが感染したPCに命令を出す司令塔サーバー |
| **メモリインジェクション** | コンピュータの一時記憶領域に直接悪意あるコードを注入する技術 |
| **キーロガー** | キーボードの入力内容をこっそり記録するツール |
| **DLLサイドローディング** | 正規プログラムに偽装して悪意あるプログラムを読み込ませる手法 |
| **プロキシ** | 通信を中継して発信元を隠すための仕組み |
| **SOCKS5** | ネットワーク通信を中継するプロトコル（通信規格）の一種 |
| **ハッシュ** | パスワードを暗号化した文字列。これを盗むことでパスワード解析に使われる |
| **Impacket** | ネットワークプロトコルを操作するための正規ツール。悪用されることがある |
| **EDR** | エンドポイント検出・対応。PCやサーバー上の不審な動作をリアルタイムで検知するセキュリティツール |
| **APT（高度持続的脅威）** | 国家などが関与する、長期的・計画的なサイバー攻撃 |
| **難読化（obfuscated）** | プログラムのコードを読みにくくすることで、解析や検出を難しくする技術 |
