# 中国系ハッカーが流出した「DarkSword」ツールを使ってiPhoneに「GHOSTBLADE」を仕込む攻撃を展開

**元記事**: [Chinese Threat Actor Uses Leaked DarkSword Kit to Deploy GHOSTBLADE on iOS](https://inl03.netline.com/ltr6/?_m=3n.009a.4046.sp0ao46r89.33os)
**解説日**: 2025年7月31日

---

## 背景知識

まず、この記事を理解するために必要な言葉や仕組みを説明します。

### 🍎 iPhoneって安全じゃないの？
iPhoneはAndroidと比べて「セキュリティが強い」と言われています。Appleが厳しく管理しているからです。でも、どんなシステムにも「穴（脆弱性）」はあります。その穴を悪用するのがハッカーの仕事です。

### 🗡️ 「エクスプロイトキット」とは？
「エクスプロイト（exploit）」とは「脆弱性を悪用する」という意味です。エクスプロイトキットは、**ソフトウェアの穴をついて攻撃するための道具セット**のことです。料理で言えば「包丁・まな板・鍋がセットになった料理道具セット」のようなものですが、悪用目的で作られています。

### 💧 「ウォータリングホール攻撃」とは？
「水飲み場型攻撃」とも呼ばれます。動物が水を飲みに集まる場所（水飲み場）で待ち伏せするライオンのように、**ターゲットがよく訪れるウェブサイトに罠を仕掛けて、アクセスしてきた人を感染させる**攻撃手法です。

### 🔑 「キーチェーン（Keychain）」とは？
iPhoneに内蔵されている**パスワードをまとめて保管する金庫のような仕組み**です。ウェブサイトのパスワードやWi-Fiのパスワードなどが暗号化されて入っています。

### 🏢 「AWS（Amazon Web Services）」とは？
Amazonが提供しているクラウドサービスです。多くの企業がサーバーをAWSで運用しているため、**AWSのログイン画面に見せかけたフィッシングサイト**は、企業の社員を狙う際によく使われます。

---

## 何が起きたのか

**一言でまとめると：「流出したハッキングツールを使って、中国系のハッカーがiPhoneを狙う大規模な攻撃を展開している」というニュースです。**

セキュリティ企業「Censys（センシス）」が2026年7月31日に発表した調査によると、正体不明の中国系ハッカーグループが以下のような攻撃を行っています。

- 📌 **100以上の偽ウェブサイト**を作成して罠を張っている
- 📌 偽サイトの多くは**「AWSのログインページ」や「Apple IDのログインページ」に見せかけた偽物**
- 📌 サーバーは**香港を中心に、日本・アメリカ・ヨーロッパ**に分散している
- 📌 「**DarkSword（ダークソード）**」という流出したハッキングツールを使っている
- 📌 最終的にiPhoneに「**GHOSTBLADE（ゴーストブレード）**」という情報を盗むマルウェアを仕込む

---

## 技術的な詳細

### 攻撃の流れ（ステップごとに解説）

```
【Step 1】被害者が偽サイトにアクセス
    ↓
偽のAWSログインページ or 偽のApple IDログインページ

【Step 2】ページの中に隠れた「iframe（アイフレーム）」が動く
    ↓
iframeとは、ページの中にこっそり別のページを埋め込む仕組み
見た目は普通のページでも、裏で悪意あるコードが動いている

【Step 3】DarkSwordの「フルチェーン攻撃」が始まる
    ↓
iOSの複数の脆弱性を連続して悪用（すでにAppleはパッチ済み）
対象はiOS 18.4〜18.7

【Step 4】JavaScriptが実行される
    ↓
JavaScriptはウェブページを動かすプログラム言語
悪意のあるJavaScriptが知らないうちに実行される

【Step 5】GHOSTBLADEがiPhoneにインストールされる
    ↓
情報を盗むマルウェア（悪意あるソフト）が仕込まれる

【Step 6】情報が盗まれて送信される
    ↓
・キーチェーン（保存されたパスワード）
・iCloudの認証情報
・Wi-Fiのパスワード
・その他のファイル
→ 攻撃者のサーバーに送られる
```

### なぜ「DarkSword」が広まったのか？

DarkSwordはもともと、**商業スパイウェア業者や国家が支援するとされるハッカーグループ**が使っていた高度なツールでした。ところが、**ソースコード（プログラムの設計図）が外部に流出してしまった**ため、元々使っていなかったハッカーグループも入手・利用できるようになってしまいました。

> 💡 **例え話**：金庫メーカーが開発した特殊な鍵の設計図が流出したら、誰でもその鍵を複製できてしまうのと同じです。

### 攻撃者の「管理パネル」が見つかった

Censysの調査では、攻撃者が使っている「管理画面（パネル）」も発見されました。

| パネル名 | 用途 |
|---|---|
| DarkSword Admin | 攻撃の管理 |
| Decode Dashboard | 盗んだデータの解読 |
| C2 Control Panel | マルウェアの遠隔操作 |

管理画面の一つには**中国語でユーザー名・パスワードのラベル**が書かれており、中国語話者が使っていることを示唆しています。また、流出したソースコードに含まれていた**ロシア語のコメント**もそのまま残っており、元のコードを使い回していることがわかります。

## なぜ重要なのか

### 1️⃣ 「フルチェーン攻撃」は非常に危険

DarkSwordは「**フルチェーンエクスプロイトキット**」と呼ばれています。これは、**iPhoneのセキュリティを段階的に突破していく複数の攻撃を組み合わせたもの**です。一つの穴をふさいでも別の穴で突破してくる、非常に高度な攻撃手法です。

### 2️⃣ 「サイトを見るだけ」で感染する可能性

フィッシングメール（詐欺メール）のように「何かをクリックしてダウンロードする」必要がありません。**罠が仕掛けられたページにアクセスするだけで、自動的に攻撃が始まる**可能性があります（ドライブバイ攻撃）。

### 3️⃣ 被害範囲が広い

サーバーの所在地が**香港・日本・アメリカ・ヨーロッパ**に及んでいます。日本も攻撃の範囲に含まれているため、他人事ではありません。

### 4️⃣ 流出によって「門が開いた」状態

ソースコードの流出により、今後さらに多くのハッカーグループが同じツールを使い始める可能性があります。実際に記事でも「他の攻撃者も便乗し始めた」と書かれています。

## 対策・今後の展望

### ✅ すぐにできる対策

| 対策 | 理由 |
|---|---|
| **iOSを最新バージョンに更新する** | DarkSwordが狙うiOS 18.4〜18.7の脆弱性はAppleがすでに修正済みです。最新版にすることで多くの既知の攻撃を防げます |
| **怪しいリンクを開かない** | 見知らぬメール・SMS・SNSのリンクは要注意。特にAWSやApple IDのログインページに見せかけたものに注意 |
| **URLをよく確認する** | 本物のAWSは`aws.amazon.com`、Apple IDは`appleid.apple.com`です。少し違う文字が含まれていたら偽物の可能性大 |
| **公共Wi-Fiでの重要操作を避ける** | 攻撃者がWi-Fi認証情報も盗む可能性があるため |
| **iCloudのパスワードを変更・二段階認証を有効にする** | 万が一の時の被害を最小限に |

### 🔮 今後の展望

- DarkSwordのソースコードが流出した以上、**今後も同様の攻撃が増えることが予想**されます
- Appleはすでに脆弱性にパッチ（修正プログラム）を当てていますが、ハッカーは常に新しい穴を探しています
- 「Coruna」というDarkSwordより古い別のiOS攻撃ツールも同じ攻撃者グループが使っている可能性があり、**組織的かつ継続的な攻撃**であることが窺えます

## 過去記事との関連

今回の記事に登場するDarkSwordは、**2026年初頭にGoogleのセキュリティチームや複数のセキュリティ企業が発見・公表**したものです。当初は「商業スパイウェア業者や国家関連のハッカー」だけが使う高度なツールとして知られていました。サウジアラビア・トルコ・マレーシア・ウクライナが標的にされていたという経緯もあります。

今回の発見は「**ソースコードの流出によって、元々使っていなかった別のハッカーグループも同じツールを使い始めた**」という新展開です。高度な攻撃ツールが「民主化（誰でも使えるようになる）」してしまう危険性を示す事例として非常に重要です。

## 用語解説

| 用語 | 意味 |
|---|---|
| **エクスプロイトキット** | ソフトウェアの脆弱性を悪用するための攻撃ツールセット |
| **フルチェーン攻撃** | セキュリティの壁を段階的に複数突破していく高度な攻撃手法 |
| **GHOSTBLADE** | iPhoneに仕込まれる情報窃取マルウェアの名前 |
| **DarkSword** | iOSを狙うエクスプロイトキットの名前 |
| **マルウェア** | 悪意を持って作られたソフトウェアの総称（ウイルスもその一種） |
| **ウォータリングホール攻撃** | ターゲットがよく訪れるサイトに罠を仕掛ける攻撃 |
| **iframe** | ウェブページの中に別のページを埋め込む仕組み。悪用されることも多い |
| **キーチェーン** | iPhoneに内蔵されたパスワード管理の仕組み |
| **C2（Command & Control）** | 攻撃者がマルウェアを遠隔操作するためのサーバーや仕組み |
| **フィッシング** | 本物に見せかけた偽サイト・偽メールで情報を騙し取る攻撃 |
| **脆弱性（ぜいじゃくせい）** | ソフトウェアのバグや設計ミスによって生じるセキュリティの穴 |
| **パッチ** | 脆弱性を修正するためのソフトウェアの更新プログラム |
| **ソースコード** | プログラムの設計図となる人間が書いたコード |
| **AWS（Amazon Web Services）** | Amazonが提供するクラウドサービス。多くの企業が利用 |

---

> 🛡️ **まとめると**：iPhoneは比較的安全なスマホですが、「最新バージョンにアップデートする」「怪しいリンクを開かない」という基本的な対策がやはり最重要です。今回の攻撃は、iOSのすでに修正済みの脆弱性を狙うものなので、**アップデートをさぼらないこと**が最大の防御になります！
