# Coldcardハードウェアウォレットの欠陥が約88億円のビットコイン盗難に繋がった

**元記事**: [Coldcard Hardware Wallet Flaw Linked to $70 Million Bitcoin Theft in 41 Minutes](https://inl03.netline.com/ltr6/?_m=3n.009a.4046.sp0ao46r89.33ps)
**解説日**: 2026年8月3日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を押さえておきましょう。

### 🔑 ビットコインウォレットとは？
ビットコインを管理する「財布」のことです。実際にはビットコイン自体を入れるのではなく、**秘密鍵（パスワードのようなもの）** を管理します。この秘密鍵がなければ、ビットコインを動かすことはできません。

### 💾 ハードウェアウォレットとは？
秘密鍵をインターネットから切り離した専用の小型デバイス（USBメモリのような機器）で管理するものです。ネットに繋がらないため「安全」とされていました。Coldcardはカナダの会社Coinkiteが作るビットコイン専用のハードウェアウォレットです。

### 🎲 「乱数（ランダムな数字）」がなぜ重要？
ビットコインの秘密鍵は、**誰にも予測できない完全にランダムな数字** から作られます。例えば、鍵を「1234」のような予測しやすい数字で作ると、誰かに当てられてしまいます。本当に安全な鍵を作るには、**サイコロを何度も振るような「真のランダム性」** が必要です。

- **ハードウェアRNG（真の乱数生成器）**：電子回路のノイズなど物理現象を使った本物のランダム性
- **ソフトウェアPRNG（疑似乱数生成器）**：数学的な計算で「ランダムっぽい数字」を作るもの。初期値（シード）が決まると、出力も決まってしまう

> 🎯 **例え話**：ハードウェアRNGは「本物のサイコロを振る」こと、ソフトウェアPRNGは「サイコロの目を数式で計算する」ことのようなものです。後者は、計算式と最初の数字がわかれば、全ての「サイコロの目」が予測できてしまいます。

### 🌱 シードとは？
ウォレットの全ての鍵の元となる「種（たね）」となる言葉の列です（例：英単語12〜24個）。このシードから秘密鍵が生成されます。

## 何が起きたのか

**2025年7月30日、たった41分の間に衝撃的な盗難が発生しました。**

- 攻撃者が **1,196個のビットコインアドレス** を次々と空にした
- 盗まれた額は **1,082.65 BTC（当時約70億2,000万円相当）**
- その後の調査で被害はさらに拡大し、**1,367.05 BTC（約88億6,000万円相当）、4,585アドレス** に及ぶと判明

原因は、Coldcardというハードウェアウォレットの **2021年3月に混入したファームウェア（機器の内部プログラム）のバグ** でした。

---

## 技術的な詳細

### 🐛 バグの正体：「本物のサイコロ」が使われていなかった

本来、Coldcardは秘密鍵を作るとき、チップに内蔵された**ハードウェアRNG（本物の乱数生成器）** を使うべきでした。しかし、2021年のプログラム更新の際に **設定ミス** が起き、代わりに**ソフトウェアPRNG（疑似乱数生成器）** が使われるようになってしまいました。

### 🔍 なぜ発見が遅れたのか？

問題はプログラムコードの中の **設定値の確認方法のミス** でした。

```
「MICROPY_HW_ENABLE_RNG が存在するか？」→ 存在した（値は0 = 無効）
　　　↓
　本来確認すべきは「有効になっているか？」だった
　　　↓
　結果：無効なのに「ある」と判断して偽物の乱数生成器を使い続けた
```

> 🎯 **例え話**：防犯カメラの「電源スイッチ」の存在は確認したが、スイッチが「オフ」かどうかは確認しなかったようなミスです。

### 📊 どれくらい弱かったのか？

安全な秘密鍵には **128ビット分のランダム性** が必要です。しかし、このバグのせいで：

| モデル | 実質的なランダム性 | 安全な基準との差 |
|--------|---------------|------------|
| Mk3 | 約40ビット | **88ビット不足！** |
| Mk4/Mk5/Q | 約72ビット | **56ビット不足！** |

これは、金庫の暗証番号が「4桁」のはずが「実質1〜2桁」しかなかったようなものです。

### 💻 攻撃者はどうやって盗んだのか？

1. チップの固有ID、タイマーの状態、過去の乱数生成の履歴などの情報を入手（または推測）
2. これらをもとに**「この機器が生成したであろう乱数の候補」を計算**
3. 候補から秘密鍵を導き出し、公開されているブロックチェーンのデータと照合
4. 一致したアドレスのビットコインを根こそぎ盗む

> 🎯 **例え話**：鍵の製造番号と製造日時がわかれば、同じ鍵を複製できてしまう欠陥があった、ということです。

## なぜ重要なのか

### 💰 被害の規模が桁違い
88億円以上という被害額は、ハードウェアウォレットの欠陥による盗難としては **前代未聞の規模** です。

### ⏱️ 「安全」の神話が崩れた
ハードウェアウォレットは「最も安全な保管方法」とされてきました。しかし今回、**ウォレット自体の製造時の欠陥** が攻撃に使われたことで、「機器さえ持っていれば安全」という考えが通用しないことが証明されました。

### 📅 被害は数年前から始まっていた可能性
このバグは **2021年3月から存在** していたため、その期間に秘密鍵を生成したユーザーは全員リスクにさらされていた可能性があります。

### 🌐 影響を受けるバージョン
以下のファームウェアバージョンで秘密鍵を**生成した**ウォレットが対象です：

| モデル | 影響を受けるバージョン |
|-------|------------------|
| Mk2/Mk3 | 4.0.0 〜 4.1.9 |
| Mk4/Mk5 | 5.6.0より前 |
| Q | 1.5.0Qより前 |

## 対策・今後の展望

### ✅ Coinkiteが行った緊急対応
- **7月31日**（盗難の翌日）に緊急ファームウェアを公開
- バグを修正したバージョンをリリース

### ⚠️ ただし「ファームウェアを更新するだけでは不十分」
これが非常に重要なポイントです！

> **ファームウェアを更新しても、バグのある時期に作られた秘密鍵（シード）は依然として危険です。**

まるで「欠陥のある方法で作られた鍵のコピーが既に出回っている」状態なので、鍵そのものを作り直す必要があります。

### 🛡️ 具体的にすべき対策

**① 新しいシード（秘密鍵の元）を生成する**
- 修正済みファームウェアをインストール
- **新しいシードを生成し直す**
- ビットコインを新しいアドレスに移動する

**② サイコロを使った生成（比較的安全）**
- 公正な50回以上のサイコロ振りで生成されたシードはこのバグの影響を受けにくい

**③ BIP-39パスフレーズの活用**
- 強力なパスフレーズを設定することで追加の保護になるが、それでもシードの再生成が推奨される

**④ マルチシグの確認**
- 複数のウォレットで承認が必要な「マルチシグ」設定でも、**全てのウォレットが影響を受けたデバイスだと意味がない**

### 🔮 今後の展望
- 誰が攻撃者かはまだ判明していない
- 今後も新たな被害が発覚する可能性がある
- ハードウェアウォレット業界全体で乱数生成のセキュリティ見直しが進むと予想される

## 過去記事との関連

以前、**「Ill Bloom」研究（2026年7月初め）** について触れましたが、今回の事件はそれと非常によく似た性質を持っています。Ill Bloom研究では、古いソフトウェアウォレット（スマホアプリ等）の**乱数生成の弱さ**が原因で、Bitcoin・Ethereum・Tronなど複数の仮想通貨から**500万ドル以上（約7億5,000万円）** が盗まれました。

今回のColdcard事件との共通点は：
- **どちらも「乱数生成の欠陥」が根本原因**
- **どちらも長期間気づかれなかった**
- **どちらも実際の被害が発生してから発覚**

「乱数生成の問題」は仮想通貨セキュリティにおける **繰り返し発生する根本的な課題** であることがわかります。ハードウェアウォレットなら安全、ソフトウェアウォレットなら安全、という単純な話ではなく、**実装の品質が重要** だということが改めて示されました。

## 用語解説

| 用語 | 説明 |
|------|------|
| **ハードウェアウォレット** | 秘密鍵をオフラインで管理する専用の小型デバイス |
| **秘密鍵** | ビットコインを動かすための「パスワード」 |
| **シード（seed）** | ウォレットの全ての鍵の元となる英単語の列（12〜24語） |
| **ファームウェア** | 機器を動かす内部プログラム |
| **RNG（乱数生成器）** | ランダムな数字を作る仕組み |
| **ハードウェアRNG** | 物理的なノイズを使った「本物」の乱数生成器 |
| **ソフトウェアPRNG（疑似乱数生成器）** | 数式で「ランダムっぽい数字」を作るもの。予測可能なリスクがある |
| **BIP-39** | ビットコインのシードを英単語で表現する標準規格 |
| **マルチシグ** | 複数のウォレットの承認が必要な取引方式 |
| **エントロピー（ビット）** | ランダム性の強さを表す単位。数字が大きいほど予測困難 |
| **ブロックチェーン** | ビットコインの全取引記録を保存する公開台帳 |
| **アドレス** | ビットコインの「口座番号」のようなもの |

---

> 💡 **まとめ**：「安全」とされていたハードウェアウォレットでも、**製造・開発時のちょっとしたプログラムのミス** が数年後に数十億円規模の被害を生む可能性があります。仮想通貨を持っている方は、使用しているウォレットのバージョンを確認し、公式の案内に従って対応することが大切です。
