# DNA鑑定ファイルの改ざんがほぼ検知不可能になる脆弱性が修正された

**元記事**: [Thermo Fisher Patches Flaw That Could Make DNA File Tampering Nearly Undetectable](https://inl03.netline.com/ltr6/?_m=3n.009a.4046.sp0ao46r89.33pa)
**解説日**: 2026年8月4日

---

## 背景知識

このニュースを理解するために、まず「DNA鑑定」と「バイオ系ソフトウェア」について簡単に説明します。

### DNA鑑定とは？
犯罪捜査や親子関係の確認などに使われる技術で、血液や毛髪などから採取したDNAを分析して「この人のものかどうか」を特定するものです。テレビの刑事ドラマでよく見る「現場に残されたDNAと容疑者のDNAが一致した」というシーンをイメージするとわかりやすいです。

### Thermo Fisher Scientificとは？
世界最大規模の科学機器・試薬メーカーのひとつです。「Applied Biosystems（アプライドバイオシステムズ）」というブランドで、DNA鑑定に使う機器やソフトウェアを世界中の警察・病院・研究機関に提供しています。

### ファイル形式「.fsa」「.hid」とは？
DNA分析機器が出力するデータファイルの種類です。たとえば「.jpg」が画像ファイルであるように、これらはDNA測定結果を記録した専用ファイルです。このデータを別のソフトウェアで読み込んで「鑑定結果」が出ます。

### デジタル署名とは？
書類に「本物であることを証明するハンコ」を押すイメージです。デジタルの世界では、ファイルが作られた後に誰かが中身を書き換えると、このハンコが「壊れた」状態になり、改ざんを検知できます。

---

## 何が起きたのか

**一言でまとめると：** DNA鑑定結果のデータファイルを、気づかれずに書き換えることができる脆弱性（セキュリティの欠陥）が発見され、修正されました。

具体的な流れはこうです：

1. Forensic Bioinformatics（法医学バイオインフォマティクス）のエンジニア、Nathan Adamsさんらがこの問題を発見
2. DNA分析機器が出力する `.fsa` / `.hid` 形式のファイルは、**改ざん防止の仕組みがなかった**ことが判明
3. AdamsさんはAIツール（Anthropic社のClaude）を使って約**45分**でファイルの書き換えに成功
4. しかも、書き換えたファイルを分析ソフトに読み込ませても**警告が一切出なかった**
5. この問題をCISA（米国のサイバーセキュリティ機関）と連携して報告
6. Thermo Fisher社は2026年7月31日にセキュリティ情報を公開し、修正済みソフトウェアを配布

> 🔑 **ポイント**: デモでは「2人分のDNAデータを合体させた偽ファイル」を作成し、しかも「2015年から一度も変更されていない」ように見せることに成功しています。

## 技術的な詳細

### どうやってファイルを改ざんするの？

```
【通常の流れ】
DNA分析機器 → データファイル(.fsa/.hid)生成 → 分析ソフトで読込 → 鑑定結果
                      ↑
             ここに「改ざん検知の鍵」がなかった！

【攻撃者の流れ】
DNA分析機器 → データファイル(.fsa/.hid)生成
                      ↓
              攻撃者がファイルを書き換え（中身を別人のデータに変更）
                      ↓
              分析ソフトで読込 → 「正常なファイル」として処理 → 偽の鑑定結果
```

### なぜ気づかれなかったの？
`.fsa` / `.hid` ファイルには、もともと**デジタル署名（改ざん検知の仕組み）が組み込まれていなかった**からです。

郵便物に例えると…
- 普通の封筒（改ざん可能） → 中身を入れ替えても見た目では分からない
- 封蝋（ふうろう）付きの封筒（改ざん検知あり） → 開封すると跡が残る

今回の修正で「封蝋」に相当するデジタル署名が追加されました。

### 攻撃に必要な条件は？
- 研究室のサーバーへの**ローカルまたはリモートアクセス**（つまり内部犯または不正侵入）
- DNA検査の仕組みについての**ある程度の知識**

誰でも簡単にできるわけではありませんが、AIツールを使えば**専門家でなくても45分でできた**という点が特に問題視されています。

## なぜ重要なのか

### 影響の深刻さ

| 利用場面 | 改ざんされた場合の影響 |
|---------|-------------------|
| 刑事事件の証拠 | 無実の人が有罪になる / 真犯人が無罪放免になる |
| 親子鑑定 | 誤った結果による法的トラブル |
| 医療・遺伝子検査 | 誤診・誤った治療 |
| 研究データ | 科学的成果の信頼性崩壊 |

### CVSSスコア8.2（High）とは？
セキュリティの深刻さを0〜10点で評価する指標です。**8.2は「高危険度」**に分類されます。

```
0 ────────── 4 ────────── 7 ────────── 9 ──── 10
  低リスク      中リスク      高リスク    緊急
                                ↑
                           今回はここ（8.2）
```

### 修正が出ない製品がある
古い製品3製品（3130シリーズ、ABI PRISM 3100/3100-Avantシリーズ、ABI PRISM 310シリーズ）は「サポート終了製品」として**修正パッチが提供されません**。これらの機器を使い続けている機関はリスクにさらされたままになります。

## 対策・今後の展望

### Thermo Fisher社が推奨する対策

**ベストな対策（強く推奨）：**
- ✅ 最新バージョンへのアップデートを即座に実施

**アップデートできない場合の代替策：**

| 対策 | 内容 | 例え話 |
|------|------|--------|
| チェーン・オブ・カストディ（証拠保全記録）の維持 | ファイルを誰がいつ扱ったか記録する | 「来客ノート」のようなもの |
| 暗号化＋パスワード保護されたメディアへの保存 | ファイルを「鍵付き金庫」に保管する | 南京錠つきのUSBメモリ |
| アクセス制限 | 必要な人だけがデータに触れるようにする | 「関係者以外立入禁止」の部屋 |
| 最小権限の原則 | ユーザーに必要最低限の権限だけ与える | スタッフに「マスターキー」ではなく「自分の部屋の鍵」だけ渡す |
| インターネット接続の制限 | 信頼できるネットワークだけに接続する | 家のWi-Fiを「鍵付き」にして見知らぬ人を入れない |

### 今後の課題
記事では「修正後に作られたファイルは署名で検証できる」とされていますが、**修正前に作られた古いファイルを遡って検証できるかどうかは不明**です。過去の鑑定結果についての信頼性検証は今後の大きな課題となりそうです。

## 用語解説

| 用語 | 意味 |
|------|------|
| **脆弱性（ぜいじゃくせい）** | ソフトウェアやシステムにある「セキュリティ上の欠陥・穴」のこと |
| **CVE（Common Vulnerabilities and Exposures）** | 脆弱性に付けられる世界共通の識別番号（例：CVE-2026-17583） |
| **CVSS（Common Vulnerability Scoring System）** | 脆弱性の深刻さを0〜10点で評価するスコア |
| **デジタル署名** | ファイルが本物・改ざんされていないことを証明する電子的な「ハンコ」 |
| **CISA** | 米国のサイバーセキュリティ・インフラセキュリティ庁。日本のIPAに相当 |
| **チェーン・オブ・カストディ** | 証拠や重要データを「誰がいつどこで扱ったか」記録し続けること |
| **最小権限の原則** | 各ユーザーに必要最低限のアクセス権だけ与えるセキュリティの基本原則 |
| **エンド・オブ・ライフ（EOL）** | メーカーのサポートが終了した製品。修正パッチが出なくなる |
| **Applied Biosystems** | Thermo Fisher傘下の科学機器ブランド。DNA分析機器で世界的に有名 |
| **Anthropic Claude** | Anthropic社が開発したAIアシスタント。今回のデモで改ざんコード作成に使用された |
| **フォレンジック（Forensics）** | 法的な目的（犯罪捜査など）のための科学的調査・分析 |

---

> ⚠️ **まとめ**: DNA鑑定は「絶対的な証拠」として裁判などでも使われますが、そのデータを管理するソフトウェアにもサイバーセキュリティ上の欠陥があり得ます。今回の件は「科学的データの信頼性」と「セキュリティ」が密接に結びついていることを改めて示した重要な事例です。
