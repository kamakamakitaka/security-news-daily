# cPanelの重大な脆弱性：ホスティング利用者がデータベースの管理者権限でSQLを実行できてしまう問題

**元記事**: [New cPanel Critical Flaw Could Let Hosting Customers Run SQL as Database Root](https://inl03.netline.com/ltr6/?_m=3n.009a.4047.sp0ao46r89.33qi)
**解説日**: 2026年8月5日

---

## 背景知識

まず、このニュースを理解するためのキーワードを整理しましょう。

### 🏠 cPanelとは？
**cPanel（シーパネル）**とは、レンタルサーバー（ホスティングサービス）を管理するための、世界で最も広く使われているツールの一つです。ブログやウェブサイトを運営するとき、多くの人がこのcPanelという管理画面からデータベースの作成・メールの設定などを行います。

> 🏢 **例えるなら...**
> cPanelは「マンションの各部屋（ユーザーアカウント）の管理パネル」のようなものです。各住人（ユーザー）は自分の部屋だけを管理できるはずで、他の部屋や建物全体の管理室（サーバーの管理者領域）には入れないはずです。

### 🗄️ SQLとデータベースとは？
- **データベース**：ウェブサイトの記事、会員情報、商品情報などを整理して保存する「倉庫」のようなもの
- **SQL（エスキューエル）**：その倉庫にデータを入れたり、取り出したり、削除したりするための「命令語」
- **root（ルート）**：「管理者の最高権限」のこと。rootになると、データベース全体を自由に操作できます

> 🔑 **例えるなら...**
> 普通のユーザーは「自分の部屋の鍵」しか持っていません。しかしrootは「マンション全体のマスターキー」を持っているイメージです。

### ⚠️ 権限昇格とは？
本来持っていないはずの高い権限を不正に手に入れることを「**権限昇格（Privilege Escalation）**」と言います。一般ユーザーが突然管理者になれてしまうイメージです。

---

## 何が起きたのか

cPanelに**深刻な脆弱性（セキュリティの穴）**が発見され、修正パッチ（修正プログラム）が公開されました。

### 問題の概要

| 項目 | 内容 |
|------|------|
| 脆弱性ID | CVE-2026-58048 |
| 深刻度スコア | 9.4 / 10（非常に高い！） |
| 影響範囲 | cPanel & WHM 全サポートバージョン、WP Squared |
| 必要条件 | 有効なcPanelアカウント + MySQLへのアクセス権限 |

### 何ができてしまったのか？

普通のレンタルサーバー利用者（一般ユーザー）が、**データベース管理者（root）と同じ権限でSQL命令を実行できてしまう**という問題です。

さらに怖いことに、サーバーの設定によっては、**データベースだけでなくOSレベル（サーバーそのもの）まで乗っ取られる可能性**があるとされています。

## 技術的な詳細

### どうしてこの問題が起きたのか？

問題は **「データベースの名前を変更する処理」** の中に潜んでいました。

#### 通常のデータベース名前変更の手順（正常な動作）
```
1. 新しい名前で新しいデータベースを作成する
2. 元のデータベースのデータをすべて移す
3. アクセス権限（grants）や保存された処理（stored code）を再作成する
4. 古いデータベースとその権限を削除する
```

#### 問題が起きていた箇所

この名前変更の処理中に、**「SQLモード」が保持（引き継ぎ）されない**という不具合がありました。

> 🔧 **SQLモードとは？**
> データベースが動作するときのルールや制限のセットです。「どんな命令を許可するか」を決めるものです。

SQLモードがリセットされた状態でSQLが実行されると、**一般ユーザーのSQL命令が管理者（root）の文脈で実行されてしまう**という抜け穴が生まれてしまいました。

> 🎭 **例えるなら...**
> セキュリティゲートを通過する際、本来は「一般通行証」でチェックされるはずなのに、名前変更の処理中だけゲートが「VIPパス」モードに切り替わってしまい、誰でも最高権限エリアに入れてしまった…というイメージです。

### CVSSスコア 9.4 はどれくらい深刻？

CVSSスコアは0〜10の範囲で、**脆弱性の深刻さ**を表します。

```
0.0 ～ 3.9  → 低（Low）
4.0 ～ 6.9  → 中（Medium）
7.0 ～ 8.9  → 高（High）
9.0 ～ 10.0 → 緊急（Critical）← 今回はここ！
```

9.4はほぼ最高レベルの深刻度です。

## なぜ重要なのか

### 影響を受けるサーバーの規模

cPanelは世界中のレンタルサーバーで使われており、その数は**数百万台規模**と言われています。多くのウェブサイトやブログがこのシステムの上で動いています。

### 誰が攻撃できるのか？

攻撃するには「有効なcPanelアカウント」が必要です。

> これは一見「条件が厳しい」ように見えますが…

- レンタルサーバーは一般人でも契約できる（月数百円〜）
- フィッシング詐欺（偽のメールでパスワードを盗む）などでアカウントを入手できる
- 複数人が同じサーバーを使っている「共有ホスティング」では、他のユーザーの情報も危険にさらされる

つまり、**「自分は攻撃されない」とは言い切れない**状況です。

### 今回の3つの脆弱性まとめ

同じ修正バージョンで、以下の3つの脆弱性が同時に修正されました：

| CVE番号 | 深刻度スコア | 内容 |
|---------|-------------|------|
| **CVE-2026-58048** | 9.4（緊急） | 今回のメイン：一般ユーザーがDB管理者権限でSQL実行 |
| **CVE-2026-58047** | 5.6（中） | HTTPリクエストスマグリング：認証なしで他ユーザーの情報が漏れる可能性 |
| **GCVE-25-2026-07-45-3** | （記載なし） | Eximというメール送信ソフトの脆弱性 |

#### CVE-2026-58047（HTTPリクエストスマグリング）とは？
> 🚌 **例えるなら...**
> バスに乗るとき、1枚のチケットで2人がこっそり乗り込むような手法です。サーバーへのHTTP通信をうまく「密輸」することで、他のユーザーの通信に干渉したり、認証情報（パスワードなど）を盗んだりできてしまいます。

## 対策・今後の展望

### ✅ 最優先の対策：アップデート！

cPanelはすでに修正バージョンをリリースしています。

**修正済みバージョン一覧：**
- 11.110.0.137
- 11.118.0.71
- 11.126.0.78
- 11.134.0.48
- 11.136.0.32
- 138.1.6（WP Squared向け）

**アップデート方法：**
- WHM（サーバー管理画面）から更新
- またはコマンドラインから実行（管理者向け）

### 🛡️ すぐにアップデートできない場合の暫定対策

| 脆弱性 | 暫定対策 | 注意点 |
|--------|---------|--------|
| CVE-2026-58048 | cPanelユーザーのMySQL機能を一時的に無効化 | 既存DBは動くが、追加・削除はできなくなる |
| CVE-2026-58047 | `cpsrvd_keepalives_disabled=1` を設定してcpsrvdを再起動 | サーバーの負荷・遅延が増加する |

### 🔍 現時点での攻撃状況

米国のセキュリティ機関CISAによると、2026年8月4日時点では「**悪用の報告なし**」とされています。ただしこれはあくまで「その時点のスナップショット（瞬間の記録）」であり、その後に状況が変わる可能性は十分あります。

> 💡 **自分にできること（一般ユーザー向け）**
> - 利用しているレンタルサーバーのお知らせをチェックする
> - サーバー会社から「アップデートのお知らせ」が来たら速やかに対応する
> - cPanelのパスワードを定期的に変更し、二段階認証を設定する

## 過去記事との関連

以前、**Google ADK（AIエージェント開発ツール）の危険なワークフローが削除された件**を解説しましたが、今回の記事とは直接の関連性は薄いです。

ただし、**共通するテーマ**として注目したいのは「**権限の境界が破られるリスク**」です。

- Googleの件：AIエージェントが本来持つべきでない高い権限を使って操作される可能性
- 今回のcPanel：一般ユーザーが管理者権限（root）でデータベースを操作できてしまう

どちらも「**本来越えてはいけない権限の壁が突破される**」という根本的な問題を抱えています。ソフトウェアの複雑さが増すほど、こうした「意図しない権限の抜け穴」が生まれやすくなっています。最近のセキュリティニュースでは、こうした**権限昇格**の問題が相次いでいることを覚えておきましょう。

## 用語解説

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **cPanel** | シーパネル | レンタルサーバーを管理するための定番ツール |
| **WHM** | ダブリューエイチエム | Web Host Manager。サーバー管理者用のcPanel管理画面 |
| **SQL** | エスキューエル | データベースを操作するための命令語 |
| **root** | ルート | システムの最高管理者権限・またはそのアカウント |
| **CVE** | シーブイイー | 脆弱性に付けられる世界共通のID番号 |
| **CVSS** | シーブイエスエス | 脆弱性の深刻さを0〜10で表すスコア |
| **権限昇格** | けんげんしょうかく | 本来持てないはずの高い権限を不正に得ること |
| **SQLインジェクション** | - | データベースに不正なSQL命令を送り込む攻撃 |
| **CWE-89** | - | SQLインジェクション脆弱性の分類番号 |
| **HTTPリクエストスマグリング** | - | HTTP通信を悪用して不正なリクエストを「密輸」する攻撃手法 |
| **Exim** | イグジム | メール送信に使われるサーバーソフトウェア |
| **パッチ** | - | ソフトウェアの問題を修正するための更新プログラム |
| **CISA** | サイサ | 米国のサイバーセキュリティ機関 |
| **フィッシング詐欺** | - | 偽メール・偽サイトでパスワードなどを騙し取る攻撃 |
| **SQLモード** | - | データベースが動作する際のルール・制限のセット |

> 🔒 **まとめ**
> cPanelという広く使われているサーバー管理ツールに、「一般ユーザーがデータベースの最高管理者権限を乗っ取れる」という深刻な脆弱性が見つかりました。レンタルサーバーを使っている方は、利用しているサービスがすでにアップデート済みかどうかを確認し、必要であればサーバー会社に問い合わせることをお勧めします。
