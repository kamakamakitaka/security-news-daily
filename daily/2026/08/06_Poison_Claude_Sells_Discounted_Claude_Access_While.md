# 「Poison Claude」の危険な罠：格安AIサービスの裏で、あなたの入力内容が全部見られている

**元記事**: [Poison Claude Sells Discounted Claude Access While Its Operator Sees Every Customer Prompt](https://inl03.netline.com/ltr6/?_m=3n.009a.4049.sp0ao46r89.33ty)
**解説日**: 2026年8月7日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を押さえておきましょう。

### AIサービスってどうやって使うの？
ChatGPTやClaudeといったAIは、企業（OpenAIやAnthropicなど）のサーバーで動いています。普通にブラウザから使う場合は無料プランや月額料金がかかりますが、**プログラムから自動で使いたい場合は「API」という仕組み**を使います。APIは「外部のプログラムからAIに命令を送るための窓口」のようなものです。

### APIキーとは？
APIを使うときには「APIキー」という合言葉（パスワードのようなもの）が必要です。このキーを持っている人だけがAIにアクセスできます。使った量に応じて料金が発生し、「トークン」という単位で課金されます（トークン＝だいたい単語や文字のかたまり）。

### プロキシ（中継サービス）とは？
インターネットの世界には「プロキシ」という「仲介役」が存在します。AさんがBに直接話しかけるのではなく、間にCを挟んで「A→C→B」という経路で通信する仕組みです。Cは内容を全部見ることができます。

---

## 何が起きたのか

セキュリティ企業Oktaの研究者が、**闇のネット上（サイバー犯罪フォーラム）で不正にAIサービスへのアクセスを売り買いしているサービスを8件以上発見**しました。

その代表例が「**Poison Claude（ポイズン・クロード）**」です。

🎯 **ポイントをまとめると：**

- ClaudeというAI（開発元：Anthropic）に、**正規料金の5〜15%という超格安価格**でアクセスできると宣伝
- 支払いは仮想通貨で受け付け
- ユーザーには専用の「APIキー」を発行し、「うちのサービス経由でClaudeを使ってね」と誘導
- でも実態は…**ユーザーがAIに送るメッセージを運営者が全部見ることができる**！

---

## 技術的な詳細

### どうやって格安を実現しているのか？

```
普通の方法：
ユーザー → Anthropic（正規料金を払って使う）

Poison Claudeの方法：
[不正な無料トライアルアカウントを大量作成]
    ↓
例）AWSのBedrockという基盤を使うと最初に100ドルの無料クレジットがもらえる
    ↓
その無料枠を使い回してユーザーにAPIを提供
    ↓
コストがほぼタダなので格安で売れる！
```

つまり、**AWSなどのクラウドサービスの「お試し無料クレジット」を不正に使いまわして**、格安価格を実現していたのです。これは完全にサービス利用規約違反であり、詐欺行為です。

### ユーザーの入力が丸見えになる仕組み

```
正規のルート：
ユーザーのメッセージ → Anthropic（Claudeが処理）→ 返答がユーザーへ

Poison Claudeのルート：
ユーザーのメッセージ 
    ↓ ←【ここで運営者が全部読める！】
Poison Claudeのサーバー（中継点）
    ↓
Anthropicのサーバー（Claude）
    ↓
返答 → Poison Claudeのサーバー ←【返答も読める！】
    ↓
ユーザーへ返答が届く
```

このような仕組みを「**ゲートウェイプロキシ**」と言います。ちょうど、あなたが手紙を出すとき、封筒を開けて中身を読んでからまた封をして送る郵便屋さんのような存在です。

### 利用者はどれくらいいたのか？
研究者がシステムの設定ミスを発見し、確認したところ：
- 総ユーザー数：**881人**
- アクティブユーザー：**872人**

が利用していたことが判明しました。

## なぜ重要なのか

### 🔴 利用者へのリスク

| リスク | 内容 |
|--------|------|
| **プライバシー漏洩** | AIに入力した内容（仕事の機密、個人情報など）が運営者に丸見え |
| **データ売買の可能性** | 運営者が集めたデータを他者に売る可能性がある |
| **突然のサービス停止** | 不正アカウントがAnthropicに凍結されると、サービスが突然使えなくなる |
| **偽物のAI** | 「高性能モデルが使える」と言いながら、実は安い旧モデルを提供している可能性 |
| **仮想通貨払い** | 詐欺にあっても返金が難しい |

### 🌏 より大きな問題：中国のAI市場との関係
記事では、このような「格安AI中継サービス」の需要が**中国で特に大きい**ことも指摘されています。

- 中国ではChatGPTなどの海外AIが「グレートファイアウォール（中国のネット検閲システム）」によって使えない
- そのため、こうした迂回サービスへの需要が高い

さらに深刻なのは：
- Anthropicは、DeepSeekなどの中国企業が「Claudeの能力を違法に盗み出している」と告発
- 中国の軍事研究者がOpenAIやAnthropicのAIを使って、自国のAI開発に活用していたと報告されている

## 対策・今後の展望

### ✅ 一般ユーザーができること

1. **公式サービス以外は使わない**
   - Claudeを使うなら → [claude.ai](https://claude.ai) または公式Anthropic API
   - ChatGPTを使うなら → [openai.com](https://openai.com) または公式API
   - 「安すぎる」サービスには必ず裏があると思ってください

2. **AIに機密情報を入力するときは慎重に**
   - 会社の機密情報、個人情報、パスワードなどは、たとえ公式サービスでも入力には注意

3. **仮想通貨払いのサービスには特に注意**
   - 返金や追跡が困難で、詐欺被害に遭いやすい

4. **怪しいAPIキーの設定変更指示に注意**
   - 「環境変数を変えて」「このURLを設定して」という指示は、自分のツールが別サーバー経由になるサインです

### 🔧 プラットフォーム側の対応
- Cloudflare（インターネットの守衛のような会社）がPoison Claudeのメインサイトに**フィッシング警告**を表示
- ただし、API用ドメインへの対応は「取らない」とされており、課題が残る

## 用語解説

| 用語 | 意味 |
|------|------|
| **LLM（大規模言語モデル）** | ChatGPT・Claudeのような、大量のテキストを学習したAI |
| **API** | プログラムからサービスを使うための「窓口」 |
| **APIキー** | APIを使うための「合言葉（パスワード）」 |
| **トークン** | AIの処理・課金の単位。だいたい数文字〜1単語に相当 |
| **プロキシ** | 通信の仲介役。中身を見ることができる |
| **ゲートウェイプロキシ** | すべての通信を中継するサーバー。今回はここで情報漏洩が起きる |
| **Bedrock** | AmazonのAI利用基盤サービス |
| **CDN（Cloudflare）** | コンテンツを素早く届けるネットワーク。IPアドレス隠蔽にも使われる |
| **グレートファイアウォール** | 中国政府が設けた、海外サービスへのアクセスを遮断するネット検閲システム |
| **フィッシング警告** | 「このサイトは危険かもしれません」という警告表示 |
| **仮想通貨（暗号資産）** | ビットコインなど。取引の追跡が難しく、詐欺に悪用されやすい |
| **Turnstile** | Cloudflareのbotアクセス防止機能 |

---

> 💡 **まとめると**：「格安でAIが使える！」という甘い言葉には罠があります。正規サービスより大幅に安いものは、不正な手段で成り立っており、あなたの入力内容が丸ごと盗まれる可能性があります。AIに何かを入力するとき、「この通信は本当に安全なルートを通っているか？」を意識する習慣をつけましょう。
