# Progress Kemp LoadMasterの深刻な欠陥、792回の攻撃試行を受けCISAの危険リストに追加される

**元記事**: [Progress Kemp LoadMaster Flaw Hits CISA KEV After 792 Reported Exploit Attempts](https://inl03.netline.com/ltr6/?_m=3n.009a.4051.sp0ao46r89.33w8)
**解説日**: 2026年8月9日

---

## 背景知識

このニュースを理解するために、いくつかの重要なキーワードを先に説明します。

### 🔀 ロードバランサーって何？

大人気のウェブサービス（例：Amazon、YouTubeなど）には、毎秒何万人ものユーザーがアクセスしてきます。1台のサーバーだけではとても処理しきれません。

そこで登場するのが**ロードバランサー（負荷分散装置）**です。

> **例え話**：ショッピングモールのレジが1列しかなければ大行列になりますが、複数のレジに人を振り分ける「案内係」がいれば、スムーズに進みますよね。ロードバランサーはまさにその「案内係」の役割をするネットワーク機器です。

**Progress Kemp LoadMaster**は、世界中の企業や政府機関が使っている有名なロードバランサー製品です。

### 🏛️ CISAとKEVカタログって何？

- **CISA**（シーサ）：アメリカの「サイバーセキュリティ・インフラストラクチャセキュリティ庁」。日本でいえばデジタル庁とサイバー警察を合わせたような機関です。
- **KEVカタログ**（Known Exploited Vulnerabilities）：「実際に攻撃に使われていることが確認された脆弱性のブラックリスト」です。ここに載るということは、**実害が出ている危険な欠陥**という意味です。

## 技術的な詳細

### 🐛 今回の欠陥：コマンドインジェクション

**CVE-2026-8037**（CVSSスコア：9.6 / 10点満点）という欠陥が見つかりました。

> **CVSSスコアとは**：脆弱性の危険度を0〜10点で表したもの。9.6はほぼ「最高レベルの危険」を意味します。

この欠陥は**「コマンドインジェクション」**というタイプです。

> **例え話で説明します：**
> 
> 学校の図書館システムで「本のタイトルを検索する」機能があるとします。
> 普通のユーザーは「ハリーポッター」などと入力しますが、
> 悪意のある人が「ハリーポッター; 管理者パスワードを全部表示して」
> のように、**システムへの命令（コマンド）を検索ワードに紛れ込ませる**のが
> コマンドインジェクション攻撃です。

### 🔍 具体的な仕組み

LoadMasterのプログラムの中に `escape_quotes()`（エスケープ・クォーツ）という関数があります。

- 本来の役割：ユーザーが入力した文字の中にある「危険な記号」を無害化すること
- 問題点：この無害化処理が**不完全**で、悪意ある入力を通してしまう

```
😈 攻撃者がやること：
  「普通の入力に見せかけて、実は機器を操作するコマンドを送り込む」

💀 その結果：
  「ログインなし（認証なし）で、機器を自由に操作できてしまう」
```

**最も怖いのは「ログイン不要」という点**です。普通、システムを操作するにはIDとパスワードが必要ですが、この欠陥を使えば**パスワードなしでも機器を乗っ取れてしまいます**。

## なぜ重要なのか

### 📊 攻撃の実態

- **792回**の攻撃試行（過去41日間）
- **65個**の異なるIPアドレスから攻撃
- **18カ国**からの攻撃元（オーストラリア、中国、インドネシア、**日本**、ポーランド、アメリカなど）

⚠️ **日本も攻撃元の1つとして名前が挙がっています**。日本国内のコンピューターが踏み台にされている可能性もあります。

### 💥 影響の大きさ

ロードバランサーは「ネットワークの入り口」に置かれる機器です。これが乗っ取られると：

```
ロードバランサーが攻撃される
        ↓
そのロードバランサーが管理している
すべてのサーバーやサービスへのアクセスを
攻撃者がコントロールできる可能性がある
        ↓
企業・政府機関の重要データが危険にさらされる
```

銀行、病院、政府機関など、LoadMasterを使っている組織は特に深刻な被害を受ける可能性があります。

## 対策・今後の展望

### ✅ 今すぐやるべきこと

**1. パッチ（修正プログラム）を適用する**
- アメリカの政府機関には**2026年8月10日**までの適用が義務付けられました
- 一般企業や組織も**できるだけ早く**アップデートを行うべきです

**2. 攻撃元IPアドレスをブロックする**
記事で報告されている攻撃元IPアドレスをファイアウォールでブロックすることも有効です：
- `192.42.116.58`
- `192.42.116.105`
- `146.70.139.154`

**3. ログを確認する**
すでに攻撃を受けていないか、機器のアクセスログを確認しましょう。

### 🔮 今後の展望

eSentireによると、今のところ攻撃の多くは**失敗に終わっている**とのことです。しかし：

> 「攻撃者が諦めたわけではなく、より巧妙な攻撃方法を準備している可能性がある」

とも考えられるため、油断は禁物です。

## 過去記事との関連

以前、**MetabaseのゼロデイA脆弱性**（ログインなしで管理者権限を乗っ取られる欠陥）と、**N-ableのN-central**（攻撃者が管理システムに居座り続けた事件）について解説しました。

今回のLoadMasterの欠陥も、これらと**共通の危険なパターン**があります：

```
✅ 共通パターン：
「認証（ログイン）をすり抜けて、管理者レベルの操作ができてしまう」
```

特にN-centralの件と似ているのは、**管理用のインフラ（仕組みの根っこ）が狙われている**という点です。攻撃者は「1つ乗っ取れば多くのシステムにアクセスできる」インフラ機器を積極的に狙う傾向が強まっています。これは「サプライチェーン攻撃」とも呼ばれる、現代のサイバー攻撃の主流トレンドです。

## 用語解説

| 用語 | 意味 |
|------|------|
| **ロードバランサー** | 大量のアクセスを複数のサーバーに振り分ける「交通整理」機器 |
| **CISA** | アメリカのサイバーセキュリティ専門機関 |
| **KEVカタログ** | 実際に攻撃に使われた危険な欠陥のブラックリスト |
| **CVE** | 発見された脆弱性につけられる国際的な識別番号（管理番号） |
| **CVSSスコア** | 脆弱性の危険度を0〜10で表した点数（10が最高に危険） |
| **コマンドインジェクション** | 悪意ある命令をシステムへの入力に紛れ込ませる攻撃手法 |
| **認証なし（Unauthenticated）** | パスワードやログインなしで攻撃できること。非常に危険な状態 |
| **パッチ** | ソフトウェアの欠陥を修正するためのアップデートプログラム |
| **IPアドレス** | インターネット上の「住所」。攻撃元の特定に使われる |
| **ゼロデイ** | 修正パッチが出る前から攻撃に使われている未知の脆弱性 |
| **FCEB** | アメリカの連邦政府機関のこと |
