# 悪意のあるSIMカードが、IoT機器の内部でハッカーのコードを実行できる

**元記事**: [A Malicious SIM Card Can Run Attacker Code Inside the Modems Behind Cellular IoT Devices](https://inl03.netline.com/ltr6/?_m=3n.009a.4053.sp0ao46r89.33yc)
**解説日**: 2025年7月

---

## 背景知識

このニュースを理解するために、いくつかの基本的な仕組みを先に説明します。

### 📱 SIMカードって何？

スマートフォンに入っている小さなチップです。「誰の電話番号か」を識別するためのものですが、実は**小さなコンピューターとしての機能**も持っています。

### 📡 IoT（アイオーティー）機器とは？

**IoT = Internet of Things（モノのインターネット）**
インターネットにつながる「物」のことです。例えば：
- 電気自動車（EV）の充電器
- 工場の産業用ルーター（ネットワーク機器）
- 車の位置情報を送る「テレマティクス」装置

これらの機器には、携帯回線でインターネットに接続するための**セルラーモジュール**（SIMカードを差し込む専用チップ）が内蔵されています。

### 📟 ATコマンドって何？

1981年に作られた、モデム（通信機器）を操作するための「命令語」の集まりです。
「AT」という文字から始まるため「ATコマンド」と呼ばれます。
> 例えば電話をかける命令、データを送る命令など、通信機器の基本的な操作をすべてATコマンドで行えます。

### 🃏 プロアクティブコマンドとは？

通常、SIMカードは「呼ばれたら答える」受け身の存在です。しかし**プロアクティブコマンド**を使うと、SIMカードの側から機器に命令を送ることができます。これは携帯通信の国際規格として正式に定められた機能です。

---

## 何が起きたのか

英国バーミンガム大学とセキュリティ企業Fuzzwareの研究者たちが、**「悪意を持って細工されたSIMカードを使うと、差し込まれた機器を乗っ取れる」**という脆弱性（セキュリティの穴）を発見しました。

### 調査の結果

| 対象 | 調査台数 | 脆弱だった台数 |
|------|----------|--------------|
| スマートフォン | 18台 | 3台 |
| セルラーモジュール（IoT機器向け） | 8台 | 6台 |

脆弱だったスマートフォンは以下の3機種です：
- OPPO Find X5
- OPPO Reno 14 F 5G
- ASUS Zenfone 9

> ✅ iPhoneやGoogle Pixelは影響を受けませんでした

また、脆弱だった6つのセルラーモジュールのうち**5つはQuectel（クアクテル）製**で、EV充電器・産業用ルーター・車のテレマティクス装置から取り出したものでした。

研究者たちは実際に**市販のEV充電器（Autel製）を使って、自分たちのプログラムを動かすことに成功**しています。

## 技術的な詳細

### 攻撃の流れをわかりやすく説明すると…

```
【通常の状態】
SIMカード → モデム（通信チップ）→ 機器が正常に動作

【攻撃の状態】
悪意あるSIMカード → 「RUN AT」命令を送る
                  → モデムがATコマンドを実行
                  → 機器全体を攻撃者がコントロール！
```

### 「RUN AT」コマンドが問題の核心

今回の攻撃に使われたのは **「RUN AT（ラン・エーティー）」** というプロアクティブコマンドです。

- SIMカードからモデムに「このATコマンドを実行して」と命令できる
- ATコマンドは通信機器の何でも操作できる「万能リモコン」のようなもの
- つまり**SIMカードが機器の操作権を持ってしまう**のです

### IoT機器がとくに危ない理由

現代のIoT向けセルラーモジュールには、通信チップのほかに**小さなアプリケーションプロセッサ（AndroidやLinuxが動く小型コンピューター）**も入っています。

> 例えるなら、「電話回線の窓口係」のすぐ隣に「なんでもできる事務員」がいる状態です。悪意あるSIMが窓口係を通じて事務員に命令を出せてしまう、というイメージです。

研究論文ではこれを「悪意あるSIMに対して豊富な攻撃対象を提供してしまっている」と表現しています。

### 攻撃に必要な条件

重要なのは、**この攻撃はネットワーク越しにリモートではできない**という点です。攻撃者は以下のいずれかの方法で悪意あるSIMを機器に入れる必要があります：

1. 🔧 手で直接SIMを入れ替える
2. 📦 薄い「インターポーザー」（割り込み基板）を既存SIMの下に差し込む
3. 🏭 製造工場や通信会社の段階で仕込む
4. 💻 ソフトウェア的にSIMを書き換える

> 「無人で設置されているIoT機器」は管理者が見ていないため、SIMトレイに物理的にアクセスしやすく、特に狙われやすいと研究者は指摘しています。

## なぜ重要なのか

### 🚗 EV充電器が乗っ取られたら？

- 充電を停止・操作される
- 利用者の個人情報・決済情報が盗まれる
- 充電ネットワーク全体への攻撃の足がかりにされる

### 🏭 産業用ルーターが乗っ取られたら？

- 工場の生産ラインを制御するネットワークへ侵入される
- 重要インフラへの攻撃につながる可能性がある

### 🌍 影響の広さ

脆弱性を持つチップはすべて**Qualcomm（クアルコム）製の通信プロセッサー**を使っていました。Qualcommのチップは世界中の携帯機器・IoT機器に広く使われているため、影響を受ける可能性のある機器の数は非常に多いと考えられます。

### ⚠️ 「規格通りの動作」という難しさ

バーミンガム大学のMuench助教授は、この問題について重要な指摘をしています：

> 「RUN ATコマンドは、携帯通信の国際規格に明示的に定められた機能です。つまりこれは"バグ"ではなく、規格に従った正常な動作と言えます」

これが修正を難しくしています。ソフトウェアのバグなら「パッチ（修正プログラム）」を当てれば直りますが、**仕様そのものが問題**の場合、各メーカーがそれぞれ判断して対応するしかありません。

## 対策・今後の展望

### メーカー側の対応状況

| 企業 | 対応状況 |
|------|----------|
| **Qualcomm** | RUN ATを初期状態でオフにする設定を今後の製品に組み込む予定 |
| **Quectel** | ファイルアクセスの問題は修正済み。RUN ATそのものは対応中 |

> ⚠️ どちらの企業も、まだ公式のセキュリティ勧告（アドバイザリー）を発表していません

### 研究者の提言

研究者たちは「RUN ATコマンドは**強化・廃止・完全無効化**のいずれかを行うべき」と主張しています。

### 今すぐできる対策

もしIoT機器（特にセルラーモジュールを使った機器）を管理している立場の人は：

1. **モジュールのメーカーに確認する**：出荷したファームウェアでRUN ATが有効になっているか
2. **無効化できるか確認する**：無効にできるなら、すぐに無効化する
3. **物理的なセキュリティを強化する**：SIMトレイへの不正アクセスを防ぐ

> 📢 現時点では、この脆弱性を実際に悪用した攻撃は報告されていません

## 過去記事との関連

今回の記事は、特定の過去記事との直接の続報ではありませんが、**IoTセキュリティの根本的な問題**を示しています。

IoT機器はしばしば「便利さ」や「コスト削減」が優先され、セキュリティ設計が後回しにされがちです。また、スマートフォンと違って**長期間アップデートされず野外に放置される**ことも多く、一度脆弱性が見つかっても修正が届きにくいという課題があります。

このニュースは「IoTデバイスの供給チェーン（製造から設置まで）全体のセキュリティ」という大きなテーマの一部として理解することができます。

## 用語解説

| 用語 | 意味 |
|------|------|
| **SIMカード** | 携帯電話の回線契約情報が入った小さなチップ |
| **IoT（モノのインターネット）** | インターネットに接続された家電・機械・センサーなど |
| **セルラーモジュール** | IoT機器に組み込まれた、携帯回線でつながるための通信チップ |
| **ATコマンド** | 通信機器（モデム）を操作するための命令語。1981年から使われている |
| **プロアクティブコマンド** | SIMカードから機器側に能動的に命令を送る仕組み |
| **RUN AT** | SIMがモデムにATコマンドを実行させるプロアクティブコマンド |
| **Qualcomm（クアルコム）** | スマートフォンや通信機器向けチップを作る大手半導体企業 |
| **Quectel（クアクテル）** | IoT向けセルラーモジュールを製造する中国の企業 |
| **テレマティクス** | 車両の位置・速度・状態などをリアルタイムで送受信するシステム |
| **ファームウェア** | 機器に組み込まれた基本的なソフトウェア（機器の「頭脳」） |
| **脆弱性（ぜいじゃくせい）** | セキュリティ上の弱点・穴のこと |
| **インターポーザー** | 既存のSIMと機器の間に差し込む薄い基板。SIMを偽装するために使われる |
| **USENIX WOOT** | セキュリティ研究の国際学会の一つ |

---

> 💡 **まとめ**: 「SIMカードはただのID証明書」と思われがちですが、実は機器に命令を送れる「小さなコンピューター」です。その機能が悪用されると、EV充電器や工場の機器が丸ごと乗っ取られる可能性があります。今のところ実際の被害は報告されていませんが、IoT機器を管理する企業・組織は早急に対応を確認することが重要です。
