# ハッカーがポーランドの発電所に侵入し、タービンをシャットダウン――携帯電話回線網が侵入経路に

**元記事**: [Hackers Breach Polish Power Plant Controls via Private Cellular Network and Shut Turbine](https://inl03.netline.com/ltr6/?_m=3n.009a.4053.sp0ao46r89.33zi)
**解説日**: 2026年8月12日

---

## 背景知識

まず、このニュースを理解するためのキーワードをざっくり説明します。

### 🏭 CHP（コージェネレーション）プラントとは？
電気と熱を同時に作る発電所です。普通の発電所は電気だけを作りますが、CHPプラントは発電した際の「廃熱」も住民の暖房・給湯などに使います。ポーランドのような寒い国では、これが多くの人の生活インフラになっています。

### 📡 プライベートAPN（専用携帯データ回線）とは？
APN（Access Point Name）とは、スマートフォンがインターネットに繋がるための「出入り口」のことです。一般の人が使うものとは別に、企業や電力会社が「自分たちの機器専用」として契約する閉じた携帯回線があります。「会社専用の内線電話回線」のようなイメージです。  
一般に「外部からは繋がらない安全な回線」と思われがちですが、**その内部の機器同士が自由に通信できる設定のままだと危険**です。

### 🏗️ 産業制御システム（ICS/OT）とは？
工場や発電所の機械を動かすためのコンピュータシステムです。タービン（発電機を回す羽根車）や水処理装置などを、遠隔から操作・監視します。普通のパソコンとは違い、「止まったら人々の生活に直結する」機器なので、セキュリティが特に重要です。

### 🌬️ 風力発電所と発電所がネットワークでつながっている理由
電力会社は、複数の施設（風力発電所・変電所・発電所など）を一つの通信網で管理しています。現場に人を置かなくても、遠隔で機器の状態を確認・操作できるようにするためです。これは便利ですが、**一か所が突破されると他の施設にも侵入できる**という弱点になります。

## 何が起きたのか

2025年12月、ポーランドで**約5万人の住民に熱を供給しているCHPプラント（熱電供給発電所）**がサイバー攻撃を受けました。

攻撃者は発電所の制御システムに侵入し、**蒸気タービンとプロセス水処理システムを強制停止**させました。

幸いにも、復旧作業が素早く行われたため、**住民への熱や電気の供給は途切れませんでした**。しかし、攻撃者がネットワーク内にいる最中から復旧作業をしなければならないという、かなり緊迫した状況でした。

この事件は発生から**3か月以上の調査を経て**、2026年8月8日にポーランドのサイバーセキュリティ機関（CERT Polska）が公式に発表しました。

## 技術的な詳細

攻撃の経路を、**泥棒が建物に侵入するときの例え**で説明します。

### 🗺️ 攻撃の経路（ステップ・バイ・ステップ）

```
インターネット
    ↓ ①VPNに侵入（多要素認証なし）
風力発電所のネットワーク（FortiGateルーター）
    ↓ ②ルーターの管理画面に不正アクセス
プライベートAPN（専用携帯回線）
    ↓ ③回線内の機器を自由にスキャン
WAGOコントローラー（発電所の制御装置）
    ↓ ④デフォルトパスワードでログイン
🔴 タービン・水処理システムの停止
```

#### ① 風力発電所のVPNを突破
攻撃者はまず、**風力発電所のVPN（仮想プライベートネットワーク）** に侵入しました。VPNとは「インターネット上に作られた専用トンネル」のことで、遠隔から安全に社内ネットワークに繋がるための仕組みです。  
しかし、このVPNには**多要素認証（MFA）が設定されていませんでした**。多要素認証とは、パスワード以外に「スマホに届くコード」などの確認を追加するセキュリティです。これがなければ、パスワードさえ手に入れれば誰でも入れてしまいます。

> 💡 **例え**: 「鍵（パスワード）」だけで開く扉。「鍵＋指紋認証（MFA）」なら安全なのに、鍵穴だけの扉でした。

#### ② ルーターの管理画面に侵入
風力発電所には **Teltonika RUTX50** というルーター（通信機器）がありました。電力会社の規定では「DNP3.0というプロトコル（通信規格）でデータを送ること」と決められており、それは守られていました。  
しかし、**ルーター自体の管理画面を保護するルールが存在しなかった**ため、管理画面がネットワーク上に無防備に露出していました。

> 💡 **例え**: 「郵便物の配達方法（DNP3.0）」は決まっていたけど、「郵便受け自体への鍵（管理画面のセキュリティ）」については誰も決めていなかった、という状況です。

#### ③ プライベートAPN内を自由に動き回る
ルーターを経由して、攻撃者は**プライベートAPN（専用携帯回線）**の内側に入り込みました。  
通常、このような専用回線では「機器Aは機器Bとだけ通信できる」というように制限（クライアント分離）が設定されるべきです。しかし、この回線では**どの機器も他のどの機器とも自由に通信できる設定（クライアント間通信が許可）**になっていました。

> 💡 **例え**: マンションの共用Wi-Fiで、「住人全員のパソコンが互いに丸見えで、自由にファイルを覗けてしまう」状態です。

攻撃者は12月18日からAPN内をスキャン（機器を探索）し、発電所にある**WAGOコントローラー**を発見しました。

#### ④ デフォルトパスワードで制御装置に侵入
発見したWAGOコントローラー（発電所の機械を制御するコンピュータ）には、なんと**出荷時のデフォルト（初期設定）パスワードがそのまま使われていました**。  
これは「金庫を買ったけど、暗証番号を『0000』のまま使っていた」ようなものです。攻撃者はそのまま管理者としてログインし、タービンと水処理システムを停止させました。

## なぜ重要なのか

### 🆕 世界初の攻撃手法
CERT Polskaは、**プライベートAPN（専用携帯回線）を経由して産業制御システムに侵入するという手口は、実際のサイバー攻撃で確認されたのは世界で初めて**だと述べています。  
新しい攻撃手口が発見されると、同じ設定をしている世界中の施設が潜在的な標的になります。

### 🌍 広がるリスク
CERT Polskaの調査によると、**プライベートAPNを使っているポーランドの組織の多くが、同様の危険な設定（機器間の自由な通信を許可）を使っていた**ことが判明しました。さらに、このような設定は他の国々でも広く普及していると見られています。

### ⚡ インフラへの脅威
5万人が利用する熱供給システムが止まる可能性がありました。冬のポーランドで暖房が止まれば、高齢者や乳幼児など脆弱な人々が危険にさらされます。発電所・水道・病院などの重要インフラへのサイバー攻撃は、人命に直結する問題です。

## 対策・今後の展望

CERT Polskaが推奨する対策をわかりやすく整理します。

| 問題点 | 対策 |
|---|---|
| APN内で機器が自由に通信できた | **クライアント分離**を有効にする（機器同士が直接通信できないようにする） |
| 制御装置のデフォルトパスワード | **必ず初期パスワードを変更する** |
| VPNに多要素認証がなかった | **MFA（多要素認証）を必須にする** |
| 管理画面が不要なところから見えていた | 不要な管理サービスを無効化・非公開にする |
| APNを「安全な内部ネットワーク」として信頼していた | APNを「信頼できない外部ネットワーク」と同様に扱い、通信を制限する |

### 🔍 パッチ（修正プログラム）で解決できない問題
今回の侵入に使われた特定のソフトウェアの脆弱性（CVE）は特定されませんでした。つまり、**「このソフトを更新すれば安全」という簡単な解決策がない**事件です。問題の根本は「設定のミス」と「ルールの欠如」にあったため、**人間による設定の見直しと運用ルールの整備**が必要です。

## 過去記事との関連

以前、「**悪意のあるSIMカードがIoT機器内部でハッカーのコードを実行できる**」という記事を紹介しました。あの記事では、SIMカード自体を悪用して携帯回線越しに機器を攻撃する手口を解説しました。

今回の事件はSIMカードそのものへの攻撃ではありませんが、**「携帯電話回線（セルラーネットワーク）を経由したインフラへの攻撃」**という点で同じ方向性の脅威です。産業用機器では、有線ではなく携帯回線で遠隔管理するケースが増えており、その携帯回線がサイバー攻撃の入り口になるリスクが現実になったことを、この2つの記事は示しています。

また、先日紹介した「**GunraランサムウェアによるFortinetの脆弱性悪用**」の記事とも関連があります。今回の侵入でも **FortiGate（Fortinetの製品）** が風力発電所のファイアウォールとして使われており、そのVPNが侵入口になっています。重要インフラでよく使われる機器が繰り返し狙われている現状がわかります。

## 用語解説

| 用語 | 説明 |
|---|---|
| **CHP（コージェネレーション）プラント** | 電気と熱を同時に生産する発電所 |
| **APN（Access Point Name）** | 携帯データ通信の「出入り口」の名称。プライベートAPNは企業専用の閉じた携帯回線 |
| **VPN（仮想プライベートネットワーク）** | インターネット上に作られた「専用の暗号化トンネル」。遠隔から社内ネットワークに安全に繋がるために使う |
| **MFA（多要素認証）** | パスワード以外にスマホのコードなど複数の確認を求めるセキュリティ手法 |
| **クライアント分離** | 同じネットワーク内の機器同士が互いに通信できないようにする設定 |
| **FortiGate** | Fortinet社のファイアウォール兼ルーター機器。企業・インフラ向けに広く普及 |
| **Teltonika RUTX50** | 産業用途向けの携帯回線対応ルーター |
| **WAGOコントローラー（PFC200）** | 工場・発電所などの機械を制御するコンピュータ |
| **DNP3.0** | 電力・水道などのインフラ向けに使われる通信プロトコル（規格） |
| **SSH（Secure Shell）** | ネットワーク越しに機器をリモート操作するための仕組み |
| **CVE** | 発見されたソフトウェアの脆弱性に付けられる公式番号 |
| **OT（運用技術）** | 工場や発電所の機械を動かす制御システム全般のこと |
| **デフォルトパスワード** | 機器を購入した時点から設定されている初期パスワード。変更せずに使うのは非常に危険 |

---

> 🔑 **今回の教訓をひとことで言うと**：「安全なはずの専用回線も、内部の設定が甘ければ攻撃の道になる。パスワードの変更と、ネットワーク内の機器の分離は、インフラを守る最低限のルール。」
