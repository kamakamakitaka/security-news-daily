# USBを差すだけでWindowsを乗っ取れる？研究者が発見した新しい攻撃手法

**元記事**: [Researchers Turn USB Auto-Install Into a Full SYSTEM Takeover on Windows 11](https://inl03.netline.com/ltr6/?_m=3n.009a.4053.sp0ao46r89.33yu)
**解説日**: 2025年8月12日

---

## 背景知識

今回の記事を理解するために、いくつかの重要な概念を先に説明します。

### 🔌 プラグアンドプレイ（Plug and Play / PnP）とは？
USBメモリやマウス、キーボードをパソコンに差し込むと、自動的に認識されて使えるようになりますよね？あの「差すだけで動く」仕組みのことです。Windowsはデバイスを差し込むと、インターネット（Windows Update）から自動的にドライバ（機器を動かすためのソフト）を探してインストールしてくれます。

### 🛡️ SYSTEMとは？
Windowsには「ユーザーの権限レベル」があります。
- **一般ユーザー**: 自分のファイルだけ触れる（学校の生徒のイメージ）
- **管理者（Administrator）**: パソコン全体の設定を変えられる（先生のイメージ）
- **SYSTEM**: Windowsのシステムそのもの。管理者よりもさらに上の、最強の権限（校長先生どころか学校の建物そのものを支配するイメージ）

**SYSTEM権限を奪われると、パソコン上で何でもできてしまいます。**

### 🎭 デバイスのエミュレーションとは？
本物のUSB機器を使わずに、ソフトウェアで「この機器が接続された」と偽る技術です。まるで変装して別人のふりをするようなものです。

---

## 何が起きたのか

セキュリティ研究者のアレハンドロ・エルナンドさんとボルハ・マルティネスさんが、**完全にアップデートされた最新のWindows 11**に対して、以下のことを証明しました。

> 「USBデバイスの自動インストール機能を悪用すれば、一般ユーザーの権限しかない攻撃者でも、最強のSYSTEM権限を乗っ取れる」

この研究は「**Plug And Pwn**（差してPwnる＝ハックする）」というタイトルで、世界最大のハッカー会議の一つ **DEF CON 34** で発表されました。

---

## 技術的な詳細

攻撃のルートは2種類あります。図で整理してみましょう。

### ルート①：物理的なUSBを使った攻撃

```
【攻撃の流れ】

STEP 1: 偽のSierra Wirelessデバイスを接続
         ↓
         Windowsが自動的に「SwiService.exe」をインストール
         （これは本物のソフトだが、SYSTEM権限で動く）
         
STEP 2: DNSを乗っ取る
         ↓
         「DNS」＝インターネットの住所帳のようなもの
         攻撃者がこれを書き換えると、通信を好きな場所に誘導できる
         
STEP 3: 偽のSony FeliCaリーダーを接続
         ↓
         ソフトウェアが「暗号化なし（HTTP）」でファイルを取得しようとする
         ↑ここが危ない！STEPで乗っ取ったDNSを使って
           悪意のあるファイルを代わりに送り込む
           
STEP 4: 「パストラバーサル」の脆弱性を悪用
         ↓
         「パストラバーサル」＝本来アクセスできないフォルダに
         抜け道を使って侵入する攻撃
         Windowsの核心部分「System32フォルダ」に
         悪意のあるDLLファイルを置くことができる
         
STEP 5: 再びSierra Wirelessデバイスを接続
         ↓
         植え付けたDLLが読み込まれ、SYSTEM権限を奪取！ 🎉（攻撃者視点）
```

### ルート②：リモートデスクトップ経由の攻撃

**リモートデスクトップ（RDP）** とは、離れた場所からインターネット越しにパソコンを操作する機能です（テレワークなどで使われます）。

```
【攻撃の流れ】

・物理的なUSBの代わりに、偽のUSB信号をRDP経由で送信
・偽のIntel RealSenseカメラのふりをする
         ↓
・RealSenseのソフトがインストールされる
         ↓
・「DLLハイジャック」で悪意のあるプログラムを読み込ませる
  （DLLハイジャック＝Windowsが読み込むべきファイルを
   悪意のある偽物にすり替える攻撃）
         ↓
・SYSTEM権限を奪取！
```

⚠️ ただし、このリモート攻撃は**デフォルト設定では使えない機能をONにしている場合のみ**有効です。

## なぜ重要なのか

### ✅ 重要なポイントをまとめると...

| 項目 | 内容 |
|------|------|
| **対象OS** | 完全アップデート済みのWindows 11 |
| **必要な権限** | 一般ユーザー権限のみ（特別な権限不要） |
| **攻撃結果** | 最強のSYSTEM権限を奪取 |
| **悪用される機能** | Windowsの正規の機能（PnP） |

### 🚨 特に怖いポイント

1. **正規のドライバ・ソフトを悪用している**
   → ウイルス対策ソフトが検知しにくい可能性があります

2. **Windows自身の仕組みを逆手に取っている**
   → すぐにパッチ（修正プログラム）を出しにくい

3. **企業・学校・官公庁のPCが狙われる可能性**
   → 特にリモートワーク環境で複数のPCが接続されている場合

## 対策・今後の展望

### 🛡️ 一般ユーザー向けの対策

1. **知らないUSBデバイスを差し込まない**
   落ちていたUSBメモリや、見知らぬ人から渡されたUSBは絶対に使わないようにしましょう

2. **Windowsを常に最新の状態に保つ**
   今後、Microsoftが修正プログラムを出す可能性があります

### 🔧 企業・IT管理者向けの対策

1. **リモートデスクトップのUSBリダイレクト機能を無効化する**
   Microsoftも「デフォルトではオフ」と説明しており、不要なら無効のままにしておくべき

2. **デバイスインストール制限ポリシーを設定する**
   WindowsにはどのUSBデバイスを許可するか制限する機能があります。これを活用して「承認済みデバイス以外はインストール不可」に設定しましょう

3. **ゼロトラストの考え方を導入**
   「社内ネットワークだから安全」ではなく、すべての接続を疑う姿勢が重要です

### 📅 今後の動向

- MicrosoftはこのルートをRemote Desktopでは「デフォルトで無効」としており、現時点で緊急パッチは出ていません
- Sierra Wireless・Sony・Intelの各ソフトウェアへの対応が今後注目されます
- DEF CONでの発表を受け、各ベンダーが対応を検討中とみられます

## 用語解説

| 用語 | 意味 |
|------|------|
| **プラグアンドプレイ（PnP）** | USBなどを差すだけで自動認識される仕組み |
| **SYSTEM権限** | Windowsで最も強い操作権限 |
| **ドライバ** | ハードウェアをOSで動かすためのソフトウェア |
| **エミュレーション** | 本物のハードウェアをソフトウェアで偽装すること |
| **DNS** | インターネットの住所帳（ドメイン名をIPアドレスに変換する仕組み） |
| **DNSリダイレクト** | DNSを書き換えて通信を別の場所に誘導する攻撃 |
| **パストラバーサル** | 本来アクセスできないフォルダに抜け道を使って侵入する攻撃 |
| **DLLハイジャック** | プログラムが読み込むべきファイルを悪意のある偽物にすり替える攻撃 |
| **System32** | Windowsの重要なシステムファイルが格納されているフォルダ |
| **RDP（リモートデスクトップ）** | 遠隔からパソコンを操作する機能 |
| **DEF CON** | 世界最大級のハッカー・セキュリティ研究者の会議（米国ラスベガスで開催） |
| **Living off the Land** | OSや正規ソフトの機能を悪用して攻撃する手法 |

---

> 💡 **まとめ**：今回の発見は「Windowsの便利な機能が、使い方次第では武器になる」ことを示しています。すぐにパニックになる必要はありませんが、**知らないUSBを差さない**・**システムを常に最新に保つ**という基本的な習慣が、こうした高度な攻撃からも身を守る第一歩になります。
