# マイクロソフト、398件の脆弱性を修正！すでに攻撃に使われているWindowsの欠陥も含まれる

**元記事**: [Microsoft Patches 398 Flaws Including a Windows Driver Zero-Day Under Active Attack](https://inl03.netline.com/ltr6/?_m=3n.009a.4054.sp0ao46r89.340k)
**解説日**: 2026年8月12日

---

## 背景知識

まず、このニュースを理解するために必要な基本知識をおさえておきましょう。

### 🗓️ 「月例パッチ」って何？
マイクロソフトは毎月第2火曜日（日本時間では水曜日）に、Windowsなどの自社製品の「バグ修正プログラム（パッチ）」をまとめて公開しています。これを「月例パッチ」や「Patch Tuesday（パッチチューズデー）」と呼びます。家のドアの鍵穴が壊れていたら鍵師に直してもらうように、ソフトウェアの「穴」を塞ぐ作業です。

### 🔑 「ゼロデイ脆弱性」って何？
「脆弱性（ぜいじゃくせい）」とは、ソフトウェアの欠陥（バグ）のことで、攻撃者に悪用される可能性があるものを指します。その中でも**「ゼロデイ脆弱性」**は特に危険で、「メーカーがまだパッチを出していないのに、すでに攻撃に使われている欠陥」のことです。"ゼロデイ"とは「対策できる日数がゼロ」というイメージです。

### 🏛️ 「カーネル」って何？
Windowsの中心部にある、コンピュータ全体を管理する超重要なプログラムです。OSの「司令塔」とも言えます。カーネルに関係する脆弱性は特に危険です。

### 📊 「CVSSスコア」って何？
脆弱性の危険度を**0〜10点**で表したスコアです。10点に近いほど危険で、一般的に7.0以上は「高危険度」、9.0以上は「緊急レベル」とされています。

### 👑 「SYSTEM権限」って何？
Windowsで最も強力な権限のことです。管理者アカウントよりもさらに上の「神様レベル」の権限で、これを取られるとコンピュータ上のすべての操作が攻撃者に可能になります。

---

## 何が起きたのか

今月（2026年8月）、マイクロソフトが月例パッチを公開しました。今回は**合計398件もの脆弱性を修正**しており、そのうち62件が最高危険度の「Critical（緊急）」に分類されています。

特に注目すべきポイントは以下の4つです：

| 注目ポイント | 内容 |
|---|---|
| ① すでに攻撃に使われているゼロデイ | CVE-2026-68820（危険度7.0） |
| ② 誰でも攻撃できる超危険な穴が4つ | 危険度9.8の脆弱性×4件 |
| ③ SharePointの攻撃チェーンが完成 | 7月・8月の2段階修正が完了 |
| ④ 北朝鮮ハッカー集団が関与 | 「Lazarus（ラザルス）」グループが悪用 |

## 技術的な詳細

### 🚨 ① すでに攻撃されているゼロデイ：CVE-2026-68820

**危険なドライバーに「解放済みメモリの再利用」という欠陥**

`afd.sys`（エーエフディー・システム）というファイルに問題があります。これは「WinSock用補助機能ドライバー」と呼ばれ、Windowsがインターネット通信を行うときの重要な部品です。

この脆弱性には**「Use-After-Free（ユーズ・アフター・フリー）」**という欠陥が含まれています。

> **Use-After-Freeをわかりやすく説明すると…**
> 図書館で本を借りて返却した後、その本が別の人に貸し出されているのに、あなたがまた勝手にその本棚の場所を使ってしまうようなイメージです。コンピュータでは、一度「使い終わった」と解放したメモリ領域を、誤って再び参照・操作してしまうことで、プログラムが予期しない動作をします。

さらに**「レースコンディション」**という仕組みを使って攻撃が成立します。

> **レースコンディションをわかりやすく説明すると…**
> 2人が同時に同じドアを開けようとしたとき、タイミングによっては両方が「自分が開けた」と思い込むような状態です。コンピュータでも複数の処理が同時に走るとき、タイミングの隙をついて不正な操作を行います。

この欠陥を悪用されると、攻撃者がすでにそのパソコンで普通のユーザーとして動いているプログラムを、一気に**「SYSTEM（最高権限）」レベル**に昇格させることができます。

**🇰🇵 北朝鮮のハッカー集団「Lazarus（ラザルス）」が悪用**

セキュリティ企業「Check Point Research」の調査によると、この脆弱性は北朝鮮と関係があるとされるハッカー集団「**Lazarus（ラザルス）**」が「**Operation Dream Job（ドリームジョブ作戦）**」という攻撃キャンペーンで使っていたことがわかっています。

> 「Operation Dream Job」とは、転職サイトや採用担当者を装ってターゲットに近づき、マルウェア（悪意のあるプログラム）を仕込む攻撃手法です。「夢の仕事を紹介します」という偽のメッセージで誘い込むことからこの名前がつきました。

---

### ⚡ ② 誰でも攻撃できる「認証不要」の4つの超危険な穴（CVSSスコア9.8）

これらは「**認証不要のリモートコード実行（Unauthenticated RCE）**」と呼ばれる非常に危険な脆弱性です。

> **認証不要のRCEとは…**
> 鍵（パスワード）も暗証番号も必要なく、外から壁をぶち破って家の中を自由に動き回れるような攻撃です。被害者が何かをクリックする必要すらありません。

| CVE番号 | 対象 | 特徴 |
|---|---|---|
| CVE-2026-62878 | Windows DNSサーバー | 「ワーム化」可能な可能性あり |
| CVE-2026-62893 | Windows展開サービス（WDS） | TFTPという通信を悪用 |
| CVE-2026-62815 | Microsoft QUIC | 次世代通信プロトコルの欠陥 |
| CVE-2026-59124 | HPCパック | デフォルトでは未インストール |

特に**CVE-2026-62878**（Windows DNSサーバー）は「**ワーム化**」の可能性があると指摘されています。

> **「ワーム化」とは…**
> ウイルスが人から人へとうつる感染症のように、コンピュータからコンピュータへと自動的に広がっていく攻撃のことです。「WannaCry（ワナクライ）」のように世界中に一気に広まった過去の事例があります。

---

### 🔗 ③ SharePointの攻撃チェーンが完成

**2段階の修正がついに完了**

セキュリティ企業「Rapid7 Labs」が2026年5月18日に、**2つの脆弱性を組み合わせる攻撃チェーン**をマイクロソフトに報告しました。

攻撃の流れはこうです：

```
①「認証バイパス」で管理者になりすます
        ↓
②「コード実行」でサーバーを乗っ取る
        ↓
完全な侵害の完成！
```

> **「認証バイパス」とは…**
> 本来ログインが必要なシステムに、パスワードなしで侵入できる欠陥です。守衛さんを無視して建物に入るようなイメージです。

マイクロソフトはこの修正を2回に分けて実施しました：
- **7月**：認証バイパスの部分（CVE-2026-55040）を修正
- **8月**：コード実行の部分（CVE-2026-63520）を修正

オンプレミス（自社サーバー）でSharePointを使っている場合は、**7月と8月の両方のパッチを必ず適用**する必要があります。

## なぜ重要なのか

### 📌 今回のパッチが特に重要な3つの理由

**1️⃣ 規模が巨大**
398件という数は非常に多く、Windowsを使っているほぼすべての組織・個人に影響する可能性があります。

**2️⃣ 国家レベルの攻撃者がすでに動いている**
Lazarusは北朝鮮政府と関係があるとされる、世界トップクラスのハッカー集団です。単なる愉快犯ではなく、組織的・戦略的に動いている点が脅威です。

**3️⃣ 「何もしなくていい」攻撃が4つもある**
通常のサイバー攻撃は「悪意のあるメールを開く」などの被害者の行動が必要ですが、今回の4つの9.8スコア脆弱性は**被害者が何もしなくても攻撃できます**。これは非常に危険な状態です。

## 対策・今後の展望

### ✅ 今すぐやるべきこと

**個人ユーザーの場合：**
1. **Windows Updateを今すぐ実行する**
   - スタートメニュー → 設定 → Windows Update → 更新プログラムの確認
2. 更新後は**必ず再起動**する（再起動しないとパッチが適用されないことがある）

**企業・組織の場合（優先順位）：**

```
最優先 ▶ CVE-2026-68820（すでに攻撃されている！）
  ↓
次に優先 ▶ 9.8スコアの4つ（RCE脆弱性）
  ↓
SharePoint利用組織 ▶ 7月・8月の両パッチを確認
```

### 🔍 パッチを当てるだけでは不十分？

脆弱性の中には「そのサービスを使っていなければ影響なし」というものもあります。たとえばHPCパック（CVE-2026-59124）はデフォルトでインストールされていないため、使っていない組織には関係ありません。**自分の組織でどのサービスが動いているかを把握すること**がセキュリティの基本です。

## 過去記事との関連

以前、「**ShieldBreak ゼロデイ攻撃：WindowsのMicrosoft Defenderのパッチが突破された**」という記事を解説しましたが、今回の記事はさらに深刻な状況を示しています。

前回はWindows Defenderというセキュリティソフト自体が狙われる話でしたが、今回はOSの**カーネル（核心部分）**が直接攻撃されています。しかも、Lazarusという国家レベルの攻撃集団が関与していることから、**Windowsの深い部分を標的にした攻撃が立て続けに発生している**という流れが見えてきます。

また「**企業の防御：外壁は回復したが、内側は崩壊していた**」という記事でも触れたように、今回のゼロデイもまさに「内側（権限昇格）」を狙うものです。外からの侵入は防げても、内部での動きを止めることが今のセキュリティの最大の課題であることが、改めて浮き彫りになっています。

## 用語解説

| 用語 | 意味 |
|---|---|
| **脆弱性（ぜいじゃくせい）** | ソフトウェアの欠陥・穴のこと |
| **ゼロデイ脆弱性** | パッチが出る前にすでに攻撃に使われている脆弱性 |
| **CVE** | 脆弱性を識別するための番号（Common Vulnerabilities and Exposures） |
| **CVSSスコア** | 脆弱性の危険度を0〜10で表したスコア |
| **カーネル** | OSの中心部分。コンピュータ全体を管理する |
| **SYSTEM権限** | Windowsで最も強い権限。管理者より上 |
| **権限昇格** | 低い権限から高い権限に不正に移行すること |
| **Use-After-Free** | 解放済みのメモリを誤って再利用するバグ |
| **レースコンディション** | 複数の処理の「タイミングの隙」を突く攻撃手法 |
| **RCE（リモートコード実行）** | 遠隔からコンピュータ上で好きな命令を実行できる攻撃 |
| **認証バイパス** | パスワードなしにシステムへ侵入できる欠陥 |
| **ワーム** | 自動的に他のコンピュータへ広がるマルウェア |
| **Lazarus（ラザルス）** | 北朝鮮と関係するとされる国家レベルのハッカー集団 |
| **afd.sys** | WindowsのネットワークI/Oを担当するカーネルドライバー |
| **SharePoint** | マイクロソフトが提供する企業向け情報共有サービス |
| **DNS** | ドメイン名（例：google.com）をIPアドレスに変換する仕組み |
| **QUIC** | Googleが開発した高速インターネット通信プロトコル |
| **HPC Pack** | 科学技術計算などに使うマイクロソフトの高性能計算ソフト |
| **オンプレミス** | 自社のサーバーで運用する方式（クラウドの対義語） |
