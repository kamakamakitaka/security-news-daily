# 北朝鮮のIT工作員が企業や政府機関に潜入している！採用前に見抜く方法とは？

**元記事**: [North Korean Remote Workers Are Infiltrating Government and Businesses: How to Expose Them Before Hiring](https://inl03.netline.com/ltr6/?_m=3n.009a.4055.sp0ao46r89.341a)
**解説日**: 2025年8月14日

---

## 背景知識

このニュースを理解するために、まずいくつかの背景知識を押さえておきましょう。

### 🌐 リモートワークとセキュリティ
コロナ禍以降、「在宅勤務（リモートワーク）」が当たり前になりました。エンジニアやプログラマーなら、世界中どこにいても仕事ができます。これは便利な反面、**「本当にその人が採用した人なのか確認しにくい」** という問題を生みます。

### 🇰🇵 北朝鮮のIT工作員とは？
北朝鮮（DPRK）は、国家として外貨（外国のお金）を稼ぐために、優秀なプログラマーを世界中の企業に「偽の身分」で就職させているといわれています。稼いだお金は、核兵器開発などに使われると言われており、FBI（アメリカの連邦捜査局）も深刻な脅威として警告しています。

> 🏫 **たとえ話**: 映画のスパイ映画みたいに、偽のパスポートと履歴書を使って一般企業に「普通の社員」として潜り込むイメージです。

### 🦅 ラザルスグループとは？
北朝鮮の国家が支援するとされるハッカー集団です。過去に銀行や暗号通貨取引所から数千億円を盗んだとされており、世界で最も危険なサイバー犯罪集団の一つです。

### 🖥️ サンドボックスとは？
本物のコンピューターに影響を与えずに、怪しいプログラムや活動を「安全な隔離された環境」で観察できる仕組みです。まるで「ガラス張りの実験室」のようなものです。

## 何が起きたのか

### 事件の概要

セキュリティ研究者たちが、**わざと北朝鮮のIT工作員を「採用」して、その行動を監視するという調査**を実施しました。

```
調査の流れ（簡単に）

① 研究者が求人を出す
      ↓
② 北朝鮮工作員が応募・面接・採用される
      ↓
③ 「普通のパソコン」に見せかけた監視用サンドボックスを渡す
      ↓
④ 工作員の行動をリアルタイムで記録・分析
      ↓
⑤ 正体・手口・使用ツールを全部バレる！
```

この調査により、工作員が使う**偽の身分証明書・遠隔操作ツール・AIの活用方法・VPN（場所を隠す技術）** などが明らかになりました。

さらに衝撃的なのは、**FBIがアメリカの連邦政府機関（お役所）で働いていた北朝鮮工作員を現在捜査中**だという点です。もはや「民間企業だけの問題」ではなくなっています。

## 技術的な詳細

### 🎭 工作員はどうやって潜り込むのか？

工作員は以下のステップで企業に侵入します。

| ステップ | 内容 |
|---------|------|
| **①偽の身分作成** | 他人の情報を盗んだり、AIで偽造した書類を用意 |
| **②応募・面接** | AIツールを使いながらリアルタイムで回答（カメラの外をちらちら見る） |
| **③採用・アクセス権取得** | 正規の社員として会社のシステムに入る |
| **④情報収集・資金調達** | ソースコード・機密情報を盗む、暗号通貨を送金する |

### 🚩 採用前に気づける「危険サイン」

研究者が発見した「怪しいサイン」をまとめると：

**📄 書類関係**
- 住所・州・証明書・銀行情報がバラバラで矛盾している
- IDがAIで改ざんされた痕跡（画像の不自然さ、メタデータの異常）

**🎥 面接中の行動**
- カメラの外をよく見る（AI/翻訳ツールで答えを確認している）
- 返答が不自然に遅れる
- リアルタイムの翻訳やAIツールへの依存が見える

**📍 場所の矛盾**
- 「東京在住」と言っているのに、ネットワークの接続元がまったく別の国

> 🏫 **たとえ話**: 「自分は大阪出身です」と言っているのに、LINEのIPアドレスがアメリカから、というような矛盾が複数重なるイメージです。

### 🔬 研究者が使った監視手法（サンドボックス環境）

研究者は工作員に**「普通の仮想デスクトップ」に見せかけた監視環境（ANY.RUNサンドボックス）**を与えました。

```
工作員が見ていたもの：普通のパソコン画面
研究者が見ていたもの：工作員が開くファイル・使うツール・
                    アクセスするサイト・送るデータ
                    ……すべてリアルタイムで記録！
```

これにより、工作員が実際に使っているツールやインフラが丸裸になりました。

## なぜ重要なのか

### 💥 従来の攻撃との決定的な違い

```
従来のサイバー攻撃
外部の攻撃者 → 壁（セキュリティ対策）→ 侵入しようとする

北朝鮮工作員の手口
採用担当者 → 面接・採用 → 正規の社員として壁の「内側」へ
```

どれだけ強いセキュリティの「壁」を作っても、**「正規の社員」として中に入られたら意味がない**のです。これが最も怖い点です。

### 🌍 影響範囲

- **アメリカ政府機関**：すでに実被害が確認・捜査中
- **IT企業・スタートアップ**：リモートエンジニアを多く採用する企業は特に危険
- **日本企業も他人事ではない**：グローバルに採用活動をする企業はリスクあり

---

## 対策・今後の展望

### ✅ 企業・採用担当者ができること

**1️⃣ 書類だけで信用しない・複数の情報で本人確認**
- 書類・面接態度・所在地・職歴・銀行情報が「一致しているか」を複数の視点でチェック
- ソースコードや社内システムにアクセスできる重要ポジションは特に厳しく審査する

**2️⃣ 面接で不審な行動を見逃さない**
- ビデオ面接で「画面外をよく見ていないか」チェック
- 急に応答が止まったり、翻訳ツールを使っている雰囲気がないか確認

**3️⃣ サンドボックスを使った安全な検証**
- 怪しいファイルやリンクを安全な隔離環境で開いて確認する仕組みを整える

**4️⃣ 入社後もモニタリング**
- 採用して終わりではなく、入社後のネットワーク通信・アクセスログを継続監視する

### 🔭 今後の展望
AIが発展するほど、偽造書類の精度も上がります。**「疑わしければ複数の方法で確認する」** という文化をIT部門・人事部門が一緒に持つことが、今後ますます重要になるでしょう。

## 過去記事との関連

以前、**「WindRelayマルウェア」** について解説しました。あの記事では、スマートフォンをNFCリレー（ニセのカードリーダー）として悪用し、金銭を騙し取るマルウェアを紹介しました。

今回の北朝鮮工作員の話と共通するのは、**「正規のもの・正規の人に見せかけて内側から攻撃する」** という発想です。

```
WindRelay  ：本物のスマホを、偽のカードリーダーに見せかける
北朝鮮工作員：本物の社員に見せかけて、会社の内部に入り込む
```

攻撃者はどんどん「外から壁を破る」のではなく、**「内側に紛れ込む」手口**に移行しています。この流れを理解しておくと、今後のセキュリティニュースがよりスムーズに理解できるようになります。
