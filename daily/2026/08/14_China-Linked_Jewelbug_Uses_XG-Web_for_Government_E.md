# 中国系ハッカー集団「Jewelbug」が政府スパイ活動と仮想通貨詐欺を同時展開

**元記事**: [China-Linked Jewelbug Uses XG-Web for Government Espionage and Crypto Fraud](https://inl03.netline.com/ltr6/?_m=3n.009a.4056.sp0ao46r89.343i)
**解説日**: 2025年7月14日

---

## 背景知識

このニュースを理解するために、いくつかのキーワードを先に説明しておきます。

### 🔑 「脅威アクター」って何？
サイバー攻撃を行う個人・グループのことです。国が背後にいる場合は「国家支援型ハッカー」とも呼ばれます。

### 🔑 「サイバースパイ（スパイ活動）」って何？
軍事機密や政府の内部情報を、インターネット経由でこっそり盗み出す活動のことです。昔は人間のスパイが行っていたような情報収集を、コンピューターでやるイメージです。

### 🔑 「ブラウザ拡張機能」って何？
ChromeやFirefoxに追加できる小さなプログラムです。広告ブロッカーや翻訳ツールなどが代表例ですが、悪意ある拡張機能も存在します。

### 🔑 「C&C（コマンド＆コントロール）」って何？
攻撃者がウイルスや不正プログラムに命令を送ったり、盗んだ情報を受け取ったりするための「司令塔サーバー」のことです。

### 🔑 「仮想通貨クリッパー」って何？
コピペした仮想通貨のウォレットアドレス（振込先のような番号）を、攻撃者のアドレスにこっそり書き換えるマルウェアです。気づかずに送金すると、お金が攻撃者の口座に入ってしまいます。

---

## 何が起きたのか

セキュリティ大手 **Broadcom（ブロードコム）のSymantecチームとCarbon Blackチーム**が、「**Jewelbug（ジュエルバグ）**」と呼ばれる中国系ハッカー集団の活動を詳しく調査し、その全貌を発表しました。

この集団のポイントは、**2つの全く異なる目的のサイバー攻撃を、同じシステムで同時に運営している**という点です。

| ターゲット | 目的 |
|---|---|
| 中東・東南アジア・南アジアの政府・軍 | 国家スパイ活動（機密情報の窃取） |
| 中国語を話す仮想通貨ユーザー | お金目的の詐欺・窃取 |

さらに、2025年10月には**ロシアのITサービス会社**へも5ヶ月にわたる侵入攻撃を行ったことが明らかになっています（味方のはずの国も標的にする、したたかな集団です）。

調査では、**南アジアの警察・政府機関のメールアドレスが90件以上**リストアップされていたことも判明しており、スパイ活動の規模の大きさがわかります。

## 技術的な詳細

### 🕹️ 司令塔ツール「XG-Web」

Jewelbugの中心にあるのが、**「XG-Web」**というシステムです。

> 🏠 家の例え話
> XG-Webを「泥棒の本部ビル」に例えると、ビルの中には「スパイ部門」と「詐欺部門」が同居していて、共通の被害者データベースを使い回しているイメージです。

技術的には以下の構成です：

- **フロントエンド**：React（Webアプリの画面を作る技術）
- **バックエンド**：Node.js（サーバー側のプログラム）
- **データベース**：MySQL（情報を保存する仕組み）

表向きは「ペネトレーションテスト（正規のセキュリティ診断）ツール」と名乗っていますが、実態は完全な攻撃用ツールです。

---

### 🔍 発覚を避けるための工夫

Jewelbugは、警察やセキュリティ会社に見つかりにくくするために様々な工夫をしています：

| 工夫 | 説明 |
|---|---|
| **12時間ごとの自動チェック** | 自分たちのC&Cサーバーが「VirusTotal（ウイルス検出サービス）」で検知されていないか自動確認し、危なくなったらすぐ乗り換える |
| **Googleドキュメントを悪用** | 正規のGoogleのサービスにウイルスコードを隠して配布（怪しいサイトに見えにくい） |
| **XOR暗号化** | 毎回異なるランダムキーでコードを暗号化し、同じものが2つ存在しないようにして検知を回避 |
| **偽装ドメイン名** | C&Cサーバーのアドレスを「Google Fonts」など有名サービスに似せた名前にする |

---

### 🦠 主要マルウェア：偽「PDF Viewer」拡張機能

最も重要な攻撃ツールが、**「PDF Viewer」という名前の偽ブラウザ拡張機能**です。ChromeにもFirefoxにも対応しています。

インストールされると、以下の情報がすべて筒抜けになります：

```
✅ Cookieの盗み取り（ログイン情報）
✅ ログインフォームへの入力内容（ID・パスワード）
✅ 閲覧履歴
✅ ブックマーク
✅ スクリーンショット
✅ クリップボードの内容（コピーしたテキスト）
✅ 通信内容（Webトラフィック）
✅ ダウンロードの監視
```

さらに、**クリップボードに仮想通貨のウォレットアドレスが入った瞬間、攻撃者のアドレスに自動で書き換える**「クリッパー機能」も搭載されています。

> 💸 具体例：
> あなたが「送金先アドレス：abc123...」をコピーして貼り付けたつもりが、気づかないうちに「送金先アドレス：攻撃者xyz987...」に書き換えられている状態です。

---

### 🌐 ネットワーク奥深くまで侵入

さらに恐ろしいのは、**LinuxサーバーやルーターへのマルウェアでC&C通信を社内プロキシ経由に通す**機能があり、**米国の大手航空宇宙・産業メーカーの社内ネットワーク**にまで触手を伸ばしている可能性が示されていることです。

## なぜ重要なのか

### 🌍 影響の広さ

- **被害地域**：中東・東南アジア・南アジア・ロシア・台湾・（間接的に）米国など
- **被害対象**：政府・軍・警察・一般の仮想通貨ユーザー

### 🎯 二刀流攻撃の危険性

通常、国家支援型ハッカーはスパイ活動のみ、犯罪集団はお金目的の攻撃のみを行います。しかし **Jewelbugはこの両方を1つのシステムで同時運営**しているという、非常に珍しく危険なグループです。

### 🏢 正規サービスを悪用

GoogleドキュメントやGoogleフォントに似せたドメインなど、**誰でも使っている正規サービスをカモフラージュに利用**しているため、セキュリティソフトでも発見しにくいという問題があります。

---

## 対策・今後の展望

### 👤 一般ユーザーができること

1. **ブラウザ拡張機能は公式ストアのみ・必要最小限に**
   - 知らない拡張機能は絶対にインストールしない
   - インストール時に「すべてのサイトのデータへのアクセス」を求めてくる拡張機能は要注意！

2. **仮想通貨の送金時はアドレスを必ず目視確認**
   - コピペした後、ペースト先のアドレスが正しいか最初と最後の数文字を確認する習慣を

3. **ブラウザの拡張機能を定期的に見直す**
   - 使っていない拡張機能は削除、見覚えのないものはすぐ削除

4. **怪しい仮想通貨取引所のサイトに近づかない**
   - 「偽の取引所ダウンロードサイト」が使われていたため、公式サイト以外からアプリをダウンロードしない

### 🏛️ 組織・企業レベルの対策

- ブラウザ拡張機能のインストールをポリシーで管理・制限する
- Googleドキュメントなどへの業務外アクセスを監視する
- 社内ネットワークのルーター・Linuxサーバーのログを定期確認する

### 🔮 今後の展望

Jewelbugは「5世代のC&Cコード」を開発しているなど、技術的に非常に高度で組織的です。中国湖南省の企業との関連も指摘されており、今後も国家レベルのバックアップを受けた攻撃が続く可能性が高いです。

## 過去記事との関連

今回の記事では、Jewelbugが**2025年10月にロシアのITサービス会社を5ヶ月間にわたって攻撃した**ことにも触れています。中国とロシアは表向き友好関係を保っていますが、サイバースパイの世界では「同盟国も標的になる」という現実が浮かび上がります。このような国家支援型ハッカーの活動は、単なる犯罪を超えた**地政学的なリスク**として注目されています。

## 用語解説

| 用語 | 意味 |
|---|---|
| **脅威アクター（Threat Actor）** | サイバー攻撃を行う個人・グループの総称 |
| **C&C（コマンド＆コントロール）** | 攻撃者がマルウェアに命令を送る司令塔サーバー |
| **ブラウザ拡張機能** | ChromeやFirefoxに追加できる小さなプログラム |
| **インプラント** | 標的のコンピューターに埋め込まれるスパイプログラム |
| **XOR暗号化** | 同じコードが2度と同じ形にならないようにする暗号化技術の一種 |
| **クリッパー（Clipper）** | クリップボードの内容を攻撃者が指定した内容に書き換えるマルウェア |
| **VirusTotal** | ファイルやURLがウイルスかどうか確認できる無料のオンラインサービス |
| **ペネトレーションテスト** | 正規のセキュリティ診断のこと（攻撃ツールの偽装に使われた名目） |
| **プロキシ** | 社内ネットワークとインターネットの間に置かれる中継サーバー |
| **React / Node.js / MySQL** | Webアプリを作るための有名な開発技術・データベース |
| **espionage（スパイ活動）** | 機密情報をこっそり盗む行為 |
| **ウォレットアドレス** | 仮想通貨の送金先を示す番号（銀行口座番号のようなもの） |

> 💡 **まとめポイント**
> Jewelbugは「政府スパイ」と「仮想通貨詐欺」という2つのビジネスを同じシステムで運営する、非常に組織化された中国系ハッカー集団です。偽のブラウザ拡張機能やGoogleサービスの悪用など、私たちの日常に近いところを攻撃ルートにしているため、**「怪しい拡張機能は入れない」「仮想通貨の送金先アドレスは目視確認」**という基本的な習慣が自分を守る第一歩です。
