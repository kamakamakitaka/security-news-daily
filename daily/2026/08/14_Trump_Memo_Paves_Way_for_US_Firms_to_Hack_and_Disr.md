# トランプ大統領の覚書：アメリカ企業が外国犯罪組織をハッキングできるようになる？

**元記事**: [Trump Memo Paves Way for U.S. Firms to Hack and Disrupt Foreign Crime Groups](https://inl03.netline.com/ltr6/?_m=3n.009a.4056.sp0ao46r89.3436)
**解説日**: 2025年8月15日

---

## 背景知識

このニュースを理解するために、いくつかの基本的な言葉と概念を確認しておきましょう。

### 🌐 トランスナショナル犯罪組織（TCO）とは？
「Transnational Criminal Organizations」の略で、**複数の国をまたいで活動する大規模な犯罪グループ**のことです。麻薬密売や人身売買だけでなく、最近はインターネットを使った詐欺やハッキングも行っています。たとえば、フィッシング詐欺メールを大量に送って個人情報を盗んだり、病院や企業のコンピュータを人質にとって身代金を要求する「ランサムウェア」攻撃なども、こうした組織が絡んでいることがあります。

### 🏛️ 「白い家（ホワイトハウス）の覚書」って何？
アメリカ大統領が署名する**公式な指示書・命令書**のことです。法律ではないのですが、政府機関への強力な指示として機能します。

### 🔒 「サイバー作戦」の2種類
記事には2種類の作戦が登場します：
- **サイバー監視作戦**：相手のシステムに侵入して情報を収集する（スパイ活動的なもの）
- **サイバー効果作戦**：相手のシステムを実際に妨害・破壊する（攻撃的なもの）

### 🏢 NCC（国家調整センター）とは？
アメリカのサイバーセキュリティに関する政府機関で、今回の取り組みを統括する役割を担います。

## 何が起きたのか

トランプ大統領が署名した新しい覚書によって、**アメリカの民間企業（一般の会社）が、政府の許可を得たうえで外国の犯罪組織のシステムにハッキングしたり、妨害作戦を行ったりできるようになる**プログラムが動き出すことになりました。

これまでは、ハッキングや妨害活動はアメリカの政府機関（軍やCIAなど）だけに認められていました。しかし今回の覚書により、審査を通過した民間企業も、政府の監督のもとで同様の活動を行えるようになります。

ターゲットになるのは：
- アメリカ政府、アメリカ市民、アメリカの国益に対してサイバー犯罪を行っている**外国の犯罪グループ**

具体的な犯罪の例として挙げられているのは：
| 犯罪の種類 | わかりやすく言うと |
|---|---|
| ランサムウェア | PCを人質にとって身代金を要求するウイルス |
| フィッシング | 偽メールや偽サイトでパスワードを盗む |
| 金融詐欺 | 偽の投資話などでお金を騙し取る |
| セクストーション | わいせつ画像などをネタに脅迫する |
| ピッグバッチャリング詐欺 | SNSで親しくなってから偽の投資に誘い込む詐欺 |
| なりすまし | 別人のふりをして詐欺をはたらく |

アメリカ市民はこうしたサイバー犯罪で、**推定208億ドル（約3兆円以上！）もの被害**を受けているとされています。

## 技術的な詳細

### どんな作戦が認められるの？

🔍 **サイバー監視作戦（情報収集型）**
> 相手の許可なく、犯罪組織のシステムに侵入してデータを集める

たとえば、犯罪組織が使っているサーバー（コンピュータ）に忍び込んで、誰がどんな犯罪をしているか調べるようなイメージです。

💥 **サイバー効果作戦（妨害・破壊型）**
> 犯罪組織のシステムやネットワークを、妨害・使用不能・劣化・破壊する

たとえば、詐欺グループが使っているウェブサイトや通信インフラを壊してしまい、犯罪が続けられないようにするイメージです。

### 歯止め（制限）はあるの？

ちゃんとルールも決められています：

- ✅ 政府の**承認を得た場合のみ**作戦を実行できる
- ❌ **アメリカ国内のシステムや、アメリカ人が管理するシステムは絶対に標的にしてはいけない**
- ⚠️ 許可された範囲を超えた場合は**即座に作戦を停止**し、NCCへ報告、さらに司法省（警察のような機関）への通知が義務づけられている

## なぜ重要なのか

### 1️⃣ 民間企業がサイバー攻撃に参加するのは異例中の異例

これまでの常識では「ハッキングは犯罪」でした。アメリカの既存の法律でも、民間企業が裁判所の許可なくサイバー攻撃や妨害活動をすることは**禁止**されています。今回の覚書は、その常識を大きく塗り替えようとしています。

セキュリティの専門家からは「**法的にも安全保障上のリスクがある**」と懸念の声が上がっています。なぜかというと...

- 民間企業がミスをして、**無関係な人や組織を攻撃してしまう**可能性がある
- 「政府公認のハッキング」が認められると、**他の国も同じことを始める**かもしれない（自国を守るため、という理由で）
- 「審査済み企業」が本当に信頼できるかどうかの保証が難しい

### 2️⃣ 被害額が桁違いに大きい

208億ドル（約3兆円）という数字は、日本の防衛予算の約半分に相当するほどの額です。それだけ深刻な問題だということがわかります。

### 3️⃣ 世界的な流れの一部

記事の最後には、**ドイツも同様に**自国の情報機関に対して「敵対的なサーバーの解体」「外国のサイバーネットワークへの妨害」「国家支援ハッカーへの報復ハッキング」を認める法案を可決したことが紹介されています。世界各国が「防御だけではなく、攻撃的な手段も使う」方向に向かっています。

## 対策・今後の展望

### 私たちへの影響は？

直接的には「民間企業が外国の犯罪組織を攻撃する」話なので、一般の人には関係ないように見えます。しかし、長い目で見ると：

- 🛡️ **よい面**：ランサムウェアや詐欺グループのインフラが壊されることで、被害が減る可能性がある
- ⚠️ **心配な面**：「民間企業によるハッキングが合法化された」という前例が、将来の悪用につながるかもしれない

### 今後のポイント

- NCCがどのような企業を「審査済み」として認定するのか
- 作戦が失敗した場合や誤爆した場合の責任の所在はどうなるのか
- 他の国がこれに反発して、サイバー攻撃を仕掛けてくる可能性はないか

これらは今後注目すべきポイントです。

### 私たちにできること

今回の話は政府レベルの話ですが、サイバー詐欺の被害を防ぐために個人でできることもあります：

1. 🔑 パスワードを使い回さない（できれば**パスワードマネージャー**を使う）
2. 📧 知らない人からのメールのリンクは絶対にクリックしない
3. 💰 SNSで知り合った人から投資を勧められたら要注意（ピッグバッチャリング詐欺）
4. 🔄 OSやアプリを常に最新の状態に保つ

## 用語解説

| 用語 | 解説 |
|---|---|
| **TCO（Transnational Criminal Organizations）** | 国境を越えて活動する大規模犯罪組織 |
| **覚書（メモランダム）** | 大統領が署名する政府への公式指示書 |
| **NCC（National Coordination Center）** | 今回のプログラムを管理するアメリカのサイバー関連政府機関 |
| **ランサムウェア** | コンピュータのデータを暗号化してロックし、解除と引き換えに身代金を要求する悪意あるプログラム |
| **フィッシング** | 偽のメールやウェブサイトを使ってパスワードや個人情報を騙し取る攻撃 |
| **セクストーション** | わいせつな画像や動画をネタに金銭を要求する脅迫 |
| **ピッグバッチャリング詐欺** | SNSなどで時間をかけて信頼関係を築き、最終的に偽の投資話に誘い込む詐欺（豚の丸焼き詐欺とも呼ばれる） |
| **サイバー監視作戦** | 相手の許可なくシステムに侵入して情報を収集する作戦 |
| **サイバー効果作戦** | 相手のシステムやインフラを妨害・破壊する攻撃的な作戦 |
| **司法省（Department of Justice）** | アメリカの法執行・司法を担当する省庁（日本の法務省＋警察庁に近い）|
| **最小化手続き（Minimization Procedures）** | 許可範囲を超えた活動をした場合に被害を最小限に抑えるための手順 |
