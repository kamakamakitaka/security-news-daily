# マスタングパンダが「署名済みルートキット」を使った高度なバックドアを展開

**元記事**: [Mustang Panda Adds Signed Windows Rootkit to CoolClient Backdoor for Stealth](https://inl03.netline.com/ltr6/?_m=3n.009a.4057.sp0ao46r89.344q)
**解説日**: 2025年7月17日

---

## 背景知識

このニュースを理解するために、いくつかの重要な概念を先に説明します。

### 🏴‍☠️ 「Mustang Panda（マスタングパンダ）」とは？
中国との関連が指摘されているサイバー攻撃グループです。「HoneyMyte（ハニーマイト）」という別名でも呼ばれています。政府機関や重要組織を標的にした**スパイ活動（サイバーエスピオナージュ）**を長年にわたって行っていることで有名です。

### 🪟 Windowsの「カーネル」って何？
Windowsというパソコンの基本ソフト（OS）は、大きく2つの層に分かれています。

```
┌─────────────────────────────┐
│  ユーザーモード              │ ← 普通のアプリ（ブラウザ、メモ帳など）が動く場所
│  (User Mode)                │   比較的制限が多い
├─────────────────────────────┤
│  カーネルモード              │ ← OSの心臓部。何でもできる最強の場所
│  (Kernel Mode)              │   ウイルス対策ソフトも監視が難しい！
└─────────────────────────────┘
```

**カーネル**とは、コンピュータの一番深いところで動くOSの核心部分です。ここで動くプログラムは、ほぼ**「神様」のような権限**を持っています。

### 🕵️ 「ルートキット」って何？
**ルートキット**とは、マルウェア（悪意のあるプログラム）の存在を隠すための技術です。たとえるなら：

> 泥棒が家に侵入した後、防犯カメラの映像を「何も映っていない画像」に書き換えてしまう道具のようなもの

セキュリティソフトがスキャンしても「何もない」と見えるようにしてしまいます。

### 📝 「デジタル署名」って何？
ソフトウェアに付けられる「このソフトは本物・安全ですよ」という電子的な証明書です。Windowsは、カーネルで動くドライバ（深い場所で動くプログラム）に**必ず署名が必要**というルールを設けています。

## 何が起きたのか

ロシアのセキュリティ企業**Kaspersky（カスペルスキー）**が、Mustang Pandaという攻撃グループが使う**「CoolClient」**というバックドア（裏口プログラム）の新しいバージョンを発見しました。

### 📌 主なポイント

- **被害を受けた国**: ミャンマー、モンゴル、パキスタン、ロシア
- **標的**: 政府機関など重要組織
- **新しい武器**: カーネルレベルで動作する「署名済みルートキット」の追加

今回の攻撃の流れをざっくりまとめると：

```
① PlugX（別のマルウェア）で最初に侵入
        ↓
② CoolClient（バックドア）を仕込む
        ↓
③ カーネルモードのルートキット（msagent.sys）を展開
        ↓
④ 完全に隠れた状態でスパイ活動を継続
```

## 技術的な詳細

### 🚪 Step 1: どうやって侵入するのか

攻撃者はまず**PlugX**というマルウェアを使って標的のパソコンに侵入します。その後、巧妙なトリックを使ってCoolClientを仕込みます。

**「DLLサイドローディング」という手口**
> 正規のソフト（Sangforという実在するセキュリティソフト）を使って、そこに悪意のあるDLL（プログラムの部品ファイル）を読み込ませる手法です。
>
> 例えると…「正規の宅配業者のトラックに、こっそり盗品を積み込む」ようなイメージ

さらに、**Microsoft Defender（Windowsのウイルス対策機能）の監視から除外**する設定まで追加して、検知を逃れます。

### 🔑 Step 2: 権限を最大化する

マルウェアは以下のような巧妙な手口で権限を高めます：

- **UACバイパス**: 「本当に実行しますか？」という確認画面を回避
- **PPID（親プロセスID）スプーフィング**: 「このプログラムは正規のプロセスから起動した」と偽装
- **SYSTEMレベルの権限取得**: Windowsで最も強い権限を持つ状態になる

### 🦠 Step 3: ルートキット（msagent.sys）の展開

これが今回の最大の新機能です！

```
CoolClient本体（ユーザーモード）
        ↕ IOCTL（命令のやりとり）
msagent.sys（カーネルモード・ルートキット）
```

**msagent.sys** というドライバが展開されます。このドライバができることは：

| 機能 | 内容 |
|------|------|
| プロセスの隠蔽 | 悪意のあるプログラムをタスクマネージャーから隠す |
| ファイルの隠蔽 | マルウェアのファイルをエクスプローラーから隠す |
| レジストリの隠蔽 | Windowsの設定データベースへの書き込みを隠す |
| 通信先の隠蔽 | 攻撃者サーバー（C2）への通信を隠す |

### 🖊️ 「署名済み」がなぜ危険？

このルートキットには、**「南京Ranyi Technology Co., Ltd.」**という中国企業名で発行された**デジタル証明書**が付いています（有効期間：2013年〜2014年）。

Windowsは「署名があるから安全」と判断してしまうため、インストールを許可してしまいます。

> 例えると…「偽造パスポートを使って空港のセキュリティを突破する」ようなイメージ

### 🎯 CoolClientで何ができるのか

| 機能 | 内容 |
|------|------|
| キーロギング | キーボードの入力をすべて記録（パスワードも！） |
| クリップボード窃取 | コピー＆ペーストした内容を盗む |
| 認証情報の収集 | IDやパスワードを収集 |
| ファイル管理 | ファイルの読み取り・送信・削除 |
| 偵察活動 | システム情報の収集 |
| プラグイン機能 | 追加機能を後から読み込める |

## なぜ重要なのか

### 1️⃣ 検知がほぼ不可能に近い
カーネルレベルで動作するため、一般的なウイルス対策ソフトでは**発見が非常に困難**です。「存在しないはずなのに攻撃されている」という状況が生まれます。

### 2️⃣ 政府機関が標的
今回の被害者には**確認された政府機関**が含まれています。外交機密や国家機密が狙われている可能性があります。

### 3️⃣ 古い証明書の悪用
2013〜2014年の証明書が現代の攻撃に使われています。古い証明書でも**Windowsが拒否しない**という問題点が浮き彫りになっています。

### 4️⃣ 多段階攻撃の高度化
PlugX → CoolClient → ルートキット という**3段階の攻撃**は、それぞれが補い合う非常に巧妙な構造です。

## 対策・今後の展望

### 組織・企業ができること

- ✅ **EDR（高度なエンドポイント検知・対応ツール）**の導入
  - 通常のウイルス対策ソフトより深いレベルで監視できるツール
- ✅ **カーネルレベルの監視**ができるセキュリティソフトの利用
- ✅ **PlugXなどの初期侵入を防ぐ**ための多層防御
- ✅ **Kasperskyが公開したIoC（侵害の痕跡）情報**を自組織のシステムで検索する
  - 具体的には `msagent.sys` というファイル名や、関連するハッシュ値を確認

### 一般ユーザーができること

- ✅ OSとソフトウェアを**常に最新の状態**に保つ
- ✅ 怪しいメールの添付ファイルを**絶対に開かない**
- ✅ 信頼できるセキュリティソフトを使う

### 今後の展望

Mustang Pandaグループは長年にわたり活動を続けており、今後も攻撃手法が進化し続けることが予想されます。特に「**署名済みドライバの悪用**」は今後の攻撃でも使われる可能性が高く、業界全体での対応が必要です。
