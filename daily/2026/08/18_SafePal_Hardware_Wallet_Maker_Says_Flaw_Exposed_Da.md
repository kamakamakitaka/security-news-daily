# SafePalハードウェアウォレットの情報漏えい：約4万人の顧客データが流出

**元記事**: [SafePal Hardware Wallet Maker Says Flaw Exposed Data of Nearly 40,000 Customers](https://inl03.netline.com/ltr6/?_m=3n.009a.4059.sp0ao46r89.3476)
**解説日**: 2025年7月

---

## 背景知識

まず、このニュースを理解するために必要なキーワードを説明します。

### 🔑 ハードウェアウォレットとは？
暗号資産（仮想通貨）を安全に管理するための**専用の物理デバイス**（USBメモリのような小型機器）です。スマホやパソコンと違ってインターネットに常時接続していないため、ハッキングされにくいのが特徴です。「金庫の鍵を金庫本体とは別の場所に保管する」イメージです。

### 🔑 SafePalとは？
ハードウェアウォレットを製造・販売する会社です。今回の事件はその会社のオンラインショップ（注文システム）で発生しました。

### 🔑 シードフレーズ・秘密鍵とは？
暗号資産の「マスターパスワード」のようなものです。これが漏れると、ウォレット内の資産を丸ごと盗まれる可能性があります。今回は**これは漏れていません**（後述）。

### 🔑 プラグインとは？
既存のシステムに「後付けで機能を追加するパーツ」です。ちょうどスマホのアプリと似ています。今回は注文の配送状況を確認するためのプラグインに問題がありました。

---

## 何が起きたのか

SafePalのオンラインショップで使われていた**注文追跡プラグイン**（荷物の配送状況を確認する機能）に**認可の欠陥（バグ）**が見つかりました。

この欠陥によって、本来は自分の注文情報しか見られないはずのシステムで、**他人の注文情報を見られる状態**になっていました。

### 漏えいしたデータの内容

| 項目 | 漏えいしたか？ |
|------|--------------|
| 氏名 | ✅ 漏えい |
| メールアドレス | ✅ 漏えい |
| 配送先住所 | ✅ 漏えい |
| 電話番号 | ✅ 漏えい |
| 購入内容の詳細 | ✅ 漏えい |
| ウォレットの資産・残高 | ❌ 漏えいなし |
| シードフレーズ・秘密鍵 | ❌ 漏えいなし |
| クレジットカード番号 | ❌ 漏えいなし |
| 銀行口座情報 | ❌ 漏えいなし |

影響を受けた顧客数は約**39,798人**で、対象となった注文は**2025年3月〜2026年4月**の間に行われたものです。

## 技術的な詳細

### 🔍 「認可の欠陥」って何？

少し難しいですが、例え話で説明します。

> **図書館で本を借りる場面**を想像してください。
> - 普通は「自分の貸し出し記録」しか見られません
> - しかし、システムのバグで「他の利用者のIDを入力するだけで、その人の貸し出し記録が見えてしまう」状態になっていたとします
> - これが「認可の欠陥」です

正式には「**アクセス制御の不備（Broken Access Control）**」と呼ばれる種類の脆弱性です。「あなたは自分の情報だけ見ていいですよ」というルールが正しく機能していなかった、ということです。

### 🔍 問題が長引いた2つの原因

**① プラグインのバグそのもの**
→ 他人の注文情報にアクセスできてしまう欠陥

**② データ削除プロセスの停止（別の問題）**
→ 本来は古い注文データを定期的に削除するはずのプログラムが、**2025年9月〜2026年4月の間、設定ミスで止まっていました**。
→ その結果、削除されるはずだった古いデータが残り続け、被害の範囲が2025年3月まで広がりました。

## なぜ重要なのか

### ⚠️ 「暗号資産ユーザー」は犯罪者に狙われやすい

ブロックチェーン分析会社の**Chainalysis**（チェイナリシス）によると、

- 2026年6月末時点で、世界で**46件の暴力的な事件**が記録されており、**3,000万ドル以上**が盗まれています
- フランスでは暗号資産保有者を狙った犯罪が2025年以前の数件から**2026年半ばまでに30件**に急増しています

なぜ狙われるのか？

> 「暗号資産は、一瞬で・取り消しができない形で送金できるため、犯罪者にとって非常に魅力的なターゲット」
> — Chainalysis

### ⚠️ 「住所＋名前＋暗号資産ユーザー」の組み合わせが危険

今回漏えいしたのは財務情報ではありません。しかし、**「この人は暗号資産を持っているし、家の住所もわかる」** という情報の組み合わせは非常に危険です。

- **フィッシング詐欺**（偽メール・偽電話）
- **偽の宅配業者**を名乗った訪問
- **最悪の場合、実際に自宅を訪れての強盗**

すでに5月の時点で、あるユーザーがSNSで「怪しいメール・手紙・電話がきた」と報告していました。

## 対策・今後の展望

### 📧 SafePalが送ったメール
2026年8月16日に `security@safepal.com` から件名 **「[Important] Your SafePal Order Information Has Been Affected」** というメールが送られました。

### 🛡️ SafePalが呼びかけている対策

> **「SafePalの購入に言及した予期しない連絡や荷物の配送は、電話・郵便・対面のいずれを問わず、怪しいと思ってください」**

具体的に注意すべき接触パターン：

- 📞 **詐欺電話**（カスタマーサポートや返金を装う）
- 📧 **フィッシングメール**（偽のファームウェア更新を求めるメールなど）
- ✉️ **怪しい手紙や荷物の配送**
- 💬 **SMS詐欺**

### 🔒 SafePal側の対応
- 7月から注文処理システムの**全面的な見直しと再構築**を開始
- 追加のセキュリティ保護措置を導入

### ⚠️ 注意：データがダークウェブで売られている可能性
犯罪者フォーラムで、今回と同じ「注文期間・顧客数」を示すデータセットが広告されていることが確認されています。つまり、漏えいしたデータがすでに不正に流通している可能性があります。

## 過去記事との関連

記事中に**Trezor（トレザー）**という別のハードウェアウォレットメーカーの名前が登場します。TrezorもSafePalの3日前に、配送業者「ShipMonk」でのデータ漏えいを公表していました。Trezorはすでに「90日間のデータ保存ポリシー」を導入していたため、被害範囲が限定的でした。

ハードウェアウォレットメーカーが相次いで**「ウォレット本体ではなく、ショッピングシステム側」**でデータを漏えいさせていることは注目すべきトレンドです。「デバイス自体は安全でも、買い物する過程で個人情報が危険にさらされる」というリスクを改めて示しています。

## 用語解説

| 用語 | 意味 |
|------|------|
| **ハードウェアウォレット** | 暗号資産を管理する物理デバイス（USBのような機器） |
| **認可の欠陥（Broken Access Control）** | 「この人はここだけ見ていい」というルールが機能していないバグ |
| **シードフレーズ** | ウォレットを復元するための12〜24個の単語からなる「マスターキー」 |
| **秘密鍵（プライベートキー）** | 暗号資産の送金を承認するための暗号。漏れると資産を盗まれる |
| **プラグイン** | 既存システムに機能を追加する拡張パーツ |
| **フィッシング** | 本物を装った偽の連絡で、個人情報や資産を騙し取る詐欺 |
| **CVE識別子** | セキュリティの脆弱性に付けられる国際的な管理番号 |
| **Chainalysis** | ブロックチェーン上の取引を分析・追跡する専門会社 |
| **ダークウェブ** | 通常の検索エンジンではアクセスできない、犯罪に使われることが多い匿名ネットワーク |
| **ファームウェア** | デバイスを動かす基本的なプログラム（ハードウェアウォレットの「OS」） |

> 💡 **まとめると…**
> SafePalのショッピングサイトのバグで約4万人の個人情報（住所・電話番号など）が漏えいしました。ウォレットのお金や鍵は無事ですが、「暗号資産ユーザー」とわかる情報が住所とセットで漏れたため、詐欺や最悪の場合は実際の犯罪のターゲットになるリスクがあります。SafePalから届いたと称する不審な連絡には絶対に応じないことが重要です。
