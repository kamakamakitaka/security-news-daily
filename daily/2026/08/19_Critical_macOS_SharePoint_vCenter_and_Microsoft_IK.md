# macOS・SharePoint・vCenter・Windowsの深刻な脆弱性が実際の攻撃に悪用されている

**元記事**: [Critical macOS, SharePoint, vCenter, and Microsoft IKE Flaws Under Active Exploitation](https://inl03.netline.com/ltr6/?_m=3n.009a.4060.sp0ao46r89.348q)
**解説日**: 2026年8月19日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的なことを押さえておきましょう。

### 🏢 登場するソフトウェアって何？

| ソフトウェア | 一言説明 |
|---|---|
| **macOS** | Appleのパソコン(Mac)に入っているOS(基本ソフト) |
| **Microsoft SharePoint** | 会社や組織内でファイルを共有したり情報を管理するMicrosoftのサービス |
| **VMware vCenter** | 企業が「仮想サーバー」をまとめて管理するための専用ソフト。大企業のITインフラの「司令塔」のようなもの |
| **Microsoft IKE (Internet Key Exchange)** | インターネット通信を暗号化するための「鍵交換」の仕組み。VPN(社外から会社のネットワークにつなぐ技術)でも使われる |

### 🔑 「脆弱性」って何？
ソフトウェアに存在する「設計上の欠陥・バグ」のことです。家に例えると、「鍵がかかっているように見えるけど、特定の操作をすると簡単に開いてしまう扉」のようなイメージです。

### 📋 CISAとKEVカタログって？
- **CISA**：アメリカ政府のサイバーセキュリティ専門機関（日本でいう「サイバー警察」のような組織）
- **KEVカタログ**：CISAが「現在実際に攻撃に使われている危険な脆弱性リスト」。ここに載ることは「今すぐ対応が必要！」という警告に等しい

### 📊 CVSSスコアって？
脆弱性の「危険度」を0〜10点で表したスコアです。
- 9.0以上 → **超危険（Critical/緊急）**
- 7.0〜8.9 → 危険（High）
- 4.0〜6.9 → 中程度（Medium）

## 何が起きたのか

2026年8月、CISAが**4つの深刻な脆弱性**を「現在攻撃に悪用されている」としてリストに追加しました。

### 発見された4つの脆弱性

#### 🍎 ① macOSの脆弱性（CVE-2026-65400）危険度：9.8/10
> **「パスワードなしでMacの画面共有にログインできてしまう」**

本来は正しいIDとパスワードが必要な「スクリーンシェアリング（画面共有機能）」に、**ネットワーク経由でパスワードなし**でログインできてしまうバグです。

🔍 **実際の被害**：この脆弱性を悪用して、**仮想通貨「Monero（モネロ）」を無断で採掘するプログラム**が被害者のPCにインストールされていることが確認されました。

---

#### 📁 ② Microsoft SharePointの脆弱性（CVE-2026-55040）危険度：9.1/10
> **「認証（ログイン確認）を素通りできてしまう」**

会社のファイル共有システムであるSharePointで、本来ログインしていないと見られないはずのファイルや機能に、**認証をすり抜けて**アクセスできてしまうバグです。

🔍 **実際の被害**：攻撃方法を示す「PoC（概念実証コード）」がインターネット上に公開されてから、すぐに不明な攻撃者グループに悪用が確認されています。

---

#### 🖥️ ③ VMware vCenterの脆弱性（CVE-2026-59310）危険度：9.8/10
> **「不正なファイルパスを使って、サーバー内で好き勝手なプログラムを実行できてしまう」**

「パストラバーサル攻撃」という手法が使われています。本来は「この場所にしかアクセスできない」という制限を、特殊な文字列（例：`../../../`）を使って**制限エリアを突破**するイメージです。

🔍 **実際の被害**：
- **中国と関連があるとみられる高度な攻撃グループ（APT）** が悪用
- バックドア（不正な裏口）を仕込まれ、継続的なアクセスを許してしまった
- 少なくとも1件のケースで**ランサムウェア（身代金要求型ウイルス）** が展開された
- **47カ国・361のIPアドレス**が被害を受けており、ドイツ(55件)・アメリカ(41件)・トルコ(38件)・イラン(26件)・フランス(25件)が特に多い

---

#### 🔐 ④ Microsoft IKEの脆弱性（CVE-2026-33824）危険度：9.8/10
> **「メモリ管理のバグを使って、ネットワーク経由で不正なプログラムを実行できてしまう」**

「ダブルフリー」という技術的なバグが原因です。コンピュータが「使い終わったメモリ領域」を2回解放しようとすると、システムが混乱して攻撃者に制御を奪われる可能性があります。

🔍 **実際の被害**：セキュリティ企業Palo Alto Networksによると、**中国語話者の別の攻撃グループ**がこの脆弱性を悪用しており、さらに注目すべき点として「**DeepSeek（中国製AI）を使った自律的なハッキング**」も同時に行っていたことが確認されています。

## 技術的な詳細

### 🤖 AI（DeepSeek）を使った自動ハッキングとは？

今回の記事で特に注目すべきは、攻撃者が**AIを使って自動的に攻撃を行っていた**という点です。

```
通常のハッキング：
人間が手動でコマンドを打つ → 時間がかかる

AI使用のハッキング：
AIが自動でターゲットを探し、攻撃方法を考え、実行する → 大量・高速に攻撃可能
```

これは「シャドーAIエージェント」問題（後述の関連記事参照）とも深く結びついており、AI技術がサイバー攻撃に悪用される新時代の到来を示しています。

### 🔓 各脆弱性の仕組みをさらに詳しく

**パストラバーサル（③の仕組み）を例え話で**

> 図書館（サーバー）に「一般の人は1階の本しか借りられない」というルールがあるとします。でも攻撃者は「1階→地下→2階→館長室」というような特殊なルートを使って、立入禁止の館長室（機密データ）に侵入できてしまいます。

**ダブルフリー（④の仕組み）を例え話で**

> レンタルショップで借りたDVDを返却したのに、もう一度「返却処理」されてしまうと、システムが混乱して別の人のアカウント情報が上書きされてしまう…そのような「二重処理による混乱」を悪用する攻撃です。

## なぜ重要なのか

### 📢 これが「重大ニュース」である理由

1. **使っているソフトが超メジャー**
   - macOS・SharePoint・VMware vCenterは**世界中の企業や政府機関が使っている**ソフトです。影響を受ける可能性のある組織の数が膨大です。

2. **すでに実際に被害が出ている**
   - 「理論上危険」ではなく、**今この瞬間も攻撃が行われている**という点が深刻です。

3. **国家レベルの攻撃者が関与している**
   - 個人のハッカーではなく、**国家が支援しているとみられる高度な攻撃グループ（APT）** が関与しており、組織的・計画的な攻撃が展開されています。

4. **ランサムウェアへの発展**
   - vCenterの脆弱性悪用がランサムウェア被害につながっており、**企業活動の停止や身代金要求**という実害が発生しています。

5. **AIによる攻撃の自動化**
   - 攻撃者がAIを活用しているということは、**より少ない労力で、より多くの標的を同時に攻撃できる**ことを意味します。

## 対策・今後の展望

### ✅ 今すぐできる対策

#### 個人ユーザー（Macを使っている方）
- **macOSを最新バージョンにアップデートする**
  - Apple メニュー → システム設定 → 一般 → ソフトウェアアップデート
- スクリーンシェアリング（画面共有）を**使っていない場合はオフにする**

#### 企業・組織のIT担当者
- **SharePoint・vCenter・WindowsのIKEサービスを最新版にパッチ適用**
- ネットワーク監視を強化し、不審なアクセスを検知する体制を整える
- vCenterへのアクセスを**VPNや特定IPに限定する**

### 📅 政府機関向けの期限
アメリカの連邦政府機関は **2026年8月21日まで** に対応を完了する義務があります（BOD 26-04というガイドラインに基づく）。

### 🔮 今後の展望
- AIを活用した攻撃はさらに高度化・大規模化すると予想されます
- 「パッチが出たら即適用」という文化をすべての組織が徹底する必要があります
- 国家間のサイバー戦争が一般企業にも飛び火する時代が続くでしょう

## 用語解説

| 用語 | 意味 |
|------|------|
| **脆弱性（ぜいじゃくせい）** | ソフトウェアやシステムに存在するセキュリティ上の欠陥・バグ |
| **CISA** | アメリカのサイバーセキュリティ・インフラセキュリティ庁。サイバー防衛の専門機関 |
| **KEVカタログ** | CISAが管理する「現在実際に攻撃に使われている脆弱性」の公式リスト |
| **CVSSスコア** | 脆弱性の危険度を0〜10で示すスコア。9以上は最高レベルの危険 |
| **パストラバーサル** | 特殊な文字列を使ってアクセス制限を突破し、本来見られないファイルに侵入する攻撃 |
| **ダブルフリー** | メモリ領域を二重に解放しようとすることで、システムを混乱させる脆弱性 |
| **バックドア** | 攻撃者が後から忍び込むために仕込む「裏口」プログラム |
| **ランサムウェア** | ファイルを暗号化して使えなくし、解除と引き換えに身代金を要求するウイルス |
| **APT（Advanced Persistent Threat）** | 国家が支援するとみられる、高度で持続的な攻撃グループ |
| **PoC（概念実証コード）** | 脆弱性が実際に使えることを示すサンプルコード。公開されると攻撃者にすぐ悪用される |
| **Monero（モネロ）** | 追跡が難しい匿名性の高い仮想通貨。攻撃者に好まれる |
| **VPN** | 暗号化されたトンネル通信で、外部から安全に社内ネットワークに接続する技術 |
| **パッチ** | 脆弱性を修正するためのソフトウェアの更新プログラム |
| **スクリーンシェアリング** | 自分のPC画面を他の人と共有する機能（Macに標準搭載） |
