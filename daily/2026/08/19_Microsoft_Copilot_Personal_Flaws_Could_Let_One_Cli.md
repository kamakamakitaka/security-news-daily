# マイクロソフト Copilot の欠陥：リンクを1回クリックするだけで連携アプリのデータが盗まれる可能性

**元記事**: [Microsoft Copilot Personal Flaws Could Let One Click Exfiltrate Data From Connected Apps](https://inl03.netline.com/ltr6/?_m=3n.009a.4060.sp0ao46r89.3498)
**解説日**: 2026年8月19日

---

## 背景知識

まず、このニュースを理解するために必要な基礎知識を整理しましょう。

### Microsoft Copilot（マイクロソフト コパイロット）とは？
マイクロソフトが提供する**AIアシスタント**です。ChatGPTのような会話型AIで、`copilot.microsoft.com` にアクセスすると誰でも使えます。メール、カレンダー、Google Driveなどの外部サービスと連携することができ、「今週の予定は？」「最近届いたメールを要約して」といった質問に答えてくれます。

### 「連携アプリ」って何？
スマホのアプリで「Googleアカウントでログイン」するときのように、CopilotにGmailやGoogleカレンダー、OneDriveなどへのアクセスを許可できます。これが「連携（接続）」です。一度許可すると、Copilotはあなたの代わりにこれらのサービスのデータを読み取れるようになります。

### 「脆弱性（ぜいじゃくせい）」とは？
ソフトウェアの**セキュリティ上の欠陥・弱点**のことです。鍵のかかった部屋に「実は裏口がある」ような状態をイメージしてください。

### 「情報流出（エクスフィルトレーション）」とは？
攻撃者が**こっそりデータを外部に持ち出す**行為です。英語で "Exfiltration"（エクスフィルトレーション）と言います。

---

## 何が起きたのか

セキュリティ会社の **Varonis Threat Labs（バロニス スレット ラボ）** が、Microsoft Copilot に **3つの重大な欠陥** を発見しました。これらの欠陥をまとめて「**CoSnitch（コースニッチ）**」と名付けています。

### 事件の流れをざっくりまとめると…

```
😈 攻撃者が「罠リンク」を作成
        ↓
😮 被害者がそのリンクを1回クリック
        ↓
🤖 Copilotが自動的に動き出す（被害者は気づかない）
        ↓
📧 メール・カレンダー・ファイルなどのデータを取得
        ↓
📤 攻撃者のサーバーにデータが送信される
        ↓
😱 被害者は何も知らないまま…
```

この欠陥は **2025年12月にマイクロソフトに報告** され、**2026年8月18日にパッチ（修正プログラム）** が配布されました。また、実際に悪用された証拠は見つかっていません。

## 技術的な詳細

少し難しい話になりますが、できるだけわかりやすく説明します！

### ① 欠陥の発見方法が面白い：「メタハッキング」

研究者たちはAIに対して、こんな質問を繰り返しました。

> 「なぜユーザーが操作しなくても命令（プロンプト）を自動実行できないの？できない理由を教えて」

Copilotは最初「それはできません」と断り続けましたが、**断るたびに技術的な理由を説明してくれました**。そしてついに…

> 「`autorun=1` というパラメータがあるが、現在は無効化されているはずです」

と、**自分の弱点を自分で教えてしまったのです！** 🤦

これを研究者たちは「**メタハッキング**（AIに自分の欠陥を語らせる手法）」と呼んでいます。Varonisは「Copilotは破られたのではなく、*まんまと乗せられた*」と表現しています。

### ② 3つの脆弱性の仕組み

#### 欠陥①：プロンプトの自動実行
通常、CopilotのURLに `?q=メールを見せて` のようなパラメータをつけると、入力欄に文字が入力されるだけで、**実行はユーザーがボタンを押すまで行われません**。

しかし `autorun=1` を組み合わせると…

```
通常のURL例:
https://copilot.microsoft.com/?q=メールを要約して

🚨 攻撃者の罠URL:
https://copilot.microsoft.com/?q=メールを要約して&autorun=1
```

ページを開いた瞬間に、**ユーザーが何もしなくても命令が自動実行**されてしまいます！しかも、被害者がすぐにタブを閉じても、処理は最後まで完了してしまいます。

#### 欠陥②：連携サービスからのデータ窃取
自動実行された命令は、Copilotが連携しているサービス（メール・カレンダーなど）にアクセスし、取得したデータを**Base64エンコード**（データを暗号っぽい文字列に変換する方法）して、攻撃者のサーバーに送り付けます。

> 🎒 身近な例えで言うと…
> 「学校の下駄箱の鍵を持っている人（Copilot）が、悪い人に操られて、あなたの荷物を全部取り出して渡してしまう」イメージです。

実際に盗まれた情報の例：
- 📧 メールの本文・件名・送受信者情報
- 📅 カレンダーの予定・参加者・場所・時間
- 📁 Google Driveのファイル名とその要約
- 💬 Copilotとの過去の会話履歴
- 🧠 Copilotの「記憶」に保存された個人ルール

#### 欠陥③：記憶の汚染（メモリポイズニング）
これは別のルートの攻撃です。攻撃者が**罠の仕掛けられたWebページ**を作っておき、被害者がCopilotに「このページを要約して」と頼むと…

Copilotは要約と同時に、**悪意のある命令を自分の「記憶」に書き込んでしまいます**。

> 😱 怖いのは…
> パスワードを変えても、ログアウトしても、デバイスを変えても、この「汚染された記憶」は消えず、**次回以降のCopilot利用時にも攻撃者の命令が実行され続ける**点です！

## なぜ重要なのか

### 🎯 攻撃のハードルが極めて低い
「リンクを1回クリックするだけ」という点が非常に危険です。フィッシングメールやSNSのDMに罠リンクを仕込むだけで攻撃が完成します。

### 📊 影響を受ける情報の範囲が広い
メール・カレンダー・ファイル・会話履歴など、**仕事でも私生活でも重要な情報**が対象になります。

### 🕵️ 発見が難しい
攻撃のトラフィック（通信）が、CopilotがWebページを普通に参照するときの通信と**見分けがつかない**ため、セキュリティシステムでの検出が非常に困難です。

### 🧠 記憶汚染は長期間持続する
欠陥③の「記憶の汚染」は、パスワード変更や再ログインをしても消えないため、**長期間にわたって被害が続く**可能性があります。

## 対策・今後の展望

### ✅ すでに修正済み！（良いニュース）
マイクロソフトは **2026年8月18日** にパッチ（修正プログラム）を配布しました。`copilot.microsoft.com` を使っているなら、**特にアップデート作業は不要**です（サービス側で自動修正されています）。

### ⚠️ ユーザーとして気をつけるべきこと

| 対策 | 内容 |
|------|------|
| 🔗 怪しいリンクを開かない | SNS・メール・DMで届いたCopilot関連のリンクは慎重に |
| 🔌 不要な連携を解除する | 使っていないサービスとの連携は切っておく |
| 🧠 Copilotの記憶を定期的に確認する | 覚えさせた内容に不審なものがないか確認 |
| 🔍 今後も情報収集を続ける | AIアシスタントの脆弱性はこれからも発見される可能性がある |

### 🔮 今後の展望
AI技術の進化とともに、AIを悪用した攻撃手法（今回のような「メタハッキング」など）は増加していくと予想されます。AIが広く使われるようになった今、AIそのもののセキュリティが今後ますます重要になっていきます。

## 過去記事との関連

以前の関連記事でも、マイクロソフト製品の脆弱性が相次いで報告されていました。

- 🔴 **macOS・SharePoint・vCenter・Windows IKEの深刻な脆弱性**（2026年8月19日）では、実際に攻撃に悪用されている脆弱性が複数報告されました。
- 🦠 **MacSync Stealer**（2026年8月19日）では、マイクロソフトがMac向けの情報窃取マルウェアのインフラを追跡していました。

今回のCoSnitchは「実際の悪用は確認されていない」とのことですが、マイクロソフト製品を狙った攻撃が活発化している時期に発見・公開された点は注目に値します。攻撃者はこうした脆弱性を組み合わせて使うこともあるため、引き続き警戒が必要です。

## 用語解説

| 用語 | 説明 |
|------|------|
| **Microsoft Copilot Personal** | マイクロソフトが提供する一般ユーザー向けAIアシスタント |
| **脆弱性（ぜいじゃくせい）** | ソフトウェアのセキュリティ上の欠陥・弱点 |
| **エクスフィルトレーション** | 攻撃者がデータをこっそり外部に持ち出す行為 |
| **プロンプト** | AIに対して入力する命令・質問文 |
| **autorun=1** | 今回発見された「自動実行」を引き起こすURLパラメータ |
| **URLパラメータ** | URLの末尾に `?key=value` の形で付け加える追加情報 |
| **メタハッキング** | AIに自分の欠陥や弱点を自ら語らせる手法 |
| **Base64エンコード** | データを英数字の羅列に変換する方法。フィルターをかいくぐるために使われた |
| **メモリポイズニング（記憶汚染）** | AIの記憶領域に悪意のある命令を書き込む攻撃 |
| **Webhook（ウェブフック）** | 外部サービスにデータを自動送信する仕組み。今回は攻撃者のサーバーへの送信に悪用された |
| **CVE** | 脆弱性に付けられる国際的な管理番号（今回は CVE-2026-24301） |
| **パッチ** | ソフトウェアの不具合を修正するためのアップデートプログラム |
| **フィッシング** | 偽のメールやリンクで個人情報を騙し取る攻撃手法 |

---

> 💡 **まとめ**
> 今回の件は「AIが自分の弱点を自分で教えてしまった」という、AIの新時代ならではの攻撃手法でした。すでに修正は完了していますが、AIアシスタントと外部サービスの連携が広まるにつれ、こうしたリスクは今後も増えていく可能性があります。「便利な機能ほどリスクも大きい」という視点を持つことが大切です！
