# Microsoftが「MacSync Stealer」という情報窃取マルウェアに関連する30以上のドメインを特定

**元記事**: [Microsoft Links 30+ Rotating Domains to MacSync Stealer Infrastructure](https://inl03.netline.com/ltr6/?_m=3n.009a.4060.sp0ao46r89.348w)
**解説日**: 2026年8月19日

---

## 背景知識

このニュースを理解するために、いくつかのキーワードを先に説明しておきます。

### 🍎 macOSって何？
AppleのMacコンピューター（MacBookやiMacなど）に搭載されているOS（基本ソフト）のことです。「Windowsは狙われやすいけどMacは安全」と思っている方も多いですが、最近はMacを狙った攻撃も増えています。

### 🦠 情報窃取マルウェア（インフォスティーラー）とは？
マルウェアとは「悪意のあるプログラム」のこと。その中でも「情報窃取マルウェア（インフォスティーラー）」は、パソコンに保存されているパスワード・クレジットカード情報・ファイルなどを盗み出すプログラムです。  
泥棒が家に侵入して貴重品をごっそり持っていくイメージです。

### 🌐 C2サーバー（指令サーバー）とは？
「Command and Control（命令と制御）」の略。マルウェアが感染したパソコンを遠隔操作したり、盗んだデータを送り届けたりするための「犯罪者の基地局」のようなものです。

### 🔄 ドメインローテーションとは？
攻撃者が捜査を逃れるために、使用するWebサイトのアドレス（ドメイン）を次々と変えていく手口です。警察から逃げるために引っ越しを繰り返す犯罪者に似ています。

---

## 何が起きたのか

MicrosoftのセキュリティチームMicrosoft Defender Expertsが、**「MacSync Stealer（マックシンクスティーラー）」** というMac専用の情報窃取マルウェアに使われていた **30個以上のWebドメイン（サーバーのアドレス）** を突き止めました。

このマルウェアは、感染したMacパソコンから以下のような情報を根こそぎ盗み出します：

| 盗まれる情報 | 具体的な内容 |
|---|---|
| 🔑 パスワード類 | macOSのキーチェーン（パスワード管理機能）に保存されたもの |
| 🌐 ブラウザ情報 | Chromeなどのパスワード・Cookie・閲覧履歴 |
| 📝 メモ | Apple Notesに保存した内容 |
| 🔐 SSH鍵 | サーバーへのアクセスキー |
| ☁️ クラウド設定 | AWSやKubernetesの設定情報（企業向けクラウドの認証情報） |
| 📁 ファイル | 個人フォルダにある重要なファイル |

特筆すべきは、「データを外部に送り出している（実際の情報漏えいが確認されている）」とMicrosoftが明言していることです。単なる「偵察」ではなく、**実際に被害が出ている**ことを意味します。

## 技術的な詳細

少し難しいですが、攻撃の流れを「泥棒が家に侵入する」に例えながら説明します。

### Step 1：侵入のきっかけ「ClickFix」手口

攻撃はまず**「ClickFix」という社会工学的手口**から始まります。これは、「このコマンドをターミナルに貼り付けて実行してください」と、ユーザー自身に悪意のある命令を実行させる騙しの手口です。

> 🏠 例え話：「ガス点検員です。この操作をしてください」と言って、自分で窓のカギを開けさせるようなものです。

### Step 2：マルウェアのダウンロード

ユーザーが騙されて操作すると、`curl`というMacの標準ツールを使って攻撃者のサーバーから悪意のあるプログラムが自動的にダウンロードされます。

### Step 3：情報の収集と梱包

マルウェアは情報を集め終わると、それを：
1. `/tmp/sync*` というフォルダに一時保存
2. `/tmp/osalogging.zip` というZIPファイルに圧縮
3. 複数の小さなかたまり（チャンク）に分割

して、送信の準備をします。

> 🏠 例え話：盗んだ貴重品を段ボール箱に詰め、宅配便で小分けにして送るイメージです。

### Step 4：データの送信（外部流出）

分割したデータを `curl` というツールで「HTTP PUT」という方式を使って攻撃者のサーバーに送信します。送信後は証拠隠滅のため、一時ファイルをすべて削除します。

### 🕵️ Microsoftはどうやって犯人を追跡したの？

攻撃者はドメインを次々と変えていましたが、Microsoftは以下の「癖（パターン）」に注目しました：

- URLのパス（`/curl/`、`/dynamic?txd=`、`/gate?buildtxd=` という形式）
- MacのUser-Agent文字列（「自分はMacです」という識別情報）
- API-keyヘッダー（認証に使う特定の値）
- ファイルを分割送信するときのパラメータ名（`upload_id`、`chunk_index`など）

これは、犯人がどんな変装をしても「歩き方の癖」でバレてしまうようなものです。

## なぜ重要なのか

### ① Macユーザーへの警告
「Macは安全」という神話が崩れつつあります。企業でMacを使っているエンジニアや、個人でMacを使っている方も、セキュリティ対策が必要な時代になっています。

### ② 被害の深刻さ
盗まれる情報のリストを見ると分かりますが、**個人情報だけでなく企業のクラウドインフラへのアクセス権（AWSやKubernetes）** まで盗まれる可能性があります。これは個人被害にとどまらず、会社全体のシステムに侵入される恐れがあります。

### ③ 30以上のドメインが使われていた事実
これだけ多くのドメインを使い回すということは、**組織的・継続的な攻撃活動**であることを示しています。単発の攻撃ではなく、現在進行形の脅威です。

## 対策・今後の展望

### 🛡️ 今すぐできる対策

**1. 不審なコマンドを実行しない**
「ターミナルにこれを貼り付けて実行してください」というWebサイトやメッセージには絶対に従わないでください。これがClickFix攻撃の入口です。

**2. macOSとアプリを最新版に保つ**
OSやアプリのアップデートはセキュリティの基本です。後回しにせず、すぐに更新しましょう。

**3. セキュリティソフトを導入する**
Macにもウイルス対策ソフトを入れることを検討してください。Microsoft Defenderなどの選択肢があります。

**4. 怪しいサイト・ソフトに注意**
信頼できないWebサイトからソフトウェアをダウンロードしないようにしましょう。

**5. 重要なパスワードは定期的に変更する**
特にAWSなどのクラウドサービスの認証情報は定期的に見直しましょう。

### 🔮 今後の展望

Microsoftが30以上のドメインを特定したことで、セキュリティ企業がこれらをブロックリストに追加できるようになります。しかし攻撃者も新しいドメインを次々と用意してくる可能性が高く、**いたちごっこ**は続くと予想されます。

## 過去記事との関連

以前「**macOS・SharePoint・vCenterなどの深刻な脆弱性が実際の攻撃に悪用されている**」という記事を取り上げましたが、今回のニュースもmacOSを狙った攻撃という点で共通しています。

macOSは長らく「Windowsより安全」とされてきましたが、最近のトレンドとして**macOSを標的にした攻撃が着実に増加**しています。特に企業でMacを多く使うようになったことで、攻撃者にとって「狙う価値のある標的」になってきた背景があります。MacSyncStealerのように「企業のクラウド認証情報まで盗む」マルウェアの登場は、その流れを象徴するものと言えるでしょう。

## 用語解説

| 用語 | 解説 |
|---|---|
| **マルウェア** | 悪意のあるソフトウェアの総称。ウイルス・スパイウェアなどを含む |
| **インフォスティーラー（情報窃取型）** | パスワードや個人情報を盗み出すことに特化したマルウェア |
| **C2サーバー** | 攻撃者がマルウェアを遠隔操作し、盗んだデータを受け取るサーバー |
| **ドメインローテーション** | 追跡を逃れるために使うドメインを次々と変える手口 |
| **ClickFix** | ユーザー自身に悪意のあるコマンドを実行させる社会工学的攻撃手法 |
| **macOSキーチェーン** | Macに内蔵されたパスワード管理機能 |
| **SSH鍵** | サーバーにログインするための電子的な「鍵」 |
| **AWS** | Amazon Web Services。Amazonが提供する企業向けクラウドサービス |
| **Kubernetes** | 大規模なサーバー群を管理するためのシステム |
| **User-Agent** | ブラウザやアプリが「自分はこんなソフトです」とサーバーに伝える識別情報 |
| **API-key** | ソフトウェア同士が安全にやり取りするための認証キー |
| **エクスフィルトレーション（外部流出）** | 盗んだデータを攻撃者のサーバーに送り出すこと |
| **osascript** | macOSでAppleScriptを実行するためのコマンド |
| **curl** | URLを指定してデータを送受信するMac/Linux標準のコマンドツール |
