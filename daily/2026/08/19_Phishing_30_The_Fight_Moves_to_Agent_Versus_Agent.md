# フィッシング3.0：AIがAIと戦う時代へ

**元記事**: [Phishing 3.0: The Fight Moves to Agent Versus Agent](https://inl03.netline.com/ltr6/?_m=3n.009a.4060.sp0ao46r89.3488)
**解説日**: 2025年7月11日

---

## 背景知識

まず、このニュースを理解するために必要な言葉を整理しましょう。

### 📧 フィッシング詐欺とは？
「釣り(fishing)」をもじった言葉で、偽メールや偽サイトを使って、パスワードやお金などを騙し取る攻撃のことです。「なりすまし詐欺メール」と考えてもらえればOKです。

### 🤖 生成AI（GenAI）とは？
ChatGPTのように、人間が書いたような文章・画像・動画を自動で作れるAIのことです。

### 🎭 ディープフェイクとは？
AIを使って「本物そっくりの偽の顔・声・動画」を作る技術です。芸能人や政治家の顔を別人に貼り付けた偽動画をニュースで見たことがあるかもしれません。

### 🦾 AIエージェントとは？
指示を与えると、調査・判断・実行を**自分で自律的に**こなすAIのことです。人間がいちいち指示しなくても、次々とタスクをこなし続けます。まるで優秀な「自動ロボット部下」のようなイメージです。

## 何が起きたのか

この記事は、**フィッシング詐欺が3段階で進化してきた**という話を解説しています。

### フィッシングの歴史を「ウイルスの進化」に例えると…

| 世代 | 別名 | 内容 | 例え |
|------|------|------|------|
| 1.0 | **悪いコンテンツ型** | 怪しいリンクや添付ファイル | 一目でわかる怪しい人 |
| 2.0 | **悪い意図型** | 偽の請求書・社長なりすまし | スーツを着た詐欺師 |
| 3.0 | **AI自動攻撃型** | AIが自律的に調査・作成・送信 | ロボット詐欺師の大群 |

### 🏢 実際に起きた被害：建設会社Arupの事件（約25億円の被害！）

イギリスの大手エンジニアリング会社「Arup（アラップ）」で実際に起きた事件です：

1. 社員に「CFO（最高財務責任者）からのメール」が届く
2. 社員が疑って躊躇していると…
3. **ビデオ通話が始まり、同僚の顔が複数映る**
4. でも、その顔は全員**AIが作った偽物**だった
5. 社員は信じてしまい、**約25億円分の送金**を承認してしまった

これは映画の話ではなく、**2024年に実際に起きた事件**です。

## 技術的な詳細

### 攻撃者がAIエージェントを使うと何が変わる？

**昔の攻撃（人間がやる場合）：**
```
人間の攻撃者
 → 会社のWebサイトを手動で調べる（時間がかかる）
 → 社員のSNSをチェックする（めんどくさい）
 → メールを自分で書く（技術が要る）
 → 1社ずつしか攻撃できない
```

**今の攻撃（AIエージェントを使う場合）：**
```
AIエージェント
 → 会社の公開情報を数秒で全部収集 ⚡
 → 社員の関係図・上司・取引先を自動分析 ⚡
 → ターゲットに合わせた自然なメールを自動生成 ⚡
 → 同時に10,000社に対して実行できる 🔥
```

### なぜ昔のセキュリティ対策では防げないの？

従来のメールセキュリティは、**「怪しい内容を検索して引っかかったらブロック」**という仕組みです。

> **例え話**：空港の荷物検査のようなものです。「銃」「爆弾」などを検知する機械があるとして、完全に普通に見える荷物の中に「詐欺の意図」は探せません。

フィッシング3.0では、メール本文は**完璧な自然な日本語・英語**で書かれており、リンクも添付ファイルも存在しないことがあります。検査機械では引っかからないのです。

### 攻撃のルートも多様化している

```
昔：メールだけ
今：メール + Slack/Teams + 電話 + ビデオ通話 + SNS
```

複数のルートを組み合わせることで「この人は本物だ」という**信頼感**を演出するのが最新の手口です。

## なぜ重要なのか

### 📊 セキュリティ専門家への調査結果（2026年1月・アメリカ）

1,000〜5,000人規模の会社のIT・セキュリティ担当者128人へのアンケートでは：

- **88%** が「過去1年でデジタル通信への信頼が揺らぐ事件を経験した」
- **82%** が「自分たちの業界を狙った攻撃が増えていると感じる」
- **60%** が「ディープフェイク攻撃に対処できる自信がない」
- **55%** が「信頼を悪用した攻撃への対応に失敗すると、大規模な情報漏洩につながると思う」

### 「中小企業は狙われない」は昔の話

> **重要なポイント**：昔は大企業だけが精密な攻撃のターゲットでした。なぜなら、攻撃の「準備」に時間とお金がかかったからです。

でも今は、**AIエージェントが自動でやってくれる**ので、準備コストがほぼゼロ。小さな会社でも「手作り感のある丁寧な詐欺メール」が届く時代になりました。

## 対策・今後の展望

### 🛡️ 個人でできる対策

1. **送金・重要な承認は必ず別の方法で確認する**
   - メールだけで判断しない。電話で本人確認（でもその電話番号もメールに書かれているものは使わない！）

2. **ビデオ通話でも疑う**
   - ディープフェイクの見分け方：口の動きが少しズレる、照明が不自然、髪の毛の境界がぼやけるなど

3. **「急かしてくる」操作に気づく**
   - 「今すぐ」「緊急」「他に言わないで」はフィッシングのサイン

4. **コードワードを職場で決めておく**
   - 重要な取引をする際に、本人しか知らない合言葉を事前に共有しておく

### 🏢 会社・組織レベルの対策

| 対策 | 内容 |
|------|------|
| AIによる行動分析 | 「この人がいつもと違う送金依頼をしている」を検知 |
| 多段階承認 | 高額送金は1人の判断でできない仕組みにする |
| ゼロトラスト | 「社内からの通信でも信用しない」を前提にする |
| 社員教育 | 最新の攻撃パターンを定期的に学ぶ |

### 🔮 今後の展望：「エージェント vs エージェント」の時代へ

記事タイトルにある「Agent versus Agent（エージェント対エージェント）」とは、**攻撃側のAIエージェントに対して、防御側もAIエージェントで戦う**という意味です。

```
攻撃側AIエージェント 🔴
  → 調査・作成・送信・適応を自動化

         ⚔️

防御側AIエージェント 🔵
  → 検知・分析・ブロック・報告を自動化
```

人間同士の戦いから、**AIが前線に出てAI同士が戦う時代**に突入しています。

## 用語解説

| 用語 | 意味 |
|------|------|
| **フィッシング（Phishing）** | 偽メールや偽サイトで個人情報・お金を騙し取る攻撃 |
| **BEC（ビジネスメール詐欺）** | 経営者などになりすまして不正送金させる詐欺 |
| **GenAI（生成AI）** | 文章・画像・動画などを自動生成できるAI |
| **ディープフェイク** | AIで作った偽の顔・声・動画 |
| **AIエージェント** | 指示なしに自律的にタスクをこなすAI |
| **ソーシャルエンジニアリング** | 技術ではなく「人間の心理」を利用した詐欺・攻撃 |
| **ゼロトラスト** | 「社内・社外を問わず、何も信用しない」を前提にしたセキュリティ設計 |
| **セキュアメールゲートウェイ** | 怪しいメールをブロックするシステム |
| **偵察（Reconnaissance）** | 攻撃前に相手の情報を集める行為 |
| **CFO** | 最高財務責任者（会社のお金を管理する役員） |

---

> 💡 **まとめると**：詐欺メールは「怪しい日本語のメール」という時代は終わり、AIが人間そっくりに書いた自然なメールや、本物そっくりのビデオ通話が使われる時代になっています。「見た目や文章がおかしくないから本物」とは思わないことが、今最も大切なセキュリティ意識です。
