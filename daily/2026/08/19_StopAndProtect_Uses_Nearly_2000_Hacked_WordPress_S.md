# 「StopAndProtect」作戦：約2,000件のWordPressサイトを乗っ取りマルウェアを拡散・データ窃取

**元記事**: [StopAndProtect Uses Nearly 2,000 Hacked WordPress Sites to Spread Malware and Steal Data](https://inl03.netline.com/ltr6/?_m=3n.009a.4060.sp0ao46r89.348k)
**解説日**: 2025年6月

---

## 背景知識

このニュースを理解するために、いくつかの基本的な用語を先に確認しておきましょう。

### WordPressって何？
**WordPress（ワードプレス）** は、世界中のウェブサイトの約40%以上で使われている、ブログやホームページを簡単に作れるシステムです。飲食店のサイト、個人ブログ、企業サイトなど、本当にたくさんの場所で使われています。

### なぜWordPressが狙われるの？
WordPressは非常に普及しているため、**古いバージョンのまま放置されているサイト**が多く存在します。パソコンのOSやスマホのアプリと同じで、更新しないと「セキュリティの穴（脆弱性）」が開いたままになり、悪者に侵入されやすくなります。

### マルウェアって何？
**マルウェア（Malware）** は「悪意のあるソフトウェア」の総称です。ウイルス、ランサムウェア、スパイウェアなどが含まれます。

### ランサムウェアって何？
**ランサムウェア（Ransomware）** は、パソコン内のファイルを暗号化（鍵をかけて読めなく）して、「元に戻してほしければお金を払え」と脅迫するマルウェアです。「Ransom（身代金）」が語源です。

---

## 何が起きたのか

セキュリティ企業「**Check Point Research**」が、「**StopAndProtect（ストップアンドプロテクト）**」と名付けられた大規模なサイバー犯罪作戦を発見しました。

この作戦の特徴をひと言で言うと：

> **約2,000件の古くて脆弱なWordPressサイトを乗っ取り、それを「悪の基地」として利用して、世界中の人々にマルウェアをばらまいている**

という、非常に大規模かつ組織的な攻撃です。

### 発見のきっかけ
2026年5月中旬に、「StopAndProtect」という名前のランサムウェア（身代金要求型ウイルス）が発見されたことが調査のきっかけでした。調べていくうちに、その背後に巨大な犯罪インフラが存在することが明らかになりました。

### 乗っ取られたWordPressサイトはどんな状態？
- **古いバージョンのWordPress**（例：2021年リリースのバージョン）のまま放置
- **古いプラグイン**（WordPressに追加できる機能拡張）も更新されていない
- その結果、**約40種類もの脆弱性**が存在するサイトも確認されています

まるで、ドアに40個の鍵穴があって、そのどれも壊れているようなイメージです。

## 技術的な詳細

この攻撃は一つのマルウェアだけに頼らず、**複数の悪意あるツールが連携して動く「犯罪ツールキット」**を使っています。段階的に見ていきましょう。

### 【ステップ1】ClickFix（クリックフィックス）攻撃でだます

乗っ取られたWordPressサイトを訪問した人には、こんなニセの画面が表示されます：

```
「ロボットでないことを確認してください。
 以下の手順を実行してください…」
```

これは本物のCAPTCHA（ロボット判定）に見せかけた**偽のCAPTCHA画面**です。指示に従って操作すると、裏で**PowerShell（パワーシェル）** という強力なコマンドが自動実行されてしまいます。

> 💡 **PowerShellとは？** Windowsに標準搭載されている、コンピューターをコマンドで操作できる強力なツールです。管理者が使う道具ですが、悪用されると被害が大きくなります。

### 【ステップ2】マルウェアが段階的にインストールされる

感染は3段階で進みます：

| 段階 | 内容 |
|------|------|
| **第1段階** | 小さなプログラムが動き、攻撃者のサーバーに「感染成功」と報告し、次のプログラムを取得 |
| **第2段階** | 「本当にウイルス解析環境（サンドボックス）じゃないか？」確認してから次を取得 |
| **第3段階** | 本格的な6種類の攻撃ツールが起動 |

> 💡 **サンドボックスとは？** セキュリティ研究者がウイルスを安全に解析するための「隔離された実験環境」です。マルウェアはこれを検知すると、大人しく振る舞って解析を逃れようとします。

### 【ステップ3】6つの攻撃ツールが活動開始

第3段階で起動する6つのツールの役割をわかりやすく解説します：

#### 🔒 SilentEncryptor（サイレントエンクリプター）
- **やること**: ファイルをこっそり暗号化（鍵をかけて読めなく）する
- **例え**: 大事な書類に南京錠をかけて、鍵を持っていかれるイメージ

#### 🐛 NetworkShareScanner（ネットワークシェアスキャナー）
- **やること**: SMB（ファイル共有）やUSBを通じて、ネットワーク内の他のパソコンにも感染を広げる
- **例え**: 一人が風邪をひいたら、同じオフィスの人にも感染するようなもの

#### 📡 VBS Spreader（VBSスプレッダー）
- **やること**: ハードディスクや外付けUSBメモリを通じてさらに感染を広げる
- **例え**: 感染したUSBを別のパソコンに挿したら、そちらも感染する

#### 🖥️ LockScreen（ロックスクリーン）
- **やること**: 画面を完全にロックして、QRコードとともに「お金を払え」というメッセージを表示
- **例え**: パソコンが突然使えなくなって、「身代金を払ってください」という画面だけが出る状態

#### 💬 SimpleChatProxy（シンプルチャットプロキシ）
- **やること**: 攻撃者と被害者がリアルタイムでチャットできる専用アプリ
- **例え**: 犯人が「お金を払い方はこうだよ」と直接指示を出せる仕組み（かなり恐ろしい）

#### 🕵️ SilentDataCollector（サイレントデータコレクター）
- **やること**: パソコン内のファイルリストを作成し、攻撃者のサーバーへ送信。攻撃者が「このファイルを盗め」と指定すると、それを盗み出す
- **例え**: 泥棒が家の中を全部リスト化して、後で「この金庫の中身だけ盗め」と指示するようなもの

### 乗っ取られたWordPressサイトの「3つの役割」

```
悪用されたWordPressサイト
├── 役割1: マルウェアの配布場所（ウイルスを置いておく倉庫）
├── 役割2: C2サーバー（攻撃者が感染PCに命令を送るコントロールセンター）
└── 役割3: 盗んだデータの保管場所（ログ、スクリーンショット、ファイルなど）
```

> 💡 **C2サーバー（Command & Controlサーバー）とは？** 感染したパソコンに「次はこれをやれ」と命令を送る、攻撃者の指令塔のようなサーバーです。

## なぜ重要なのか

### 1. 規模が大きい
約2,000件ものWebサイトが乗っ取られているという事実は非常に深刻です。被害サイトを訪問しただけで感染する可能性があるため、普通にネットを使っている人も被害を受けるリスクがあります。

### 2. 攻撃が多段階・多機能
一般的なウイルスと違い、このキャンペーンは：
- **ファイルを暗号化**（ランサムウェア）
- **データを盗む**（スパイウェア）
- **感染を広げる**（ワーム）
- **画面をロック**（ロックウェア）
- **攻撃者と直接チャット**

という5種類以上の攻撃が組み合わさっており、非常に複雑で対処が難しいです。

### 3. ランサムウェアが「メイン目的ではない」場合もある
重要な点として、**身代金要求よりも、こっそりファイルを盗むことが主な目的**の場合が多いことが確認されています。被害者が気づかないまま、重要なデータが盗まれている可能性があります。

### 4. 攻撃者の「うっかりミス」で実態が判明
攻撃者自身の操作ミスにより、被害者のログやスクリーンショット、ツールなどが外部から見える状態になっていたため、セキュリティ研究者が詳細を把握できました。これは非常にまれな幸運でした。

## 対策・今後の展望

### WordPressサイト管理者向けの対策

もしあなたや家族・知人がWordPressサイトを運営している場合、以下を今すぐ確認してください：

| 対策 | 内容 |
|------|------|
| ✅ **WordPressを最新版に更新** | 管理画面から「更新」を必ず実施 |
| ✅ **プラグインを最新版に更新** | 使っていないプラグインは削除 |
| ✅ **強いパスワードを設定** | 管理者アカウントのパスワードを長く複雑にする |
| ✅ **二段階認証を導入** | ログイン時にスマホ認証を追加 |
| ✅ **セキュリティプラグインを導入** | Wordfenceなどのセキュリティツールを使う |
| ✅ **定期的にバックアップ** | 万が一感染しても復元できるように |

### 一般ユーザー向けの対策

| 対策 | 内容 |
|------|------|
| ✅ **ClickFix詐欺に注意** | 「コマンドをコピーして実行してください」という指示は絶対に従わない |
| ✅ **怪しいCAPTCHAに注意** | 「コマンドプロンプトを開いて貼り付けて」と言ってくるCAPTCHAは偽物 |
| ✅ **OSとソフトを最新に保つ** | Windowsアップデートを怠らない |
| ✅ **セキュリティソフトを使う** | ウイルス対策ソフトを導入・最新状態に保つ |
| ✅ **重要ファイルのバックアップ** | 外付けHDDやクラウドに定期的に保存 |

### 今後の展望
このような「複数の攻撃ツールを組み合わせた大規模キャンペーン」は、今後も増加すると予想されます。特に**古いWordPressサイトは格好の標的**となるため、サイト管理者のセキュリティ意識向上が急務です。

## 過去記事との関連

今回の記事では **ClickFix攻撃** が感染の入り口として使われていますが、これは近年非常に多くのマルウェアキャンペーンで使われる手口になっています。「本物っぽい画面でだましてコマンドを実行させる」というソーシャルエンジニアリング（人間の心理を利用した詐欺的手法）は、技術的な防御をすり抜けるため特に危険です。また、**WordPressの脆弱性を悪用した攻撃**も定番の手口となっており、「更新を怠ること」がいかに危険かを改めて示しています。
