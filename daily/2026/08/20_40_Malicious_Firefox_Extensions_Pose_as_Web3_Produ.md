# 40個の悪質なFirefox拡張機能がWeb3製品に偽装して仮想通貨ウォレットの秘密情報を盗んでいた

**元記事**: [40 Malicious Firefox Extensions Pose as Web3 Products to Steal Wallet Secrets](https://inl03.netline.com/ltr6/?_m=3n.009a.4061.sp0ao46r89.34aa)
**解説日**: 2026年8月21日

---

## 背景知識

このニュースを理解するために、まずいくつかのキーワードを押さえておきましょう。

### 🦊 ブラウザ拡張機能（アドオン）とは？
Firefoxなどのウェブブラウザに「あとからインストールして機能を追加できる小さなプログラム」のことです。たとえば「広告をブロックする拡張機能」「翻訳してくれる拡張機能」などがあります。便利な反面、**悪意のある拡張機能をインストールしてしまうと、ブラウザ上で行ったことをすべて監視・盗まれる危険があります。**

### 💰 仮想通貨（暗号資産）ウォレットとは？
ビットコインやイーサリアムなどの仮想通貨を管理するための「デジタルお財布」です。銀行口座に似ていますが、**「リカバリーフレーズ（シードフレーズ）」や「秘密鍵（プライベートキー）」という特別なパスワードを使って管理されます。**  
これが盗まれると、第三者があなたのウォレットにアクセスして仮想通貨を全額持ち去ることができてしまいます。

### 🌐 Web3とは？
ブロックチェーン技術を使った「次世代のインターネット」のことです。仮想通貨や、NFT（デジタルアート作品などの所有権証明）などがWeb3の代表例です。

### ☁️ Cloudflare Workers / Supabaseとは？
どちらもインターネット上でプログラムやデータを動かせるクラウドサービスです。本来は便利な開発ツールですが、今回は**攻撃者が盗んだ情報を送り届ける「隠れ基地」として悪用されています。**

---

## 何が起きたのか

セキュリティ企業「Socket」の研究チームが、**Firefoxの公式拡張機能ストアに登録されていた悪質な拡張機能を77個発見しました。** そのうち**40個は明確に「仮想通貨ウォレットを狙った情報泥棒」であることが確認されました。**

これらの拡張機能は、**OKX・Rabby Wallet・TronLinkなど、実在する有名な仮想通貨ウォレットサービスに偽装していました。** まるで本物のアプリのように見せかけて、ユーザーにインストールさせるのが手口です。

この攻撃キャンペーンは「**Offside Wallet Theft Factory（オフサイド・ウォレット窃盗工場）**」と名付けられ、**2026年3月ごろから活動が始まっていた**と見られています。

## 技術的な詳細

### 🎭 巧妙すぎる「偽装の二段構え」

驚くべきことに、これらの悪質な拡張機能は**最初から怪しい見た目ではありませんでした。**

> 📌 **「スポーツスコア」や「便利ツール」として登録** → しばらく後に**ウォレット窃盗機能を追加**

つまり、まず「サッカーや野球のスコアを表示するアプリ」として公式ストアに登録して信頼を得てから、あとでこっそりウォレットを盗む機能に作り替えるという手口です。同じIDを使い続けるため、ストアの審査をすり抜けやすくなっています。

### 🔍 40個の悪質な拡張機能の内訳

| 種類 | 数 | 手口 |
|---|---|---|
| Supabase（クラウドサービス）を使って偽ページを表示 | 7個 | 状況に応じてフィッシングページを動的に切り替え |
| リカバリーフレーズ・秘密鍵を盗んでCloudflare経由で送信 | 15個 | 最も危険！ウォレットの「マスターキー」を盗む |
| Rabbyウォレットの改ざん版（暗号化前のデータを横取り） | 13個 | 保存される直前のデータを盗む |
| ハードコードされたサーバーにパスワード等を送信 | 5個 | クリップボードの内容（コピーした文字列）も狙う |

### 🧰 盗みの2つの方法

1. **リモートで偽ウォレット画面を読み込む**  
   → インターネット上の別の場所に用意された偽のウォレット入力画面を表示し、そこで入力させる

2. **拡張機能自体の中に盗む機能を仕込む**  
   → 拡張機能のプログラム内部に情報を盗むコードを直接埋め込んでいる

### 🎲 残りの37個は「準備段階」か？

残り37個はまだ明確な窃盗機能は確認されていませんが、コードや仕組みが40個と共通しており、**将来的に同じように「切り替え」される可能性がある**と研究者は警告しています。

## なぜ重要なのか

### 💸 被害は「取り返しがつかない」

銀行の不正送金であれば、カード会社や銀行に連絡して止めることができる場合があります。しかし仮想通貨の場合、**秘密鍵やリカバリーフレーズが盗まれてウォレットを空にされると、原則として取り戻す手段がありません。**

研究者のキリル・ボイチェンコ氏はこう述べています：

> 「たった1回のインストール成功で、インストールを繰り返すコストをはるかに上回る価値のリカバリーフレーズ・秘密鍵・ウォレット情報が手に入る」

つまり、**攻撃者にとってコスパが非常によい犯罪**なのです。

### 🔄 「使い捨て」戦術で検出を逃れ続ける

- 名前やIDをどんどん変えて新しい拡張機能を登録
- 既存の拡張機能のIDを使い回す
- 悪質な機能をバラバラの拡張機能に分散させる
- クラウドサービスを中継地点にして追跡を困難にする

こうした工夫により、**1つの拡張機能がストアから削除されても、次々と別の偽装版が現れる**という「いたちごっこ」状態になっています。

## 対策・今後の展望

### ✅ あなたにできる具体的な対策

1. **🔍 拡張機能を入れる前に必ず確認する**
   - レビュー数・評価・公開日・開発者名を確認する
   - 公式サービス（例：Rabby Wallet）のウェブサイトから直接リンクされているものかを確認する
   - 不自然に新しいのに高評価の拡張機能は怪しい

2. **🧹 不要な拡張機能は今すぐ削除する**
   - 使っていない拡張機能は削除するのが基本

3. **🔐 仮想通貨の秘密情報はブラウザ上で入力しない**
   - リカバリーフレーズや秘密鍵は、本物のアプリ以外には絶対に入力しない
   - 疑わしい画面が出たら、まずブラウザを閉じて公式サイトを直接確認する

4. **📋 クリップボードに秘密情報をコピーしない**
   - 今回の拡張機能はコピーした文字列も盗みます。パスワードや秘密鍵のコピーは最小限に

5. **🔒 ハードウェアウォレットを使う**
   - 「Ledger」などのハードウェアウォレット（物理デバイス）を使えば、秘密鍵がインターネットから切り離されるため安全性が大きく高まります

### 🔭 今後の展望

Mozillaはこれらの拡張機能を順次削除していますが、攻撃者は次々と新しい偽装版を登録しています。ストア側のAIによる審査強化や、コード共有の検出精度向上が求められています。

## 用語解説

| 用語 | 意味 |
|---|---|
| **ブラウザ拡張機能（アドオン）** | Firefoxなどに追加できる小さなプログラム |
| **Web3** | ブロックチェーン技術を使った次世代インターネットの総称 |
| **仮想通貨ウォレット** | 仮想通貨を管理するデジタルお財布 |
| **リカバリーフレーズ（シードフレーズ）** | ウォレットを復元するための12〜24個の単語。これが盗まれると終わり |
| **秘密鍵（プライベートキー）** | ウォレットへのアクセスに使う暗号。銀行のマスターパスワードのようなもの |
| **フィッシング** | 本物そっくりの偽サイト・偽画面でユーザーをだまして情報を入力させる攻撃 |
| **Cloudflare Workers** | クラウド上でプログラムを動かせるサービス（今回は盗んだ情報の中継に悪用）|
| **Supabase** | クラウドデータベースサービス（今回は攻撃の「リモコン」として悪用）|
| **C2（Command and Control）** | 攻撃者がマルウェアを遠隔操作するためのサーバー |
| **クリップボード** | コピー（Ctrl+C）したときに一時的にデータが保存される場所 |
| **ハードコード** | プログラムの中に値を直接書き込むこと（変更が難しい固定値）|
| **キーリング（keyring）** | 複数の暗号鍵をまとめて管理する仕組み |

---

> 💬 **まとめ**：「公式ストアにあるから安全」は大きな誤解です。今回の事件は、攻撃者がいかに巧みにユーザーの信頼を利用するかを示しています。仮想通貨を使っている人はもちろん、ブラウザ拡張機能を使うすべての人が気をつけるべき話題です。
