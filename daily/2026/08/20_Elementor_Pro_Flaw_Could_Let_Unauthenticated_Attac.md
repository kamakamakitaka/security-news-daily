# Elementor Proの欠陥により、ログインなしの攻撃者がPHPファイルをアップロードしてコードを実行できてしまう問題

**元記事**: [Elementor Pro Flaw Could Let Unauthenticated Attackers Upload PHP and Execute Code](https://inl03.netline.com/ltr6/?_m=3n.009a.4061.sp0ao46r89.34ag)
**解説日**: 2026年8月21日

---

## 背景知識

まず、このニュースを理解するために必要な言葉を整理しましょう。

### WordPressとプラグインって何？
**WordPress（ワードプレス）** は、世界中のウェブサイトの約40%以上で使われているサイト作成ツールです。ブログや企業サイト、ネットショップなど、さまざまなサイトがWordPressで作られています。

**プラグイン** は、WordPressに機能を追加できる「拡張パック」のようなものです。スマホのアプリと同じようなイメージで、インストールするだけでサイトに新機能が加わります。

### Elementor Proとは？
**Elementor Pro（エレメンター・プロ）** は、WordPressで使われる超人気のプラグインで、**世界中で数百万サイト以上** に導入されています。ドラッグ＆ドロップでウェブサイトのデザインを簡単に作れるツールです。コードを書かなくてもプロっぽいサイトが作れるため、多くのサイト運営者に愛用されています。

### PHPって何？
**PHP** は、ウェブサイトを動かすために使われるプログラミング言語です。WordPressそのものもPHPで書かれています。PHPのファイルをサーバーに置くと、それをブラウザから実行することができます。つまり、**悪意のあるPHPファイルを置かれると、サーバー上で何でも好き勝手に命令できてしまう** という危険があります。

### ファイルアップロードって何が危ないの？
「履歴書を送ってください」「写真を添付してください」といったフォームは、ファイルをサーバーに送る機能ですよね。このとき、**悪意のあるファイル（PHPスクリプトなど）を送り込まれると大変** なことになります。本来なら「.php」という拡張子のファイルはブロックするように設定されているはずなのですが、今回はその仕組みに穴がありました。

## 何が起きたのか

セキュリティ研究者の **Tin Pham（ティン・ファム）氏** が、Elementor Proというプラグインに **非常に危険な欠陥（脆弱性）** を発見し、開発元に報告しました。

- **発見・報告日**: 2026年7月16日
- **修正版リリース日**: 2026年8月19日（バージョン4.2.2）
- **危険度スコア**: 10点満点中 **9.0点**（かなり高い！）
- **管理番号**: CVE-2026-32475

この欠陥を使うと、**サイトにログインしていない人（完全な第三者）でも** 、悪意のあるPHPファイルをサーバーにアップロードして、サーバー上でコードを実行できてしまいます。

「コードを実行できる」というのは、例えば：
- サーバー内のデータをすべて盗む
- サイトのページを書き換える
- そのサーバーを踏み台にして別の攻撃をする

…といったことが自由にできてしまうということです。

## 技術的な詳細

少し難しいですが、できるだけわかりやすく説明します。

### 欠陥の場所
問題は **Elementor Proの「フォーム機能」** の中にある **「ファイルアップロードフィールド」** にあります。

例えば「お問い合わせフォームで、ファイルを添付して送信できる」という機能が対象です。就職応募フォームの「履歴書を添付」や、サポートフォームの「スクリーンショットを添付」などに使われます。

### なぜ欠陥が生まれたのか

🔑 **ポイント：チェックと実行が「バラバラなループ」で行われていた**

普通、ファイルをアップロードするとき、サーバー側では：
1. 「このファイルの拡張子は許可されているか？（.phpはNG！）」← **検査ステップ**
2. 「OKなら、サーバーの保存場所にファイルを移動する」← **移動ステップ**

という2段階の処理をします。

しかし今回の欠陥では、この **①検査ステップ** と **②移動ステップ** が **別々のループ処理** で動いており、**空のファイルエントリの扱い方が違いました**。

攻撃者はこの隙を突き、**同じフィールドに対して2つのファイルパーツを同時に送信** することで：

```
1つ目のファイル → 拡張子チェックは通る（正常に見える）
2つ目のファイル（PHPスクリプト） → チェックをスキップして移動ステップへ直行！
```

というズル抜けができてしまいました。

まるで、**スーパーのレジで「この商品はスキャン済みです」と嘘をついて、実は悪いものを袋に入れて持ち出す** ようなイメージです。

### アップロードされたファイルはどこに置かれる？
悪意あるPHPファイルは以下の場所に置かれます：

```
wp-content/uploads/elementor/forms/【ランダムな名前】.php
```

このURLをブラウザで開くだけで、攻撃者はそのPHPコードを実行できてしまいます。

### 攻撃に必要な条件はたった1つ
- 対象サイトに **「ファイル添付フィールドつきのElementorフォーム」が設置されているページ** が1つでも存在すること

それだけです。ログイン不要。特別な設定も不要。フィールドの「必須」設定がOFFがデフォルトなので、ほとんどのサイトがそのままでリスクにさらされていました。

## なぜ重要なのか

### 影響を受けるサイトが非常に多い
Elementor Proは世界中で何百万ものサイトで使われています。しかも「ファイル添付フォーム」は：

- 就職応募フォーム（「履歴書を送ってください」）
- 写真や証明書のアップロードフォーム
- サポートチケット（「スクショを添付してください」）

などで **日常的・ごく普通に使われている** 機能です。「特殊な設定をしていたから被害を受けた」ではなく、**デフォルトの状態でも危ない** という点が特に深刻です。

### 「認証不要」の恐ろしさ
通常、危険な攻撃には「管理者権限でログインできる」などの前提条件が必要です。しかし今回は **完全な第三者（ログイン不要）** でも攻撃可能。インターネットに公開されているサイトなら、世界中の誰でも攻撃者になれてしまいます。

### 危険度スコア9.0という高さ
CVSSスコアは脆弱性の危険度を0〜10で示す指標です。9.0は「緊急対応が必要なレベル」に相当します。

### 同時期にWordPress本体にも別の脆弱性
さらに追い打ちをかけるように、**WordPress本体（バージョン4.7〜7.0）** にも別の危険な欠陥（CVE-2026-65640、スコア8.8）が見つかりました。こちらは「著者（Author）権限」のユーザーが悪意のある画像ファイルをアップロードすることでコードを実行できてしまうもの。複数ライターがいるニュースサイト、会員制サイト、クライアント向けサイトなどでは特に注意が必要です。

### 「StopAndProtect」作戦との関係
記事では **「StopAndProtect（ストップアンドプロテクト）」** と名付けられた大規模な攻撃キャンペーンも紹介されています。数千ものWordPressサイトがすでに乗っ取られ、マルウェアの配布や攻撃の踏み台として使われているというものです。今回のような脆弱性が、こうした攻撃の入口になる可能性があります。

## 対策・今後の展望

### ✅ すぐにやること

1. **Elementor Proをバージョン4.2.2以上にアップデートする**
   - 管理画面 → プラグイン → Elementor Pro → 更新
   - これが最も重要な対策です！

2. **WordPress本体もバージョン7.0.4以上にアップデートする**
   - WordPress本体の脆弱性も修正済みのバージョンが出ています

3. **他のプラグインやテーマも最新版に保つ**
   - 「あとでやろう」は危険です。更新通知が来たらすぐに対応しましょう

### 🔍 確認してほしいこと

4. **知らないアカウントが増えていないか確認する**
   - 管理画面 → ユーザー → 見知らぬアカウントがあれば即削除

5. **知らないプラグインがインストールされていないか確認する**
   - 管理画面 → プラグイン → 見知らぬものがあれば即削除

6. **サイトが勝手に別のページに飛ばしたり、変なポップアップが出ていないか確認する**
   - これらは感染のサインかもしれません

7. **アップロードフォルダに不審なPHPファイルがないか確認する**
   - `wp-content/uploads/elementor/forms/` の中を確認

## 過去記事との関連

以前、**「NASAの宇宙機操作ツールに重大な脆弱性！パスワードなしで宇宙船に命令できてしまう欠陥が発見された」** という記事を解説しました。あの記事でも「認証（ログイン確認）なしで不正な操作ができてしまう」という問題が核心でした。

今回のElementor Proの欠陥も、まったく同じ「**認証不要で攻撃できる（Unauthenticated Attack）**」という性質を持っています。セキュリティの世界では、「ログイン確認なしに重要な操作ができてしまう」系の脆弱性は特に危険視されており、宇宙船の制御システムからウェブサイトのフォームまで、あらゆる分野で繰り返し発生する根本的な設計ミスの一種です。

また、**「40個の悪質なFirefox拡張機能がWeb3製品に偽装して仮想通貨ウォレットの秘密情報を盗んでいた」** の記事でも触れましたが、攻撃者は「普通に見えるもの（フォームの添付機能・ブラウザ拡張機能）」を悪用するケースが増えています。今回も「よくある就職応募フォーム」「サポートフォーム」という日常的な機能が攻撃の入口になっている点は、同じ流れと言えるでしょう。

## 用語解説

| 用語 | 意味 |
|------|------|
| **WordPress（ワードプレス）** | 世界で最も使われているウェブサイト作成・管理ツール |
| **Elementor Pro（エレメンター・プロ）** | WordPressで使える人気の有料デザインプラグイン |
| **プラグイン** | WordPressに機能を追加できる拡張パック（スマホのアプリのようなもの） |
| **PHP** | ウェブサーバー上で動くプログラミング言語。WordPressもPHPで作られている |
| **脆弱性（ぜいじゃくせい）** | ソフトウェアやシステムにある「セキュリティ上の穴・弱点」 |
| **CVE（シーブイイー）** | 発見された脆弱性に割り振られる管理番号（例：CVE-2026-32475） |
| **CVSSスコア** | 脆弱性の危険度を0〜10で示す指標。9.0以上は「緊急」レベル |
| **認証（Authentication）** | 「あなたは誰ですか？」を確認すること。ログインがその代表例 |
| **認証不要（Unauthenticated）** | ログインなしでも攻撃できてしまうこと。非常に危険 |
| **リモートコード実行（RCE）** | 離れた場所から攻撃者がサーバー上でプログラムを実行できてしまうこと。被害の中では最悪レベル |
| **拡張子チェック** | アップロードされたファイルの種類（.jpg, .phpなど）を確認すること |
| **ブロックリスト（Blocklist）** | 「これはダメ」というリスト。今回はこれをすり抜けられてしまった |
| **Patchstack（パッチスタック）** | WordPressのセキュリティ問題を専門に調査・報告しているセキュリティ会社 |
| **Imagick / Ghostscript** | 画像や文書ファイルを処理するためのサーバーソフトウェア。WordPress本体の別脆弱性に関係する |
| **StopAndProtect** | 数千のWordPressサイトを乗っ取り、悪用する大規模攻撃キャンペーンの名称 |
| **マルウェア** | ウイルスや不正プログラムなど、悪意のあるソフトウェアの総称 |
