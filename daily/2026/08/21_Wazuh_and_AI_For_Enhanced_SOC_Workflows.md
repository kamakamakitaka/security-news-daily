## 背景知識

まず、この記事を理解するためにいくつかの基本的な考え方を押さえておきましょう。

### 🏢 SOC（セキュリティ・オペレーション・センター）とは？

「SOC（ソック）」とは、企業や組織のコンピューターやネットワークを**24時間365日監視する専門チーム・部署**のことです。

学校に例えると、「生徒の安全を守るために廊下を見回りする先生たちの専門チーム」のようなイメージです。ただしその規模は桁違いで、1日に**数百万件ものアラート（警告）**が飛んでくることがあります。

### 🚨 アラートの洪水問題

SOCのアナリスト（分析担当者）は毎日膨大な数の警告を受け取ります。たとえばこんなものです：
- 「このパソコンが変なサイトにアクセスした」
- 「ログイン失敗が100回続いた」
- 「大量のファイルが急に暗号化された」

これが1日に何百万件もくると、**本当に危険な攻撃を見逃してしまう**リスクがあります。これを「アラート疲れ（Alert Fatigue）」と呼びます。

### 🛡️ Wazuhとは？

**Wazuh（ワズー）** は、オープンソース（誰でも無料で使える）のセキュリティ監視プラットフォームです。パソコン・サーバー・クラウド環境などを一元的に監視し、異常を検知してくれるツールです。世界中の企業・組織が採用しています。

### 🤖 AIとセキュリティの関係

AI（人工知能）はセキュリティの世界でも急速に普及しています。ただし、**攻撃側もAIを使う**という現実があります：
- 🔴 **攻撃者側**：AIを使って自動的に大量の攻撃を仕掛けたり、脆弱性（弱点）を素早く見つけたりする
- 🔵 **防御者側**：AIを使って脅威を素早く検知したり、対応を自動化したりする

## 技術的な詳細

### 🤖 Wazuh AI Analystの仕組み

```
あなたの環境のセキュリティデータ
        ↓
  Amazon Bedrock（AWSのAI基盤）
  + Anthropic Claude（高性能AIモデル）
        ↓
  自動でレポート作成・メール送信
```

このAIが自動的にやってくれること：
| 機能 | 内容 | 例え |
|------|------|------|
| アラート集計 | 警告の件数・種類をまとめる | 「今日は風邪ひきが30人いました」的な報告 |
| 脆弱性の一覧 | 今アクティブな弱点を整理 | 「鍵がかかっていない扉は3箇所です」 |
| セキュリティ態勢の要約 | 全体的な安全レベルを評価 | 学校の安全点検レポートのようなもの |
| PDF レポート | 上記を全部まとめた報告書 | 定期健康診断の結果表 |

👉 設定不要・自動でメールが届く、というのが大きな特徴です！

### 🔒 プライバシーへの配慮

> 「サブスクリプションデータは第三者と共有されず、AIモデルの学習にも使用されない」

つまり、**あなたの会社のセキュリティデータがAIの学習に使われない**という約束があります。

セキュリティ対策：
- 📡 送信は暗号化
- 🏝️ 処理は隔離された環境で実施
- 🗑️ 永続的な保存はなし

---

### 🦙 自社内で完結する「Llama 3 + Ollama」連携

```
インターネット
    ✕（データを外に出さない！）

自社サーバー内
 ┌──────────────────────────────┐
 │  Wazuh（セキュリティログ収集）│
 │         ↓                   │
 │  Ollama（AIを動かす仕組み）  │
 │  + Llama 3（Metaのオープン  │
 │    ソースAIモデル）          │
 │         ↓                   │
 │  チャットで質問できる！      │
 └──────────────────────────────┘
```

これを使うと、アナリストが自然な言葉で「**先週、怪しいログインが一番多かった時間帯はいつ？**」などと質問できるようになります。

**FAISS（フェイス）** というのはAIが大量のログを素早く検索するための仕組みです。図書館で言えば「超高速な索引システム」のようなものです。

**LangChain（ランクチェーン）** はAIと各種ツールをつなぎ合わせるための「接着剤」のようなフレームワーク（枠組み）です。

## なぜ重要なのか

### 📊 現状の深刻な課題

現代のSOCアナリストは以下のような問題を抱えています：

1. **情報過多** → 1日に数百万件のアラート
2. **ツールの切り替え疲れ** → ダッシュボード、ドキュメント、脆弱性DBを行ったり来たり
3. **複雑な環境** → 社内サーバー＋クラウドと、監視対象が分散している

これはつまり、**人間だけでは限界**という状況です。AIがそこを補うことで：

- ✅ 重要なアラートを見逃しにくくなる
- ✅ 調査時間が短縮される
- ✅ アナリストがより高度な判断に集中できる

### 🌍 セキュリティ全体への影響

WazuhのようなオープンソースツールにAIが組み込まれることは、**大企業だけでなく中小企業も高度なセキュリティを低コストで実現できる**ことを意味します。これはセキュリティの民主化とも言えます。
