## 背景知識

### CIS（Center for Internet Security）とは？

**CIS（インターネットセキュリティセンター）** は、アメリカに本部を置く非営利団体で、「世界中の組織がサイバー攻撃から身を守るための標準ルールを作る」ことを使命としています。

学校に例えるなら、「全国統一の安全マニュアルを作る文部科学省みたいな存在」です。

CISが作る代表的なものに以下があります：

| 名称 | 内容 |
|------|------|
| **CIS Controls** | 組織が実施すべきセキュリティ対策の優先リスト |
| **CIS Benchmarks** | OSやソフトウェアの安全な設定基準 |
| **CIS SecureSuite** | 上記ツール・リソースをまとめたサービス |

---

### CIS SecureSuiteとは？

**CIS SecureSuite** は、企業や団体がサイバーセキュリティ対策を実施するために使える「ツールとリソースのセット」です。

具体的には以下のようなものが含まれます：

```
CIS SecureSuiteの主な内容
├── CIS Benchmarksの全文PDFへのアクセス
├── 設定チェックツール（CIS-CAT Pro）
├── セキュリティポリシーのテンプレート
└── セキュリティ評価・診断ツール
```

## 技術的な詳細

### CIS SecureSuiteで何ができるの？

たとえば、あなたが会社のIT担当者だとします。新しいWindowsサーバーを設置したとき、「このサーバー、本当に安全に設定できてる？」と心配になりますよね。

そこで使うのが **CIS Benchmarks + CIS-CAT Pro** です：

```
【設定チェックの流れ】

① CIS Benchmarkを参照
   └→「Windowsサーバーはこの設定が推奨」という基準を確認

② CIS-CAT Pro（チェックツール）を実行
   └→ 実際のサーバー設定を自動スキャン

③ レポートが出力される
   └→「◯項目OK、△項目は要改善」と一覧で表示

④ 改善作業を実施
   └→ セキュリティレベルが向上！
```

## なぜ重要なのか

### セキュリティ標準の重要性

CISの基準は、世界中の企業・政府機関・学校などで使われており、**グローバルスタンダード**として認められています。

日本でも、金融庁や経産省が出すセキュリティガイドラインで参照されることがあります。

```
【CIS基準が重視される理由】

一般企業 ──→ 「何から手を付ければいい？」がわかる
政府機関 ──→ 「監査基準として使える」
中小企業 ──→ 「専門家がいなくてもチェックリスト化できる」
```

### 割引キャンペーンの意義

セキュリティツールは一般的に**コストが高く**、特に中小企業や非営利団体にとっては導入のハードルが高いのが現実です。

15%割引は小さく見えますが、年間費用が数十万円規模になることもあるため、**実際の節約額はかなり大きくなる**場合があります。
