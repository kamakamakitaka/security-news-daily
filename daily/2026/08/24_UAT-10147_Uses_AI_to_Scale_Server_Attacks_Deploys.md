# AIを使ってサーバー攻撃を自動化！「UAT-10147」グループの手口を解説

**元記事**: [UAT-10147 Uses AI to Scale Server Attacks, Deploys SPECTRE With EDR Bypass and Linux Rootkit](https://inl03.netline.com/ltr6/?_m=3n.009a.4064.sp0ao46r89.34eg)
**解説日**: 2025年7月11日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を説明します。

### 🖥️ WebサーバーとIISって何？
Webサーバーとは、みなさんが普段アクセスしているウェブサイトを「提供する側」のコンピューターです。ウェブサイトのデータを保管して、ブラウザからのリクエストに応答しています。「IIS（Internet Information Services）」は、Microsoftが作ったWindowsパソコン向けのWebサーバーソフトです。

### 🤖 AIを使ったサイバー攻撃って？
みなさんが学校のレポートにAIを活用するように、攻撃者もAIを使って攻撃を効率化しています。AIに「この脆弱性をどう突けばいいか」と聞いたり、攻撃コードを自動生成させたりすることが可能になっています。

### 🔓 「脆弱性」と「CVE」って何？
**脆弱性（ぜいじゃくせい）**とは、ソフトウェアの「穴」や「バグ」のことで、攻撃者に悪用される可能性があるものです。**CVE（Common Vulnerabilities and Exposures）**とは、世界共通の「脆弱性の番号」で、例えば「CVE-2022-0847」のように記録されます。図書館の本に ISBN番号があるように、脆弱性にも固有の番号が付いています。

### 🐧 LinuxとWindowsのサーバー
世界中のサーバーは、大きく分けてWindowsとLinuxという2種類のOS（基本ソフト）で動いています。今回の攻撃グループは**両方**を標的にしているのが特徴です。

## 何が起きたのか

セキュリティ研究者が、**「UAT-10147」という中国語圏のサイバー犯罪グループ**の活動を詳しく調査・公開しました。

このグループは世界中のWindowsおよびLinuxサーバーを攻撃しており、被害対象となっている主な分野は以下の通りです：

| 分野 | 具体例 |
|------|--------|
| 🎓 教育 | 大学・学校のWebサイト |
| 📺 メディア | ニュースサイト・動画配信 |
| 💻 テクノロジー | IT企業のサーバー |
| 🎮 ゲーム | オンラインゲームサービス |

攻撃の主な被害国は**ブラジル・ボリビア・中国・カナダ・ベトナム**ですが、攻撃者が持っていたターゲットリストには**約17万件のURL（アドレス）**が記載されており、狙われている国のトップ5は**アメリカ・インド・イギリス・ドイツ・オランダ**です。

つまり、**すでに被害が出ている国**と、**これから狙おうとしている国**が別々に存在するという恐ろしい状況です。

---

## 技術的な詳細

### 🎯 攻撃の目的は主に2つ

1. **SEO詐欺（Search Engine Optimization Fraud）**
   SEOとは「Googleなどの検索エンジンで上位に表示されるための工夫」のことです。攻撃者は他人のWebサイトに不正なコードを仕込み、そのサイトを悪用して自分たちのサイトの検索順位を不正に上げる詐欺を行います。まるで他人の土地に勝手に看板を立てるようなものです。

2. **データ窃取（情報の盗み取り）**
   サーバーに保存されている個人情報や機密情報を盗み出します。

---

### 🔄 攻撃の流れ（ステップバイステップ）

```
①　既知の脆弱性を使ってサーバーに侵入
        ↓
②　自動スクリプト（プログラム）を実行してマルウェアをインストール
        ↓
③　権限昇格ツールで「管理者権限」を奪取
        ↓
④　セキュリティソフトの監視を無効化・回避
        ↓
⑤　証拠隠滅（最初に使ったツールを削除）
        ↓
⑥　バックドアを設置して長期間潜伏
        ↓
⑦　SEO詐欺・データ盗難を実行
```

---

### 🤖 AIの活用方法（ここが新しい！）

UAT-10147がこれまでの攻撃グループと違うのは、**攻撃の各段階でAIを活用している**点です。

| 攻撃フェーズ | AIの使い方 |
|------------|-----------|
| 侵入準備 | 攻撃コード（エクスプロイト）の改良 |
| 実行中 | エラーのデバッグ・修正 |
| 侵入後 | 後続作業の自動化 |
| 確認作業 | 攻撃が成功したかの検証 |
| 記録 | 作戦マニュアルの自動生成 |

AIを使うことで、**少人数でも大規模な攻撃が可能**になっています。これは非常に危険なトレンドです。

---

### 🦠 使われている主なマルウェア・ツール

#### Windows向け
- **Quasar RAT（クァサーRAT）**：遠隔操作ツール。攻撃者がまるでそのパソコンの前に座っているかのように操作できます
- **BadIIS**：IIS（Webサーバー）に感染する特殊なマルウェア。「マルウェア・アズ・ア・サービス（MaaS）」として他の犯罪グループにも貸し出されています（後述）
- **Gh0stCringe**：バックドア（裏口）型マルウェア
- **SPECTRE**：新発見のマルウェア。WindowsとLinux両方で動く「クロスプラットフォーム型」

#### Linux向け
- **Noodle RAT**：有名なマルウェア「Gh0st RAT」の改良版
- **Meterpreter**：攻撃フレームワーク「Metasploit」の一部。侵入後の操作に使われる

#### 悪用されたオープンソースツール（本来は合法なセキュリティ研究用）
- **Metasploit**：ペネトレーションテスト（侵入テスト）用フレームワーク
- **PentestGPT / DeepAudit**：AIを使ったセキュリティテストツール（これを悪用！）

---

### 💡 「マルウェア・アズ・ア・サービス（MaaS）」って何？

BadIISは「マルウェア・アズ・ア・サービス（MaaS）」モデルで動いています。これはNetflixのような「サブスクリプション型」のマルウェアです。

```
一般的なサービス：Netflix（月額を払えば誰でも映画が見られる）
    ↓ これと同じ仕組みで
MaaS：月額（または使用料）を払えば、犯罪グループが
      マルウェアを提供・サポートしてくれる
```

つまり、技術力がない犯罪者でも「お金を払えば」高度なマルウェアを使える時代になっています。

---

### 🔒 証拠隠滅とセキュリティ回避の工夫

このグループが特に巧妙なのは、**バレないための工夫**をしている点です：

- **「Google Chrome Start」という名前の偽タスク**を作成：一見すると正規のChromeの動作に見えます
- **Microsoft Defenderの除外設定を変更**：Windowsのウイルス対策ソフトが自分たちのマルウェアを検出しないよう設定します
- **最初に使ったツールを削除**：フォレンジック（デジタル鑑識）による調査を妨害します
- **正規のクラウドサービスを経由**してデータを送信：通信が「普通のクラウド通信」に見えるため検出が難しくなります

## なぜ重要なのか

### 📊 影響の大きさ

1. **規模が圧倒的**：ターゲットリストに**約17万件のURL**が含まれており、自動化によって大量のサーバーが短期間で狙われる可能性があります

2. **AIが「攻撃の民主化」を加速**：以前は高度な技術者でないとできなかった攻撃が、AIの助けで誰でも実行できるようになりつつあります

3. **両OS（WindowsとLinux）が標的**：「Linuxは安全」という神話が崩れています

4. **新しいマルウェア「SPECTRE」の発見**：これまで知られていなかった脅威が確認されました。特にEDR（後述）を回避する能力を持っています

5. **教育・ゲーム・メディアが狙われている**：日本の学校や企業も無関係ではありません

## 対策・今後の展望

### 🛡️ サーバー管理者向けの対策

| 対策 | 内容 |
|------|------|
| **パッチ適用の徹底** | CVE番号が付いた脆弱性は速やかに修正する |
| **IISの設定確認** | 不審なモジュールが追加されていないか確認 |
| **スケジュールタスクの監視** | 「Google Chrome Start」のような偽タスクがないか確認 |
| **EDRの導入・最新化** | エンドポイント検出・対応ツールを最新状態に保つ |
| **ログの監視** | 不審な通信や権限昇格の試みを検出する |
| **ゼロトラスト原則** | 「社内だから安全」と思わず、すべての通信を疑う |

### 🧑‍🎓 一般ユーザー向けのポイント

- 利用しているWebサービスが侵害された場合、個人情報が漏れる可能性があります
- **パスワードの使い回しをしない**（1つのサービスが漏れても他に影響しないように）
- **多要素認証（MFA）を使う**：ログイン時にSMSやアプリによる認証を追加する

### 🔮 今後の展望

> 「AIを使って攻撃を自動化・スケールアップする」というトレンドは今後さらに加速すると予測されます。防御側もAIを積極的に活用した「AI vs AI」の時代が来ています。

## 過去記事との関連

以前、**ミャンマー政府を狙った「Operation QUICSILVER」**について解説しましたが、今回のUAT-10147も**国家・政府・大規模組織を狙う高度なサイバー脅威**という点で共通しています。

ただし違いもあります：

| | Operation QUICSILVER | UAT-10147 |
|---|---|---|
| **目的** | 主にスパイ活動 | SEO詐欺・データ窃取（金銭目的） |
| **標的** | ミャンマー政府・IT業界 | 教育・メディア・ゲーム・技術（世界規模） |
| **規模** | 標的を絞った攻撃 | 17万件のURLリストによる大規模攻撃 |
| **AI活用** | 特記なし | 攻撃全フェーズでAIを活用 |

また、**Keycloakの脆弱性**（前回解説）のように、ソフトウェアの「既知の穴（脆弱性）」を突く攻撃は今回も同様です。脆弱性の修正（パッチ適用）がいかに重要かが、改めて確認できます。

## 用語解説

| 用語 | 読み方 | 説明 |
|------|--------|------|
| **マルウェア** | - | 悪意のあるソフトウェアの総称（ウイルス・ランサムウェアなど） |
| **RAT** | ラット | Remote Access Trojan。遠隔操作を可能にするトロイの木馬型マルウェア |
| **バックドア** | - | 攻撃者が後から侵入できるように仕込む「裏口」 |
| **ルートキット** | - | OSの深い部分に潜み、自身の存在を隠すマルウェア |
| **権限昇格** | - | 一般ユーザー権限から管理者権限を不正に奪うこと |
| **RCE** | - | Remote Code Execution（遠隔コード実行）。外部から自由にコードを実行できる最も危険な脆弱性の一種 |
| **EDR** | イーディーアール | Endpoint Detection and Response。PCやサーバーへの攻撃を検出・対応するセキュリティツール |
| **Webシェル** | - | Webサーバーに設置される遠隔操作用の入り口。ブラウザから操作可能 |
| **C2サーバー** | シーツーサーバー | Command and Control（指令・制御）サーバー。攻撃者がマルウェアに命令を送るための拠点 |
| **フォレンジック** | - | 犯罪捜査のためにデジタル機器の証拠を収集・分析する技術 |
| **MaaS** | マース | Malware as a Service。マルウェアをサービスとして提供するビジネスモデル |
| **SEO詐欺** | - | 検索エンジンの順位を不正に操作する詐欺行為 |
| **CVE** | シーブイイー | Common Vulnerabilities and Exposures。脆弱性に付けられる世界共通の識別番号 |
| **EfsPotato** | - | Windowsの権限昇格に使われる攻撃ツール |
| **オープンディレクトリ** | - | インターネット上に誰でもアクセスできる状態で公開されたフォルダ。今回これが発見の糸口になった |

---

> 💬 **まとめ**：UAT-10147は、AIを攻撃に組み込んだ新世代のサイバー犯罪グループです。17万件ものサイトを標的にリストアップし、既知の脆弱性を自動で突いて侵入する手口は、「量でカバーする」という戦略です。防御側は、**脆弱性の早期修正**と**AIを活用した監視の強化**が求められています。
