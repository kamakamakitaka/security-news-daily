# 24個のnpmパッケージが「unpkg」ミラーを悪用して偽のCloudflare CAPTCHAページを配信

**元記事**: [24 npm Packages Abuse unpkg Mirrors to Host Fake Cloudflare CAPTCHA Pages](https://inl03.netline.com/ltr6/?_m=3n.009a.4065.sp0ao46r89.34f6)
**解説日**: 2025年7月14日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な概念を説明します。

### 📦 npmとは？
**npm（Node Package Manager）** は、プログラマーが使う「部品の倉庫」のようなものです。  
料理で例えると、「調味料や食材をまとめて売っているスーパー」のようなイメージです。プログラマーはここから便利な部品（パッケージ）をダウンロードして、自分のプログラムに組み込みます。世界中の開発者が毎日利用している非常に信頼度の高いサービスです。

### 🪞 unpkgとは？（ミラーサービス）
**unpkg** は、npmに登録されたパッケージのファイルを、そのままウェブ上で公開・配信してくれる「中継サービス（CDN）」です。  
例えば、npmに登録されたファイルを `unpkg.com/パッケージ名/ファイル名` という形でURLアクセスできるようになります。**unpkg.com はCloudflareと同様、多くの人に「安全・信頼できる」と認識されているドメイン**です。

### 🤖 CAPTCHAとは？
「私はロボットではありません」のチェックボックスや、画像を選ぶあれです。  
**CAPTCHA** は「あなたが人間かどうかを確認する仕組み」で、Cloudflare（大手セキュリティ企業）がよく使っているものが有名です。普段、怪しくないサイトでも表示されることがあるため、ユーザーが「これは普通のことだ」と思いやすいのが特徴です。

### 🪤 ClickFix（クリックフィックス）とは？
**ClickFix** は近年流行している詐欺の手口です。  
「エラーが発生しました。以下の手順で修正してください」などと表示し、ユーザーに**自分でマルウェア（ウイルス）を実行させる**ように誘導する攻撃です。偽のCAPTCHAページもこの手口によく使われます。

### 🎣 フィッシング（Phishing）とは？
本物そっくりの偽サイトに誘導して、パスワードや個人情報を盗む詐欺です。  
「釣り（fishing）」のように、ユーザーを「釣る」ことからこの名前がついています。

## 何が起きたのか

セキュリティ会社「OX Security」の研究者たちが、悪意ある攻撃者による新しい巧妙な攻撃キャンペーンを発見しました。

**攻撃の流れをざっくり説明すると：**

1. 攻撃者が **npmに24個の偽パッケージを登録**する
2. 各パッケージの中には **偽のCloudflare CAPTCHAページ（HTML）** が仕込まれている
3. unpkgなどのミラーサービスがそのファイルを自動的に公開する
4. `unpkg.com/パッケージ名/index.html` というURLで **信頼できるドメインから偽ページが配信**される
5. このURLを踏んだユーザーが攻撃者の罠にはまる

> 🔑 **ポイント**: 攻撃者の目的は、開発者にパッケージをインストールさせることでは**ありません**。npmとそのミラーを「**無料の偽サイトホスティング場所**」として使っているのです。

## 技術的な詳細

### 🏗️ 攻撃のアーキテクチャ（仕組み）

```
攻撃者
  │
  ├─① npmに偽パッケージ（中にHTML）を登録
  │
  └─② unpkg.comが自動ミラー（公開）
          │
          └─③ 信頼ドメイン(unpkg.com)から偽CAPTCHAページが配信
                  │
                  └─④ ユーザーが偽ページにアクセス
                          │
                          ├─⑤-A（初期）Microsoftの偽ログインページへリダイレクト
                          │         → Chromeのセーフブラウジングにブロックされた
                          │
                          └─⑤-B（現在）KeyVal（正規サービス）を経由して
                                    → 攻撃者が設定したURLにリダイレクト
```

### 🔄 巧妙な回避技術：「Dead Drop Resolver（DDR）」

最初は偽のMicrosoftログインページ（`login.microsofte.live` ← 本物と似た偽ドメイン）に誘導していましたが、Googleのセーフブラウジング機能にブロックされてしまいました。

そこで攻撃者は新しい手口を使いました。

**KeyVal（`api.keyval.org`）** という正規のサービスを「中継地点」として利用するようにしたのです。  

料理で例えると：  
> 「毒入りの食品を直接渡すのがバレたので、今度は普通の宅配業者（KeyVal）に荷物を預けて、受け取り側が住所を調べて取りに行く形にした」

このように、正規サービスを踏み台にすることで、セキュリティソフトによる検知を回避しようとしています。これを **「Dead Drop Resolver（DDR）」** といいます（スパイ映画で情報を直接渡さず、隠し場所を経由して受け渡す手口に似ています）。

### 📄 現在の状況
現時点では、最終的な誘導先は **ChatGPTの正規サイト** になっているようです。  
しかし研究者は、**攻撃者がいつでも設定を変えて悪意あるサイトに切り替えられる**状態であると警告しています。つまり「今は害がないが、準備は整っている」という危険な状態です。

## なぜ重要なのか

### ✅ 「信頼できるドメイン」を悪用する点が特に危険

通常、フィッシング詐欺のURLは怪しいドメイン名（`xn--secure-bank-jp.xyz` など）を使うことが多く、見慣れた人は気づけます。  

しかし今回の攻撃では、**`unpkg.com`** という開発者なら誰でも知っている信頼できるドメインからページが配信されます。セキュリティツールも「unpkg.comは安全なサイト」と判断しやすいため、**フィルタリングをすり抜けやすい**のです。

### ♾️ 削除後も残り続ける問題

もう一つ重大な問題があります。  
npmから公式に削除されたパッケージでも、**ミラーサービス上にはファイルが残り続ける**ことがあります。これは図書館で本を返却しても、コピーが他の図書館に残っている状態に似ています。

攻撃者はこれを知った上で、「一度登録すれば長期間使える無料インフラ」として悪用しています。

### 🌐 影響を受ける可能性のある人
- 開発者（unpkg.comのリンクを日常的に扱う）
- 一般ユーザー（偽CAPTCHAのリンクをメールやSNSで受け取った場合）

## 対策・今後の展望

### 👤 一般ユーザー向けの対策

| 対策 | 説明 |
|------|------|
| 🔗 URLをよく確認する | `unpkg.com` のURLでも安心しない。リンクの出所（誰から送られてきたか）を確認する |
| 🤔 CAPTCHAに疑問を持つ | 突然CAPTCHAが現れてコマンドを実行するよう求められたら絶対に従わない |
| 🛡️ セキュリティソフトを使う | 最新のセキュリティソフトを使い、常に更新する |
| 📧 リンクを安易に踏まない | メールやSNSで送られてきた不審なリンクはクリックしない |

### 💻 開発者向けの対策

- npmパッケージを利用・公開する際は、含まれるファイルの内容をしっかり確認する
- 不審なパッケージを見つけたら、npmに報告する

### 🔮 今後の展望

セキュリティ企業はnpmレジストリの監視を強化しています。しかし攻撃者は常に新しい正規サービスを踏み台にする手法を探し続けており、**「いたちごっこ」が続く**と予想されます。

## 過去記事との関連

今回の記事の中でも言及されていますが、**2025年10月にも似た事件が起きていました**。  
セキュリティ会社「Socket」が「**Beamglea（ビームグリア）**」と名付けられたキャンペーンを報告しており、このときも**175個のnpmパッケージ**が `unpkg.com` を悪用して、ユーザーをパスワード窃取ページに誘導していました。

今回の事件はその手口をさらに進化させたものと言えます。  
> 以前は「ミラーからリダイレクト」するだけでしたが、今回は「正規サービス（KeyVal）を中継地点にする」という回避技術が加わり、より検知されにくくなっています。

同じ「npm×unpkgの悪用」という根本的な問題は解決されておらず、攻撃者が繰り返し同じ弱点を突いていることがわかります。

## 用語解説

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **npm** | エヌピーエム | プログラムの部品（パッケージ）を配布する倉庫サービス |
| **unpkg** | アンピーケージ | npmのファイルをウェブ上で直接公開するCDNサービス |
| **CDN** | シーディーエヌ | ファイルを世界中に素早く配信するための中継サービス |
| **CAPTCHA** | キャプチャ | 人間とロボットを区別するための認証（「私はロボットではありません」） |
| **ClickFix** | クリックフィックス | 偽のエラー画面でユーザー自身にマルウェアを実行させる攻撃手口 |
| **フィッシング** | - | 本物そっくりの偽サイトでパスワード等を盗む詐欺 |
| **マルウェア** | - | ウイルスなど悪意のあるソフトウェアの総称 |
| **ミラー** | - | 元のサービスのコピーを別の場所で公開する仕組み |
| **Dead Drop Resolver** | デッドドロップリゾルバー | 正規サービスを「中継地点」として悪意あるURLを隠す技術 |
| **タイポスクワット** | - | 本物のドメインに似た偽ドメインを使う手口（例: microsofte.live） |
| **セーフブラウジング** | - | Googleが提供する危険なURLをブロックする機能 |
| **パッケージ** | - | プログラムの部品をまとめたファイルの集まり |

---

> 💡 **まとめ**: 今回の攻撃の一番のポイントは「**信頼できるサービスを悪用する**」という点です。`unpkg.com` という誰もが知る安全なドメインを使うことで、ユーザーもセキュリティツールも騙されやすくなっています。インターネットでは「有名なドメインだから安全」とは言い切れない時代になっています。URLのリンク先が信頼できるものか、常に一歩立ち止まって考える習慣を持ちましょう。
