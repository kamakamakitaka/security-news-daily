# E4delとPINHOLE：FTPのウェルカムメッセージを悪用した新型マルウェアが発見される

**元記事**: [E4del and PINHOLE RATs Turn FTP Banners Into Dead Drops for Malware Commands](https://inl03.netline.com/ltr6/?_m=3n.009a.4065.sp0ao46r89.34fi)
**解説日**: 2025年8月26日

---

## 背景知識

このニュースを理解するために、まずいくつかの基本的な仕組みを説明します。

### 📁 FTPって何？
**FTP（File Transfer Protocol）** とは、インターネット上でファイルを送受信するための古くからある通信規格です。サーバーに接続すると、最初に「ようこそ！」という短いメッセージが届きます。これを **FTPバナー** と呼びます。ちょうどお店のドアを開けたときに「いらっしゃいませ！」と言われるようなものです。

### 🎮 RAT（リモートアクセストロイ）って何？
**RAT（Remote Access Trojan）** とは、感染したパソコンを**遠隔操作できるようにする悪意のあるプログラム**です。名前の通り「トロイの木馬」のように、無害なソフトウェアのふりをして侵入してきます。感染すると、攻撃者はまるで自分のパソコンを操作するように、あなたのPCを遠隔から自由に動かせるようになります。

### 📮 デッドドロップって何？
**デッドドロップ（Dead Drop）** とはもともとスパイ映画などに出てくる言葉で、「直接会わずに情報を受け渡す隠し場所」のことです。サイバー攻撃の世界では、**マルウェアが次の命令をどこから受け取るかを示す"隠れた場所"** のことを指します。たとえばXのプロフィール欄やGitHubのコメントに命令をこっそり書いておく手口が過去にも確認されています。

### 🖥️ C2サーバーって何？
**C2（Command and Control）サーバー** とは、マルウェアに対して「次はこれをやれ」と命令を送る、攻撃者が管理するサーバーのことです。マルウェアはこのサーバーと定期的に通信して、次の行動を受け取ります。

## 何が起きたのか

セキュリティ企業「SOCRadar」の研究者たちが、**まったく新しいタイプのサイバー攻撃の手口**を発見しました。

🔴 **世界初の確認事例** として、攻撃者が **FTPバナー（サーバーに接続したときのウェルカムメッセージ）を、マルウェアへの命令の隠し場所として悪用**していることが判明しました。

この攻撃で使われているマルウェアは **E4del（イーフォーデル）** と **PINHOLE（ピンホール）** という2種類で、どちらも今まで報告されたことのない新種です。

### 攻撃の入口となる罠
- スペイン語の「クーポン・割引券を受け取れます！」という**偽のメッセージ**でユーザーをだます
- クリックすると、**Windowsのショートカットファイル（.LNKファイル）** が実行される
- そこから次々と悪意のあるプログラムが読み込まれていく

## 技術的な詳細

### 🔗 攻撃の流れ（E4delの場合）

```
ユーザーが偽メールの罠をクリック
        ↓
LNKファイル（ショートカット）が実行される
        ↓
FTPサーバーに接続 → バナー（ウェルカムメッセージ）に命令が隠されている
        ↓
別のFTPサーバーのバナーから次の命令を受け取る（二段構え！）
        ↓
PowerShell（Windowsの管理ツール）でZIPファイルをダウンロード・解凍・実行
        ↓
E4del（RATマルウェア）がインストールされる
        ↓
攻撃者がPCを遠隔操作できる状態に…
```

### 🎭 E4delの特徴：「Discordのふり」をする
E4delは **Discord（ゲーマーに人気のチャットアプリ）に偽装**されています。しかも「Electron」という正規の開発フレームワークを使い、デジタル署名（正規ソフトの証明書）まで付けているため、一見すると本物のアプリのように見えます。

**E4delにできること：**
- 🖥️ デスクトップ画面のリアルタイム映像を攻撃者に送信
- 📸 スクリーンショットの撮影
- 📁 ファイルのダウンロード・送信
- 💻 遠隔からのコマンド実行（シェル操作）
- 🔄 追加マルウェアのインストール
- 🕵️ システム情報の収集

### ⏱️ 巧妙な「タイミングずらし」機能
E4delは、セキュリティシステムに発見されにくいよう、**サーバーへの問い合わせ間隔を動的に変化**させます。

| 状態 | 条件 | 問い合わせ間隔 |
|------|------|----------------|
| **アクティブ** | 最後の命令受信から0〜20秒 | 0.2〜2秒ごと |
| **セミアクティブ** | 20〜40秒間命令なし | 2〜5秒ごと |
| **インアクティブ** | 40秒以上命令なし | 5〜9秒ごと |

まるで「見張りが来たときだけ静かにする泥棒」のような賢さです。

### 🔒 PINHOLE：さらに高度な手口

PINHOLEはE4delよりもさらに洗練されていて、**Pinterest（画像共有サービス）やSurveyMonkey（アンケートサービス）という有名サービスを隠れ蓑として利用**します。

```
FTPバナーに命令が埋め込まれている
        ↓
PowerShellでスクリプトを取得
        ↓
スクリプトは実行後すぐ自動消去（証拠隠滅！）
        ↓
PinterestやSurveyMonkeyからC2サーバーの場所を取得
        ↓
Cloudflare Workers（正規サービス）を経由して通信を隠す
```

有名サービスを経由することで、「普通のネット通信」のように見せかけるわけです。

## なぜ重要なのか

### 🌐 「世界初」の手口が使われた
FTPバナーをデッドドロップとして悪用するのは**世界で初めて確認された手法**です。セキュリティ担当者も「まさかウェルカムメッセージに命令が隠されているとは思わない」ため、発見が遅れる可能性があります。

### 🧩 有名サービスを隠れ蓑にする巧妙さ
PinterestやSurveyMonkey、Cloudflareといった**誰もが知っている信頼性の高いサービスを経由**することで、ファイアウォール（不審な通信を遮断する仕組み）をすり抜けやすくなっています。

### ⚠️ ただし弱点もある
FTPへの接続は、HTTPSなど普通のウェブ通信と比べて**目立ちやすい**という弱点もあります。企業のセキュリティ製品は「見知らぬFTPサーバーへの接続」を怪しいと判断しやすいため、企業環境では比較的検出しやすいとも言えます。

## 対策・今後の展望

### 個人でできる対策

| 対策 | 内容 |
|------|------|
| 🔗 不審なリンクを開かない | 「クーポンが当たった！」などの甘い言葉に注意 |
| 📧 メールの送信元を確認 | 見知らぬ人からのファイルは開かない |
| 🔄 OSとソフトを最新に保つ | 定期的なアップデートで脆弱性を塞ぐ |
| 🛡️ セキュリティソフトを使う | 最新のウイルス定義でE4del/PINHOLEを検出可能に |

### 企業・組織でできる対策
- **FTPへの外部接続を監視・制限**する（不審なFTP接続をブロック）
- **EDR（高度なエンドポイント保護）ツール**を導入する
- PowerShellの実行ポリシーを制限する
- 不審なLNKファイルの実行を制御する

### 今後の展望
この手口が広まると、攻撃者が他にも「普通は命令なんか来ない」ような場所（例：メールの自動返信メッセージ、ゲームのサーバーメッセージなど）を使い始めるかもしれません。セキュリティ業界全体での監視強化が求められます。

以前、**「24個のnpmパッケージが偽のCloudflare CAPTCHAページを配信していた」** という事件を解説しました。

今回の記事でも、**ClickFix（偽のCAPTCHAやエラー画面でユーザーに悪意のあるコマンドを実行させる手口）** が登場しています。PINHOLEの感染経路でも「偽のCAPTCHA」が使われており、正規サービス（Cloudflare）を悪用する点も共通しています。

つまり、「**信頼できるサービスや見慣れた画面に偽装して攻撃する**」という大きな流れが続いており、攻撃者たちが同じ手口を組み合わせ・進化させていることがわかります。

## 用語解説

| 用語 | 意味 |
|------|------|
| **FTP（File Transfer Protocol）** | インターネットでファイルを転送するための通信規格 |
| **FTPバナー** | FTPサーバーに接続した直後に表示されるウェルカムメッセージ |
| **RAT（リモートアクセストロイ）** | 感染したPCを遠隔操作するためのマルウェア |
| **デッドドロップ（DDR）** | マルウェアが次の命令を受け取るための「隠し場所」 |
| **C2サーバー** | マルウェアに命令を送る攻撃者のサーバー |
| **PowerShell** | Windowsに内蔵されている管理・自動化ツール（悪用されやすい） |
| **LNKファイル** | Windowsのショートカットファイル（悪意のある処理を隠せる） |
| **Electron** | Webの技術でデスクトップアプリを作れるフレームワーク |
| **WebDAV** | Webサーバー上でファイル管理ができる仕組み |
| **ClickFix** | 偽のエラーやCAPTCHAを表示してユーザーに悪意のある操作をさせる手口 |
| **ClearFake** | 偽のウェブサイト更新画面を使ってマルウェアを配布する攻撃キャンペーン |
| **Cloudflare Workers** | Cloudflareが提供するクラウド実行サービス（正規サービスだが悪用される） |
| **ビーコニング** | マルウェアがC2サーバーに定期的に「生きてますよ」と連絡する動作 |
| **ジッター** | 通信間隔にランダムなズレを加えて検出を逃れる技術 |

> 💡 **まとめると…**
> 「FTPのウェルカムメッセージ」という、誰も命令が来るとは思わない場所に悪意のある指示を隠す、まったく新しい攻撃手法が発見されました。しかも有名サービスを隠れ蓑にしてセキュリティをすり抜けようとしています。「クーポンが当たった！」などの甘い言葉に乗せられず、不審なファイルは絶対に開かないことが最大の防御策です。
