**元記事**: [INTERPOL Operation Jackal IV Arrests 58, Identifies 263 in Global Cyber Fraud Crackdown](https://inl03.netline.com/ltr6/?_m=3n.009a.4066.sp0ao46r89.34hh)

## 背景知識

まず、この記事を理解するために必要なキーワードを整理しましょう。

### インターポール（INTERPOL）とは？
「国際刑事警察機構」の略称で、196か国が加盟する世界最大の国際警察組織です。各国の警察が単独では追いかけられない「国境をまたぐ犯罪」を協力して取り締まります。ちょうど、各国の警察を束ねる「世界の警察司令塔」のようなイメージです。

### 西アフリカ系犯罪組織とは？
ナイジェリアを中心とした西アフリカ地域に拠点を置く、国際的な詐欺・マネーロンダリング（資金洗浄）を専門とする犯罪グループです。「ブラック・アックス（Black Axe）」はその代表格で、世界中に支部を持ちます。

### 今回の主な詐欺の手口（3種類）

| 詐欺の種類 | わかりやすい説明 |
|---|---|
| **ロマンス詐欺** | SNSや出会い系アプリで「恋人」を演じ、お金をだまし取る |
| **仮想通貨・投資詐欺** | 「絶対に儲かる！」と嘘の投資話で資金を騙し取る |
| **ビジネスメール詐欺（BEC）** | 会社の上司や取引先になりすましたメールで送金させる |

## 何が起きたのか

2025年11月〜2026年6月の約8か月間、インターポールが主導した**「作戦ジャッカルIV（Operation Jackal IV）」**が実施されました。

6大陸の**22か国が参加**したこの大規模作戦の結果は以下の通りです👇

- 🚨 **58人を逮捕**
- 🔍 **263人の容疑者を特定**
- 💰 **約267万ドル（約4億円）を押収**
- 🏦 **257の銀行口座を凍結**

参加国には**日本も含まれており**、オーストリア、アルゼンチン、オーストラリア、カナダ、フランス、ドイツ、インドネシア、アイルランド、イタリア、マレーシア、オランダ、ナイジェリア、ポルトガル、南アフリカ、スペイン、スウェーデン、スイス、UAE、英国、米国など、文字通り「世界総出」での摘発作戦でした。

## 技術的な詳細

### 事例①：「サービスとしての犯罪（CaaS）」ネットワークの摘発

今回、特に注目すべきは**196人が関与した「CaaS（Crime-as-a-Service）ネットワーク」**の解体です。

> 💡 **CaaSとは？**
> 「犯罪のサービス化」という意味です。まるでAmazonが商品を売るように、犯罪に必要なツールや仕組みを「売る」・「貸す」ビジネスモデルです。

このネットワークは、詐欺師たちに以下のものを提供していました：

```
┌─────────────────────────────────┐
│   CaaS（犯罪サービス）の提供内容     │
├─────────────────────────────────┤
│ ✓ 偽のウェブサイト用ドメイン         │
│   （本物そっくりの詐欺サイトを作成）  │
│ ✓ マネーロンダリングのサポート       │
│   （盗んだお金の出所を隠す仕組み）   │
└─────────────────────────────────┘
```

つまり「自分で詐欺はしないけど、詐欺師をサポートするビジネス」が存在していたわけです。これに関連して**17人が逮捕**されました。

---

### 事例②：南アフリカのロマンス詐欺組織

ヨハネスブルグ（南アフリカ最大の都市）の7か所を家宅捜索。英語圏の**退職者**を狙ったロマンス詐欺・投資詐欺の組織が摘発されました。

この組織の面白い（というか怖い）点は、**普通の会社みたいに役割分担**されていたことです：

```
組織の構造（普通の会社と同じ！）
├── 「コンバージョン担当」
│     → 被害者を最初に口説いて詐欺に引き込む係
└── 「リテンション担当」
      → 被害者が疑い始めたとき、引き留める係
```

まるでコールセンターのように分業化された「詐欺工場」だったわけです。**39人逮捕、267万ドル押収**。

---

### 事例③：ルーマニアの投資詐欺コールセンター

ルーマニアで運営されていたコールセンター型の投資詐欺も摘発されました。

- 「株や仮想通貨で高リターンが得られる！」と嘘の宣伝
- 騙された被害者がお金を振り込むと…
- 詐欺師が管理するウォレット（財布）に送られ、全額横取り

被害総額は**推定1億6600万ドル（約250億円！）**。11人が逮捕され、現金・不動産・高級腕時計などが押収されました。

---

### 事例④：ヨーロッパ規模のマネーロンダリング

ある1つの口座だけで、**560回の取引、20種類の金融手段**を使って**約8億円相当を洗浄**していたケースも発覚。「ペーパーカンパニー（実体のないダミー会社）」や「送金サービス」「現金引き出し」を組み合わせてお金の出所を隠していました。

## なぜ重要なのか

### 📈 シリーズ作戦としての成果の積み上がり

今回は「ジャッカル作戦」の第4弾です。過去の成果と比較してみましょう：

| 作戦 | 時期 | 逮捕者数 | 特定容疑者 | 凍結口座 |
|---|---|---|---|---|
| ジャッカルI | 2022年9月 | 75人 | — | — |
| ジャッカルII | 2023年5月 | 103人 | 1,110人 | 208口座 |
| ジャッカルIII | 2024年4-7月 | **300人** | 400人 | 720口座以上 |
| **ジャッカルIV** | **2025-2026年** | **58人** | **263人** | **257口座** |

第3弾より逮捕者数は少ないですが、今回は**「組織の資金の流れ」を追うことに重点**が置かれており、より高度な犯罪ネットワークの解体を狙っています。

### 🌍 あなたにも関係する話

これらの詐欺は「海外の話」ではありません。日本も参加国に含まれており、実際に日本人も被害を受けています。特に：

- SNSで知り合った「外国人」からの投資話 → **ロマンス詐欺 or 投資詐欺**
- 会社の上司になりすましたメールでの送金依頼 → **BEC詐欺**

は今まさに日本でも多発しています。

## 対策・今後の展望

### 🛡️ あなたが今日からできる対策

**ロマンス詐欺・投資詐欺への対策**
1. SNSで知り合った「会ったことのない人」からの投資話は100%疑う
2. 「絶対儲かる」「元本保証」は詐欺のサインです
3. 急いで振り込むよう促されたら、一度立ち止まる

**ビジネスメール詐欺への対策**
1. 送金を求めるメールは、必ず電話で本人確認する
2. メールアドレスのドメイン（@以降）をよく確認する

**全般的な対策**
- 怪しいと思ったら**警察庁の「#9110」**に相談
- 国際ロマンス詐欺の情報は**消費者庁・国民生活センター**に

### 🔮 今後の展望

インターポールのTomanobu Kaya（加屋友暢）部長は「国際協力の力を示した作戦だ。不正な資金の流れを追うことで、組織犯罪の"血液"を断ち切り、犯罪グループが活動しにくい環境を作り続ける」とコメントしています。

「ジャッカルV」の実施も今後予想されます。

## 過去記事との関連

今回の記事は、過去に解説した記事とは直接の技術的なつながりはありませんが、サイバーセキュリティの「大きな流れ」として関係しています。

以前、**「SLEEPWALKER バックドア」**（特殊なパケットを受け取るまで潜伏するマルウェア）を解説しましたが、今回の事件のような詐欺組織も、同様に「**発覚しにくくするための工夫**」に多大な労力をかけています。CaaSネットワークが提供する偽ドメインやマネーロンダリングの手口は、まさに「サイバー犯罪を見えにくくする仕組み」の一例です。

攻撃者は常に「見つかりにくく」なろうとしており、それに対抗するために国際的な協力が欠かせないことが、今回の作戦からもわかります。

## 用語解説

| 用語 | 解説 |
|---|---|
| **INTERPOL（インターポール）** | 196か国が加盟する国際刑事警察機構 |
| **Black Axe（ブラック・アックス）** | ナイジェリア発祥の国際犯罪組織。サイバー詐欺で悪名高い |
| **ロマンス詐欺** | SNS等で恋愛感情を利用してお金を騙し取る詐欺 |
| **BEC（ビジネスメール詐欺）** | 会社の役員や取引先を装ったメールで送金させる詐欺 |
| **CaaS（Crime-as-a-Service）** | 犯罪ツールやインフラを他の犯罪者に提供するビジネスモデル |
| **マネーロンダリング（資金洗浄）** | 犯罪で得たお金の出所を隠す行為 |
| **シェルカンパニー（ペーパーカンパニー）** | 実際には活動していない「名前だけの会社」。資金隠しに使われる |
| **ドメイン** | ウェブサイトのアドレス（例：google.com）のこと |
| **ウォレット（仮想通貨）** | 仮想通貨を管理するためのデジタル財布 |
| **OST（作戦支援チーム）** | インターポールが現地捜査を支援するために派遣する専門チーム |
