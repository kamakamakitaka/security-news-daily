# 「眠り歩き」バックドア「SLEEPWALKER」— 特殊なパケットを受け取るまで完全に潜伏し、独自の命令言語で動く新型マルウェア

**元記事**: [Newly SLEEPWALKER Backdoor Waits for One Crafted Packet, Then Runs Its Own Bytecode](https://inl03.netline.com/ltr6/?_m=3n.009a.4066.sp0ao46r89.34h2)
**解説日**: 2025年8月27日

---

## 背景知識

このニュースを理解するために、いくつかの基本的な概念を先に押さえておきましょう。

### 🏠 DLL（ダイナミックリンクライブラリ）とは？

Windowsのプログラムは、全ての機能を1つのファイルに詰め込むのではなく、「部品」として別のファイルを読み込んで使います。この「部品ファイル」が**DLL（`.dll`という拡張子のファイル）**です。

> 例え話：DLLは「調理道具の共有棚」のようなもの。複数の料理人（プログラム）が同じ道具（DLL）を棚から取り出して使います。

### 🎭 DLLサイドローディングとは？

Windowsは、プログラムが必要なDLLを探す際に「決まった順番（検索順序）」で探します。この仕組みを悪用して、**正規のDLLより先に悪意あるDLLを読み込ませる**攻撃が「DLLサイドローディング」です。

> 例え話：本物の鍵と同じ形に作った偽の鍵を、本物より手前の引き出しに入れておく、というイメージです。

### 🔐 バックドアとは？

家の「裏口（バックドア）」から攻撃者がこっそり侵入できるようにする仕組みです。通常のセキュリティチェックをすり抜けて、外部から命令を受け取り実行します。

### 📦 バイトコードとは？

人間が読めるプログラミング言語（例：Python、Javaなど）を、コンピュータが直接実行できる形に変換した中間的な命令の集まりです。今回のマルウェアは「誰も知らない独自の言語」でできたバイトコードを使っています。

## 何が起きたのか

独立系のマルウェア研究者が、**「SLEEPWALKER（スリープウォーカー＝夢遊病者）」**と名付けられた、これまで報告されていなかった新型Windowsバックドアを発見・公表しました。

### 発見のポイントをまとめると…

| 項目 | 内容 |
|------|------|
| 対象OS | Windows（64ビット） |
| ファイルサイズ | 約59,904バイト（約60KB）と非常に小さい |
| 偽装対象 | Microsoftの正規DLL「dpapi.dll」 |
| 侵入先プログラム | ESETのセキュリティ管理ソフト「ERAAgent.exe」 |
| 発見者 | 元Palo Alto Networks Unit42のDominik Reichel氏 |

名前の「スリープウォーカー（夢遊病者）」は、**命令が来るまで完全に眠っていて（何もせず）、特定の合図があって初めて動き出す**という動作から来ています。まるで夢遊病者が寝ながら歩くように、ひっそりと存在し、気づかれないまま活動するのです。

## 技術的な詳細

### 🥷 Step 1：潜伏（眠り続ける）

SLEEPWALKERは、**特定のネットワークパケット（通信データのひとかたまり）を受け取るまで、一切何もしません。**

- 不審な外部への通信をしない
- ドメイン名・IPアドレスなどをファイル内に持たない
- ただメモリ上に存在し、ネットワークを監視し続けるだけ

> 例え話：スパイが街角のカフェで普通の客のふりをして座り、特定の合言葉を聞くまで絶対に動かない、というイメージです。

これにより、**「怪しい通信先への接続」を検知するセキュリティツールには引っかかりません。**

### 📡 Step 2：起動トリガー（目覚めの合図）

攻撃者が「特別に細工されたネットワークパケット」を送ると、SLEEPWALKERは目を覚まします。

さらに驚くことに：

- 自分宛てのパケットだけでなく、**他のコンピュータ宛てのパケットも盗み見る（プロミスキャスモード）**
- そのため、ゲートウェイ（ネットワークの入口）やVPNサーバーに感染していれば、別のマシン宛てのトリガーでも起動できる

> 例え話：カフェ全体の会話を聞き耳立てていて、隣のテーブルの合言葉でも動き出せる、というイメージです。

### 🔤 Step 3：独自の命令言語（23命令のバイトコード）

SLEEPWALKERは**自分だけの専用プログラミング言語**を持っており、23種類の命令（オペコード）で動作します。

この命令セットでできることは：
- ⏰ スケジュール管理（タイミングを制御）
- 📁 ファイルの分割配信（SHA-256ハッシュで検証後に実行）
- 💾 データの移動・操作
- 🧠 **ディスクに書き込まずメモリ上で直接コードを実行**（フォレンジック対策）

### 📶 Step 4：6種類の通信手段

SLEEPWALKERは以下の6種類のプロトコル（通信方法）を使えます：

| 通信方法 | 説明 |
|----------|------|
| TCP | 一般的なインターネット通信 |
| UDP | 映像や音声などに使われる通信 |
| ICMP | ping（通信確認）に使われる通信 |
| SMB名前付きパイプ | Windows内部のプロセス間通信 |
| プロミスキャスキャプチャ | ネットワーク上の全パケットを盗聴 |
| **VMCI** | 仮想マシン専用の通信経路（後述） |

### 🖥️ 特に怖い「VMCI」通信

**VMCI（Virtual Machine Communication Interface）**とは、仮想マシン（VM）とその親となる物理マシン（ESXiホスト）の間だけで使われる特殊な通信路です。

- **通常のネットワークキャプチャツールでは検出できない**
- 外から見ると「通信していない」ように見える

> 例え話：建物の外から見ると人が動いていないのに、実は壁の中に秘密の通路があって、中でこっそり荷物を運んでいる状態です。

## なぜ重要なのか

### 🎯 「国家レベル」の攻撃を疑わせる高度さ

元Unit42の研究者Reichel氏は「これは**標的を絞った潤沢なリソースを持つ組織による攻撃**と一致している」と述べています。つまり、**国家が支援するハッカー集団**による攻撃の可能性があります。

### 🔍 検出が非常に難しい

| 回避している検出方法 | 理由 |
|---------------------|------|
| 不審な通信先への接続チェック | 外部への通信をしない |
| ファイル書き込み監視 | メモリ内でのみ動作 |
| 既知のマルウェアパターン | 独自の命令言語を使用 |
| ネットワーク監視 | VMCI通信はパケットキャプチャに映らない |
| デジタル署名チェック | ホストプロセス名だけ確認（署名は見ない） |

### 😰 まだ多くのことが不明

- **誰が作ったのか**（既知のハッカー集団との関係不明）
- **実際に使われたのか**（実運用された証拠なし）
- **被害を受けた組織や国**（不明）
- **どうやって最初に侵入したのか**（不明）

## 対策・今後の展望

### ✅ 現時点でできる対策

**1. パッチ（修正プログラム）はない**
> このマルウェアはESETのバグを使っていないため、「ESETを更新すれば防げる」という話ではありません。WindowsのDLL検索順序という**仕様**を悪用しているためです。

**2. 感染が判明した場合の対応**
- **即座にインシデントレスポンス**（専門家による調査対応）
- **システムの再構築**（クリーンインストール）

**3. 予防的な対策**
- 管理者権限の最小化（攻撃者は最初から管理者権限を持っていることが前提）
- ネットワーク内の異常な通信パターンの監視
- EDR（エンドポイント検出・対応）ツールの導入
- ESET Management Agentが動作するディレクトリへの書き込み権限を制限

**4. ESETのコメント**
> 2025年8月26日時点で、ESETは公式なアドバイザリや声明を出していません。The Hacker Newsがコメントを求めており、続報を待つ必要があります。

### 🔮 今後の展望

- 同じ手法を使う他のマルウェアが発見される可能性
- セキュリティベンダーによる検出シグネチャの追加
- ESETによる公式見解の発表

## 過去記事との関連

記事の中に、過去の関連事例として**「ToddyCat（トッディキャット）」**というハッカー集団の事例が紹介されています。

このグループも過去にESETのコマンドラインスキャナーの**DLL検索順序の脆弱性**を悪用して、悪意あるDLLをESETに読み込ませるという似た手法を使っていました（Kasperskyが報告）。

また、**UNC3886**というグループが、VMwareの仮想マシン間通信（VMCI）を使って検出を回避しながら攻撃を行っていたことをMandiantが記録しており、SLEEPWALKERも同じ技術を取り込んでいることがわかります。

> つまり、「以前から悪用されていた技術をパーツとして組み合わせ、さらに高度化させた」のが今回のSLEEPWALKERと言えます。

## 用語解説

| 用語 | 解説 |
|------|------|
| **DLL（ダイナミックリンクライブラリ）** | Windowsのプログラムが共有して使う「部品ファイル」（拡張子`.dll`） |
| **DLLサイドローディング** | WindowsのDLL検索順序を悪用して、偽のDLLを先に読み込ませる攻撃 |
| **バックドア** | 攻撃者がこっそり侵入・操作できる「裏口」 |
| **バイトコード** | 人間向けのプログラムを中間形式に変換したもの。今回は独自形式 |
| **AES-256-CCM** | 軍事レベルの強力な暗号化方式 |
| **プロミスキャスモード** | 自分宛て以外のネットワーク通信も盗み見るモード |
| **VMCI** | 仮想マシンとホスト間の特殊な通信経路。通常のパケット監視では見えない |
| **インシデントレスポンス** | セキュリティ事故が起きた際の専門的な対応手順 |
| **ESXi** | VMwareの仮想化基盤ソフトウェア（多くの企業のサーバーで使用） |
| **SHA-256ハッシュ** | ファイルが改ざんされていないか確認するための「電子的な指紋」 |
| **フォレンジック** | デジタル機器を調査して証拠を集める技術（犯罪捜査の電子版） |
| **Unit42** | Palo Alto Networksのセキュリティ研究チーム |
| **ERAAgent.exe** | ESETのセキュリティ管理エージェントの実行ファイル |
| **SMB名前付きパイプ** | Windowsのプロセス間通信や共有フォルダ通信に使われる仕組み |
| **オペコード** | コンピュータへの命令コードのこと（Operation Codeの略） |
