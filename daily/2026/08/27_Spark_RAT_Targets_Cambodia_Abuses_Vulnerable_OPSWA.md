# カンボジアを標的にしたSpark RAT攻撃：セキュリティソフトを無効化する巧妙な手口

**元記事**: [Spark RAT Targets Cambodia, Abuses Vulnerable OPSWAT Driver to Disable Security Tools](https://inl03.netline.com/ltr6/?_m=3n.009a.4067.sp0ao46r89.34ip)
**解説日**: 2026年8月28日

---

## 背景知識

まず、この記事を理解するために必要な基礎知識をざっくり説明します。

### 🖥️ RAT（リモートアクセス型トロイの木馬）とは？
「RAT」とは **Remote Access Trojan** の略で、感染したパソコンを**遠隔から不正に操作できるようにするウイルス**のことです。ギリシャ神話の「トロイの木馬」のように、無害に見せかけて侵入します。映画やドラマでよく見る「ハッカーが遠くから他人のパソコンを操作している」シーンは、まさにこれです。

### 🛡️ セキュリティソフトとドライバーとは？
- **セキュリティソフト**：ウイルスを検知・ブロックするソフト（例：Windows Defenderなど）
- **ドライバー**：ハードウェアやOSの深い部分を操作するための特別なプログラム。車で言えば「エンジン直結の制御装置」のようなもの

### 🚗 BYOVD（脆弱なドライバーを持ち込む）攻撃とは？
**Bring Your Own Vulnerable Driver** の略で、「**自分で欠陥品のドライバーを持ち込む攻撃**」です。
たとえば、学校の正門（セキュリティ）は突破できないけど、**合法的な業者の制服を着て（正規のドライバーを装い）、裏口から入る**ようなイメージです。正規ソフトのドライバーに欠陥があることを悪用し、OSの深い部分に潜り込みます。

### 🎣 フィッシングメールとは？
**本物のメールに見せかけた偽のメール**で、悪意あるファイルを開かせようとするものです。「政府からの通知です」「重要な健康情報があります」などと偽って、受け取った人をだまします。

## 何が起きたのか

セキュリティ企業 **Acronis** の研究チームが、**カンボジア**の個人・組織を狙った新しいサイバー攻撃キャンペーンを発見しました。

### 攻撃の流れ（全体像）

```
① 偽メール送信（政府通知・健康情報・不動産書類などを装う）
        ↓
② 被害者が圧縮ファイルを開いてしまう
        ↓
③ 悪意あるプログラムがインストールされる
        ↓
④ セキュリティソフトを無効化する
        ↓
⑤ Spark RAT が起動 → パソコンを遠隔操作される
```

攻撃は **2026年6月末〜8月上旬** の間に確認されており、現在も続いているかどうかは不明です。

### おとりに使われたテーマ
攻撃者はさまざまな偽の内容で被害者をだまそうとしました：
- 📜 カンボジア政府の公式通知（に見せかけたもの）
- 🏥 公衆衛生・健康に関するお知らせ
- 🦷 歯科検診の記録
- 🏠 不動産に関する書類
- 🎁 プロモーション・割引情報

幅広い内容を使うことで、「誰かは引っかかる」という戦略を取っています。

## 技術的な詳細

少し複雑ですが、なるべくわかりやすく説明します！

### ステップ①：最初の侵入（偽メール＋圧縮ファイル）

攻撃者はフィッシングメールで**圧縮ファイル（ZIPなど）**を送ります。その中には `Inno Setup` という正規のインストーラーに見せかけた実行ファイルが入っています。

> 💡 **Inno Setupとは？** 本来はソフトウェアをインストールするための正規ツールです。攻撃者はこれを悪用しています。

### ステップ②：DLLサイドローディングで正規ソフトを悪用

インストーラーが起動すると、**テンセント（Tencent）の正規署名付きプログラム**を使って悪意あるDLLファイルを読み込ませます。

> 💡 **DLLサイドローディングとは？** Windowsでは、プログラムが起動するときに必要な部品ファイル（DLL）を読み込みます。攻撃者は正規プログラムに「偽の部品」をこっそり読み込ませる手口を使います。警備員（正規プログラム）の隣に偽の仲間（悪意あるDLL）を忍び込ませるイメージです。

### ステップ③：アンチサンドボックスで解析を回避

マルウェア（悪意あるソフト）は、**自分が「検査用の仮想環境（サンドボックス）」の中にいるかどうか**を確認します。

- セキュリティ研究者はウイルスを「サンドボックス」という隔離された仮想環境で動かして調べます
- このマルウェアは「睡眠時間（スリープ）が不自然に短縮されているか」をチェックし、調査されていると判断したら自動的に止まります

> 🧪 **例え話**：「テストだとわかったら演技を止める」スパイのような振る舞いです。

### ステップ④：BYOVDでセキュリティソフトを無力化（核心部分！）

ここが今回の攻撃の最も巧妙な部分です。

**`ardrv.sys`** という、OPSWAT AppRemoverというソフトの正規ドライバーに、**CVE-2026-36425** というセキュリティ上の欠陥（脆弱性）があります。

攻撃者はこの欠陥を使って：
1. 管理者以上の権限（SYSTEM権限）を獲得
2. **Windows Defender、Huorong Internet Security、Tencent PC Managerなどのセキュリティソフトを強制終了**

> 🔑 **例え話**：鍵のかかったドアを正面突破するのではなく、「合法的に手に入れた合鍵（正規ドライバー）の欠陥」を使って裏から侵入するイメージです。

### ステップ⑤：AMSI・ETWを無効化

- **AMSI**（Antimalware Scan Interface）：Windowsが悪意あるスクリプトをスキャンする仕組み
- **ETW**（Event Tracing for Windows）：Windowsの動作ログを記録する仕組み

これらを無効化することで、マルウェアの動作が**記録・検知されにくくなります**。

### ステップ⑥：PNGファイルに隠されたコード

このマルウェアのユニークな点は、**画像ファイル（PNG）の中にこっそりコードを隠している**ことです。

> 💡 これを**ステガノグラフィー**（電子透かし技術の悪用）と言います。「ただの画像ファイル」に見せかけて、その中に命令コードを埋め込んでいます。手紙の文字を読むと普通のメッセージだけど、特定の文字を拾うと暗号が現れる、というスパイ映画のような手法です。

### ステップ⑦：Spark RATの起動と常駐化

最終的に `ctfmon.exe`（Windowsの正規プロセス）などに悪意あるコードを注入し、**Spark RAT**が起動します。

- Go言語で作られたオープンソースのRAT
- Windows・Mac・Linuxを横断して動作できる（クロスプラットフォーム）
- 感染したパソコンを攻撃者が遠隔操作できる

また、**常駐化（パソコンを再起動しても生き残る）** のために：
- Windowsサービスへの登録
- タスクスケジューラへの登録

の2つの方法でしつこく生き残ります。

## なぜ重要なのか

### 🎯 1. 攻撃の精巧さが際立つ
単純なウイルスと違い、この攻撃は：
- セキュリティソフトを**積極的に無効化**する
- 正規ツール・正規ドライバーを**巧みに悪用**する
- 複数の段階を踏んで**追跡・解析を困難にする**

という多層的な工夫が施されています。

### 🌏 2. 国家レベルの関与が疑われる可能性
政府通知を装ったフィッシング、Tencent製品の悪用、中国系セキュリティソフト（Huorong、Qihoo 360）の確認など、**地政学的な背景が透けて見える**攻撃です。

### 🌐 3. カンボジアに留まらない可能性
使われているSpark RATはオープンソース（誰でも入手可能）であり、手口が公開されることで**他の地域・組織への転用**が心配されます。

### 🛡️ 4. セキュリティソフトを信頼しすぎることの危険性
「セキュリティソフトが入っているから安心」という考えが通用しない攻撃です。

## 対策・今後の展望

### ✅ 個人・組織ができる対策

| 対策 | 説明 |
|------|------|
| 🎣 不審なメールを開かない | 政府機関・公的機関からの連絡はまず公式サイトで確認 |
| 📦 知らない圧縮ファイルを実行しない | メール添付の実行ファイル（.exe）は特に要注意 |
| 🔄 OSとソフトを最新に保つ | 脆弱性（CVE-2026-36425）は修正パッチで対応される可能性がある |
| 🔐 最小権限の原則 | 普段使いのアカウントに管理者権限を与えない |
| 📊 ログ監視の強化 | ETW・AMSIの無効化を検知する仕組みを整備する |
| 🏢 企業はEDRを導入 | 振る舞い検知型のセキュリティツールを使う |

### 🔮 今後の展望
- **CVE-2026-36425への対応**：OPSWATがドライバーの修正パッチを提供することが期待されます
- **BYOVD攻撃の増加**：この手口は近年増加傾向にあり、今後も注意が必要です
- Microsoftは脆弱なドライバーをブロックリストに追加することで対応できますが、イタチごっこが続いています

## 用語解説

| 用語 | 説明 |
|------|------|
| **RAT（リモートアクセス型トロイの木馬）** | 感染したPCを遠隔操作するためのマルウェア |
| **BYOVD** | 欠陥のある正規ドライバーを攻撃に悪用する手法 |
| **Spark RAT** | Go言語で書かれたオープンソースのRAT。複数のOSで動作する |
| **フィッシングメール** | 本物を装った偽メールで悪意あるファイルを開かせる手口 |
| **DLLサイドローディング** | 正規プログラムに偽のDLLファイルを読み込ませる攻撃 |
| **サンドボックス** | マルウェアを安全に動かして分析するための隔離された仮想環境 |
| **AMSI** | Windowsがスクリプトの悪意を検知する仕組み |
| **ETW** | Windowsの動作ログを記録する仕組み |
| **ステガノグラフィー** | 画像や音声ファイルの中にデータを隠す技術 |
| **CVE** | セキュリティ上の欠陥（脆弱性）に振られる識別番号 |
| **SYSTEM権限** | Windowsで最も強い管理者権限 |
| **プロセスインジェクション** | 正規プロセスに悪意あるコードを注入して実行させる技術 |
| **オープンソース** | ソースコードが公開されており、誰でも使えるソフトウェア |
| **クロスプラットフォーム** | Windows・Mac・Linuxなど複数のOSで動作すること |
